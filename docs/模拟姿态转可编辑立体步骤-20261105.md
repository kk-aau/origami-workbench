# 模拟姿态转为可编辑立体步骤

“将当前姿态应用到下一步”原先保存模拟曲面，并把渲染图放入画布，关闭纸面折线与 CP 联动。用户需要的是普通立体步骤，可转动、选纸层、画折线并继续编辑。

| 修改 | 行为 |
| --- | --- |
| 提取实际折角并求闭合解 | 固定一条实际测得的驱动折痕，求其余折痕的闭合角；此转换不使用 ±0.25° 修正范围。若某个驱动产生不合适的空间分支，继续尝试其他实际驱动。仍执行来源、方向、几何和遮挡验证。 |
| 使用正常 `DiagramPose.spatial` | 下一步具有真实材料面、面变换、空间顶点及 CP 身份，启用正常纸面与绘图编辑。原曲面文件仍可载入。 |
| 观察方向 | 从模拟的稳定纸面恢复朝向，按普通立体画布的正交投影显示；转动视角走现有空间编辑流程。 |
| CP 与步骤 | 校正后的实际角度写入共享 CP；保留完整目标角记录。已创建但无操作的下一步同步继承新角度，已有后续操作不直接覆盖。 |
| 原子提交 | Worker 完成后一次提交；停止、失败或来源变化时不改变工程。计算无默认时限。 |
| 修正量 | 界面说明会校正闭合折角，成功消息报告最大修正角，CP 元数据记录转换方式与修正量。不能把该结果称为模拟曲面逐点完全相同。 |

验证：19 项定向测试通过，覆盖画线写回 CP、转动时折线跟随、保存重开、六射线预折工程、旧折角应用行为和空间视角事务；TypeScript 与前端构建通过。

真实界面使用用户《千纸鹤》工程：95% 模拟经按钮生成第 5 步，最大修正显示 2.32°，立体转动及 CP 联动可用。另在生成工程上绘制折线，CP 从 72 条变为 78 条，转动后视角保存成功。浏览器控制台无错误。证据位于 `.runtime/editable-simulation-qa/`。
