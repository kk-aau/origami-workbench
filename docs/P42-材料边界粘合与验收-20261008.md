# 第42节材料边界粘合与验收（2026-10-08）

完整复现目标保持 active。本批补齐材料切开后的显式边界粘合；源码及网页已更新，现有 v0.13.5 免安装 EXE 未重打包。有限输入与回归通过不表示全部 Origamica / Wolfram 语义已经复现。

| 功能 | 当前行为 |
|---|---|
| 入口与选边 | 材料属性面板新增“粘合材料边界”。用户明确选择两侧边 ID，可增加至256对；第二侧仅列出 CP 端点完全重合、面侧方向相反的完整边界候选。不会因坐标重合自动粘合其他边。 |
| 连接类型 | 每对明确选择 M/V/F/U。M/V 为反射铰链，F 为平面连接，U 保持未知角与未知层序语义；这是材料连接类型，不是加工方式设置。 |
| 预览与取消 | 毫米坐标、刻度、边 ID / 所属面、第一侧紫色与第二侧青色虚线可视化；显式预览显示部件数量和折后位置处理。修改配对或类型使旧预览失效，失败不能应用，取消不改工程。1000×720与800×720窗口无整体滚动。 |
| CP 与身份 | 不吸附、不移动 CP 端点，不改各面的 CP 坐标和面编号；只合并用户明确配对的顶点身份。保留第一侧边 ID 与显示样式，第二侧选择映射到第一侧；其他材料边、辅助对象及元数据保留。 |
| 折后位置 | 新连接与旧 FF 相容时逐值保留各面的 FF；不相容时从原固定面姿态传播刚性变换，重新核对共享顶点、铰链闭环及逐面等距。原固定面不移动；其他合并部件可以随新连接重算 FF。没有 FF 的工程不虚构折后位置。 |
| 提交与历史 | 中央提交从旧工程独立重放粘合意图，与完整提案比对；篡改、过期或非法提案原子拒绝。应用后旧平折层序过期，重新计算；撤销/重做恢复完整工程。 |
| 保存与显示 | 实际 JSON 工程与 CP/FF 双帧 FOLD 下载、重开、重新平折、同画布正背面显示均已验收。 |

共享刚性传播提取到原重算流程与粘合流程共同使用。原同拓扑编辑的前置检查保留；新入口要求面数量、面顺序及每个面角的 CP 坐标保持原值。严格材料拓扑校验、材料切口内核及加工优化导出的三个文件与本批基线 SHA 相同，没有放宽旧校验或改变普通 DXF 格式。

粘合仅支持完整边段端点精确对应、面侧相反的材料边界。重复使用同一边、非边界、同面自接、微小间隙、不可形成合法材料拓扑或无法闭合的平折连接明确拒绝，不自动修正几何。不同长度边的部分粘合需要先实现明确细分，当前没有隐式切分。U连接不伪造已认证层序。
