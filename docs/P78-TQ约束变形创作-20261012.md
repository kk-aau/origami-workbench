# P78 TQ 约束变形创作

入口为“镶嵌设计 → 空间构造类型 → 原 TQ 约束变形 CP”。采用后，在折痕编辑点击“修改 TQ 约束设计参数”继续编辑，同一模型重建保留名称和 UUID。

| 构造 | 实际创作 |
| --- | --- |
| 自由褶带／平折偏好褶带／错位褶带 | 拖动或数值编辑三维点目标；刚性四边形、弯曲和平折硬度、峰谷约束与原分面 |
| 双平面／平面与点目标 | 编辑原顶点组、平面原点、法向及点目标；XY/XZ/YZ 投影保留未显示轴 |
| 3×3／5×5 水雷 | 原水雷来源、有限受约束拉伸、目标点与硬度；相连点可成对修改 |
| 水雷基础形 | 原开合角与偏斜角，数值和滑条；原未参与计算的 θ₂ 明确保留标记 |

保留原 CP 位置、单位、顶点及边身份，用原 In[2656] 的边长、四边形对角条件及外部约束求原能量的工程局部解。有限弯曲构造采用声明并验证的 13 分枝；刚性四边形验证两条对角线。原分面保留符号与优先次序，不替换对角来制造刚性假象。重力参数在原式未使用，不提供假生效控件。三维显示只是参考，没有附加未证明的 Scene、平折、层序或连续运动认证。

拖点时本地输入图立即更新，松开后才请求计算；数值输入合并请求，只有当前有效结果可采用。独立 Worker 使用现有会话认证及忙等待协议，取消和过期结果不能写入工程。无效约束保留参数和旧图的明确标记，用户可继续调整另一目标点；瞬时不可达的单点状态不能被当作有效结果。
