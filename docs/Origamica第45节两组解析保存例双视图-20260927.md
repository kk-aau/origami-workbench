# 第 45 节两组解析保存例的只读双视图

本入口仅把已独立验证的两组保存输入接到工作区的二维／三维对照视图。圆锥 `FoldAcrossRightBoth` 对应 In[3999]／数值取样 In[4002]；平面圆弧 `FoldCurvedFold3D` 的正负 120° 分别对应 In[3973]/In[3978] 和 In[3974]/In[3979]。原笔记本没有这几例可逐点比较的数值曲面 Out；本项目展示的是依据其源码方程、保存参数和初值重建的连续解析曲面采样。

`backend/tessellation_curved_saved_pair_query.py` 使用封闭 JSON 输入，只调用既有的 `certify_cone_across_right` 和 `fold_curved_circle_3d`，不解析表达式字符串。专用 `POST /api/tessellation/curved-saved-pair` 经本地会话令牌和 `operation='curved-saved-pair'` 分发；通用 `/api/tessellate` 拒绝提交该分析 operation。工作区候选折痕、纸面和工程状态不会被写入。

| 参数 | 圆锥保存子域 | 正／负平面圆弧子域 |
| --- | --- | --- |
| 族标识 | `cone-across-right` | `planar-circle-to-curved-fold-3d` |
| 关键输入 | `thetaDeg∈[5,85]`；`parameterStartPi/EndPi∈[-2,2]` 且区间长 `0<Δ≤1` | `orientation∈{+1,-1}`，固定 `u∈[0,π]`、折角 `±120°` |
| 左／右母线宽度 | 左 `[.05,.95]`，右 `[.05,4]`；左侧严格止于锥顶前 | 两侧 `[.05,1.8]`；严格止于焦半径 2 前 |
| 数值网格 | `curveSegments∈[16,256]`，`rulingSegments∈[1,8]`，总点数至多 4000 | 同左 |

默认圆锥保存参数为 `θ=30°、u∈[-π/2,π/2]、左右宽度=.75`；默认圆弧为正 120°、左右宽度 1。服务端和 `src/app/curvedSavedPair.ts` 分别执行字段白名单、有限数值、整数及采样上限检查；前端还核对返回的原版单元编号、折角、来源参数、同索引二维／三维顶点、共用折痕行与左右母线网格。任何称采样弦段精确等距、称精确直折痕 FOLD 或称可采用折痕的响应都会被拒绝。

`src/components/CurvedSavedPairDialog.tsx` 在独立弹窗内显示二维展开与三维正交投影；可切换圆锥／正负圆弧，调整该子域的宽度、参数区间和采样密度，滑动查看同一个折痕点及两侧母线。图元仅由采样点画 SVG 折线和透明带面，不构造三角折纸片、FOLD 边或采用动作。连续曲面的局部等距和可展性已由解析模块证明；采样弦长一般不等距，部署路径、厚度、自碰撞和有限纸张的整体嵌入尚未验证。

专项覆盖三组保存输入的来源与数值锚点、额外字段／表达式／越界拒绝、HTTP 令牌与通用路由隔离、真实 Python JSON 到 TypeScript 严格解析的往返，以及仅作投影的双视图。主面板 `TessellationPanel.tsx` 的“保存曲折双视图 · 解析”仅打开该只读弹窗；该组件不进入镶嵌生成分支。
