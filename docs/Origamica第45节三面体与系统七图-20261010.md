# 第45节原三面体与三维系统七图

| 原定义 | 已有语义覆盖 | 本次补足 |
|---|---|---|
| StyledFrenetTrihedron，In[3708]，293961–294026 | 系统可算原T/N/B，主工具显示所选点拟合标架 | 独立原位置/三个原向量、显式长度/标签与数值绘图选项、三条原端点/文本数据及完整JSON |
| StyledDarbouxTrihedron，In[3789]，299219–299286 | 系统可算原T/L/U，允许非单位输入法向 | 同类独立原T/L/U图形数据，保持非单位、非正交与零向量 |
| Curve3DSystemPlots，In[3665]，289992–290066 | 三维系统返回7规则，已有位置图与所选标架、数值表 | 原7个有序图、3个标量随参数图及T/N/B参数轨迹、完整点值与原系统数据JSON |

三面体原默认长度是1，默认标签为三个空串。不是默认标签t/n/b或t/l/u。端点严格是 `p + length × 原向量`，没有归一化或正交化；长度因子允许零和负值。颜色保留原符号 `TangentVectorColor/NormalVectorColor/...`，同时记录 In[3614] CurveVectorStyle 原CMYK映射。受支持数值选项为长度因子、三个纯文本标签、VectorThickness2D、VectorThickness3D和VectorLabelPosition；原StyledVector默认分别为3、0.007和[-2,0]。

三维七图顺序严格为 Curve3D、Speed3D、Curvature3D、Torsion3D、TangentVector3D、NormalVector3D、BinormalVector3D。原系统规则自身是T/B/N顺序，不能直接当成绘图顺序。前三个标量速度/曲率/挠率使用Plot，其余使用ParametricPlot3D语义的数据。所有输入参数点和实际规则值原样保留，未定义点为null；未证参数区间不画跨区间连线。零曲率直线仍保留有意义的位置、速度、零曲率和切向图，N/B/挠率三个位置保持未定义。

公开数据函数位于 `src/app/curvedSystemGraphics.ts`：styledFrenetTrihedron、styledDarbouxTrihedron、curve3DSystemPlots，配套readTrihedronGraphics和readCurve3SystemPlots独立回读。图形来源复用已验证的七类数值系统；未引入新的曲率算法。主App路径：镶嵌设计 → 空间构造 → 原式工具与参考示例 → 曲线与恢复系统；选择三维Frenet/恢复三维时可打开原三面体或原系统七图，Darboux/恢复Darboux可打开三面体。

受支持三面体输入是3维有限数值原位置和三向量，坐标绝对值≤10¹²；长度因子绝对值≤10⁶，纯文本标签≤120字符，二维线宽0–1000、管粗0–1、标签偏移绝对值≤1000。不对原输入要求单位或正交。对数值原端点、标签、顺序、CMYK映射、原系统源和七图点值进行回读检查，伪造或错误来源拒绝。

输出是有来源证明的数值图形数据和独立SVG查看器，不宣称原生Wolfram Graphics/Graphics3D对象或任意Wolfram Function等价，也未逐选项复刻任意Graphics3D、复杂VectorLabelStyle/符号标签、Wolfram自适应Plot算法和原3D管体渲染。标签偏移数值保留，查看器使用可读的12px标签与近似字宽布局。FrenetTrihedronPlot3D的多标架数量、Drop及Graphics3D选项另列为后续批次。本来是图形的输出没有强加CP采用要求。

验收：10项TypeScript回归、19项真实隔离主App检查、4个实际图形JSON独立回读，tsc和隔离构建通过。390×720三面体弹窗354×688，无内溢出，标签可读；七图小窗口可逐图选择。数学意义上等价的-0/0按普通JSON约定读取，不当作几何或单位变更。
