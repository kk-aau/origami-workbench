# P77 旋转褶纸带创作

入口为“镶嵌设计 → 空间构造类型 → 原旋转褶纸带 CP”。采用后，在折痕编辑点击“修改旋转褶构造参数”继续创作，同构造重建保留工程名称和 UUID。

| 构造 | 实际编辑 |
| --- | --- |
| Canonical Troublewit／Goblet | 段长、绝对方向、原目标起点、重复对数与空间弧角；Canonical 原固定长度保留 |
| 矩形／梯形 | 毫米目标路径、初始宽、展角、增删末点与原山谷；支持拖点及坐标数值 |
| 原三角共尖 | 原 In[2669] 的零初始宽三角纸带、部分扇区与完整 CP 周期；保留原尖点身份 |
| 分面及查看 | 原带符号的 13 优先／24 次选分面，阈值、双图、毫米刻度、视角、缩放和平移 |

原 In[2667] 是带全部原初值的数值 FindRoot，保持未平移 Rx90 种子、原锚点、原边等长及四边形两对角误差乘积。完整 CP 周期只识别已知的原共同尖点及 2nΘ=360° 身份，保留第一坐标，不吸附任意近点。空间图为数值工程参考，未认证原 Mathematica 唯一根、所有面刚性、运动或层序，不能把它当作认证平折 Scene。
