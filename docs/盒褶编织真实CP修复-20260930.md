# 盒褶编织的母结构、真实 CP 与平折来源

旧 `family='woven'` 在二维正交格点上画成对直线，再按格点下标分配山谷。默认 3×3、全宽 .25 的三种节奏均只有 64 点／112 边／49 面，局部 Kawasaki／Maekawa 通过，但整片层序无解；“交替”与“三列错位”的整个 FOLD 相同。最小 2×2 在宽 .1／.25、三节奏和两个反转相位的 12 个样本也无解。宽 .45 的部分小图有层序解，因此不能把所有旧参数都说成无解；它们同样不能替代真实编织构造。

原版依据是 `tmp/Origamica-15.0-reference.nb` 第 250978 行起的第 42 节说明：输入是内部直线、四度交点的母图，构造结果同时给出 CP 和折后条带图。第 252723 行起说明条带全宽为单侧内缩的两倍。当前修复复用已验证的 `tessellation_woven.py`：母面二着色、内缩角点滑动、四次反射等距闭合、逆展开和完整几何检查；没有将折后母线直接冒充展开 CP。

| 参数 | 修复后的含义 |
| --- | --- |
| `family='woven'` | 保留独立产品入口及原工程参数，不改成 `woven-lines` 工程。 |
| `width=w` | 实际折后条带全宽。内部线组使用全局 `w/2` 与每线倍率 2，单侧内缩为 `w/2`。 |
| `plain` | 等距交替条带，列母线 `x_i=i+.5`。 |
| `basket` | 双列成组，相邻两列靠拢；`x_i=i+.5+δ·(+1,-1)` 循环。 |
| `twill` | 三列逐列偏移后重置；`x_i=i+.5+δ·(-1,0,+1)` 循环。 |
| `phase` | 全部 M/V 同时反转，CP、等距 FF 和固定面不变；层序单独重新验证。 |
| 固定面／FF | 保存真实 `foldedForm`、闭合误差及零基 `stationaryFoldFace`，前端严格按该折痕面恢复姿态。 |

这里 `δ=(1-w)/4`，横母线均为 `y_j=j+.5`。相邻列中心距至少 `(1+w)/2`，扣掉条带全宽后净距至少 `(1-w)/2`；外缘净距至少 `(1-w)/4`。在公开宽度 .1–.45 中分别至少 .275 和 .1375，对所有 2–6 行／列成立。三种是**条带布局**，都沿原版交替拓扑生成，不宣称实现纺织意义的任意篮纹或 2-over/1 斜纹交点序列。

默认三布局现均为 88 点／148 边／61 面，CP 坐标各不相同，保存 FF 范围为原 `[0,3]²`。修复后的前端专项核对默认 3×3、三布局、宽 .1／.25／.45、两相位的 18 组真实层序、FF 来源与正反面遮挡；另对 2×4、宽 .45、三布局与两相位的 6 组确认层序已解。不把局部条件当作整体证明。每次真实参数生成仍须通过整片层序门禁；这些样本不构成连续宽度全域的层序存在性证明。

6×6 双列窄带 .1 在原首初值需要 174 次求值、约 2.53 秒。适配层改为优先原引擎已使用的第三个确定初值（内部长度 1.6、边缘长度 1.0），降至 17 次、约 146ms。全部原回退初值仍保留，方程、迭代限额、闭合／几何容差均未放宽。该优先初值只用于产品盒褶适配，不改变原线组默认行为。求解有自由褶长，不同初值可能生成不同 CP；换初值本身不证明整体层序。浏览器若仍连接旧服务，会继续得到旧初值的 CP，必须按同一来源结果验证，而不能把新进程的层序正例套到旧 CP。

独立纸张外延仍有限：逆展开有自由褶宽，重新求更大母图不能靠平移保证保留原 CP，旧扩图裁剪也会留下失效的固定面编号。因此 `woven+paper` 的缺省外延／显式 `fit='extend'` 在任何非线性求解前明确拒绝，并提示沿用原边界；退役的多圈网格扩图路径已删除。不把空白外环、改变核心或旧固定面编号当作保真结果。

后续新增显式 `paper.fit='inscribed'`：可把本次真实编织 CP 裁到用户选择的内切纸形，保留内部山谷，映射逐面与逐点来源，重选裁后固定面并恢复真实平折姿态；必须重新通过整片层序验证。它会裁掉纸形外部结构，不能代替保留完整核心的纸张外延。详见 [内切纸张说明](内切纸张-20260930.md)。
