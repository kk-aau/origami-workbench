# 弱材料闭合线网裁剪与可视编辑（2026-10-09）

本批接通弱切口材料的闭合线网、用户明确选择的跨面/跨部件裁剪，以及两个闭环之间的真实连接线。完整 Origamica 目标仍在进行，免安装 EXE 未重打包。

| 功能 | 当前效果 |
| --- | --- |
| 面内完整线网 | 内部切口、边界悬空切口、交叉树、孔洞单桥上的不跨边界闭环可生成真实子面；包围切口的闭环保原切口和孔洞。 |
| 参考面裁剪 | 输入线网可以穿切口和孔洞，按实际纸面分段；两侧交点保独立索引，空白不加线。 |
| 参考部件/全部材料裁剪 | 明确选择范围后生成实际 CP。多面 F 网格可统一构造，未选部件不修改；同坐标独立纸片保持独立身份及原 FF 帧。 |
| 连接两个闭环 | 显式材料裁剪模式可保实际连接线，不把它丢掉或改成辅助边；F连接线的两侧真实网格、平折及源姿态通过检查。旧完整模式的拒绝规则保留。 |
| 可视节点与赋型 | 沿用毫米刻度、拖点、加点、连点、精确坐标、草稿历史和逐输入边赋型。原线黑色、输入紫色、实际结果青色。 |
| 默认草稿 | 优先保旧矩形；若穿切口/孔洞或固定点无效，有限搜索实际面内可构造草稿。无法自动找到时保空草稿，用户可加点绘制，不移动纸张或原端点。 |
| 预览与选择 | 范围/赋型/数值变动使旧预览失效；裁剪预览显示实际长度和空白长度。默认完整模式不静默裁剪。 |
| 原位 FF 与仅 CP | F编辑可保持原 FF；明确仅CP清除旧FF。不相容混合赋型可保存实际CP并进入数值模拟，不标为刚性平折通过。 |
| 导出与接续 | 实际 JSON/FOLD/普通 R12 LINE DXF 和三维网格 FOLD 可回读；原源线覆盖、尺度、坐标、角度与切口身份保持，三维返回不修改CP。 |

## 实现与一致性

原面内线网对带重复面角的切口使用简单面绕行，导致没有接触切口的闭环也会报面角丢失。现在单面弱检测选择实际有向边界分面；旧无弱边界的完整线网路径继续保持。

新增可选 `scope` 只在用户选择裁剪范围时启用，复用已核查的跨材料交点、切口侧选择、同步分点和真实面构造。闭合输入本身仍必须通过点边、交叉、自由端点和重叠核查。不同部件的同坐标点不会合并；同一部件的切口对侧只同步划分，各有自己的顶点和 FF。

预览长度分开计算实际材料长度与输入空白覆盖。独立纸片重合时，实际材料长度可累计多个纸片，空白仍按输入几何覆盖计算；它不是加工抬笔距离。普通导出与加工优化未改。

另修复跨不同面的同端点 B 切口边进入旧模拟器时丢失一侧的问题：即使每个单面看起来是简单环，也必须使用显式面边网格。已有显式模拟快照只重新核查，不再次三角化或改变三角角点顺序。各源 B 边各拥有一个三角面，源编号前缀及顶点保留；导出重开仍核查全部关联。
