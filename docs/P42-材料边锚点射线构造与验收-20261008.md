# 材料边锚点射线构造与验收（2026-10-08）

原版镶嵌采用为索引材料后，在折痕编辑“纸张属性/选区 → 材料射线构造”中可指定原边起点及沿边比例，再拖动方向点或输入毫米坐标，沿正向构造至实际材料边界。仍使用原画布、材料编辑窗口、坐标和导出链，不新增持久工作区，不重打包 EXE。

| 功能 | 最终行为 |
| --- | --- |
| 正向射线 | 方向点只决定方向，不是折痕终点；向材料包围区之外的私有点计算交点，只把实际材料内的区间写入 CP，反向与空白不补线。 |
| 原边身份 | 起点绑定所选索引边及0–1比例。原坐标不自动移动，切口两侧不焊接；新增交点按原材料边面关系同步细分。拖动起点约束在所选边上，拖动方向点无网格吸附。 |
| 可视操作 | 毫米刻度、缩放/平移、明确正向箭头、方向点拖动及键盘按刻度微移、精确坐标输入。原线为黑、构造方向为紫、实际分段为青。 |
| 固定侧与赋型 | 可选择部件/全部材料、F/M/V/U、固定侧。完整图完成后统一重折；不能闭合的局部山折拒绝同步FF，用户可显式仅CP，旧FF不保留为新结果。 |
| 预览与提交 | 数字草稿一变化即禁用旧预览；直接点击预览读取当前输入，应用核对预览意图签名并独立重放。取消不改源工程，整条射线一次撤销/重做。 |
| 布局 | 1000/800/390×720弹窗无整体滚动，坐标标签可见。反馈区固定高度，真实拖动使预览失效时画布位置/高度不抖动。390检查限弹窗，不声称主App已有移动布局。 |

实际落笔长度按各材料分段计，空白按正向有效区间的并集计；重叠独立纸片不因坐标相等合并。统计范围截止最后实际材料边界，不把私有包围点之后的空白计算进去，也不把无穷射线当作加工指令。
