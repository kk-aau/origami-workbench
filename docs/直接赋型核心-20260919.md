# 直接赋型核心（界面待接）

覆盖原版模式23／24／25／60：改为山折、谷折、边界、构造辅助线。核对本地 Oriedita 的四个 CreaseMake handler、BaseMouseHandlerBoxSelect、FoldLineSet 的赋型与最近线搜索、InsideToAux、Fix2、Polygon 接触判据及 LineColor.isFoldingLine。

- 点击选择最近的有限线段，距离严格小于容差。山／谷／边界等距取文档中先出现的线，辅助等距取后出现的线。不采用删除工具按ID打破平局的规则。
- 框选两种拖动方向均为接触规则。只接触端点也命中，改变整条已有小段，不按框裁剪。
- 转辅助仅处理原山／谷／边界；点击先选最近线，再检查可转换资格，不穿透已有辅助、未指派或平面边去找后方可转换线。框选也排除这些来源。
- 工作台边界保护启用时先排除边界，与其它编辑工具保持一致；这是工作台附加保护规则。
- 共用 assign 保留山谷角度幅值、零和未指定角；其他类型转山谷采用默认角。原类型相同或空命中返回原文档，不增历史。保留对象、坐标和ID。

新 directAssignment.ts 提供命中预览集合和不可变原子提案，界面释放时应调用 applyDirectAssignment，再经 App.commit 真实分段及选区映射。原版转辅助的删除／重插可能合并相邻折线，本工作台不复制这种行为：按用户明确要求保留包括辅助交点在内的可编辑小段。没有执行上游运行时逐例对照，不能声称全等价。
