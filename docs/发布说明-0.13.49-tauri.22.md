# 折纸工坊 Tauri 0.13.49 · tauri.22

日期：2026-10-30。适用于 Windows x64 迁移版。

| 更新 | 使用效果 |
| --- | --- |
| 模拟曲面应用到下一步 | 三维模拟底部新增“将当前姿态应用到下一步”，保留当前曲面、观察视角和纸面颜色，不替换原 CP 折痕角度。 |
| 曲面视角旋转 | 新步骤可通过“转动视角”拖动或用方向键调整；保存、复制、继续下一步及重开工程时保留曲面。 |
| 曲面显示修复 | 修复三角面之间漏色、斜面折痕被自身遮挡等显示问题；主图、缩略图、PDF 单步与完成效果图共用曲面图像，局部放大使用实际曲面边界。 |
| 碰撞推进优化 | 复用拓扑计算，对可证明安全的运动区间加速；接触后允许其他安全运动继续推进，每帧可完成多个子步。无法确认安全时仍停止，不跳过碰撞检测。 |
