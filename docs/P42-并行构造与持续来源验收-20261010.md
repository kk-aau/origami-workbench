# 并行构造与持续来源验收（2026-10-10）

完整 Origamica 目标仍在进行。本批交付可生成、可采用、可保存的实际功能；不以诊断图、入口数量或源函数名关联代替完成证明。普通导出和加工优化未改动。

| 功能 | 用户入口 | 实际行为与范围 |
| --- | --- | --- |
| 高偶度编织 | 镶嵌设计 → 线组编织 → 构造示例 | 新增 10、12、16、32 度星形母图示例。原目标求解保留所有母边，4～32 度偶度输入接通；每个候选仍须通过几何检查。无解的当前数值搜索不被宣称为数学无解。 |
| Flasher 四环 | 镶嵌设计 → 空间构造 → Flasher → 四环 CP/FF | r=4 进入原求解器和现有参数控件，11 组真实公开生成响应留存；空间静态形态通过逐面等距检查。未证明连续无碰撞折叠。 |
| 材料辅助线 | 折痕编辑 → 纸张属性 → 材料辅助线 | 批量创建、修改、删除；固定坐标默认不吸附。用户可明确绑定材料边上的点，支持参数重算、取消和一次撤销/重做。空材料历史也可使用；不分割纸面。 |
| 持久曲线来源 | 材料曲线批量、参数构造组 | 持久曲线编号跟随增删及排序；贝塞尔以持久相邻节点对绑定后续端点，支持无关段增删、反向参数映射。删除依赖来源或破坏相邻关系明确拒绝。 |
| 圆/椭圆母孔 | 线组编织 → 构造示例 → 曲线孔；母图编辑器 | 解析参数、采样点序号和弦误差界共同保存并独立重算，产生真实孔洞与可采用 CP。此项是工作台输入扩展；原 In[3428] 要求直线 TGraph，不能把新增解析孔算成原版已缺的函数。 |

辅助线保存编号以 `curve-group-N::aux-line-K` 标识，避免前组增删条目把后续镜像轴换绑到别的线。模型 v15 保存曲线编号，v16 保存贝塞尔节点编号；旧版本仍可读。原未托管辅助线的旧模型保持其自由编辑规则，首次加入依赖辅助线的配方才建立辅助线快照。

曲线端点参数对应当前离散 CP 弦上的位置，调整采样密度后跟随原曲线/输入段的同一参数。不会强制补解析采样点，也不把贝塞尔几何偏差界误写成同参数坐标误差界。完整边区间、切开和镜像整段仍须证明全部覆盖，不能静默截短。

真实界面与下载验收额外修复两处问题：共享面编辑入口曾在空材料状态拦截辅助线；普通 FOLD 导入曾重命名空材料中的辅助线，使保存模型失效。已补共享入口及空材料 FOLD 重开回归。普通非材料导入的旧编号规则保留。
