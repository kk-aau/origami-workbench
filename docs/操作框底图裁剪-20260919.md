# 按操作框裁剪底图

读取本地BackgroundTrimAction后，将裁剪接到现有操作框参数条，不另建一套框。模式61有有效框且底图显示、不透明度大于零时可用。保留跟随状态、当前位置和不透明度；只裁底图，不合入纸白色填充、网格、折线或紫色框。裁剪通过commit进入工程历史，可一次撤销回原始图片字节。

backgroundCropPlan先验证框/像素限制与世界范围，计算当前相机下的图片矩阵；旋转和等比缩放烘焙进输出PNG像素。以画布CSS像素分辨率裁剪，与上游屏幕截取语义一致，不照搬2000×1100固定离屏大小。小数框取向外整数像素包围盒，再clip精确内框，边缘最多不足1像素透明补边，不拉伸图。最大单边16384、4000万像素及4M数据URL字符限制继续生效。

cropBackground真实解码后仅绘制原图；使用xMidYMid meet等比容纳，与SVG的EXIF解码显示保持一致。透明度留在metadata，不烘焙进alpha，避免重复裁剪变淡。输出PNG重编码，因此不是无损保留原压缩字节；原图可通过撤销恢复。动画输入裁剪为当前解码静态帧，稳定帧选择策略仍待完善。

App裁剪使用请求序号、AbortController和doc/frame/view/mode/tool快照。用户取消不应用结果，解码结束后先检查abort再分配画布；期间工程/框/视图变化则拒绝过期结果。按钮、右击、Esc均可取消；失败和编码超限不替换图片。Canvas公共取消接cropBusy状态，防止取消裁剪时意外删线。
