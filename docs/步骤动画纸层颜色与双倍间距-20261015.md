# 步骤动画纸层颜色与双倍间距

2026-10-15。本次续接[复杂步骤动画与三维导航](复杂步骤动画与三维导航-20261015.md)，修复已有平折纸层在步骤动画起态、中途及终态显示错误纸张颜色的问题，并将精度相关的显示层间距增至原来的两倍。

同日后续增加[三维纸层间距参数](三维纸层间距参数-20261015.md)：用户可在普通三维与步骤动画底部调整 0–1000 倍间距，默认 1 沿用本次双倍间距；下文保留当时修复与验证记录。

## 问题与复现依据

| 现象或检查 | 结论 |
|---|---|
| 用户截图 | 已折叠纸层在起态、26%、99% 与终态出现颜色差异；不能仅凭图片确定原工程的全部 CP、作用纸层和选定层序 |
| 原工程范围 | 本次未取得截图对应的用户工程文件，使用通过工作区 CP 映射和工程导入／导出生成的实际两次谷折工程复现同类问题 |
| 可导入复现 | `output/step-color-triangle-1015.diagram.json`：正面纯红、背面纯蓝。第一次谷折将两张红色正面合在内部；第二次让已重叠的两层继续一起折叠，因此可见外表应始终为蓝色背面 |
| 旧离线像素结果 | 同一相机与画面尺寸下，26% 有 53,474 个纸面像素被画成红色，可信层序确认这些像素应为蓝色。材料边长、固定点和折角均正确仍会出现此错误 |
| 旧颜色验证的遗漏 | 之前主要检查固定区域是否同色、颜色值是否来自主图以及有无三角拼色，没有验证实际可见的是哪张纸层及其哪一面；均匀显示错误的红色也可能通过检查 |

## 修复方式

| 部分 | 当前处理 |
|---|---|
| 完全重叠的初态与中途纸层 | 起态和动作过程中也携带可信材料纸层关系。此前未提供这些关系时，零间距纸层可能按三角网格的绘制先后选中首面，导致内部纸面覆盖外表 |
| 主图选定的层序 | 主图已有可信层序时，将原纸面的关系映射到本步公共网格的各个子面，并按父面／子面的实际绕向调整 FOLD 关系符号；避免重新搜索时换成另一合法解而改变可见纸层。没有选定解时再分析初态层序 |
| 动作阶段时间线 | 每个运动阶段保留同一刚性组件中的旧纸层关系，覆盖静止叠层以及随纸瓣一起转动的叠层。分段折叠时，后续阶段沿用已确认的接触状态 |
| 新的终态接触 | 从实际规划路径反向分析最后接触的纸面，以解析首次非零分离方向确定接触顺序；不能直接拿最终 CP 的任意平折层序解替代实际折叠过程到达的顺序 |
| CPU 像素归属 | 不透明绘制保留像素对应的材料三角片；只有双方三角形在其自身 Float32 坐标误差范围内确实共面、且有可信 FOLD 纸层关系时，才由层序决定该像素归属。法线和相机方向共同确定从当前视角可见的纸层 |
| 真实空间分离 | 纸面存在可分辨的实际距离，或不满足数值共面条件时，继续按真实深度显示；不会使用一个宽泛的深度容差把前景纸面盖到后面 |
| 不确定关系 | 解析接触方向无法确认或计算预算不足时，不按纸面编号补造层序；保留已可信的同组件关系，其余关系缺省 |
| 跳转进度 | 每次按目标进度选择相应阶段的层序和姿态，支持乱序拖动、返回 0%、重播，以及在正背视角间切换 |

本次解决的是可见纸层选择及接触顺序的表达。它继续使用原有刚性路径和连续碰撞检查，没有将颜色修复当作碰撞检查的替代品。

## 双倍显示间距

| 项目 | 本次变化 |
|---|---|
| 精度下限 | 原有坐标精度与深度量化下限整体乘以 2，继续依据相机、深度位数和纸面朝向选择显示间距 |
| 运行时上限 | GPU 等显示路径的精度相关上限从 `模型半径 × 2e-5` 调整为 `模型半径 × 4e-5`，运行时缓存调整使用同一上限 |
| CPU 环状样例量级 | 原先约为模型半径的 `1e-6`，调整后约为 `2e-6`；具体数值仍取决于实际相机与坐标精度，不是所有模型都使用同一绝对厚度 |
| 铰链跨层距离 | 仍为 `abs(rankA-rankB) × 基础间距`；中间夹 N 层时对应 N+1 个基础间距 |
| 数据边界 | 只调整显示网格及其缓存，不改 CP、求解器材料顶点、材料边长、折角、工程草稿或导出的实际材料网格 |

显示间距是表达可信上下关系的微小分离量，不是纸张真实厚度或厚纸动力学。接近侧视、深度精度不足等情况仍受显示上限约束。

## 源码与样例

|---|---|
| `src/app/diagramStepAnimation.ts` | 原主图选定层序到公共材料子面的映射 |
