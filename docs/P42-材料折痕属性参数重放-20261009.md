# 材料折痕属性参数重放（2026-10-09开发，10-10验收）

入口：**折痕编辑 → 纸张属性/选区 → 材料折痕属性**。山谷线型、目标折角和山谷互换默认保存参数；采用后可从“参数构造组”重新修改，并顺序重算后续构造。源码运行版已更新，免安装包尚未更新；完整 Origamica 复现目标仍在进行。

| 操作 | 当前效果 |
| --- | --- |
| 线型与折角 | 支持 M/V/F/U 线型、折角绝对值、山谷互换和带符号精确赋值。普通线型设置与互换继续调用原规则；未知角度保留为未知。 |
| 原操作入口 | 原属性面板的线型按钮、目标角输入、未知角按钮和山谷互换也保存材料参数。连续调整末尾同选区的折角，更新同一组；其它操作按顺序追加。 |
| 完整来源区间 | 修改先前交叉线的位置后，属性选择跟随完整原边区间的各段，不只修改某个旧小段。后续镜像继承当前赋型和折角。属性本身不创建或移动材料身份。 |

| 保存与历史 | 参数修改使旧预览失效；取消不提交，一次撤销/重做。JSON/FOLD重开继续编辑；删除属性组可让后续构造重新使用先前属性。 |
| 空状态 | 后续剪切为空后，仍能重开前面的属性组；显示空结果，禁用无依据的FF预览。 |
| 兼容与容量 | 模型v12读取v1–v11；旧来源和辅助线快照保持。组外修改须保留归档后重新建立参数模型。仍为8组容量，超额拒绝，不截断已有工作。 |
