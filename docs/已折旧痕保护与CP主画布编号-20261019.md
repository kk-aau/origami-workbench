## 已完成折叠的旧痕保护

新画的山谷折线沿着已折旧痕经过时，同一旧铰链两侧纸面可能分别反投影出相反的山谷赋型。此前全部纸层可能因此报告冲突；顶层或指定纸层还可能把旧折痕反向赋型。

现在先把新线按所选纸层反投影到真实 CP，再扣除操作前已完成折叠的物理覆盖。只跳过新线的对应部分，旧折痕保留。

| 情况 | 当前行为 |
|---|---|
| 新线完全重合已折旧痕 | 不生成重复 CP 折痕，也不反转旧折的山谷类型或角度 |
| 新线部分重合 | 跳过已折区间，未折部分继续生成 |
| 主图同位置的其他纸层 | 按真实 CP 材料分别判断；其他纸层上的新折痕仍可生成 |
| 全部、顶层、指定纸层 | 均采用相同的旧痕保护规则 |
| 背面与旋转视图 | 先逆向映射，再保护相同物理旧痕 |
| F／0° 展开线或 M／V 的零目标角 | 不作为已完成旧痕过滤，仍允许新折叠 |
| 显式“预折后展开”操作 | 保留沿旧痕折回的既有意图记录，不改变历史 CP 折叠 |
| 同一步两条真正互斥的新山谷线 | 继续报告冲突，事务失败时不写入工程 |

保护来源是本步操作前 CP 中 M／V 且角度非零的覆盖；未指定角度的 M／V 沿用当前平折姿态的默认折叠语义。过滤不依据屏幕坐标、线段名称或拆段 ID，也不通过删除旧折痕解决冲突。

操作前 CP 与已保存姿态不变。新线生成后的操作后 CP 沿用原有规范化流程：可能合并同属性的相邻段或切分新交点，旧折痕的物理覆盖、山谷赋型和角度保持。通用 CP 赋型与冲突检查规则未放宽，直接编辑 CP 仍走原有明确编辑流程。

## CP 主画布编号

| 功能 | 使用方式与约定 |
|---|---|
| 纸面编号 | CP 主画布工具栏“纸面编号”，默认开启，显示 F1、F2 等 |
| 线段编号 | 同处“线段编号”，默认开启，显示 E1、E2 等，可与纸面编号分别开关 |
| 与侧栏对应 | 使用相同 `buildDiagramFold` 拓扑索引；E 是交点拆分后的原子边，不是文档原线段数组序号 |
| 展开线与辅助线 | F／0° 作为折痕标记，不额外划分物理纸面；辅助线不参与 F／E 拓扑编号 |
| 凹形与孔洞 | F 锚点从真实材料三角区域中选取，避开孔洞与纸边 |
| 密集结构 | 编号以屏幕像素避让，空间不足时暂隐；放大可显示更小纸面和短边的编号 |
| 选中线段 | 对应 E 编号优先布局，真实来源相同的原子边可以对应同一条源线 |
| 编辑与显示 | 字号保持约 12 个屏幕像素；编号不拦截点击、画线或选择，隐藏主折痕时同步隐藏 |

编号只用于当前 CP 编辑视图，不写入工程、计算数据或导出的折序图。拓扑编号可随真实 CP 编辑而改变；缩放和平移不改变拓扑索引。

几何按文档缓存，编号布局按视口、开关和选区缓存；单纯移动指针不重新构建编号拓扑。碰撞避让采用空间网格，并把 3 像素留白计入桶范围。
