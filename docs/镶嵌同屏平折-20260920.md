# 镶嵌同屏平折与布局稳定性

版本 0.12.1，2026-09-20。

镶嵌顶部的“计算平折”直接打开同屏平折画面；参数改变后自动更新，不切换到折痕编辑，也不创建或修改原折痕工程的模型。支持暂停／继续、正背面、X 光、滚轮缩放、拖动画布、适合画布及层序时间预算。

加载状态改为画布内固定位置的小标记，取消按钮始终保留位置；构造参数错误也在原位置提示，不添加会挤动画布的横条。单次快速拖动测试中，两块画布及取消按钮的边界框变化为 0，平折画面更新 38 次，浏览器 rAF 间隔 P95 为约 5.7ms。本机 1000×720 参数面板无滚动。

## 实现

- 复用已有平折几何阶段，从已生成的镶嵌面拓扑直接计算，避免逐帧重新切分交点。
- 平折几何采用常驻 Web Worker，当前帧完成后只处理最新输入，不积压拖动过程的所有参数；离开工作区、收起或暂停会释放任务。
- 旋转／缩放的精确前端预览也传入平折线程，因此即使构造检查尚未返回，平折几何仍能跟随最新参数。
- 层序求解使用独立可终止的 Worker，参数稳定后启动；输入变化立即取消旧层序任务。旧层序不能附着到新几何，无解、超时与尚未求解分别显示。
- 图形视角只在首次显示、切换正背面或用户主动“适合画布”时调整，参数和状态变化保留平移、缩放。
- 提取公共几何阶段时补上稀疏顶点数组检查，孤立顶点不能被当作有效平折结果。

## 验证入口

- `tests/app/tessellationFlat.test.ts`：真实生成数据与原编辑器平折引擎对照、折后边长、层序结论一致；路径不一致／孤立点拒绝；常驻线程排队、错误恢复与释放后的迟到消息隔离。
- `scripts/verify-tessellation-flat.browser.js`：同屏计算、真实折叠面、独立层序、快速拖动的布局边界、阻塞后台时实时平折、相机保持、暂停恢复、正背面、X 光、错误提示及原工程隔离。
- `desktop/smoke.cjs`：在打包后的 CSP 和内置计算组件环境中实际计算镶嵌平折，并确认参数改变更新画面。

九类默认镶嵌均能生成平折几何。本机直接几何阶段抽样约 0.2–2.5ms，不包括线程启动、通信与绘制开销；复杂图样和层序求解仍可能耗时。几何候选不等于层序已验证，无有效全局绘制顺序时使用透明面，不借用旧层序伪装正确遮挡。

## 本轮结果

979 项自动测试通过（933 项前端／核心、3 项桌面模块、26 项 Python、17 项服务与进程）；67 项浏览器检查通过（19 项新交互、39 项输入／九类布局、9 项取消与错误恢复）。源码桌面 76 项检查通过。最终快速拖动的画布位移仍为 0，平折更新 38 次，帧间隔 P95 约 5.6ms。详细日志位于 `output/tess-flat-*`。
