# 画布侧栏与线型组合

折痕编辑的右侧改为固定“画布”面板，取消“平折参数”页签。点击平折模型或计算平折时，右侧不再切页；折痕与模型的缩放、平移目标仍分别处理。

| 设置 | 行为 |
|---|---|
| 网格 | 显示开关、纸内／全画布范围、等分、减半／加倍、重置、对角线 |
| 吸附 | 保留网格、端点、交点的既有吸附开关 |
| 明暗（黑灰） | 黑色山折、灰色谷折，实线；本轮暂按既有黑灰模式解释“明暗” |
| 蓝红实线 | 红色山折、蓝色谷折，实线 |
| 蓝红虚线 | 红色山折点划线、蓝色谷折虚线，保留短线自适应 |
| 黑色虚线 | 山谷均为黑色，以点划线和虚线区分 |
| 折线下拉 | 四种线型组合使用下拉选择，下方展示当前山谷线型 |
| 点样式下拉 | 空心圆、实心方块、实心圆；取消自动选项，旧自动设置兼容为原来的空心圆 |
| 线宽／点大小 | 滑条或数值输入即时更新并保存；点大小控制点的外半径／半边长；空心圆为原来的浅色中心与单层细圈，实心样式无描边，均不叠加第二层外壳；非法数值不写入，失焦恢复已保存值 |

线型设置不改 CP 的山谷类型、角度或几何。旧彩色区分线型、黑色两点划线继续原样读取和渲染，在新面板中归入对应组合；只有主动点击组合才采用新的组合参数。辅助线自定义颜色、独立线宽及未指派线的专用样式保持。折序操作 CP 原有的实线规则独立保留。

纸张尺寸、保护边界、保持选择、选区属性、剪贴板、底图和构造来源编辑入口放在右侧“工具选项”；左侧只保留绘图工具。计算、停止、活动模型及显示控制继续在底部；文件、模型历史、层序与批量输出通过底部“模型操作”打开，批量结果在关闭该浮层后仍保留。

绘制预览和有限结果候选使用与已绘折痕相同的颜色、线宽、自适应虚线及端点设置。绘制中切换样式也会更新；参考轴、测量线等构造引导保留独立样式。常态交点交互层透明，不重复覆盖所选点样式；键盘焦点、选中和吸附提示独立保留。
