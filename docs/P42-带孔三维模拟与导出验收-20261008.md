# 带孔材料三维模拟与导出验收（2026-10-08）

本批将上一批“带孔三维明确拒绝”推进为实际三维模拟。单孔、双孔、独立重叠材料及带真实山折铰链的材料可进入既有 GPU/CPU 模拟流程，孔洞不被填成纸面。完整镶嵌复现目标仍 active，未重新打包安装版或免安装版。

| 改动 | 实际行为 |
| --- | --- |
| 入口 | 采用后的材料工程使用既有“三维模拟 → 载入当前折痕”，沿用目标折叠比例、播放/暂停/复位、视角、材质和导出控制。 |
| 网格 | 在独立模拟副本中复用完整多环三角化，恢复全部原边界角；三角片按源面朝向一致排列。只在模拟副本内增加 F/0° 刚性辅助边，源 CP 不增加这些边。 |
| 孔洞与身份 | 检查内外环几何、真实源边与邻面、三角片面积和有向边界覆盖。不同材料副本的同坐标顶点不焊接，单孔和双孔保持不同边界。 |
| 平面输入 | 接受二维材料图及逐面共面的三维 FOLD；使用逐面投影构网，真实输入顶点不移动。非共面多环面明确拒绝，不用平面片冒充曲面。 |
| 模拟清理 | 若第三方网格清理会改变原顶点数、边序或三角片，则拒绝，不输出漏结构的结果。既有普通无孔模拟流程保留。 |
| 导出 | 三维 FOLD/OBJ/STL 使用当前实际模拟三角网格，删除原多环面和源面层序/邻接字段，防止旧索引混入三角网格。保留三角片到源面对应元数据。 |

模拟继续沿用既有 XZ 纸面基底和居中、按包围半径归一化的模拟坐标。三维导出沿用这套当前状态坐标；它不是源 CP 的毫米加工文件。普通 DXF 和加工优化的坐标、单位及格式未修改。没有本批刻字机导入或试压结果。
