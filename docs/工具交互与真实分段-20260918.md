# 工具交互与真实分段补丁

日期：2026-09-18。已实现、构建并通过真实浏览器操作验证；是在现有 v0.2 上修复交互，不代表 Oriedita 全工具移植已完成。

## 用户确定的规则

1. 选中工具后可见完整用法及当前步骤；鼠标右上方额外显示当前该点哪里的小提示，边缘自动避让、鼠标事件穿透。
2. 构造中的角边、候选角平分线和测量参考使用紫色，不借用正式山谷颜色。
3. 三点 A→V→B 仅定义角，第二点 V 是起点；第四次必须点选已有有限线段或纸边确定截止。只取内角正向交点；空白、反向、平行、共线、不在目标线段内等情况不提交，并保留输入供重选。
4. 用户明确：构造进行中右击仅取消；构造尚未开始则右击删线，右拖矩形框删。框删删除完整包含的小段，边界保护有效、一次撤销。
5. 交点必须真实拆分编辑对象，不只是可见的捕捉点。单选、改型、移动、Delete、右击和框删均作用于独立小段。

## 实现

- `src/components/ToolGuide.tsx` / `toolGuide.css`：全部现有 7 个工具的用途、步骤、紫色说明与右键规则；同一 `getToolStep` 同时供常驻区和光标浮层使用。
- `src/components/CreaseCanvas.tsx`：四步角平分状态机、紫色参考及截止预览、点编号、鼠标跟随提示、右键取消优先／空闲删线与框删。左键拖动中追加右键通过 pointermove 的按钮位处理，避免浏览器不再次发 pointerdown 导致漏取消。
- `src/app/bisector.ts`：角内单位射线及有限目标求交；不将目标延长线当作线段，不允许零长输出。
- `src/app/erase.ts`：屏幕容差折算后的最近小段、矩形完整包含判定；无副作用、保护 B 类型。
- `src/app/planarize.ts`：编辑用真实分段，独立于计算副本的合并／冲突拒绝策略。包含辅助线和纸边；X／T／共线重叠端点均可分段，重合的不同赋型不擅自合并。未变化对象及首段保留 ID，其余稳定生成不冲突 ID，重复运行不继续拆分。
- `src/App.tsx`：统一在提交、导入、恢复和采用副本时分段；选区映射到对应全部子段。一次提交连同自动分段只有一个历史步骤。旧工程自动分段后须保存，原文件不直接覆盖。
- 分段及校验失败不修改当前文档；`replace()` 仅成功时才关闭入口或清除恢复提示。否则自动保存可能覆盖尚未恢复的旧稿，现已防护。

目前上限仍为 1500 个可编辑小段；密集交点可能较早触达此上限。错误会明确报告并保留原状态，未通过提高限额掩盖性能边界。直接点击交点会选中关联小段；想编辑单段，应点该段中部。这不是单点拖动带动全网格的约束变形工具。
