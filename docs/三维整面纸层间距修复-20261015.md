# 三维整面纸层间距修复

2026-10-15。[三维纸层间距参数](三维纸层间距参数-20261015.md)的后续：用户发现交错成型的纸面在调整间距时被按重叠区域分成碎片。本次保留原纸面及其三角拓扑，改为为完整纸面求显示高度。

## 问题与调整

| 部分 | 当前行为 |
|---|---|
| 旧局部重叠方案 | 按重叠区域裁出显示碎片，可能使同一原纸面出现不同高度与可见割裂；该方案已退出生产调用 |
| 完整纸面 | 保留原有纸面及其原三角片，不因纸面相互重叠而新增显示切片、交点或三角片 |
| 普通可全局排序的纸层 | 沿可信层序给完整纸面分配显示高度 |
| 上下交错的纸层 | 为每个完整纸面求一个仿射高度场，允许沿法向产生微量倾斜；同一纸面的全部三角片沿用同一高度关系，保持连续 |
| 重叠多边形 | 仅用于确定哪些位置需要满足上下间距约束，不直接生成显示顶点或显示三角片 |
| 原折痕边界 | 按原纸面的归属分离显示顶点，不把真实材料顶点重新切成重叠区域碎片 |
| 无法确认安全布局 | 本次整套显示布局不应用，并提示原因；不混合局部成功和失败的纸面结果 |

仿射高度采用 `h(u,v)=a·u+b·v+c`。在每个真实重叠多边形的顶点约束上层高度减下层高度不小于请求间距；求解后重新检查全部原始约束。达到计算时间、迭代或约束数量预算，不作为成功布局接受。

## 数据与使用边界

| 项目 | 约束 |
|---|---|
| 用户参数 | 保留 0–1000 倍、小数、快捷倍率、恢复默认及共享偏好保存方式 |
| 生效条件 | 沿用 100% 平折、近平且稳定、可信层序等条件 |
| 显示范围 | 参数仍只改变显示间距；倍率调整和视角旋转不改写 CP、求解器顶点、工程数据或真实材料网格导出 |
| 物理含义 | 法向微移和微倾斜用于完整纸面的显示分离，不代表增加真实纸厚或建立厚纸接触动力学 |

主要实现位于 `src/engine/simSurfaceLayers.ts`、`simIntactSurfaceLayers.ts` 与 `simSurfaceHeightSolver.ts`。旧 `simLocalSurfaceLayers.ts` 的重叠切片方案不再参与生产显示。
