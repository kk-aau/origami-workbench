# 补线与网格输入（v0.9.2，未打包）

工具栏新增独立入口“补线与网格输入”，当前47项实际工具。使用紧凑参数栏、紫色暂定线与鼠标分步提示。

点击已有顶点或显示的网格点起笔；若存在单个局部角度候选，自动形成一个网格间距长的暂定线。多个候选时点击方向建议或紫色线；也可点已有／网格点设置暂定终点。没有候选时同样允许输入终点，不报成局部补线失败。

暂定终点需再次点击确认，或按“确认暂定线段”。点其他已有／网格点只替换终点，不写入之前那条线；点回起点取消。点实际线身可沿暂定方向截到有限交点，反向／延长线目标拒绝且保留状态。已有点和网格点优先于线身，因此要执行截止时应避开这些点。

最终线始终使用当前绘制线型及默认折角，即使孤立原线为V45而当前预设为M，新增也为M−180。原线不改。这与“局部平折补线”单邻线保留原类型及角度不同。任意重选终点可能不再满足角度条件，本工具不保证局部或全局可折。

右键／Esc取消暂定操作不删线，闲置右键恢复删除。所有写入经过重合冲突处理和真实分段，可一次撤销及保存恢复。
