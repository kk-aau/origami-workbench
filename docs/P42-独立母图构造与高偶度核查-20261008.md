# 独立母图构造与高偶度核查（2026-10-08）

本批完成互不接触、互不包含的独立母图部件的实际编织构造、整片平折、采用和保存导出。高偶度仍未找到有效 CP，不标记完成。完整镶嵌复现目标 active；源码和网页更新，免安装版与安装版未重新打包。

## 可使用的功能

| 功能 | 最终行为 |
| --- | --- |
| 工作区入口 | “镶嵌设计 → 线组编织 → 构造示例 → 独立双部件编织（本地母图）”。可在既有母图入口载入不同的独立线网，不增加侧栏行或新工作区。 |
| 母图解析 | 沿原点边数组、原半边发现顺序编号。每个部件有自己的单外边界；孤点、桥边、交叉、接触、相互包含等明确拒绝，不猜测内圈是孔洞还是纸片。仍保留 512 点/1024 边/256 面和内点四、六、八度的既有范围。 |
| 二着色和数值构造 | 各部件从其首个原面开始，以请求相位进行二着色；所有真实变量、反射方程和周期约束共同求解。完整逐边内缩仍绑定全局源边编号，不按部件重排。 |
| 固定面和回展 | 请求的固定母面保持原索引；其余部件分别从自己的首个母面回展。全部根面在各自原 FF 坐标中固定，不自动搬到原点、拼接或补线。 |
| 原式回读 | 前端独立验证部件、源面、回展根、仿射 FF、全部原 M/V/B 拓扑、逐面等距及闭环。缺少或伪造部件来源不能退回普通纸面路径；其他构造的图扩展不会被误识别成编织材料。 |
| 平折和采用 | 采用前仍须整片层序已解。独立部件和内部 B 切口进入既有索引材料流程，保留原相对 FF 位置；采用后仍可编辑、重新平折、保存重开。 |
| 导出 | 原生 JSON/FOLD 保留身份、源参数和 CP/FF；普通 DXF 保持 R12 AC1009 独立 LINE，毫米坐标只经过既有一次转换。原 CP 与加工优化未修改。 |

`wovenIndependentMother` 是可独立回读的来源描述，保存原顶点部件、原母面分组及生成 CP 根面；它不声称层序或物理折叠已通过。两个普通部件不会被标成单纸片。带切口情景中的两个母图部件会生成六个实际材料片，二者数量分开核对。
