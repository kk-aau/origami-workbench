工作区“自定义 → 原版正多边形”的“拼块排布”现在给居中扭角 Alt 三种侧接预设、偏置模式三种侧接预设。选择后载入上表完整参数；按原版 `JoinTiling` 的三元组语义，将**新片末边（第 n 边）**反向贴在旧片第 2 或第 3 边，具体为新片顶点 1 接旧片指定边的起点、新片顶点 n 接旧片指定边的终点。Alt 预设由首片逐边 M/V 自动导出第二片相反赋型；偏置预设保留每片独立的 `d` 与 M/V。改边数会退回单块，改褶宽、扭角、偏置或赋型后是原版接边排布上的本地变体，仍须重新通过实时整片检查。

`src/app/unitRegularCentered.ts` 保存六种明确的 `arrangement` 和对应边数／接边。`src/app/tessellation.ts` 的工程读回重新计算顶点、面与每片实际扭转；来源标签、接边、第二片赋型或几何被单独改写都不能冒用预设。`tests/app/p36RegularIn3079.test.ts` 从这六个可见预设逐一生成工作区请求，检查原版接边两端严格反向重合、JSON 往返、M/V 篡改拒绝、后端 CP 几何和局部条件、2D 平折几何 `ready` 以及全局层序 `solved` 且解数精确为 1。In[3079] 还另与独立具名 Python 构造逐顶点／逐边／逐赋型／逐面对照，参见《Origamica第36节正方形侧边Alt双块In3079-20260927.md》。
