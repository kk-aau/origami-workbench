# 跨线型合点界面

模式41新增独立“跨线型合点”入口，当前77项工具。第一次点击已有共线顶点生成紫色双源和合并段预览，显示结果类型／折角；再次点击同点或“确认合点”提交。山＋谷明确显示结果为边界。辅助混合、T/X、角点、重叠及边界保护拒绝。

同型折角冲突时，预览保留而确认按钮禁用；下拉可选来源角度或明确设为未指定。再次点顶点不能跳过检查。新工具专用mergeclick手势在释放时调用构造逻辑，按下不提交；右击或Esc取消，原同型合点行为不变。此两步确认与上游按下即合并有意不同，以满足工作台的取消与明确结果约定。

Canvas共用pending、合点预览和几何核心，crossMergeAngle在取消时清空；文档／工具变更沿用统一取消。边界保护在预览与提交时重新检查，折角选择不改变绘制预设。按钮保持限宽多列，无弹窗。
