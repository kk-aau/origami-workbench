# 第 45 节 In[3968] 非均匀螺旋曲折保存例

原版参考为只读 `tmp/Origamica-15.0-reference.nb`。空间母线的解析式见 In[3959]（323512–323794 行），数值包装见 In[3963]（324165–324231 行），二维平展包装见 In[3966]（324388–324436 行）；保存调用 In[3968] 在 324515–324602 行。保存输入固定为 `r=1`、`θ=30°`、`u∈[0,π]`、`γ(u)=60°+60°u/π=π/3+u/3`，两次调用都写有 `InterpolationPoints→128`。笔记本没有可机读的 Wolfram 逐点坐标 Out。

## 源式与局部数值范围

令 `c=cosθ=√3/2`、`s=sinθ=1/2`、`g=γ′=1/3`、`A_L=2s+g=4/3`、`A_R=2s−g=2/3`、`B(u)=2c sin(γ(u)/2)`，则 In[3959] 两侧分母的平方分别严格化为

`D_L=A_L²+B²≥91/36≈2.527778`，`D_R=A_R²+B²≥43/36≈1.194444`。

因此整个保存区间没有母线分母退化。三维折痕为 `F(u)=(cosu,sinu,u tanθ)`。以 `e_r=(cosu,sinu,0)`、`e_φ=(−sinu,cosu,0)`、`e_z=(0,0,1)` 表示，源码两侧单位母线等价于

`R_L=[−c sinγ·e_r+c((1+cosγ)s+g)·e_φ+(c²(1−cosγ)+2s²+s g)·e_z]/√D_L`，

`R_R=[c sinγ·e_r+c((1+cosγ)s−g)·e_φ+(c²(1−cosγ)+2s²−s g)·e_z]/√D_R`。

固定例的二维折痕满足 `f(0)=(1,0)`、单位切线 `T(0)=(0,1)`、`|f′|=secθ`。其切线相位可从原平展方程化为 `φ(u)=π/2+6c[sin(π/6+u/6)−1/2]`，`f′(u)=secθ(cosφ,sinφ)`。位置 `f(u)` 是该切线的定积分，本地以每小区间八点 Gauss–Legendre 积分求值。令 `T=(cosφ,sinφ)`、`N=(−sinφ,cosφ)`，二维母线为 `r_L=(A_L T+B N)/√D_L`、`r_R=(A_R T−B N)/√D_R`。这些式子同样给出 `|r_L|=|r_R|=1`，且折痕两侧具有相同速度、沿折痕投影与内禀转角率。源码三维母线的可展三重积为零，所以两个局部直纹面在同一 `(u,v)` 下第一基本形式相同；专项从独立坐标差分核验 `E,F,G` 与可展残差。这里的连续方程是来源推导，屏幕坐标仍为数值采样。

**不能把原单位母线长度直接画为一整片正则纸带。** 令 `J` 为二维直纹带的有向 Jacobian，`0≤v≤w` 时

`J_L=secθ·B/√D_L−v·c cos(γ/2)(1+A_L g/D_L)`，

`J_R=−secθ·B/√D_R−v·c cos(γ/2)(1−A_R g/D_R)`。

`B` 随 `u` 增加，`cos(γ/2)` 递减；以全区间的端点界取 `w=0.5`，得到 `J_L≥0.1880368360`，`|J_R|≥0.9149914220`。右侧括号始终为正。相比之下，左侧在 `u=0` 的焦线距离仅 `0.7132255712<1`，原 `CurvedFoldGraphics` 绘制的单位长起点母线若扩为宽度 1 的连续面便跨过奇线。本地双视图只画宽度 0.5 的局部正则带，界面也展示这个差别。

## 与原版数值调用的边界

In[3963] 的 `NCurvedFoldHelix3D` 会把传入的 `InterpolationPoints` 用在 3D 曲线、两条母线和折角插值。In[3966] 的 `NCurvedFoldHelix2D` 虽接受 `opts___`，内部调用 `NCurvedFoldHelix3D` 和 `NFlattenFold2D` 时**没有转发该选项**。因此保存调用的 2D `InterpolationPoints→128` 不能当成已生效的 2D 网格规格。本地保持 128 个均匀曲线采样点作为清楚标注的预览设置，用原解析 3D 式直接评价、用二维求积评价；这不声称复刻 Mathematica 插值阶数或 Wolfram 逐点 Out。

`src/app/curvedNonuniformHelix.ts` 是固定保存输入的独立只读计算，`src/components/CurvedNonuniformHelixDialog.tsx` 在“空间构造 → 非均匀螺旋曲折 · In[3968]”展示二维与三维同参数图、当前折角及正则性下界。它不写入当前工程或采用候选。三角弦段不精确等距，不生成精确直折痕 FOLD；局部光滑等距不证明连续部署、厚度或自碰撞可行。
