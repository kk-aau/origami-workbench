# 角度拖画与定向截取（v0.9.2，未打包）

本轮新增两个实际入口，当前43项工具，完整Oriedita覆盖目标仍在进行中。

## 用法

- 角度拖画（模式37／deg2）：点击起点，再点击终点；也可按下拖动、松开结束。鼠标位置正交投影到活动角度方向，附近实际线交点及同方向顶点／网格点可吸附，不为吸附而改变方向。重复点起点保留等待状态。紫色预览不写入折痕，松开才提交当前绘制线型。
- 定向截取（模式16／deg3）：基准点 → 起点 → 候选方向 → 实际截止线。第二点为起点。点紫色方向或使用候选下拉列表选方向；选方向不生成线。目标必须在所选方向前方、交点位于真实有限线段上；反向、空白、平行及延长线目标不能提交，保留已选基准供重试。
- 共用角度设置：等分A默认180/12，等分B默认180/8；自定义ABC默认40/60/80，DEF默认30/50/100。两组自定义产生各角度及其360°反角，定向截取额外含基准方向。每组独立编辑，切换工具保持；修改设置取消未完成构造，避免把旧方向用于新角度组。
- 两入口保持紫色参考、固定及鼠标右上分步提示、右键／Esc取消、原图保留、真实分割、整组撤销和工程保存恢复。右键取消后，闲置右键仍执行已有删除规则。
