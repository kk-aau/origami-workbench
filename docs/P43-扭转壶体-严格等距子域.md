# 第 43 节：`MakeTwistedPot` 的静态 CP/FF 子域

只读依据是 `tmp/Origamica-15.0-reference.nb` 第 268665–271532 行。定义在 In[3520]（269061–271110）；`PotTrimmed`、`PotFlatFlangesFaceted/Smooth` 说明在 268813–268938；三个 `ShowExample` 输入在约 271135、271270、271420 行。原笔记本保存了输入表达式和图形调用，**未保存可直接逐顶点提取的数值坐标 Out**。下列数值是从原版方程在本地独立求得并由等距条件验证，不能称为 Wolfram 内核输出的逐点对照。

原版的 `pts` 是外部 x-z 剖面，首两点须等高；后续高度严格单调。首点会平移到原点。`m` 是旋转阶数，`ρ` 与 `τ` 分别是法兰方向和 gore 对角线方向，均仅可取 ±1。`ζ` 是直法兰折线相对普通薄法兰壶体的旋转角；它不由 `ρ` 或 `τ` 决定。令 `φ=π/m`，在展开图中第 i 层的 `pᵢ` 是 `rᵢ` 关于经过首层边界点、方向为 `φ+ζ` 的直线的镜像。折后 `pᵢ` 与 `rᵢ` 位于同一三维位置：`Rz(ξᵢ)(xᵢ,tan(φ)xᵢ,zᵢ)`。原版同时要求径向边、横截边以及由 `τ` 选择的 gore 对角线在 CP/FF 中等长，并逐层求解平面 `rᵢ` 与空间扭角 `ξᵢ`。

`PotFlatFlangesFaceted` 是原版默认值。它使法兰展开点沿方向 `φ+ζ` 延伸，并求三维点的径向/切向位移，使相邻三条约束等长；末层第三条约束改为末端法兰三角形共面。原文明确说明，某些剖面或扭角没有 faceted 解，可能抛出 `noqsoln` 或 `nofsoln`。本实现用有界非负法兰增量及多初值求根，保留方程残差门槛，并在组装后独立核验整个二维边图没有退化/交叉，每张三角面在 CP/FF 中逐点对距，FF 面共面、非退化。任何一步失败即拒绝输出。求根分支与 Wolfram `FindRoot` 无逐点证据可断言完全相同。

选项的几何语义决定可验收范围：

| 原版选项 | 对纸面与三维形态的影响 | 本实现 |
| --- | --- | --- |
| `PotBorder -> PotPlanar` | 保留末层 `q` 点，末端轮廓在同一 z 平面，最后法兰局部为方形结构 | 支持 |
| `PotBorder -> PotTrimmed` | 删除末层 `q` 点，将末端法兰角修成三角边界；边界通常不在单一 z 平面 | 支持 |
| `PotFlatFlanges -> PotFlatFlangesFaceted` | 逐层求出可分面且面内等距的法兰；不保证每组参数有解 | 支持，求解失败时拒绝 |
| `PotFlatFlanges -> PotFlatFlangesSmooth` | 原版说明法兰展开折痕是 pro-forma，3D 渲染 **不等距**，预期真实法兰为光滑曲面 | 严格 CP/FF 模式拒绝；独立只读参考显示原版纸面和非等距三维示意 |
| `PotFlatFlangeInset -> ε` | 原版按 `1−ε` 缩放一侧法兰的三维 x/y 顶点，以避免渲染共面闪烁，改变真实长度 | 支持 `0–0.5`，但只改三维显示副本；真实 CP/FF 仍严格等距 |
| `TypeMinimumAngle` | 仅把原来 `U` 的边按有符号 FF 折角分为 M/V/U；默认阈值 `0.5°`；原版预设的底边和法兰纵向 M/V 保留 | 支持 |

实现位于 `backend/tessellation_twisted_pot.py`，由共享 `tessellate.py` 的 `twisted-pot` 路由分发；工作区“空间构造”下拉、`TwistedPotControls` 和同画布静态三维视图已接入。参数键是 `family='twisted-pot'`、`crossSection`、`sectors`、`asymmetry`、`goreTwist`、`flangeRotationDeg`、`border`、`flatFlanges`、`flangeInset`、`typeMinimumAngleDeg`。受限输入为 4–12 个剖面点、3–16 阶旋转、`ζ∈[-45°,45°]`、`ρ,τ∈{−1,+1}`、`faceted`，显示内缩 `ε∈[0,0.5]`；这只是求解搜索域，**不是保证所有输入都有解**。输出的 FOLD 二维顶点和 `source.foldedForm3D` 使用同一索引，保留原版边赋型种类及 FF 折角。原版只在 `i≥3` 缩放 `ρ=1` 的 r 点或 `ρ=-1` 的 p 点，本实现将这些索引记录为显示元数据，对原始等距点另造视图副本。几何上等价的 ±180° 折角按原版固定山谷/山赋型规范化，使文档与渲染校验一致。它是已检验的静态空间状态，不声称连续刚性折叠路径、自碰撞可行性或与原版执行结果逐点相同。

原版第一保存例 `pts={{0,0},{1,0},{1,.5},{1.5,1},{1,1.5},{1,2}}`、`m=12`、`ρ=τ=1`、`ζ=25°` 使用了显示内缩 `0.05`；本地保留该显示参数，但真实等距数据与 ε=0 相同，为 156 顶点、420 边、265 面，面内最大距误差约 `3.0×10⁻¹²`。第三保存的细剖面为 `m=6`、`ρ=τ=1`、`ζ=−8°`，同样可显示 ε=0.05，真实等距数据为 132 顶点、372 边、241 面，最大距误差约 `5.8×10⁻¹¹`。第二保存例显式选择 `Smooth + Trimmed + inset 0.05`，按原版说明不是可逐面等距的静态 FF 样例，不作为严格等距对照。对第一剖面改用 `Trimmed`，本地为 144 顶点、384 边、241 面；两种边缘的边界边均为 36 条，前者所有边界点 z=2，后者 z 跨 1.5–2。

第二保存例现可从扭转壶体控件的“Smooth 法兰 · 原版只读参考”查看。`backend/tessellation_twisted_pot_smooth_query.py` 复用原版 gore 方程，直接使用其 pro-forma `q/qq` 法兰点，不运行 Faceted 求根；二维展开为 144 顶点、384 边、241 面，单纸面几何通过；原版展示坐标的最大面内距离误差约 `0.1899`，因此结果只有 `paper`、`reference3D` 和显式 `metricPreserving=false/adoptableCreasePattern=false` 证书，**不返回 FOLD，也不修改工程或平折结果**。ε 仅缩放显示副本，原始二维与三维参考坐标不变。三维使用线框正交投影并明示“非等距示意”，避免把面片遮挡和折后形态误认为已验证。
