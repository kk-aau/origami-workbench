# 材料内部闭合线网构造与验收（2026-10-08）

完整 Origamica 复现目标继续。本批把采用后的材料面内部闭合线网接入实际 CP、面划分、平折检查和可视编辑；不代表任意母图或原版所有域已经复现。没有重新打包或发布，免安装 EXE 仍为旧版。

入口：原镶嵌采用为索引材料后，在折痕编辑“纸张属性/选区 → 材料闭合线网”中操作。

| 操作 | 本批行为 |
| --- | --- |
| 可视编辑 | 原坐标毫米刻度；移点、点击加点、依次点两个点连边；精确 X/Y、键盘微移、导航、显式删点及关联边、删边、草稿撤销重做。128 输入点、256 输入边、1024 新交点上限，超限拒绝而不截断。矩形仅是起始示例，可清空后绘制其他合法闭合图。 |
| 原面和固定点 | 显式选择原材料面，固定点选择该面细分后的唯一子面；固定点落在新线或孔洞明确拒绝。坐标不吸附，原顶点、边及其它材料部件身份保留。 |
| 相交和嵌套 | 精确有理交点身份，多个数学上相同的交点使用同一新编号；交点坐标一次舍入至最近双精度数。每条新边按原输入方向拆分，逐段继承源边赋型。嵌套反向环归属于最小包含外圈，真实纸张孔洞保留。 |
| 材料拓扑 | 闭合折痕真正生成多环子面，折痕两侧有面关联；不把闭合折痕改成纸边，不引入辅助桥接或三角化线进入 CP。 |
| 预览和提交 | 原线黑、草稿紫、结果青。CP/FF预览；不兼容赋型不能保留旧 FF 冒充新结果，用户可明确选择仅 CP。输入变化立即失效旧预览，应用核对意图签名并独立重放，取消不改源工程，应用只占一次工程历史。 |
| 布局 | 1000/800/390×720 窗口无需整体滚动；反馈行固定高度，拖点使预览失效时画布不抖动。390检查仅限本窗口，不代表主 App 已有手机布局。 |

闭合线网限定在同一个原材料面的严格内部。点或边接触原边界、跨纸外/孔洞、重复坐标/边、共线正长度重叠、自由端点、单桥和弱简单面均明确拒绝。此限制保留了真实材料与拓扑，不用额外线条伪造构造完成；跨面直线、原边射线等仍使用各自已有入口。
