# 折序绘图镜像复制

工具入口位于折序绘图主工具栏的“选择”旁。

| 操作 | 结果 |
| --- | --- |
| 点击对象、Shift 增选，或空白处拖框 | 选中一个或多个折线、折纸符号 |
| 点击“镜像复制” | 保留选区，开始指定镜像轴 |
| 点击主图第一点 A，移动鼠标 | 显示镜像轴及半透明副本预览 |
| 点击第二点 B | 固定镜像轴，便于检查副本 |
| 点击“确认镜像”或画布内按 Enter | 保留原对象，添加并选中新副本 |
| 点击“重选镜像轴” | 清除预览轴，重新指定两点 |
| 点击“取消镜像”、右键或 Esc | 取消此次操作，不添加或删除对象 |
| 撤销／Ctrl+Z | 一次撤销此次生成的全部副本 |

镜像轴沿用网格、纸角、折线端点、交点、纸边与符号定位点吸附；按住 Alt 暂停吸附，Shift 将轴方向限制到 45° 的倍数。选轴和预览期间仍可滚轮缩放、中键平移，以及使用画布右下方的缩放、旋转、适应按钮。

副本继承折痕类型、折痕作用、颜色、线宽及符号组件参数。启用“折线与 CP 联动”时，谷折、峰折副本按其目标位置和当前“最上层／全部纸层／指定纸面”设置映射到操作后 CP，不沿用原线的纸面编号；操作前 CP 保持。已有折痕的副本作为独立的已有折痕绘图线。

扯角状态允许复制符号；含折线的选区需要切回平整状态后再复制。副本具有独立身份，可继续移动、调整夹点、修改属性、保存及重新打开。
