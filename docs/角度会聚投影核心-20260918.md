# 角度会聚／角度投影核心（尚未接入界面）

本轮完整核对本地 MouseHandlerDrawCreaseAngleRestricted（模式13）和 MouseHandlerDrawCreaseAngleRestricted3_2（模式18），以及 OritaCalc.lineSegment_rotate 的倍率语义。新增 app/angleConstructions.ts，尚未新增用户入口，工具数仍43。

## 已实现的区别

- 会聚：基线两端朝向彼此，分别生成两个方向扇。等分系统排除0°基准方向，其余2*divider−1方向保留；自定义只用ABC及其360°反角。预览长度为基线10倍。一个点击位置分别选择两组最近候选，以两个方向的交点生成两条有限腿，不生成基线。
- 投影：第二点为起点，朝第一点为基准，预览长度为基线100倍。同样排除等分系统基线方向。第三次点击选择附近候选并正交投影，不增加定向截取的第四步。若附近真实线交点距点击位置小于投影误差的两倍，则优先交点；否则保留投影终点。
- constructionFan、convergenceFans、angleConvergence、angleProjection均不修改原图、不自行决定山谷；后续UI使用当前绘制线型与原子去重／提交。

## 明确差异和源码缺陷

- 原版模式13自定义第二扇循环i=1..6，却访问长度6的jk[i]，跳过索引0且访问越界6。本版对两扇遍历同一个六角列表，不复制这个缺陷；重复自定义方向仍去重。
- 本版交会拒绝近乎平行、反向及零长结果，并检查实际生成点±1000000范围。预览点可超出文档范围，不作为实际折痕写入。
- 投影吸附遵守工作台实际有限线段规则，不取不可见目标延长线交点；保留原版两倍投影误差判据，不直接复用角度拖画的无条件临近线吸附。
- 原版无效候选会清空输入；后续UI应保留基线供重试，右键／Esc显式取消。原版严格已有点输入与工作台自由／吸附扩展需在入口说明。

下一步新增独立 angleconverge、angleproject 入口，共用持久化角度设置。会聚需同时支持点击已有基线和两点定义基线，不能仅实现其一；点与线优先级参照原版：附近已有点优先，否则线身可作为基线。紫色双扇与结果悬停预览，点击交会结果原子提交两腿。投影两点后第三击提交，候选之外不能生成。必须回归取消、预设改变、真实分段、一次撤销、恢复及不误改参考线。尚未进行浏览器或原版运行时动态对照，不更新目录为基础可用。
