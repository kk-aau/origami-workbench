## 原版依据

已核对本地 Oriedita 1.1.3 的 `MouseHandlerChangeStandardFace`、`WireFrame_Worker.setStartingFaceId` / `getFacePositions` / `fold_movement`：在展开图中选面，该面保持原坐标，其余面通过邻接折线反射得到折叠位置。改变面后后续估计阶段失效。原版内部面编号从 1 开始。

本地 Rabbit Ear 0.9.4 的 `graph/faces/matrix.js` 已提供 `makeFacesMatrix2(graph, rootFaces)`，根面矩阵为恒等，其他面沿生成树组合反射。

## 实现

- `FlatFoldOptions.startingFace` 为当前 `buildFold` 图中的零基面索引；省略保持此前第 0 面默认值。不是原版按原点所在面自动选择的完整复刻。
- `computeFlatFold` 第三个参数接收选项，验证整数、非负和范围；无效返回中文 invalid，不默默钳制到其他面。
- 几何进度与最终结果的 `geometry.startingFace` 记录实际根面；每次调用重新计算几何和层序，不复用旧解。
- 独立 Worker 协议改为 `{doc, options}`，客户端仅复制计算参数，不尝试复制 UI 回调；Worker 端同步解包。
- 不向 Doc 写入不稳定的面索引，未改变文件格式、撤销历史或用户作品。界面目前继续默认根面，尚无选面入口。
