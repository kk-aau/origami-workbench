# 本批实际文件验收的脚本修正

这些修正发生在验收代码中；普通 DXF、FOLD 导出和导入核心保持原字节。旧脚本、失败文件和初步假设均保留，新脚本独立重跑真实用户文件。

| 情况 | 实际原因与处理 |
| --- | --- |
| 多瓣 DXF 的 0 / -0 | JavaScript 的深严格数值比较区分正负零，而 DXF 将它们写成相同的 0。新审计按有限数值严格相等比较，所有非零坐标仍精确相等；没有修改导出的坐标。 |
| 离散 CP 采用后的工作区等待 | 导航按钮的隐藏序号使 textContent 为 `01折痕编辑`。新脚本只去除工作区数字前缀，仍要求同一个活动按钮。早期 NAV/DIV 假设经真实 DOM 反证，错误且未执行的脚本另存；它没有计入通过结果。 |
| 工程库同名文件重开等待 | 刚导入的文件已有相同名称，名称判断会早于异步读取完成。新脚本等待真实保存 UUID 的 GET 响应及已保存状态，再核工程库重开。 |
| 普通 FOLD 的原索引 | CP-only 的材料 FOLD 保原图索引；普通采用没有材料图，其普通 FOLD 沿用既有识别器重新编号。独立回读建立顶点一一对应，并严格核每条边、赋型、折角及同向面环，保留原坐标公差；不把合法编号变化视为结构变化。 |

真实普通离散样本的顶点到原图映射为 `[0,1,3,6,2,4,7,5,8]`，面映射为 `[2,0,1,3]`。完整 9 顶点、12 边、4 面及山谷赋型保持；普通 FOLD 及其重开文件的最大坐标差为约 `7.105427357601002e-15 mm`。这个舍入量没有触发端点吸附、几何修补或单位转换变更。

最终界面为 `/assets/main-BziiVrYT.js`。五个完整主界面流程共 166 项，76 份按钮导出；每份文件回读报告与最终冻结清单分别记录，程序生成夹具和 API 捕获不计作用户下载。未验证第三方刻字软件、机器加工、Wolfram 执行或物理折叠。
