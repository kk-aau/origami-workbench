# P33：通用二维 Graphics 的数值入口

本轮补上实际可编辑的图元来源，而非仅保存单个测试图。入口为“拼块装饰与编号 → 二维绘图”；来源经受限解析后用于母片、折痕图叠加和层序已验证的实体平折图。没有新增具名三维 `RenderTile` 分派，也不执行 Mathematica 程序。

## 数值合同

| 类别 | 接受内容 |
| --- | --- |
| 图元 | `Point[{x,y}]` 或 `Point[{{x,y},...}]`；Line／Polygon 的单点列或多点列数组；`Text["普通文字",{x,y}]`，可再给 `{对齐x,对齐y}`、非零 `{方向x,方向y}`。普通多列表的原式有效变换域见下表。 |
| 组织与变换 | 裸图元、列表及嵌套列表、`Graphics[对象]`、`Style[对象,样式...]`、`Directive[...]`、`GraphicsComplex[顶点,对象]`、`MatrixTransform[对象,{{a,b},{c,d}}]`。GraphicsComplex 不嵌套；Point 接受单索引／索引列表，Line／Polygon 接受单索引列／多索引列，Text 锚点接受单索引；均严格一基编号。 |
| 样式 | 已有不透明颜色表达式、TilingText／TilingLine／TilingNoFill／TilingLightFill／TilingMedFill／TilingDarkFill；`AbsoluteThickness`、`AbsolutePointSize`、`FontSize->数值`、`FaceForm`、`EdgeForm`、空 `Dashing[{}]`、`AbsoluteDashing[有限数列]`、有限 CapForm／JoinForm。 |
| 数值 | 有符号实数字面量、科学记数、Mathematica `*^` 和有限字面量分数；不允许符号坐标、运算函数或求值。矩阵元素绝对值≤100，坐标绝对值≤10⁶。 |
| 容量 | 来源≤8192字符、解析树≤4096节点、深度≤20、输出≤128图元／512点（多折线／多面按各条／各片计）、框架≤512顶点；字号6–72、线宽0.1–12、点径0.1–32；绝对虚线≤16段、每段0–64且非空数组须有正段。Text≤128字符，不允许控制字符或任意转义程序。 |
| 保存 | 每片 `graphics:{source,frame}` 仅允许这两个字段。source 原文完整保留；每次回读重新解析，frame 是有限非共线源顶点列表且数量对应源 face。不接受夹带的缓存 AST、未知绘图 head 或代码。无该字段的旧工程保持旧行为。 |

frame 采用**已有母片工作区的坐标**，与既有母图和 CP 一致，其 SVG 屏幕 y 方向向下。它不是独立 Mathematica 图片的像素坐标还原；已有 TestTile 来源预览的 y↑ 转換只用于其独立保存输出。非对称 L 线从 `(0.05,0.05)` 至 `(0.05,0.35)`、再至 `(0.3,0.35)`，在来源预览和 CP 均同向；A 字形不镜像。源码数值不因画布缩放改写。

框架与当前拼块不相似、角编号不确定或原框架退化时，不猜测绘图定位。原有形状编辑清除装饰的规则保持不变。母图允许输入图元伸出母片；折后显示只保留真实纸面上的部分。

## 多列表与原函数层级

原定义并非任意层数的坐标递归映射。按 [Wolfram Dot 文档](https://reference.wolfram.com/language/ref/Dot.html)，`m.x` 收缩 m 的末轴与 x 的首轴；2×2 矩阵左乘多点列表会混合两行点，而不是分别旋转每个点。EmbedTile 的 `offset + m.x` 还按照 Plus 的可列表化行为，将 offset 的两个分量分别广播到结果的两行。默认放置也保留这一行为，不能只在 MatrixTransform 入口做到原式语义、随后又静默换成逐点放置。

| 来源形式 | 原式作用与工作台行为 |
| --- | --- |
| 普通单 Point／单折线／单多边形／Text 锚点 | 每个二维向量按原矩阵与放置变换；Text 的后续参数不变。 |
| 普通 `Point[{{x1,y1},{x2,y2}}]` | Point 将整个2×2点列交给 f；显式矩阵与 EmbedTile 放置均保留行混合和 offset 行广播。例：`{{0,-1},{1,0}}.{{1,2},{3,4}}` 得 `{{-3,-4},{1,2}}`。 |
| 普通 `Line[{{{x1,y1},{x2,y2}},...}]` | Line 只 map 一层，因此每条两点路径作为一个矩阵交给 f；按同样行运算。各条路径不能接成一条折线。 |
| 普通多于两个点的 Point、含三点以上路径的多折线、多多边形 | 独立 Graphics 数值来源可以预览，但显式2×2 MatrixTransform／EmbedTile 的原 Dot 维数不相容。显式矩阵来源准确拒绝；裸来源保持编辑原文，显示独立来源预览并禁保存放置。保存回读也拒绝不相容来源。 |
| GraphicsComplex 多点／多折线／多多边形 | 原定义先 `f /@ vertices` 并保护索引，任意有限索引分组都在有效域；完整支持母图、CP 和已验证正背 FF。 |
| 编辑器“转为共享顶点” | 用户显式点击才替换编辑文本，将当前已解析数值图形等价写成 GraphicsComplex，保留列表层级、Style／Tiling 样式及 Text 参数；已求出的有限 MatrixTransform 数值保留在新顶点中。转换前不会改写原文或已保存项目；保存后仍只有新 source 与原 frame。超出来源容量的转换不提供按钮。 |

转换保持独立来源的图形。对于原本可放置的两行普通多点／多线，转成 GraphicsComplex 后将采用原定义的逐顶点变换，放置结果可能因此改变；按钮是明确的来源转换，不声称这两种变换层级互为同义。

Text 的 offset 是文字包围盒的相对对齐点，允许不在 -1…1 内；方向 `{1,0}` 为正常水平、`{0,1}` 为自下向上、`{0,-1}` 为自上向下、`{-1,0}` 为倒置。按 [Wolfram Text 文档](https://reference.wolfram.com/language/ref/Text.html) 的该合同测量实际 SVG 字形包围盒；矩阵、母片放置、纸面反射与背面投影仅改变锚点，既不旋转这些参数也不镜像默认字形。锚点仍遵守上文工作区 y↓ 合同，文字方向与包围盒参数遵守其独立 Text 合同。

## 平折与显示门禁

| 场景 | 行为 |
| --- | --- |
| 展开图 | 源框架 → 当前母片／重复片 → 现有200单位画布；按来源列表顺序渲染。图元不改 CP 的顶点、山谷赋型或构造键。 |
| 正面实体 | 使用正面的实际 `modelRegionLayers` 已确认可见面；图元先定位到 CP，再用该实际面坐标映射，最后裁到该面与拼块的可见交集。 |
| 背面实体 | 独立使用背面的实际可见面集合并应用背面投影；没有复用正面 top face。回归 front 的 top faces 为19／21／23／25／27／29／30／32／34，back 为18／20／24／31／35，均147个可见分区且覆盖面积一致。 |
| 层序无解／未知／超时、遮挡待确认、面映射失真 | 沿用既有关闭装饰的门禁，不用上次图元绕过验证。P36 无解原输入不因此获得可见墨迹。 |
| 透视 | 保留既有透视不叠加平折装饰的合同，本轮未扩展透视墨迹语义。 |
| 缩放 | 线宽与绝对虚线 `non-scaling-stroke`；文字字号和点径按 SVG 的实际屏幕 CTM 补偿。2倍视域缩放前后均保持18px文字、6px点径、2px线宽和3／3绝对虚线；文字 offset 按实际字号下的字形包围盒重新测量。 |

来源编辑器1000×800和1000×390窗口均无面板横纵滚动，保存／取消按钮完整可见；低窗口预览仍有169px高度。输入文字编辑区域可以滚动长来源，主工具栏没有新增参数行。

## 尚未声称覆盖的通用域

| 原版／Mathematica 更宽的能力 | 本轮边界 |
| --- | --- |
| 任意 `FunctionTransform` 纯函数、任意 Wolfram 表达式、符号运算／富文本 | 仅有限字面量和上表 grammar；不执行代码，不提供整个 Mathematica 运行时。 |
| FunctionTransform 原定义还识别 Sphere、Tube、Arrow 等三维元素 | 不在本次数值二维原语组内；没有捏造缺失的具名 FoldedForm3D RenderTile 规则。 |
| Circle／Disk／GeometricTransformation／Inset 和额外 Graphics 选项 | 本次 FunctionTransform 的显式坐标转换定义未覆盖这些 head；本轮不接受，不宣称已复现。 |
| 任意多列表都按单点语义递归变换 | 原 FunctionTransform 没有该语义；默认入口准确保留原函数层级和维数门禁。GraphicsComplex 覆盖完整数值多列表有效域，未引入静默逐坐标扩展。 |
| 任意透明材质、动画评估、象征型 TObj 图元分派 | 本轮二维来源不会改变现有真实几何、层序及材质合同。 |

此前 P16 对具名 PolygonTile 的固定装饰列表审计仍适用于其原规则。本轮基于 In[2786] 通用列表及 EmbedTile 所实际调用的 FunctionTransform／MatrixTransform 补出新的数值通用入口，不把这组支持误称为任意 Graphics／TObj 全域完成。
