# 正方格与旋转

用户于 2026-10-28 反馈对角网格不是正方形，并要求旋转正方形网格。本次仅修改迁移版，不打包、不上传、不改版本。

原先横纵分别按纸张宽、高等分，长方形纸上的单元格被拉伸。现在主应用的“方格”和“方格＋对角”统一采用工程记录的纸张基准宽度除以等分数作为两个方向的格距，对角参考线与方格边保持 45°。

用户随后补充：删除边界再重画时，网格不能跟着新边界变化。当前网格固定读取工程的 `doc.paper` 尺寸，原点固定为 `(0,0)`；不再按边界、折痕或辅助线的外包框重新等分。新建空白默认 **300 × 300 mm**；已有工程的有效尺寸保留。右侧“纸张与画布”宽高和“适应画布”控件组已移除。

| 功能 | 当前行为 |
| --- | --- |
| 网格旋转 | 右侧“画布 → 网格与吸附 → 网格旋转”；输入度数，或选择 0°、45°、90° |
| 旋转中心 | 固定纸张基准的中心，整套方格和对角参考线一起旋转；增删边界不会移动中心 |
| 输入 | 有效有限角度提交并规范化，例如 270° 为 −90°、360° 为 0°；非法草稿不改变当前角度，Esc 取消 |
| 显示与吸附 | 网格、节点、纸边／折痕与网格交点、构造紫线及受限取点使用同一旋转几何 |
| 范围 | 有效闭合边界按真实纸面及孔洞裁切；边界删除或未闭合时，基准矩形内继续显示参考网格以便重画，不伪造实际纸面；全画布模式沿相同网格延伸 |
| 正三角 | 保持原来的等边密铺，切回方格时恢复保存的方格旋转 |
| 导出 | SVG 使用相同旋转原点及角度；周期图案避免大范围导出枚举大量网格线 |
| 偏好 | 旋转保存在本机并参与原生配置归档；重置网格归零 |

该操作是整体旋转正方格，不恢复之前撤回的自定义对角夹角。内部未指定网格格式的旧工作区调用仍保留其原有纸张等分语义，不改写用户工程和既有折痕。

开发验收记录位于 `output/square-grid-rotation-20261028/`，包括各模块修改前 SHA256、针对性测试、真实画布交互、导出渲染、开发构建及最终 `result.json`。全部验证缓存和隔离测试数据位于 D 盘。
