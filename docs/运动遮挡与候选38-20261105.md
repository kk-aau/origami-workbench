# 运动遮挡与候选 38

| 改动 | 结果与边界 |
| --- | --- |
| 立体拖动预览 | 后台执行与保存视角相同的空间重投影、局部遮挡和 SVG 绘制；一次计算一个视角，待处理鼠标位置合并，旧任务可以终止。不再在拖动时覆盖无纸层关系的 GPU 纸面；复杂场景可能有响应延迟 |
| 空间动画起态 | 将空间纸面中已验证的物理接触独立传入动画规划，保留原本禁止用二维平折推断非水平起态的约束 |
| 数值动画中间态 | 对没有解析刚性阶段的路径，只有两源纸面的全部顶点仍共享同一刚性变换时，才能继承旧纸层关系；拉伸、相对移动、滑动、弯曲不继承 |
| 准备完整性 | 默认完整遍历显示接触关系，不再因固定显示对数预算丢弃新层序。窗口关闭仍可终止；整体 Worker 等待不再写死 60 / 120 秒，显式调用者仍可给定时限 |
| 真实相交 | 默认开启动画碰撞保护；无法确认无穿透时停止。渲染只裁定可见纸层，不移动求解顶点，也不把真实交叉伪装成无碰撞 |
| 其他修复 | 含折序三维取消 180° 自动暂停与细分入口，以及应用折角后继续调角的目标保存修复 |

开发验证：针对空间动画、连续叠纸、光栅颜色、真实微小间隙与交叉深度的回归；独立浏览器使用三纸面（旧折痕 180°、另一折痕 −60°）验证拖动时生成精确 SVG、无 GPU 纸面覆盖、松开保存完成，控制台无错误。截图位于 `.runtime/motion-occlusion-qa/`。未取得本次用户出现异常的原工程做逐帧对照，不宣称任意运动都能达到目标。

候选 `0.13.53-tauri.38` 按已授权打包请求生成，沿用“打包不检查”的最终 EXE 验收边界，开发验证与最终发行包验收分别记录。不上传网络，不覆盖 tauri.37。
