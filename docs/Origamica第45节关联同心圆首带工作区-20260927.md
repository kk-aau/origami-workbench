# 第 45 节关联同心圆保存例：首条直纹带

原版 `Origamica 15.0.nb` 339070–340310 行给出五条关联同心圆的绘图输入：`R_i=1+0.1i`，`q_0(s)=s`，`q_1(s)=s+0.1 sin(2s)`，初始折角 `γ_0=120°`，`s∈[0,π]`。笔记本没有保存可机读的三维点表。后续传播将自身参数与公共参数混用，见[源码审计](Origamica第45节关联多曲折保存示例审计-20260924.md)；本入口因此只复现**第一条** `f_0→f_1` 带片，不能标称原版五折整串已完成。

二维两边界是 `f_0=(cos s,sin s)`、`f_1=1.1(cos q_1,sin q_1)`。在首曲线的切向 `T` 和左横向 `L` 下，联结母线 `h=aT+bL`，其中 `a=1.1 sin(q_1−s)`、`b=1−1.1 cos(q_1−s)`。三维首曲线按原版 Darboux 条件积分：`T′=L+√3N`、`L′=−T−√3(a/b)N`，初值 `F_0(0)=(1,0,0)`、`T(0)=(0,1,0)`、`L(0)=(−1,0,0)`、`N(0)=(0,0,1)`；第二边界为 `F_1=F_0+aT+bL`。因为 `a√3+b(−√3a/b)=0`，母线导数没有法向分量，二维与三维首带的第一基本形式逐点相同，带片可展。`|q_1−s|≤0.1`、`q_1′≥0.8`，两端的有向雅可比分别为 `b≤1−1.1 cos(0.1)<−0.0945` 和 `1.1 q_1′(cos(q_1−s)−1.1)≤−0.088`；中间对母线参数线性插值，故 `v∈[0,1]` 不碰焦线。这是连续方程的局部证明，三维点列由高精度 ODE 作数值绘图。

工作区“空间构造 → 关联同心圆首带 · 只读”通过独立 `/api/tessellation/curved-linked-first-band` 查询展示二维展开和三维正交投影；可改 8–128 段本地采样、当前母线和视角。默认 32 段是本地绘图选择，不冒充原版 `ListInterpolation` 的 32 个插值节点或 Wolfram 数值输出。查询只接受固定保存族，前端重新验算每条二维圆、三维对应母线长度、数值误差证书，并拒绝把五折整体、精确直折痕 FOLD 或可采用折痕宣称为已验证。无采用按钮，不写入当前工程。

本项目默认 32 段返回 33 对边界点，三维标架正交最大数值误差 `3.73×10⁻¹²`，两边界切向身份最大误差 `2.50×10⁻¹⁶`。这些数是本地计算，不是原版 `Out`。后端 `test_tessellation_curved_linked_first_band.py` 和前端 `curvedLinkedFirstBand.test.ts` 各 2 项通过。1000×720 实际浏览器双视图无页面或对话框垂直滚动；改为 8 段会重新计算，输入非法的 129 段立即清空旧图并显示范围错误。截图见 `../output/playwright/linked-first-band-20260927.png`。完整回归记录以主台账为准。此项不证明后四条带片、整串无自交、连续部署路径、纸厚可制造性或可导出的精确直折痕 FOLD。

同一保存首带另有有限三角纸面近似，逐面精确等距并可在同画布采用；它不改变本只读光滑带的认证边界，见《Origamica第45节关联同心圆首带等距多面体-20260927.md》。
