# PDF 首页与保存目录

本次改动已接入源码，当前发行包仍为 v0.13.13。网页前端可独立更新；保存目录的磁盘操作需要本次新版服务。已运行的旧镶嵌进程不重启，下一次正常启动新版服务时启用目录功能。

## PDF 排版

默认“图文首页”参考所提供样张的元素位置，不限制步骤网格。首页上方从左到右是作品信息、完成图、最终 CP，横线下方直接开始步骤；步骤图片下方显示编号、标题与说明。页码居中显示为 001、002，两侧有短横线。

2026-10-14 调整：首页高度按实际信息与可见图形计算，信息文字适度放大；短附注紧随纸张信息，较长附注放在信息和图形下方的通栏中。关闭完成图或最终 CP 时收回对应空栏；关闭两者后仅按文字所需高度排版，减少留白。首页和后续页的行列设置保留。若过多首页文字使折图高度不足，会提示减少首页行数或精简文字，不自动改变用户所选网格。

| 设置 | 用法 |
|---|---|
| 首页步骤网格 | 单独选择首页的列数和行数 |
| 后续页步骤网格 | 单独选择后续页的列数和行数 |
| 纸张与方向 | A4 / A3，纵向 / 横向 |
| 作品信息 | 标题、设计者和设计日期、制图者和制图日期、纸张信息、可选首页附注 |
| 首页主图 | 最后一步纸面、当前步骤纸面或不显示 |
| 首页 CP | 可显示最终 CP，或关闭 |
| 首面类型 | 图文首页、独立标准封面、独立简洁封面、直接从步骤开始 |
| 导出范围 | 全部、当前步骤、自定义范围 |

完成图采用保存的纸张姿态，不附加教学箭头。尚未保存完成姿态时使用 CP 提示。步骤说明过长会进入说明续页。预览与真实导出共用排版坐标；参考图中的作者、群号、网址等信息没有作为用户数据默认填写。

## 保存目录

首次使用新版服务会先显示目录设置，用户可以分别选择三个文件夹，或确认默认目录。之后可从界面“设置”或桌面菜单“设置 → 保存目录设置”修改。

| 目录 | 保存内容 |
|---|---|
| 折痕工程 | 折痕编辑工作区保存的工程 JSON 及备份 |
| 折序绘图 | 绘图库目录、文件夹记录、工程、手动保存版本和草稿 |
| 程序数据 | 应用设置、折痕编辑自动恢复与应用日志 |

浏览器及 Electron Chromium 缓存由宿主管理，不作为可在线搬移的数据。定位三类目录的配置保留在原程序数据入口，程序重开后仍可找到用户选择的目录。免安装版移动至其他电脑时，自选目录中的内容也需要一并备份和携带。

选择新文件夹后，界面会显示待应用路径；点击“迁移并应用”统一处理。三个目录应使用不同文件夹。应用先完成已排队的保存、暂停日志写入、复制应用管理的文件并核验内容，全部成功后才切换目录。随后新保存进入新位置；原目录的文件保留。

目标目录存在同名而内容不同的文件、文件不可写或复制核验失败时，仍使用原目录，不覆盖目标文件。用户可撤回待应用选择、重新选择空文件夹后重试。旧浏览器绘图与磁盘绘图库合并时保留双方内容；旧浏览器记录保留作恢复副本。
