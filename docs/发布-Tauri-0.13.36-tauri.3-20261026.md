# 折纸工坊 Tauri 独立版 0.13.36-tauri.3（已撤回候选）

本版迁移桌面运行环境与本地服务：Tauri／系统 WebView2 替代 Electron，Rust 替代 Node 服务。四个工作区的界面、操作与数值算法保持 v0.13.36 原样，完整 Python 离线计算引擎仍随包提供。原 `workbench/` 和旧版应用数据不改动。

| 内容 | 行为 |
|---|---|
| 安装与便携 | 提供独立命名的 Setup 和单文件 Portable；数据不与原 Electron 版混用 |
| 系统要求 | Windows 10/11 x64，已有 Microsoft Edge WebView2 Runtime；不需要另装 Node 或 Python，不自动下载运行环境 |
| 启动和退出 | 解压反馈与宿主启动页接力；日志写入有界等待，避免存储锁拖住退出；Windows Job Object负责后代清理 |
| 可移动资源 | 前端和引擎从EXE同级resources定位，不依赖开发目录 |
| 便携目录修复 | 先创建临时根再规范化；盘符、直属父目录与自有标记通过后才解压和清理 |
| 便携窗口修复 | 解压时显示独立启动图，宿主运行后启动器在后台等待退出；不再显示停在“运行”的安装进度窗口 |
| 启动页操作 | 修正本机 Origin 权限匹配，使慢启动时的退出与诊断操作可用；权限仍限于启动窗口 |
| 对应源码 | 普通ZIP与solid7z包含同一冻结清单；Rust依赖完整源码、原许可和构建脚本纳入交付 |

调试归档单独提供sourcemap与PDB，运行目录排除开发依赖与映射文件。完整引擎与已验证版本195个文件逐字节一致，沿用已有1358项Python回归，本轮不重复该完整矩阵；最终包中的真实计算、导入、三维、折序PDF、日志和原生关闭另行实测。

最终体积、逐文件SHA及验收完成状态以 `release/Tauri-0.13.36-tauri.3/RELEASE-0.13.36-tauri.3.json`、版本化SHA清单和本机 `output/tauri-release-0.13.36-tauri.3/` 为准。仅在全部门禁通过后才运行finalize脚本交付；本文件本身不代表某项测试已通过。
