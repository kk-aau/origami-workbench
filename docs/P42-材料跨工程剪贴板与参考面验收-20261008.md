# 第42节材料跨工程剪贴板与FF参考面（2026-10-08）

完整镶嵌复现目标保持 active。本批补齐会话内跨工程材料复制、完整部件剪切、带预览的粘贴，并修复补查发现的参考面混用。源码/网页构建已更新，现有0.13.5免安装EXE未重打包。

| 功能及原问题 | 当前实际行为 |
|---|---|
| 材料快照 | 复制完整部件的顶点、边、逐角面边归属、面、切口侧、孔洞边界、赋型、角度、显示色及当前FF姿态。副本独立；只选部分材料边明确拒绝，失败不替换原剪贴板。已选辅助线可携带；未选文字、圆、底图、工程设置和旧层序不作为材料复制。 |
| 普通剪贴板 | 普通工程和材料中的纯辅助选择仍保存旧几何快照，直接原位/偏移粘贴，保零/未知/自定义角及新ID规则。工具按钮与Ctrl+C/X/V共用同一处理；材料Ctrl+V打开预览。剪贴板只保当前会话，不写系统剪贴板或持久化到工程。 |
| 跨工程粘贴 | 可粘贴到已有材料、普通闭合纸面、空工程/仅辅助工程。目标已有几何及独立注释保持，来源副本获得不冲突的新ID；不按坐标焊接，原位重复粘贴仍为独立材料。 |
| 普通目标转换 | 默认必须有可逐值绑定的面边。允许用户明确选择“按已有交点分段目标”，沿用既有分段器并检查原端点及直线覆盖不变；预览显示分段前后数量。重复/零长/悬空线及不能在原直线上精确表示的交点拒绝，不静默删除或吸附；普通有效纸面按当前起始面生成并校验FF，不假定任意折痕的FF等于CP。 |
| 缺少FF | 两侧有FF时保留；一侧缺少时明确拒绝，必须由用户勾选“仅粘贴CP”，才清除合并工程的FF。不伪装已有FF。两侧均无FF继续缺省；仍可编辑和导出CP。 |
| 完整剪切 | 遵守纸边保护。删除完整部件及其材料关联；其余材料不焊接。起始面被删时明确迁移到剩余面，全部剪切时移除材料合同/起始面，保留未选辅助和独立注释；一次撤销/重做。材料剪切成功才更新剪贴板，拒绝时原快照保留。 |
| 预览与布局 | 有CP/FF毫米刻度、缩放、平移和恢复全图；紫色目标、青色副本。参数或选项变化使预览失效，不能跳过预览应用，支持取消。1000×720/800×720全控件可见，无窗口滚动。 |
| 原子提交 | 材料剪切/粘贴在中央提交层从当前工程、快照和选择完整重放；拒绝篡改提案与不一致合同，再写一次历史。旧平折过期，重新分析正背层序。 |

| FF参考关系修复 | 证据与当前行为 |
|---|---|
| 补查发现 | 目标原FF参考面F5，用户活动面F4。旧粘贴把活动面写成参考面而没有换坐标，已有画面发生285.2954831454554 mm位移；单看原FF数值不变或层序已解不能发现。 |
| 统一基底 | `materialFrameMap`集中定义活动显示基底及逆变换。相同基底直接保数值，避免恒等加减吞掉很小的坐标。参考面是材料合同的`startingFace`；活动面保在Doc的轮廓/`materialFace`。不得用活动面重新标记未换基的FF。 |
| 剪贴板 | 快照保存当前可见FF姿态。粘贴时显式换到目标的储存基底，保目标原FF及参考身份；显示后来源姿态仅作用户给定的毫米偏移。剪切若保留两种根则维持原坐标，根被移除时刚性换基，保剩余材料的显示位置。 |
| 既有编辑 | 完整复制和参考点移动保FF参考身份。粘合/面编辑分别处理临时重折锚定与最终参考：不能把重算锚点当成FF参考。面细分/合并同步映射参考与活动面，保原选中的固定侧。 |
| FOLD | 新增顶层`zhezhi_flat_fold`保存活动面配置，材料扩展继续保存原参考面及原FF。导入按FOLD单位转换轮廓一次，并校验活动面；不再用活动面覆盖FF参考面。普通CP/DXF坐标和普通FOLD流程未改变。 |
| 实际模型证明 | GUI实际下载粘贴前/后的模型快照与JSON/FOLD重开后的模型快照。原14个显示顶点逐值一致，最大位移0；参考面索引4、活动面索引3分别保留。不是仅根据层序通过推断没有跳动。 |
