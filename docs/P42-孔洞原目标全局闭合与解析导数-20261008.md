# 孔洞原目标全局闭合与解析导数（2026-10-08）

线组编织新增“非对称环带 · 原目标闭合（本地母图）”可采用示例。显式孔洞的原目标求解现在同时约束整片回展闭合；求解详情展示绕孔约束数量、独立求解/全部核对数量及实际残差。仍最小化原褶宽倍率平方和，保留下界、无人工倍率上限、原周期顺序与末项规则。

前批仅把全局闭合加到了兼容求解：非对称母图的局部反射方程可以成立，整圈仍未闭合，原目标当时会在最终回展门禁拒绝。本批没有改用兼容解冒充原目标，而是把完整回展约束接入原目标、解析导数和全部输出核对。

| 处理 | 最终行为 |
| --- | --- |
| 全局闭合 | 在固定面的回展森林中，逐面投影每个角点；同一原角点的所有重复投影差须为零。按母图坐标跨度归一化，既检查绕孔平移，也检查旋转，不仅检查局部四射线。 |
| 解析导数 | 原角点仍是褶宽倍率的仿射函数。逐条反射轴计算切向单位矢量与反射矩阵导数，递推完整等距变换的矩阵和偏移导数。对照独立旧回展程序及中央有限差分通过。 |
| 冗余约束 | 重复角点约束会有数值线性依赖。只在带孔原目标中，对初始下界的联合雅可比作带主元 QR，固定当前图的独立行供 SLSQP 求解。最终仍检查全部原反射、周期及回展残差；KKT诊断使用全部雅可比，不能以被选行的成功代替整片成功。 |
| 分支与预算 | 固定当前图的面绕数分支；越过分支、反射轴退化、非有限导数或预算/容量超限明确拒绝，不默默钳制、删除几何或换方法。保留512变量/方程、12000调用、8秒预算。 |
| 结果说明 | 非对称例是局部数值候选；对称例只有达到全部约束的精确下界时才标“下界已达到”。没有全局最优或Wolfram等价证明。 |
| 原功能 | 未带孔求解不做新增 QR 选行，既有反射及周期算法/保存来源保留。普通CP/DXF与加工优化生产代码保前批SHA。 |

原目标原始周期列表先按既有规则丢弃最后一个周期面积项，再追加全局回展约束；没有把“丢弃周期末项”误用于绕孔列表。数值独立行只对当前图和初值说明数值秩，不代表全域恒定秩或符号等价；最终全残差门禁继续保留。
