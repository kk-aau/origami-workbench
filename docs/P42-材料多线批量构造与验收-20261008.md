# 第42节材料多线批量构造（2026-10-08）

本批完成多条原边锚定直线的一次材料构造，完整目标保持 active。源码和网页构建已更新，现有0.13.5免安装EXE未重打包。旧批次验收快照保留。

| 原问题与功能 | 当前实际行为 |
|---|---|
| 逐条生成的中间态不闭合 | 先完成所有直线的材料面划分与交点同步，再按最终分段赋型统一重折。六角纸三条M/M/V并发线实测六段可平折；此前只生成前两条M时闭环不成立，不能因此拒绝最终完整结构。 |
| 输入范围 | 1–32条直线，端点按原材料边ID及0–100%比例确定，可选一个部件或明确全部部件。细分后锚点继续沿用原边世界坐标；不自动吸附或移动原端点。总新增分段限制4096，不静默截断。 |
| 交点与身份 | 每个共享材料交点只生成一次；切口两岸分别分点且身份独立；重叠部件不焊接。凹面、已有材料孔洞及部件间空白按实际材料区间裁剪，不跨空白补线。 |
| 分段赋型 | 每条直线设F/M/V/U，也可预览几何后逐段覆盖；分段按本条起点到终点顺序编号。完整重折失败时仍保留几何分段表，用户可以修正赋型后重新预览，不能应用失败的结果。 |
| 固定区域与FF | 原起始面内的固定点决定细分后固定子面，必须严格位于唯一子面内部；落在新增折痕上明确拒绝。保原参考面/活动面关系；缺少FF不虚构。用户明确选择“仅生成CP，清除FF”才清除已有FF。 |
| 可视化 | 毫米网格刻度、原边选取、比例滑条与精确数值、端点和固定点拖动/键盘调整、缩放平移及CP/FF预览。紫色虚线是构造参考，青色实线是实际折痕。1000×720和800×720完整控件可见，无窗口整体滚动；分段表独立滚动。 |
| 原子提交 | 中央提交层从当前工程和完整意图独立重放，拒绝篡改/过期提案；全部操作一次撤销/重做。取消不改工程。旧平折模型过期，重新计算层序；生成FF不等于已求层序或连续无碰撞折叠。 |
| 普通导出 | 保留原导出。实际JSON/FOLD重新解析，核对完整意图、CP/FF、根身份和正背层序；普通DXF仍为AC1009 R12 LINE，核对逐实体图层、毫米坐标和数量。加工优化三文件SHA保持，本批没有改加工方案。 |
