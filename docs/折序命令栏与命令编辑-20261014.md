# 折序命令栏与命令编辑

折序绘图主面板底部提供 CAD 命令栏。直接在画布输入英文字母，焦点进入命令框，按 Enter 启动对应功能；支持上下选择候选、Tab 补全、点击候选，以及中文名、内部标识和全角字符。Esc 只取消本次命令输入，保留绘图选区。空框 Enter 重复上次命令并重置该工具的未完成草稿。

| 常用命令 | 折序绘图功能 |
| --- | --- |
| L / LINE | 画折线，沿用当前折线类型 |
| V / SELECT | 选择 |
| PLINE | 连续折线 |
| P / PAN / H | 平移视图 |
| E / ERASE | 擦除 |
| MI / MIRROR | 镜像复制，随后点两点指定镜像轴 |
| CO / COPY | 复制选中，与“复制选中”按钮一致 |
| PL / PER / BI | 平行线、垂线、角平分线 |
| TR / EX | 修剪、延长 |
| MV / MM / MF / MA | 改用谷折线、峰折线、已有折痕、辅助线绘制 |
| PFC / FOLD | 预折后展开、本步折叠 |
| RA / SP | 比例分点、特殊取点 |
| VX / FIX / LY | 拖角、固定侧、选择纸层 |
| SY | 放置当前折纸符号 |
| SFOLD / 谷折箭头 | 放置谷折箭头 |
| U / DEL | 取消选择、删除选中 |

折序目录包含 60 项已有功能，其中 34 项为折纸符号。每种符号可直接输入符号名称，或输入 `S` 加符号内部名称，如 `SFOLD`、`SSWIVELDOUBLE`。需要选区、平折模型或平整状态的功能仍遵守对应按钮的使用条件。

两个工作区的直接输入偏好同步，并随程序设置保存。开关位于“设置 → 命令编辑 → 画布直接键入命令”，点击“保存并应用”后生效，取消不改变原偏好。底部命令栏不再显示 CAD 按钮；关闭直接键入后仍可点击命令框手动输入，Ctrl 组合键仍按当前工作区原有规则执行。步骤说明、标题、参数输入、文件库和弹窗中的文字输入不触发画布命令。

## 编辑自己的命令

点击应用顶部 **设置 → 命令编辑**，选择“折痕编辑”或“折序绘图”。默认分别提供 93 项和 60 项功能。

| 操作 | 行为 |
| --- | --- |
| 搜索功能名或命令 | 按中文名、内部标识、默认或自定义命令筛选 |
| 修改简称 | 在单独的“简称”输入框修改常用命令，不改变其他命令 |
| 编辑全称及其他命令 | 每个命令独立显示为标签；点击标签上的 × 删除，点击“添加”输入后按 Enter 确认 |
| 清空简称 | 保留其他标签，重新打开时全称也不会自动变成简称 |
| 清空所有命令 | 仍可通过功能的完整中文名或内部标识执行 |
| 恢复 | 恢复该功能的默认命令 |
| 恢复本工作区默认 | 仅恢复当前工作区，另一工作区的草稿保留 |
| 保存并应用 | 同时保存两个工作区的修改，命令栏立即更新 |
| 取消或关闭 | 放弃此次尚未保存的修改 |

同一工作区内，别名不能与其它功能的别名、中文名称或内部标识冲突。发现冲突时显示对应两项功能并阻止保存；两个工作区可分别使用同一个别名。保存失败会保留草稿。切换保存目录和命令编辑页不会丢失命令草稿；首次保存目录向导仍需先完成目录配置。

偏好使用 `zhezhi.tool-command-aliases.v1`，经现有程序偏好存储保存，跟随“程序数据”目录。外部损坏或冲突设置会回到可用的默认目录。

简称与其他命令分开显示（2026-10-14）：默认值仅在简称下方简要提示，恢复操作仍保留。原有自定义命令自动加载；旧版首个命令继续作为简称。新设置可明确保留空简称，其他命令保持独立。

本次分栏调整通过 33 项命令及偏好测试、39 个独立浏览器断言，并检查了 1,000 × 720 下的表内滚动与按钮可达性；覆盖旧设置、标签增删、输入法、焦点恢复、冲突、空简称、保存重开与恢复默认。记录见 `output/playwright/diagram-cad-fields-ui-validation-1014.json`。

## 重命名绘图

主工具栏上方显示当前绘图名称，旁边的 **重命名** 按钮可直接修改；右侧“工程 → 工程名称”与“文档库 → 绘图卡片底部 → 重命名”入口仍可使用。主图入口同步当前工程与文档库的名称，保留步骤、CP 和绘图内容。
