# 弱材料直线、射线与批量构造（2026-10-09）

本批接通实际弱切口材料上的直线分面、射线和批量线，并修复这些新构造接入三维时暴露的网格问题。完整 Origamica 复现目标继续；免安装版本未重打包。

| 功能 | 当前效果 |
| --- | --- |
| 跨切口直线 | 内部孤立切口、边界悬空切口、交叉树及孔洞单桥可按实际出射方向选择两侧交点，并生成真实材料子面。 |
| 单面添加折痕 | 弱轮廓使用实际有向面角分面，不再用第一次出现的顶点位置切割重复轮廓。预览以青色显示实际分段。 |
| 指定切口侧射线 | 从明确选择的切口侧出发，只加工正向纸面；选择与方向不符的另一侧会提示，而不会悄悄换侧。交叉切口中心保各个独立顶点扇。 |
| 两线及分段赋型 | 后续线按原锚点后代重新绑定，保独立切口的同步分点；批量分段可独立赋型，并整体提交。 |
| 明确仅 CP | 单面和跨面直线新增“仅CP”，修改后旧预览失效；单桥 M 可采用实际 CP、保存和模拟，仍不伪造刚性 FF。历史中没有此字段的旧意图保持兼容。 |

| 界面与历史 | 沿用毫米刻度、边锚点比例、拖动及预览/取消。新直线窗口在 1000×720、800×720 下全部控件可见，无窗口滚动。一次构造一次撤销/重做。 |
| 普通及三维文件 | CP/JSON/FOLD/普通 R12 LINE DXF 保实际源线和原坐标；三维副本完整载入，源边/顶点/切口侧保留，当前网格 FOLD 可重开。 |

## 问题与实现

原直线流程把同坐标的两侧切口当成排序相邻的两个事件，选中的事件无法代表实际材料侧。无孔弱轮廓又进入简单环的首个顶点分割；有孔弱轮廓进入不允许重复边界的旧绕行。这些路径会报“材料角归属不一致”或丢失面角。

现在每个几何交点分组后，按实际射出方向核对原边侧与顶点扇；几何分组不合并公开顶点。弱材料和孔洞统一从真实边界 darts 生成分面。切口对侧仍分别建立分点，各自保存赋型、坐标和原 FF，不加孔洞/空白中的连接线。重叠继续提示并拒绝，不吸附或移动源端点。

三维接续新增两层处理：局部验证按实际边关联区分一个全局顶点在单个原面内的多个局部扇，避免把合法分面误判成焊接；最终公共网格仍必须保持每个源顶点的单个连通全局材料扇。

普通 Earcut 在附接支线的切口树上可能省略整段弱绕行。受约束回退先取得纸面区域的几何三角种子，再逐一插入全部源点和源线：穿越新约束的三角走廊重新分为两侧，所有先前约束必须保留。之后按实际扇恢复独立索引身份，并独立检查原线方向、源点完整性、孔洞/纸面覆盖、原面所有权、边关联和全局材料扇。区域种子没有直接充当模拟网格，省略切口的种子不得导出。没有生成新源点、移动原坐标或把辅助边写入 CP/DXF；全部工作受预算限制。
