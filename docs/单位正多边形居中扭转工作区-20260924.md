# 单位正多边形扭转工作区入口（2026-09-24）

在“镶嵌设计 → 自定义”点击“原版正多边形”。同一弹窗的“原版构造”可选三个稳定具名类型：`UnitRegularPolygonCenteredTwistTile`（居中褶角 τ，In[3005]）、`UnitRegularPolygonCenteredTwistAltTile`（居中扭角 α，In[3010]）和 `UnitRegularPolygonOffsetTwistTile`（逐块有符号偏置 d，In[3019]）。居中两块样例为 `n=4,w=0.2,τ=70°,MMVV`；Alt 为 `n=4,w=0.2,α=30°,MMVV`；Offset 为下块 `d=+0.15,VVVV`、上移一单位的上块 `d=−0.15,VVVV`，两块褶线倾角均为 90°。每种模式都可改单块、边数、褶宽和逐边 M/V；Offset 的两块偏置与赋型独立编辑。切换模式载入相应样例参数，并保留边数、褶宽和单块／两块排布。

Alt 限于 `1° ≤ α < 90°`，按原版关系 `τ=atan(tan α / w)` 换算；实现使用数值稳定的 `atan2(sin α, w cos α)`。任意参数会生成候选，但尚未逐点证明与原版 Mathematica 输出等价。

入口复用 custom 母网格和逐块 `tileTwists`；Alt 使用既有 `angleMode:'twist'` 与 `twistAngle`，Offset 逐块使用 `tilt:90` 与有符号 `offset`。三个模式沿用整片 CP 构造、平折预览与全局层序求解，只有当前候选的整片层序为 `solved` 且 `canAdoptTessWithTileLayers` 通过时才能采用。“原版正多边形”仍只占侧栏一个按钮，逐边赋型放在弹窗内。

采用并保存后，工程的 `metadata.tessellation.parameters.unitRegularCentered` 保留原始类型与参数：居中型为 `n/w/τ` 或 `n/w/α` 及逐边 M/V，Offset 为 `n/w` 及每块自己的有符号 `d` 和逐边 M/V。`unitRegularCentered` 是为兼容旧工程保留的来源键，`tileType` 明确区分三个具名类型。后端请求剥离该来源字段，只发送已定义的构造参数。在“镶嵌设计”点击“读取工程参数”可继续编辑。读回时核对来源规格、母网格、逐块扭转参数与拼块合并选项；伪造来源无法读回。用户修改拼块合并选项时，过期来源会被清除。

专项脚本 `scripts/verify-unit-regular-centered-workspace.ts` 与 `scripts/verify-unit-regular-offset-workspace.ts` 验证三个来源的构造、唯一完整层序、采用门禁、工程读回和篡改拒绝。Alt In[3010] 与 Offset In[3019] 的两块 CP 均为 24 顶点、38 边、15 面。隔离端口 `8898`、`8899` 与独立数据目录的真实浏览器分别验证了 Alt 与 Offset 的已解采用和保存、工程库重开后参数回读及重新求解、伪造来源拒绝；1000×720 下默认侧栏、n=4/n=12 弹窗及侧栏无垂直滚动。Offset 的 n=12 双块共 24 个 M/V 控件，最终弹窗 `clientHeight=scrollHeight=607`。不相容的褶宽/偏置输入会显示错误且不会覆盖当前有效候选。浏览器脚本与截图保存在 `output/playwright/unit-regular-*`。
