# 折痕编辑辅助线选择与删除

本次更新源码及网页构建，未重新打包安装版／免安装版。

## 问题与修复

普通辅助线保存为工程内的 A 类型线段，原本没有统一禁止选择或删除。实际发现以下交互问题。

| 条件 | 原行为 | 修复结果 |
|---|---|---|
| 辅助线与同画布平折面重叠 | 模型面截获点击和右拖；收起平折后才能操作原线 | 绘图工具模式使模型叠层不参与鼠标／键盘交互，折痕画布正常接收操作；平折参数模式保留模型选面、拖动 |
| 隐藏主线紧邻显示的辅助线 | 拾取仍查询完整工程，可能选中／删除隐藏主线 | 点击、框选、顶点和区域选择、撤选、镜像选区及擦除查询显示线段；提交仍基于完整工程，不丢弃隐藏线或材料合同 |
| 材料框删同时包含材料边和辅助线 | 提交被材料拓扑限制拒绝，却清除选区并报告已删除 | 拒绝时显示原因，保留工程和选区，不报告成功；只框住辅助线可正常删除 |

已用真实浏览器在平折覆盖处复现原问题：同点命中模型 polygon，辅助线未选中、右拖后仍保留；收起平折后同点恢复选择。修复后，同一类重叠位置在绘图模式可选择和框删，同时模型模式的点击和拖动通过回归检查。

点击左侧绘图工具、新线类型或执行 CAD 工具命令会回到绘图模式。需要操作平折模型时，切到右侧“平折参数”。

## 操作规则

| 操作 | 行为 |
|---|---|
| 选择辅助线 | “选择”，或 CAD 开启时输入 V 后按 Enter；点选、Shift 多选、框选均可 |
| 右键单击 | 空闲时删除命中的可见小段 |
| 右键向右拖 | 删除被框完整包含的小段 |
| 右键向左拖 | 删除与框相交或接触的小段 |
| 已有起点或未完成构造时右键 | 第一次取消当前操作；再次右键才删除 |
| 撤销／重做 | Ctrl+Z、Ctrl+Y 或 Ctrl+Shift+Z |

材料边仍需要明确的材料拓扑操作；本次没有绕过该约束，也没有恢复已取消的三维自穿越保护。
