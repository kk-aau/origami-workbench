# 母图可视点边编辑与验收（2026-10-08）

有限母图现在可以直接用画布构造和修改，不必逐个改 JSON 坐标。沿用“线组编织 → 编辑母图”窗口，原 CP/FF 检查、自动拆交点、来源文件导入导出仍保留。完整镶嵌复现目标 active；本批源码和网页更新，EXE 未重新打包。

| 操作 | 最终行为 |
| --- | --- |
| 移点与精确输入 | 拖动、方向键微移或输入完整双精度 X/Y；点边原序保持，默认不吸附。黑色原线、紫色草图改动、青色选中。拖动时固定视图，每次拖动只记录一次历史。 |
| 点边构造 | 空白处新增点，点击两点连边或选起终点加边，删点/删边，按比例分边；可从空草图开始。分边追加新点，其他编号保持；明确删点会删除关联边并重编号后续点，可整次撤销。重复/零长边明确提示。 |
| 导航与刻度 | 母图、原 CP、原 FF 均有源坐标刻度、缩放和平移。中键或平移按钮导航；显式吸附使用可见网格。刻度不是另一次毫米转换，纯导航不改变母图坐标。 |
| 历史与取消 | 草图撤销/重做、Ctrl+Z/Y、跨原 CP/FF 检查保历史；指针取消回滚拖动。关闭窗口保原工程及参数。数字输入内保留原输入操作，不劫持文本快捷键。 |
| 来源与保存 | 修改草图即禁用旧 CP/FF。保存时重新构造；几何变化清除旧完整内缩绑定、周期和固定面编号。原来源保只读派生图，可选择手工母图或编辑自动拆分的原输入。 |
| 自动拆分 | 源线网原输入可直接增删点边；改动后必须重新拆交点。未重拆时禁止保存和导出旧派生母图。原输入与实际拆分母图分别保存，不伪造来源。 |
| 布局 | 1000/800/390×720 的手工母图、原线网编辑及拆分检查均无整体横纵滚动，画布高度至少 90 px。390 检查限本弹窗，不声称主工作区已实现移动布局。 |

草图允许暂时没有足够点边或存在待完成连接；只有满足既有输入合同的母图才能保存，后台几何、局部条件和整片层序门禁继续保留。拖动即时更新草图，实际 CP 在保存时重新构造。视觉操作没有移动原工程 CP 端点；采用前仍需层序已解。
