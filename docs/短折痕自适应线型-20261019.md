# 短折痕自适应线型

2026-10-19。日常源码开发，不生成或覆盖桌面发行包。

## 使用方式

| 位置 | 用法 |
|---|---|
| 折痕编辑 | 设置中的“折痕显示 → 自适应线型”，即时保存 |
| 折序绘图 | 顶部颜色、粗细、线型旁的“自适应线型” |
| 默认状态 | 开启；两个工作台共用同一偏好，切换工作台和重启后保持 |
| 关闭 | 恢复原有笔宽与虚线间距，不增加自适应相位 |
| 极短折痕 | 悬停查看峰折／谷折类型，放大后重新计算线型细节 |

颜色和线型类别沿用用户设置，包括显式实线、自定义虚线及辅助线颜色。自适应只改变显示，不写入 CP、FOLD、求解几何、材料选择或折序注释，也不产生工程撤销历史。

## 渲染规则

| 场景 | 行为 |
|---|---|
| 正常长线 | 保留可读的原节距 |
| 亚像素花纹 | 在计算周期前适当增加节距，避免远缩放时点划与间隙糊在一起 |
| 短线 | 依次尝试两周期、一周期，按完整逻辑来源的长度压缩节距；起点调整后让点划特征落入可见范围 |
| 圆头端点 | 间隙计算扣除端点延伸，必要时适度减细笔画，避免粘连 |
| 极短线 | 不能同时放下可读点划和间隙时，显示同色细线并附类型与放大提示；原本就很细的笔画不会被强行加粗 |
| 命中与编辑 | 选择、吸附、构造预览和控制点范围使用原有规则，不随可见笔画变细 |

可读间隙参考下限为 0.7 个 CSS 像素，笔画与点参考 0.65 个 CSS 像素；保留用户本来低于该宽度的细线。接近周期切换阈值时，花纹周期和相位可能切换一次。只有几像素的折痕仍需依靠类型提示、颜色或局部放大辨识。

`adaptiveLineStyle.ts` 使用显示比例 `units`（每输出像素占用的世界单位）计算，不改变源线段。独立短线使用自身长度；已知来源的碎片使用 `strokeSpan.length/offset` 共享节距、笔宽及累计相位。

## 来源与相位

折痕主画布以文档中的真实 Segment 为来源，不把交点显示或吸附分割当作新折痕。侧栏 CP 的图拓扑具有唯一真实 `edgeSourceIds` 时，可从完整源线延续相位；外供图或重叠多源不能证明身份时，不凭坐标猜测合并。

折序联动预览携带可选、仅展示的 `strokeSpan`。同一真实来源的跨纸面片段按显示后的实际弧长累计，再由遮挡拆成片段；非等距扯角按变形后的各三角片实际长度累计。共享三角缝不会重复计长；缺纸、切口及不能确认连续的材料重新起算。不同物理来源即使共线，也不合并。相位字段不进入持久工程注释或生成 CP 段。

## 导出与局部放大

| 输出 | 比例 |
|---|---|
| 折痕 SVG／位图／打印 | 默认按 96 DPI 对应的毫米单位；调用方可传明确输出比例 |
| 折序 SVG | 按导出的 1200 × 900 视口计算，与编辑相机无关 |
| PDF 步骤图 | 按最终排版尺寸，将 point 按 96/72 换算为 CSS 像素；无纸面模型的自由注释图同样包含 SVG 留白；导出期间固定读取一次共享开关 |
| PDF 封面／首页 CP | 按各自最终图框尺寸计算，使用本次导出固定的共享开关 |
| 局部放大框 | 按每个大圆的实际倍率重新生成源图，不能把主图中已经退化的细实线直接放大 |
| CP 前后对照框 | 两个大圆使用同一 CP 选区，各自按实际半径重新取样，保持独立圆样式 |

共享偏好键为 `zhezhi.adaptive-line-style.v1`，仅存版本和布尔开关。既有 `CreaseDisplay`、Oriedita 导入字段和工程格式保持。

创建圆框时的选区对话框沿用静态预览；确认后的实际主图、缩略图和导出按倍率重采样。已知真实来源的碎片延续相位，不保证每一小片都独立包含一个完整峰折点划周期。
