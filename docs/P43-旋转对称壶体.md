# Origamica 第 43 节：旋转对称壶体

当前工作区提供 `family: "radial-pot"`，对应笔记本的 `MakeRadialPotWedge` 与 `MakeRadialPot`。输入是依次排列的二维剖面 `[半径, 高度]`、扇区数 `m`、法兰不对称度 `ρ`、接缝半角 `δ`、赋型最小折角，以及 `PotBorder`。后端生成单张连续纸的二维折痕，逐扇区绕轴旋转、并点，输出同顶点编号的真实三维面。

原版定位：`tmp/Origamica-15.0-reference.nb` 第 261696–263030 行为 `MakeRadialPotWedge`，第 264189–264330 行为 `MakeRadialPot`；第 264342 行附近的 In[3480] 保存了剖面 `{{0,0},{1,1},{1,2},{1,3},{2,4}}`、`m=5`、`ρ=0`、`δ=3°`、赋型阈值 `10°` 的可视示例。笔记本保存的是图形，不是数值顶点表，因此数值回归锚点由源码方程计算，不能声称与 Wolfram 的数值输出逐项对照。

本实现直接转写原版楔形公式：剖面弧长 `rᵢ`、半宽 `wᵢ=tan(π/m−δ)xᵢ`，六列二维点 `a…f` 与三维点 `aa…ff`；非零接缝角时解 `|dᵢ−cᵢ|²=|ddᵢ−ccᵢ|²` 并取最小非负根。`PotPlanar` 保留原版平面外缘；`PotPolygon` 在每个楔形末端 c/d 之间加入原版正多边形角点；`PotCircular` 以原版 `RayCircleInt2D` 和 `PolygonalEllipseArc2D` 细分边界，默认 5° 内接圆弧，也支持最大分角、最少分段和外切圆弧。任何分支都必须通过逐面所有顶点对的二维/三维距离、三维共面、二维无交叉及单张纸流形边检查后才返回可采用候选。静态三维等距不代表平折、连续折叠路径或无自碰撞。

In[3480] 对应结果：`PotPlanar` 为 101 顶点、200 边、100 面，`PotPolygon` 为 106/205/100，默认 `PotCircular` 为 161/260/100；各分支的逐面最大距离误差约 `2×10⁻¹⁵`。后端专项测试覆盖向上/向下壶体、平底、`ρ=±1` 零接缝、三种边界、山谷符号、失败域和工程参数恢复。超过静态等距域的参数会被拒绝，不用圆化二维坐标冒充三维形态。

`PotCircular` 现在也支持 `ρ=±1` 的退化法兰：计算圆弧前跳过已焊成同一顶点的零长度边，其余圆弧仍按原版内接／外切方法生成并走完整几何门禁。以保存剖面、`δ=0` 为有界验收子域，两种 `ρ` 的内接结果均为 141 顶点／220 边／80 面，外切均为 161／240／80；Euler 示性数为 1，真实 3D 面内距离及共面误差均通过。浏览器实测 `ρ=+1`、外切、ε=.1 可采用、几何和静态等距通过，1000×720 页面／属性栏无纵向滚动；截图 `../output/playwright/radial-pot-circular-extreme-20260927.png`。原笔记本未保存这个极端输入的机器可读 Out，故只宣称依据源公式和独立门禁得到的子域，不宣称 Wolfram 逐点相同。

原版的 `PotFlatFlangeInset` 已作为 `ρ=±1` 时的“法兰分层 ε”显示参数接入，范围 `0–0.5`。它仅对三维**显示副本**中的 b/e 类顶点施加原式的平面缩放 `(1−ε)`，用于分开共面法兰；真实 `foldedForm3D`、二维折痕、等距及采用门禁始终使用未修饰坐标。显示副本不再是等距构形，界面明确标注“仅修饰三维显示”，重叠层序无法可靠确定时仍以线框显示。后端回归对 `ρ=−1/+1` 核对原始折痕与三维坐标完全不变，前端回归验证显示坐标不能通过真实等距门禁；1000×720 浏览器实测侧栏和页面无垂直滚动。工程来源参数可严格回读，不能把显示偏移混进已验证折叠结果。

原版的 `PotCircular` 可通过 `opts` 把 `ArcDirection=CW` 透传给 `PolygonalEllipseArc2D`，但当前**可采用的单张纸静态等距入口**只接受原版默认的 `CCW`。笔记本 In[315] 的 CW 公式在 `a₂>a₁` 时令 `a₂-=2π`。对 In[3480] 保存剖面、`m=5`、`ρ=0`、`δ=3°`，楔形 `a→b` 与 `e→f` 两段本来各约 14.71°、15.06°，CW 后分别约 345.29°、344.94°；这些同一外圈上的绕圈长弧相互重叠，不能直接拼成非自交的壶体纸张边界。专项回归按原公式强制生成 CW，在该剖面与 `ρ=-1/0/+1`、内接／外切 6 组代表性参数中全部被完整壶体的面拓扑或同一点对应不同三维位置门禁拒绝。`output/experiments/radial-pot-cw-audit.py` 可供独立实验，正式回归见 `backend/test_tessellation_radial_pot.py`。

追加来源核对：In[315]（约 17624–17750 行）将 `ArcDirection` 列为 `CCW|CW`，并规定 CW 在终角大于起角时减去 `2π`；第 43 节 `MakeRadialPotWedge` 的 `arcify`（约 262615–262705 行）确实把 `opts` 传给该函数，因此 CW 不是无效参数。但第 43 节约 261000–264500 行**没有保存的显式 `ArcDirection=CW` 调用或 CW 数值 `Out`**。对 In[3480] 而言，五个扇区在同一外圆上以 72° 相隔；单条 `a→b` 的 CW 路径长 345.29°，已超过扇区间距，其五个旋转副本必然共享圆周区间，无法作为单张无自交纸张的外边界。此结论只针对保存例及同样存在这种绕圈长弧的输入，不构成全部合法剖面中 CW 绝无安全子域的普遍定理。

补充参数域扫描见 `output/experiments/radial-pot-cw-domain-scan.py`：保持原版 CW 公式，枚举 `m=3/5/8`、末端剖面半径 `0/.1/.5/1/2/4`、`ρ=−1/0/+1`、`δ=0/1°`，共 108 组输入。36 组在弧线前因侧翼宽度为负而被拒；剩余 72 组进入 CW 构造后，45 组不满足面轮廓限制、26 组出现同一折痕点对应不同三维点、1 组不满足单张无孔纸面的 Euler 条件，静态等距与几何门禁通过数为 0。该扫描扩大了已知失败区域，**不是 CW 全域不可能性的证明**，也不把弧线前失败误记作 CW 自身失败。

现在工作区的“PotCircular CW 长弧 · 原版只读线图”经独立 `radial-pot-cw-reference` 查询展示 In[315] 的真实 CW 角度解支、内接／外切采样、五段边界及扇区旋转副本。查询沿用原可采用入口的剖面、角度、半径与规模检查，但保留 CW 方向，并在返回中逐字回读查询参数；前端核对参数、图元索引、弧线范围、来源行号及全部不可采用标记。In[3480] 保存剖面的默认 5° 内接 CW 重建得到 1816 个线图顶点、1915 条边、25 段源圆弧；首条 a→b 转角约 −345.289°，大于五扇区间隔 72°，旋转后的原圆弧角区间重叠。结果没有面、FOLD 或三维等距证书；笔记本也没有该 CW 调用的数值 Out，因此这些是**按源码重建**的线图计数，不是 Wolfram 数值逐点对照。后端专项和前端跨语言读回回归分别见 `backend/test_tessellation_radial_pot_cw_query.py`、`tests/app/radialPotCWReference.test.ts`。

真实浏览器在独立端口 8814、1000×720 视口验收：从“镶嵌设计 → 空间构造 → PotCircular CW 长弧”进入，独立查询返回 200，状态显示 1816 点／1915 边／25 弧，完整来源 SVG 实际绘制 1915 条线；弹窗内容区 958×648，无水平或垂直溢出，浏览器无 `pageerror`。关闭后原可采用候选仍为 5 单元／200 边。截图 `../output/playwright/p43-cw-readonly-20260928.png`，复核脚本 `../output/experiments/p43-cw-browser-audit.cjs`。

前后端的**工程参数**均明确拒绝 `arcDirection: "CW"`；显式 `"CCW"` 被规范化为默认值，非圆弧边界也不能携带方向选项。CW 仅通过独立只读查询进入上述线图。在找到一个通过二维无交叉、单张纸拓扑、共享顶点三维一致与逐面等距的子域之前，不能把原版 CW 线图称作可采用 FOLD 或真实壶体。第 43 节后续其他壶体家族不是本构造；`SingleGoreData` 在原版注释中也明确没有用于折痕生成。

In[3481]/In[3482] 的 21 点 Mosely Bud 剖面现作为同一径向壶体控件的两个保存输入。原 `MoselyBudCrossSectionPt` 复数椭圆积分在保存实数域化为稳定实积分，50 位原表达式锚点与独立实现的点列相符；两例各 393／792／400，静态逐面等距和工程读回通过。24 点新容量继续受 600 面预算限制；1000×720 双例的二维/三维、正背、采用和无滚动已实测。详细推导、验证和边界见 `P43-MoselyBud保存例-20260928.md`。

In[3483] 的五点上向法兰分层保存输入也已加入同一保存例下拉：`m=5,ρ=−1,ε=.1`，静态结果 81／160／80；真实等距坐标不受仅显示用的 ε 影响。与矩形壶体剩余保存例的逐项对照见 `P43-其余壶体保存输入-20260928.md`。
