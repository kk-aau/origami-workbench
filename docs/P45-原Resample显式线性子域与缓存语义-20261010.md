## 实际接口和材料输出边界

沿用 `POST /api/tessellation/curved-flatten-generic`，原参数后可增加：

```json
{"resample": true, "interpolationPoints": 8, "interpolationOrder": 1}
```

ip 为4–256整数，表示间隔数；显示纵向段数独立，不能用显示段数代替 ip。未提供选项及显式 `resample:false` 保持原连续数值行为。True 时缺少 ip/order、越预算、声明高阶、单独提供插值选项、关闭采样但提供自适应选项，以及在当前重塑入口声明该选项，都明确拒绝。

结果附 `resampling` 来源戳：四阶段、原选项名、ip+1 参数点、全部逐分量样本、1阶子域已实现标志、默认/自适应插值未复现标志。TypeScript 从原表达式独立双向恢复 ODE，再重做四阶段采样并核验实际几何、导数、EFG、来源戳及初值偏差。篡改样本、参数、导数或证书均不能回读通过。

分段线性导数可能在采样节点不连续；本工作台明确采用节点右侧导数、末端左侧导数，浮点网格坐标在舍入范围内按节点处理。该约定保证前后端一致，不宣称 Wolfram 不连续点导数的内部选择。闭原域外不外推。

原 `query`、`initial.point/tangent` 继续保存 ODE 的原始初值；重采样后的实际曲面可能在离格 ui 处偏离它们，来源戳和界面显示实际点/切向偏差。不会加 ui 采样点、移动 ui、重置种子或归一化插值标架来消除偏差。连续源系数的区间正则性仍可成立，但**采样曲面的纸带正则性、形式等距证书为未证**；度量残差使用真实插值导数。`source.interpolationReproduced` 和 `wolframOptionsReproduced` 保持 False，只有来源戳中的显式均匀1阶子域为 True。

这些是原数值曲面工具输出；本批没有把弦段网当精确直线折痕 CP，也没有新增采用或 FOLD 认证。真实下载为原源 JSON，含原式、坐标、完整域、原初值与选项。产品入口：镶嵌设计 → 空间构造 → 原式工具与参考示例 → 一般展开；新增原 Resample 模式和 InterpolationPoints 控件。
