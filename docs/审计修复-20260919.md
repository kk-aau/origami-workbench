# 2026-09-19 审计修复

本次处理审计报告中的 4 项问题，版本仍为 v0.9.2 开发版；没有生成安装版或免安装版。

## 修复内容

1. **桌面运行依赖完整性**：打包清单包含全部 `src/core/*.mjs` 共享运行模块，以及新增的桌面偏好存储模块。新增回归测试读取实际 electron-builder 清单，递归检查本地运行依赖，并在隔离目录中实际启动服务，防止再次出现前端构建通过但桌面服务缺少模块的情况。
2. **跨启动偏好设置**：主题、快捷键、角度、面板布局、网格和拾取等偏好通过受控 preload 接口写入 `userData/preferences.json`。端口变化不再改变设置存储位置。接口仅接受主窗口主框架的同源请求和应用偏好键；文件采用临时写入后替换，损坏文件不会被静默覆盖。网页版继续使用浏览器存储，升级时可迁移当前来源下的已有设置。旧随机端口中的历史设置不会自动扫描或合并。
3. **完整工程容量与往返**：客户端编辑校验、服务端保存和原生 JSON 导出共用 8 MiB（8,388,608 字节）的紧凑 UTF-8 JSON 上限，包括原生格式封装字段。小文件保留缩进；缩进后超限时自动输出紧凑 JSON。旧缩进备份最多读取 16 MiB，但其有效工程内容仍必须满足 8 MiB 上限。HTTP 额外保留 4 KiB 请求封装空间。超限编辑或覆盖保存会被拒绝，原数据保留。交换格式、模型快照与模型集合原有容量策略继续独立处理。
4. **服务端测试隔离**：每个用例独立启动服务，使用独立临时目录和随机端口。镶嵌测试自行创建要保护的工程，不再依赖其他测试。默认 `npm test` 串行执行工作台单元测试、桌面模块测试和服务端测试。
