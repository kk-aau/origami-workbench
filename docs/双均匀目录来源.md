# 双均匀和 Resch 目录的独立构造

## 参考与边界

用户提供的 Origamica 15.0 笔记本中，双均匀目录列出 20 种构型，ReschStarPatch 列出 5 种星形拼块。读取其标题、参数说明和顶点类型用于核对范围，没有复制或翻译笔记本实现，也没有执行 Wolfram 内核。

双均匀的有限边连接数据核对自 Marek Čtrnáct 编制的公开 [tes-catalog](https://github.com/zenorogue/tes-catalog/tree/master/files/tessellations/k-uniform/02/2)。记录仅包含正多边形边数、旋转周期和数学边配对；每条记录保留对应文件名。Doily 连接符号的含义参考 [HyperRogue 格式说明](https://github.com/zenorogue/hyperrogue/tree/master/tessellations/sample)。应用程序不执行 TES，也不依赖这些外部程序。

`scripts/build-two-uniform-catalog.py` 是开发时的数据整理工具；`backend/tessellation_uniform.py` 是本项目独立编写的几何开发与周期恢复实现。等长边刚性对接生成正多边形面；返回种子拼块同一装饰方向的路径给出平移。最短平移与最小面积的独立平移组成周期基，半开基本区域保留每个平移轨道的一份拼块，并校验面积闭合。

本项目编号按原版顶点类型分组排列。相同顶点类型的两个排列以 A/B 区分；未执行原版，因此不宣称 A/B 与原版同组两个编号的顺序或坐标朝向逐字相同。原版若干标题缺少一个 `3` 等排版错误，以内角和为 360° 的实际顶点类型列示。

## Resch 的五种母结构

1. 从 3.6.3.6 将六边形变成三尖星。
2. 从 3.3.6.6 / 3.6.3.6 将六边形变成三尖星。
3. 六边形格三着色，保留一类六边形，另外两类变成三尖星。
4. 从 4.8.8 将八边形变成四尖星。
5. 从 3.12.12 将十二边形变成六尖星。

独立实现先对星形角的奇偶作图约束，使每个内点恰有一个星尖角和一个凹角；不满足平移周期时扩大基本拼块。由单位边长、指定星尖角和角度闭合逐面展开，重新求出随星尖角变化的两个周期向量。母结构再分成凸面供现有扭转构造使用。

原版这一节的公开入口是名称、拼块和周期向量，并以 Resch 的空间结构说明背景；该节并未提供独立三维运动求解函数。本次实现对应这些拼块接口及工作区扭转折痕，不能把扭转折痕称为 Resch 专门空间折叠运动。

## 验证记录

- 双均匀 20 种：边长恒为 1；内点环绕的正多边形类型与目录一致；基本拼块 3×3 周期连接无孔洞、无交叉；工作区两档规模均通过几何和局部折叠必要条件。
- Resch 5 种：星尖角 10°、25°、40°、55° 下边长恒为 1；每个内点恰有一个尖角和一个凹角；周期重复无孔洞、无交叉；25°、40°、55° 生成的扭转折痕通过几何和局部条件。
- 25 个目录默认输入经实际前端平折几何引擎验证闭合，工程参数往返通过。这不是每个输入都存在层序解的证明。
- 实际浏览器 77 项检查通过：25 个入口可采用、返回周期向量、1000×720 无工具栏滚动，Resch 调角与工程恢复。
