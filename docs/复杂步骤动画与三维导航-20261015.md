# 复杂步骤动画与三维导航

2026-10-15。本次在[步骤动画参与范围与颜色修复](折序步骤动画修复-20261015.md)的刚性材料运动基础上，加入非线性联动、先后折叠规划、连续碰撞检查和初态层序检查；三维视图增加方向方块，并按显示精度选择微小层间距。

同日后续修复见[步骤动画纸层颜色与双倍间距](步骤动画纸层颜色与双倍间距-20261015.md)：补充起态／中途的可信可见纸层与真实接触时间线，并将显示间距的精度下限和运行时上限增至两倍。下文保留本次原始实现与当时验证记录。

## 用户操作与结果

| 操作或情况 | 行为 |
|---|---|
| 折序绘图中打开“步骤动画” | 在后台检查本步材料机构、初态层序及运动路径，检查通过后提供播放；关闭预览会终止对应计算任务 |
| 多条折痕需要联动 | 对支持的机构求不同折角之间的关系；保持纸面刚性、固定侧和旧折角，不再把所有折痕强行同步线性折叠 |
| 多个纸瓣同步折叠会相撞 | 尝试有界的先后折叠顺序；调整各纸瓣的时间安排，保持最终 CP 和指定山谷方向 |
| 预折后展开 | 到达指定预折角后沿合法路径返回；保留本步“折下再展开”的动作语义 |
| 活动纸瓣起初压在其他纸层上 | 按重新求得的初态层序检查首次离层方向；拒绝从错误一侧穿出零间距纸层 |
| 未找到路径、发生碰撞或证明不足 | 显示具体中文原因，不启动未经确认的动画；可调整作用纸层、固定侧或拆分步骤 |
| 点击方向方块的面 | 切换正面、背面、左、右、上、下视角；“立体”按钮恢复默认立体视角 |
| 在方向方块或主三维画布上拖动 | 连续旋转视角，水平角和俯仰角均不设旋转圈数限制；滚轮缩放仍可使用 |

## 运动路径与实现边界

| 部分 | 实现与边界 |
|---|---|
| 真实材料机构 | 保留操作前／后的公共材料网格；把恒角折痕连接的纸面合并为刚性区域，仅本步活动铰链可以转动 |
| 固定区域 | 固定侧保持起态；所有共享材料顶点、固定点、材料边长和实际二面角都接受检查，不通过拉伸、平均接缝或带动其他纸面隐藏闭环误差 |
| 非线性联动 | 在改变的折角中求中间闭合构形，拟合并验证半角正切关系 `tan(ρᵢ/2)=kᵢ·tan(s/2)`；展开方向使用相应倒数关系。各铰链仍遵守本步指定的山谷方向 |
| 支持的复杂机构 | 支持通过刚性检查的半角正切联动族，包括实际四折线顶点及其预折回程；并非任意闭环机构的通用折叠规划器 |
| 先后折叠搜索 | 默认最多检查 48 个候选，接口上限 96 个；尝试同步、可用的联动关系及有界先后排列，不穷举任意复杂折叠动作 |
| 任意进度 | 从不可变起态和解析折角路径重新求值，并复验刚性闭合；乱序拖动进度、重播不会积累变形误差 |
| 数据边界 | 动画路径仅为临时播放数据，不加入折序工程保存格式；跨 iframe 接收的数据检查分段数量、有限折角、端点、连续性、预折中点及恒角约束，不相信外部传入的成功标记 |
| 输入范围 | 保留现有 1,200 顶点／2,400 三角片的 CPU 预览上限及原有材料、等距姿态校验；未赋型、未知角度、切口、孔洞等原有限制不会因新增规划器自动解除 |
| 后台生命周期 | 路径规划运行在独立 Worker；关闭预览会取消任务，预算耗尽或超时给出中文原因，不把未完成计算当作可播放结果 |

真实四折线样例的扇区角为 60°／90°／120°／90°。其中一条合法分支的中间折角约为 `90°、−150°、−90°、−150°`，四条折痕并非同时变为 90°。另一真实样例由固定方形和两个相邻纸瓣组成：同步折叠会相互穿透，先折完一片再折另一片可以保持同一最终 CP 并通过连续检查。

## 连续碰撞与初态纸层顺序

| 检查 | 依据 |
|---|---|
| 实际相交 | 对真实材料三角片检查穿透，报告三角片及原 CP 纸面；共享一个顶点不意味着整对纸面都可跳过 |
| 全时间区间 | 使用逐材料顶点的保守运动界、区间投影和分离平面检查整个区间。少数时间点没有相撞不能替代连续证明 |
| 联动相关性 | 半角正切路径使用共同参数的有理多项式和 Bernstein 区间界，保留多个折角的相关性，处理近平折端点的零间距接触 |
| 内部贴合再分开 | 检查接触前后有向侧别；拒绝纸层通过中间的完全共面状态交换两侧。严格沿同一路径返回的预折回程允许通过 |
| 初态重叠 | 只检查不同刚性区域之间的真实正面积重叠；取重叠多边形中心及内缩顶点，以重心坐标保持原材料点身份 |
| 初态离层方向 | 按可信 FOLD `faceOrders` 的原始方向，以第二纸面的当前材料法线检查首次非零法向分离；解析首项不确定则拒绝确认，不用有限时间采样猜测 |
| 层序来源 | 对公共索引的初态几何重新分析层序；不能拿操作后的层序替代起态，也不能按纸面编号猜上下 |
| 无需独立离层的情况 | 初态没有真实面积重叠，或重叠纸层属于同一个恒角刚性区域时，不凭空增加离层关系 |
| 结果语义 | `clear` 才接受路径；`collision` 拒绝已发现的冲突；`inconclusive` 表示层序、接触证明或计算预算不足，同样不能宣称无碰撞 |

这部分检查约束零厚度材料的运动方向和连续分离。它没有引入厚纸的质量、摩擦、弯曲、受力平衡或接触力积分。

## 方向导航与微层间距

| 部分 | 处理 |
|---|---|
| 方向方块 | 直接采用模型相机的同一旋转基底，包含现有坐标反射；可见面和标签随当前视角同步变化 |
| 连续旋转 | 保留未截断的水平角与俯仰角，允许跨过上下极点、连续多圈旋转；方块拖动与画布拖动更新同一相机状态 |
| 最小实用间距 | 结合当前相机距离、深度范围、实际深度位数、纸面相对视角和 Float32 坐标精度，选取能够区分纸层的显示间距；计算留出深度量化与坐标 ULP 的余量 |
| 间距上限 | 当前显示选择上限为模型半径的 `2e-5`。接近侧视或低位深时，上限可能使深度排序仍无法完全分辨；不会为了消除所有误差把纸画成明显厚片 |
| 纸层跨度 | 全局可排序区域中，铰链两侧显示间距为 `abs(rankA-rankB)×基础间距`。若中间夹着 N 层纸，跨度对应 N+1 个基础间距 |
| 局部层序循环 | 继续按真实重叠区域处理，不给无法全局排序的区域编造统一排名或铰链厚度跨度 |
| 启用位置 | 可信层序、100% 目标、近平且暂稳的终态按原有渐入机制应用；中途立体动作不强行压平。线框和透视显示保留各自语义 |
| 数据隔离 | 微层间距只调整显示网格，方向方块只调整相机；二者均不改求解器顶点、材料边长、折角、CP、工程草稿或导出的实际材料网格 |
| 旋转性能 | 每个稳定材料姿态只求解一次重叠布局；保留 Float64 零间距基点及 `rank×normal`，调整视角时线性重算显示位移并共享拓扑。极薄碎片无法保持 Float32 绕向时退回已验证的微间距上限布局，不重复求重叠排列 |

微层间距是为浮点坐标和深度缓冲提供的显示分离量，不是纸张真实厚度，也不是厚纸折叠动力学。纸层顺序负责上下关系，显示间距负责在渲染精度下表达该关系；运动路径是否安全仍由前述刚性、初态层序和连续检查负责。
