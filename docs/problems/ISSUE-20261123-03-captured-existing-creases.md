|---|---|
| 触发 | 用户导出含模拟器捕获过程图的教程，指出已有折痕全变黑色粗线；截图与 gentleman-body-1122 的 10-1 过程图相符 |
| 预期 | 已有展开折痕使用已有折痕样式，真正纸边/折叠轮廓保留边界样式；基本信息分类设置作用于过程图 |
| 代码证据 | `frameArtworkFromSVG` 仅提取 points/color；`frameInkSVG` 将所有线统一画为 1.35 或边界设置换算值，丢失类别、独立线宽 |
| 真实工程证据 | 只读原工程，10-1 捕获图有 186 个黑线段、34 个蓝线段、32 个红线段，仅保存 kind/color/points；无模拟位置或线类别可逆映射，黑色内部线与黑色边界不可仅按颜色可靠区分 |
| 历史关联 | 与 [过程图线宽修复](ISSUE-20261123-01-branch-numbers-process-width.md) 为同一路径的新分类问题；原修复解决整体固定线宽，未解决语义丢失。与 [模型边界宽度](ISSUE-20261122-10-model-boundary-width.md) 共享样式设置但不是几何求解故障；热恢复未改变捕获的片段数据 |
| 方案 | 在真实三维边上区分当前动作、展开痕迹和折叠轮廓，将类别存入捕获矢量；画布与导出按类别读取全局颜色/线宽/线型，缓存区分样式。旧无类别片段保留原显示，不能凭黑色猜测、误淡化真正轮廓 |
| 输入边界 | 原工程不修改；旧捕获图无法从当前保存信息无损补回类别，需要从动画重新捕获。新捕获图分类与样式链路已修复 |
| 修改入口 | `svgRenderer.ts`、`diagramFrameArtwork.ts`、`diagramImages.ts`、`diagramDrawing.ts`、`DiagramImageLayer.tsx`、`DiagramDrawingCanvas.tsx` |
| 本机证据 | `.runtime/process-crease1123/`，改前 SHA、测试及渲染证据；不收录完整私人工程 |
| 验证/交付 | 39 项专项及关联测试、类型检查、生产构建通过；真实 Edge 中验证 SVG 捕获→DOM 提取→JSON 重开→分类重画。未打包，未完整操作真实工程的动画重新捕获与原生 PDF 输出 |
