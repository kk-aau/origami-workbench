## 因果链与解决方法

基本信息已经正确保存并向 PDF 传递 `lineDefaults`。普通手绘边界注释会解析它，但模型面的描边、遮挡区域边界、侧立轮廓和最上层边界补画仅继承颜色，宽度分别固定为 0.8、1.2 或 1.35。成品图同样调用模型绘制，所以取消下一步折线、修改 PDF 排版或清空预览缓存不能解决此问题。

新增统一的模型边界线宽换算：保留原默认显示尺度，只有边界类别明确启用 width 时按 `设置值 / 0.7` 调整原笔宽，不再忽略设置，也不新增下限将 0.4 抬回默认值。外轮廓与折叠／遮挡形成的可见内部边界一起生效。峰谷动作线、已有折痕和单线覆盖继续沿用各自类别；不改材料 CP、折角、姿态、纸层顺序、遮挡证书、边界偏移或虚线自适应。
