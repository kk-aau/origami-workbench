## 前因后果与历史对比

原来的全分支入口无论阅读模式都调用 `layoutDiagramPDFBranchTree`，按分支布局而非完整链路顺序分配格子。本次将顺序阅读引到独立规划器，蛇形仍使用原邻格搜索；文字引导依赖最终节点到物理页映射，再参与图文空间计算。视觉验证发现通用装饰层还会生成旧边缘标签，因此同时限制其仅用于蛇形。

检索范围：问题索引、05／06 彩带及分支布局记录、20261121-01 预览记录、对应布局／分支／预览测试，以及 `diagramPDFLayout`、`diagramPDFBranchPanels`、`diagramPDFDecoration` 调用链。

| 历史问题 | 关联与保护 | 验证结果 |
|---|---|---|
| [06 固定格点分支搜索](ISSUE-20261122-06-grid-tree-pagination.md) | 共用图解树，阅读模式不同。本次顺序模式允许明确提示后的非相邻页跳转；蛇形仍要求开放分支接入紧邻下一页、页内正交邻格及分层回溯，不能将两套规则混用 | 原布局、密度和分支测试通过；没有修改其搜索算法 |

## 解决方法和保护边界

| 项目 | 方法 |
|---|---|
| 长度排序 | 对父子树计算每个叶子的完整步骤深度，稳定降序排序；不是按新后缀长度排序。根深度 6 的短后缀应先于根深度 4 的长后缀 |
| 不重复、不遗漏 | 每条链从终点沿父节点回溯，到已排节点即止；反转未排部分并追加 |
| 新行 | 一条链结束后对格位向上取整至下一行；满页则开新页；指定行列与页步数仍约束页面 |
| 引导可读性 | 步号／来源页／目的页使用最终分页；按格宽换行，提示高度参与折图高度和说明文字预算 |
| 原保护 | `scope` 为 route/current/range 的单链逻辑、蛇形搜索、已有手调位移、成品页机制保持原入口；不清除用户保存的样式与位置 |
| 适用范围 | 自动顺序阅读排版；用户之后手动移动格内图形会继续应用其保存位移，不擅自重置 |
