# 材料切口编辑与验收

本批始于2026-10-07，验收于2026-10-08完成；文件名中的1007/20261007为开始时批次标识。

完整镶嵌目标保持进行中。本批实现材料拓扑编辑的**切开内部折痕**操作，包含真实预览、取消、应用、撤销/重做、重新平折和工程往返；粘合、一般面细分/增删折痕及高偶度等余项继续保留。

使用：采用材料切口构造后，在折痕编辑的“纸张属性/选区”窗口选择“切开材料折痕”。可以在毫米刻度图上点击内边，也可按内边编号勾选；“预览切口”独立验证后显示部件变化，“应用材料切口”才写入工程。已有外边界/切口不能再次切开。

| 改动 | 实际行为 |
|---|---|
| 拓扑切开 | 通过已验证的 `faces_edges/edges_faces` 和材料边ID定位，沿未切开的共享边连接面角；选中铰接边分为两条单侧B边。不能根据重合坐标猜测材料身份。 |
| 端点与裂缝 | 完整切口分离面扇顶点；内部裂缝末端保留共同顶点和两条并行切口边。已有切口再切时保留独立角槽，不按端点合并切口两侧。 |
| 保持几何 | 原CP顶点和原FF位置逐值复制；新增独立顶点复制相应原值，无吸附、移动、重缩放或镜像。面编号、固定面、辅助对象、颜色和未改边ID保留。没有FF的位置输入不凭空生成各部件折后位置。 |
| 可信提交 | 声明操作在中央提交入口从当前文档独立重放，整份提案必须一致；旧预览、被篡改提案或无声明的合同替换原子拒绝，不进入普通坐标焊接路径。 |
| 模型与历史 | 更新文档使旧平折模型过期，需要重新计算层序；撤销/重做恢复完整拓扑、FF、ID和原根面。旧模型保留但明确标为过期。 |
| 可视化 | 图有实际毫米刻度，待切边为青色，列表显示两侧面与长度；1000/800×720窗口完整显示操作区，无窗口滚动。长材料内边列表单独滚动。预览选项变化会撤销旧预览的应用资格。 |
