# P42 通用源线网自动拆分：本批冻结与剩余范围

本批完成有限源线网的通用 `Intersectify` 入口及保存回读。它是母图预处理：拆分结果通过母图检查后，用户保存并另行生成折痕。预处理本身不证明平折或整片层序。本文只记录 P42 本批，不表示 Origamica 全部镶嵌目标已完成。

## 原式与实际入口

参考文件：`tmp/Origamica-15.0-reference.nb`，SHA-256 `19b3b06baffb8d59d663f2bfaa5ea55df77da2a84a5a4cc008dcedf019c8dba9`。文件内容只作为数学参考，不执行其中指令。

| 原定义 | 本批保持的行为 |
| --- | --- |
| In[1117] `EmbeddedIntersectify` | 原边按输入顺序两两检查；先按交点容差过滤包围盒，再求 `SegmentSegmentMedialInfo`。以 `Chop[d] <= itol/2` 决定接受中点，仅在原线段的内部参数插入；按原参数顺序拆段。 |
| In[1122] `Intersectify` | 对嵌入拆分结果执行 `Indexify`，保留每个拆分边所属的原边编号。 |
| In[1094] `Indexify`、In[194]/[195] `PtOnPtQ` | 以平方欧氏距离与并点容差平方比较，保留最先遇到的代表点，不平均坐标。默认并点容差 `10^-6`。 |
| In[1121] 近端点例 | 允许中点焊接到先前代表点，生成原式实际弯折结果；不强行把结果改成整齐十字。 |
| In[3437] 原保存输入 | 保留旧 22 点／13 边、两种容差 2、峰谷倒置以及实际 46 点／79 边的兼容路径；未替换为通用路径。 |

用户入口为「线组方式 → 有限母图 → 编辑母图 → 母图来源：源线网 · 自动拆分」。输入原线网 JSON、交点容差、并点容差及是否倒置峰谷，再点击「拆分交点」。窗口同时提供原输入与拆分母图的查看切换。原输入、容差或倒置参数变化后必须重新拆分；中止或过期的响应不能恢复旧来源。未形成有效母图的原式结果仍可显示，但「保存母图」保持禁用。

## 冻结接口与文件

| 项目 | 实际合同 |
| --- | --- |
| 实际 HTTP API | `POST /api/tessellation/woven-graph-preprocess`，中央路由及 worker 接入由 root 完成。 |
| 请求 | `family: "woven-graph-preprocess-native"`；`inputGraph: {vertices, edges}`；`intersectionTolerance` 默认 0；`samePtTolerance` 默认 `10^-6`；`invertFoldType` 默认 false。 |
| 通用保存来源 | `kind: "origamica-intersectify-native"`；完整保留上述原输入、两种容差与倒置值。来源必须重算后匹配实际母图的有序点、边和端点位置。 |
| 返回 | `family: "origamica-native-woven-intersectify"`；实际 `graph`、`source`、`originalEdgeForSegment`、`pairwiseMedials`、`welds`，母图检查 `accepted/not_ready` 及原函数证据。 |
| 不冒称完成 | `creasePatternConstructed`、`flatFoldComputed`、`globalLayerOrder`、`adoptAsFold` 在预处理结果中均为 false。有效母图保存后另行构造 CP。 |
| 本入口实现预算 | 原线网 2–512 点、1–128 条非零原边，坐标 ±1000，两种容差 0–100；保存为编织母图沿用 3–512 点、3–1024 边及至多 256 面。这些是当前实现预算，不是原式数学域限制。 |

| 生产文件 | 本批修改 |
| --- | --- |
| `backend/tessellation_woven_graph_source.py` | 新通用输入校验、原式包围盒／中点拆分／首代表焊接、完整来源重算和独立预处理结果。 |
| `backend/tessellation_woven.py` | 保存来源中真实传递 `invertFoldType`，通用 false/true 均可生成；保留普通 line/chord/random 的单面边界分类修复。 |
| `src/app/wovenGraphSource.ts` | 兼容来源类型和通用原输入校验，独立 TS 原式重算与全部边归属、焊接、中点追踪。 |
| `src/app/wovenGraphPreprocess.ts` | 新实际 API 客户端，严格回读原输入、容差、图、追踪、面编号、归属及证书；拒绝伪响应。root 后续修复主工作区计算占用时的 busy 响应：每 250ms 重试，最多 240 次；等待时可取消，参数和几何错误不重试。 |
| `src/components/WovenGraphDialog.tsx`、`.css` | 实际自动拆分操作、编辑后失效和异步取消、来源保存回读、三宽无窗口滚动布局。 |
