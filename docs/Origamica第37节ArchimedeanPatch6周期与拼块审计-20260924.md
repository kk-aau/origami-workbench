# Origamica 第 37 节：ArchimedeanPatch[6] 非方格周期拼块审计

原版 `tmp/Origamica-15.0-reference.nb` 的 `ArchimedeanPatch[6]` 是顶点构型 **3.3.3.4.4** 的三片 `{三角形、三角形、正方形}` 基本拼块。保存 In[3124–3126] 规定了两次接边、以具名顶点取两条格矢，并用 `{0,1}×{0,1}` 复制成 2×2 晶格；In[3182] 另用同一三片拼块绘制居中 Alt 扭转。该段没有保存可机比的数值 `Out`、点表、CP 或 FF 坐标；以下严格对照源码公式、来源面序、周期平移和本项目拓扑，**不把原版图形目测当逐点证据**。

`PatchVector` In[3092]（231116–231142 行）从 `EmbedTiling[patch,TileVertices]` 的 1-based `{片,顶点}` 引用相减，`PatchVectors` In[3094]（231259–231295 行）共用起点给两条向量。`MakeLatticeTiling` In[3096]（231485–231519 行）先 `RegularizePatch`，对每片的位移加 `j1·l1+j2·l2`；`Table` 的外层是 `j2`、内层是 `j1`，两个整数范围均含端点，再以 `Flatten[...,2]` 保持片序。本项目对应 `backend/tessellation_lattice_patch.py` 的 `patch_vectors`、`make_lattice_tiling` 和接入 `family=custom` 的通用格点管线。

原版 In[3124]（232600–232635 行）依次把第二个单位正三角形按 `{1,2,1}` 接到第一片、把单位正方形按 `{2,2,2}` 接到第二片。由 `UnitRegularPolygonVertex` In[433] 的首点原点和首边单位水平线，逐次反向重合接边后，来源面顶点为：

| 原片序 | 顶点（逆时针，保留原片起点） |
| --- | --- |
| 1：三角形 | `(0,0),(1,0),(1/2,√3/2)` |
| 2：三角形 | `(1,0),(3/2,√3/2),(1/2,√3/2)` |
| 3：正方形 | `(1/2,√3/2),(3/2,√3/2),(3/2,1+√3/2),(1/2,1+√3/2)` |

In[3125]（232637–232663 行）指定 `PatchVectors[patch,{1,1},{1,2},{3,4}]`，故 **`l1=(1,0)`，`l2=(1/2,1+√3/2)`**。行列式 `1+√3/2` 等于三片面积 `√3/4+√3/4+1`；两个向量不正交，和方格测试不同。源码保存的 In[3126] 用两个 `[0,1]` 闭区间生成 4 个格点、每格 3 片。通用 `generate(family=custom,customOutput=tiling)` 独立复跑得到 12 面、15 顶点、26 边，母结构几何检查通过，源片号为 `[0,1,2]` 重复四次；格点与片序依次为 `(0,0;0,1,2)、(1,0;0,1,2)、(0,1;0,1,2)、(1,1;0,1,2)`，正与原 `j2→j1→片` 嵌套顺序一致。每片顶点等于上述来源顶点加 `j1·l1+j2·l2`，且无 T 接缝补点。

原版保存例未用负格点。将**同一源码公式**延伸到 `j1∈[-1,0]`、`j2∈[-1,1]` 后，本项目通用生成链路得到 18 面、21 顶点、38 边；第一片首点 `(-3/2,-1-√3/2)`，来源片号仍按 `[0,1,2]` 重复，格点仍按 `j2` 外层、`j1` 内层递增。这是对负索引实现的公式回归，不声称原版有对应保存 Out。

`PatchCheckTypes` In[3174]（234217–234275 行）只检外层片数和每片类型列表长度；`PatchCheckParity` In[3177]（234362–234389 行）只检奇偶列表长度。原版 In[3182]（234662–234720 行）为同一 n=6 三片给 `w=.2`、`α=25°`、`types={{M,M,M},{V,V,V},{M,M,M,M}}`，未给 parity。当前受限后端在长度之外还要求类型为 M/V、偏置方向为 ±1，以免把任意符号或数值送进已验证的 CP 子域；这是比原版两项**纯长度检查更窄**的输入域。测试核对所保存的类型长度与片序，以及错误长度的拒绝；±1 奇偶核对只说明当前偏置适配域，**不是 n=6 原版保存的奇偶输入**。

In[3181] 的居中 Alt 公式使 `τ=atan(tan25°/.2)≈66.785439879°`。本项目对原版三片 In[3182] 输入生成的单个 twist patch 为 32 顶点、48 边、17 面，几何和局部山谷条件通过；逐面反射的 FF 闭合误差约 `1.46×10^-9`，每面顶点对距离保持。这些均为本项目数值，原版只保存了 `CreasePattern/Tiling` 绘图输入，不能逐点比对，也未保存整片层序。**2×2 验证针对纯平铺，Alt 扭转验证针对三片 patch；不据此认定重复 Alt 扭转可全局平折。**

对这一**单个** In[3182] Alt 拼块，`scripts/verify-archimedean-patch6-alt-in3182.ts` 另执行完整工作区流程。脚本一侧从原版两次接边公式独立重建三片来源面，直接调用逐片扭转构造器；另一侧把解析所得顶点、面与 `w=.2、α=25°、M3/V3/M4` 交给 `readTessParams → tessellate.py` 通用请求入口。两侧所得 CP 的 32 个顶点坐标逐项相同（最大误差 0），48 条边及 M/V/B 赋型、折角、17 个面和来源片号逐项相同。这是**本项目具名入口与通用入口的 CP 身份比对**；原版没有保存数值 CP `Out`，所以不是原版逐点身份声明。

同一 CP 经 `tessFlatInput → computeFlatGeometry → recomputeFlatLayers` 得到 `flatGeometry=ready`、`layerOrder=solved`、**精确 1 解**。展开和折后图的第 2 面（从 0 起）均为实际凹面；内部求解仅给原面建立上下变量，返回 64 条原面关系，正背面各 520 个局部覆盖区域全部有序。原版没有保存可机比的数值 CP 或全局层序输出，因此这里只证明**本项目重建的单个三片 patch** 在零厚度层序模型下有解；不外推至 In[3126] 的 2×2 纯平铺或重复 Alt 扭转，也不证明连续无碰撞折叠路径。

此前的 `unsupported` 源于 Rabbit Ear 默认 earcut 在第 8 原面（从 0 起）切出面积约 `6.73×10^-8` 的近共线三角片，其相对高度约 `2.96×10^-9`，随后数值清理会删掉这片。现只在默认切法会丢片时，对同一简单凸原面试验保留全部原边顶点的扇形切法；择优锚点的最小三角面积约 `115.23`（工作区坐标）。候选仍须通过原边、边两侧来源、面积、绕向、三角片非退化、共线清理、人工对角线 `J/0°` 等原有全部门禁，不能删除片段或让子三角形独立排序。四种原面起点与 `ε=10^-6、10^-7、10^-8` 的 12 次完整求解给出同一原面关系；另一套凸面首点扇形与研究版独立 SAT 编码也得到同一唯一解，并能升回 Rabbit Ear 全部三角片约束。

专项回归位于 `backend/test_tessellation_archimedean_patch6_lattice.py`。从 `workbench/backend` 运行：

```text
..\.venv\Scripts\python.exe -m unittest test_tessellation_archimedean_patch6_lattice -v
```

四项测试通过，覆盖原版接边几何、格矢和面积、保存 2×2 的完整通用生成、负格点公式与来源面序，以及保存 Alt 类型的受限 CP／逐面等距。此次未发现来源片序、周期向量或负格点实现差异，未修改共享前端或格点核心。
