# 双变量曲面与公开曲线系统

用户在 v0.13.1 暂停打包后明确要求恢复原完整镶嵌构造目标。本批补齐公开数值查询及主应用入口，历史安装包保持原快照；全部原版功能仍未完成。

| 入口 | 可用输入与结果 | 保留的区别 |
|---|---|---|
| 双变量曲面 · 基本形式与曲率 | 三个安全双变量表达式，独立 u/v 域和密度；切向、法向、两种基本形式、曲率矩阵、可选主曲率及方向，另显示混合导数 | 正交空间中的主方向与原 UV 参数方向分别输出；重根方向不声称唯一或连续 |
| 双变量曲面 · 正反法向 | 相同曲面来源与独立 ±1 朝向；原三维曲面及局部法向 | 正反切换只反转法向，不改变曲面；不附加曲率规则 |
| 曲线与恢复系统 · 七类原式 | Curve2D、Curve3D、Darboux3D、RuledSurfaceNormal，以及 RecoverCurve2D、RecoverCurve3D、RecoverDarboux3D | 源向量和恢复初帧保留原始长度；不通过强行归一化改变原式 |

两个曲面模式共享源 JSON 存取、规则导出、实时请求取消与最新结果保护。曲线系统使用自己的七模式源合同。实际计算调用本机服务，TypeScript 端独立回读源导数与结果，不仅检查 HTTP 成功。

## 原式与有限数值范围

曲面分别对照 In[3777]、In[3746]/[3750]；公共曲线系统对照各原系统及恢复函数。合法输入限定于安全表达式语法和有限数值域，不运行任意 Mathematica 程序。

有限采样结果、完整矩形源正则证据和全局自交／折叠认证相互独立。完整域未能证明时保留真实图形并标为未证，不将采样成功冒充全域证明。通用曲面和诊断系统没有据此生成 CP 或允许采用 FOLD。

RecoverDarboux3D 原四个系数为 ds、sdκg、sdκn、sdτg；只有曲线位置导数再次乘 ds，后三个已是参数导数系数。所有恢复系统保留用户原初帧，初帧相容与字面数值输出分别呈现。

双变量曲面完成四类数值修复后，通过 Python 15 项、TypeScript 14 项、实际服务专项，以及最终构建的 22 个真实主应用场景。23 份系统和 46 份正反法向来源通过独立回读。实际界面覆盖常量零根式、极小尺度、极小非零曲率、近乎平行参数、三宽布局、JSON 下载重开和异步竞态。最终报告为 `output/playwright/p45-final-surface-report-20261001.json` 与 `p45-final-surface-races-report-20261001.json`。

根式与逆数避免生成会溢出的中间导数系数；相减消去和病态参数使用局部数值补偿，原 UV 形算子独立于正交空间矩阵核验。次正规数转换也作回归。真实主应用联测另修正了中文“已有镶嵌计算正在进行”未被重试器识别的问题；两种曲面入口现在等待空闲，可取消，几何错误不重试。

五种 289 点查询的单次本机后端测量为约 0.035–0.207 秒，见 `output/audits/p45-surface-numeric-performance-20261001.json`。这是单次计算测量，不是端到端帧率或跨设备性能保证。

原版 Wolfram 符号对象、插值对象、求解选项与精度语义，以及数值 ODE 完整误差包围仍未等价。后续已修复 `sqrt(u-u)`、`sqrt(2*u-u-u)` 等两端证明差异：有预算的精确有理正规形覆盖同子树消去、常见三角关系和指数乘积，同时保留消去前的分母、根式、log、tan 定义域检查。没有按采样导数为零推断恒等式。高级和角／双角恒等式仍不计完整 CAS 复刻；详见后续冻结记录。本文件不把公开数值入口完成解释为整个 Origamica 已复现。
