# 材料参考面参数重放（2026-10-10）

入口：**折痕编辑 → 纸张属性/选区 → 材料参考面**。点击展开纸面或选择面编号，预览后采用；参考面选择与恢复默认均可保存参数。原“起始面”和“恢复默认起始面”按钮也接入，连续切换更新末尾参考面组。源码已更新，免安装包尚未更新，完整 Origamica 目标保持 active。

| 操作 | 效果 |
| --- | --- |
| 选择参考面 | 原 `setStartingFace` 设置查看基准；保原CP、材料ID、拓扑、存储的FF坐标及其参考面，不把活动面写成未换基的FF参考。 |
| 恢复默认 | 原 `clearStartingFace` 恢复存储材料的默认基准，保存明确的默认操作；参数重开可继续改为指定面。 |
| 连续重算 | 指定面保存来源边、材料侧及原面所属关系；前组交点/形状改变后解析实际后代面，后续构造按新基准重算，不按旧编号改别的纸片。 |
| 可视编辑 | CP中真实点击纸面；毫米刻度、放大缩小、拖动平移和适合材料。预览能查看原坐标转换后的FF，选中面紫色高亮。 |
| 保存与历史 | JSON/FOLD重开可编辑，取消不提交，预览后改输入必须重算，一次撤销/重做；可预览删除无依赖参考面组。 |
| 独立来源/孔/切口 | 粘贴片的参考面跟随独立源；源删除明确拒绝。孔环、弱切口及无FF材料保原结构；不制造折后坐标。 |
| 空状态 | 后续剪切全部材料后，仍能重开前面的参考面组；显示空结果，禁用FF。 |
| 旧模型与失效设置 | v13读取v1–v12，不降级。原轮廓失效时，以用户明确的新面/默认选择修复后建立基底，旧配方按原值归档，不覆盖当前几何；容量仍为8组，超额不丢弃旧工作。 |

原问题可在前批材料模型上复现：直接调用原 `setStartingFace` 改活动面后，构造模型的已采用快照与当前设置不同，`inspectMaterialCurveModel` 变为失效。现在选择本身进入重放流程；原设置函数和坐标基底算法保持，新增独立提交核对及来源绑定。
