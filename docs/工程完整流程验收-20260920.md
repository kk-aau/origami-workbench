验证损坏 JSON 不覆盖未保存修改，也不清空撤销历史；验证切换工程后从工程库重新打开、实际下载完整工程再通过文件输入重新导入，以及刷新后的恢复工作。上述完整文档比较均包含线段 ID、坐标、类型、折角和对象。

## 复用

脚本：`scripts/verify-project-workflow.browser.js`。先使用独立 `ZHEZHI_DATA_DIR` 启动服务，再通过 Playwright CLI 打开服务地址并运行：

```powershell
npx --offline --package @playwright/cli playwright-cli -s=workflow run-code --filename workbench/scripts/verify-project-workflow.browser.js
```

命令从项目根目录运行；脚本会保存测试工程，不能在用户日常服务上执行。

产物位于项目根目录：

- `output/workflow-unit.log`
- `output/workflow-browser.log`
- `output/playwright/workflow-roundtrip.zhezhi.json`
- `output/playwright/project-workflow-complete.png`

本轮只验证完整工程格式，不能据此推断 CP、FOLD 等交换格式无损，亦未覆盖三维模型文件或桌面安装包。
