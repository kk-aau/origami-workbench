# 折序步骤动画：第一版

2026-10-14。折序绘图上方新增“步骤动画”，按当前步骤的操作前／操作后 CP 生成独立三维预览。预览不改写 CP、步骤姿态、符号、工程草稿或历史记录。

2026-10-15更新：步骤预览现使用严格刚性铰链动作，固定整个恒角材料区域，并沿用当前主图配色；另修复CPU共面三角拼色。后续行为与验证见[步骤动画修复记录](折序步骤动画修复-20261015.md)，以下保留第一版实现说明。

| 用户操作 | 行为 |
|---|---|
| 选步骤 → 步骤动画 | 载入本步操作前的已折形态，暂停在0%；第二步不会先把纸张全部展开 |
| 播放／暂停 | 只推进当前步骤发生变化的折痕，旧折痕保持原角度 |
| 重播 | 恢复本步起态、固定侧和角度，再播放当前动作 |
| 拖动进度 | 设置本步目标角度，模拟器向该进度求解；时间轴到100%后继续等待数值稳定 |
| 预折后展开 | 根据本步保存的山谷方向执行“0° → ±180° → 0°”，已有折痕仍保持原状态 |
| 速度与观察 | 0.5×／1×／2×，正面／背面／立体视角，鼠标旋转和缩放 |
| 关闭／切工作区 | 取消播放定时器、后台层序任务和模拟桥接；Esc在画布内也可关闭 |

## 数据与求解

| 部分 | 实现 |
|---|---|
| 共同材料网格 | 对 before∪after 的 CP 路线进行公共细分，包含旧折痕、已删除但需要展开的铰链和本步新折痕 |
| 原始材料长度 | 使用未折 CP 准备模拟网格；操作前的已折坐标仅作为初始姿态，不能当作新的纸张休止形状 |
| 初始映射 | 逐操作前源面求等距变换，按材料坐标映射公共网格顶点；浮点模拟网格仍用原始双精度CP坐标查找材料身份 |
| 本步角度 | 所有模拟折痕都有完整 from／to，预折可含 via；几何覆盖匹配不依赖两份 CP 的线段ID或纸面编号 |
| 固定侧 | 优先用户选定的固定侧；固定本步新折痕分出的实际子面，避免把整个旧面两侧同时锁住。未指定时使用原起始面中的最大子面并提示 |
| 初态校验 | 源签名、索引、完整目标、边长、初始二面角和至少3个非共线固定点；拒绝后不部分写入求解器 |
| CPU种子 | `ReferenceSolver.setInitialPositions` 同步当前位置、位移历史、速度和折角历史，保持原材料 rest 数据 |
| 终态遮挡 | 后台重新求解本步最终公共网格的真实层序，仅在100%且近平暂稳后应用已有显示修正 |
| 渲染隔离 | 复用独立模拟 iframe；动画模式隐藏重复的模拟控制与内部状态框，普通三维工作区保持原控件与GPU路径 |

## 第一版范围

| 支持 | 范围 |
|---|---|
| 本步新增山谷折 | 未折0°至明确的山折−180°或谷折+180° |
| 保留旧折／展开旧折 | 旧±180°保持，或展开至0°；共同网格保留原材料铰链 |
| 预折 | 使用 `foldLink.precreases` 保存的真实方向，不从F/0°终态猜方向 |
| 扯角图示 | 存在有效存档时使用 `paperStates.flat`，不拿非等距扯角图作为物理起态 |
| 无动作／不支持 | 单纯符号或已有F痕变化不伪造运动；过旧姿态、非等距变形、未赋型或未知折角、非平折目标角、直接山谷反转、更换边界、材料切口或孔洞均给出中文原因 |
| 容量 | CPU预览上限1200顶点／2400三角片；两份CP合计最多4000材料线段 |

GPU后端目前不支持逐折痕角度范围，动画明确使用CPU。普通三维模拟继续优先GPU。本版是目标角驱动的数值预览，不证明复杂步骤存在无碰撞、刚性的连续路径；时间轴百分比也不是实际运动完成度的证明。复杂动作可能继续收敛或出现穿插，不把两张平面图的顶点直线插值冒充真实折叠。
