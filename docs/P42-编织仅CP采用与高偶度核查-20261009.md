# 编织仅 CP 采用与高偶度核查（2026-10-09）

完整 Origamica 复现目标继续。本批新增明确的“仅采用 CP →”，使已生成、独立验证的原生有限母图编织可进入材料编辑区，即使整片层序尚未认证。原有“采用折痕副本 →”门禁保持。十度及以上构造仍未完成，不以这项编辑入口替代它，也不把 CP 几何通过当作物理可平折。免安装 EXE 未更新，不打包、发布或操作设备。

入口：镶嵌设计 → 线组编织 → 有限母图 → 仅采用 CP →。新入口适用于能通过原式、材料拓扑和候选坐标独立核对的原生有限母图，不适用于只有数值网格的只读曲面诊断。

| 状态或操作 | 行为 |
| --- | --- |
| 整片层序未解或无解 | 可明确仅采用经过验证的 CP，继续修改山谷、折痕或材料构造。没有活动 FF 或层序证书，后续计算仍可能报告无解。 |
| 普通采用 | 原几何、局部和整片层序检查全部保持；新增入口不会让普通按钮跳过层序。 |
| 参数变化/正在计算 | 旧 CP 不能采用；新响应、当前参数签名和完整来源核对通过后才启用。 |
| 独立验证 | 重放原母图、内缩、位移、赋型、原 CP/FF 等距和固定面来源，再核对候选实际线段。伪造来源、坏状态、已修改坐标或过期结果拒绝。布尔标签不作为构造证据。 |
| 切口身份 | 原 B 内部切口沿用既有拆分模型，保留独立岸、原边角和部件编号；不按同坐标焊接或静默去重。 |
| 坐标与单位 | 从原 CP 使用既有 200/span 与 minX/minY 转换一次，保候选纸张设置；不额外镜像或翻转。普通 DXF 继续原毫米与负 Y 的 R12 LINE 格式。 |
| 保存与重开 | JSON/FOLD 保材料 CP、起始面和来源配方，没有活动折后帧。来源 FF 仅保留在原构造资料中，不安装为当前材料姿态。读取配方可再次由公共后台构造。 |
| 编辑与性能 | 是独立材料工程副本，原镶嵌参数不覆盖后续手工修改；可使用既有材料编辑入口。采用能力独立核对按结果/参数缓存，拖动草稿及忙时不重复执行。 |

## 高偶度新证据

本轮回到 In[3428] 的 `makeverts` / `addpleat`、负初值 CP 邻接、反射方程与原平方和优化，不修改源边或山谷来凑解。附件里的 Mathematica 内容只用作设计与公式资料，没有执行其中的命令。

| 核查 | 结论 |
| --- | --- |
| 实际面绕行去重 | 六、八及三种十度数据均未发现“同顶点集合、不同实际绕行”被合并的碰撞；本批排除这一假设，不修改生产去重逻辑。 |
| 各向异性 | 24 个新的十度长宽比/内缩/奇偶样例，未认证。 |
| 方形纸面与四边母面 | 20 个方形纸面五线交点样例未认证；前批次四边母面 20 个也未认证。首轮诊断误走只允许两线四度交点的 arrangement 入口，已改为显式母图，保留中断/预算未知记录。 |
| 聚角与非圆边界 | 60 个聚角/非圆边界/非均匀正初值情景未认证，多数没有进入反射求解。 |
| 实际位移归一化的负图 | 60 个诊断仍未认证；尺度修正尚未证明有效，不写入生产。 |
| 对称根分支 | 标量分支找到了六度校准 CP；十至十六度共 103 个近零残差根均未通过完整 CP 几何。零残差不能当成功。 |
| 二色独立位移 | 正负色及进/出边界分别设倍率；八度有一个几何/局部通过候选，实际材料层序为 `no-solution`，不记为可平折。十至十六度的 800 个初值仍未认证。 |
| 发布状态 | 十度以上公开门禁保持；这些失败不是数学无解证明，更不是功能已复现。 |

下一步需要同时处理 CP 的实际嵌入及正初值分支，取得完整几何与层序证据，不能仅增加同一类初值或取消度数限制。有关 JSON/日志随本批冻结，前批档案不覆盖。

完整目标仍缺：有效偶度 ≥10 构造；曲线/触碰/交叠母图孔环、单桥/弱简单拓扑；材料面内自由或悬空端点和复杂切口合并；任意材料操作栈持续重放及原版任意非平折编辑；剩余 Wolfram 输入/选项/插值与未证数值全域。

未验证：所有参数组合和最大规模性能、Wolfram 数值 Out 全域等价、连续曲线/刚性纸张折叠或碰撞、免安装 EXE 原生交互、外部刻字软件导入及实机试压/速度/精度。CP 副本可编辑不代表可物理平折，不承诺实机提速。
