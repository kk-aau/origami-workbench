# 嵌套独立母图纸片与验收（2026-10-08）

本批解决母图嵌套轮廓全部被拒绝、无法明确作为独立纸片构造的问题。完整 Origamica 复现目标继续；**多环母面没有在本批完成**，嵌套独立纸片不替代同一张纸的孔洞。免安装 EXE 未重新打包。

入口：镶嵌设计 → 线组编织 → 构造示例“嵌套独立纸片编织（本地母图）”；手工母图编辑中的“嵌套轮廓作为独立纸片”可明确开启或关闭。

| 原问题 | 本批实现 |
| --- | --- |
| 两个独立部件的轮廓相互包含时一律拒绝 | 新增明确的 `graph.nestedSheets:true`，仅用户选择后允许原有独立母图路径处理嵌套。省略仍拒绝，不自动猜测纸片或孔洞。false/null/数值/字符串/显式undefined均不能冒充声明。 |
| 内轮廓可能被误当成外纸片的孔洞 | 源图半边面全部保留，各部件使用自己的固定回展根，不增加跨部件线；真正挖孔仍使用显式 `holeFaces`。独立纸片自身可以带自己的孔洞。 |
| 来源和绘图需共同接受新语义 | 参数读取、母图文件包、编辑及原式回读同步检查该字段。移点/点边编辑保留声明；关闭声明即使点边未变也禁用旧CP/FF。草稿撤销/重做、取消及保存保持一致。只切换声明保留固定面、周期和逐边内缩绑定，点边/孔洞实际改变时仍清除失效绑定。 |
| 单独放开输入无法证明生成可用 | 公共生成器实测三组双纸片及一组内纸片带孔，逐面等距、严格回展、几何和统一材料层序都通过；采用后的JSON/FOLD和普通DXF实际下载回读。 |

这是现有数值 TGraph 独立材料输入域的扩展，并非新增 Wolfram 执行器或保存 Out 数值等价证明。“嵌套独立纸片”是多张材料的明确模型；它不把外纸片挖孔，也不把两张材料焊成一张。普通 DXF 仍按当前 CP 绘制全部线段，不能由文件推断用户打算如何摆放实际纸片。

最后一组遵守原版内部B切口语义，内纸片编织环带被拆成8个材料部件，另有外纸片，共9个；没有把原内部B改为折痕。它不能宣传为一张无切口环带或只有两个最终材料部件。外纸片的材料可能覆盖内纸片孔洞的位置，这是独立纸片语义，不是填补内纸片自己的孔洞。

四组实际母图包和原始来源JSON保留用户参数及点边编号。以**本次实际生成的来源**独立回读原式并重建采用材料，再逐值核对采用JSON/FOLD；独立运行求解可能产生约一个ulp的数值差，不能把另一轮求解当成本轮序列化应精确一致的对象，也未为此放宽实际文件核对。普通 R12 DXF与现有导出逐字一致，独立解析全部LINE、赋型图层、既有Y轴转换后的毫米端点及线段次数。实际JSON/FOLD重开可重新求层序；没有跨部件连接。证据 `output/audits/woven-nested-sheets-download-1008.json`。
