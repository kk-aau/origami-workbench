# 底图随画布／固定屏幕界面

右侧「参考底图」新增勾选项「底图随画布移动与缩放」。勾选对应原版lock=true；取消对应固定画布内的CSS像素位置。旁边明确显示当前语义。frontend-design用于保持紧凑面板和既有控件样式，没有引入新弹窗。

Canvas将当前视图x/y/units发布给App与BackgroundPanel；切换以当前相机换算，保持显示位置不跳变。固定模式在底图世界矩阵外增加相机补偿，不改原图数据或折痕。窗口尺寸/属性栏变化不改变画布内像素位置。重新勾选后，以切换时有效世界姿态继续跟随。

四点配准使用当前有效世界姿态，提交后按上游语义自动固定屏幕。固定模式下配准途中，前两个图片特征点随相机补偿更新，目标点仍留在世界坐标；支持中途平移/缩放后准确配准。图片隐藏/替换/工程变化仍取消未完成配准。新加载与「适合纸张」恢复随画布；切换、配准、适合纸张均走工程历史，可撤销/重做，完整工程保存viewport并恢复屏幕姿态。
