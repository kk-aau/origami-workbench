# 底图对照赋型（模式 30）

读本地 MouseHandlerCreaseAdvanceType 后实现 advanceCrease 和 advancetype 入口，当前81工具。此模式不是自动识图或新增折线，而是按住已有线临时隐藏、原位松开循环赋型，便于查看底图。名称与分步提示明确这一边界。使用 frontend-design 保持原有紧凑工具布局。

循环为未选 B→选中 B→未选 M→未选 V→未选 B；已选 M/V 不变。保护边界禁止操作，A/U/F明确拒绝，不穿透最近的不合格线；其它选区保留。M→V保留自定义角度幅值、零和null，V→B归零。B的第一次点击只改变选区，不新增作品历史。模式独立于新绘制预设。

按下仅隐藏SVG线段组，不删除工程线段，因此保存／恢复不会保存临时缺线状态；按住后发生鼠标位移即恢复并取消赋型（移回原位也不提交）。右击／Esc／切工具／工程变更走公共取消路径，迟到释放不修改。原位松开才提交，几何修改可一次撤销；仅作用于真实小段。悬停沿用紫色参考高亮，按住时去掉高亮露出底图。

验证：4新增单元，全量500通过；TypeScript/Vite构建通过。隔离8799浏览器：新模式20、原循环19、取消优先级17，共56断言通过。新模式测试包含内嵌真实PNG底图，截图output/playwright/advance-type-held.png已查看。浏览器脚本曾因“选择”按钮实际可访问名称含V、SVG水平线组零高度导致可见等待失败，分别改为真实按钮名和DOM附着/显隐属性断言后完整重跑通过。产品未为测试改变行为。

模式30目录标基础可用，完整上游运行对照、共线等距命中次序的精确对照仍待验收。没有增加自动图片识别承诺。背景锁定、裁剪、EXIF等其它全目标继续；未打包，正常8787和用户作品保持不动。
