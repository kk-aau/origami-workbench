# 单面细分、合并参数重放（2026-10-09）

后续更新：本档记录的“前组改镜像后插面拒绝”已在[镜像参数与逻辑原面续接](P42-镜像参数与逻辑原面续接-20261009.md)修复。下文保留本批的原验收及历史限制。

入口：**折痕编辑 → 纸张属性/选区 → 编辑材料折痕**。添加折痕/细分面、删除折痕/合并面现在默认保存参数组；采用后在“参数构造组”重新打开对应操作。源码运行版更新，免安装包尚未更新；完整 Origamica 目标仍在进行。

| 操作 | 效果 |
| --- | --- |
| 添加折痕/细分面 | 保存两端的来源边和比例、材料侧、赋型、固定侧及仅CP设置；修改前组后重算该面和后组。 |
| 删除折痕/合并面 | 保存明确选定内边的完整来源区间，重算时解析实际后代链；保纸边、孔洞和切口，不删除未选的内边。 |
| 重开修改 | 回填细分/合并原操作与参数，可调整端点、线型、固定侧或选边；预览后一次采用，取消不修改。 |
| 来源删除 | 删除被后组依赖的细分拒绝；删除合并可恢复原内边，并按当前材料重算后续构造。 |
| 多来源合并 | 新面保留所有原面来源，包括两张独立材料粘合后形成的合并面；后续线网可编辑，删除合并后定位对应原面。 |
| 保存及兼容 | JSON/FOLD保v7配方和引用；接受v1–v6，追加复制/变换/旧构造不降级；组及归档各限8。 |
| 普通流程 | 关闭保存参数保原纯几何细分/合并；普通R12 LINE DXF保原实现、单位与一次Y翻转。 |

## 来源与几何

插面使用来源边的明确左/右材料侧，优先引用最新构造边，不用旧面编号或邻近坐标转绑。重合副本、独立切口侧保持各自身份。合并后逐面保完整原面集合，后续曲线/线网保存该集合及固定点；删除合并后更新原面和部件来源。复杂生成曲线改变分段身份仍明确拒绝，未宣称任意连续参数寻址已完成。

额外诊断确认：将前组移动/旋转改为镜像时，后续插面记录的方向侧会拒绝续接，当前不会修改或转绑其它面。需要补逻辑原面身份及反射后的方向更新；该混合操作限制仍未实现，不能把本批当作完整操作栈完成。证据：`output/audits/material-face-model-mirror-remainder-1009.json`。

单面几何规则、山谷重折和孔洞/弱切口细分沿用原实现；同时修复原细分新ID未避开文字等独立对象ID的问题。删除列表仅列出可合并的内部折痕，单侧悬空边仍按原规则不作为合并边。

v7沿用v6辅助线快照保护，组外材料/辅助线几何变化不能被旧配方覆盖；新记录明确归档旧配方并保当前实际材料。显示属性、独立对象和原单位保持。
