# 平折层序面数限制移除

用户此前要求平折分析与三维展示取消独立面数门槛。复查发现平折几何已取消，但 `computeFlatFold` 的层序阶段仍拒绝超过 70 面的输入。本次删除该分支及 `LIMITS.solverFaces`，更新右侧容量和结果说明。

计算仍在每任务独立 Worker 中运行，时间预算为 1–60 秒；停止与超时会终止 Worker，并保留已经发布的平折几何。不承诺任意复杂模型都能求解。编辑小段、平面化边数、文件体积限制及引擎对凹面、多边界、未指派山谷的能力边界未改变。
