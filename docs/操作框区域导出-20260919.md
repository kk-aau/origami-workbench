# 操作框与区域导出

模式61已接Canvas/App会话状态，当前82工具。框外拖建、内部移动、拖边/角调整尺寸，沿用上轮operationFrame几何；紫色框和四个角手柄、固定及鼠标步骤提示。进入工具清空选区。操作框以画布内CSS像素为基准，平移缩放画布不改变屏幕框，框自身不改变作品或增加撤销记录。

拖动只预览，释放才更新App操作框；右击/Esc/失去捕获走公共取消，恢复上一有效框。空闲右键仍通用删线。提供清框入口；切工具/工作区/换工程清框并禁用残留的区域导出选择。清框后也复位exportFrame，避免禁用但仍勾选的导出状态。

「导出框内图」打开现有导出对话框，默认SVG并勾选只导出框范围，可改PNG。svgText(crop)使用当前相机和frameWorldBounds求viewBox及实际毫米尺寸，SVG根overflow=hidden；PNG沿用既有SVG栅格导出，尺寸比例跟随操作框。图中不含操作框、底图和预览。完整工程、CP/FOLD/OPX及打印仍全图，对话框明示。导出不裁改原始折线。

验证：514单元/build通过；最新构建21操作框交互与17取消回归，共38断言通过。真实下载保存output/playwright/operation-frame.svg及.png；校验SVG viewBox等于当前框的世界范围，PNG可解码且宽高比正确。截图operation-frame-ui.png已查看。测试曾因缩放改变显示笔宽导致比较outerHTML失败，改为几何坐标/类型比较；PNG下载使用离线未挂载anchor，测试改为捕获原生anchor.click的href，未改变产品导出。
