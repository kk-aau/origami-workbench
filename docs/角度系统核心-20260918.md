# 角度系统共用核心（尚未接入界面）

本轮只实现计算与测试，不增加可用工具数，不提升工具目录完成级别。当前仍为 41 项可用工具，全工具目标继续。

## 原版依据

已完整读取本地 Oriedita 的 MouseHandlerAngleSystem（模式16）、MouseHandlerDrawCreaseAngleRestricted5（模式37）、AngleSystemModel、SnappingUtil，并核对 OritaCalc.angle 的坐标约定。

- 等分系统每步 180 / divider 度，默认 divider=8，共16个方向；原版另有 divider=12 的预设。
- 自定义为 A、B、C、360-A、360-B、360-C，不是三个角度累加。原版两组默认值为40/60/80与30/50/100。
- deg3候选以第二点为起点，朝第一点为基准，加上角度系统各方向；自定义系统额外含基准方向。
- deg2把鼠标正交投影到所选方向，非保持径向距离；临近线交点优先，然后可吸附到同方向且临近的已有点。

## 实现与明确差异

新增 app/angleSystem.ts：angleOffsets、angleFan、angleRayCutoff、snapAnglePoint。无文档写入、无线型赋值；由后续交互层控制提交、预览及撤销。

- 重复角度合并，避免多个重合候选无法选取。
- 等分数限制2–360，避免无界候选数量；自定义角度允许0–360°，坐标受现有±1000000范围保护。
- 截止仅接受指定方向前方的真实有限线段，拒绝零长、反向、延长线交点。原版模式16使用支撑线交点，此处遵守工作台已确认的有限截止规则。
- 拖画临近线仅使用实际有限段交点，不吸附到不可见延长线，也不跳到鼠标相反侧；否则保留投影点。原版 SnappingUtil 可使用支撑线交点，此处有意收紧。
- 端点吸附保留原版1e-5°方向容差，不因最近点而改变选定角度；本轮调用方可传入网格点，但尚无UI接入。
