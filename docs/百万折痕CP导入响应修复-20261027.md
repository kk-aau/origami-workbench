# 百万折痕 CP 导入响应修复

本次只修改独立迁移工程 `workbench-tauri`，不修改原 `workbench`。开发构建与正式打包发布分开，本记录不表示已发布新的应用包。

## 输入与复现

| 项目 | 记录 |
| --- | --- |
| 用户输入 | `senbazuru.cp`，85,684,954 字节，1,187,392 条有效线段 |
| 原始文件 SHA256 | `62679bd97bc77c6db26601ac13cd651d5e73f69918e365847b83f26fbf71c865` |
| 线型 | B 4,044；M 638,272；V 545,076 |
| 数据检查 | 无非法行、无零长度线；原图已经在交点分段 |
| 旧版实际窗口 | 导入 Worker 返回全部线段后，主线程心跳中断超过 60 秒；原生关闭提示工作台暂时没有响应 |
| 文件保护 | 使用 D 盘固定副本及隔离配置测试；用户原始文件不作为测试输出位置 |

文件曾在检查期间从约 81.7 MiB 变为 0 字节，之后由用户恢复；恢复后的大小和 SHA 已固定。没有证据证明空文件由应用导入产生，不能据此归因。

## 修复内容

| 路径 | 行为 |
| --- | --- |
| CP 读取 | 扫描换行位置，避免保留全文件逐行字符串数组；保留 CR/LF/CRLF 行号和严格校验 |
| 交点整理 | 无需后代映射的导入路径免建完整 Map；按需创建切点、ID 表与分段输出；几何、容差、原 ID 和线型不变 |
| 导入结果 | 大图按 4096 条线段分批传入，接收端确认后发送下一块；只有总数、顺序和最终完成标记齐全才替换工程 |
| 编辑拓扑 | 大图完整交点与吸附点计算移入可取消 Worker，输入及输出分块；过期结果不影响新文档，未完成时锁定依赖交点的编辑，允许导航 |
| 交点显示 | 密集图按屏幕空间显示代表标记；完整几何命中、吸附集合仍保留，完整键盘列表按页提供 |
| 纸面边界 | 保留原交叉判据，对规范顶点的边界包围盒做保守候选筛选，避免全部边界两两扫描 |
| 文档保存 | 复用同一不可变 Doc 的 JSON 文本；大图完整作品在 Worker 中恢复并验证冻结 JSON，免在主线程深拷贝多份编辑器对象树 |
| 原生存储 | 借用文档序列化、流式原子写入及修订哈希；大型文档请求在读取请求体前排队，保留全部请求和完整校验 |
| 冲突检测 | 每 5 秒仅获取 `{id, revision}`；修订仍覆盖正式稿和草稿所有字节，不再为了修订号反复传回整份工程 |

未采用线段截断、删点、降低精度或取消自动恢复来缓解卡顿。测试保护进程中的时间/内存上限只用于隔离诊断，不是生产计算上限。

完整自动化脚本没有整轮通过：初次 raw CDP 的 Enter 合成未触发按钮，之后改正测试按键合成并实际选中了交点；保存期间调试 WebSocket 曾断开，导致保存回执事件断言失败。失败记录保留，完整保存改由独立磁盘读回和全部线段 SHA256 核验。不能将这些证据描述为“GUI 自动化全部通过”。`fixed-real5` 首次退出的来源未确认，显式 WM_CLOSE 验证为后续独立执行，不推定首次退出原因。

这份百万段工程仍有较高内存需求；最后一轮周期采样的进程树 RSS 总和峰值约 7.55 GiB，包含多个计算线程及可能重复统计的共享页。此数字不是连续物理峰值，也不证明所有电脑都能以相同速度处理。无 GPU 情况的百万段 SVG 兼容绘制未在本轮实机验证。

最终开发构建的完整原生交互验收，以 `output/playwright/senbazuru-20261027/` 中最后一轮记录及汇总为准；中间失败或测试保护关闭均保留，不冒充最终通过。用户 CP、隔离运行配置与诊断输出不加入源码交付材料；生产代码及正式测试代码按打包规范交付。
