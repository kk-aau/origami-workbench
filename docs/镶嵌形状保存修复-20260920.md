# 镶嵌形状保存后调参修复

版本：v0.12.2，2026-09-20。

## 复现与原因

在“编辑扭转轮廓”中，将最右侧顶点向右拖动约 15 像素后保存，原编辑器写入 x=1.09989。后端只接受 [-1,1]，保存请求和随后修改角度的请求均返回 422“x 必须在 -1–1 之间”。因此预览一直保留旧画面。

同时，面板原先每次调整数字参数都会删除 dualTargets，导致对偶点修改在旋转或缩放时丢失，并使前端连续几何预览的结构匹配失效。

## 修复

- 拖动与数值编辑使用同一坐标范围：扭转轮廓 [-1,1]、母结构 [-10,10]、种子 [0,1]、对偶目标 [-100,100]。
- 保存前检查越界、重复点及凸面条件。无效草稿留在窗口供修改，当前参数不被替换。凸轮廓检查也拒绝交叉星形。
- 坐标输入后直接点击保存，采用最新坐标；输入错误和形状错误的提示区域预留高度，保存按钮不会随提示出现或消失移动。
- 旋转、缩放和反向扭转保留对偶目标。母结构改变时重建目标；显式清除按钮仍可恢复默认对偶。
- 保留后台计算与同屏平折的更新机制。几何约束不满足的参数仍可能无法生成候选，不把失败结果伪装成成功。

## 验证

- TypeScript 构建通过。
- 镶嵌参数、编辑验证与平折相关 14 项单元测试通过。
- 真实浏览器 17 项回归通过，覆盖边界拖动、越界输入、凹轮廓、直接点击保存、重新打开形状、自定义母结构、对偶目标、后续旋转缩放、同屏平折更新和显式清除。

回归脚本：`scripts/verify-tessellation-editing.browser.js`。复现响应记录：`output/reproduce-shape.browser.js`（开发调试脚本）。
