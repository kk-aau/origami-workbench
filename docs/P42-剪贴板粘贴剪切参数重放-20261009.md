# 剪贴板粘贴、剪切参数重放（2026-10-09）

本批完成已有材料剪贴板操作的参数保存、编辑和后续重算。源码运行版更新，免安装包尚未更新，完整 Origamica 目标仍在进行。

| 入口 | 可体验效果 |
| --- | --- |
| 折痕编辑 → 绘图工具 → 剪贴板 → 原位/偏移粘贴 | 默认保存参数组；毫米偏移、CP/FF预览、导航、取消和采用。 |
| 纸张属性/选区 → 剪切材料部件 | 选择完整材料部件，明确边界保护和保存参数；采用后放入工作台剪贴板。材料Ctrl+X/“剪切选中”也打开此预览，普通线段剪切保持原流程。 |
| 纸张属性/选区 → 参数构造组 | 重开粘贴偏移、CP选择或剪切部件并重算后组；剪切全部材料后入口仍保留，可删除剪切组恢复。 |
| JSON/FOLD保存重开 | 参数源快照和独立来源身份仍可重算。普通DXF沿用原R12 LINE导出器，不含加工指令。 |

| 行为 | 实现及边界 |
| --- | --- |
| 跨工程粘贴 | 保存所选材料的独立源快照；源工程后续修改不会影响已采用副本。源面有独立来源编号，不借用目标原面，重合纸片不焊接。 |
| 普通/空目标 | v9基底可保存无材料合同的普通或空工程；普通目标沿用原精确交点转换，必要分段仍需明确选择，拒绝重复、零长或近端点移动。文件导入自身已有普通分段流程，浏览器测试核对导入后的实际目标。 |
| 原几何、单位与FF | 复用原纯几何粘贴/剪切，不新增缩放或坐标翻转；已有FF依原参考面坐标转换，混合缺失FF须明确仅CP。 |
| 后组续接 | 导入纸片的细分端点、变换、复制、曲线来源可保存；更改粘贴后按原边比例重算细分。删除被后组依赖的粘贴来源拒绝，不转绑其它材料。自由世界坐标/曲线固定点仍保原声明，不会随源自动移动；失效时明确拒绝。 |
| 空状态 | 剪切全部材料保模型，移除活动材料/起始面；可恢复、重新编辑选择或再次粘贴。参数管理器在无材料时不读取FF坐标，修复实际浏览器发现的空窗口错误。 |
| 辅助线与历史 | 保存对应辅助线快照，不重复生成；删除辅助线的后代映射为空。预览变更使旧结果失效；取消不写入，采用一次撤销/重做。 |
| 兼容与容量 | v1–v8保持读取，后续定位复制不降级v9。原组外修改先保归档再从当前实际材料记录。组/归档各限8，容量拒绝不截断。关闭记录继续原纯几何。 |
