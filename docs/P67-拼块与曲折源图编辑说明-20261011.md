# P67 拼块与曲折源图编辑

这批改造已进入本地源码。它晚于 v0.13.6 免安装包，不包含在该包中；该包和源码压缩包保持原有字节。

| 操作入口 | 可以体验到的改动 |
| --- | --- |
| 镶嵌设计 → 混合平铺／自定义 → 拼块组合 | 组合图有网格和坐标刻度；滚轮以鼠标位置为中心缩放，空白处、Alt 或中键拖动平移。适合组合、网格开关、查看操作不改变拼块坐标和撤销历史。 |
| 拼块组合 → 编辑拼块形状 | 在当前轮廓上插入或删除点，支持 3–24 点；可拖点、输入精确坐标，预览后采用或取消。其它拼块及明确设置的格矢保留。 |
| 镶嵌设计 → 空间构造 → 离散曲折 CP → 原 N 点／母线／山谷 | 在源图中拖折线点或左右母线端点；网格、刻度、缩放、平移和精确输入配合使用，可在现有点列中插入／删除点。 |

曲折编辑保留原母线向量的幅度，不把它们强制归一化。拖动折线点时保存的母线向量不变；拖动母线端点时保存端点相对该折线点的原向量。增加／删除点后，存活原边的山谷赋型保留，新分割或合并出的边设为未指派，需要用户确认。

编辑窗口先修改本地草稿，取消不会写入工程，采用草稿后由原有计算流程重建候选。无效输入保留错误说明，不能静默恢复默认形状。源图刻度使用原构造坐标；采用 CP 时仍使用原工作区的包围框平移及最长边 200 mm 转换，不再额外缩放或翻转。

凹拼块仍可用于母结构拼接；不满足原扭转条件时，扭转 CP 选项保持禁用。曲折源几何通过并不等于整个图案已经通过平折层序；使用“仅采用 CP”时保持现有明确标识。

本批没有新增原版阵列算法。Miura/Huffman 波纹格、Yoshimura 折筒、Yoshimura/Miura 双向螺旋、水雷阵列及其它实用缺口继续按原 Notebook 与实际创作流程核对，不能用当前通用网格或固定示例代替已经完成的声明。
