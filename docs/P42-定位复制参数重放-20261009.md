# 定位复制参数重放（2026-10-09）

入口：**折痕编辑 → 纸张属性/选区 → 材料定位复制**。可选两点平移、四点相似、任意直线镜像；默认保存参数组，采用后在“参数构造组”重开调整。源码运行版更新，免安装包尚未更新；完整 Origamica 目标仍在进行。

| 操作 | 效果 |
| --- | --- |
| 两点平移 | A→C，使用原 `point + to - from` 公式。 |
| 四点相似 | A/B对应到C/D，使用原复数相似变换，不分解旋转/缩放再取整。 |
| 直线镜像 | A—B作为任意轴，使用原反射规则；镜像修正面/孔环方向，原线型与折角保持。 |
| 可视化 | A/B/C/D手柄、毫米刻度、精确坐标输入、放大/缩小/平移及CP/FF预览；示意连线不进入CP。 |
| 调整已采用副本 | 从原阶段重新生成，后续细分和其它构造重算；原件CP/已有FF逐值保持，重合副本不焊接。 |
| 保存与历史 | JSON/FOLD重开继续编辑，取消不写入，一次撤销/重做完整；删除被后组依赖的来源明确拒绝。 |
| 辅助线/兼容 | 可包含已选辅助线，重算仅生成一次；关闭保存参数保原纯几何规则，原画布两点/四点/镜像工具保持。 |

参考点是用户明确设置的CP世界毫米坐标，不自动吸附或绑定材料端点；改变前组形状时这些坐标保持原参数。整片选择按来源标记重算，原件的后代链不混入新副本。CP与已有FF使用同一原定位公式，FF显示按现有视图坐标转换，单位没有二次转换。

v8接受v1–v7，定位复制保存选择/辅助线来源及原变换参数。追加普通复制、单面细分/合并等不降级。组和归档各限8；组外实际材料/辅助线变化不被旧模型覆盖，新记录先保归档，再以当前材料建立新模型。
