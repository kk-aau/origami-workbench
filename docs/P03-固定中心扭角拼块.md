# P03 固定中心扭角拼块

原版 `Origamica 15.0.nb` 的 In[2905] 将 `PolygonCenteredTwistAltTile` 的 `(w, α)` 传给 `CenteredTwistTiltAngle[w, α]`，再转为 `PolygonCenteredTwistTile`。In[2960] 对 `QuadrilateralCenteredSplitTwistAltTile` 做同样的换算，令偏置为 0，且以 `α < 90°` 确定分裂扭转方向。对应定义位于笔记本约 213822–213859、214720–214894、220297–220376 行。

自定义拼块的“逐块扭转参数”现可逐块选择“扭角 α”。新模式保存 `angleMode: 'twist'`、`twistAngle`、`width`、`offset: 0` 和逐边中心 M/V；四边形分裂另存 `construction`、`baseVertex`、`connection`。构造时每次由当前宽度计算 `τ = atan2(sin α, w cos α)`，所以改宽度后 α 保持固定。旧工程仍保存和读取原有 `tilt`、偏置及可选分裂方向 `ccw`，不会悄然改变其折痕。

该模式只对应原版**居中** AltTile：不能与非零偏置或手动 `ccw` 同时指定。整片构造仍要经过共享边、局部平折、面内等距和全局层序检查；参数形式等价并不保证任意拼块组合有整片平折解。笔记本将换算写作 `ArcTan[Tan[α]/w]`；工作区以 `atan2` 选取 0–180° 的物理褶角分支。笔记本的这些示例没有保存可独立比对的 Wolfram 数值 CP，尤其缺少 α 大于 90° 的输出锚点，因此专项测试依据原版委托方程、独立三角函数换算和本项目两种参数形式的几何一致性，不宣称全参数逐点等价。
