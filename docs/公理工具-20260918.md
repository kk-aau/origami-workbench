# 折纸公理5／7

开发版v0.9.2，未打包。工具栏“折纸公理”组。

- 公理5：点A → 目标线 → 必经点B → 选择编号候选 → 确定长度。结果折线经过B，反射A后落到目标直线；最多两个候选，切线情形为一个，无解会保留前两项以便重试B。
- 公理7：点A → 目标线 → 垂直参考线 → 选择候选 → 确定长度。结果折线垂直参考线，反射A后落在目标直线上。目标经过A、目标和参考平行等退化输入会拒绝。

目标线采用所点线段的完整支撑直线，因此映射后点可落在原线段延长线上。紫色圆点标出映射位置，不写入工程。选解可点击编号按钮或唯一命中的紫色候选；候选重合处必须用编号，不自动猜解。

确定长度有两种方式：

1. 点击实际截止线段：公理5从B、公理7从A与映射点的中点，画到该线段的真实交点，可选任一方向；不接受只有延长线相交的目标。
2. “生成所选整段”：从上述原点向两边找到最近非辅助折线或纸边。某侧无实际截止时只显示方向提示，不伪造端点，也不允许生成整段；仍可指定单侧有限截止。

结果使用当前新绘制线型；参考线不改变。交点真实分段，整体一次撤销。右键／Esc取消构造，不同时删线；换工具清空。需要重选目标时可保留A，其后步骤重置。辅助线可作为明确选择的目标或截止，但不作为自动整段的默认截止。

实现依据本地Oriedita公理5／7 handler的输入语义，公理5用圆线交点与垂直平分线求解，公理7沿参考方向映射后求垂直平分线。与原版交互区别：本版可选自由／吸附点，显式选解，不使用所选截止线的延长线；尚未做原版运行时逐例对照，目录保持基础可用。

验证：12项核心测试（含60组约束反射验证），全量338单元通过；公理33、兔耳26、原交互98共157浏览器断言通过；构建通过。桌面安装包和免安装包未生成。
