# Origamica 第 39 节：自定义母结构的原始—对偶扭转

依据 `tmp/Origamica-15.0-reference.nb` 第 243441–245737 行。原版 `MakePrimalDualTwistTessellation[tobj,γ,α,opts]` 的 `tobj` 是带原始／对偶邻接的 `TPrimalDualGraph`，不局限于正方形、三角形、六边形预设。原版把通用安全褶角范围标为 `IN PROGRESS`，故本工作区只接受有限、无交叉、无重叠、无孔洞且不超过 256 面的母网格，并把生成结果分为几何、局部折痕、整片层序三关。

现在可从周期、混合、非周期、自定义网格和普通环状母结构使用“用于原始—对偶”，或在原始—对偶面板输入 `motherParams` JSON；工程参数严格回读。自定义母图与铺石共用 `build_mother` 的平面拓扑检查。后端对母图求垂直对偶、按现有收缩旋转公式生成折痕；`γ/α`、定向和手动对偶点仍可用。内置 `tiling+rings` 预设继续走旧路径，不因新入口变更。

| 检查层级 | 当前行为 |
| --- | --- |
| 母图 | 限制输入大小与坐标，拒绝非法邻接、交叉、重叠、孔洞、递归母结构及原版环状直接折痕输出。 |
| 折痕几何／局部 | 报告退化、相交、Kawasaki、Maekawa 和四价 LFF 必要关系；失败候选不能采用。 |
| 折后面内等距 | `γ/α` 模式计算原版负 `α` 对应点后，补上源文前述比例／转角变换；面内距离不闭合则不提供直接折后坐标。 |
| 整片层序 | 自定义母图在工作区自动求解；无解、无效、未确认或仍在计算时不能采用。层序已解仍不证明连续无碰撞运动。 |
| 逐边成对定向 | 以母结构的内部共享边顶点对保存翻转位，同时反转其原始／对偶边定向。2×2 方格数值测试中坐标完全不变，仅关联的 3 条山谷赋型 M↔V；局部条件及整片层序重新检查。边界边或不存在的母边拒绝。 |
| `FaceupFace` 局部传播 | 有符号折痕面 Fk 独立于全局顶面：正号指定该面正面朝上，负号指定反面朝上。按原版 `TwoColorGraph` 的面对偶邻接二染色，再按 `LocalFaceOrdering` 的有向对偶边、山谷类型逐边生成“上面→下面”关系。工作区据此选平折几何的参考面，并检查求得的完整层序覆盖每条局部关系；不一致、不可二染色或共享边山谷未定时禁止采用。单个无折痕面可从背面显示。 |
| 有符号可见顶面 | 工作区规范化的折痕面 Fk 用正号表示正面朝上、负号表示反面朝上；层序求解必须找到该面为全局最上层且纸面方向匹配的解，否则不可采用。面号越界拒绝。 |

第 39 节保存示例给 `{0,2,4}²` 的 9 顶点、4 方形面，`γ=2`、`α=20°`、逆时针、原始面定向，并指定 `FaceupFace=3`（245559–245676）。本地按保存公式得到折痕参数 `ρ=0.7925482672068609`、`β=21.862218721594214°`；该母图生成 16 顶点、24 边、9 面，几何和局部检查通过，折后面内距离最大误差 `6.17×10⁻¹¹`。这些是源码输入的本地复算，笔记本此处没有可机读的 Wolfram 数值 `Out`。

**逐项对照。** 原版 `OrientEdgePairs`（103266–103361）在改 `DualEdges` 方向时同步反转对应 `InteriorEdges`，保持二者有向正交；因此工作区每条内部共享边的独立翻转位，完整表达当前有限正交母图内该对偶边的两个方向，不应另外开放破坏正交的“只反转原始边”。原版 `LocalFaceOrdering`（126597–126720）在有符号种子上给面二染色，并由山谷类型和对偶边定向导出局部箭头；新入口对此使用工作区规范化后的折痕面号。保存例对应的 9 面，`±F1…±F9` 共 18 种种子均得到平折几何、完整层序和 12 条一致的局部箭头。`F3` 的解中全局顶面是 `F9`，直接证明局部种子没有被误当作全局顶面。方形、三角形、六边形的一圈构造及默认纸张外延的正反种子也通过；单面负种子显示背面。UI 面板截图：`output/playwright/p39-faceup-seed-dialog-20260927.png`。

**未等价范围。** Mathematica 原版的面序与工作区规范化面序不同，不能把笔记本 `FaceupFace=3` 直接当成同一物理 F3；须在工作区折痕图选择对应物理面。原版 `FacesAboveAutomatic` 从局部箭头继续传播全体上下关系，工作区用独立的 Rabbit Ear 全片几何约束求解并逐条核验局部箭头；尚无原版这一传播过程和 Wolfram 数值 `Out` 的逐点等价证明。完整任意 `TPrimalDualGraph` 输入仍受有限单纸、无交叉、256 面等边界限制。原版主函数 245514–245522 直接把 `−α` 顶点作为折后图坐标，未执行前文 `FoldedFormScaleRotation` 要求的比例 `m` 和转角 `φ`；示例所需 `m≈0.755203210819111`、`φ≈−7.6810285586651545°`。工作区执行这一步并核验面内等距，因此符合源文几何意图，但不是保存代码逐字的数值复刻。
