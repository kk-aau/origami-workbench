# 折纸工坊 0.13.50-tauri.23

日期：2026-10-30。Windows x64 · Tauri 迁移版。

本版优化多步骤折序工程主画面的拖动、放大和缩小，减少连续操作中的停顿。

| 改动 | 效果 |
|---|---|
| 连续缩放在画布内按帧预览，停止滚轮后再提交视口 | 避免每次滚轮输入都处理整份工程；切换步骤或开始其他操作前保留当前视口 |
| 平移、缩放使用仅更新相机的事务 | 校验相机数据和活动纸面快照，保留纸面几何及其他步骤，不重复执行无关步骤的处理 |
| 复用纸面 SVG、绘图边界和折痕预览等显示数据 | 视口变化时减少重复生成；纸面、颜色、方向或标注改变后正常更新 |
| 平移复用按下时的变换矩阵，独立监听画布尺寸 | 减少拖动过程中的重复布局读取 |

开发阶段用用户提供的 66 步工程，在本机同一原生 WebView2 中执行相同的 16 次滚轮输入，耗时由约 **3.04 秒降至 0.54 秒**。已在开发阶段确认密集输入累计及切换步骤后的视口保留；这是开发阶段的测量，不代表本轮安装包或所有设备的性能验收。

本次按用户“打包，不检查”的要求直接构建和归档，**未运行新增测试，也未执行安装版／便携版实包验收**。已有曲面姿态、碰撞及其他功能继续随本版提供。

安装版、便携版、同版本完整源码 ZIP／7z 和独立调试材料一同交付。完整源码作为独立附件，包含许可证和来源材料；应用内保留必要的原始许可与源码获取说明。运行需要系统已有 **Microsoft Edge WebView2 Runtime**，应用不自动下载或安装该运行环境。
