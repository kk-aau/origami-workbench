# 局部短痕动画

在折序绘图中选择谷折或峰折，把用途设为“预折后展开”，画出需要压出的短段，再打开“步骤动画”。无法组成刚性纸瓣的短段使用端点曲面近似：指定短痕转动，内部端点周围形成可展扇面，反向延长方向留在一个完整扇区内，不人为增加延长折痕。

| 使用范围 | 当前行为 |
|---|---|
| 纸张 | 一张凸的展开纸面，可包含已有 F 折痕标记 |
| 短痕 | 一端在纸边、一端在纸内；每步最多四组 |
| 中途峰值 | 默认 90°，界面明确显示实际演示角度 |
| 初态和结束 | 精确保持原始材料坐标；不改变普通步骤的 100% 端点 |
| 多组 | 自动依次压下、展开，每组回到相同原姿态后再执行下一组 |
| 固定侧 | 指定材料点所在三角片的三个顶点全程固定；参考姿态改变时要求重新选取 |
| 普通刚性步骤 | 继续使用原来的刚性路径及安全并行分组 |

这是零厚度可展曲面的局部演示近似，尚未模拟纸张的塑性、摩擦及真实厚度。90°演示不表示材料已被物理压平定型。两个端点都在纸内、已有折叠的初态、凹纸边、孔洞、切口及多张纸尚不支持这一分支；系统会说明原因，不会用整条延长线折叠来代替短痕。局部压痕与改变最终折形的动作应拆成不同步骤。

## 网格和显示

| 项目 | 处理方式 |
|---|---|
| 材料网格 | 内部端点作为扇面中心；辅助径向网格仅存在于动画中 |
| 多组共用网格 | 一到四个端点的射线在同一材料平面内求交、细分；各组共用材料顶点与三角片编号 |
| 材料身份 | 临时三角片映射回原材料纸面；不增加 sourceFaceCount 或纸层 |
| 原有折痕 | 原 CP 中的 F 标记保留可见；同一扇区内的细分三角片采用相同姿态 |
| 新短痕 | 动画开始后出现，未执行的组暂不显示；回退到起点重新隐藏 |
| 辅助线 | 不显示为 CP 折痕，不写回工程或绘图草稿 |
| 正反面和纸层 | 使用原有配色；纸层间距保持关闭，中途使用实际三维几何遮挡 |

每组使用同一端点和连续的扇区旋转形成闭合曲面，不能只让末端旋转矩阵闭合而留下材料开缝。姿态参考由整张材料的大跨度三点构造，避免细小三角片放大 Float32 误差。三个固定顶点保持准确原位，共享顶点误差仍须小于 2×10⁻⁷（归一化坐标），不通过平均顶点隐藏开缝。

## 路径验收

只有通过验收的候选曲面才进入播放。关闭动画窗口会取消求解；预算耗尽、材料变形、局部形态不符或防穿透检查未通过时，明确拒绝该路径。

| 检查 | 判定标准 |
|---|---|
| 面内形状 | 整个线性播放区间的边长相对误差不超过 0.02%，面积相对误差不超过 0.08% |
| 硬铰链 | 整个区间的实际二面角误差不超过 0.006 弧度 |
| 端点局部形态 | 每个内部短痕端点附近必须有实际曲率，且反向延长方向不能以同一折角继续折叠 |
| 固定区域和复原 | 固定片始终不动；每组起末及整个步骤起末均准确回到原姿态 |
| 自穿透 | 同源纸面的非邻接三角片也受约束；使用整体单射证明或逐对连续检查，不能以“属于同一层”为由免检 |
| 连续性 | 检查关键帧之间的线性运动区间，不能只检查静态采样帧 |
| 加载复核 | 不信任保存的通过标志和误差统计；运行端重新验证材料、曲率和连续防穿透 |
| 资源限制 | 最多 1,200 顶点、2,400 三角片；合并运动最多 4,097 帧、300 万坐标标量 |

各组在准确相同的展开姿态处拼接，仅对已认证路径作正仿射时间缩放；中途不会添加未经验证的过渡运动。逐组路径与最终合并路径均需通过验证。所有数值保证均针对零厚度网格、规定容差和当前播放插值，不构成对真实纸张物理行为的保证。

连续防穿透优先尝试整体投影证书：独立确认网格是连通的有向三角圆盘，再证明整个线性区间中所有三角片投影面积严格同号、投影边界始终为简单闭环。这些条件保证整个投影单射，因而三维纸面不会自交。面积和边界使用同一组实际浮点投影坐标，并以向外区间界证明全程条件。任一前提不满足就回退逐三角片检查，不把证书失败当作通过。

simPartialCreaseMesh.ts 和通用顶点柔性求解保留为实验模块；产品中的局部短痕入口仅使用上述经验证的端点扇面方法。
