2026-10-19。源码开发记录，本轮不生成桌面发行包，不覆盖已归档的 v0.13.29。

## 本轮需求

| 需求 | 实现行为 |
|---|---|
| 对折后，本步已有折线端点／交点不能拖角 | 按真实材料面补充图示锚点，第一次拖动即可选中；原 CP 与求解模型的顶点编号保持 |

## 拖角修复

用户红圈对应原工程第 7 步主图坐标 `[37.5,12.5]`。本步操作后的 CP 和绘图中存在该端点，但操作前纸面只有 41 个基础顶点，没有这个点。旧拖角覆盖层只枚举基础顶点，因而没有命中目标。简单增加一个屏幕坐标也无法正确处理该处的四个重叠材料面。

新增可选 `pose.paperDeformation.nodes`，每个节点保留材料面编号、原 CP 坐标与图示位置。网格在对应材料面内细分，纸边、折痕、选点、吸附、CP 高亮、缩略图和导出共用这套派生网格。基础 CP、求解模型拓扑与材料面编号不变；新增节点不会跨重合材料面合并。

节点与原顶点共用选择、拖动和撤销。第一次拖动归档包含相同节点布局的平整状态；恢复扯角、保存重开和旧扯角工程补节点时都按原材料坐标对齐。投影中心仍取基础模型，新增点超出原边界不会让观察中心跳动。

局部变形不能借未变化的基础模型重新获得层序证书。新增节点偏离当前基础纸面映射时，保持图示层序并提示恢复平整后重分析；平整节点和既有普通顶点分析继续工作。严格退化、自交和非等距固定侧校验保留，新增锚点不授权放宽这些检查。

真实桌面验证使用用户工程的隔离副本：首次鼠标拖动即选中顶层 face4 成员，目标约为 `[43.75,18.75]`。基础 41 顶点、所有 CP 状态、来源快照和其余 22 步保持不变。完整 13 个图示节点在状态切换和保存重启后保持。

平整／扯角切换继续执行既有绘图重投影规范化：此工程从 50 条标注变为 49 条，两条同位置、同外观的 face1／face2 谷折合并为同一对象的两个材料面；旧非覆盖虚线字段省略为类别默认值。有效线段覆盖保留，保存与重启的完整标注一致性以恢复扯角后的保存态为基准，不声称首次拖动与状态切换前后原始 JSON 完全相同。

## 重合边界的显示

遮挡由纸面严格内部产生，边界共线接触保留正常折痕样式。部分共线会拆分显示区间，第三层真实覆盖仍遮挡；孔边界和非刚性纸面的三角并集也使用同一原则。内部三角共享边继续被视为纸面内部，避免重新漏出细线。

此规则限于展示投影。画线时“最上层”的物理材料选择保留原逻辑，不会因为下层折痕显示正常而扩大 CP 赋型范围。

## 圆框的使用

| 操作 | 用法 |
|---|---|
| 放大框 | 在“折纸符号 → 视图方向”中点击“局部放大框”，在预览中选择区域并插入；也可从符号库拖入主图，以落点初始化小圆 |
| CP 结构放大框 | 在同一分类选择“CP结构放大框”，参考操作前或操作后 CP 圈定区域，插入一个定位小圆及两个前后对照大圆；拖入主图的落点用于定位小圆 |
| 移动与缩放 | 在选择工具下拖动圆框，蓝点调整大小。纸面小圆改变放大选区；CP 小圆只调整主图标注位置和大小，不改变已选 CP 内容 |
| 修改来源 | 选中圆框后点击“重新选区”；保留定位圆及全部大圆的位置和大小，主动修改倍数时才改变大圆半径 |
| 删除 | “删除圆框”或 Delete；支持撤销 |
| 取消手势 | Esc、右键或失焦取消当前拖动，松手才提交一次工程修改 |
| 多个圆框 | 新圆框默认避开已有大圆，随后可自由排版 |

CP 的定位小圆与前后两个大圆独立显示，不绘制圆间外切连接线；主图、缩略图、符号库图标及 SVG／PDF 统一采用这一显示方式。纸面局部放大框继续使用双圆连接线。

轻点圆框或蓝点不会产生多余修改记录。缩放按指针相对按下位置的径向增量计算，避免点中蓝点边缘时半径跳变；平移也先计算位移差，再加回原坐标，保留无位移操作的精确值。

来源是当前纸面图示或对应 CP 的实时矢量内容，不把截图、SVG、文件地址或外部资源写入工程。纸面来源显式排除全部圆框，避免重复放大与递归；每份复制内容的 mask、clipPath 和 use 引用独立命名。

CP 小圆与 CP 选区使用独立坐标：`source.center/radius` 始终表示两图共用的 CP 区域，`source.locator` 表示主图小圆。`source.stateId` 与主显示圆引用本步操作前 CP，`comparison.stateId/target` 引用操作后 CP 及其独立显示圆。两大圆使用相同原始坐标选区，分别标明“操作前 CP”“操作后 CP”，可独立移动和缩放；标签与全部圆框一同计入导出边界。修改 CP 内容使用“重新选区”，并保留小圆和两大圆的位置及大小；主动修改放大倍数时才改变两大圆半径。翻面／旋转重投影只调整主图定位小圆，CP 采样区域和两大圆布局保持。

旧工程中没有 `locator` 的 CP 圆框会自动派生主图小圆，打开与显示不会写入迁移字段。第一次移动或缩放任意一圆时固定该定位信息，各圆随后独立编辑。旧的单图 CP 圆框保持可用，“重新选区”后升级为前后对照；CP 原坐标不会扩大主图范围。符号库共显示 38 种，既有 CAD 符号和放大／缩小箭头保留。

`step.callouts` 为可选独立数组，不扩展线段／符号的既有类型。CP 引用仅允许本步前、后两个状态；复制步骤、删除步骤或重接状态链时按角色重绑。圆框的显示边界纳入适应视图与导出排版，CP 来源坐标不扩张主图边界。

主图、步骤缩略图、文档库缩略图、SVG 与 PDF 共用矢量渲染。CP 圆框随对应 CP 修订更新，纸面圆框随当前纸面和全局折线显示样式更新。PDF 完成模型封面沿用只显示最终纸面的规则，步骤页保留圆框。
