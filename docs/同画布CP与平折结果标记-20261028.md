# 同画布 CP 与平折结果标记

折痕编辑直接在同一画布显示 CP 和多个平折结果，取消该工作区的“正背同显”组合窗格入口。

| 操作 | 行为 |
| --- | --- |
| 在 CP 上短按鼠标中键 | 在实际点击位置显示深绿色十字，指定后续“计算平折”的完整 CP；多 CP 时必须先指定目标 |
| 重复点击“计算平折” | 为标记的 CP 新增独立结果，每 CP 最多 4 个；达到上限时明确提示，保留旧结果 |
| 在结果上短按中键 | 在实际点击位置显示暖橙色十字，指定显示操作目标；原 CP 标记保留。落点保存在模型原坐标中，随正背面、旋转和相机变换 |
| 调整结果样式、纸面颜色、正背、透视、旋转、适应画面 | 仅作用于标记结果；其他结果各自保留显示参数与相机 |
| 中键拖动 | CP 继续整体平移共享画布，平折结果仅平移所命中的结果；不改变两个标记，超过短按阈值后再拖回原处也不会误标记 |
| 滚轮缩放 | 按最近标记的 CP／结果类型，将缩放交给相应画布；结果按活动结果 ID 定位 |
| 计算期间更换标记 | 正在计算的来源保持固定；完成后保留用户重新标记的结果，不取消计算或写入别的结果 |
| 完整作品与模型集合 | 保留各结果来源关联、颜色、正背和独立相机；重新打开仍遵循已有层序重新验证规则 |

标记只有 CP 与结果两种。十字为 12×12 屏幕像素、4 像素粗臂的实心形状，整体 60% 不透明度，不拦截鼠标。新结果默认错开放置；手动调过相机的结果不会因新增结果重新排布。结果命中使用实际纸面，孔洞不会被整个外接矩形误当作纸面。

用户随后明确暂缓 CP 独立拖动，本轮保留原共享画布行为，不改变 CP 数据或已有结果。

## 数据兼容

- 模型集合格式新增 v3 的 CP 来源关联，兼容读取旧 v1／v2；完整作品保持 v1，新增可选来源字段，并同步 Rust 原生保存校验。
- 同 CP 的新计算与快照复制共用 4 个名额。旧文件已有超过 4 个的结果仍完整恢复，仅限制后续新增。
- CP 来源按原纸边／材料身份关联，内部折线增删或分割不改变归属。删除并重建纸边锚点、改变材料身份可能形成新来源；纸张移动后需重新标记。
- 重叠或嵌套导致无法唯一确定纸张时明确报错，不裁剪折线或回退成整张多 CP 文档计算。
- CP 十字为当前编辑会话的计算目标；结果活动项按原模型集合保存。十字不进入几何、纸面求解或导出图形。
