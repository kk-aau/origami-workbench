# 区域山谷互换

模式58接通，当前76项工具。核对本地 MouseHandlerCreaseToggleMV、Worker.MV_change、FoldLineSet.MV_change：单击最近线或拖出接触框，释放时仅互换M/V，其他类型不变。框选不限方向，不裁剪线段。

regionalSwapHits复用直接赋型普通最近线规则（严格容差、等距文档先出现优先），再筛山谷；不穿透辅助/未知/平面边。边界保护先排除受保护边界是本工作台共用编辑规则。applyRegionalSwap复用swap保留角度幅值、零和null，空命中返回原文档，无无效历史。原版点击非山谷线仍record，本工具省略这种无效记录。

Canvas复用typefilter点框手势，专用核心命中与提交；紫色预览、固定指南和鼠标步骤提示、参数条命中数。新增“直接赋型”组按钮及双向箭头图标，保持限宽多列布局。目标不依赖绘制预设，不主动改选区。按下不提交、释放提交一次；右击／Esc取消活动操作，空闲右击沿用删除。
