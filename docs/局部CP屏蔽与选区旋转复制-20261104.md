# 局部 CP 屏蔽与选区旋转复制

| 功能 | 使用方式 |
| --- | --- |
| 局部 CP 屏蔽已有折痕 | 在 CP 结构放大框创建／重新选区窗口勾选“屏蔽已有折痕”；也可选中已插入的 CP 圆框直接勾选。隐藏 F 型已有折痕，保留山谷折痕、边界及其他对象。操作前后两个圆框同时生效。 |
| 旋转复制选区 | 在折痕编辑选择线段，展开“复制与移动”选择“旋转复制”，点击旋转中心，选区中离中心最近的点自动成为起始参考。移动鼠标，指针投影到等半径圆上，整组选区旋转预览，再点击落位；不输入角度。中心在线上时使用最近的非重合端点避免零半径。支持命令 RCOPY。 |

局部图开关随折序工程保存，旧工程默认不屏蔽；缩略图、SVG 和 PDF 共用该设置，不删除真实 CP 几何。旋转复制保留原线、山谷赋型和折角，沿用边界保护、交点切分、材料复制与一次撤销流程；Esc／右击可取消定点。选中线段的属性面板也提供“旋转复制选区 · 指定中心”入口。

验证：56 项选区变换、局部图保存／渲染、工具命令及排版相关测试通过，前端生产构建通过。隔离浏览器实操确认指定中心、鼠标投影、距离保持与点击落位、副本真实保存、撤销，以及前后 CP 圆框同时隐藏、重新选区记住开关、取消勾选恢复显示；控制台无错误。图像记录位于 `.runtime/cp-rotate-qa/`。本次没有重新打包或上传。
