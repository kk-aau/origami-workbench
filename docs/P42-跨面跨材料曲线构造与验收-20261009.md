# 跨面、跨材料曲线构造与验收（2026-10-09）

本批把上一轮单面闭合曲线扩展到参考面所在部件或全部材料。曲线与原边及其它曲线同时拆分、按实际面域裁剪，再统一构造材料面和验证FF。完整Origamica复现目标继续，免安装EXE未更新，不打包、发布或操作设备。

入口：镶嵌采用为材料 → 折痕编辑 → 绘图工具 → 纸张属性/选区 → 材料曲线批量 → 范围。圆/椭圆及闭合贝塞尔保持原参数和明确的毫米离散误差。

| 范围 | 行为 |
| --- | --- |
| 当前面 | 保上一轮合同：完整闭合曲线必须处于选定面内。旧来源、操作及文件不被隐式改为跨面。 |
| 参考面所在部件 | 依据indexed材料身份选择该部件所有面，跨现有折痕裁剪，纸边外及孔洞内不生成折痕。 |
| 全部材料 | 分别处理每张实际材料，包括断开或重叠的独立纸片；不按坐标焊接，也不添加跨空白连接。 |

跨面模式下更换参考面保留曲线几何，只更新固定点所属参考；修改范围立即失效旧预览。固定点仍须严格位于参考面及唯一子面内。当参考面是原起始面时，它选择固定子面；否则保原起始面的第一子面，不把参考面静默替换为全局折后坐标参考。

## 拓扑及坐标合同

| 检查 | 实现 |
| --- | --- |
| 共享折痕的交点 | 使用原边身份和精确有理交点取整结果注册。同一原边的两面使用同一新增顶点，多个曲线及原折痕相交不产生近似重复交点。 |
| 独立切口两侧 | 原B边保持各自索引、朝向与FF姿态。同部件重合切口同步细分，但使用不同顶点和边，不粘合切口。 |
| 其它材料 | 各部件的曲线交点分别注册；即使CP坐标完全相同，仍保不同材料身份。 |
| 纸孔与空白 | 分类在原面的真实外圈/孔环上完成，只保正长度内部区间。不填孔、不重置纸形、不补桥接线。 |
| 原点及赋型 | 原顶点数组及FF前缀逐值保留；细分原边保原段ID、属性及后继映射。新增曲线继承各自F/M/V/U，原边不改成曲线赋型或新的纸边。 |
| 完整图事务 | 所有曲线与原面一次处理后再划分、回展和提交。避免逐线插入把暂时面内端点丢掉或误报闭环失败；一次应用、一条工程历史。 |

原线网入口128点/256边、1024交点及闭合条件仍保留。内部原面+曲线组合使用单独有界容量，允许临时开放线段用于裁剪；它不是开放材料折痕的公开入口，最终仍必须通过完整材料图、面扇、边界、欧拉特征及CP/FF检查。共享计算检查预算2,000,000；原材料容量及层序预算不放宽。

误差仍是采样前源曲线与LINE近似之间的界；裁剪、材料长度和空白长度基于实际采样线段，不称为解析曲线的精确弧长或精确曲线交点。重叠独立纸片的加工长度按实际材料次数累计，空白按选定范围覆盖的区间并集统计，不能以坐标重复为由少处理一张材料。

## 剩余目标与未验证范围

本批完成有限闭合圆/椭圆/贝塞尔曲线的跨面、跨部件裁剪，不等于任意连续曲线折叠或Wolfram全输入语义。源曲线最大16条及128采样点不变；预算用尽、病态/过近交点、重复/重叠、不能表示为简单子面的接触或单桥仍明确拒绝，不移动端点或删除源边来换取成功。

完整目标仍缺有效≥10偶度编织、曲线/接触/交叠母图孔环、单桥/弱简单面、材料自由起点/开放端点与开放曲线、复杂切口合并、已提交曲线持续参数化重构、原版任意非平折编辑，以及剩余Wolfram输入/选项/插值及未证数值全域。没有将目标改成只验收本批功能，也未标记完成。

最大规模及所有组合性能、原版Wolfram保存Out逐点等价、连续无碰撞/曲率物理折叠、免安装EXE与原生交互、外部刻字软件导入及机器试压未验证。不操作设备、不承诺实机速度或压痕精度、不自动发布。
