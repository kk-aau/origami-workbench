# 镜像参数与逻辑原面续接（2026-10-09）

入口：**折痕编辑 → 纸张属性/选区 → 参数构造组 → 编辑已有移动/旋转组 → 左右/上下镜像**。预览会重算后续细分；复制组也可逐份改镜像并增加副本。源码运行版更新，免安装包尚未更新；完整 Origamica 目标仍在进行。

修复上一批已确认的问题：前组由移动/旋转改为镜像后，后续细分不再因几何左右方向翻转而拒绝定位原面。旧工程的方向侧引用在原参数仍有效时补齐身份，再修改前组；预览和取消不会写入升级。

| 情况 | 当前效果 |
| --- | --- |
| 移动/旋转改镜像 | 保同一来源面，CP/已有FF沿原变换和细分规则重算，不累积旧偏移。 |
| 两级细分 | 镜像前置时子面生成顺序可能反转；以两端所属边及来源边共同确认实际子面，再刷新身份，不固定使用旧子面序号。 |
| 单份副本镜像 | 每份使用独立来源；增加其它副本后，后组仍作用于原指定副本。 |
| 孔洞、弱切口 | 保源边/材料侧身份及原几何规则，孔洞不补线，切口不焊接。 |
| 旧v7 | 兼容旧的方向侧字段；在改变或删除来源前用真实当前材料迁移，无法唯一确认时拒绝，不推断其它纸片。 |
| 保存与历史 | JSON/FOLD重开可再换镜像；取消、一次撤销/重做和来源删除保护保持。 |

引用保存来源边相邻面的序号，并通过每一步真实的原面关系追踪当前后代；该序号属于来源操作，不是当前全局面编号。方向字段按来源面更新。若构造生成子面顺序变化，只有两端所属边和来源边共同确定唯一子面时才刷新；没有唯一依据仍拒绝。旧格式先通过原有独立几何重算核查，再在副本模型中补充身份。没有按邻近坐标重绑、移动端点或额外压痕。
