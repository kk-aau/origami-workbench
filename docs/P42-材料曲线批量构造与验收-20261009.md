# 材料曲线批量构造与验收（2026-10-09）

本批增加圆/椭圆及闭合三次贝塞尔曲线的可视批量构造，按明确毫米误差生成可采用的 LINE CP，并核对真实材料面、折后位置及普通导出。完整 Origamica 复现目标继续，未打包、发布或操作设备。

入口：镶嵌结果采用为索引材料后 → 折痕编辑 → 绘图工具 → 纸张属性/选区 → “材料曲线批量”。本入口沿用原画布与材料编辑事务，不新增持久工作区。

| 操作 | 行为 |
| --- | --- |
| 圆/椭圆 | 毫米中心、两轴半径与旋转；相等半径为圆。拖动中心或X轴方向点，精确输入参数，可按刻度键盘微移。 |
| 闭合贝塞尔 | 四节点初始示例，每节点有端点与入/出控制点，闭合共享端点身份；直接选点拖动或改坐标。核心合同接2–16节点，当前界面调整初始四节点。 |
| 多曲线 | 当前材料面内最多16条，可添加、删除与逐条赋型；相交和嵌套在同一次图中拆交点并生成真实子面，保纸张孔洞及材料身份。 |
| 误差与预览 | 用户指定正毫米误差。紫色为真实SVG源曲线，青色为实际离散折痕；预览显示段数和误差上界。超过128输入点/256输入边预算明确拒绝，不截断或自动降低精度。 |
| FF及仅CP | F细分可保持原面刚性FF；M/V/U仍走完整材料/回展验证，不兼容结果不能保旧FF。用户明确选择仅CP后，采用真实CP并删除旧FF。 |
| 历史及提交 | 一次拖动一条草稿历史；指针取消恢复整次操作。参数草稿变化即失效旧预览，直接预览读取当前数字；应用独立重放意图，整批一次工程撤销/重做，取消不改源材料。 |

曲线不得跨当前纸边、孔洞或其它部件，不能以包围点/跨空白桥接代替实际材料。数值离散线段构成曲线的近似 CP，不把输出称为连续曲率的精确物理折叠。其界面F/M/V/U选择不改变加工优化入口“仅压痕、普通DXF LINE”的既有合同。

## 数值与来源核对

椭圆参数曲线满足 `||γ''(t)||≤max(rx,ry)`，每个弦段的线性插值误差界为 `M Δt²/8`。从8段起以4段递增，选择满足误差的段数。贝塞尔按de Casteljau二分，利用控制点到有限弦段的最大距离约束整段曲线的凸包偏差；不是仅用中点误差，也不使用无限直线距离掩盖回折。二分保原端点，不吸附、平均或改动原材料坐标。

真实浏览器回读曾发现原生 `Math.sin/cos` 与Node末位不同。本批以固定区间归约与有限级数计算椭圆CP坐标，并保坐标舍入余量；计数由同一误差不等式确定。解析源SVG仍表达椭圆/贝塞尔形状。浏览器、来源重放及本地测试的六组实际CP现逐值一致，没有放宽导出位置、尺度或覆盖核对容差。单元测试另禁用原生三角函数，核对采样不依赖它及整周旋转不改变几何。

`metadata.materialCurveConstruction`记录本次意图、采样图、误差界及新增边ID，作为最后一次曲线操作的来源资料；材料图仍独立核验，并非以此字段认证几何、FF或层序。当前它不是跨后续任意编辑持续求值的参数化模型，也不是Wolfram `DiscretizeCurveUniformly`全部语义的逐式移植。原版一般曲线表达式、均匀弧长/插值对象及任意非平折功能继续在目标余项中。

## 高偶度与剩余目标

本轮高偶度诊断改变的是数值候选搜索：尝试中心FF面凸性不等式，保持源点/赋型/正下界，最后仍检回展、CP几何与局部条件。共26条记录（含6/8度对照），其中14条十/十二度记录仍无已认证CP，两组未找到初始拓扑。对照也未得到有效新候选，不能把这一启发式称为可靠求解器，更不能据此断言数学无解。生产内点4/6/8度合同保原SHA，高偶度仍未完成。
