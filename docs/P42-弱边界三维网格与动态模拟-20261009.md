# 弱边界三维网格与动态模拟（2026-10-09）

本批把已能构造的弱边界 CP 接入现有三维模拟入口。支持下表中的实际材料子域；完整 Origamica 复现目标仍在进行，免安装 EXE 未更新。

| 功能 | 当前效果 |
| --- | --- |
| 真实独立切口 | 内部孤立切口、边界悬空切口、交叉树及外边到孔洞的单桥可生成模拟网格。切口两侧各自拥有三角面，不按相同坐标或端点焊接。 |
| 开放 F 平面线 | 保留源顶点和每一段原线；与已有 M/V 铰链接合后可实际驱动 CPU/WebGL2 数值模拟。 |
| 悬空 M/V | 目标折角进入数值求解器，允许观察应变和形变；不把数值形变认作有效刚性平折。原二维自铰接拒绝规则保持。实际浏览器已验证悬空 M；全部悬空 M/V 参数并未遍历。 |
| 孔洞与独立部件 | 按实际索引轮廓三角化，原孔洞保持空白；重合坐标的独立材料仍保持独立身份。 |
| 反向轮廓 | 三角化的私有输入先统一绕向，再还原源绕向，避免只翻输出三角形时选错同坐标切口角点。四组反向切口专项覆盖。 |
| 现有三维交互 | 沿用目标比例、暂停/继续/复位、正背/立体视角、材质颜色、纸面/折线/透视/应变显示及导出。 |
| FOLD/OBJ/STL | 完整当前三角网格和有限三维坐标；FOLD 保精确面边关联，重开重新校验。当前状态不携带未测量的目标折角或旧平折层序。 |
| 原 CP 与加工文件 | 模拟使用独立副本；八组真实返回文件逐值核对 CP 不变，普通 R12 LINE DXF 与原导出逐字节一致。三维模拟的既有归一化坐标不能当作毫米加工坐标。 |

## 实现与保留规则

新增模拟专用三角化直接使用实际逐角边界，保每个源顶点编号、源边编号前缀、赋型和驱动目标。内部辅助边只存在于模拟副本，赋型 F、折角 0；不得跨原面建立辅助边。先检查源实际边方向、面所有权、单顶点材料扇、孔洞/弱绕行，再独立检查三角片的面积、覆盖、边关联与源顶点完整性。

模拟器新增默认关闭的 `preserveTopology` 选项：经过验证的弱网格按显式 `faces_edges` 读取边，不再按端点查找或合并共线源段。普通 CP 的原网格清理和共线简化流程不变，原测试继续覆盖。任何清理造成原顶点/边/面变化、无效目标或 Float32 坐标塌缩均拒绝，不以填孔、焊接或删结构换取显示。

`zhezhi_simulation_mesh` 标记只表示要求走显式网格流程，并非可信证书。重开文件必须重新检查实际三角片、顶点扇和全部边关联。层序计算使用的私有面积图没有被当成三维网格。
