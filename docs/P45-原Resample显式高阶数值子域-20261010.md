# 第45节：原 Resample 的显式高阶数值子域

本批将原生一般展开的实际重采样扩展到显式 `InterpolationOrder=2/3/4`、`InterpolationPoints=4–256`。四阶段、真实插值导数、原曲线/域/初值保存及实际预览均可使用。它是确定的局部多项式数值实现，**没有宣称 Wolfram 默认插值算法、Automatic 点数或高阶内部 stencil 已完全等价复现**。

这是对上一批“仅1阶明确子域”的增量；前批原1阶输出与连续旧入口仍通过原 fixture 回归。原未知 Automatic 点数没有被替换成固定32，也没有新增用户未选择的自动密度政策。

当前官方 [FunctionInterpolation](https://reference.wolfram.com/language/ref/FunctionInterpolation.html) 说明结构域默认阶为3，但没有给出这里可验证的原内核具体点数。[ListInterpolation](https://reference.wolfram.com/language/ref/ListInterpolation.html) 的阶和方法默认为 Automatic，支持 Spline/Hermite，且值连续不保证导数连续。[InterpolationOrder](https://reference.wolfram.com/language/ref/InterpolationOrder.html) 将显式 n 定义为点间 n 次多项式。这些证据支持阶数意图，不能证明本工作台局部 stencil 与 Wolfram 默认方法相同。

原行号摘录、笔记本 SHA256、官方来源及上述明确边界保存于隔离 `evidence/original-higher-resample-source.txt/.json`。没有运行 Wolfram 内核。

## 实际算法和回读

| 项目 | 实际行为 |
| --- | --- |
| 点数 | ip 表示间隔数，包含两端共 ip+1 个样本；显示段数仍独立。 |
| 每个原单元 | 使用连续 order+1 个样本；起索引为 `cell-floor(order/2)`，在端点钳制至可用范围；完整原域不改变。 |
| Python | Lagrange 基函数及解析导数。 |
| 独立 TS | Newton 差商和 Horner 值/导数，算法不同；节点值精确保留原样本。 |
| 数值连续性 | 值在原采样节点连续；一阶导数可能跳变。主行/网格采用节点右导数，末端左导数。 |
| 节点核验 | 每个内部采样节点分别核验左/右导数，纳入实际 EFG 残差；来源戳保存基线、母线及标架导数最大跃差与两侧核验数。 |
| 初值与标架 | query 和 initial 保存原 ODE 种子；实际采样点/切向偏差另明确返回并显示。没有加 ui 样本、移点或归一化标架来隐藏偏差。 |
| 范围 | 原源式安全表达式及原双向 ODE 数值恢复保持。没有域外外推、默认自适应、自动点数或猜测的全局样条替代。 |

沿用真实 `POST /api/tessellation/curved-flatten-generic`，如原参数后增加：

```json
{"resample":true,"interpolationPoints":8,"interpolationOrder":4}
```

API及UI保留显式阶数；缺项、Automatic、非整数、0、5以上阶数、采样预算外值均明确拒绝，不降为1阶或改为固定32。高阶结果的 `polynomial.wolframDefaultAlgorithmReproduced`、`originalAutomaticPointsReproduced` 均 False。现有 `source.interpolationReproduced` / `wolframOptionsReproduced` 仍 False；未把当前可用算法计作原完整运行时。

主 `sample/grid`、目标预览及目标 b′/d′ 均是真实高阶插值结果。来源戳全部样本、阶数、stencil、单侧导数跃差及误差由 TS 独立恢复核验；篡改阶数/stencil/导数/核验数或默认算法主张均拒绝回读。

产品现有一般展开窗口增加 InterpolationOrder 选择，提供1/2/3/4阶；真实源 JSON 下载和重新载入保存完整原式、坐标、原域、初值、点数与阶数。连续曲面输出未赋予采样纸带正则性、精确等距、CP采用或精确 FOLD 认证。
