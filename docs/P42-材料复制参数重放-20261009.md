# 材料复制参数重放（2026-10-09）

入口：**折痕编辑 → 纸张属性/选区 → 复制材料部件**。默认保存参数组，采用后在“参数构造组”重新打开复制组；数量、偏移、角度、比例和镜像可修改，后续构造顺序重算。源码运行版更新，免安装包尚未更新；完整 Origamica 目标仍在进行。

| 用户操作 | 结果 |
| --- | --- |
| 统一复制 | 设置1–64份副本；偏移逐份累加，旋转/比例/镜像每份相同。原件CP/已有FF保持原值，副本使用原普通复制规则，不焊接重合坐标。 |
| 逐份调整 | 切换“逐份调整”，分别设置每份的X/Y、旋转、比例和镜像；数量可增减，不同参数重开后无损回填。 |
| 修改已采用副本 | 从复制前阶段重新生成，偏移不累积；后续变换、射线和切开继续引用对应副本。 |
| 增加/减少数量 | 增加副本保已有副本身份；删除被后组依赖的一份拒绝整次修改，不转绑其它纸片。 |
| 辅助线 | 保留原“包含已选辅助线”；保存并重算时只生成对应副本一次，已复制辅助线也可作为下一组复制源。 |
| 取消和历史 | 采用前预览，取消不修改；一次撤销/重做恢复全部结果。独立复制可预览删除，后组依赖复制时删除拒绝。 |
| 普通流程 | 关闭“保存参数组”沿用普通复制几何；既有工具栏和定位复制流程保留。 |

## 保存和来源

v6接受v1–v5。每份副本使用独立稳定ID，材料边与辅助线分别编号，辅助线开关不扰动材料副本ID。副本来源引用记录份号及该份源边数量；增加其它副本不改变已有引用，来源被删或真实分段身份改变明确拒绝。原件的来源后代不包含副本，防止后续原件射线错绑副本。

复制后面的面保留原面来源，可与曲线、线网、直线、射线、批量、切开、粘合和变换组共同保存/重算；组及归档各限8。保存到JSON/FOLD，普通DXF沿用原R12 LINE导出器及单位/一次Y翻转，不增加加工指令。

v6保存辅助线几何快照，避免重算时将已生成辅助线作为当前额外输入再次复制。辅助线的显示颜色修改保持；在参数组外增删或改辅助线几何会使旧配方失效，新记录明确归档旧配方并以实际当前材料建立新模型，不能覆盖当前工作。
