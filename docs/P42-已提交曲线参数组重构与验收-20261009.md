# 已提交曲线参数组重构与验收（2026-10-09）

本批补齐有限闭合曲线的持续参数编辑：从创建时保存的材料基底顺序重算各组，避免修改参数后旧曲线仍留在 CP。完整 Origamica 复现目标继续，免安装 EXE 未更新。本批不打包、发布或操作设备。

入口：镶嵌采用为材料 → 折痕编辑 → 绘图工具 → 纸张属性/选区 → 参数曲线组。新建仍使用“材料曲线批量”。

| 操作 | 最终行为 |
| --- | --- |
| 编辑已提交组 | 加载该组之前的材料和原曲线参数，继续使用毫米刻度、控制点、精确输入及 CP/FF 预览；采用时重建完整材料，包括后续组，不叠加旧折痕。 |
| 编辑前组 | 后续组保留配方和组身份，依据原材料面祖先及严格内部固定点重新绑定子面；不沿用可能指向其它面的旧编号。无法唯一绑定时拒绝，不猜测。 |
| 删除组 | 先重算剩余组并预览，明确应用后一次工程撤销可恢复；取消不改实际工程。 |
| 保存与重开 | JSON/FOLD 保存基底、配方和实际材料戳；重开后独立重放核对，继续编辑。普通 CP/DXF 不含参数模型，仅导出实际线段。 |
| 组外材料修改 | 材料几何、赋型、折后姿态或起始面变化后拒绝旧组重算，保护后续工作。用户明确“从当前材料建立新模型”时归档旧模型，当前实际材料成为新基底。 |
| 辅助线与标注 | 当前 A 线、对象、名称、纸张设置和额外元数据保留；颜色按仍存在的线段 ID 合并，不能保证已被替换线段的所有旧身份继续对应。 |
| 容量 | 最多 8 个活动组和 8 份归档；到达容量明确拒绝，不截断、不静默清除。删除后新组编号继续递增，不复用旧组身份。管理列表紧凑展示八组。 |

新模型不把附件或保存文件中的快照当作构造证书。先验证基底及实际图，再重放每组，核对最后 CP、FF、起始面和材料边绑定。最终采用继续经过编辑提交的独立意图重算。共享材料边、重合切口和独立纸片身份沿用上一轮精确拆交与材料拓扑合同；新增线段加组命名空间，普通 DXF 的坐标、毫米单位、Y 轴转换及 R12 LINE 格式保持原实现。

旧文件若没有创建时的材料快照，不能凭最终曲线反推出原基底和所有历史配方；其折痕保持静态，可明确从当前材料建立新模型。归档仅保资料，本批未提供任意历史材料编辑栈的重放。
