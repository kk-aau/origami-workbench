# 横截反射（开发版 v0.9.2，未打包）

入口：“镜像 / 变换 → 横截反射”。当前 33 个实际工具。沿用原紧凑多列工具栏、中文步骤和鼠标旁提示。

1. 点击横截轴第一点。
2. 点击第二点，让原线端点位于横截轴内部，形成 T 形连接。
3. 核对紫色批量预览，点击“确认横截反射”或任一紫色结果线。

横截轴只作参考，不加入工程。每条符合条件的原线，以自身端点为起点，关于横截轴反射其方向，并延伸到前方第一条非辅助线或纸边。截止范围使用原工程，不让尚未提交的预览线互相截断。保留原线、原山谷／辅助／边界类型与折角（含未知角），不采用顶部新绘制预设。

仅处理原线端点在横截轴内部的 T 形连接；仅穿过未分割线身的 X 形、在横截轴端点相接的 L 形、共线、延长线相交均不计入。已有真实分割后的原图按实际小段判断。同型同角重合部分去除；冲突重合或任何一条缺少截止，整组不生成。边界保护开启时不复制边界原线，但纸边仍可作为截止。

右击／Esc 取消当前操作，不同时删除；切换工具、修改几何会清空参考。结果和交点真实分割一起撤销，支持保存恢复。尚未照搬原版受限拖画手势；本工具不是连续反射，连续反射仍待开发。
