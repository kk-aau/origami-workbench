# 选区变换核验 · 2026-09-20

## 修复

选区镜像使用独立的旧网格计算：始终限制在纸张矩形内，未检查缩放可见性与纸张孔洞。浏览器在旧构建上复现：开启全画布网格后，纸外可见网格点仍无法作为镜像轴点（`output/selection-browser-before.log`）。

`CreaseCanvas.tsx` 的镜像轴网格拾取现复用 `drawingAnchors()` 和 `restrictedDrawingPoint()`：全画布模式允许纸外可见网格；纸内模式遵守纸张轮廓与孔洞；关闭或缩小到隐藏的网格不参与定轴。保留已有顶点优先、线身切换选区、吸附开关和确认提交规则。
