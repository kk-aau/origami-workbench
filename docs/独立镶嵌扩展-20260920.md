# 独立镶嵌扩展 · v0.11.0

按第二方案继续在 Python／TypeScript 工作区独立实现，无需 Mathematica。九类构造均接入真实后端、候选检查、预览、采用、工程保存和参数恢复。没有复制或翻译 Origamica 笔记本程序。

## 已实现范围

| 入口 | 当前能力 |
| --- | --- |
| 单元扭转 | 3–12 边正多边形及可编辑凸多边形，双向旋转、偏置、内接比例、1–4 个镜像兼容单元连接 |
| 周期拼接 | 方格、三角格、六角格，2–6 行／列，共享边与顶点 |
| 原始—对偶 | 保留原有三种规则构造；显示母结构与对偶叠加，编辑对偶目标位置 |
| 混合平铺 | 八种非正则阿基米德顶点构型，以及 pgg、4.6.12／3.4.6.4 双均匀和一种等边五边形平铺 |
| 非周期 | Voronoi、Delaunay、Penrose 菱形及边界半菱形、Goldberg 五重中心；种子可拖动、增删和精确输入 |
| 自定义 | JSON 网格、从当前折痕提取面、拖动顶点、横纵重复；要求连续无孔的凸多边形网格 |
| 环状镶嵌 | 3–16 扇区、1–4 环、半径倍率 |
| 铺石镶嵌 | 方格／矩形、三角格、六角格，平行双褶与周心分子，褶宽可调 |
| 盒褶编织 | 正交条带，交替／两列分组／三列错位，宽度与山谷反转 |

对偶编辑求解距离目标最近且与母边垂直的正向对偶；拖动目标不一定能原样满足约束。未找到稳定解或局部赋型无解时给出错误，不返回可采用的假结果。

种子数量 4–36，Penrose 细分最多 3 层，Goldberg 最多 2 层。自定义输入最多 96 点、96 面，重复后最多 192 面；共同计算入口限制母结构最多 256 面。

## 与原版的差距

这是同类功能的独立实现，**不是 Origamica 15.0 全部函数的等价移植**。当前仍未实现／未验证：

- 原版四边形 split-twist 的精确构造：现在“分裂数”是镜像单元沿铰线连接。
- Resch 星形、规则星形及 Brocard 专用构造。
- 全部双均匀平铺目录；目前只有表中两种附加构型。
- 任意方向线集的 woven 构造；当前仅为正交盒褶编织。
- 任意拼块的交互组合／变换；目前支持网格编辑和矩形周期重复。
- 与 Mathematica 原版输出的数值等价性和完整原例对照。

笔记本中的管状、壶状及曲面等独立三维专题也未移入本次镶嵌模块。不得把入口数量或测试通过解释为原版全功能完成。

## 交互和检查

九个入口使用三列紧凑布局，参数成对排列；1000×720 的九类默认面板均无需滚动或翻页。说明、检查详情和几何编辑在独立窗口中打开。母结构黑色、对偶青色、编辑参考紫色。

预览不修改当前工程。参数改动后旧候选失效；计算中、几何失败、局部条件失败／不完整时不可采用。没有内部顶点的小网格显示“无内部顶点”，几何通过后允许采用。工程 JSON 保留参数、算法来源、检查信息，可重新导入恢复；损坏的类型、范围和面索引不会进入控件。

几何和局部 Kawasaki／Maekawa 检查不证明全局层序、连续折叠路径或实物可折。采用后可继续使用既有平折分析。

## 实现与来源

新增模块为 `backend/tessellation_meshes.py`、`tessellation_advanced.py`、`tessellation_flagstone.py`，编辑界面为 `TessellationEditor.tsx`。母结构生成、正向垂直对偶投影及受限局部山谷赋型分别使用独立几何、SciPy 线性／约束优化和整数求解。Shrink-Rotate、部分平铺与 Goldberg 运算调用固定版本 MIT Pleat。

数学参考：[Penrose 黄金比例细分说明](https://preshing.com/20110831/penrose-tiling-explained/)、[P. Vitelli 的铺石构造说明](https://pvitelli.net/2020/01/20/origami-flagstone-tessellations/)。没有将这些文章或笔记本源码打包进程序。Pleat 的本地修复记录见 `vendor/pleat/UPSTREAM.md`。

## 验证与运行

测试覆盖所有九类、额外构型、大小规模、正反向、多边形偏置、种子重现性、面拓扑、局部条件、非法输入、工程往返及旧接口。真实浏览器验证了拖动／增删种子、编辑母结构／对偶、JSON 错误保护、全部入口无滚动、实际下载再导入。

最终通过：`npm test` 共 964 项（928 个前端／几何单元测试、3 个桌面模块测试、19 个 Python 测试组、14 个真实服务测试）；浏览器 102 项（九类流程 59、变体／指针 16、原有流程回归 23、最小网格 4）；源码 Electron 搭配独立引擎 69 项。`npm run build` 与 `npm run package:tess` 均成功。主 JS 仍保留原有分块体积提示，未做发布安装包验收。

日志在 `workbench/output/advanced-*.log`，桌面结构化结果在 `workbench/output/advanced-desktop-final/smoke-result.json`。浏览器脚本在 `workbench/scripts/verify-tessellation*.browser.js`，截图和往返工程在项目根目录 `output/playwright/`。

源码、`dist` 和独立计算组件更新；在 `workbench` 运行 `npm run desktop` 使用。按项目日常开发约定没有重制安装包，`release/` 的 v0.9.2 EXE 不包含本次功能。
