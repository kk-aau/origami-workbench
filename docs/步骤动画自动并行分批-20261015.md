# 步骤动画自动并行分批

日期：2026-10-15

## 行为

同一个绘图步骤包含多条折痕时，动画先尝试完整并行或必要的联动；无法同时执行时，再自动规划可安全执行的批次。每批预折完整折下到原目标 ±180°，沿同一分支展开，再进入下一批。

| 输入 | 实际规划结果 |
| --- | --- |
| 两条交叉对角预折 | 两批，每条完整对角线的两个子铰链一起折下、展开 |
| 四角各两条角平分线，共八条预折 | 四批，每批同一个角的两条线并行 |
| 前一步留下 X 形已有折痕，第二步增加四角八条预折 | 保留旧折痕，第二步仍为同角两线并行的四批 |
| 刚性上允许并行，但实际会互相阻挡的两条预折 | 分成各自折下、展开的两批 |
| 所有折痕确实可一起执行 | 保留原来的并行或联动路径 |

动画进度条下显示当前批次、折下或展开状态，以及可跳转的批次按钮。每批按四秒的基础时长播放，可继续用原来的速度控件调节。

新折痕在各自第一次动作前隐藏；预折展开后保留；拖回其动作前重新隐藏。已有折痕始终保留。默认固定中央区域时，只移动该角外侧的纸瓣；显式选择其他固定侧时，继续尊重用户选择。

分批是本次动画的临时运动计划。原绘图步骤、前后 CP、文件内容、固定侧和折痕作用范围不因此被修改。

## 原问题与实现

原规划把所有预折痕强制安排在全局进度 50% 同时到达峰值；后备串行策略也只是先折下全部铰链，再展开全部铰链，无法表达独立批次。交叉对角线及四角预折因此会被误当成不可执行的单个动作。

| 环节 | 改动 |
| --- | --- |
| 运动指令验证 | 每条预折独立验证一次有向单峰往返；普通折痕保持单调，未参与的旧折角不能变化 |
| 完整折痕识别 | 材料上相连、材料轴与起态物理轴共线、起角/终角/预折方向同义的子铰链视为同一轴组 |
| 并行规划 | 优先搜索较大组合，相同大小优先共享材料纸角；失败时回溯更小组合与先后顺序 |
| 安全检查 | 每个接受的完整方案仍通过材料连接、固定点、边长、折角、起始层序与连续碰撞认证 |
| 计算边界 | 候选数量、几何尝试和总搜索时间均有上限；八轴以内枚举组合，更大输入保留单轴与低阶组合的搜索配额，不宣称全局最优 |
| 失败剪枝 | 仅在失败时间或整个失败区间严格落在某批内部时，缓存相同起角与轴组的本轮失败；批次边界不作错误局部归因 |
| 元数据 | 批次起止、峰值和参与铰链根据真实路径重新计算；伪造批次信息被拒绝 |

仍无法证明安全的模型会保守拒绝，不使用抽帧无碰撞、放宽容差、99% 截断或增加间距作为替代。

## 连续碰撞证明

四角模型暴露了旧算法的两个限制：重复计算所有顶点的区间投影，以及没有共享顶点编号的接触纸片缺少移动材料平面的证明。

- 对完全不动的相对铰链跳过恒等变换；对共用的符号分母做等价化简。
- 精确缓存区间、投影方向和原点，按调用方实际访问的顶点惰性计算投影界；不量化方向，不改变区间界公式。
- 对没有共享顶点的纸片，以完整材料三角形定义移动平面，证明另一个三角形的三个顶点在整个区间保持同侧。
- 跨多个运动阶段时，必须始终使用同一个材料平面或材料轴及相同一侧；禁止把前一阶段的正侧与后一阶段的负侧拼成一份错误的安全证明。

最后一条由真实负例确认：两片纸在 25% 的阶段交界接触并交换所在侧，旧的逐阶段拼接会漏判；现已正确识别为碰撞。共享顶点与非共享顶点两类均有回归。其他负例还包括真实穿透、75% 内部接触换侧，以及只在起点和终点合法的路径。
