# 第 36 节通用圆内接母图的工作区来源

原版依据：`tmp/Origamica-15.0-reference.nb` 的 `UnitCyclicPolygonVertices` In[378]，以及 In[354]–In[359] 的奇偶内角补全与中心弧角保存输出。工作区原先只有四／六／八边形扭转专项，通用母多边形公式虽在后端 `tessellation_unit_cyclic_polygon.py` 实现，不能从拼块组合直接选用。

现在“自定义 → 拼块组合 → 原版 tilespec／整组对接”可把**已有严格凸圆内接拼块**转换为“圆内接母多边形 · In[378]”，并编辑 3–24 边的独立内角。奇数边自动补最后一个角；偶数边自动补最后两个角，以第 2–n 边的一条数值边长选定交错中心弧角自由度。第一边固定为单位长度，现有拼块的位移、转角和倍率在转换时保留。这个 `UnitCyclicPolygonTile` 名称是工作区存储原版顶点函数参数的来源包装，不宣称笔记本有同名拼块类型。13/24 边来源严格回读与篡改拒绝已有专项验证。

来源记录同时保存输入内角、定长边值／编号与重新计算的顶点；`readTileSpecs` 会按原公式重建并逐顶点核对，拒绝改过角度、边长或顶点但未同步重建的工程。它仅是母结构来源，后续统一／逐块扭转仍走现有几何与层序门禁，不能因为母多边形成立就认为折痕可平折。

`tests/app/unitCyclicPolygon.test.ts` 将 n=3、5、6、8 的关键坐标与独立 Python 原版公式输出逐点比到 `1e-9`，`tileSpecs.test.ts` 验证五／六边来源保存回读与篡改拒绝。浏览器从默认四方拼块转换后编辑内角，再恢复并采用拼块组合；重新打开来源编辑器仍显示圆内接类型和 90° 内角。原版没有这些任意输入的可机读 Wolfram 顶点 Out，故这是数值公式和工程合同验收，不声称 Mathematica 任意符号表达式或各边数的扭转 CP/FF 全域已复现。
