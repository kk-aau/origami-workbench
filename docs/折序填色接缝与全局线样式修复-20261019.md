## 问题与处理

| 用户现象 | 原因 | 修复后的行为 |
|---|---|---|
| 第 7 步主图和导出出现淡蓝细斜线 | 同一不透明纸面的三角形分别填色，共享边抗锯齿露出下层蓝色纸面 | 同一物理面内连续同正背材质的三角形使用一条复合路径填色，消除内部接缝 |

| 垂直符号蓝色控制点拖动只移动符号 | CAD 距离夹点的原拉伸动作等量移动直角线的全部顶点 | 蓝色控制点围绕红色锚点缩放，保留方向和锚点 |

## 填色范围

不改变 CP、纸面几何、三角网格、折痕或层序。合并只作用于不透明展示，且保持每个面的原绘制顺序。正背材质即使采用相同颜色也不跨组；透明／透视状态保留逐三角形叠色。真实纸边、折线、撕窗及正背色边界保持原语义。

用户第 7 步只渲染纸面即可复现旧淡蓝线。独立对照中，修复移除 1,302 个蓝偏像素，没有新增蓝偏像素；移除像素到原三角共享边的距离均小于 0.44 像素。第 7、17 步修复实现与独立候选逐像素一致。此结果说明问题来自填色接缝，不能据此推断 CP 无法压平。

## 全局样式与单线例外

| 操作 | 生效范围与数据约束 |
|---|---|
| 顶部类别栏修改颜色、粗细、线型 | 仅修改该类别对应字段的全局显示偏好；已有和后续线条继承它 |
| 右侧选中线段外观 | 只把本次修改的字段标记为单线例外，其他字段继续继承 |
| 使用全局样式 | 清除选中线段的单线例外，恢复该类别样式 |
| 全局显示设置 | 持久化于应用偏好；不写工程、不新增撤销事务、不重算 CP 或纸面 |
| SVG 与 PDF | 使用同一显示解析；PDF 在导出开始时冻结调色板，多页导出不混用中途修改的样式 |
| 旧偏好与旧工程 | 保留原格式版本；旧自定义偏好按非初始字段迁移为全局字段。旧线的原始外观值保留；新单线例外使用可选字段列表保存 |

拾取与橡皮擦按显示线宽计算，拖动仍返回原始绘图对象，避免把派生的全局颜色写回工程。CP 编辑和刷新按纸面保留单线覆盖，不合并继承范围不同的手柄。三维步骤动画不经过二维线类别渲染，本轮未改变三维材料颜色。
