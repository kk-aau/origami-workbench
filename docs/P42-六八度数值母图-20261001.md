# P42 六／八度数值母图（2026-10-01）

既有有限母图入口现接内点四／六／八度。六、八度母点按原式生成多个**四度 CP 点**，并非把原四反射条件套在六、八度 CP 点上。已验证的六度圆与八度椭圆例生成有效 CP／FF，但整片层序为 `no-solution`，只读预览，禁止采用。入口扩展不等于任意这些度数的 TGraph 都有可用根，也不等于已复现原 Wolfram `FindMinimum` 的具体最优解。

## 数值初始嵌入预算

仅 graph 模式且存在六／八度内点时启用额外初始化。四度图、旧 lines/chord/random、In[3437] 路径保持此前输出完全一致。

先运行已有的小负初值序列；再依次尝试独立 `di/db` 取值 `.1,.5,1,2,3,5,8,10,12,16,20,30,50` 的 169 对候选，共至多 170 **候选轮次**（首轮包含旧探针序列）。候选只代入同一原式 affine newverts，不改变源点、边、面发现顺序、山谷指派或最终正褶宽约束。相同循环邻接与面集合只求一次；新拓扑仍走已有四个 FF 正初值和全部 CP 校验。

source 保存 `topologyProbe:[di,db]`、`topologyProbeBudget`、实际 `topologyProbeAttempts` 与 `topologyChartsSolved`，用于重现数值初始化诊断；它们是结果证据，不是输入来源或新的产品参数。输入仍保存真实 `graph`，不虚构全局 lines。

失败报告最深实际阶段：拓扑／内缩（未进入方程，无残差）、反射／周期、平折展开或 CP 几何；后三者保留最小方程最大残差。170 轮耗尽明确是当前算法预算未找到有效 CP，**不构成数学无解证明**。非法來源、奇度或本轮未接的 ≥10 偶度仍在原入口拒绝；普通非凸外边界／非凸面、切口、未拆交叉等门禁不放松。
