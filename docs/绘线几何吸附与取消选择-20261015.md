# 绘线几何吸附与取消选择

日期：2026-10-15

| 场景 | 行为 |
| --- | --- |
| 普通画线或连续折线接近垂直方向 | 自动沿参照线的法向吸附，显示直角标记、参考线高亮和“垂直 · 90°” |
| 画线终点接近参照线上的垂足 | 吸附精确垂足，在实际交点显示直角标记 |
| 从两条线的公共顶点沿内外角平分方向画线 | 自动吸附角平分线，显示两段相等圆弧及相同刻线 |
| 端点、交点与几何关系同时靠近鼠标 | 优先保留真实端点或交点；仅在最终线段满足关系时显示几何标记 |
| 按住 Alt / 取消“吸附” | 暂停自动吸附及几何标记；原地按下、释放 Alt 也立即更新 |
| 按住 Shift / 指定预设角度 | 保留用户指定的方向限制，自动几何不会把线段拉离该方向 |
| 右拖删除、右击取消当前画线 | 清除当前草稿，保留普通/连续画线模式、线型和折痕用途 |
| 右击、Esc 或改用其他工具 | 可取消固定纸面的黄色提示，固定约束仍用于下一步 |

吸附参照使用当前纸面的显示坐标，包含实际纸边、独立绘线及联动预览；排除隐藏纸面、被上层完全遮挡的纸边，以及不再显示的旧联动线位置。纸面孔洞与背景线按真实覆盖范围处理。准备参照在静态 memo 中完成，鼠标移动只计算附近候选。

接近鼠标的交点另作局部检测，避免复杂图形中仅检查最前 120 条线而漏掉后画折线的交点。几何算法先做有限线段和共点检验，并限制吸附距离及角度；重合、反向重合、零长、平行和附近但不共点的线不会产生虚假角平分标记。

直角、等角和文字提示仅属于当前交互，不写入工程，也不进入 SVG/PDF。标记按屏幕尺寸绘制，几何随画布旋转，中文标签保持直立。点击两端、按住拖画和连续折线均使用同一终点求解，预览与提交一致。

固定约束与黄色提示单独管理。固定完成后可查看提示，右击或 Esc 取消提示不会清除 `foldLink.fixed`。重新进入“固定侧”可再次查看、修改原固定位置。
