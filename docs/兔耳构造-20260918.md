# 兔耳构造

开发版 v0.9.2，未打包；工具栏“精确作图 → 兔耳构造”。

依次点击三角形三个顶点，再点击“确认兔耳构造”或紫色结果线。三个顶点各连接到三角形内心，全部采用当前新绘制线型与默认折角；紫色三角形外框仅参考，不写入工程。构造中可以修改山谷预设，不丢失已选点。

共线、近共线、重复顶点不能构造，保留已选有效点以便重试。同型同折角的已有部分去重，不同型或折角的重叠整组拒绝；完全重复结果不再生成。相交线会真实分割，构造及分割一次撤销。右键／Esc取消当前操作，不同时删线；切换工具清空预览。

依据本地固定源码：`MouseHandlerInward.java`（模式INWARD_8）和 `OritaCalc.center`。原版第三次选已有点后提交；本版允许自由／吸附点，额外增加明确确认。公式采用对边长度加权内心，与角平分线交点等价；不提供兔耳的三维折叠过程，也不自动猜测各线山谷。本批未做原版动态样例运行，目录保留基础可用状态。

验证：10项新增几何单元，全量313通过；浏览器兔耳26＋连续反射24＋镜像42＋既有绘图98共190断言通过，包含紫色预览、错误输入、预设变化、右击取消、交点真实分割、整组撤销、保存恢复。构建通过，主包体积警告仍在。桌面包未重新生成。
