# Origamica 第 45 节：关联多曲折的同心圆保存示例审计

只读依据是 `workbench/tmp/Origamica-15.0-reference.nb` 第 338448–340407 行。本次没有生成五条折痕的三维曲面：保存示例内部有两处可复算的公共参数与自身参数混用，而且保存的第二折角在起点已破坏下一带的测地曲率匹配。数值复跑见 `backend/test_tessellation_curved_linked_source_audit.py`。这说明**不能凭原版保存输入严格认证整串曲面的逐侧等距和可展性**，不等于声称 Mathematica 的显示图一定错误。

## 输入契约和保存数据

原版在 338460–338477 行说明：非平凡构形少见解析解，因此直接使用数值函数；为控制长链的高阶导数级联，按等距节点用 `ListInterpolation`，而不是自适应节点的 `FunctionInterpolation`。`NLinkedFoldsNext2D` 在 338691–338918 行接受三条二维折痕 `f0,f1,f2`、前两条的公共参数映射 `q0,q1`、第一条折角 `γ0` 和区间，返回共同参数下的 `{γ1,q2}`（338557–338620）。默认插值阶数为 4，`InterpolationPoints=32`（338658–338669）；折角样值来自 338789–338841，下一条参数通过对每个样点 `FindRoot` 后再插值（338843–338915）。原版自己在 338636–338640 行提醒，投影可落到区间外，需要外推。

`NLinkedFoldsFirst3D` 将公共参数下的 `f0,γ0,f1` 及三维初始点、切向、面法向交给 `NRecoverDarboux3D`（339337–339523）；保存初值为 `(1,0,0)`、`(0,1,0)`、`(0,0,1)`（339599–339620）。`NLinkedFoldsNext3D` 按前一三维折痕及 Darboux 切向／横向、二维两条折痕、当前折角，返回三维新折痕、切向及右横向（339830–340028）。说明文字 339794–339799 写成四个返回项，但实际返回表达式 340027–340028 只有三个；因此验收以可执行定义为准。

保存的同心圆输入（339070–339211、340056–340310）为：

```text
R_i = 1 + 0.1 i，i = 0,1,2,3,4
tf_i(x) = R_i (cos x, sin x)
q_0(s) = s
q_1(s) = s + 0.1 sin(2s)
f_i(s) = tf_i(q_i(s))
γ_0(s) = 120°，s ∈ [0,π]
```

先调用三次 `NLinkedFoldsNext2D` 得到 `γ1,q2`、`γ2,q3`、`γ3,q4`（340125–340197）；然后一次 `NLinkedFoldsFirst3D` 和四次 `NLinkedFoldsNext3D`（340199–340310）。最后一次传入 `0&` 作为 `γ4`（340290–340310）。它只为第五条边界曲线生成末端 Darboux 横向，没有第 4–5 号带片；在该公式中，零角令末端右横向等于左横向，是平展的末端标架约定，不能作为另一条非零曲折面的验证。零角本身并不宣称已生成的第 3–4 号带片退化。

这些单元保存的是构造与绘图调用，后面关闭单元组，没有可直接读出的 Wolfram 三维点表或误差证书。下面的数值均是**由保存输入和源方程独立推导／本地计算**，不是 Wolfram `Out`。

## 首带可证明的局部性质

记 `e(s)=(cos s,sin s)`，`t(s)=(-sin s,cos s)`，`l(s)=-e(s)`，`δ(s)=q1(s)-s`，`h=f1-f0=a t+b l`。由输入直接得

```text
a = 1.1 sin δ
b = 1 - 1.1 cos δ
q1′ = 1 + 0.2 cos(2s) ∈ [0.8,1.2]
```

`|δ|≤0.1`，所以 `b≤1−1.1 cos(0.1)<−0.0945`。首条二维带片 `X₂(s,v)=f0(s)+v h(s)`，`0≤v≤1`，的雅可比行列式是两端值的线性插值：

```text
J(s,0) = det(f0′,h) = 1−1.1 cos δ < 0
J(s,1) = det(f1′,h) = 1.1 q1′(cos δ−1.1) < 0
```

故整条首带没有参数化焦线，且左右端点的共用曲线都正则。`First3D` 按 339475–339509 行给 `ds κg=1`、`ds κn=tan(γ0/2)=√3`、`ds τg=−√3 a/b`。`NRecoverDarboux3D` 的标架方程在 304061–304157 行给出；因此 lifted rulings `h₃=a T+b L` 的导数法向分量 `a√3+b(−√3 a/b)=0`。光滑 ODE 在此有界区间存在；作为连续方程，首带 `X₃=F0+v h₃` 的第一基本形式与 `X₂` 相同且为可展面。这个结论不把 `NDSolve`／插值的有限精度误差当成精确零，也不推出全局无自交。

## 阻断整串严格认证的三处冲突

**第一处：`Next3D` 的切向未跟随 `q1`。** 接口说明在 339744–339751 行称 `f1` 由自身参数化，但保存输入在 340075–340109 行定义 `f_i=tf_i∘q_i`，又在 340118–340123 行预计算 `cs[i]=Curve2DSystem[tf[i]]`。首次三维续接把公共参数形式的 `f[0],f[1]` 与未复合的 `cs[0],cs[1]` 一起传入（340224–340244）。`Next3D` 在 339860–339897 行直接从预计算系统取切向 `t0(s),t1(s)`，并在 339925–339990 行用它们计算 `cosρ,sinρ,tt1`。两条未复合的同心圆在同一个 `s` 的单位切向和左法向完全相等，因而该公式严格给 `cosρ=1, sinρ=0, tt1=tt0`。

可是，已证明首带的 lifted 第二条边界曲线满足

```text
F1′(s) = 1.1 q1′(s) [cos δ(s) T0(s) + sin δ(s) L0(s)]。
```

在 `s=π/4`，`δ=0.1` 弧度且 `q1′=1`，故真正的单位切向与返回的 `tt1` 相差 **0.1 弧度**。这是标架定义不变量 `tt1=F1′/|F1′|` 的直接冲突；即便两条相邻片在 `F1` 的位置上共用边界，后续使用的切向已不一致。另一个独立的源码问题是：未提供 `Curve2DSystems` 时，第二个系统的回退调用仍是 `NCurve2DSystem[f0,…]`，而非 `f1`（339872–339882）。

**第二处：二维求根在 `q1(s)` 处读取按公共 `s` 插值的折角。** `Next2D` 的返回契约明确说 `γ1` 和 `q2` 都按公共参数给出（338612–338620），并确实在公共 `s` 节点上插值 `γ1`（338789–338841）。然而下一条参数的求根函数写成 `γ1′[q1[s]]`（338843–338855），其他量则按 `s` 取值。对首步同心圆，`ds·κg=1`，因此其连续解析对应函数可写为

```text
B(s) = [1.1−cos δ(s)] / [1.1 cos δ(s)−1]
γ1(s) = −2 atan2(B(s) tan 60°, 1/q1′(s))。
```

在 `s=π/8`，`q1(s)≈0.463409759817`，独立计算得到 `γ1′(s)≈0.029102050105`、`γ1′(q1(s))≈0.065139506747`，相差约 `0.036037456642`。这组值用于暴露参数位置错误，**不是**原版 `ListInterpolation` 的导数输出。原版经过四阶插值和逐点求根，具体数值受节点、外推、数值误差和根分支影响；不能把这个解析极限直接写作原版五折结果。

**第三处：保存输入的第二折角在起点不保测地曲率。** `s=0` 时 `q1′=1.2`、首带第二条空间曲线的测地系数 `G=1.2`、法向系数 `N=√3`。`Next2D` 保存公式用 `ArcTan[1/q1′, tan(γ0/2)]` 得 `γ1≈−128.613238191°`；`Next3D` 按该角转动横向后，下一片空间侧的测地系数成为 `G cosγ1−N sinγ1≈0.604511278`，但二维侧仍需 `1.2`，差约 `0.595488722`。若只为满足起点这一不变量，非平凡角应为 `−2 atan(N/G)≈−110.569992092°`。这项反例独立于上面两个参数误用，说明简单修正缓存曲线系统和插值取值仍不足以认证保存的非零扰动五折整串。

这处反例还能写成**精确有理数**，无需求根、插值或 ODE 数值结果。在 `s=0` 与 `s=π/2`，`q₁(s)=s`，预缓存的 `tf₁` 切向恰好等于真实 `f₁` 切向，且 `γ₁′[q₁(s)]=γ₁′[s]`；前两处参数误用在这些点均消失。令 `p=q₁′(s)>0`，首带第二边界的单位切向满足 `T₁′=pL₁+√3N₁`，而笔记本折角为 `γ₁=−2 atan(√3p)`。`Next3D` 规定 `L右=cosγ₁ L₁−sinγ₁ N₁`，因此

```text
G右 = T₁′·L右 = p (7−3p²)/(1+3p²)
G平 = p
G平−G右 = 6p(p²−1)/(1+3p²)

s=0:   p=6/5，G右=402/665≈0.604511278，G平=6/5，差=396/665。
s=π/2: p=4/5，G右=508/365≈1.391780822，G平=4/5，差=−216/365。
```

测地曲率乘以曲线速度是共享折边两侧第一基本形式的内蕴不变量；两侧不相等时，任何后续折痕采样、折角插值或 3D 绘图都不能把该带片变为原二维纸的等距折叠。对 `q₁=s+ε sin(2s)` 且 `|ε|<1/2`，上述对齐点的 `p=1±2ε`；原保存公式在整个非零扰动族都不能同时满足这两个不变量。把 `1/p` 猜改为 `p` 可以修正这些点，却改变了原版函数，且不自动解决另外两处参数混用，不能标作原版完整复现。

将 `q1` 扰动置零的精确四带子域另见 `Origamica第45节关联同心圆零扰动四带子域-20260927.md`。该子域不是原保存图，其折角公式在 `q_i=s` 时才一致；三维端边相接，仍无全局层序和无碰撞认证。

## 验收边界

由源输入可严格说明首条连续带片的二维／三维对应边界、第一基本形式一致、可展性和焦线不进入 `v∈[0,1]`。从第二条边界起，返回的切向已不等于曲线导数，二维后续求根也混用参数，因此无法从现有保存输入证明五条曲线的各相邻带片都同样满足这些条件。`FindRoot` 在 338902–338915 行只用 `q1(s)` 作每点初值，并未给连续根分支或全区间误差证书；示例在 339141–339211 和 340125–340197 行还静默端点外推警告。若将来修正参数组合，应重新计算三步二维传播与四步三维传播，并逐片核验共享边界、第一基本形式、可展性及焦线位置；采样网格也不能冒充逐边精确等距的 FOLD 图。本轮不输出精确 FOLD、连续运动或无碰撞证明。
