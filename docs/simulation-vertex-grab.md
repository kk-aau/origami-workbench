# 顶点塑形与漂移修复

日期：2026-10-21。范围为三维模拟的普通顶点塑形；步骤动画不启用抓点。此次更新源码与网页构建，不生成桌面发行包。

## 当前塑形行为（同日反馈后的修正）

之前的版本只清除松手后的惯性，并自动恢复旧折叠目标求解，因此仍会弹回目标折形；拖动时只有一个约束点，整张纸还可以跟随平移和旋转。本轮将塑形明确作为姿态编辑：

| 操作 | 当前行为 |
| --- | --- |
| 开始拖动 | 按原纸面边长加权的拓扑距离，选择同一连通纸片上远处的非退化三角面，在其当前位置添加临时支撑；不同连通纸片暂时保持各自姿态 |
| 拖动中 | 暂时关闭折痕目标角驱动力，保留纸面长度、面内与面片刚度；不会将原纸面坐标作为支撑目标 |
| 松手／取消手势 | 清除临时支撑和全部动能，恢复用户求解参数并暂停，精确保留当前位置，不再居中或自动恢复旧目标 |
| 连续塑形 | 基于上次留下的形状重新选择支撑，不自动回到折叠进度对应的形状 |
| 后续操作 | 旋转、缩放、保存和修改求解参数保持暂停；主动继续求解、单步或改变折叠进度才会重新按原目标计算 |
| 用户固定点 | 保留原固定点；临时支撑不计入固定点标记、撤销前状态或保存姿态。没有可用支撑面时，可用本连通纸片内手动固定点提供支撑，否则提示先设置固定点 |

姿态编辑仍遵守纸面的数值约束，邻近面可能随动；不改变 CP、原始边长或原折角，也不提供碰撞处理。

## 先前实现与原工具核对（历史记录）

| 环节 | Origami Simulator 原工具 | 本地处理 |
| --- | --- | --- |
| 拖动 | 首次移动时临时固定命中的顶点，更新该点的位置，其它纸面参与动力学求解 | 保留真实位置约束；超过 2 CSS 像素后才开始，保留初始点击偏移，单击不启动求解 |
| 松手 | 恢复原固定状态，居中几何并清除全部速度 | 先解除临时抓点；没有用户固定点时，将真实模拟坐标移到原观察中心；有固定点时保持锚定位置。同步位置历史并清除全部速度，保留当前折形和目标 |
| 命中 | 命中可见纸面后选择顶点，有悬停提示 | 半径内选择最近可见顶点；不透明纸面过滤被前层遮住的候选，线框/透明显示允许抓取后层；增加悬停和抓取亮点 |
| 本地交互补充 | 原工具为独立 Grab/Rotate 模式 | 塑形/Shift 未命中时不旋转；恢复拖动前暂停或运行状态；取消、失去指针捕获、窗口失焦、页面隐藏、切换积分/视角、缩放、复位和关闭模式时清理抓点 |

依据：[原站抓取与命中源码](https://github.com/amandaghassaei/OrigamiSimulator/blob/main/js/3dUI.js#L24-L112)、[原站居中与速度处理](https://github.com/amandaghassaei/OrigamiSimulator/blob/main/js/dynamic/dynamicSolver.js#L104-L114)。

此前仅撤销一个顶点的约束，其它节点仍带有抓取积累的速度；相机中心固定，因此纸面和导出几何都可能持续漂移。此次处理发生在真实求解状态中，普通视角旋转不修改网格，未使用逐帧相机追随掩盖漂移。

塑形遵循纸面的动力学，拉住一点仍可能牵动相邻纸面乃至整体姿态。用户可手动添加固定点作为锚；系统不会自动选择远端固定点。塑形不改写 CP，也不永久修改折痕目标角。

## 固定点、独立历史与姿态恢复

2026-10-21 在上述漂移修复基础上新增：

| 操作 | 行为 |
| --- | --- |
| 固定点 | 开启“固定点”后点击可见顶点固定，再次点击解除；标记显示其位置。当前固定点需先解除，才能直接抓取该点 |
| 固定后塑形 | 切回“顶点塑形”拖动其它顶点；固定点保持原位。松手清除全纸动能，不进行破坏锚点位置的整体居中 |
| 解除全部 | 解除用户固定点，可用三维撤销恢复 |
| 撤销／重做 | 记录完成的塑形、固定／解除、解除全部及展开复位。画布中的 Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做；也可使用画布按钮 |
| 恢复历史 | 恢复当时姿态、固定点、目标比例与求解参数，并保持暂停；与二维 CP 编辑历史独立 |
| 新分支 | 新塑形或固定操作清除重做；继续求解、单步、改变目标或求解参数也清除旧重做分支。历史最多 20 条，并受 32 MiB 预算约束 |
| 保存与恢复 | “完整作品”包含当前模拟姿态及其源 CP、固定点、物理参数、目标比例和视角。重新打开后保持暂停，历史从恢复处重新开始；单独导出的 FOLD／OBJ／STL 不等同于完整作品 |
| 积分器与步骤动画 | 固定点与顶点塑形使用 Euler；有固定点时需先解除才能切换 Verlet。步骤动画继续由步骤数据控制，不接收自由塑形姿态 |

求解器的 `capturePose()`／`restorePose()` 保存、恢复的是静止姿态。快照保留绝对顶点坐标、相对原纸面的精确位移、未绕回的折角历史和固定点；恢复时同步三份位置历史并将速度清零。它不恢复拖动惯性，不改变原纸面的静止边长、原折角或材料参数。GPU 恢复同时重建应变通道，暂停画面的应变不因速度归零而被误报为零。

导入前验证整个快照及其源 CP，再验证完整几何签名、顶点／折角尺寸、有限数、固定点与几何的一致性。相同顶点数但纸张尺寸、拓扑或原目标角不同的模型不能混用姿态；不匹配时拒绝恢复。绝对坐标和精确位移同时保存，避免反复保存或撤销时相减造成坐标精度逐次损失。

固定点和姿态历史用于控制、保存当前数值模拟，不增加自碰撞、纸厚或摩擦求解。它们不解决纸面真实相交，也不证明保存的姿态可实际折出。
