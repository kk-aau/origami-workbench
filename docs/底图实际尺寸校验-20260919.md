# 底图实际尺寸校验

新增共享rasterHeader.mjs，在浏览器与服务器接受底图时，从实际编码头读取PNG IHDR、JPEG SOF、WebP VP8/VP8L/VP8X尺寸，并与工程声明宽高比较。拒绝超尺寸、截断头、越界段长或声明不一致，避免仅靠可伪造的工程width/height控制解码规模。包文件清单补共享模块，未打包。

依据：[PNG规范](https://www.w3.org/TR/png-3/)、[WebP容器](https://developers.google.com/speed/webp/docs/riff_container)、[WebP无损位流](https://developers.google.com/speed/webp/docs/webp_lossless_bitstream_specification)、[libjpeg-turbo marker解析](https://github.com/libjpeg-turbo/libjpeg-turbo/blob/main/src/jdmarker.c)。独立实现尺寸提取，不复制完整解码器。

5新增测试，全量496、构建与隔离服务器底图恢复专项1项通过。测试部分使用人工构造的头部，只验证尺寸读取，不当作有效图片解码测试。未校验全部CRC、压缩流或动画帧；浏览器真实解码与尺寸复核仍必须完成。JPEG EXIF方向可能交换显示宽高，后续加载器要区分编码尺寸与显示尺寸，不应误判合法方向图片。

当前仍79入口，无图片加载/显示或26交互，目录不升级。下一轮优先接真实解码和加载UI，保存原字节；如需要缓存重复头部校验，缓存以不可变dataUrl为键且有界，不能仅信任可变对象身份。正常8787/用户作品未动，测试临时目录自动清理，未打包。
