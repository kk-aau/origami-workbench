# 连续反射（开发版 v0.9.2，未打包）

入口：“镜像 / 变换 → 连续反射”。当前 34 项实际工具，沿用紧凑多列布局、中文步骤和鼠标旁提示。

1. 点击路径起点。
2. 点击方向点。此点仅确定方向，不限制第一段长度。
3. 核对整条紫色路径与停止原因，点击“确认连续反射”或任一紫色路径线。

第一段采用当前新绘制类型；M/V 之后逐段交替，折角采用各自默认 ±180°。其他类型不交替，U 保持未知角。参考折线的原山谷／折角不修改。改变绘制预设会重算待确认路径类型，但不丢失两点。

## 方向与停止规则

不是普通光学反弹：到达某条折线后，将上一段起点关于该折线反射，以命中点到映射点的方向继续。因此垂直穿过一条折线时会沿原方向继续，而不是原路返回。

- 每次选择前方最近的非共线有效折线／纸边交点；辅助 A 与平面 F 不作为反射轴。未指派 U 可作为几何参考，不因此推断其山谷。
- 到纸边停止；普通线内交点或两条共线小段构成的分点可以继续。
- 三分支顶点中，若一支沿入射方向、另两支共线，则沿共线对继续映射；其他不能唯一续接的顶点停止。
- 回到首个命中点即停止；另有重复位置／方向检测防止异常循环。整条路径的重复同型同角覆盖部分不再添加，有冲突则整组拒绝。
- 第一段找不到截止线时拒绝。已经生成有限段后，后续没有交点时，明确显示“后续方向没有截止线；仅保留已到达实际交点的有限路径”，不添加无限尾段，仍需用户确认。
- 计算步数沿用编辑器1500段安全容量；触发保护时明确报错、整条路径不提交，不静默截断当成完成。

右击／Esc 取消；切换工具或修改几何清空构造。新路径与全部真实交点分割一起撤销，保存恢复保留生成的每一段。
