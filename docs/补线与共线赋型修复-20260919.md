# 自由补线与共线交替赋型

- 自由补线的补线分支不再使用当前绘图预设。单邻线端点沿用原线的山谷及折角（包括自定义角度、零度、未知角度）；多邻线顶点按已有山谷射线数量推断使差值绝对值为 2 的补线类型。未切分的穿过线按两个方向计数。
- 多线交点含边界、未指派线或无法用单条补线配平时，明确提示，避免拿当前预设代替推断。自动赋型只处理局部数量条件，不等于全局可折证明。
- 普通自由画线分支、独立“网格补线”和独立“局部补线”继续保留各自原有行为。
- 共线交替按起点朝终点方向排序，以首个命中小段已有的山折或谷折为基准，保留首段并逐段交替；预览与提交共用同一规则。反向画参考线从另一端重新确定基准。首段非山谷时提示先指定其类型，受保护的边界仍跳过。
- 共线图标改为同一直线上的连续红蓝交替小段。后续按可读性反馈简化为三段并去掉方向箭头，见 [图标配色记录](构造图标配色-20260919.md)。工具说明、目录和参数提示同步更新。

验证：36 项相关单元测试与生产构建通过；实际浏览器验证正向两击、反向拖动、首段与当前预设不同、补线期间切换到边界预设、山谷端点延续、三山折顶点自动补谷、预览、单步撤销及重做。测试使用独立数据目录。
