# 两线角平分／平行中线

开发版v0.9.2，未打包。位于“精确作图 → 两线角平分”；已有“角平分线”仍使用三点输入。

依次点击两条不共线的实际参考线，紫色高亮只作参考，不改原线型。

- 两线相交：按各线距交点较远的端点确定角平分支撑线，再点击实际截止线，从交点画到交点与截止线的真实交点。任一方向均可；延长线上的截止不接受。
- 两线平行：预览等距中线。依次选两条截止线定义两端，第一端确认不会提前画半条线。也可在尚未选择第一截止时，点击“生成完整中线”或紫色有限指示线，使用参考锚点两侧最近的非辅助折线／纸边截止。缺少两端截止时拒绝生成整段。

结果采用当前新绘制线型，参考线型与折角保持原值。重复／共线参考、同点截止、零长、近似平行不稳定交点等均提示并保留有效输入。右击／Esc取消构造；没有构造时右击仍删除小段。交点真实分割，一次撤销整个操作，可保存恢复。

依据本地Oriedita MouseHandlerSquareBisector。当前独立入口、等距端点按坐标序稳定选择、截止限定真实段，与原版混合点线入口及可能使用延长线的行为不同，尚未做上游运行时逐例对照。目录仍基础可用。

验证：该核心共9项单元，全量347通过；两线25、公理33、原交互98共156浏览器断言通过；构建通过，主包体积警告仍在。未重新打包桌面版。
