# 第 45 节：螺旋直纹带二维／三维只读工作区入口

原版只读来源为 `tmp/Origamica-15.0-reference.nb` 第 307674–309036 行。`RibbonPair` 定义在 In[3854]，保存例 In[3855]；`NRibbonPair` 定义在 In[3858]，保存例 In[3859]。两个保存例都给定三维螺旋 `c(s)=(cos s,sin s,0.5s)`、`η=0.35π`、母线朝向 `+1`、`s∈[0,π]`、直纹坐标 `v∈[-0.5,0.5]`，绘图采样 200×20。笔记本没有可提取的 Wolfram 数值 `Out` 顶点表，因此工作区只声明依据原方程重建和核验了这个解析子域，不声明逐点匹配 Wolfram 内核。

此例是一张**单条连续可展直纹带**。二维展开与三维曲面使用相同的 `(s,v)` 参数、共同基线和母线索引；基线没有被原版声明为两侧夹角非零的折痕。`backend/tessellation_curved_helix_ribbon_pair.py` 已证明配对第一基本形式相等、三维直纹面可展，并计算焦线距离。保存例的焦线距离约 2.401133，大于半宽 0.5；上述连续几何专项见《Origamica第45节螺旋直纹带配对-20260924.md》。

新入口由以下部分构成：

| 部分 | 文件 | 契约 |
| --- | --- | --- |
| 后端安全查询 | `backend/tessellation_curved_ribbon_pair_query.py` | 仅接受有限数值 JSON 和已核解析族；通过 `certify_helix_ribbon_pair` 拒绝超焦线宽度，最多返回 5000 对采样点。 |
| 后端路由 | `backend/tessellate.py`、`server.mjs` | 专用 `POST /api/tessellation/curved-ribbon-pair`，通用 `/api/tessellate` 不接受此只读操作。 |
| 客户端校验 | `src/app/curvedRibbonPair.ts` | 校验输入范围、焦线宽度、来源 In、响应参数、共同采样网格和“非精确 FOLD”证书。 |
| 只读弹窗 | `src/components/CurvedRibbonPairDialog.tsx` | 同参数二维展开／三维正交投影、母线位置和方位角；无应用或保存为 CP 按钮。 |

界面参数允许 `r∈[0.25,4]`、每弧度螺距 `h∈[0.05,2]`、`η/π∈[0.05,0.45]`、朝向 `±1`、`s/π∈[-2,2]` 内跨度不超过 1、正半宽 `[0.05,2]` 且严格在焦线之前。曲线分段为 16–200、母线分段为 2–20 的偶数，同时受 5000 对点总量限制。它只覆盖常参数螺旋分支；原版任意空间曲线、变化的 `η(s)`、零曲率过点及一般数值插值路径仍未实现。

二维与三维的**连续曲面**有解析局部等距证书。有限采样点连接成的弦段通常不逐边等长，所以它不是精确直折痕 FOLD，也不是可采用的折痕图。连续部署路径、自碰撞与厚纸制造未验证；弹窗明确呈现这些边界。
