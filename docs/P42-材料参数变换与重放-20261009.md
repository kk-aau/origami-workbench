# 材料参数变换与重放（2026-10-09）

入口：折痕编辑 → 纸张属性/选区 → **材料参数变换**。默认保存参数组；采用后在“参数构造组”重新打开修改，顺序重算后续构造。源码运行版更新，免安装包尚未更新。完整 Origamica 目标仍在进行。

| 功能 | 当前行为 |
| --- | --- |
| 移动、旋转、缩放、左右/上下镜像 | 选择完整材料部件，毫米坐标预览；复用现有变换规则，CP和已有FF使用同一变换。 |
| 中心及赋型 | 旋转、正等比缩放和镜像以所选材料CP整体包围盒中心为基准；山谷线型保持，镜像校正面及孔环方向。 |
| 顺序重算 | 修改原参数重新计算，不累积旧偏移；切开后可仅变换一个部件，另一片CP/FF保持原值。 |
| 后续构造 | 来源边端点沿变换后材料定位；后续射线方向点、曲线固定点仍为原世界坐标，不擅自随材料移动。 |
| 保存和删除 | JSON/FOLD保存配方；删除有预览，后组依赖来源时拒绝；取消不提交，一次撤销/重做恢复整组结果。 |
| 兼容与保护 | v5接受v1–v4，加入旧类型不降级；失效旧配方归档并以当前材料为基底，组和归档各限8。 |
| 普通编辑 | 原工具栏变换保持；关闭保存参数仅执行几何变换，独立辅助线不作为材料一起变换。 |

部件选择使用原边/前组来源标记重新定位，不依赖变化后的部件编号。生成曲线分段身份变化仍明确拒绝，尚未实现任意连续解析位置寻址；复制、单面插入/删除的完整持续操作栈也未完成。
