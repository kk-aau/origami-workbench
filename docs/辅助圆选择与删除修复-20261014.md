# 辅助圆选择与删除

用户截图中的青色辅助圆保存在 `doc.objects`。此前普通选择与右键删除只处理 `doc.segments` 中的线段，圆仅可通过圆编辑工具操作。本次补齐圆对象的普通交互，更新源码及网页构建，尚未重新打包安装版／免安装版。

## 操作

| 操作 | 行为 |
|---|---|
| V → Enter，点击圆周 | 选中辅助圆，显示圆周高亮及参考点；纸张外的圆也可操作 |
| Shift 点选／框选 | 可多选圆，或与线段混选；普通框选需完整包含圆 |
| 拖动已选圆 | 修改圆心，保留半径；可撤销、重做 |
| 圆属性 | 承接所选圆，进入圆编辑，修改圆心、半径及颜色 |
| Delete／删除所选 | 一次删除所选圆与线段；材料约束拒绝时保留工程及两类选区 |
| 空闲时右键圆周 | 删除最近的线段或圆；线圆距离比较后拾取，不固定让圆抢占 |
| 右键向右拖 | 要求完整框住圆 |
| 右键向左拖 | 框与圆周相交或接触即删除整圆；完全位于圆内的小框不命中 |
| 擦除线段／仅擦除辅助线 | 左键圆周也可删除圆；仅擦除辅助线不会删除山谷线 |
| 图层 → 辅助线 | 同时控制辅助线与圆的显隐；隐藏圆不参与画布拾取 |

未完成构造的第一次右键仍只取消，第二次才删除。圆保持完整对象，不转换为折痕小段，不进入材料边或折叠图。折痕复制、镜像等既有工具仍按折痕语义工作；圆编辑中的圆心拾取及构造吸附保留。
