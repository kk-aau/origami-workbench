# 铺石与实时层序修复

版本 v0.12.6，2026-09-20。

旧铺石赋型只满足 Maekawa 与局部小扇区条件，方形默认样例实际上没有全局层序解；实心几何候选仍按纸面编号绘制，交汇处因此露背色、显示错误结构。现在固定石块边缘与角部径向线为山折，中心多边形为谷折，褶带连接按统一方向反向收拢，中心纸层收在完整石块下方。测试不仅检查颜色，还检查正面可见区域全部由完整石块覆盖，排除同色褶片遮住石块的错误结构。方形／矩形的宽度、长宽比、2×2 至 6×6 和六边形样例均求得有效层序。三角铺石仍属于候选构造，当前部分参数无层序解，不宣称已修复所有原版铺石变体。

混合平铺比例调整时，原来只有新几何立即返回，层序需等停手后重新求解；局部遮挡又由另一轮异步任务计算，期间出现错误的面编号叠放。现在：

- 用不随角度、比例改变的构造系数稳定顶点、边和纸面的编号，避免后台按当前坐标排序时误判拓扑改变。
- 在常驻工作线程中核对新几何的全部层序约束；上一帧的层序仍有效才沿用，不进行新分支猜测。
- 需要局部遮挡时，几何、局部区域和可见边在同一帧返回；无法验证时保留上一张确认图像，首次未验证结果显示线框。
- 上下关系转换使用固定观察轴，面编号变化不会导致正反遮挡翻转。
- 明确无解的编辑模型与图像导出使用线框，不再用实心面伪装有效层叠。

回归包括真实计算、长短边保长、正背面材料、完整石块覆盖、混合平铺比例连续变化、错误层序拒绝、面编号置换和 SVG 无解导出。浏览器脚本 scripts/verify-flagstone-live-order.browser.js 覆盖铺石可见面及混合平铺连续拖动，结果和截图位于 output/flagstone-live-browser.log、output/flagstone-correct.png、output/mixed-live-order-correct.png。

旧版已采用为折痕工程的铺石保留原山谷线；请在新版铺石构造中重新生成并采用独立副本。不会自动覆盖已保存工程或手工修订。本版未实施安装包体积优化。

## 2026-09-24：原版 P04 平行褶的对偶与可见面核查

原版 `MakeReciprocalDiagram` 默认使用 `MaxMinPleat`：对偶边必须垂直母边，在保留初始对偶总褶宽的条件下，最大化最窄的褶宽。原工作台只把面重心投影到垂直约束。原版保存例 In[3390] 的五条对偶边，旧投影宽度约为 `[1.01333, 0.86, 0.86, 0.56647, 0.56647]`，最大最小优化后约为 `[1.19257, 0.66667, 0.66667, 0.66667, 0.66667]`。同一 ρ=0.5 构造从“层序无解”变为“层序已解”；所得折痕有 42 顶点、82 边、41 面。实现仅用于“原版统一”赋型；旧“兼容折入”继续使用原投影，以保留旧工程几何。新铺石模板明确选择“原版统一”，读取缺少赋型字段的旧工程时补为“兼容折入”。

In[3390] 的平折存在 9,041,760 个层序候选，但不能靠换候选消除所有反色。按当前相同的平折几何与山谷指派，求解树根节点已有 248 条必然面序关系；其中 28 个重叠分区强制正面露出背材，面积 `190.7720694 / 13926.3612329 = 1.369863%`。首个解的反色面积恰等于这个所有候选共同的下界。背面反向材料面积约 `0.0000022`，为数值量级。原版 P04 说明的是褶宽尽量均衡，未承诺任意不规则母图折后两面都严格单色。因此该例的非零反色既不是显示透色，也不是错误选择首个层序；不能通过隐藏背材来“修复”。规则方格 3×3 的原版与兼容赋型在当前回归中正背反色面积均为零。

对应的后端回归核对最窄褶宽和旋转等变性；平折回归核对 In[3390] 的真实层序及根约束反色下界；浏览器在 1000×720 验证默认赋型、褶宽调整后的实时重算，以及该例正背面实体画面。截图见 `output/playwright/flagstone-in3390-front.png` 和 `output/playwright/flagstone-in3390-back.png`。这里完成的是原版 P04 的平行褶路线；原版另述的倾斜褶路线须独立核对，不能因本例通过就称铺石所有变体已复现。
