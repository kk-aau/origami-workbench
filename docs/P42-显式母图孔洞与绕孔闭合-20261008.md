# 显式母图孔洞与绕孔闭合（2026-10-08）

线组编织新增“方形环带 · 显式母图孔洞”可采用构造。母图编辑窗口可以选择原半边面并查看高亮范围，设为孔洞或恢复实面，使用既有撤销/重做；孔洞在画布用虚线标识。沿用同一工作区与原坐标、参数保存和普通导出，不重新打包 EXE。

| 原因 | 本批处理 |
| --- | --- |
| 原母图将所有内部闭环保留为实面 | 增加显式 `graph.holeFaces` 原半边面编号，移除所选内部单元的材料面，原顶点/边坐标与顺序保持。外圈不再是唯一纸边，孔洞边按真实面关联成为 B。 |
| 负初值探测会移动构造角点，中心点包含判断可能认错孔洞 | 沿构造角点来源压缩出原顶点循环，与所请求孔洞循环逐项绑定；每个孔洞必须唯一匹配。欧拉特征改为部件数减孔数，不能填补遗漏面。 |
| 局部反射方程不能约束非单连通纸面的整圈回展 | 兼容求解加入实际逐角回展的全局闭合残差；最终严格回展、几何和材料层序门禁继续保留。非对称环带改形原本有约0.000478源单位闭合误差，修复后实测约2.51264e-14。 |
| 孔洞变化没有改变点边数组，旧结果可能仍被视为当前结果 | 母图检查绑定完整原图，包括孔洞参数；恢复或改动孔洞即禁用旧 CP/FF，保存后重新构造。 |
| 通用平面枚举与原版半边编号顺序不同 | 挖孔编号使用原有 Edges+反向 Edges 的半边遍历顺序；重排源边测试明确绑定新的原面编号，不能用通用面排序冒充原编号。 |

## 可用范围与限制

| 项目 | 合同 |
| --- | --- |
| 孔洞输入 | 1–32个不重复的原有有界面编号；不设置孔洞时省略字段。只能移除闭合内部单元，不自动猜测相互包含的独立轮廓。 |
| 材料条件 | 孔洞不能碰外边界、相接或共享顶点；移除后每条源边仍须有实际材料面关联，同一原部件的面关联保持连通。 |
| 原支持域 | 保留母图内点四/六/八度、边界二/三度、原内缩交角等门禁；一般高边界度、任意多环母面及嵌套独立轮廓输入未接。 |
| 编辑 | 可以精确改点并重算；孔洞绑定时增删点边/分边明确拒绝，要求先恢复实面，避免面编号被静默转移。孔洞操作和阻止拓扑变化的提示均有真实界面验收。 |
| 材料采用 | 保留原版全局 B 语义及实际切口，生成材料分片，而非把内部 B 改成折痕。方形环带实际采用后是8个材料部件，不能宣传为一个无切口的环状纸片。 |
| 原目标求解 | 对称环带的原版平方和例已验证；全局绕孔残差本批仅加入兼容求解。任意非对称孔洞的原目标求解仍需继续，失败不会静默切换方法或放宽回展门禁。 |
| 原输入自动拆分 | 孔洞选择作用于手工有限母图。原 Intersectify 线网输入及其派生来源仍按既有来源合同；自动拆分原输入不携带孔洞参数。 |
