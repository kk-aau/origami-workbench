# 层序候选选择

## 更新：后台与候选面板

Worker两条入口均传solutionIndex。平折右栏提供上一解、下一解、1基指定编号（按钮或Enter），显示当前候选和精确总数。过期、计算中或选择起始面时不可发起候选切换；无效编号不能提交。层序更新不变顶点、不增加模型编辑撤销步。每次重新计算整棵树，仍受时间预算与取消约束。

四解条带真实浏览器23项验证不同绘制层序及坐标不变，621单元测试和构建通过。取消参数与保几何由单元覆盖，本轮未额外实测大图候选超时。未打包。以下为核心阶段记录。

原版AnotherSolutionAction从活动折叠模型调用foldAnother；指定编号入口另见方案源码核对。当前先补Rabbit Ear求解核心，不宣称与Oriedita搜索顺序或解数等价。

layerSolutions.selectLayerSolution按求解树AND组/OR选择结构，用BigInt计数和混合进位编号提取一个候选，不构造全部笛卡尔积。遍历顺序与所用0.9.4版compileAll一致。对外编号暂为零基非负安全整数，计数以十进制字符串精确保留。

computeFlatFold/recomputeFlatLayers支持solutionIndex，默认首解，成功返回当前编号及总数；越界保留几何、说明编号错误而非几何无解。仍只解决现引擎支持的层序约束，不证明连续运动或实际纸张可制造。

7项新增测试、全量620测试与构建通过。真实五面等宽全谷折条带4候选，与依赖compileAll逐项对应，模型坐标不变。Worker参数与候选UI尚未接，下一阶段必须做真实浏览器切换、取消与过期保护。
