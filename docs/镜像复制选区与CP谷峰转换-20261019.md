# 镜像复制选区与 CP 谷峰转换

2026-10-19。本次为 v0.13.30 之后的源码修复，不自动覆盖已交付的同版本安装包。

| 功能 | 使用方式 |
|---|---|
| 镜像复制 | 选中折线、符号后点击“镜像复制”，依次选择镜像轴 A、B 两点，查看预览并点击“确认镜像”或 Enter；原对象保留，可一次撤销 |
| CP 谷峰转换 | 在折序右侧 CP 卡点击“切换到主画布”，使用 CP 编辑工具栏的“谷峰转换” |
| 转换已有选择 | 用 CP 的“选择”工具选中折痕，再点“谷峰转换”，仅互换所选 M／V |
| 点选和框选转换 | 没有选中可转换折痕时，点击“谷峰转换”进入工具，再点击折痕或拖框，互换命中的山谷线 |
| 取消和撤销 | 镜像支持右键／Esc 取消及重选轴；CP 转换走工程的撤销、重做，可保存重开 |

镜像复制的根因是：画布在镜像轴第一点取消图片选择时，父组件无条件清空了折线、符号和纸层作用范围，导致第二点读取不到镜像来源。修正后只有真正选中图片才替换绘图选择，取消图片选择只取消图片；镜像持续读取当前有效选区，不缓存一份脱离工程的副本。

CP 转换复用折痕编辑原有的区域山谷互换逻辑。M 与 V 互换，折角符号随之改变，绝对值与未知角度保持；边界 B、辅助 A、已有折痕 F 和未指派 U 不变，不改变新绘制线型预设，也不会在没有选择时自动转换全图。点选采用最近命中规则，不穿透命中的非山谷线。

CP 提交继续使用现有材料校验、相邻步骤共享 CP、折线联动和历史记录。共享的操作前 CP 仍需到上一步修改；只读、计算中及扯角状态的已有保护保持，工具不能绕过这些限制。转换通过现有 CP 提交路径同步可用的主图预览，不擅自重新计算纸面姿态。

本轮验证证据存放在 `output/mirror-cp-swap-20261019/`。本次不生成桌面发行包；后续打包仍遵循[打包与体积控制要求](打包与体积控制要求.md)。
