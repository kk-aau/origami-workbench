# v0.13.30 桌面打包说明

2026-10-19，Windows x64。安装版和便携版采用同一冻结源码，保留已有 v0.13.29 发行包。本页记录构建输入；最终字节数、SHA256、执行与沿用的检查记录在 `release/验收-v0.13.30-20261019.json` 和 `output/release-0.13.30-20261019/`。本次仅整理本机发行文件，不对外上传，也不修改 README 中已发布版本的下载链接。

| 范围 | 本版内容 |
|---|---|
| 自适应线型 | 两个工作台默认开启，共享并保存开关；短线调整节距和笔宽，保留峰谷特征，极短线提供类型提示和放大恢复 |
| 输出与相位 | SVG／PDF 按最终尺寸计算，放大框按各自倍率重采样；能确认同一来源的遮挡碎片延续相位，不改 CP 或工程数据 |
| 局部放大符号 | 小圆圈定主图、大圆显示放大；CP 局部图保留主图定位小圆，以两个独立大圆显示操作前后所选区域，CP 不画外切连接线 |
| 显示与编辑修复 | 消除淡蓝填充接缝，主图同步全局折线样式；垂直符号蓝点缩放；拖角可命中折后折痕的已有端点和交点；重合纸边不错误遮挡下层折痕 |
| 原有能力 | 保留自动选层遮挡段补齐、启动过渡、工作日志、文档删除、完整离线计算及导入导出 |
| 构建与许可 | 使用锁定依赖、本地 Electron、独立调试归档；随包仅一份完整源码 7z，对外另附相同内容 ZIP／7z 和许可 |

已知边界：只有几像素的极短折痕仍需类型、颜色或局部放大辨识。创建圆框时的选区对话框为静态预览，确认后的实际主图和输出按倍率重采样。相位只在可证明相同物理来源的连续材料上延续。既有“全部纸层”的固定侧轮廓校验继续保留，失败不替换原工程；透明预览也不能独自证明 CP 无法压平。

功能说明和本机开发验收见[自适应线型](短折痕自适应线型-20261019.md)、[拖角与圆形细节框](折序拖角节点与圆形细节框-20261019.md)。桌面交付必须通过[打包与体积控制要求](打包与体积控制要求.md)中的源码、许可、实际内嵌归档、实包 GUI、最终 Portable、关闭与日志验收。

打包前扩大回归时发现三项陈旧测试断言：命令总数仍写为 62，以及双向段折箭头仍要求单套夹点和已移除的人工间距／错位夹点。从已交付 v0.13.29 对应源码独立运行原测试，复现相同三项失败。本版只校正测试，使其验证实际 63 项命令、左右两套原生来源夹点，以及通过显式属性修改间距／错位时的几何效果；未修改或回退对应生产交互。首次失败、旧版复现和修正后的结果均保留在本次证据目录。

便携版更新前保存并正常关闭旧版，把新 EXE 放到原程序目录并保留“折纸工坊数据”。本次构建不删除或迁移已有用户工程、恢复稿、日志，也不关闭用户正在运行的实例。未在全新 Windows 虚拟机测试，未进行发布者代码签名。
