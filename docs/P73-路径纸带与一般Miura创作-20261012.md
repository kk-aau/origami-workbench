# 原路径纸带与一般 Miura 创作

本批接入本地源码，尚未更新 v0.13.6 免安装包。整体实用构造目标继续，不能据本批测试数量宣称全部原功能完成。

| 在主界面中的入口 | 可创作的输入 | 实际输出 |
| --- | --- | --- |
| 镶嵌设计 → 空间构造 → 空间构造类型 → 路径波纹／Tachi CP | 有序目标路径拖点、扇区角列表、转角列表；条带宽、重复、设计／当前折角；Tachi 的设计转角及水平／斜段长度 | 原 A/B/P/Tachi 有限 CP，保原毫米位置、山谷、目标角与材料图 |
| 同一菜单 → 折链／空间折线纸带 CP | 每站四扇角、脊线长度／山谷；三维 XYZ 点、左右宽、初始子弧、CP 方位与密切方向；XY/XZ/YZ 投影拖点 | 有限纸带 CP；点按源索引保留，投影拖动只改对应两轴 |
| 同一菜单 → 一般／嫁接 Miura CP | 两独立扇区角与互补联动、两个方向逐段边长；嫁接的三种段长、行列、原整数 offset、有向折角 | 原一般与嫁接 CP，以及经过逐面等距、共享轴及有向折角核验的静态三维预览 |

每个窗口使用毫米刻度，可滚轮缩放、拖动查看及复位。紫色表示输入，青色表示生成折痕，纸边为黑色。选择重合投影中的点后，该点的手柄优先响应拖动，不改变另一点。取消保留当前工程；空值或无效参数不能采用上一次有效图。

采用后，在折痕编辑区点击对应的“修改……构造参数”重新编辑。明确修改来源并采用时，同一种构造保留工程名称与 UUID；从新入口采用另一构造建立新工程。完整工程及材料 FOLD 保存源参数；普通 DXF 保留现有 LINE 导出与原坐标转换。

Tachi 的 ±90° 设计转角不再被一个未用于 CP 的高度极点误拦截。该未使用高度在极点明确保存为 `null`，并保留原因；旧非极点样本未改变。

空间折线原源中存在连接两面的内部 `B/0`，与材料边界身份冲突。本地显式编码为 `F/0` 共享缝；原赋型、面连接和原三维数据完整保存在来源中，坐标未修改。CP/OPX 对其无法表达的 F 类型继续明确拒绝。原静态姿态的目标折角未通过完整核验时，不显示为已认证三维；三维运动、碰撞及平折层序不在本批完成声明中。

最终统一验收（第四轮固定快照）：3385 项前端单测、TypeScript 与 Vite 构建通过；1337 后端、7 桌面、66 服务检查以全部对应输入 SHA 未改变为条件复用。131 项真实主界面断言、34 个实际按钮文件、16 次实际保存、8 个磁盘 UUID 和独立全文件回读通过，393 个普通 LINE 无增删或重复加工，尺度、位置及一次 Y 转换一致。24 个实际 JSON/FOLD 在 Chrome→Node 的来源校验通过。

折链纸带 v2 保存原数学函数计算追踪，并按原运算顺序精确重放整个来源、材料和线段；16 EPS 容限仅用于原派生函数返回，不用于移动顶点。旧 v1 保留参数读取与同运行时严格校验；缺原追踪的旧跨运行时文件不会被伪造认证，用户可明确重建为 v2。前三轮失败保持记录，不计最终成功。第三轮的同参数重建已由第四轮每种构造的有效改参、同 UUID 保存和新文件回读补足。
