# CAD工具命令（2026-10-14）

折痕编辑工作区默认开启画布直接键入命令。输入英文字母后，焦点进入底部“工具命令”框；继续输入命令，按 **Enter** 才启动工具，再回到画布按原取点步骤操作。字母输入本身不会立即切换工具。

也可以直接点击命令框，输入中文工具名、完整工具 ID 或全角字符。命令不区分大小写，例如 `co`、`ＣＯ`、`复制所选` 和 `copyselection` 都指向“两点复制”。

## 输入与确认

| 操作 | 行为 |
|---|---|
| 画布键入字母 | 进入底部命令框，显示匹配候选 |
| 输入精确命令 → Enter | 启动该命令对应的已有工具 |
| ↑ / ↓ → Enter | 选择候选并启动该工具 |
| Tab → Enter | 补全候选的主命令，再启动 |
| 点击候选 | 直接启动所点工具 |
| 命令输入中按 Esc | 清除本次命令输入，回到画布；不清空选区 |
| 命令框为空时 Enter | 重复上次从命令框执行的工具；重新开始该工具的未完成草稿 |
| 设置 → 命令编辑 → 关闭“画布直接键入命令”，保存并应用 | 恢复原有单字母工具快捷键；命令框仍可点击输入 |
| 画布的 Ctrl 组合键、1／2 | 继续使用原有快捷键设置；命令框里的数字作为命令文字输入 |

未识别的输入不会自动执行工具。前缀可用于查找候选，需明确选择或补全后确认。命令别名与自定义快捷键分别使用：直接键入关闭时按现有快捷键，开启时普通字母先作为命令输入。开关位于“设置 → 命令编辑”，两个工作区共用；取消设置不改变原偏好。底部命令栏只保留当前工具和命令输入框。

该入口只选择已有工具。切换后仍按原工具提示选线、取点或填写参数，不解析CAD坐标、长度或角度，也没有新增旋转等命令。

## 验收与构建

| 检查 | 结果 |
|---|---|
| 命令表、快捷键与偏好 | 18项测试通过，包含完整工具覆盖、别名唯一、前缀不误执行、大小写／全角和保留原快捷键 |
| 实际主界面 | `verify-tool-commands.browser.js` 123项通过：画布键入、Enter后焦点、真实画线及撤销重做、选区保留、输入法、名称／数值／模态隔离、CAD切换 |
| 候选与重复命令 | `verify-tool-command-candidates.browser.js` 16项通过：箭头、Tab、点击候选、同工具重启与空Enter重复、数字预设、六项候选无滚动 |
| 两种窗口尺寸 | 1200×800与1000×720页面、命令栏、六项候选均无滚动；1000×720时编辑画布352×442.5，命令栏高36 |
| `npm run build` | TypeScript与网页生产构建通过 |

浏览器测试使用8897的独立数据目录，未改用户工程；输入法用composition与isComposing事件验证，未替代操作系统输入法的所有组合。当前更新源码与网页资源，Windows安装版／免安装版未重新打包。
