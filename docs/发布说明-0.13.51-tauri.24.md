# 折纸工坊 0.13.51-tauri.24

日期：2026-10-31。Windows x64 · Tauri 迁移版。

本版调整折序工程的自动保存时机，并减少大工程拖动、缩放时的重复计算。

| 改动 | 效果 |
|---|---|
| 修改后在切换步骤、离开折序工作区时自动保存 | 编辑时先保留在内存；内容没有变化时跳过重复保存，仍可随时手动保存 |
| 平移、缩放和单纯浏览步骤不触发保存 | 避免视口操作后反复处理整份折序工程；翻面、旋转、颜色及真实图稿修改仍纳入保存 |
| 完整校验与草稿写入移到后台 | 减少保存对界面线程的阻塞；保留多窗口修订冲突检测与原子提交保护，失败不报告已保存 |
| 复用主图折痕投影和右侧 CP 几何缓存 | 仅视口变化时不再重建 CP 图、标签和命中区域；纸面与显示内容变化时正常更新 |
| 步骤 PNG 缩略图忽略纯视口变化 | 平移、缩放后切换步骤不再生成相同图片；实际图稿修改仍在离开步骤时刷新 |
| 静态折序停止周期性完整作品采样 | 完整作品自动恢复采用已成功保存的折序检查点；手动保存完整作品仍包含最新编辑内容 |

完整步骤、CP、纸层状态、折痕、符号及原有离线计算功能继续保留。本次沿用既有 Python 离线计算引擎，不裁减计算能力或依赖。

开发阶段曾用 66 步工程副本进行交互与保存验证，同组操作记录的最长界面线程任务由约 5.85 秒降至 0.13 秒。该结果仅属于此前开发阶段，不代表本轮实包验收，也不保证所有电脑或工程达到相同耗时。

本轮按用户“打包，不检测”的要求直接构建和归档，**未运行新增测试，也未执行安装版／便携版实包验收**。此前开发验证与本轮打包记录分别保留，不以旧验证替代新版实包验收。

安装版、便携版、同版本完整源码 ZIP／7z 和独立调试材料一同交付。完整源码作为独立附件，包含许可证和来源材料；应用内保留必要的原始许可与源码获取说明。运行需要系统已有 **Microsoft Edge WebView2 Runtime**，应用不自动下载或安装该运行环境，也不需要另装 Node 或 Python。
