# Origamica 第 37 节 `TwoUniformPatch[13]` 四片来源入口

对照原版第 37 节 235444–240499 行的双均匀目录，既有工作区“**双均匀 13**”以第三方目录的最小周期单元表示同类平铺：两个来源面，`sides=[4,3]`。它无法回读原版 In[3245] 的**四片** `TwoUniformPatch[13]`，也无法表达 In[3246] 所保存的具名顶点格矢。此处详记 In[3245–3247] 这个最小例；n=14 另有五片专项记录，1–20 全部来源目录见《Origamica第37节TwoUniformPatch全目录-20260927.md》。

| 原版稳定输入 | 本轮实现和核对 | 分级 |
| --- | --- | --- |
| `In[3245] TwoUniformPatch[13]` | 按 `UnitRegularPolygonTile` 面序 `{4,4,3,3}` 及三个原式 `JoinTiling` 引用 `{1,2,1}`、`{2,2,1}`、`{3,2,2}` 构出连续四片；前端保留带接边引用的 `tileSpecs`。 | 保存公式来源；原版无数值 `Out` 顶点表。 |
| `In[3246] TwoUniformPatchLatticeVectors[13]` | 按 `{1,1}→{3,2}`、`{1,1}→{1,4}` 两条 `PatchVectors`，得到约 `(2.8660254037844384, 0.5)`、`(0,1)`；四片面积等于格矢行列式。 | 保存公式与几何不变量。 |
| `In[3247] MakeLatticeTiling[...,{0,1},{0,1}]` | 新的“原版双均匀补片 13”工作区按钮默认 2×2，共 16 来源片、21 顶点、36 边。来源面序及格点顺序严格核验，几何检查通过。 | 保存排布输入与本地后端输出；非 Wolfram 数值逐点等价。 |

工程参数中的 `twoUniformPatch` 只接受指定来源名、编号 1–20 和有界整数闭区间；n=13 回读同时核对四片面序、单位正多边形类型、三次接边、顶点、格矢和范围。若用户修改形状、来源或输出方式，具名来源会失效或整个伪造请求被拒绝。按钮在自定义镶嵌工作区中，并允许按原版格矢改变格点范围；偏离 `[0,1]×[0,1]` 时明确不称为保存的 2×2 例。

**采用分级**：此保存例只有母结构图形调用，没有给出山谷折痕或平折图形的数值输出。产品因此以 `customOutput='tiling'` 生成辅助线面网格：几何为 `passed`，局部山谷条件为 `not_applicable`，整体层序为 `not_checked`，平折性为 `not_applicable`。这可作为母结构排布使用，不能算已复现原版折痕或可采用的平折候选；若后续要加扭转配方，须另有来源参数和完整层序验证。

专项脚本 `scripts/verify-two-uniform-patch13-in3247.ts` 验证来源公式锚点、严格工程回读、6 类伪造和后端真实生成；`tsx` 专项及 TypeScript 检查通过。
