# 原线网拆分后的区域构造与验收（2026-10-08）

本批补齐通用原线网 Intersectify 拆分后的明确区域选择：用户能够设置环孔、内部单元孔洞或嵌套独立纸片，继续实际生成、采用与导出 CP。完整 Origamica 复现目标尚未完成；免安装 EXE 未更新，本批不打包或发布。

入口：镶嵌设计 → 线组编织 → 编辑母图 → 母图来源“源线网 · 自动拆分”。在原输入中绘制或修改点边，点击“拆分交点”；在拆分结果中选择原面/独立圈，设置环孔或内部单元孔洞，或明确选择嵌套轮廓为独立纸片。确认区域后保存母图，正常完成生成与平折层序检查，再采用折痕副本和普通导出。

| 原问题 | 本批结果 |
| --- | --- |
| 自动拆分后只能查看，嵌套轮廓被拒后无法进一步构造 | 拆分结果可直接设置区域，并有源坐标刻度、孔洞高亮、定位圈、缩放及撤销重做。纯几何拆分不冒充已生成 CP；未声明的嵌套轮廓不能保存或导出为可用母图。 |
| 原来源只核对点边，区域变化可能没有被校验 | 通用来源增加可选 `motherSelection`，包含派生几何戳及明确 `holeFaces`、`ringHoles`、`nestedSheets`。前后端分别重算原 Intersectify 点边，再核对戳和声明；实际图不能添加、移除或替换来源未声明的角色。 |
| 修改派生点边后可能仍保留原版来源 | 派生图只允许区域归属修改，坐标只读，无新增、删除或分边操作；修改原输入或容差后，旧来源和区域许可立即失效，需重新拆分和明确选择。不会静默沿用旧面/部件编号。 |
| 缺少取消、保存和回读的闭环 | 角色历史可撤销重做，取消不改变原工作区结果；母图来源包和采用工程可重开，原输入、容差、倒置设置、原边对应关系和声明均保留。 |

区域声明是本地明确编辑合同，并非声称原 Wolfram 已具有这些 JSON 字段。底层继续使用原拆分遍历、首代表点 Indexify、原内缩和回展构造。`In[3437]` 原22点/13边、容差2/2及倒置设置仍冻结，不允许附加区域字段或给原输入贴区域标签。普通 CP、普通导出及加工优化实现保留原 SHA。

## 实际文件验收

| 场景 | 采用 V/E/F | 实际材料部件 | 新环孔 | 普通 DXF LINE |
| --- | --- | --- | --- | --- |
| 单环孔 | 24/36/13 | 1 | 1 | 36 |
| 同面双环孔 | 28/40/13 | 1 | 2 | 40 |
| 原单元孔与环孔组合 | 52/60/16 | 8 | 1 | 60 |
| 嵌套独立纸片 | 40/64/26 | 2 | 0 | 64 |

四组都经过真实浏览器：原输入 → 拆分接口 → 可视区域选择 → 公共生成 → 原CP/FF独立核对 → 正背平折 → 采用 → 下载母图包、原始来源、JSON、FOLD、普通 DXF。下载回读以本次实际响应重建材料，逐值核对索引图、原FF位置、固定面、来源与参数；JSON/FOLD重新求得层序。普通 R12 DXF 与原导出文本一致，独立解析每条 LINE 的赋型图层、毫米端点、原Y转换和次数。零与负零视为同一几何数值，没有使用放宽坐标误差来掩盖偏移。

组合例保原版内部B切口，实际为8个材料部件，不能描述为一张未切断环带。后端专项和界面可能以不同原输入边序得到不同有效候选；验证不把两次不同输入/求解的数组混作同一次导出结果。

## 剩余目标与未验证范围

本批限通用有限直线原线网、明确且不接触的简单内环及已有内部单元孔洞/独立纸片；不自动猜孔，不补跨空白线，不放宽512点/1024派生边、128原输入边、32组孔洞以及原4/6/8度等构造门槛。拆分后的区域可保存只表示来源和基本母面可用，不能代替完整CP、回展及层序生成门禁。

完整目标仍包含有效≥10偶度编织、曲线/触碰/交叠环、单桥/弱简单面、面内自由起点/开放材料端点、曲线材料批量、复杂切口合并、任意非平折编辑及未复现的Wolfram输入语义/选项/插值和未证数值全域。后续继续按可构造和采用CP优先推进，不能把这些余项称为已实现。

最大规模/任意组合性能、原版Wolfram保存Out逐点等价、原生免安装交互、外部FOLD/刻字软件导入、机器试压、连续无碰撞折叠均未验证。本批不操作设备，不承诺实机提速，不自动发布。
