307373–307640 是 In[3845–3847]/In[3850–3851] 例子区域。原文没有直接 `f_List` 向量重载；“向量”是函数返回列表，API 不把直接向量数组冒充原重载。Unplanarize 的说明文字误用了 Planarize 描述，本地按明确原定义中的 `Append[...,0]` 实现。

此前切线可展平展和柱面重塑固定例已覆盖截前两坐标/补零的一部分语义；本次补足任意受支持安全函数源的独立转换、完整转换函数描述和点值查询。没有把原图形/函数额外要求为可采用直线 CP。

主 App 路径：镶嵌设计 → 空间构造 → 原式工具与参考示例 → 平面函数嵌入。保留源函数形式、参数顺序和原分量表达式，可保存/载入源 JSON、导出完整转换及每个参数点的结果。

公共 API：`POST /api/tessellation/planar-functions`。`input` 是 `{form:'slots',arity,body}` 或 `{form:'parameters',parameters,body}`。纯函数以 `#`/`#n` 表示 Slot；显式参数按名称使用。返回 `convertedFunction` 保留形式与参数，`sample.rows` 与原请求的参数点一一对应。保留分量未定义时该行返回 `values:null` 与错误，保持其他点及完整参数列表。

Planarize 的丢弃分量先做语法安全检查，但不求值。例如 `{Cos[#],Sin[#],1/(#-#)}` 转为 `{Cos[#],Sin[#]}`，即使第三分量在整个域有零分母也不阻止前两分量的点值。任意分量中的属性访问、代码调用、未知变量仍拒绝；不执行 Wolfram 或任意程序。

安全数值子域：0–8个显式参数，或1–8个 Slot 参数；每个分量1–240字符、AST最多96节点；只接受四则、−8…8整数常数幂、sin/cos/tan/atan/sqrt/exp/log和pi/e，兼容对应大写标量函数与方括号、隐式乘法。常数和求值参数在±10¹²内有限；每请求1–129个点。SlotSequence、任意表达式头、插值对象、原生 Wolfram Function 对象及任意选项未复刻。这里返回安全函数体的精确坐标转换及数值点值，不宣称连续域完整认证。

回归：Python10项，TypeScript9项，真实HTTP12项，隔离真实主App15项及4个实际下载文件。独立前端表达式回读拒绝伪造转换体、参数、点值及认证升级。源变化立即清除旧结果，共用工作进程忙时等待，可取消过时请求。390×720窗口中弹窗354×688且无内溢出。
