# 按类型替换和删除：核心

已核对MouseHandlerReplaceTypeSelect、MouseHandlerDeleteTypeSelect及FoldLineSet.insideToReplaceType/insideToDeleteType、replaceAux、CustomLineTypes。尚未接入两个界面入口，当前仍58项实际工具。

语义：单击先找最近可编辑线，再检查来源类型，不穿过不匹配线去找更远的线；拖框采用接触命中，与拖动方向无关。来源含任意、山谷组合、山、谷、辅助、边界；本版另覆盖已有的未指派和平面边。替换目标必须是一个具体线型，不将组合筛选值当线型。

纯计算位于app/typeFilter.ts：typeFilterHits用于预览/命中，applyTypeFilter返回doc/matched/changed。没有实际变化时返回原doc，避免无意义撤销步骤；批量仅生成一次文档提案，调用方统一提交真实分割及撤销。山谷互换保持绝对折角、0与null；辅助改山谷取默认角，改辅助/边界/平面边角为0、改未指派为null。边界保护适用，辅助圆等绘图对象不受影响。
