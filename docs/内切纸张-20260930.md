# 显式内切纸张与真实裁剪来源

新增 `paper.fit='inscribed'`。用户选择内切纸张后，只保留纸形内部的真实折痕与纸面；原外延失败不会自动改成裁切。缺省 `fit` 仍为 `extend`，已有工程对象保留原文与原外延行为。

| 参数／范围 | 合同 |
| --- | --- |
| `fit` | 仅接受 `extend`、`inscribed`；旧工程缺省为外延。 |
| 纸形 | 正方形、长方形（保留长宽比）、正多边形。 |
| `margin` | 内切 .02–.45；外延 .02–1。 |
| 构造参数 | 内切从同一次原构造生成结果裁剪，保留包括边界修剪、选定对偶面与母图参数在内的原始输入。 |
| 二维范围 | 编织、原线组、精确多边形、分裂、Brocard、非周期、周期、原始／对偶、铺石、自定义及其它有限二维候选；实际原纸边必须是完整单闭环，原纸面必须严格凸，裁剪纸形必须为严格凸多边形。原外围有凹陷时，必须仍能在原纸域中心内接出有效纸形。 |
| 空间／非法面 | 空间族、失效几何、凹面或零面积裁切明确拒绝，不拆面掩盖无效来源。 |
| 母图输出 | `source.output='tiling'` 可以裁剪；内部 F／辅助边不当作 180° 折痕，平折不适用。 |
| 整片层序 | 裁后必须重新求解与验证。局部条件和等距反射坐标均不能代替整片层序证明。 |

实现复用 `tessellation_paper_clip.py` 的逐面裁切。裁切保留原内部 M／V 赋型，只有新纸边成为 B；各面不会被伪造为一张简单外轮廓。新入口把实际 CP 临时归一化到局部单位坐标完成几何校验，再通过来源权重恢复原坐标，精确多边形的 1e-8／1e-14 尺度仍保留。旧裁切 helper 的默认至少保留 20% 原面积合同未改；显式内切允许用户主动裁掉更多，只要保留非退化的完整纸域。

| 新结果字段 | 含义 |
| --- | --- |
| `paperMethod='inscribed-pattern-clip-v1'` | 区别于原外延流程。 |
| `paperPolygon` | 当前实际坐标中的纸边。 |
| `sourceVertexMap` | 每个新点的原顶点／原线插值／原面插值来源及无量纲权重。 |
| `sourceFaceMap` | 每个新面对应同一次原生成结果的面编号。 |
| `paperStartingFace` | 裁后当前零基固定面。原明确固定面仍存活时映射；否则按纸域中心选择几何稳定的最近面，精度一致的距离再按中心坐标排序，避免原面序列变化造成姿态跳动。 |
| `provenance` | 原构造族、算法、固定面和原点／面计数，仅用于来源解释，不当作裁后编号。 |
| `fold.zhezhi_face_*` | 原逐面装饰／实例信息按 `sourceFaceMap` 同步映射。 |
| `foldedForm` | 原真实平折坐标先逐面等距校验并映射；存在 M／V 反射模型时在裁后固定面姿态中重算并核对。不使用展示用示意图冒充平折。 |

新结果不沿用旧 `stationaryFoldFace`、旧 `foldedFormStationaryFace`、原逐面索引、层序或连续路径。`preview=None`，没有保留与裁后点数／来源系数不符的旧实时配方或 `paperClipPreview`。

浏览器极值核查发现默认编织的宽高比 5、内缩 .1 原会报纸域裂缝。追溯表明新纸域在原 B 闭环内、交点也正确，但原裁切 helper 用整张纸尺度的面积阈值删掉两块实际存在的小三角面（单位坐标中面积约 2.41e-10／2.54e-10，边长仍约 3e-5）。现在按每个裁后面的周长乘原长度容差／2 判断无法分辨的宽度，保留真实小面；原完整面积覆盖、连通圆盘、边唯一来源、山谷赋型与面内等距检查均保留。没有放宽坐标容差或绕开裂缝校验。
