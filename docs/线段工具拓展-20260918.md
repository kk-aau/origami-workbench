# 线段与顶点工具拓展 · v0.3.0

本批增加五项真实工具，沿用现有工作区、工具栏和绿色界面，构造参考统一紫色。不是完整 Oriedita 替代版。

## 操作

| 工具 | 点击顺序 | 结果 |
|---|---|---|
| 延长线段 | 靠近待延长端点击已有线段 → 点击目标线段或纸边 | 仅向外延长该端，截止于目标实际线段上的交点；目标延长线上的交点无效 |
| 截断线段 | 靠近要截去的端点击 → 点击线段内部截断点 | 紫色虚线是保留部分，另一端不动；支持吸附并投影回原线 |
| 等分线段 | 设置 2–100 整数 → 点击线段 → 再点击该段确认 | 真正生成独立小段，预览显示分点 |
| 比例分割 | 设置正数 m:n → 靠近起算端点击 → 再点击该段确认 | 按起算端到分点、分点到另一端的长度比拆为两段 |
| 中垂线 | 基准点 A → 基准点 B → 截止线段或纸边 | 从 AB 中点沿垂直方向到所选目标；基准 AB 不生成折痕 |

前四项保留源线型与目标折角（包括未知角 null）。中垂线采用“新绘制线型”。纸边默认可编辑；启用边界保护后，不能作为前四项的修改对象，但仍可作延长或中垂线的目标。新增交点沿用真实分段。

构造中右击仅取消，空闲右击仍删线；Esc、切换工具、撤销、打开其他图纸均清理构造。每次完成与相关交点分段合为一次撤销。失败不部分修改工程。分割后的小段保留独立 ID，保存恢复不合并回原线。

## 实现与验证

- `src/app/segmentTools.ts`：独立几何与错误边界；`tests/app/segmentTools.test.ts`：15 项新单测。
- `src/app/tools.ts`：12 个工具统一名称、用法和当前步骤；新工具已加入工具侧栏。
- `src/components/CreaseCanvas.tsx`：点选状态、紫色预览、分割参数及提交。参数当前保留于画布组件会话，重载后恢复默认，不属于工程存档字段。
- 单元测试共 156 项、服务测试 9 项通过；生产构建通过（既有 bundle 体积警告仍存在）。
- 独立服务 8797、独立数据目录验证：新工具 48 项浏览器断言、既有交互 98 项通过。
- 交互脚本 `../../output/playwright/verify-segment-tools.js`，截图 `../../output/playwright/segment-tools-v3.png`。
- 安装版与 portable 的构建、最终桌面验收记录以发布完成后的续接记录为准；安装包构建不代表已执行安装验收。

## 尚未覆盖

当前等分／比例工具处理已有小段；尚未等价实现 Oriedita 的所有“新画线并分割”、根式比例参数和变体。同色连续延长、删顶点合并、分支处理、公理、圆／反演、高级选择等仍在全工具总账中，不能据本批五项将整个功能组标为完成。

升级先保存并关闭旧桌面窗口，再从根目录桌面启动器或 v0.3.0 Portable EXE 打开。保留 EXE 旁的“折纸工坊数据”目录。网页模式则先保存再刷新。开发过程中不关闭正常 8787 或用户旧桌面窗口。
