# 环状镶嵌 100% 层序显示修复

2026-10-14。针对用户反馈的“环状镶嵌在99%正常，100%出现纸面锯齿和透线”进行修复。此次处理稳定平折终态的显示遮挡，不重新启用已取消的自穿越回退、暂停或碰撞响应。

| 复现数据 | 结果 |
|---|---|
| 默认环状镶嵌 | 8边、2圈、growth1.8、angle36、scale0.3 |
| 源CP／模拟网格 | 72顶点、65源面／126三角片 |
| 平折层序 | 唯一解、416条关系，可映射回源纸面 |
| 真实CPU终态 | 暂稳后应变约1.9e-6，全部纸面满足近平条件 |
| 原显示失败 | 通用重叠分区有32处角点越出声明三角片，触发整组分层放弃；部分区域还含缺交点造成的自交梯形 |
| 独立透线原因 | 屏幕线带的宽度沿用中心线深度，倾斜时下层线带的半边可以浮出上层纸面 |

## 修复

| 部分 | 当前实现 |
|---|---|
| 局部区域 | 用实际源边补齐有限线段交点，再逐竖向区间计算真实覆盖；不复用会合并近交点的编辑预览分区 |
| 纸面保全 | 区域与其源三角片真实裁剪，保留非负、归一的重心坐标；逐源三角片核对绝对覆盖面积和绕向 |
| Float32微片 | 删除实际零面积显示片，统一非零微片的最终绕向；每源三角片影响面积不超过1e-6，否则整组退回原网格 |
| 开销限制 | 512输入三角片、1024边、8192竖向断点、100000区域、20M覆盖候选、250k输出三角片、200k显示顶点；超限不输出部分纸面 |
| GPU线宽深度 | 在片元处按纸面平面与实际像素视线计算透视深度，避免角点插值削细自身折线；层距和偏移上限不增加 |
| CPU线宽深度 | 每个线带像素使用同一纸面平面的逆眼距梯度 |
| 平面使用条件 | 仅整个源网格的非退化三角片及显示层法向均平行时提供统一纸面法向，避免把局部平面套到其余弯曲纸面上 |
| SVG | 确认统一纸面法向时禁用跨平面的提线容差，保留自身折线的微小深度偏移；普通调用保持原行为 |
| 模拟与导出几何 | 求解器、源CP、FOLD／OBJ／STL实际坐标不改；显示裁分复用已有缓存 |

## 适用范围

修正要求目标为100%、数值暂稳、已有匹配源CP的可信层序且纸面实际近平。环状的局部循环层序按所在区域应用，不强行生成不存在的全局顺序。

滑块达到100%本身不能证明几何已经平折。改变推进历史仍可能使原求解器停在有明显应变的立体局部姿态；浏览器测试中曾出现约4.24%应变，这类姿态继续保留真实空间深度，不被显示修正压成平面。此项未修改动态求解或保证运动过程无穿透，也未运行全项目回归。
