变宽例的极限检查：把 `y=.5` 条带宽从 `.4` 提高至 `.598`，相邻 `.2` 条带之间仍余 `.001` 的内缩面边，折痕图和层序都可生成。原先固定 `0.1` 的拓扑探针会把这一有效输入误报为条带间距不足；现在依次验证原位移和较小位移，极窄面使用最短内缩边十分之一以内的位移。逐段变宽的另一保存输入需要较大的探针，专项回归同时覆盖该情况。宽度到 `.6` 时余量为零，返回“内缩边退化”，不输出候选。

工作区现对所有 `woven-lines` 候选独立求解完整平折层序；检查中、超时、无解或几何失败时禁止“采用折痕副本”。已解候选的平折画面按确认的层序显示，可切换正反面，叠层区域不能确认时只保留线框。`StationaryFace` 仍以母结构面编号输入，新增 `stationaryFoldFace` 把它映射到折痕面，平折显示使用同一参考面恢复保存的折后姿态。层序有解不证明连续折叠路径或纸张厚度可制造性。

参数面板提供上述四个具名保存样例按钮，直接加载线组、宽度、边界、奇偶、固定面及周期端点；七角星按钮标明“层序冲突，不可采用”。四组参数与独立抄录的保存输入逐项比较，并经完整工程的 JSON 回读路径 `readTessParams` 验证；加载样例总会返回新的嵌套数组，不会把上次的线宽或端点修改带入下一次。

剩余未等价：原版接受满足四度交点与内部直线条件的任意 `TGraph`，当前交互只从有限条完整方向线、旋转弦星或随机线组生成母图；原版绘图的样式、`FlopGraph2D`/`FaceupFace` 选面和隐藏线输出尚未逐像素比对；笔记本没有可读取的数值 `Out`，因此上述逐点比较是对当前逆向展开保存结果的自洽验证，不能宣称与 Wolfram 求解的每个自由褶宽数值相同。全局层序采用工作区 Rabbit Ear 引擎，未复刻原版全部枚举顺序。
