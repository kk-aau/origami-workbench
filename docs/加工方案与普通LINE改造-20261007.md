# 压痕优化方案与普通 LINE 输出

本次执行用户最新要求：加工方式始终为压痕；所有优化方案均只减少普通 DXF 的 LINE 实体数量，不生成抬笔或设备指令，也不优化空走。原工程、普通导出、坐标和单位转换保持。

## 工作区行为

| 方案 | 参数 | 实际输出 |
| --- | --- | --- |
| 共线相连合并（默认） | 最长合并长度 / mm、最多合并原段数，留空不限 | 同加工设置、精确共线、完全相连的源边合成一个完整 LINE；不会跨空白、近似拉直或改变端点 |
| 原方案 · 限制转弯 | 每条规划分组最多转弯次数，0—48,000，默认 1 | 保留原路径算法并按上限分组；每段直线仍输出普通 LINE，共线连续部分可合并；所有转弯处仍为多条 LINE |
| 保留原线段 | 无合并参数 | 保持原线段及方向，使用普通 LINE |

DXF 不表达抬笔/落笔分组。转弯次数只约束本软件的规划分组，不能保证刻字软件不会自行重排、重新拼接或逐实体加工。界面默认显示实际导出的 LINE，勾选“规划分组”才查看分组；统计始终按实际 LINE 数量。没有导出 PLT 或任何机器指令。

## 几何保护

| 项目 | 规则 |
| --- | --- |
| 普通格式 | 固定 R12 / AC1009，复用普通导出的 HEADER、TABLES、图层与 LINE 组码，不采用 POLYLINE、LWPOLYLINE 或私有扩展 |
| 坐标 | 沿用现有毫米值，Y 仅转换一次；不缩放、平移、另行居中或旋转纸张 |
| 共线 | 用 IEEE-754 的精确有理数计算判断，不引入角度容差、吸附或近似拉直 |
| 相连 | 共享端点坐标必须完全相同；未分割的交叉不擅自分段，微小间隙仍保留 |
| 长度上限 | 只限制合并结果；已超限的单条原线保留并明确提示，不自动切短 |
| 次数/重复 | 默认一次；重复或重叠先阻止，明确保留才允许；多次加工分别合并，不减少某次覆盖或回头重复合并 |
| 分组 | 不同设置仍分组，只有用户明确勾选才合并同设置线型；边界不被强制放到最后 |
| 顺序 | 不做最近邻/空走优化；结果按最早源线的位置稳定排序；未合并单线保留源方向 |
| 回读 | 校对真实 LINE 起终点、图层与数目，再核对完整相连共线链及各来源加工次数；缺失、重复、拉长或移动均拒绝 |
| 参数修改 | 参数或方案改变立即作废旧文件与预览；取消和停止保持原工程 |

合并后的线段总长与逐段累加可能有末位浮点差异，只对统计累加采用浮点误差界；坐标与覆盖校验仍严格精确，不用该误差界接受移动端点。

底层保留历史 SVG/R2000 的解析与回归代码，用于已有样本兼容；当前优化入口及工作线程只生成普通 DXF。常规“导出作品”入口保持原有格式和行为。

实际 13 边示例：默认共线输出 7 个 LINE，最多原段设 1 输出 13 个，最长设 100 mm 输出 9 个；长度均为 1400 mm。原方案转弯上限 0/1/3 对应 7/5/4 个规划分组，实际 LINE 始终为 7 个，说明规划分组与 LINE 实体是不同指标。

未验证：当前刻字软件导入/重排、V48 实物精度、提速和设备试压。未操作机器、未发布。本次不为先前纸张偏斜添加人工坐标补偿。
