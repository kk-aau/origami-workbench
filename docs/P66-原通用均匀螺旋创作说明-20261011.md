# 原通用均匀螺旋：创作、预览与导出

0.13.6源码版已完成本实用构造分支的最终验证。在同一窗口调形状、看毫米纸面、采用到工作区，再编辑、保存和导出。免安装版由root随后统一打包，产物路径与SHA以包报告为准。

| 入口 | 操作 |
|---|---|
| 镶嵌设计 → 空间构造 → 原式工具与参考示例 → 原通用均匀螺旋 CP · In[3951] | 新建构造，选择标准或扩展模式 |
| 采用后 → 修改原通用均匀螺旋纸面参数 | 预览修改、取消或重新采用；同模式再建保留工程身份 |

| 模式 | 适合的创作 |
|---|---|
| 标准构造（v1） | 保留旧工程；r>0、−90°<θ<90°、0°<γ<180° |
| 扩展构造（v2） | 更多有限数值角度，例如θ390°、γ300°，以及γ180°直线延续 |

模式需要明确选择，系统不悄悄升级旧工程，也不把390°改写成30°。θ的正负影响旋向，不代表山折或谷折。扩展模式会按原公式、数值能力和纸面条件核验；θ90°等正割奇点不能直接构造。

| 参数 | 用途 |
|---|---|
| 半径r / mm | 正数，改变螺旋尺度 |
| 螺旋角θ、折角γ / ° | 改变旋向与折角；γ为本工具的常量 |
| 原角起点/终点u / rad | 起点小于终点，可用负值；截取原绝对曲线，不重新搬回原点 |
| 左/右内切宽 / mm | 各为(0,1]，不随r自动缩放，也不自动内切 |
| 采样弦段数 | 16–128，默认100 |

1. 用默认参数开始，再调整形状。查看毫米轴、起终点和两个纸面。
2. 可勾选原单位宽参考；参考虚线不加入导出CP。
3. 若提示抵达焦点，手动减小显示的内侧宽度。左右按原构造定义，随旋向改变可能朝不同屏幕方向。
4. 等待当前参数计算完成，点击采用。等待或报错时不会采用旧图；失败输入原样保留。
5. 在工作区编辑、保存，导出JSON/FOLD/普通DXF，或使用优化加工导出生成DXF与报告。

γ180°（π）的直线纸带使用新增解析延续；原平面Sec表达式在这里没有定义，不能称原表达式原本就能直接取值。该直线可使用任意有限、递增u裁域，仍须有限图和材料接口检查。其他非零转角率纸域须少于一圈，并满足对应焦点条件；合法凹分区可采用，真实交叉或重叠会拒绝。

原世界单位对应1mm，导出保留原坐标。初始曲线U/null、纸边B/0；手改山谷属性由普通保存保留，明确重新采用原参数构造才恢复U/null。本工具输出二维CP，不附带有限刚性三维或平折证明。

最终真实主流程739项、52件按钮文件及24父场景通过，见统一验收。用户可创作总目标继续；纯理论参考、内部helper和完整Mathematica语义不作为待补创作数量。
