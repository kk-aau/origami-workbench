# 第 32 节：临界角尺度与赋型边界

Origamica 保存输入 In[2702] 用五边形 `{{0,0},{1,-0.5},{1.8,-0.2},{1.5,0.5},{0.5,0.7}}` 查询 `ThreeCycleCriticalTwistAngles`。原函数用线交与边向量求角；整体平移或正比例缩放不会改变角度。现有实现却对线交行列式和半平面叉积使用固定绝对阈值：原尺寸得到三循环 `42.87614608194722°–140.60184834770803°`，缩小至 `0.01` 倍便错误地返回“无适用的边组”。

现在以两方向向量长度之积归一化行列式，并以边长之积归一化半平面叉积；三边闭合判定也随边长缩放。保存五边形在 `10⁻¹–10⁻⁶` 倍、再平移后的两类临界角与原尺寸相差小于 `10⁻⁷°`，原版默认 `CheckHalfPlane → True` 的数值语义保留。

另按保存的 `RegularPolygonTwistValidQ` 例核对了临界值本身：`n=3` 的 30°/60°、`n=4` 的 45°、`n=5` 的 54°/72° 在相应赋型下均是**包含**的边界，越过边界 `0.0001°` 后无效；以 `180°−α` 对称的边界同样成立。循环枚举保留旋转等价、反射和 M/V 反转彼此不同的原规则。

分析弹窗现对超过 12 边的直接调用只运行临界角和当前赋型的数值判据，省略指数增长的循环赋型枚举并明确提示；不再因枚举上限抛错。13、24、64 边专项输入均返回可查询的临界角，Vite 服务端实际渲染的三种弹窗也均显示临界角、当前赋型和省略提示；12 边的 352 个旋转等价赋型仍保留。这里是弹窗防护，不代表普通 `twist` 构造已扩至 64 边；64 边入口属于独立的 `circular-twist` 构造。

笔记本该段保存的是输入与绘图调用，没有可提取的 Wolfram 数值 `Out`；上述五边形数值由保存公式在本地重算，并由相似不变量交叉检查。临界角与赋型查询是局部设计谓词，不证明整片折痕的全局层序或物理折叠路径。
