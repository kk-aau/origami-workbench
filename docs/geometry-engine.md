# 几何、格式与平折引擎边界

版本：2026-10-26。所有接口在 `src/core`，不依赖 DOM，不读写用户文件。界面不得把本引擎的结果描述为刚性运动、无碰撞或有厚度纸张的可制造性证明。

## 数据与接口

- `Doc`：毫米坐标；真实纸边界是 `assignment:'B'` 的线段，`paper.width/height` 不是隐式边界。负坐标不移动；视图原点应从边界坐标包围盒计算。
- `M/V/B/U/A/F` 分别为山折、谷折、边界、未指派、辅助、展开线；M/V 与颜色解耦。
- `angle` 允许 `null`，表示未指定；M 非正、V 非负。FOLD 中明示 null 保留，缺少整个角度数组才按山谷默认值恢复。
- `buildFold(doc)` → `{graph,warnings,edgeSourceIds}`。计算副本拆分交叉/T 交点和共线重叠，合并同型重复边；冲突重叠拒绝。辅助线不参与划面，源工程不变。
- `diagnose(doc)` → `{issues,summary}`，问题含中文说明、严重性、源线段 IDs 和可选定位坐标。
- `importDocument(text,format,name?)` / `exportDocument(doc,format,options?)` 返回中文 warnings；不在函数内触发下载或覆盖文件。CP 默认按实际纸边居中、最长边等比缩放到400；`options.cpCoordinates='original'` 保留原始坐标。两种方式均不修改输入工程。
- `startFlatFold(doc,{timeoutMs,onProgress})` → `{promise,cancel}`；编辑区默认按实际面数使用 10 秒（少于 256 面）、60 秒或 180 秒（至少 10000 面），用户手动设置优先，最长 600 秒。每个任务独立 Worker，取消/超时真实终止线程。先发布几何，再求层序；层序超时/取消时保留已完成几何。复杂凸面模型默认先求完整验证的合法候选，不虚构编号或总数；显式指定 `solutionIndex` 时继续精确枚举。
- `computeFlatFold` 为同步测试/Worker 内入口，不应在界面主线程调用。

## 几何与局部检查

可编辑线段、交点切分后的边数及工程文件大小不设固定数量或大小上限，实际处理受可用内存和计算预算约束；独立绘图对象仍保留 `src/core/capacity.mjs` 中的单独校验。交点与吸附索引按包围盒筛选候选线段，密集重叠情况下仍受实际相交数量影响。平折几何与三维均不设独立的 200 面上限，凸面层序没有独立的 70 面上限，由 Worker 超时限制搜索；凹面路径仍执行其几何和材料身份校验。buildFold 统一构建纸面，由模拟引擎独立验证三维网格。算法使用尺寸相关容差 `max(1e-6 mm, max(width,height)*1e-8)`。

检查零长、重合冲突、重复线、交点、边界闭合和分叉、悬空边。川崎/前川只针对内部顶点；边界顶点不套用完整圆周条件。F 展开边不计折痕数。U 未指派线参与角度检查，但不能判断山谷数量。检查通过仅表示这些必要条件未发现问题。

平折几何采用 Rabbit Ear 面反射矩阵，再验证共享顶点经不同面路径变换后的一致性；不是任意生成树结果直接冒充正确平折。几何成功后独立求层序，使用真实 Rabbit Ear taco/tortilla 约束求解器，提取完整有效分支而不展开所有组合。

当前不支持多闭合边界、孔洞、多张纸、切口。简单凹面的层序通过[受限原面商约束路径](受限凹面层序生产接入-20260924.md)：三角化仅用于覆盖判定，同一原面对只有一个层变量，原面拓扑不变；上限为 20 原面、48 三角片、128 原面对、2048 子句、50000 搜索节点。构造容量/数值/可见面约束不支持为 `unsupported`，搜索节点超限为 `unknown`，仅完整精确计数为零才是无解。未指派 U 只能展示完全折叠的几何候选，层序为未知。非 ±180° 的目标角不参与平折，源工程保留给三维预览。

`geometry.status` 与 `layers.status` 独立。层序区分 solved/no-solution/unknown/unsupported/timeout/cancelled/error。超时、取消、异常不是无解。

折痕编辑的源图整理也在可取消的平折 Worker 内完成，返回源 CP 图后按实际面数选择原有自动预算；手动预算优先，整个任务不因阶段切换重新计时。画布提示分别报告准备、几何、层序与后续局部遮挡计算，终态明确解释线框。正背双视图复用同一折叠解、覆盖几何和已验证的局部层序，按观察方向分别确定可见边线；未开启纸层阴影时不计算阴影。取消一个视图的订阅不打断仍在使用该任务的另一视图。

一个文档可包含多张 CP。“追加 CP”保持毫米尺寸并移到现有内容右侧；“折叠选区”只提取一个完整闭合边界中的折线，补入原有被保护纸边，不把框选矩形伪造为纸边，不裁断漏选或越界折线。各模型保留独立来源 CP；来源有效性按真实折叠输入与选区范围检查，区域内新增/删改使结果过期，区域外编辑不使其过期。完整作品保存现有全部 CP 与模型视图。

整页计算前仅用真实纸边保守识别彼此分离的完整 CP，确认多个后立即提示使用“折叠选区”，不构建整页纸面。破边、嵌套/相交边界及显式材料拓扑继续走原校验。选区检查复用纸边空间索引，仍执行原包含、交叉与漏选判定；同一文档的边界索引可供来源检查复用。

`faceOrders` 是 FOLD 法向约定的关系三元组，不是画面堆叠索引。成功得到 `faceOrder` 时可按其绘制遮挡；不能线性排序时使用完整且有序的局部区域表面，未返回或不完整时只展示几何线框，不得用任意面序假装实体正确。

大型凸面候选将面关系分为强连通分量。根关系有环时，保留分量之间已有的确定顺序作为搜索偏好；分量内部仍允许回溯，不能把偏好当作新约束。每个候选重新计算分量，三面循环仅可能位于同一分量内，因此只对这些组合执行原精度的几何交叠复核。全部接触约束和完整的零违例终检保留，不用全局有环代替局部无解判断。

接触约束以空间索引和已有接触关系倒排生成候选，再执行原精确几何谓词。三面循环以有序邻接交集枚举，每批补充约束后仅从根传播闭包刷新搜索偏好，不保留候选猜测。规则直接写入紧凑数组，避免同时保留一份大型临时数组。

完整作品自动恢复的序列化、模型源拓扑校验在专用 Worker 中执行；只有完整输入相同且已通过校验的模型快照才复用。源折痕、几何或约束改变必须重新校验。暂存周期与保存格式不变，切换作品或卸载时终止旧线程；撤销历史和旧层序本来就不属于保存格式，不随暂存请求跨线程复制。

局部实体显示优先使用连通平面图的有界区域，检查 Euler 数和简单边界；凹区域仅在显示副本中三角化以保持凸区域接口。孔洞、弱边界和不连通嵌套继续使用垂直分解。最大区域的覆盖查询与边线间距查询通过包围盒保守筛选，再执行双精度包含/距离谓词；垂直分解按原面外环和孔洞的边界归属确定覆盖。覆盖集合相同的区域复用层序；边线复用同一平面分割，不显示私有三角化产生的对角线。

局部实体显示有独立预算：不足 10000 面为 10 秒，至少 10000 面为 60 秒；超时保留已确认层序与线框，不称为无解。计算在可终止 Worker 中进行，延长预算不能保证所有复杂数据都能在可用内存内完成。

显示平面化使用模型坐标中的线性容差和真实交叉事件，避免依赖上游平面化的隐式参数容差。原端点生成稳定的显示坐标副本，覆盖、孔洞、边界及可见面子集共享该副本，不修改原模型。无法验证为简单平面区域时，沿源边进行垂直分解：在相邻事件簇之间取样，按每个外环／孔洞跨边的奇偶状态更新覆盖，纸面须位于外环内且不在任何孔洞内；同环重复边相互抵消。连续区间只有上下边及完整覆盖集合都一致才可合并，真实交叉和屏障保护保留。真实细小纸面、孔洞或极窄区间在显示精度内省略时保留诊断，结束提示分别解释区域遮挡、细小区域和边界可见性，不将分解成功等同于全部纸面已确认。

局部层序在全图无环时复用拓扑排序；全图有环且关系稠密时用有界位矩阵计算局部入度，完整有向比较图仍须证明其入度为 0…k−1，缺关系或反向冲突继续执行局部拓扑检查。正背面共享相同覆盖的已确认层序对象，不逐个区域重复复制逆序数组。只有覆盖面积核对通过、从未可见且不涉及未确认区域的深层纸面，才从可见边候选中排除。

大量折线的编辑画布按每组 512 条挂载 SVG 节点，保留线段顺序和全部拾取节点，避免导入时同级节点插入的重复扫描。包含凹面的模型仍受凹面算法构造范围约束；超出范围会明确结束并保留几何线框，增加时间预算不会改变这种不支持状态。

## 文件互通

- JSON：完整本工具工程，优先保存格式；未知扩展移入来源元数据并提示。
- FOLD：单帧二维 creasePattern；非零 Z、foldedForm、依赖父帧、多帧均拒绝，不静默选第一帧。已知物理单位转毫米，unitless 明确提醒。未知线型（如切口 C）拒绝。原拓扑/层序不重用，保存在来源元数据；编辑后重建。
- A 辅助线以 `zhezhi_auxiliary` 扩展保留，其他软件可能忽略并明确提示。来源 metadata 写入 `zhezhi_metadata`，不作为有效引擎约束。
- CP/OPX：0辅助、1边界、2山、3谷。缺少单位按毫米读并提醒。导出不保留任意目标角、完整工程、历史等，有明确提示；U/F 不支持，拒绝导出而不偷偷转线型。
- OPX 仅解析白名单数据，不执行 Java。拒绝 DTD/实体声明、未知对象、缺失数组项、过深嵌套。兼容 Bean 属性与 Java XMLEncoder 的 public-field 编码。原始非几何字段保存在元数据。
