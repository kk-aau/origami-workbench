# 操作框几何核心（界面尚未接）

本轮完整读取本地 MouseHandlerOperationFrameCreate、OperationFrame、OperationFrameSelectAction。模式61为屏幕坐标操作框：框外拖动创建，框内移动，近边调整一边，近角固定对角调整；框面积小于1屏幕像素平方时失效。进入模式清空选区，reset清框。最终框供背景裁剪和区域导出共同使用，不写折线几何。

新增 app/operationFrame.ts：

- frameBetween/frameCorners：标准化屏幕矩形；所有拖动方向一致。
- beginFrameDrag：以原始鼠标命中分类，角优先于边，框内移动，框外重建；新建点可由调用方传入单独吸附坐标。角重叠时目前选择最近角（稳定按索引破同距），与上游顺序覆盖的极小框退化行为仍需动态对照。
- updateFrameDrag：引用开始时的独立快照，不积累逐帧误差；跨越对边后正常化，不改变固定对边/对角。
- finishFrameDrag：小于1px²返回null，与上游无效小框一致。
- frameWorldBounds：以当前而非创建时相机换算导出世界范围，保留屏幕框不动；校验±1e6mm范围。不包含栅格裁剪或图像重编码。

7项测试涵盖四向创建、吸附锚点独立性、四角优先和跨越、四边仅改目标轴、整框移动不漂移、无效小框、当前相机导出范围和非法值。514全量单元通过；初次构建暴露联合类型收窄问题，拆成独立判别分支后TypeScript/Vite通过。构建产物未增加UI或工具入口，仍81。未浏览器测试，未升级模式61目录状态。
