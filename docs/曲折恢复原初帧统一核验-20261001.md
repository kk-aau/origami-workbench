# 曲折恢复原初帧统一核验

一般展开、一般重塑、九源双侧展开和六源三维恢复现在共用同一初帧核验原则：保留用户原值，把输入接收容差和形式身份的初始条件核验分别处理。

| 项目 | 行为 |
|---|---|
| 原输入 | 继续按原单位／正交输入合同的1e−10容差接收，原tti及bbti等不会被归一化或替换。 |
| 初帧证据 | 由实际初始基向量计算 max\|FᵀF−I\|，单独显示残差；数值相容阈值为64倍binary64机器epsilon。 |
| 数值与形式分级 | 初帧未相容时，即使有限EFG在2e−8门槛内，也不能因此把形式等距或共同展开标为通过。 |
| 条带证据 | 初帧未相容时，形式目标条带为unknown，方向和下界为null；独立源条带的正则性保持原实际判断。 |
| 图像 | 继续显示原值积分得到的真实双图，不用归一化重算图掩盖问题。状态区保持固定高度。 |
| 证书边界 | 这是ODE初始条件的数值相容检查，不是用户浮点输入的符号精确性证明，更不等于积分轨迹误差的严格区间证书。 |

| 统一验收 | 证据 |
|---|---|
| 四入口真实API | 一般展开／重塑、九源展开的ttiₓ=1.000000000045及六源tti=(1,9e−11,0)均保原值；形式旗标false且有限图像保留。 |
| 主App九场景 | 三入口×1000／760／390×720全部双图和字段可见、无工具滚动；初帧未相容时状态区不移动。六源原初帧已另纳入其26场景。 |
| 独立60位复核 | 两个旧审计已扩大覆盖三个near-frame夹具。一般重塑另用原初帧MP-RK4双分辨率独立积分，九源及一般展开使用保原初帧长度的独立闭式。 |
| 永久回归 | Python新增两条统一门槛测试；一般Darboux、九源和六源TS严格解码器分别验证旗标、原向量及证书绑定；服务接口同样回归四入口。 |
