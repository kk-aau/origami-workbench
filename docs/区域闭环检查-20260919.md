# 区域闭环检查（模式63）

入口：左侧“区域检查 → 区域闭环检查”，共86个绘图入口。原版名称为多边形可平折检查，实际是闭环反射几何检查，因此工作台使用更精确的名称。

## 操作

依次自由点出轮廓，也可按住拖动后松开确定当前末点；首笔拖动可确定首边。至少三个点后靠近首点点击，或点击“闭合并检查”。不吸附网格/折线，只在闭合时近距回到首点，因为轮廓应横穿线段内部，不能碰顶点或沿折线走。

未完成轮廓使用紫色参考线。完成后显示几何一致（青色）、几何不一致（红色）或无法判断（赭色），并给交叉编号、数量及适用时的回位误差。通过只表示这一条闭合路径的反射几何一致，**不证明山谷赋型、层序或整个模型可平折**。无交叉也会说明它不能证明区域可折。

“撤回末点”用于修正轮廓，同时清除旧结果；“重新绘制”、右击或Esc清空检查。平移/缩放保留轮廓；切换工具或作品变化清除它。结果显示后不会因为额外左击静默改变，须先撤回或重画。临时检查不写入工程、不导出、不新增撤销记录。右击优先清除当前操作；下一次空闲右击恢复通用删线。

## 上游依据与扩展

完整阅读本地MouseHandlerFlatFoldableCheck。沿轮廓逐边将横穿线按距离排序，原版折线色编号小于3（边界/山/谷）参加反射；A/F不参加。奇数次交叉不一致，偶数则将首条线关于后续支撑线依次反射，两端回位容差1e-4。任何非X接触均不适用（包括辅助线接触）。工作台对未指派线、重复交叉、自交/折返等增加明确“无法判断”，不伪报通过。闭合按钮/撤回末点是工作台便利扩展；第一笔单击不会立即闭合零长路径。

算法当前同步O(轮廓边数² + 轮廓边数×工程线数)，没有伪造面数上限；超大轮廓性能仍需验收。大坐标、近退化和完整上游动态对照仍待继续；该工具不能替代已有平折求解或全局检查。
