# 折纸工坊 Tauri 本地体验版 0.13.41-tauri.14

日期：2026-10-28。本版仅本地交付，未上传发行站。基于迁移版持续开发，保留完整离线计算引擎，原 `workbench/` 不变。系统须已有 WebView2，无需另装 Node 或 Python。

| 本次变化 | 行为 |
|---|---|
| 原生文件保存 | 主图、折序、三维 iframe 与专用工具统一由 Rust 打开另存为并写入文件，不经过桌面浏览器下载器 |
| 保存反馈 | 文件实际提交后才报告成功；取消或失败保留原文件；使用有界分块传输，没有固定文件大小上限 |
| 纸边过滤 | 按各纸层的原始 CP 跳过与纸边重合的部分，保留原边界、已完成折痕及其他纸层的有效折线；真实线型冲突仍提示 |
| 纸层搜索 | 在纸层列表输入 F 编号或数字进行筛选，可清空，固定、隐藏、选择与真实层号保持 |
| 工具分类 | 类型只留四种绘线选择；赋型、互换、循环归变换，交替归修复；旧默认分类自动迁移，自定义布局保持 |

保留上一版的折痕目标角度、真实空间主图与步骤动画。空间分支不支持有限短折痕的柔性压痕；不相容的刚性折角仍会明确提示，几何终态不代表连续运动无碰撞。

本地交付目录：`release/Tauri-0.13.41-tauri.14/`。运行其中 `Portable.exe` 即可体验，也可选用安装版。完整对应源码 ZIP／7z、独立调试材料与 SHA256 同目录提供，应用包不内嵌源码或调试材料；运行不需要下载源码附件。

构建、冻结源码、引擎复用、最终双 EXE 解包与真实应用验收记录位于 `output/tauri-release-0.13.41-tauri.14/`。最终 `RELEASE-0.13.41-tauri.14.json` 仅在全部验收完成后生成；本说明本身不代表验收已经通过。
