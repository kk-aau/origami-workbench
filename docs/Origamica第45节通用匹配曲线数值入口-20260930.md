# 第45节通用匹配曲线数值入口

本入口已实现原 `MatchCurvesPair` / `NMatchCurvesPair` 的有界纯数值源函数职责：输入同参数的平面曲线与空间曲线，按原 ψ、σ 构造真实母线和有限带面。它保存五个源表达式原文，并返回源导数及分开的数值、区间、全局充分证据。通用数值入口不等同于完整 Mathematica 符号系统或精确直线折痕 FOLD。

| 来源与接口 | 具体职责 |
|---|---|
| 原 Notebook In[3864] | `MatchCurvesPair[c,cc,ψ,σ,opts]`，同一参数下两条曲线须同速，输出 `{c,d,cc,dd}` |
| In[3867] | N 版用数值曲线系统和函数插值得到同一匹配公式。标题漏写 σ，但定义及 In[3868] 调用均有 σ |
| In[3865]/[3868] | 原圆例：`c=(2 cos(s/2),2 sin(s/2))`、`cc=(cos s,sin s,1)`，ψ=σ=1，s∈[0,π]、w∈[−1,1] |
| 后端生产模块 | `backend/tessellation_curved_matched_pair_query.py`，导出 `query_curved_matched_pair(data)`；operation 为 `curved-matched-pair` |
| 输入 family / variant | `curved-matched-pair` / `generic-native`，不增设原配对公式不存在的 Newton 或 ODE 初值 |

## 安全输入与完整域

| 字段 | 数值合同 |
|---|---|
| `flatCurve` / `spaceCurve` | 2 / 3 个只含 s 的标量表达式；每个 1–240 字符、AST 至多96节点，常数绝对值≤10¹² |
| 运算 | 四则、−8…8整数幂、sin/cos/tan/atan/sqrt/exp/log；支持原输入器的对应 Wolfram 函数书写及隐式乘法 |
| `psi` / `sigma` | 固定整数 −1 或 +1，布尔值不作为分支；全域不逐点翻支 |
| `parameterStart/End` | −10≤start<end≤10，跨度0.01–12；不会自动改成弧长参数，也没有正 q′ 门禁 |
| `transverseStart/End` | −10⁶≤start<end≤10⁶；保留世界长度单位，不要求域包含0 |
| `segments` / `rulingSegments` | 曲线8–128段，横向偶数2–64段；它们是显示密度，不是全域证明密度 |

解析器只检查和递归解释白名单 AST，源字符串不会传入 eval、SymPy 字符串解析或任意执行。未知字段、自由名、属性访问、导入、函数对象与不合法分支会拒绝。输入或真实标架退化错误均为 ValueError 子类，HTTP 分派可返回422。

## 原母线与相容条件

以下撇号全部对共同参数 s 求导。平面 `v₂=|c′|, t=c′/v₂, l=Rot90(t), κl=det(c′,c″)/v₂³`；空间 `v₃=|cc′|, T,N,B,κ,τ` 为源 Frenet 系统。κl 保留符号，参数反向和镜像均保留原帧方向。

```text
C = κl/κ,       S = ψ sqrt(κ²−κl²)/κ
L = C N−S B,    U = S N+C B
A = U′·T = −v₃ κ S
Q = U′·L = −C′/S−v₃ τ
H = sqrt(A²+Q²)
p = −sign(A) Q/H,   r = |A|/H
d = σ(p t+r l),     dd = σ(p T+r L)
X(s,w)=c(s)+w d(s), Y(s,w)=cc(s)+w dd(s)
```

严格曲率差使 A 的符号固定，无需求根选支。源坐标四阶 Taylor 导数足够产生标架、母线和它们的一阶 s 导数。生产通过上面的 Frenet 恒等式求 U′ 两个分量；独立审计直接求源 U 的导数核对，不复制该计算路径。

同速 `v₂=v₃=v` 时，`T′=vκl L+vκS U`，母线式给 `dd′·U=0`，两侧在 t/l 和 T/L 中的母线导数系数相同，因此完整连续 E/F/G 相等。速度失配时 w=0 的 E 已不同，需要调用者显式给共同重参数曲线，不能靠调曲率比或自动改源修补。

有限带的平面雅可比对 w 是仿射：

```text
J = σ v₂ r+w(r p′−p r′−v₂ κl)
```

空间速度0、空间曲率0、`κ²−κl²≤0`、未定义 H/母线，或真实有限宽度触焦线/倒向会拒绝。平面左曲率为0本身并非拒绝条件。原式曲率差触0可能存在别的几何构造，但不是这里有定义的正则分支。

## 原尺度、来源与样本接口

固定相似归一化长度 `scale=|c′(parameterStart)|`，两个 origin 分别为平面/空间源起点。源加性常量与动态项先分开，动态差用补偿算术求值；因此10⁻⁸尺度叠10⁹平移不会先被世界坐标相减吃掉。微小世界坐标仍受 binary64 的表示分辨率限制，可信的几何检查使用归一化字段和保存源原文。

每行返回 `s,c,d,cc,dd,cPrime,dPrime,ccPrime,ddPrime` 及对应八个 `normalized*` 字段。d、dd是世界单位母线，归一化母线及其导数为世界值除scale；归一化基线以origin平移并除scale。网格点保存原世界横向参数w、flat/space和normalizedFlat/Space。诊断 EFG 在规范长度坐标中计算，`ds=normalizedCPrime+(w/scale)*dPrime`、`dw=d`，因此G=1；`maximumMetricDifference`不是未归一化世界长度平方残差。

完整 exact-key contract 见 `output/audits/p45-matched-pair-contract-20260930.json`。query 中五个表达式逐字保留；source 固定标记源单元3864/3867与保存例3865/3868，但 `savedNumericalOut=false`。前端须独立重算源、ψσ、导数、归一化、EFG与证据依赖，不能只相信布尔证书。
