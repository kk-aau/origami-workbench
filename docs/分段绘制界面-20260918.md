# 分段绘制界面与提交

2026-09-18，v0.9.2 开发版，未打包。27／28 两入口接通，当前 64 项实际工具，上游动态逐例对照仍待做。

- 画线并等分：设置 1–1500 的整数等分数，两次点击或左键拖画；生成真实小段而非标记点，现有分割命令仍独立。
- 根式比例画线：六参数 S=a+b√c、T=d+e√f，显示有效 S:T；从第一点计算 S 对应分段。支持零比与外分，非法比和或退化结果中文提示，原作品不变。
- 界面沿用紧凑工具栏；根式系数控件固定小宽度，窄屏参数组换行。紫色参考小段和分点，不随山谷预设改变预览颜色。参数改变取消当前操作；右击／Esc 取消、空闲右击删小段，统一提交一次撤销。

## 提交修正

新增 appendDividedLine：先对候选与原线做共线类型／角度冲突检查，再把原线和候选一起真实交点拆分，最后只去掉本次新增的重复小段。因此在同型已有整线上重新等分不会抹掉新增分点，原线 ID 尽量保留。无关旧重复线、辅助圆不清理。零比或重复同一分段返回原 doc，不记新历史。

容量检查移到最终拆分和去重后，避免暂时的重叠候选导致误报超量；生成核心仍限制单次候选数量与坐标。超过最终 1500 条则原子拒绝。核心说明中的早期“总容量在候选阶段检查”以本说明为准。
