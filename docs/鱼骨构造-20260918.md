# 鱼骨构造

后续输入更新：可两次点击，也可按住左键拖动基线，松开定义第二点并进入预览；原位点击后松开则仍等待第二点。拖动中右键／Esc可取消。本页下方保留初版验证范围，原版严格已有点限制仍未独立提供。

开发版v0.9.2，未打包；位于“精确作图”。

1. 点击基线起点，再点击终点。
2. 检查紫色鱼骨预览，以及面板的间距、跳过点和无截止方向数。
3. 点击“确认鱼骨构造”或紫色结果线。空白点击不会提交。

间距取当前可见纸张范围宽度／网格等分数；改变等分数会即时重算预览。基线只作参考，不添加到工程。从起点按间距取点，到终点以内为止；每个取点沿垂直基线的两个方向到第一条实际非辅助折线或纸边。某侧无截止不绘制该侧；两侧均无截止则该点无结果，不凭空画无限线。

当前山／谷线型决定第一取点，之后逐取点交替；点落在既有非平行线身上时跳过，但交替相位继续推进。未指派、辅助和边界等其他线型保持不变。已有折线折角不修改。两侧连接为完整有限线，相交后真实分割；整个操作一次撤销，支持保存恢复。

依据固定本地Oriedita模式33的MouseHandlerFishBoneDraw及排除平行线的距离判定。本版目前是两次点选（支持自由／吸附点）加确认，原版受限拖画尚未接入；未声称全部交互等价，未做上游运行时逐例动态对照。
