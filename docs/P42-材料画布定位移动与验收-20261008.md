# 第42节材料画布定位移动（2026-10-08）

完整镶嵌复现目标保持 active。本批补齐材料两点移动和四点移动，保留此前材料复制及普通折痕工具。源码与网页构建已更新，现有 0.13.5 免安装 EXE 未重打包。

| 痛点及改造 | 当前实际行为 |
|---|---|
| 普通线段移动不能承载材料图 | 原普通工具会替换移动线段 ID、裁剪目标重合部分。材料两点/四点移动现提交专用意图，中央提交层从原材料和参考点完整重放，再原子写入历史。 |
| 两点定位 | 选完整材料部件后，以基准点到目标点的原平移公式同时移动 CP 和已有 FF；支持两次点击和工具内拖放。 |
| 四点定位 | A→C、B→D，直接使用原复数相似变换，支持平移/旋转/正等比缩放组合，不拆角度重复计算；四点仍取已有端点或交点。 |
| 保持身份 | 顶点、边、面、逐角面边关联、切口双侧及部件身份全部保持。重叠/接触不会合并，移动到已有同位置材料也不裁剪。原山谷、折角、颜色和线段 ID 不变。 |
| 选择与纸边 | 材料部件选择器支持全部或单部件移动。部分边选择明确拒绝；移动纸边必须先关闭边界保护。复制入口仍可在边界保护开启时新增独立副本，两类操作规则不混淆。 |
| 未选内容 | 未选部件 CP/FF、未选辅助线、纸张参数、独立文字/圆/底图和其他元数据保持原值。明确选中的辅助线一同移动，不加入材料索引图。 |
| 起始面与模型 | 同一个起始面索引及新坐标轮廓同步更新；旧层序过期后重算，不复用旧模型证书。没有 FF 的材料继续缺省，不编造折后坐标。 |
| 无位移处理 | 相同两点或相同四点映射明确拒绝。修复相同参考点下浮点加减产生微差并误建历史的问题，不把舍入误差当成用户移动。 |
| 预览/取消/历史 | 鼠标预览只做选中参考线的点映射，完整图校验和复制仅在提交时执行。Esc 取消不写入，支持整组一次撤销/重做。 |
| 坐标与导出 | CP/FF 都应用相同世界坐标定位公式。普通 R12 LINE DXF 沿用原毫米单位与一次 Y 转换，无新的镜像、缩放或设备指令。 |
