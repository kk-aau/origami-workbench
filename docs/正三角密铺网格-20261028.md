# 正三角密铺网格

用户于 2026-10-28 撤回自定义角度输入，要求保留对角网格，增加正三角形密铺。仅开发迁移版；原项目未改，不打包、不上传、不改版本。

| 项目 | 当前行为 |
| --- | --- |
| 入口 | 右侧“画布 → 网格与吸附 → 网格格式” |
| 格式 | 方格、方格＋对角、正三角 |
| 方格修正与旋转 | 方格横纵使用相同格距；方格及其对角参考线支持绕纸面中心整体旋转，见 [正方格与旋转](正方格与旋转-20261028.md) |
| 正三角 | 0°、＋60°、－60° 三组等间距线，六个等边三角形围成正六边形，保留内部三角分割 |
| 等分 | 三角形边长为工程固定纸张基准宽度除以等分数；行高为边长的 √3/2，边界增删或重画不改变格距 |
| 对齐与范围 | 锚定固定基准原点 `(0,0)`；闭合时按真实纸面及孔洞裁切，未闭合时保留基准矩形内参考网格；全画布网格延伸到视口 |
| 吸附 | 使用实际三角节点及有限可见线段与网格的交点，不吸附旧方格的虚假节点 |
| 导出 | 画布与 SVG 共用周期网格图案；PNG／JPG 沿用 SVG 导出内容 |
| 偏好 | 保存格式；旧自定义角度被忽略，颜色、线宽及密度保留；重置恢复方格 |

之前修复的构造紫线取点、角度拖画／投影、受限圆、线网格交点吸附保留。内部旧角度字段仅供兼容调用；主应用已移除角度输入和偏好使用，不会继续应用旧角度。

网格采用周期 SVG 图案，不随视口范围枚举所有网格线，避免放大导出范围造成额外的大量几何对象。
