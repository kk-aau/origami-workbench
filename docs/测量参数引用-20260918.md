# 测量参数引用

本轮接通根式比例画线的六个系数，以及自定义角度 ABC／DEF。可输入数字或完整的 `L1`、`L2`、`A1`、`A2`、`A3`，回车或离开输入框提交。L 使用格单位；不支持算术表达式。

引用采用提交时快照，显示解析后的数字；之后重新测量不会改变已提交参数。范围不合法、非有限数字和未知表达式显示错误，不覆盖原有效值。负角填入非负角度或根号字段会报错，不自动转换。Esc 放弃草稿并保留正在进行的画布构造；有效参数提交重新开始构造。

专用 MeasurementField 不改变其他普通 NumberField。五槽值及长度详情属于工作台会话，跨工作区保留，刷新重置，不写作品和撤销历史。其他上游支持引用的参数字段仍需逐项核对和接入。

验证：453 项单元测试、构建通过；引用专项14、分段绘制26、角度设置14、取消优先级17，共71项浏览器断言通过。分段绘制夹具显式重置默认根式参数；角度设置刷新测试显式恢复作品。角度工具脚本更新文本字段选择器，本轮未重跑，不计入通过数。截图 measurement-reference.png 已检查。

工具入口仍71项，不代表全功能完成。未打包；既有大构建块警告保留。测试使用隔离的8799服务和 measurement-reference-data，未改正常8787与用户作品。
