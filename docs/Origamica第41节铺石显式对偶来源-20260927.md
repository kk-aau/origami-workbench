# Origamica 第 41 节：铺石显式对偶来源

原版第 41 节的平行褶铺石以 `TPrimalDualGraph` 为输入。保存的 `In[3390]` 先对五面母图执行 `MakeReciprocalDiagram`，再以 `ρ=0.5` 构造铺石；`In[3393]` 则在构造前明确执行 `ReplaceProperty[DualVertices -> dverts]`，注释称这些原始点会建立垂直关系。因此，对偶点已满足共享母边的垂直约束且方向为正时，它们就是铺石输入的坐标；再次重排会改变指定的来源几何。

| 核对项 | 修复前 | 修复后 |
| --- | --- | --- |
| `In[3390]` 保存的五面母图，附加一组已垂直的显式对偶目标 | 后端仍运行 MaxMin 优化，首个对偶点偏离目标约 `0.1396636401`。 | 在每条内部母边核验垂直残差及正向双褶宽度；目标可行时直接保留全部输入坐标，回归误差小于 `1e-9`。 |
| 默认来源 | 原有 MaxMin 均衡双褶。 | 未提供目标时仍执行原有 MaxMin；已保存的最小双褶宽 `2/3` 回归保持。 |
| 不可行的编辑目标 | 作为软目标求解。 | 保持软目标行为；把一处目标沿切向扰动 `0.1` 后会重新求解，不会假装目标已经垂直。 |
| 编辑母参数的提示 | 声称旧对偶目标仍保留，实际会清除顶层旧目标。 | 提示明确说明：铺石层旧对偶目标清除，新母参数 JSON 中的修剪／对偶设置按新内容读取。 |

实现位于 `backend/tessellation_flagstone.py`；入口和验证用例位于 `backend/test_tessellation_flagstone_sources.py`，提示位于 `src/components/FlagstoneSourceControls.tsx`。测试复用 `In[3390]` 的母图及独立垂直对偶求解器提供的可行点，验证 `In[3393]` 所要求的**先指定对偶、再构造铺石**语义。它不宣称重建了 `In[3393]` 的完整 25 点急角三角化，也不宣称与未保存数值顶点的 Mathematica 图像逐点相同。

验证：Flagstone、倾斜局部、Advanced、Voronoi、Penrose、Primal-Dual 六组后端专项共 40 项通过；`tsc --noEmit` 通过。

剩余界限：`In[3391]` 的 3.4.6.4 与 `In[3392]` 的 Penrose 母结构虽有当前来源入口，本轮未获得原版可机器比较的数值折痕输出；`In[3393]` 的完整急角三角化尚未逐边核对。结果元数据现按输入区分“可行输入对偶／MaxMin 回退”和无目标的 MaxMin，专项测试固定该标签。一般铺石的局部条件检查不证明全局平折层序。
