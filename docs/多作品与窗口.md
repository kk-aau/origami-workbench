# 多作品与窗口

一个作品标签包含这份作品的折痕、基础形设计、镶嵌、三维状态和折序绘图。标签下方的工作区切换属于当前作品；点击另一个作品标签后，工具和保存命令作用于新选中的作品。

| 操作 | 使用方式 |
| --- | --- |
| 新建作品 | 顶部“文件 → 新建作品”、标签栏的“＋”，或 Ctrl+N |
| 打开另一份作品 | 最上方的“打开”、顶部“文件 → 打开作品”，或 Ctrl+O；在新标签中打开 |
| 切换或排序 | 点击作品标签；拖动标签调整顺序；方向键可切换同组标签 |
| 标签快捷操作 | 右键打开保存、分组和关闭菜单；中键关闭；双击打开工作区选项 |
| 标签较多时 | 滚轮横向滚动，或使用标签栏右侧的作品列表；选中标签与关闭按钮自动保持可见 |
| 并排编辑 | 顶部布局按钮或“窗口”菜单选择左右并排、上下并排、平铺；拖动分隔线调整大小 |
| 自定义分组 | 将另一个标签拖到目标标签栏的左、右、上、下分组位置 |
| 独立窗口 | 拖动标签到当前应用窗口外，或使用“窗口 → 移到独立窗口” |
| 合并窗口 | “窗口”菜单将当前作品移到已有窗口，或将所有窗口的作品合并到当前窗口 |
| 保存完整作品 | Ctrl+S；Ctrl+Shift+S 另存作品。仍使用不压缩的 ORIW 格式 |
| 关闭作品 | 标签右侧“×”、Ctrl+W，或“文件 → 关闭当前作品” |

顶部只保留一套应用菜单与作品标签。当前工作区的独立打开、保存、导出在“文件”菜单中，显示、快捷键、保存目录、帮助和日志等收纳在“工作区选项”。Ctrl+S 始终保存完整作品；菜单中“保存折痕／设计／折序工程”仅保存对应工作区。

折痕画布不再常驻“全选／全部撤选”工具行。点击左下角当前工具标签可打开向上的选择菜单，也可使用 Ctrl+A 和 Ctrl+Shift+A；全选仍遵守可见图层和保护边界设置。

每份作品保留自己的内容、撤销记录、草稿、恢复记录和计算任务。移动到另一个窗口会保留原编辑实例；切换标签、拆分或合并窗口不需要序列化和重新载入整个作品。

标签上的琥珀色圆点表示完整作品还有未保存改动。单独保存折痕、基础形或折序文档，和保存整个作品仍是不同操作。保存过程中继续编辑时，尚未包含在本次文件中的改动会继续标记为未保存。

关闭一个窗口会先检查其中的所有作品。取消关闭会保留整个窗口中的作品；关闭一个窗口不会结束其他窗口中的作品和计算。关闭最后一个窗口后，应用和共享本地服务才退出。

文档库中的正式文件仍由所有窗口共享。同一份已保存工程被多个作品打开后，正式保存仍检查版本冲突，不能用一个窗口的旧版本覆盖另一个窗口的新版本。各作品的临时草稿分别保存。

窗口排列与分组属于本次运行的界面状态；ORIW 保存作品内容，不保存操作系统窗口布局。普通浏览器入口继续使用原来的单作品界面。
