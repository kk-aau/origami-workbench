# 按类型替换／删除

新增两个实际入口，工具栏“线段 / 顶点”组可用，当前60项工具。全工具目标仍在开发，未打包。

先设置来源类型（任意、山谷组合或具体线型），替换工具另设目标类型。目标独立于上方新绘制线型；预览为紫色，不提前修改作品。

单击最近线段后匹配来源，不跳过不匹配的近线去操作远线。按住左键拖框采用接触规则，两方向一致，即使两个端点都在框外也能命中穿过框的线段；松开后一次提交。工具参数与普通右键框删规则不同，说明已在界面标明。

山谷互换保留原折角大小、0和未知值；辅助改山谷使用默认角。边界保护适用。转换后通过统一真实分段与撤销管线，整组一次撤销；不匹配或已是目标类型不添加历史。修改来源／目标会取消当前手势。右击／Esc取消拖动，迟到的松开不再执行；空闲右击仍是通用删除，不受来源筛选限制。

目前来源与目标为会话参数，尚未加入全局偏好持久化；源码核对基于模式72/73，原版运行时动态逐例对照未做，目录保持基础可用。
