本轮新增 3 项，当前实际工具 28 项；Oriedita 全功能移植仍未完成。

## 操作

|工具|步骤|结果|
|---|---|---|
|半径差同心圆|选圆 A → 减去半径的圆 B → 加上半径的圆 C → 确认|圆心为 A，半径 rA+rC-rB 的新圆|
|圆反演|选待反演圆 → 选反演基准圆|结果圆需确认；结果直线需再选两个截止线段／纸边|
|直线反演|选已有线段 → 选基准圆 → 确认|该线段整条支撑直线的反演圆，不是有限线段对应圆弧|

结果圆可点紫色圆周，或点击／键盘激活确认按钮。反演结果直线先显示临时无限方向参考，不写入工程；点击第一、第二个实际截止线后，才写入有限辅助线。交点必须位于所点小段上，而非其延长线；支持引用受保护纸边，但不绕过边界编辑保护去修改原对象。

所有源圆／源线保留。新增圆为独立辅助对象，反演直线为 A 辅助线，不采用当前山谷线型，不参与折叠计算；辅助线与已有线相交后照常真实分段，整体一次撤销。圆参考点和交点沿用既有吸附，保存／恢复沿用工程 v2。导出 CP／FOLD 等不支持圆对象的格式仍会提示信息丢失。

构造中右击／Esc 取消，不同时删线。中文固定指南及鼠标旁提示随结果类型和当前截止步骤变化；参考几何为紫色，沿用现有面板限宽与最多四列布局。错误保留此前有效参考，允许重选，切换工具和撤销会清空构造状态。

## 退化与数值边界

- 半径差为零、结果半径不为正或太小，拒绝生成；A 与 B 可选同一圆，B 与 C 等半径则无增量。
- 待反演圆经过基准圆心时，结果为直线；不以超大半径圆冒充。其余情况使用解析圆公式，包括包围圆心与同心圆。
- 支撑直线经过反演中心时不生成重复对象；圆反演结果与源圆重合也不重复生成。
- 两截止点重合、平行截止线、交点仅在目标延长线时拒绝；需选择实际小段。
- 新圆心坐标限 ±1000000 mm，半径 0.000001–1000000 mm；超范围给出错误，不截断或产生 NaN。无限参考线只作预览，提交端点必须符合工程坐标边界。
