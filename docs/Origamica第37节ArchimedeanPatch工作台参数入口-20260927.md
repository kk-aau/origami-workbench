# 第 37 节普通 ArchimedeanPatch 工作台入口

普通 `ArchimedeanPatch[1..12]` 是 12 个显式 `JoinTiling` 来源拼块及其 `PatchVector(s)` 格矢，不等同于 `TwoColorableArchimedeanPatch`。权威静态目录和后端验证见 `backend/tessellation_archimedean_patch_catalog.py`、`backend/test_tessellation_archimedean_patch_catalog.py`；逐项接边、格矢、保存的 In 编号和 2×2 母图计数见《Origamica第37节ArchimedeanPatch全目录与静态工厂-20260924.md》。

工作台参数入口使用现有 `family:'custom'` 晶格网格契约：来源片的焊接顶点与面、两个格矢、闭区间 `range1/range2`、`repeatX=repeatY=1`；母结构默认 `customOutput:'tiling'`，具名 Alt 保存例使用 `customOutput:'tile-twists'`。附加来源记录为 `archimedeanPatch:{source:'Origamica.Section37.ArchimedeanPatch',number,range1,range2,preset?}`。UI 默认 `range1=range2=[0,1]`，对应原版每个编号保存的 2×2 母图。更改闭区间后仍按同一格矢复制来源片，但新范围不是该 2×2 保存例；最多输出 192 个面。

`src/app/archimedeanPatchSource.ts` 逐项转录普通目录的接边和格矢引用，在前端重建来源几何。`readArchimedeanPatchSpec` 只接受 1..12 的整数编号、精确来源标识和有界升序闭区间。保存回读时须同时运行通用自定义参数校验和 `archimedeanPatchSourceMatches`：它逐项比对来源面索引、顶点、格矢、闭区间、输出模式；拒绝来源编号与几何不符、伪造格矢、其他具名来源或折痕模式。普通自定义编辑器若修改这些字段，必须移除过期的 `archimedeanPatch` 来源记录。向后端发通用 `custom` 请求时只剥离这个显示和回读用来源记录，保留实际几何与格矢字段。

`src/components/ArchimedeanPatchControls.tsx` 提供 12 个来源编号与格矢范围编辑，保存例标签引用对应 In。未选折痕预设时，该入口只表示已核验的母结构和晶格展开，不推断折痕或层序。n=1 有 In[3180] 单补片居中褶角及 In[3106]+In[3180] 的 2×2 接缝组合，n=2、6、8 有具名 Alt 保存预设；二色变体仍由独立入口处理。

六个具名预设固定来源编号、闭区间和逐片山谷／角度配方；两个 n=1 预设固定褶角，其余四项固定中心扭角。In[3185] 与 In[3186] 两个裁剪分支还固定裁剪窗口及已核验的重合边、清理选项。工程回读同时比对来源顶点、面索引、格矢、参数、裁剪边界和构造选项；伪造标签或改动源参数将拒绝，普通参数编辑时清除过期来源记录。编辑网格 JSON 若几何不变保留来源，改动顶点则清除来源。纸张设置在切换预设时保留。`scripts/verify-archimedean-patch6-alt-in3182.ts`、`scripts/verify-archimedean-patch8-alt-in3186.ts` 从工作区单补片预设出发，经过 `readTessParams` 严格回读，再剥离显示用来源标签送到通用生成请求；与绕开 JSON 分派的具名构造对照，CP 坐标、拓扑、M/V、折角和来源面完全一致。整纸的 `scripts/verify-archimedean-patch8-pruned-in3186.ts` 核对具名构造的 120→21 来源片及受限层序；`backend/test_tessellation_archimedean_patch8_in3186.py` 对照具名与通用 CP。本次又以工作区整纸预设实际请求通用后端，所得 21 片／152 点／260 边／109 面的全部边、M/V、折角、面及来源字段与具名构造逐项相同，最大顶点误差为 0。原笔记本没有可机比的数值 CP／FF `Out`；此处只证明本项目的重建结果，不证明连续折叠路径。

`tests/app/archimedeanPatchSource.test.ts` 检验 12 项来源面顺序与独立解析格矢锚点、n=9 的解析顶点、保存 JSON 来源记录回读，并拒绝改动来源几何或范围后继续冒用具名来源。后端的 12 项 2×2 展开、焊点和几何检查另由上述 Python 测试覆盖。

接入后又将前端生成、剥离显示元数据的 12 个 `custom` 请求逐项送入本地 `tessellate.generate`：12/12 的几何检查均为 `passed`，输出面数依次为 `8,4,4,36,36,12,24,24,12,12,24,8`，与静态目录保存样例一致。

工作台的通用逐块扭转前端校验允许先生成最多 192 面的晶格母图，前提是已经提供通过几何校验的裁剪边界；未提供裁剪边界时仍限定 36 面。后端先裁剪母图，再由逐块构造器执行最终 36 面上限。前端回归测试覆盖 40 面无裁剪拒绝、有效裁剪放行和无效裁剪拒绝；同一有效边界在后端将 40 面裁至 35 面。In[3186] 整纸保存预设在该有界流程中由 120 片裁成 21 片；普通母结构入口仍不自动推断未具名范围的折痕结果。

隔离的本地浏览器验收在 1000×720 视口选取 n=8，真实工作区显示 24 个单元、60 条边、几何检查通过，且仍明确标注“母结构 · 未构造折痕”。新增按钮后自定义工具行改为四列三行，实测参数栏 `scrollHeight=clientHeight=524`、工具行 `scrollWidth=clientWidth=310`；截图为 `output/playwright/p37-custom-controls-compact-20260927.png`。新入口的完整名称保留在按钮无障碍名称与标题中，短按钮文案为“阿基米德”。
