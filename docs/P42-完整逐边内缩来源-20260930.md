# P42 完整逐边内缩来源（2026-09-30）

在原有「线组编织 → 逐段内缩」弹窗内增加完整逐边列表，覆盖当前母结构的所有内边和边界段。不同边界段的 h 实际进入内缩多边形、边界褶顶点、平折方程和展开图；没有只保存来源标记或把边界 h 合并成一个平均数。

| 源依据 | 原定义语义 | 当前实现 |
|---|---|---|
| `tmp/Origamica-15.0-reference.nb` In[3428]，253203–253272 | `inset` 为列表时长度必须等于 `Length[edges]`，含边界；按每个面的边索引取 h，调用 `InsetPoly` | `fullEdgeInsets.entries` 按全体母结构边索引完整排列，长度、编号、归属及端点逐一核验 |
| In[3428]，253239–253252 | 周期存在或 `BorderInset===None` 时，将 `h[[bedges]]` 强制设为 0 | 保留完整原始请求表，同时记录 `requestedEdgeInsets`／`effectiveEdgeInsets`；后者在上述条件下将边界归零 |
| In[931]，59192–59285 | 每条边平移 `-h Rotate90[NormalizeReal[p-q]]`，再求相邻两条平移直线的交点 | `inset_faces` 对每条实际母边取有效 h，求相邻内法线偏移直线的交点 |
| In[3428] `makeverts`，253408 起 | 内缩角作为基点，位移含对应内边的 `h·di/db·csc`；边界 h 通过内缩角改变边褶几何 | 保留原有拓扑、交替方向、最小褶宽约束、固定面和反射展开；全边 h 更新实际基点与位移 |

对有向边 p→q，令内单位法线为 n，偏移直线为 `n·x=n·p+h`。相邻边的这两条直线交点就是内缩角。独立 Python 对照直接照 In[931] 先平移两个端点，再用参数式直线交点求解；没有复用生产内缩函数的行列式表达式。

## 保存合同

`woven-lines` 可选来源字段如下。其余既有线组参数照常保存。

```json
{
  "fullEdgeInsets": {
    "edgeCount": 24,
    "entries": [
      {"edge": 0, "line": -1, "from": [0.4, -1], "to": [1, -1], "inset": 0.01}
    ]
  }
}
```

上例只展示一条记录的格式；有效列表必须包含全部 24 条，依次为 edge 0…23。UI 编号显示为 1…24。

| 字段／操作 | 严格规则 |
|---|---|
| `edgeCount`／`entries` | 3–1024 边；数组长度严格等于实际全边数，不能省略、重复或换序 |
| `edge`／`line` | `edge` 为实际母结构边索引；`line=-1` 表示边界，内边为实际活跃线编号 0…31；不以其它线编号替代 |
| `from`／`to` | 两个有限二维坐标，范围 −10…10，不重合；可交换端点方向，但不能引用其它边 |
| 几何戳容差 | `1e-9 × 母图真实包围盒跨度 + 16 × 最大绝对坐标的 ULP`；兼顾小图及平移后的浮点保存，不用 `max(1,scale)` 放宽小图，也不依赖字符串逐字相同 |
| `inset` | 0…1 的有限非负绝对单侧 h；整条带宽为 2h |
| 来源互斥 | `fullEdgeInsets` 与旧 `segmentInsets` 不得同时出现，包括空 `segmentInsets:[]`；其它构造族不得静默丢弃完整来源 |
| `periodicityEnabled` | 可选布尔值；缺省保持旧工程空表为无周期、非空表自动启用；true 允许空配对表并强制边界有效 h=0；false 与非空表同时出现严格拒绝，不静默删除配对 |
| 基准宽／线宽倍率 | 完整列表保存每一条边的绝对 h；基准宽和整线宽度倍率改变时全表保持。旧逐段来源仍只冻结被覆盖的内边 |
| 改母结构几何 | 改线方向／距离／条数、边界、随机生成几何或恢复圆弦边界后，明确清除来源与旧周期引用；旧戳也会在后端严格拒绝 |
| 改其它编织参数 | 交替反向、最小褶宽、固定面、周期和边界内缩模式保留完整请求表；实际构造按当前参数重算 |
| 清除／切换模式 | 清除全部恢复旧内边覆盖方式；显式转为完整列表时，将其余边的当前实际 h 填入全表。没有单独的伪来源 mode 标志 |

边界 h=0 合法，也可与正 h 混用。In[3428] 没有把内边 h=0 作为列表语法错误；In[931] 的内缩交点也可计算。本实现同样接受零值来源并能算内缩多边形，但原编织位移乘以该内边 h 后会形成零位移、重复顶点或零长折痕，因此在编织几何阶段明确拒绝退化构造。没有把这一退化诊断称为原数学问题的一般无解证明。

原 In[3428] 的 `isper=!(wper===None)` 会把 Wolfram 显式 `WovenPeriodicity->{}` 也视为周期并归零边界。本轮已接入这一真实差异：在原周期配对标题行增加「启用周期」勾选，保存 `periodicityEnabled:true` 与空 `periodicity:[]`，对应原显式空表；未启用的空表对应原 None。缺省标志维持旧工程映射，非空配对自动启用；显式 false 与非空表矛盾时两端均拒绝。清除配对不自动关闭已明确启用的周期，可通过勾选单独控制，来源和实际有效 h 都按当前条件重算。
