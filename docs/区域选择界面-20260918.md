# 多边形、套索与划线选择

新增六个实际入口，共57项可用工具；全工具目标仍未完成，此批未打包。

工具栏“区域选择”组：

- 多边形选择／撤选：依次点击顶点，或按住左键逐边拖画。至少三个不共线点后点击起点闭合，也可点击“完成轮廓”。仅命中完全处于内部或边界上的线段；凹轮廓不会仅按两个端点误选穿出区域的线。
- 套索选择／撤选：按住左键自由圈画，松开自动闭合。轨迹不吸附网格，仅命中完整处于内部且不接触轮廓的线段；退化轨迹不改变选区。
- 划线选择／撤选：两次点击或按住拖放形成参考线，命中真正X相交或共线正长度重叠，不命中T接触、共享端点或参考线延长线。

选择是追加，撤选是移除，不反复切换；区域外的已有选区保持不变。完成前不改变选区。保护边界开关适用，辅助线仍可选择。轮廓为紫色，不采用当前绘制线型，指引同时出现在画布上方和鼠标附近。

右击或Esc取消正在圈画/定点的操作，原选区及作品保持不变；空闲右击仍为删线。取消拖动后迟到的左键松开不会执行选择。选择本身不修改作品、不创建几何撤销步骤；后续删除、变换仍使用已有撤销流程。

实现依赖上轮 selectionRegions 核心。套索按非零环绕，多边形按奇偶填充；自重叠、边界容差和Java GeneralPath的细节仍需上游动态对照，目录仅标基础可用，不声称全部原版变体已验收。
