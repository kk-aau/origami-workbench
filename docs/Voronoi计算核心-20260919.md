# Voronoi 计算核心

## 上游依据

已完整阅读本地 `MouseHandlerVoronoiCreate.java`、`VoronoiAction.java`，核对 `OritaCalc.bisection` 实现。

模式 62 在按下时加入种子，附近已有种子则移除；最近已有点可作为吸附位置。全部种子与生成线存入临时 lineStep，紫色显示；handler 本身未把线提交为折痕，松开和拖动没有操作。进入工具清除已有选区，reset 清空临时数据。上游初始垂直平分线总长 1000，中心两侧各 500，不是纸张边界裁剪。

## 实现范围

`src/app/voronoi.ts` 提供种子切换与临时 Voronoi 边计算，尚未接 UI，不计入可用工具。

- 对每对种子构造垂直平分线，裁剪到所有其他种子的最近点半平面，不复制上游带已知误差注释的增量算法。
- 在平移到局部中点后计算，避免大世界坐标平方相减。每对只输出一条正长度边；共圆时只接触一个顶点的“边”不会输出。
- 固定预览总跨度默认 1000，保留上游有限显示范围含义；可传入正跨度，但当前无 UI 选项。不自行添加纸边、矩形细胞外框或折痕。
- 无效坐标及 1e-7 内重复种子拒绝并给中文错误。种子切换按上游最后一个落入容差的种子删除；保留其余顺序，未复制原版交换末尾元素的内部排序。
- 此核心为同步全量重算，最坏 O(n³)。接 UI 前需考虑大型种子集预览延迟、取消与调度，不能借“测试通过”声称性能已完成。
