# 通用可展面展开与重塑

原空间构造的“可展面展开”和“可展面重塑”窗口新增一般原式输入，原圆锥展开及柱面双向保存例可切回。依据原 `FlattenGeneric2D/NFlattenGeneric2D` In[3882]/[3885] 和 `ReshapeGeneric3D/NReshapeGeneric3D` In[3890]/[3895]，不以调整保存族参数代替一般入口。

| 原职责 | 实际行为 |
| --- | --- |
| 一般空间基线和母线 | 各三个安全 s 表达式；保留原母线长度及导数，支持非圆、非恒速、变长度母线和两种σ。 |
| 平面展开初值 | 参数域内任意 ui、二维 bi/ti；按原速度与测地曲率恢复位置及切向，向 ui 两侧积分。 |
| 空间重塑 | 可编辑目标法曲率 κn(s)，按原 Darboux 方程恢复三维 B/T/L/U；保留原 p/q，不改输入来配图。 |
| 原初值顺序 | 展开 ui/bi/ti；重塑 ui/bbi/ddi/tti。原 ddi 只确定初始法向方向，输出母线长度和切向投影仍取源 p/q；分别报告请求／实际母线及差值。 |
| 初始切向 | 原单位向量合同按1e−10数值容差检查，保留输入原值；未悄悄归一化或把 ui 改成左端。 |
| 不相容与未知 | 非可展源仍保留原算法产生的真实双图，分别报告源可展性、有限度量及形式相容性。全域区间预算未知仍保完整源域和采样。 |
| 参数存取与显示 | 原式和所有初值存 JSON，载入重算；改参即清旧图，忙时重试保最新请求。视角／母线定位在本地更新，使用归一化坐标显示极小尺度和大平移。 |

数学实现与60位独立核查详见 `output/audits/P45-通用Darboux-内核与独立证据-20260930.md`。源 p/q 保非单位长度，因此正确 G=p²+q²；不能继承单位母线 G=1。局部雅可比为 σvq+w(qp′−pq′−g(p²+q²))，正反定向均可验证，焦线与区间未知分别报告。

| 范围与证据 | 准确限制 |
| --- | --- |
| 安全源／参数预算 | s∈[−10,10]、跨度.01–12；横向系数 w∈±10⁶且递增；8–128纵向段、2–64横向段，横段不要求偶数；初始点／母线各分量±10¹²。 |
| 源域证据 | 原函数、速度及T×d在全部区间有定义；保留标量原求值，不通过符号消去隐藏源极点。局部IntervalTaylor对常量也作外向运算，防止tinyD下界漏一ulp。 |
| 形式与数值分级 | 源解析可展恒等式及完整定义域共同支撑形式ODE相容；形式条带正则另检查完整w域。数值积分轨迹的全区间误差未认证，`integrationErrorIntervalCertified=false`，不把有限EFG核验称为严格轨迹误差包围。 |
