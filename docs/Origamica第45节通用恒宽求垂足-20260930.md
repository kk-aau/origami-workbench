# 原式通用恒宽求垂足

新增可编辑二维基线及母线，在原“恒宽”窗口直接求 `NConstantWidthScale2D` 的宽度函数；原 In[3879] 圆弧模式保留。源依据是参考笔记本 In[3878]，311070–311225 行。

| 原职责 | 实际实现 |
| --- | --- |
| 给定二维 b、d、有向垂距 w0 及 s 区间 | 四个安全标量原表达式，母线不单位化；返回真实基线、边线、垂足、宽度及一阶导数。 |
| 原两维求根 | `b(s)+w(s)d(s)=b(u)+w0*l(u)*sign(l(u)·d(u))`，其中 l 是足点基线的单位左法向。Sign 在足点 u 求值，不能换成 s。 |
| 原两对起始值 | 宽度 `.5w0,w0`；足点 `s,s+.01(s1-s0)`。保留原初始差分 Jacobian 后求原向量式，不把双起始值误当边界。没有宣称逐步复制 Wolfram 默认求解器。 |
| 原未使用的外推 | 定义过的 be/te/le 没进入实际 FindRoot；足点允许越出原 s 区间，继续在原函数上取值。 |
| 数值源保存 | JSON 保存四个原字符串及全部参数；载入重新计算。没有复制 Wolfram FunctionInterpolation 对象、节点和选项。 |
| 独立读取 | 前端重新算原曲线高阶导数、足点 Sign、向量式、隐函数导数及全部归一化/物理字段，并核证书范围和根界。 |

默认 b=(cos s,sin s)、d=(−1,0)、w0=.1、s∈[0,.35π]。原例末足点约 1.429308，超过显示终点 1.099557，仍在真实圆上；不会改成端点切线。

| 输入及证据 | 精确范围 |
| --- | --- |
| 原表达式 | 每组各2维，只含 s；沿用安全 AST，单式最多240字符/96节点。支持四则、有限整数幂及 Sin/Cos/Tan/ArcTan/Sqrt/Exp/Log/Pi。 |
| 参数域 | s∈[−20,20]，跨度 .001–12；有向垂距 −1000…1000，含负及零；显示8–128段。 |
| 垂足求值域 | 额外有限算法范围，位于 −40…40、跨度≤40；默认 −.5…2。不是原数学方程的边界；范围不足提示扩大计算范围，不称原方程无解。 |
| 小尺度 | 加性常量与变化项分别算，长度尺度为 `max(abs(w0),9个速度最大值*s跨度)`。10⁻⁸几何叠10⁹平移保留真实归一化坐标；世界 binary64 坐标有自身 ULP 限制。 |
| 点与区间 | 显示行加129个独立点核方程与垂距；全 s-cell 用参数化 Krawczyk 包围简单根。相邻 cell 及每个返回点分别做 point-Krawczyk，再在根界联合 hull 上排 F_u=0 和 Sign 变化，证明是同一根。 |
| 预算未知 | 最多1023次自适应 cell，额外一次预算检查；未覆盖段明确列为 unresolved，保留完整原域和真实样本，连续根/全域距离标志为 false。 |
| 纸带证据 | 单独检查 `X(s,λ)=b(s)+λw(s)d(s)`、λ∈[0,1] 的 Jacobian。恒宽函数成立不自动证明纸带局部正则；零宽度明确为退化纸带。 |
| 其余能力 | 到所返回垂足的法向距离，未证明全局最近足点、单射、无碰撞、精确直线 FOLD 或可采用折痕工程。 |

源示例 b=(s,0)、d=(1,cos(10s))、w0=.3、s∈[−.01,.01] 在 s=0 返回 w=u=−.3。若错用当前位置 d(s) 的 Sign，会得到 +.3，代回原式残差 .6。变长非单位母线、共同参数反向及负 w0 均按原式处理，不按预期图形暗改源。
