# Origamica 第 45 节：曲折离散化只读查询

## 来源与可达范围

| 工作区选项 | 原版输入 | 本地计算 | 边界 |
| --- | --- | --- | --- |
| 系统采样 | In[4088]：`t={0,.25,.5,.75,1}`，`Curve2D=(t,t²)`，`Curve3D=(t,t²,0)` | 保序调用 `DiscretizeSystem`，展示二维及三维采样 | 固定保存输入，无任意函数上传 |
| 均角离散 | In[4090]：`f(t)=(-t²,t)`，`n=4`，`[0,1]` | 调用 `DiscretizeCurveUniformly`，展示参数、折痕点、弦长与每个内部点的弦向残差 | 可调分段数 `2..16`，曲线与区间固定；只覆盖等参数初值可达的递增根 |
| 椭圆系统 | In[4093]：`ConicSection2DSystem[{-2,-1},{-3/2,1},Simplification->Simplify]`，`n=5`，`[0,90°]` | 按 In[4019] 九条规则构造椭圆系统，依次调用三个离散化函数，展示左右次横曲线、弦向残差和各点折角倍率 | 曲线和区间固定；`n=2..16` 可调，只有 `n=5` 是保存参数，其余为明确标识的本地推演 |
| 角度倍率夹具 | In[4092] 的 `FoldAngleMultipliers2D` 定义 | 用固定三顶点夹角夹具验算端点与内部倍率 | 与 In[4093] 的真实椭圆保存例分开标识 |

这些保存单元没有可逐数对照的 Wolfram 数值 `Out`。屏幕上的数值均为当前 Python 实现对保存输入的复算；角度倍率夹具则是独立的固定验算数据。均角离散条件为

```text
(unit(f(t_i)-f(t_{i-1})) - unit(f(t_{i+1})-f(t_i))) · f'(t_i) = 0
```

它不要求等弧长或等弦长。后端同时返回按原式计算的 `residual` 与切向单位化后的 `normalizedResidual`；表中显示原式残差。初始猜测为等参数间距，求解只接受严格递增的参数列，不枚举其它非线性根。In[4090] 保存的四段例复算参数约为 `0, 0.183316669579, 0.391274766869, 0.651828020428, 1`，四段弦长约为 `0.18637, 0.23984, 0.37650, 0.67230`。

In[4093] 的 `cl`、`cr` 取自 `SecondCrossCurveLeft2D`、`SecondCrossCurveRight2D`，不是系统内取固定焦点的 `CrossCurveLeft2D`、`CrossCurveRight2D`。令 `q=tan(t/2)`，按 In[4019] 真分支和保存参数代入后，三条关键曲线为：

```text
f(t)  = (-2 + 4 cos(t)/(3-cos(t)), 4 sin(t)/(3-cos(t)))
cl(t) = (-2 + cos(t)/2, sin(t)/2)
cr(t) = (-3 + 4/(1+4q²), 8q/(1+4q²))
```

`f` 满足椭圆方程 `8(x+3/2)²+9y²=18`。保存的五段复算参数约为 `0, 0.262966419351, 0.539324974706, 0.842067164498, 1.182945041182, π/2` 弧度。由 `cl-f`、`cr-f` 构造的左右母线送入 `FoldAngleMultipliers2D`，六个局部折角倍率均约为 `−5.139331298929`；这是本地数值结果，原版没有保存对应数字。

工作区另外允许对**同一原版椭圆、区间和左右次横曲线**调节 `n=2..16`。每个返回值仍用等参数初值寻找严格递增根，独立核验弦向残差、椭圆方程、九规则逐点值和局部平折倍率；没有扩展原版焦点、准线或任意函数。倍率在每次离散结果的各顶点相等，但随分段数变化，例如本地 `n=3` 约 `−3.118092124466`、`n=8` 约 `−8.191754175459`。因此响应的 `source.savedDivisions=5` 固定，`source.parameterStatus` 在 `n=5` 时为 `saved-input`，其它取值为 `bounded-local-extension`，不得将后者描述成原版保存输出。

## 接口与安全约束

`backend/tessellation_curved_discretization_query.py` 只接受下列 JSON 对象：

```json
{"example":"in-4088"}
{"example":"in-4090","divisions":4}
{"example":"in-4093","divisions":5}
{"example":"in-4093","divisions":8}
{"example":"multiplier-fixture"}
```

`in-4090` 缺省 `divisions=4`，`in-4093` 缺省 `divisions=5`；两者都只接受 `2..16` 的 JSON 整数。其它字段、字符串形式的数字、布尔值、负数、非整数与越界分段数都会拒绝。用户无法提供函数体、表达式、方程、区间或夹角数组。结果的 `source.origin` 区分保存输入与验证夹具，`source.parameterStatus` 进一步区分椭圆保存分段和本地推演，`wolframNumericOutAvailable` 恒为 `false`。前端 `src/app/curvedDiscretization.ts` 还检查来源一致性、点列与函数、弦向计算、局部倍率公式，以及响应是否属于原查询。

工作区已把 `/api/tessellation/curved-discretization` 映射为服务端固定操作 `curved-discretization`，并在 `backend/tessellate.py` 分发到该封闭查询。`TessellationPanel.tsx` 的入口打开只读弹窗；查询不写入镶嵌参数。
