# 通用 NearConstantWidthScale 数值输入

对照原 `In[3871]`（310465–310549）与 `In[3874]`（310740–310786），新增可编辑二维／三维基线 b(s) 及同维母线 d(s)，直接计算原式
`ws(s)=1/sqrt(1-(normalize(b′(s))·d(s))²)`。保留原 In[3872]/In[3875] 保存视图，新入口与它们共用「近恒宽比例」窗口，无新增工作区。参数 JSON 保存原表达式字符串；载入后重新计算，不保存旧图冒充新输入。

| 原语义 | 实现与准确范围 |
|---|---|
| t 为单位基线切向 | 安全源函数二阶自动导数；源位置与切向各自按同一个 s 求值，不暗改弧长参数。 |
| 原式直接使用 d | 不自动归一化母线，不把非单位 d 的结果换成另一个构造。母线为单位向量时，局部切向正交距离等于宽度倍率绝对值；非单位时按实际向量显示真实距离。 |
| 近恒宽 | 这是基线当前位置的切向正交距离，不是到整条弯曲基线的最近距离。没有替代另一个求垂足的 NConstantWidthScale2D。 |
| 原数值调用 | 直接计算数值源函数，未复制 Wolfram FunctionInterpolationAlt 的插值对象、采样点或选项；不称为原数值 Out。 |
| 输入 | 2／3 维，安全标量函数包含 Sin/Cos/Tan/ArcTan/Sqrt/Exp/Log、Pi、整数幂与相邻乘法；每个源仍受已有 AST 容量。s 在 −20…20，区间长 .001–12，显示8–128段；宽度倍率 −1000…1000，含0，负值反转母线侧。 |
| 完整区间 | 向外舍入 Interval 证明速度正与根号严格正；最多1023次、深度10。真实点退化拒绝，包围未闭合返回 unknown 并保留原输入数值只读图，不把采样吻合当全域证书。沿用既有 libm 端点2ULP假设。 |
| 独立坐标 | 基线常量与变化项先分开，局部坐标再恢复世界坐标。10⁻⁸源叠加±10⁹平移仍保留真实归一化图；世界 binary64 坐标受自身分辨率约束，不夸称保存小于ULP的位移。 |
| 证书 | 只认证比例函数有定义；纸带正则、全局单射、空间可展、运动、碰撞、精确直线 FOLD 与可采用标志均为 false。零宽度的图虽塌成基线，比例函数本身仍有定义。 |

后端 `backend/tessellation_curved_near_width_query.py`；前端 `src/app/curvedGenericNearWidth.ts` 逐源独立重算全部点、导数、比例及尺度。区间来源与覆盖独立检查，浏览器的定点证据不被描述成浏览器区间算法；全区间证明由后端执行。路由 `/api/tessellation/curved-near-width` 与普通镶嵌生成分开。
