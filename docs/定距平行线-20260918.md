# 定距平行线

开发版v0.9.2，未打包；“精确作图 → 定距平行线”。

先选择有限原线，再用独立两点的距离作为偏移宽度：可点击起点再点终点，也可按住左键拖动后松开。测量起终点支持当前吸附设置，拖动中显示紫色左右候选，松开只确定宽度，不提交。

也可输入“平行距离”并点“使用数值距离”，不必画测量段。最后点击紫色候选或“生成候选1／2”；两侧太接近无法唯一命中时必须使用编号。重新量距会保留原线，重置测量点。

复制结果长度与原线一致，不延长到纸边、不改变原线型和折角；新线采用当前绘制预设。改变预设不取消构造。测量段只是参考，不写入工程；仅提交选中的一个候选。交点真实分割，一次撤销；完全重复或冲突重合拒绝。

只有原线被选中时，右击也优先取消，不删除原线。拖动中Esc／右键遵循通用取消规则，松开不会补交。换工具清空；支持保存恢复。

依据本地Oriedita模式51 MouseHandlerParallelDrawWidth。原版严格限制量距起终点为已有点，本版允许自由／吸附点，增加两次点击和数值输入；未做上游运行时逐例对照，目录保留基础可用。
