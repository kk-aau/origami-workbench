# 弱切口切开、粘合与跨切口构造（2026-10-09）

本批接通重复面角材料的实际切开、同面独立边界粘合以及切开后的曲线构造。完整 Origamica 复现目标仍在进行；免安装 EXE 和安装包未更新。

| 原问题 | 当前处理 |
| --- | --- |
| 切开只能处理每面唯一顶点 | 按每个真实有向边和面角切分顶点扇，不再用 `indexOf(顶点)` 猜切口侧。内部孤立边、边界悬空边、交叉树、部分分支和孔洞单桥可实际切开。 |
| 同面切口无法粘回 | 显式选择方向相反、CP端点完全重合的两条独立 B 边后可以粘合。只合并所选边界身份，不移动或吸附端点；可恢复切开前的真实 CP。 |
| 内环边界在粘合列表中缺失 | 配对方向从实际内外环逐角查找；零面积内切口和真实孔环边界均可选。 |
| 后续曲线焊接切口两侧或直接失败 | 临时几何裁剪图按重合屏障分析；实际图按出射方向及材料面角选择对应边界侧。交点分别绑定两侧顶点，同步细分边界，保留两侧身份。 |
| 切开后旧参数配方覆盖当前材料 | 旧配方过期时保留并拒绝重放；用户可明确从当前材料建立新模型，原配方归档，再保存新的曲线参数组。 |
| 诊断混淆 | 弱切口仍仅CP，平折明确说明粘合或分面流程；三维明确拒绝。普通过短线和畸形孔洞仍走原诊断，未改为泛化的“弱切口”错误。 |

## 拓扑和导出

新增 `zhezhi-material-topology-v4` 表示同面真实独立 B 切口侧的弱轮廓。v3 继续只表示同 indexed 非 B 折痕的双向绕行；v1/v2 的原简单面和多环约束保留，不能把独立切口写成 v3 绕过验证。

区域几何分析可以对完全同坐标的角建立临时别名，以分解真实外圈、孔洞和零面积切口。实际图的顶点、边和逐角归属保持独立，另行核对反向切口侧、顶点扇、相交/接触、材料域和欧拉特征。别名不会合并工程；粘合只有用户明确选择的配对才执行身份合并。

普通 DXF 与加工优化实现保持上批源码 SHA。DXF 仍是原 R12 独立 LINE，按实际边界身份保留线段；重合的两条切口侧也保留两条 LINE，没有静默去重。仅CP的 v4 没有活动 FF，JSON/FOLD 都保留实际身份，不再次缩放或改变坐标变换。

粘合使用用户选择的连接线型及既有默认折角；本批往返核查采用标准 CP 折角，不自动恢复任意自定义目标角。
