# 折纸工坊 v0.13.35

本版改进复杂 CP 平折计算、同文件多 CP 编辑和图片导出。

| 变更 | 使用方式与行为 |
| --- | --- |
| 复杂模型计算 | 优化首个合法候选的关系处理，减少重复层序计算；结果继续进行完整合法性检查 |
| 计算状态 | 显示准备、平折几何、层序和局部显示处理状态，区分进行中、超时、取消与结束 |
| 正背同显 | 同时显示正面和背面，复用纸面分析结果 |
| 多 CP | 使用“追加 CP”加入图案，选定目标后执行“折叠选区”；完整作品保留图案与模型 |
| 大图导航 | 复用折痕绘制数据并减少导航中的重复吸附，交点和端点随画布缩放 |
| 方向框选 | 向右拖实线框选择完整包含对象；向左拖虚线框包含相交或接触对象；Shift 可追加 |
| 网格图片 | SVG／PNG／JPG 可勾选“添加背景网格”，沿用当前网格外观与等分参数，默认关闭 |

Windows x64 安装版与免安装版包含完整离线计算引擎。Gitee 下载附件采用分卷；下载同一版本所选类型的全部分卷后，用 7-Zip 打开 `.7z.001` 解压。更新前保存并正常关闭旧版，保留原数据目录。

对应源码以相同内容的 ZIP 和 7z 交付，另附 SHA256 清单。打包、实包验收及版本归档遵循[打包与体积控制要求](打包与体积控制要求.md)；本机本次验收证据保存在 `output/release-0.13.35-20261025/`，其最终记录区分本轮执行与复用的检查。
