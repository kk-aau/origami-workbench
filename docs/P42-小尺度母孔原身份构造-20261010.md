## 恢复方式

所有旧170轮探针及原近可行恢复失败之后，才分类原已记录的负图。沿用32epsilon角点分辨余量、平移及每次操作向外舍入的严格面积区间。每个保留材料循环及每个被排除void循环均须下界严格正；原来源压缩循环唯一匹配全部原孔，再从材料面列表排除void，不补面／挪点／焊接。

| 检查 | 要求 |

| Euler | 原部件数减原孔数；三例均为0。对无孔旧域仍为原Euler=1。 |
| 全部原边／母面 | 每个原母面角点唯一对应；全部原边的面关联继续核对。void不进入材料faces；原B切口／山谷属性不变。 |
