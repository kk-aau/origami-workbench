# 开放曲线构造与可视节点编辑（2026-10-09）

本批补齐可实际生成材料 CP 的开放贝塞尔路径，并接入上一批持续参数曲线组。完整 Origamica 复现目标继续；这是有限数值材料编辑子域，不能称为原版任意曲线或 Mathematica 插值对象全等价。免安装 EXE 未更新，不打包、发布或操作设备。

入口：采用镶嵌为材料后，折痕编辑 → 绘图工具 → 纸张属性/选区 → 材料曲线批量 → 开放贝塞尔。保存后的路径在“参数曲线组”中继续编辑。

| 用户操作 | 最终行为 |
| --- | --- |
| 开放路径 | 2–16 个节点，节点间三次贝塞尔按明确毫米误差离散；准确保留源端点，不自动闭合或延伸。直线路径可离散为两个点、一条边。 |
| 可视改形 | 毫米坐标刻度、节点及实际使用的入/出控制柄、精确输入、拖动、键盘微移、缩放平移；首节点无无效入柄，末节点无无效出柄。画布自动适配窗口，文字仅标当前控制点，避免多节点文字遮挡曲线。 |
| 分段加节点 | 使用 de Casteljau 中点分段，修改相邻控制柄并加入中间节点，保持源曲线几何；实际样例分段前后 CP/FF 逐值一致。 |
| 删除节点 | 明确改变路径，至少保留两个节点；草稿撤销重做可恢复。闭合贝塞尔也可使用节点增删。 |
| 当前面 | 开放路径按该实际面外圈及孔洞裁剪，可从纸外进入或端点直接接原边界；不会扩展到其它原面。闭合曲线原严格内部合同保持。 |
| 参考部件/全部材料 | 与原折痕和其它曲线同时拆交；空白和孔洞不生成折痕，独立纸片分别构造，同坐标不焊接材料身份。 |
| 相连路径 | 完全相同的采样点使用同一线网编号，允许明确连接的路径和开闭曲线组合；近邻点不吸附，重复边或正长度重叠明确拒绝。 |
| 曲线组及导出 | 原材料基底、配方、后续组重算、预览删除、工程历史、组外修改保护继续有效。JSON/FOLD 重开可编辑，普通 DXF 沿用 R12 LINE、毫米与原 Y 转换，输出实际 CP。 |

开放输入并不意味着材料拓扑门禁放宽。最终仍须有合法面、双侧折痕关联、原边界与材料等距证据。面内单端悬空、单桥连接孔洞等无法形成现有简单多环面时，明确拒绝；不生成额外桥接线来假装成功。曲线 M/V 若不能构造合法 FF，不保旧 FF，用户可明确仅 CP。

## 几何及误差

每段三次贝塞尔用控制凸包到端点弦的最大距离作为离散误差上界，自适应二分；开放末节点显式加入，最后一边不连接首节点。128 个输入采样点、256 条输入边、1024 个新增交点、共享工作预算及原材料/层序预算保持；超限拒绝而不放宽误差。

同一组含开放路径时，精确相等的采样点按坐标复用编号，再通过原有精确有理交点和最近双精度舍入拆分。没有近邻容差焊接。两条数学相近但双精度输入不同的曲线可能产生低于材料分辨精度的不同交点，此时继续拒绝。

采样误差是源路径与 LINE 近似的界；材料长度、孔洞与空白裁剪基于实际采样线段，不是解析曲线弧长或解析曲线交点。连续曲线折叠与物理运动不由该 CP 证明。

## 完整目标余项与未验证事项
