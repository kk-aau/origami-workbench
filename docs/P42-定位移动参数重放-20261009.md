# 定位移动参数重放（2026-10-09）

入口：**折痕编辑 → 纸张属性/选区 → 材料定位移动**。两点平移、四点相似移动所选完整材料，默认保存参数；采用后从“参数构造组”重开调整并重算后组。源码运行版更新，免安装包尚未更新，完整Origamica目标仍在进行。

| 操作 | 当前效果 |

| 后续构造 | 修改移动方式/参考点后重算细分、复制、镜像等后组；导入片保持独立来源，前组改粘贴位置后移动选区仍对应该纸片。 |
