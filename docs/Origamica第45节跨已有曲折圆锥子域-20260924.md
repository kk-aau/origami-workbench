原版二维入口使用折痕速度、左曲率、切向与左法向，将左母线的切向／法向比与 `tan(γ/2)`、`γ′` 组成右母线角。三维入口以 `T,N,B` 为 Frenet 标架，从左侧单位面法向 `U_L=normalize(T×rrL)` 与左侧横向 `L_L=U_L×T` 构造候选右法向 `U_R`；`U_R′` 的切向符号和模确定右侧母线分支。`Both` 使用同一个三维分支的角系数，分别生成三维和二维右母线。原版函数本身没有跨二维／三维输入的全局等距、焦线宽度或无自交证书；本子域把这些局部条件显式证明并限制宽度。

## 圆锥闭式及唯一分支

令 `a=sin θ`、`b=cos θ`，`0<θ<π/2`。保存输入是

```text
f(u)   = (-sin(a u), cos(a u))
rL(u)  = -f(u)
ff(u)  = (-a sin u, b, a cos u)
rrL(u) = -ff(u)
```

三维 `T=(-cos u,0,-sin u)`、`N=(sin u,0,-cos u)`、`B=(0,-1,0)`。代入 In[3998]：`U_L=aB-bN`，`L_L=aN+bB`，所以 `U_R=bN+aB` 且 `U_R′=-bT`。因为 `b>0`，原版符号分支在整段内固定，`cosρ_R=0`、`sinρ_R=1`，得到唯一的

```text
rR(u)  = f(u)
rrR(u) = (-a sin u, -b, a cos u)
```

这也符合 In[3983] 的二维公式：左母线纯法向、`γ=π-2θ` 为常数，因此左侧切／法向比和 `γ′` 都为零，二维右母线为向外法向。两侧在每个空间使用同一条 `v=0` 折痕，折角为 `π-2θ`；`θ=90°` 时 `U_R′=0`、原版分支失去定义，故明确拒绝。

令正 `v` 从折痕分别走向各侧。二维／三维曲面为

```text
X2L(u,v) = (1-v) f(u)                 X3L(u,v) = (1-v) ff(u)
X2R(u,v) = (1+v) f(u)                 X3R(u,v) = ff(u) + v rrR(u)
```

直接对四个曲面微分，每侧二维与三维的第一基本形式完全相同：

| 侧 | `E=∂uX·∂uX` | `F=∂uX·∂vX` | `G=∂vX·∂vX` |
| --- | ---: | ---: | ---: |
| 左 | `a²(1-v)²` | `0` | `1` |
| 右 | `a²(1+v)²` | `0` | `1` |

左侧在 `v=1` 到达锥顶，二维和三维同时失去浸入正则性。右侧焦线位于 `v=-1`，不在正向右带内。`certify_cone_across_right` 要求 `left_width<1`、`right_width>0`，并将右宽上限设为 `10⁶` 以保持浮点评价有界；参数区间长度至多 `π`。它证明的是这一子域的局部等距与焦线前正则性，不包含厚度、连续运动或全局无碰撞证明。

保存参数 `θ=30°` 在 `u=0` 给出推导锚点：二维折痕 `(0,1)`，左右母线 `(0,-1)`／`(0,1)`；三维折痕 `(0,√3/2,1/2)`，左右母线 `(0,-√3/2,-1/2)`／`(0,-√3/2,1/2)`。折角为 `120°`。

## 可调用结果及限制

`backend/tessellation_curved_across_right_cone.py` 的 `certify_cone_across_right(...)` 返回解析对象；`frame(u)`、`surface(space,side,u,v)`、`differentials(...)`、`first_form(...)` 分别提供对应折痕／母线、曲面点、连续导数和第一基本形式。`sample(curve_segments,ruling_segments)` 对相同参数网格返回二维与三维点，并为两侧引用**同一组折痕索引**。它不返回三角面或 FOLD 边。

采样弦长不能代替精确折纸：在保存例两个端点 `u=±π/2`，折痕的二维端点弦长是 `√2`，三维端点弦长是 `1`，即使上面的连续度量逐点完全相同。`sample` 只是连续曲面的数值观察；它不构造可逐边等距的直折痕展开图。原版六个通用入口的任意函数输入、插值误差证书、`FoldCurvedFold3D` 的初值微分求解、整体纸张边界与自交判定仍未实现。

验证：在 `workbench/backend` 执行 `..\.venv\Scripts\python.exe -m unittest test_tessellation_curved_across_right_cone -q`，5 项通过。测试覆盖原版保存参数推导锚点、三维符号分支唯一性、四个曲面的符号第一基本形式和三维可展性、共享折痕、取样弦长不等距、焦线／退化输入拒绝。
