# 构造图标配色

- 共线交替重新绘制为三段连续的红／蓝／红线，去掉细轴线及箭头。工具栏中宽 27 px、线宽 3 px；压缩行高时保留横向宽度。
- 52 个绘制、构造及变换图标按几何角色分色：已有线或圆为黑色 `#202124`，临时基线、候选及辅助标记为紫色 `#8b4bc0`，生成结果为青色 `#009eae`。配色独立于当前绘图线型。
- 兔耳外侧三角形仅连接三个输入点，用紫色；顶点到内心的三条结果线用青色。三点角平分与两线角平分分别用紫色角边和黑色参考线；三点反射与两线反射同样区分输入方式。
- Voronoi 只生成临时参考图，使用紫色。共线交替继续用红蓝表达山谷，不套用构造结果的青色。
- 深色主题为构造图标增加浅色底，保留黑色已有线的含义和对比度。
- 构造 SVG 集中在 `src/components/draftingGlyph.tsx`，移除 `Fields.tsx` 中对应的旧单色定义。

验证：TypeScript 检查与生产构建通过，12 项现有工具栏／面板测试通过。实际浏览器核对 1440×900、1000×720、800×600 下 93 个工具均未裁切，工具区无滚动或分页；检查浅色及深色主题，并生成包含放大与实际尺寸的图标对照图。桌面最小窗口仍为 1000×720，极小网页窗口沿用原有图标压缩策略。
