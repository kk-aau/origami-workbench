# Origamica 单位圆内接多边形：通用母多边形数值子域（2026-09-24）

原笔记本 `tmp/Origamica-15.0-reference.nb` 的 `ConcyclicCenterAngles` 对奇数边用 In[354]（19778–19831 行），对偶数边用 In[357]（19902–19999 行）；`UnitCyclicPolygonConcyclicInfo` 的 In[373]（20938–21060 行）返回 `{vertices,circumcenter,circumradius}`，In[378]（21361–21375 行）只取顶点。其 `angles_List` 的长度即边数 `n`：奇数 `n` 忽略并重算**最后一角**，偶数 `n` 忽略并重算**最后两角**，使内角和为 `(n−2)·180°`，且偶数边的交错内角和为零（20924–20935 行）。源函数没有显式的有限数值边数上限；本项目的 [独立母多边形模块](../backend/tessellation_unit_cyclic_polygon.py) 当前将数值子域限为 `3≤n≤24`，24 是工作区单面容量。

源 In[373] 的可选参数为 `side=1,is=2`，边号从 **1** 起算。奇数边形唯一，因而完全忽略 `side/is`；偶数边形的中心弧角有交错自由度，源代码通过 `FindRoot` 从 `ζ=0` 出发，使第 `is` 条边长等于 `side`（21021–21041 行）。本模块对偶数边限制 `is∈{2,…,n}`、`0.05≤side≤5`；第 1 条边已固定为单位长度，不能用它选出自由度。模块还要求有效内角在 `1°–179°`、所有中心弧角在 `1°–179°`、严格凸、共圆且有限。这是圆心位于多边形内部的可控分支；原版的符号输入、其他 `FindRoot` 根和圆心在外的有效图形均未声称覆盖。

推导独立于原版矩阵代码。令 `gᵢ` 为第 `i` 条边对应的正向圆心弧角、`θᵢ` 为第 `i` 顶点内角，圆周角定理给 `gᵢ₋₁+gᵢ=2(180°−θᵢ)`。奇数 `n` 的循环方程唯一决定 `g`；偶数 `n` 的全部解为 `gᵢ=gᵢ⁰+(−1)ⁱζ`，其中 `g⁰` 的交错和为零。首边长 1 令半径 `r=1/[2sin(g₀/2)]`、圆心 `(1/2,cot(g₀/2)/2)`；偶数边的第 `is` 条边再满足 `side=sin(g_{is−1}/2)/sin(g₀/2)`。依圆心弧角累加顶点，并把前两点精确定为 `(0,0),(1,0)`。模块对输出重新核验边长、共圆和严格凸性。

[专项测试](../backend/test_tessellation_unit_cyclic_polygon.py) 首先核对原版 `ConcyclicCenterAngles` 的保存 Out[355]/Out[356]（19856–19891 行）与 Out[358]/Out[359]（20023–20061 行）：三、五、四、六边的零交错圆心角分别为 `[160,80,120]`、`[52,92,32,72,112]`、`[100,80,80,100]`、`[58,64,60,70,62,46]` 度。测试另用**非保存输入**验证母多边形：

| 输入 | 重算内角与求得中心弧角 |
|---|---|
| `n=3`：`[50,60,999]`，任意 `side/is` | 末角重算 `70°`；弧角 `[140,100,120]°`；`side/is` 不参与求解。 |
| `n=5`：`[110,125,112.5,102.5,999]` | 末角重算 `90°`；弧角 `[45,65,70,85,95]°`。 |
| `n=6`：`[130,120,112.5,117.5,0,0]`，`side=1,is=2` | 末两角重算 `117.5°,122.5°`；零交错解 `[50,70,65,60,65,50]°` 经 `ζ=10°` 成为 `[60,60,75,50,75,40]°`。另以第 3 边指定长度测试另一 `ζ`。 |

每例均由顶点反算内角与中心弧角，并验证首边单位长度、全部顶点到圆心等距及逐角严格凸。退化内角、不可能的边长、越界边号和不能消除偶数自由度的指定边均拒绝。对已有的四边形保存参数 `[75,85,95,105]`、`side=1.2,is=2`，原版规则实际使用 `[75,85,105,95]`；新模块顶点与现有 n=4 四边形求解相差小于 `10⁻¹⁰`。若直接用未重算的第三角 `95°`，所得形状不同，这正是必须保留奇偶重算契约的原因。

这个模块只返回底层单位圆内接**母多边形**。已有 n=4 的 `UnitCyclicPolygonCenteredTwistTile`/Alt 是独立具名扭转专项；此处没有构造新 CP、FF、整片层序，也没有 `adoptable` 结论，更不宣称覆盖原版所有 `angles/side/is` 或 Mathematica 绘图的逐点等价。从 `workbench` 运行 `.venv\Scripts\python.exe -m unittest discover -s backend -p test_tessellation_unit_cyclic_polygon.py` 复现。
