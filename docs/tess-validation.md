# 镶嵌生成后端验证记录

日期：2026-09-17。环境：Windows x64 / Python 3.11.3；代码与私有依赖均位于新 `workbench`，没有更改旧 `zhezhi` 或全局 Python。

## 交付范围

`backend/tessellate.py` 是已运行验证的本地 Python CLI，调用 Pleat 的真实平铺、相互图、Shrink-Rotate、山谷赋型和 FOLD 导出。不是二维多边形缩放示意。

上游固定为 [imagirom/pleat](https://github.com/imagirom/pleat) 提交 `6a7015834b3357290a1678abf35b613987b07c44`。`vendor/pleat/LICENSE` 保留 MIT 声明；只复制 Python 包源码及包内 YAML 数据，不含上游文档、笔记本照片、模型权重和 `.git`。顶层 `__init__.py` 改为按需导入，其他几何算法未修改。详见 `vendor/pleat/UPSTREAM.md`。

暂不调用 Pleat 层序求解器，也不外发模型到 Origami Simulator 网站。PuLP 因上游生成模块的导入依赖而安装在私有环境内，其求解器不在本功能执行路径中。

## 接口

在项目根目录运行：

```powershell
'{"tiling":"square","rings":1,"angle":36,"scale":0.5}' | .\.venv\Scripts\python.exe .\backend\tessellate.py
```

- stdin：一个 UTF-8 JSON 对象，最多 4096 字节；未知参数拒绝。
- `tiling`：`square` / `triangle` / `hexagon`，默认 `square`。
- `rings`：整数 0–3，默认 1；0 是空白种子多边形，明确提示角度和缩放不会生效。1–3 才生成镶嵌候选。
- `angle`：角度制 -80°..80°；非零圈数时绝对值至少 0.1°，默认 36°。
- `scale`：0.20..0.85，默认 0.5。
- 这些是**有限探索范围，不是全部可折参数域**；范围内仍可能产生交叉或局部条件失败。
- stdout：唯一 JSON `{fold, stats, warnings, source}`；不混入上游打印。
- stderr：失败时中文提示；非零退出码。NaN、Inf、过大整数、布尔冒充数字、过大规模及畸形 JSON 都拒绝。
- 输出上限 3000 点、6000 边；FOLD 为二维，M=-180、V=180、B/U=null。

`stats.checks` 包含：

- `geometry`：短边、重复拓扑边、非共端点边相交／重合；违规边索引可用于 UI 标注。
- `local`：内部顶点奇数度、Kawasaki、完整赋型时的 Maekawa；独立从输出 FOLD 坐标重算，未复用上游有符号最大值的捷径。
- `layerOrder.status = not_checked`：**未计算整体层序**。
- `foldability = candidate`：始终是候选；局部通过不升级为“保证可折”。

Kawasaki 容差为 0.001°。边界顶点不套用内部顶点定理。几何检查的长度容差随图样尺度变化。检查不是对曲线、厚纸、接触、碰撞、连续折叠路径或物理可实现性的证明。

三种 0 圈种子也成功输出，局部检查为“不适用”，没有伪装成扭褶生成。

独立参数矩阵：三类 × 一圈 × 角度 `[-60,-36,-18,18,36,60]` × 缩放 `[.2,.5,.85]`，共 54 组：

- 36 组几何及局部必要条件均通过。
- 12 组几何及局部条件均失败。
- **6 组局部条件通过，但几何发生交叉**。这直接说明不能把 Kawasaki/Maekawa 通过显示为整体可折。
- 所有结果保留候选语义；失败项有中文警告，不伪造成功或自动隐藏图样问题。

另有 2M2V 的 Maekawa 负例、非直角扇区的 Kawasaki 负例、相交边负例、角度／缩放实际改变输出几何、赋型符号／边索引／欧拉关系、纯 JSON 与错误退出测试。

性能是本机观测而非跨机承诺：独立 CLI 六角三圈约 1.72 秒，其中导入和计算约 1.52 秒；同一进程初始化后单次默认生成约 12–99 毫秒。首次安装后的字体／库初始化可能更慢，服务层仍应提供取消和超时隔离。

私有 `.venv` 当前约 565 MB（十进制，含科学计算轮子），不是精简发行包。仅 vendored Pleat 源码／数据／运行缓存约 1.1 MB。将来打包时需单独审计依赖二进制与许可，不能把源码 MIT 推断成所有依赖都同一许可证。
