## 全路径公式及完整证明域

记运动参数 `λ∈[0,1]`，`γ(λ)=2πλ/3`、`c=cos(γ/2)`、`h=sin(γ/2)`。用同一材料坐标定义

`Xλ(s,w)=(c(2+w)cos(s/(2c)), c(2+w)sin(s/(2c)), h|w|)`。

`λ=0` 时 `X0=(P,0)`；`λ=1` 时 `c=½,h=√3/2`，因此 `X1=F(s)+(−w)rL(s)`（左片）或 `F(s)+w rR(s)`（右片）。保存终点采用代数常数 `½,√3/2` 计算，避免 `cos(π/3)` 的机器舍入进入方位角除法。

本地输入区间 `arcEnd∈[π/8,π]`、`leftWidth∈[0.1,1.5]`、`rightWidth∈[0.1,2]`。这个闭域覆盖默认保存绘图区，且严格停在左侧焦点 `w=−2` 前。以下证明针对所有输入参数、所有 `λ`、所有材料点，不是从画面网格采样推出的结论。

| 性质 | 解析证据 |
|---|---|
| 等距 | 在每一侧 `X_s=(-(1+w/2)sinφ,(1+w/2)cosφ,0)`，`X_w=(c cosφ,c sinφ,sign(w)h)`，`φ=s/(2c)`。第一基本形式始终 `E=(1+w/2)²,F=0,G=1`，恰等于 `P` 的形式，与 `λ` 无关。 |
| 正则 | `|X_s×X_w|=1+w/2≥1−leftWidth/2≥¼`。投影雅可比的绝对值为 `c(1+w/2)≥⅛`。左右片沿 `w=0` 共折痕；每片含闭边界正则，整张纸在折痕处允许法向折角。 |
| 可展 | 每片 `X_ww=0`，`X_sw=(-½sinφ,½cosφ,0)` 与单位法向点积为零。因此第二基本形式的 `f=g=0`，高斯曲率为零。 |
| 完整域单射 | 投影径向半径 `ρ=c(2+w)>0`；方位角区间 `0≤φ≤arcEnd/(2c)≤π<2π`。同一个 `(x,y)` 唯一给出 `φ` 与 `ρ`，随后 `s=2cφ`、`w=ρ/c−2` 唯一。两片、端边及内部均包含在同一个逆映射中，因此任意两不同材料点在同一帧不会重合；两片只沿公共折痕接合。 |
| 平展起点 | 逆映射完全不除以 `h`，所以 `λ=0` 时仍有效；高度仅检查 `z=h|w|`。没有把平展帧遗漏于证明域。 |
| 连续运动 | `c∈[½,1]` 永不为零，位置对 `λ` 连续并在每片内光滑。空间运动是零厚度纸张的连续等距嵌入；无自碰撞结论适用于每一帧全部有限域。 |

`inverseMotionPoint`／`inverse_motion_point` 返回解析材料坐标并核验有限域和高度。越域、非有限值、轴线上点或不在当前曲面的点直接拒绝；机器边界误差仅以 `2e-10·max(1,ρ,|z|)` 校验，不扩大上述数学证明域。

## 仍须与其他构造分别验收的范围

此证书覆盖上述完整有限**光滑纸张**的全部运动路径。它不认证 `curved-circle-polyhedral` 静态伴随 FOLD 的刚体路径：圆弧弦段近似及平面扇角修正是另一种离散纸张。它也不提供任意三维曲线的 `FoldAcrossRight3D` 通用符号分派、非零纸厚、直折痕平折层序或 Wolfram 插值输出。不能把该保存例的完成推为整个第 45 节或整个笔记本等价。
