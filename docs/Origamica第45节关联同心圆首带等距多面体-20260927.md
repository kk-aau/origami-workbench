# Origamica 第 45 节关联同心圆：保存首带的有限等距纸面

原版 `Origamica 15.0.nb` 的 `In[4086]` 保存五条关联同心圆的输入，但未保存可机读三维点表；工作区先前只有该保存输入的**首条** `f₀→f₁` 光滑直纹带只读视图。原保存输入取 `q₁(s)=s+0.1 sin(2s)`、`γ₀=120°`、`0≤s≤π`。其第二带起存在参数与内蕴测地曲率冲突，见《Origamica第45节关联多曲折保存示例审计-20260924.md》。本构造仅为首带提供可采用的**有限多面体近似**，不声称五折整串已经成立。

## 构造和验证

后端 `tessellation_curved_linked_first_band_polyhedral.py` 对已认证的首带 Darboux 方程作高精度数值积分，在 `n=8…96` 的共同参数节点取空间边界点 `F₀(sᵢ),F₁(sᵢ)`。这些是本地 ODE 数值样点，不是 Mathematica 原始 `Out` 或解析精确坐标。两个顶点行构成一条三角带；每段拆成两个三角形。三角带没有内部顶点，面邻接对偶是一条路径，因此可以从第一条母线起按三条空间边长逐面展开。展开图顶点与三维顶点共用索引；每个三角面三边长度逐对相同，空间面共面性、非退化和二维折线不交叉由独立门禁检查。山谷符号及折角从相邻有向空间三角面的法向计算。

默认 `n=32` 生成 66 点、129 边、64 三角面；二维几何状态为 `passed`，最大面边长误差约 `1.39×10⁻¹⁶`。按第一条母线平移对齐原版光滑二维边界后，最远节点漂移随局部采样缩小：`n=8` 约 `0.11855739`，`n=32` 约 `0.00727394`，`n=96` 约 `0.00080704`。这一漂移是**必需的弦长修正**，不是原版解析式误差。若直接连接原光滑二维边界与三维同参数样点，对应直线弦长不同，不能作为等距 FOLD；见《Origamica第45节零扰动四带不可采用核查-20260927.md》中的同类弦长核查。

主工作区“空间构造 → 关联同心圆首带 · 等距多面体”使用统一 CP 画布和同索引三维窗格；可调曲线分段及山谷阈值，可把该**静态多面体纸面**采用到工程。生成结果明确记录 `originalSmoothSurfaceExact=false`、`sampledSmoothSpatialVerticesExact=false`、`numericalDarbouxIntegration=true`、`exactPolyhedralFacetIsometry=true`、`wholeSavedPerturbedChainCertified=false`、`selfCollisionChecked=false`、`continuousRigidPathChecked=false`。它不是原光滑带本身、平折层序、连续无碰撞折叠路径，也不能被扩展成任意独立纸张而仍沿用现有三维映射。

原零扰动四带是另一输入 `q₁=s`，仍只读。其所有带界在空间有端边接触，且有限同参数直边不等距；这个**首带**候选既不把零扰动四带标为可采用，也不将其 `boundaryEndContact=true` 误写进不同的保存输入。

专项复验：后端执行 `python -m unittest test_tessellation_curved_linked_first_band_polyhedral test_tessellation_curved_linked_first_band test_tessellation_curved_linked_zero_chain test_tessellation_curved_linked_source_audit -q`；前端执行 `npx --offline tsx --test tests/app/linkedFirstBandPolyhedralParams.test.ts tests/app/tessellation.test.ts tests/app/curvedCirclePolyhedralParams.test.ts` 与 `npx --offline tsc --noEmit`。前端从真实 Python JSON 回读 FOLD，重新逐面校验 CP／三维边长，篡改单个三维顶点会被拒绝。

真实浏览器复验：在镶嵌工作区选择该构造，默认 32 段显示 66 点／129 边／64 面；将分段数改成 48 后无需重新计算按钮即可更新为 98 点／193 边／96 面，画布静态等距误差显示约 `1.8×10⁻¹⁶`，候选检查为几何通过和静态三维等距已验。[48 段同画布截图](../output/playwright/p45-linked-first-band-polyhedral-48-20260927.png)。
