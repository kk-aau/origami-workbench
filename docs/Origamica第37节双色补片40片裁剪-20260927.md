直接核对 `tmp/Origamica-15.0-reference.nb` In[3187] 与 In[3188] 的保存输入：两者都使用 `TwoColorableArchimedeanPatch[2]` 的两块正方形、格矢 `(2,0)` / `(1,1)`，先按 `[-2,2]×[0,3]` 生成 40 片，再以 `[.1,3.9]²` 矩形执行 `PruneTiling`。In[3187] 是 `w=.2, α=30°` 居中 Alt，来源片中心赋型分别为 M4 / V4；In[3188] 是 `w=.2, d=.1001` 偏置型，parity `(+1,-1)`，两片都为 M4。
