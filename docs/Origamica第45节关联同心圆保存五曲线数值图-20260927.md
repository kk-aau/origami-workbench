# Origamica 第 45 节：保存输入的五曲线有限数值图

工作区“关联同心圆首带 · 只读”弹窗现有第三种范围“原保存输入 · 五曲线数值图”。它保留 `In[4086]` 的 `q₁(s)=s+0.1 sin(2s)`、`γ₀=120°`、五个半径 `1,1.1,1.2,1.3,1.4`，画出 `0≤s≤π` 的五条二维及三维曲线。笔记本没有保存可机读的 Wolfram 数值点表；这些是**按保存表达式在本地独立计算的有限数值近似**，不能称为原 `Out` 的逐点复现。

后端 `tessellation_curved_p45_linked_chain_query.py` 按 `NLinkedFoldsNext2D` 三次递推。原函数提供 `InterpolationPoints` 选项，保存调用沿用默认值 32；它在该数量的等间隔区间上取折角样值，用 SciPy 四次样条近似 `ListInterpolation[...,InterpolationOrder→4]`。每点在下一圆投影的无极点中央区间找与 `qᵢ(s)` 相邻的根，再对根节点作四次样条。保留原式的 `γᵢ′[qᵢ(s)]` 读取方式。三维绘图从已认证的首带 Darboux 数值标架出发，按 `NLinkedFoldsNext3D` 的位置和右横向表达式接出其余曲线，也保留该保存调用将公共参数形式的 `fᵢ` 与未复合的 `Curve2DSystem[tfᵢ]` 混用的行为。绘图在请求的 8–128 个段上直接取本地表达式值；不模拟 Mathematica `FunctionInterpolationAlt` 的内部样条，因此曲线间的虚线仅表示同参数对应点。

固定 32 区间的三次求根最大节点残差约 `6.3×10⁻¹⁴`，本地首带与原首带查询的空间位置最大差约 `2.5×10⁻¹⁶`。这说明所选近零根分支和首带拼接在本地算法内一致，**不证明**跨软件数值结果相同或后续带等距。第五条曲线端点已越过原区间：`q₄(0)≈−0.00640045`、`q₄(π)≈π+0.00640045`。把同一算法的内部插值区间改为 16／32／64，`q₄(0)` 依次为约 `−0.01496617／−0.00640045／−0.00283483`；端点值对插值分辨率敏感。在内段 `s∈[π/8,7π/8]`，32 与 64 区间结果的 `q₄` 最大差约 `3.91×10⁻⁴`，也仍只是分辨率比较而非误差证明。因此默认 32 区间是保存参数下的一个可查看数值图，不是有误差包络的唯一原版曲线。现在用户可分别调整“本地插值区间数”和“本地采样段数”（均限 8–128）：前者重解三步传播，后者只改变绘图密度。更改插值区间后属于本地数值试验，源式半径、扰动、初始折角及不可采用判定保持不变；8–128 的整数区间本地求根扫描均通过，但不证明 Wolfram 内部插值及根分支等价。

原版 `In[4086]` 的二维和三维绘图各调用一次 `StyledRuledPatchSequence[flist,{u0,u1},RulingLineDivisions→50]`，再叠绘五条 `StyledCurve`；该函数的默认 `CurveDivisions→100` 见 In[1757]。界面现对四对相邻曲线画出只读直纹带及同参数母线，保存模式初始按 100 段绘制曲线，在每隔两段的位置画 51 条母线，对应 50 个母线分段。用户改变曲线采样数时，母线仍在可用样点上均匀取最多 51 条；这属于本地显示密度试验。色彩、透明度和 SVG 绘制仍是本地示意，不冒充 Mathematica 原始样式。直纹面可单独关闭，以便观察曲线；插值区间仍独立使用原默认 32。

更根本的几何边界已由源公式精确给出：`s=π/4` 时缓存切向与真实第二边界切向相差 `0.1` 弧度；`s=0` 时第二带两侧测地系数差为 `396/665≈0.59548872`。后续空间曲线即使数值求根稳定，也不能作为同一平纸四带的等距折叠。界面明确写“有限数值图”“第二带不等距”，直纹带仅作原公式的可视化，不提供采用、FOLD 导出、碰撞或运动认证。可严格采用的有限纸面近似仍仅限另一个已分开的首带多面体构造；零扰动四带则是改变保存输入的独立只读子域。

专项验证：在 `workbench/backend` 运行 `..\.venv\Scripts\python.exe -m unittest test_tessellation_curved_p45_linked_chain -q`；在 `workbench` 运行 `npx tsx --test tests/app/curvedP45LinkedChain.test.ts` 与 `npx tsc --noEmit`。测试覆盖保存输入、首带位置一致性、节点残差、端点外推敏感性、插值区间调整后的真实重解和对虚假等距／可采用声明的拒绝。
