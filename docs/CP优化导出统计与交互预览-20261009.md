# CP 优化导出统计与交互预览（2026-10-09）

入口：顶部独立的“优化加工导出”。本批核对DXF条数并增加缩放、拖动和高亮；源码运行版更新，免安装版未重打包。

| 功能 | 最终效果 |
| --- | --- |
| 条数 | 显示DXF回读的LINE实体数，交叉核对实际导出预览；不把可转弯规划组当成一条LINE。不一致阻止显示/导出。 |
| 次数 | 条数/长度均累计加工次数，排除线型和零长不计有效边。 |
| 视图 | 默认实际导出线段，规划组单独标记；当前编号跟随视图。 |
| 缩放/平移 | 鼠标中心滚轮缩放，放大/缩小/适合按钮，左键拖动；前后视图切换保位置。 |
| 高亮 | 悬停命中线段显示高亮、编号、线型、来源段数及长度；移出取消。 |
| 文件 | 普通R12/AC1009 LINE保留，不新增设备/抬笔指令，原CP和普通导出保留。 |

原规划路径与序列化LINE有不同计数。本批分开显示名称、编号和统计来源，收到线程报告时核对实体数、来源加工次数和长度。核验JSON新增 `displayedStatistics`，旧规划/回读字段兼容。
