# 圆与辅助线着色

模式59已接入左侧“辅助圆 → 圆与辅助线着色”，绘图入口共85项。选显示颜色，单击或左键拖接触框，松开应用；紫色表示命中预览，不是将要写入的颜色。整批一次撤销。操作中右击/Esc取消，空闲右击仍按既有规则删线。

## 规则与数据

- 单击按原版比较最近的所有线段与圆，线平局优先；最近线不是辅助线时不会穿透给后方对象着色。同类等距取后加入对象。圆以圆心/圆周较近者命中。
- 框选不限方向，辅助线接触即命中；圆周与框接触或圆心在框内命中。不含圆心、完全位于大圆内部的小框不命中该圆。拖回起点时清除矩形预览，松开按单击判定。
- Segment.displayColor只在A辅助线时显示。非A对象仍显示原山谷/边界语义颜色；休眠覆盖值保留以便改回A，不改变几何、类型或角度，也不进入折叠求解。圆沿用独立对象color。
- Canvas、SVG（包括操作框导出）及平折原位置缩略图共用segmentDisplayColor，PNG/打印沿用SVG链路。原生JSON/恢复保留；FOLD辅助线扩展保留，本工具之外的软件可能忽略；CP/OPX明确提示颜色丢失。
- frontend-design 技能用于保持单行紧凑参数条、色值与命中数量；工具按钮继续遵守既有最大宽度和最多四列规则。
