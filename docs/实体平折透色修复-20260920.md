# 实体平折透色修复

版本 v0.12.5，2026-09-20。

十边形扭转（角度 36°，半径比 0.5）可复现：局部层序分解得到 768 个区域，逐个 SVG polygon 填充时，抗锯齿接缝漏出下层纸面颜色。并非实体模式主动使用了透明度。

现在按可见颜色及已确认／未确认／冲突状态合并区域。绘制前抵消同组的内部边，纵向切分边使用区间扫描处理 T 形接缝；在几何容差内焊接共享坐标。只绘制合并轮廓，保留孔洞、分离区域及真实可见边。原有区域仍用于选面和层序说明，但命中多边形不再重复上色。高亮选面使用独立颜色，正背面材料与旋转投影沿用原规则。计算数据及层序不变。

折痕编辑、镶嵌和比较视图共用 ModelRegionSurface；SVG 导出共用 modelRegionPaths 的轮廓生成。透视和线框不启用不透明局部表面。

验证：28 项相关单元测试通过，覆盖局部层序、T 形接缝、浮点端点、选面颜色、孔洞、分离区域、镜像、SVG 导出及阴影。真实浏览器 11 项回归通过；同一十边形样例在正背面 320/800 像素和背面旋转 45° 的 640 像素渲染中，检测到的实体内部漏色像素均为 0，旧逐块绘制对应为 7070、22540、4817、15002、9006。像素检查排除真实材料边界的正常抗锯齿，保留同色区域内部接缝；透视切换和相机位置保持同时通过。

补充修复：同画布的 SVG 拖动捕获会使浏览器把单击派发到 SVG 根节点，从而丢失选面操作。现在记录按下时的可见面，未发生拖动才在松开时选择，移动模式与拖动不会选面。另加 4 项真实交互检查，验证编辑区选中可见面、独立高亮、拖动与避免误选；浏览器总计 15 项。

回归脚本：scripts/verify-solid-seams.browser.js。截图：项目根目录 output/playwright/solid-seams-fixed.png。
