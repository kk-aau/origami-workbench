# 角度会聚与角度投影（v0.9.2，未打包）

新增两个独立工具，当前45项实际工具；沿用紧凑多列工具栏，完整目标仍进行中。

## 操作

- 角度会聚：点击已有线段线身，直接以其两端为基准；或点击两个基准点。附近已有端点／交点优先于线身。两组紫色方向展开后，点击交会位置一次生成两条有限线，基线不写入也不改型；两条新线均采用当前绘制线型，可一次撤销。
- 角度投影：点击基准点，再点击新线起点；第三次点击候选方向附近的终点位置，直接投影并生成。起点为第二点，不要求定向截取的第四次截止。开启吸附时，附近实际交点只有满足原版两倍投影误差判据才替代投影终点。
- 共用现有持久化角度设置；改变角度设置取消构造，改变山谷预设保留基准。无效点击保留输入，右键／Esc明确取消；空闲右键仍按通用规则删线。
- 候选扇、基线和悬停结果均为紫色参考，不写入折痕；会聚两腿提交后自动真实分割已有交点。
