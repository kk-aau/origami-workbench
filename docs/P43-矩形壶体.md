# Origamica 第 43 节：矩形壶体

独立后端 `tessellation_rectangular_pot.py` 复现原版 `MakeRectangularPotWedge` 与 `MakeRectangularPot` 的严格静态几何。笔记本只读副本 `tmp/Origamica-15.0-reference.nb` 第 265373–266620 行为单块定义，第 268073–268223 行为多块拼接。保存的 In[3489] 示例是 `{{.3,0},{1,1},{1,2},{1,3},{2,4}}, m=8, ρ=0, PotFlangeExcess=.1` 的单块；In[3503] 示例是 `{{0,0},{1,1},{1,2},{1,3},{2,4}}, m=5, ρ=0` 的整片。

剖面高度减去首点高度，半径 `x` 保留；沿剖面累加弧长为 `r`。每块纸在二维中占宽 `r_max`、高 `2h` 的矩形，其中 `wᵢ=tan(π/m−δ)xᵢ`、`h=max(wᵢ)(1+fe)`。原版六列 `a…f` 的折后点 `aa…ff` 保留为真实三维坐标。零接缝角使用笔记本针对 `ρ=0`、`ρ=±1` 及一般 `ρ` 的解析解；非零接缝角逐行求 `|d−c|²=|dd−cc|²` 的最小非负根。`PotPanels` 块在二维纸上沿矩形长边平移并共边，三维中逐块绕 z 轴旋转 `2π/m`。

模块对每个纸面**所有顶点对**比较二维和三维距离，检查三维共面、二维折痕无交叉、边的流形性与 Euler 连通无孔条件。In[3503] 整片得到 105 顶点、204 边、100 面，最大面内距离误差约 `1.5×10⁻¹⁵`；In[3489] 单块得到 30/49/20。`panels=3,m=5` 得 65/124/60，纸面中间接缝共享顶点，而首尾纸边不错误焊接。原笔记本保存图形而非数值顶点表；这些数值锚点由原版公式转写并在当前求解器重算，尚未与 Wolfram 导出的坐标逐项比较。

请求字段为 `family:'rectangular-pot'`、`crossSection`、`sectors`、`panels`、`asymmetry`、`gapHalfAngleDeg`、`flangeExcess`、`typeMinimumAngleDeg`。省略时采用 In[3503] 的剖面与 `m=panels=5,ρ=δ=fe=0`。`panels` 限 1–m；原版可请求更多面板，但这样绕轴重叠，不在当前严格等距且未验证碰撞的可采用域。求解失败、负法兰宽度、折痕交叉或静态等距失败均拒绝，不返回冒充三维的坐标。

`PotFlatFlangeInset` 已作为 `ρ=±1` 时的“法兰分层 ε”显示参数接入，范围 `0–0.5`。它按原版对 b/e 类点的 `(1−ε,1−ε,1)` 缩放，只作用于三维绘制副本；真实 CP、`foldedForm3D`、逐面等距检查和采用门禁保持原样。显示副本本身不是等距纸面，重叠层序无法确定时继续画线框。后端对两种极端不对称度核对真实折痕和坐标完全不变，前端检查不会把该显示副本当成真实等距结果。1000×720 实际浏览器中，ε=.1 的构形、几何检查和静态等距标记可见，页面及属性栏均无垂直滚动；截图 `../output/playwright/rectangular-pot-flange-inset-20260927.png`。静态三维等距不证明存在连续可折路径或无自碰撞；局部平折检查在此结构不适用。

现已接入镶嵌工作区“空间构造 → 矩形壶体”，可编辑扇区数、实际面板数、剖面、法兰余量、接缝角与赋型阈值，并在同一画布切换展开图与静态三维。1000×720 和 1600×900 的真实浏览器测试覆盖默认整片、面板数 5→3、法兰余量 0→.1、剖面编辑、正反视角与采用副本：所有构造均 HTTP 200、几何通过且静态等距已验；证据在 `output/playwright/rectangular-pot-browser-report.json`。默认视角下部分法兰面重合且相反朝向，无法从无厚度几何唯一排序，视图明确提示并安全回退为线框。

In[3504]/In[3505] 的非废弃光滑保存输入现有一键选择：精确按 `Table[{.5 Sin[θ],Cos[θ]-1},{θ,0,π,π/20}]//N` 生成 **21 个数值剖面点**，取 `m=PotPanels=4`、`PotFlangeExcess=.5`、`TypeMinimumAngle=30°`，仅 `ρ` 分别为 `0`、`.3333`。工作区的剖面上限由 12 提到 24；后端同步校验点数和 `5×panels×(点数−1)≤600` 的面预算，非法 25 点或超预算组合仍拒绝。两个保存例各生成 425 顶点、824 边、400 面；真实后端的二维折痕几何、同索引三维逐面所有顶点对距离及共面均通过，独立距离误差低于 `10⁻¹⁰`。原默认和 12 点剖面仍通过回归。TS 检查了响应读回、篡改三维坐标时的采用拒绝和完整工程 JSON 的参数/来源读回。1000×720 Chrome 可切两例、二维/三维及背面，采用按钮可用，页面与侧栏均无纵向滚动；`output/playwright/rect-smooth-browser-report.json` 保存布局、状态和 API 证据。这证明两个**静态等距目标构形**，不证明连续折叠路径、自碰撞安全或原版保存图片的像素相同；笔记本没有对应可机读的数值顶点 Out。

同一保存例下拉还提供 In[3489]–In[3494] 六个**单楔片**和 In[3506] 缺一面板的整壶体。In[3494] 原版 `PotWedgeJoinVertices` 的 a/f 接合边语义已按当前 0-based 顶点索引在响应来源返回；不能把不同顶点编号误称为 Mathematica 的原数值输出。八例参数、几何计数、专项和真实浏览器证据见 `P43-其余壶体保存输入-20260928.md`。
