原式从左侧恢复共同平面曲线：`f′=v t, t′=gL l, l′=−gL t`，在任意域内 ui 向两端积分。左法向按 `UL=normalize(T×rrL)`，右按 `UR=normalize(−T×rrR)`。原右母线的两个负号抵消后实际为 `rR=pR t+qR l`，qR保负号；母线长度、参数及左右数据不做替换。

左右源各自可展仍不足以证明共同展开。右侧自己的 gR 必须等于驱动共同平面的 gL。输入 `ff=(cos s,sin s,0),rrL=−ff,rrR=(0,0,1)` 的两侧各自可展，但 gL=1、gR=0；原式右源 E=1，平面 E=(1+w)²。界面保留其实际双侧结果，独立显示相容失败及右度量失败。
