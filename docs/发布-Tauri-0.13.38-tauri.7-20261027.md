# 折纸工坊 Tauri 独立版 0.13.38-tauri.7

本候选继续保留四个工作区、完整本机离线计算及独立数据目录，使用 Tauri／Rust 和系统已有 WebView2。

本轮修复大工程浏览器缓存达到配额时的恢复状态误报：等到磁盘写入结果后再判断是否需要提醒。磁盘失败时仍提示临时缓存或未能保存，不裁剪工程内容，见[恢复副本保存反馈](恢复副本保存反馈修复-20261027.md)。

用户要求优先缩短龙神完整计算耗时，允许增加内存使用，并尽可能利用多核 CPU 与 GPU。性能改动必须保留完整区域、层序、接触和可见边界验证；只根据同一输入、同一口径的实测结果保留优化，不以硬件占用率或局部耗时冒充完整计算耗时。

CPU 关系查询采用双向二位缓存，符合条件的大工程使用共享内存和最多 20 个检查线程完成全部区域认证；线程异常回退完整检查，停止操作释放求解及检查线程。真实宿主通过同源隔离允许共享内存，现有来源限制和原生桥鉴权保持有效。

同一龙神缓存几何与拓扑输入的完整候选求解从 1,005.51 秒降至 312.27 秒，缩短约 68.9%；最终 1,828,791 个区域的完整证书逐字节一致。该口径不包含原始 CP 导入、几何和拓扑构建，不能当作应用端到端耗时。GPU 真实 16k／64k 区域实验结果正确，但当前收益不足以替代多核 CPU，因此没有纳入生产层序认证；原有 CP 绘制与三维模拟 GPU 功能继续保留。验证口径见[大工程速度优先计算](大工程速度优先计算-20261027.md)。

新 WebView2 原生宿主的独立冷计时中，从原始龙神 ORI 导入到完整双面结果约 256.20 秒（4 分 16 秒，排除额外 SHA 计时），两面各完成 1,827,830 个区域验证。该管线使用正式 Worker 资源，不复用几何、拓扑或证书；主界面最终绘制与实包操作另行验收。计算中途停止约 68.2 毫秒返回并释放整组线程。旧 834.311 秒基线使用不同版本的 Headless Edge，不据此宣称严格同环境的整体提速比例。

本版应用包和完整源码 ZIP／7z、调试资料分别交付；应用内不含源码归档。系统须已有 Microsoft Edge WebView2，完整 Python 引擎随应用提供，不自动下载运行环境。
