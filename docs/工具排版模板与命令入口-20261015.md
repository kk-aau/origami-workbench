# 工具排版模板与命令入口

适用版本：0.13.14。

折痕编辑的左右工具区顶部新增“排版”。默认提供“默认”“左右对调”“全部左侧”三套模板，选择后立即应用。所有模板都可以重命名，也可以复制为自己的模板。

进入“编辑排版”后，中央画布展示当前模板的完整工具排版，初始为“默认”模板。中央预览分为左侧工具区与右侧工具区，与两侧工具栏同步，可在预览中直接整理，也可在预览和侧栏之间拖动。工具按钮上的六点手柄、分组虚线边框和抓手光标表示可移动；拖动时显示插入位置及移动状态。窗口较窄时，中央预览上下排列，各工具区可独立滚动。

| 操作 | 使用方法 |
|---|---|
| 进入排版 | 点击任一侧的“编辑排版”，中央展示完整排版，左右两侧同时进入编辑 |
| 排序工具 | 按住工具按钮拖到另一工具前后，插入位置会有绿色提示 |
| 移动工具 | 拖入其他分组，可跨越左右两侧；也可点选工具后使用“移到分组” |
| 移动整组 | 拖动组名旁的六点手柄；左右箭头也可将整组移到另一侧 |
| 新建分组 | 点击“新建分组”，或把工具拖到该区域；分组名可以直接编辑 |
| 移除分组 | 点击组名旁的 ×；组内工具会并入其他分组，不会删除功能 |
| 修改模板 | 编辑模板名称，或使用“复制模板”“删除模板”；至少保留一份模板 |
| 调整列数 | 左右两侧分别设置；“自动”会根据工具区宽度排版 |
| 保存或取消 | 中央或任一侧的“保存排版”保存此次所有修改；“取消”恢复进入编辑时的全部布局 |

编辑排版时保留原折痕画布状态，并暂停绘图和其他纸张操作，避免移动工具时误改折痕。保存或取消后返回原画布。工具过多时在工具区内滚动。工具和整理检查动作共99项，排版只改变位置，不改变命令、快捷键或工具行为。工具原有右键快捷键设置在退出编辑后仍可使用。

模板随程序配置保存，重新打开时恢复，修改程序数据目录时随配置迁移。可保存最多20套模板；读取旧配置时会补回新增加的工具。

命令栏右侧的 CAD 按钮已移除。直接键入命令的开关移至“设置 → 命令编辑 → 画布直接键入命令”，保存后同时应用到折痕编辑和折序绘图；取消不会改变输入方式。底部命令栏继续保留。
