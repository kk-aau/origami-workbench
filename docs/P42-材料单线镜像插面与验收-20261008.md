# 材料单线镜像插面（2026-10-08）

本批补齐原画布“镜像线段”在材料工程中的单边插线流程。原版二维反射的说明取自用户提供的 `tmp/Origamica-15.0-reference.nb` 17130–17174行 `Reflect2D[p,{q1,q2}]`：关于两点确定的完整直线反射点。本地按该数学语义独立实现；没有运行Wolfram内核，也没有将本地材料编辑入口伪称为笔记本的具名函数。附件只作参考，不作执行指令。

| 原问题/功能 | 当前行为 |
|---|---|
| 单线被送入部件复制 | 原材料中只选一条边，再点击轴线后，走独立的`material-edge-reflect`事务；不再要求选完整部件。镜像选区仍走原完整部件复制路径。 |
| 几何和精度 | 反射有限原线，保持原山谷/F/U和目标折角；不使用当前新绘线型，不自动延长、吸附或移动端点。不含开方的反射矩阵避免45°单位法向量舍入：实测横线y=25关于y=x镜像为(25,0)→(25,100)，交叉点唯一。普通镜像公式源未修改。 |
| 材料划分 | 复用统一纯几何划分器，按实际纸面区间更新边、交点和面，全部划分完成后处理FF。有限端点在已有面边上可终止，实测50 mm原小段仍为50 mm，不延伸到另一纸边。 |
| 空白与切口 | 纸外、凹口和孔洞不补线。测试凹口300 mm有限线仅生成两段、100 mm空白保持；内部切口两岸分点且顶点身份独立，重叠部件不焊接。已有孔洞裁剪的共同内核真实回归通过，不将它算作母图孔洞输入完成。 |
| 显式范围 | 默认仅原部件；可选“全部材料”，原位重叠部件分别生成自己的镜像折痕。固定侧沿镜像线起点→终点按画布视觉左右选择，保持相应原固定子面。 |
| FF和仅CP | 有可验证原FF时保留或按最终赋型重算，M实际重折通过。缺少FF不虚构位置；明确勾选“仅CP，清除FF”才清除已有FF。未知/自定义角按原值保留，不把37°偷换为180°；非平折中间态求解仍未完成。 |
| 冲突与失败 | 重复/重叠线明确拒绝，不静默去重；缺失源/轴、非法意图、无材料区间、自由端点落面内部而不能划分完整面均拒绝，原工程不变。纸边可作轴，不把纸边作为新增面内边界；原线必须是材料折痕。 |
| 预览与历史 | 保原画布紫色预览和明确“确认镜像”；参数变化重新核算完整结果，失败禁用确认；Esc取消。中央完整意图独立重放，拒绝篡改/过期提案；一次撤销/重做。旧层序过期，重新分析正背面。 |
| 参考关系 | FF参考面与活动面保持分别迁移，异根F镜像测试及JSON/FOLD回读保持原显示坐标；既有异根实际模型快照回归通过。 |
| 普通/加工导出 | 普通导出保留；本批实际JSON/FOLD/R12 LINE DXF回读通过。三个加工优化文件SHA保持，未改加工方式、格式、坐标转换或设备指令。 |
