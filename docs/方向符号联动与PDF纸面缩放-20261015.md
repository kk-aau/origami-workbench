# 方向符号联动与 PDF 纸面缩放

日期：2026-10-15

| 操作 | 结果 |
| --- | --- |
| 本步放置翻面符号 | 下一步自动换到另一面；本步的输入纸面不改变 |
| 本步放置顺时针或逆时针旋转符号 | 下一步按箭头指示旋转，默认 45° |
| 双击旋转符号中央数字，或编辑“旋转角度” | 可输入 0～360°及小数；Enter/失焦保存，Esc 取消 |
| 修改或删除已有方向符号 | 自动同步后续继承方向的步骤；撤销、重做同步恢复 |
| 用户手动修改某步纸面的方向 | 此步保留手动方向，之后的自动步骤从它继续继承 |
| 导出 PDF 时方向符号位于纸外或贴边 | 以纸面和普通绘图确定主体大小，将方向符号排入纸边留白 |

旋转数字表示下一步纸面的转角；符号的“基线角度”仍用于摆放箭头。反向符号及 CAD 翻转会反转箭头和对应动作。多枚方向符号各执行一次，重复进入下一步、保存和载入不累加。新逆时针命令为 `SROTATECCW`，旧“旋转”命令保留。

纸面方向单独记录自动/手动模式，无折图时保存待继承方向。旧工程在载入入口统一推断：明显手动设置的方向保留，原来与前一步相同的方向升级为自动继承。原材料几何、CP 和纸层身份不改变。平整/扯角快照共享自动继承的方向。

刷新投影前同步重投影关联折痕及构造点，防止颜色和线宽匹配丢失；换面后的谷峰显示随观察面转换，材料 CP 不改。纸外方向符号使用 PDF 专属布局，与普通 SVG 的原始摆放独立。PDF 预览和实际导出共用布局，自选行列保持可用。

验证覆盖自动继承、新建下一步计算、级联修改、手动方向保护、撤销重做、载入、复制删除、角度双击编辑和取消、原折痕样式保留，以及复杂步骤动画回归。PDF 使用纵向 3×2 和横向 4×4 实际导出并渲染 PNG：同一纸面添加纸外方向符号前后尺寸一致，栅格量化差异不超过 1 像素；方向符号完整可见。
