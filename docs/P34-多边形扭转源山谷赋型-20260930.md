# P34 多边形扭转：按原版固定褶线山谷方向

本轮修正四种 `polygon-tile` 公有变体及自定义逐块扭转的 plain 数值配方。此前共享函数先把外围两组褶线设为 `U`，再让局部赋型算法自由选择；这能让几何不变但方向与显式 `ccw` 相反的输入被静默接受。现在调用方请求严格保留原赋型：不相容输入报错，不以改变来源山谷类型代替校验。

## 来源与调用合同

| 原版位置 | 原规则 | 本轮调用处理 |
| --- | --- | --- |
| `tmp/Origamica-15.0-reference.nb` In[2872]，212236–212460，`atypes`／边列表 | 每个中央边类型 `t` 对应六条边 `B,B,B,(ccw?t:Invert[t]),(ccw?Invert[t]:t),t`；前三条为纸边，随后两条为褶线，最后一条为中央边。 | `construct_polygon_tile` 四变体均显式传 `preserve_source=True`；`general` 必须尊重公有参数 `ccw`。共享函数内部实现归原修复任务维护，本轮未改。 |
| In[2896]，214248–214265 | 居中型委托一般型，`d=0`，`ccw=(τ<π/2)`。 | plain 配方无显式 `ccw` 字段，普通 tilt 按严格 `tilt<90` 推定方向；零偏置、90°保留 `false`。 |
| In[2905] | Alt 型先以 `CenteredTwistTiltAngle` 转换 α，再委托居中型。 | `angleMode='twist'` 沿用原转换，方向以 `twistAngle<90` 推定。 |
| In[2919]，215823–215842 | 偏置型委托一般型，`τ=π/2`，`ccw=(d>0)`。 | plain 数值配方在 `tilt=90` 且偏置非零时使用该偏置方向；其它倾角仍按居中方向。 |

修复调用点为 `backend/tessellation_tile_twist.py` 的 `construct_polygon_tile` 与 `backend/tessellation_tile_patch.py` 的 plain 分支；split 分支未被本轮改动。plain 配方保持既有 JSON 字段合同，没有新增或伪造 `ccw` 字段。
