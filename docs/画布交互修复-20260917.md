# 画布交互修复：中键平移、双模式画线、交点

用户本轮指定的三项问题已实现并重新构建实际工作台。仅改动二维画布与相关提示，不关闭旧 Java，不修改已有工程。

## 行为

1. 任意二维绘图工具下，按住鼠标中键（滚轮）即可平移，松开停止；阻止浏览器原生中键自动滚屏。使用指针捕获处理拖出画布后的释放。滚动滚轮仍为缩放，空格和手形工具仍可用。
2. 画线在 pointerup 判断意图：首次原地单击只保留起点；第二次点击确定终点；按下后拖动则在释放位置确定终点。4 px 内轻微手抖按单击处理。拖动期间显示预览，不提前提交或重复提交。起终点均进入端点／交点优先、网格后备的吸附逻辑。
3. 根据实际有限线段实时计算派生端点／交点，支持非网格交点、T 接点、共享节点、辅助线、负坐标。交点小圆点可点选，选择后高亮点和关联线。无需先整理交点，不为显示或吸附擅自拆分原始线段；计算/交换时仍使用原来的切分流程。共线重叠只保留真实端点，不制造无穷个交点。

交点集合按几何变化缓存，不在每次鼠标移动时重算。选择工具的悬停与点击使用同一 8 px 半径，避免提示可选却点不中。绘图吸附半径为 11 px，随缩放换算到文档坐标。
