# 步骤动画：参与范围与纸张颜色修复

用户反馈：局部折叠时，其余纸层被带动；纸张颜色与主图不一致，纸面内部出现三角片明暗分界。

同日续篇：[复杂步骤动画与三维导航](复杂步骤动画与三维导航-20261015.md)。后续增加半角正切联动、有界先后折叠搜索、连续碰撞及初态层序检查、方向方块与精度相关的显示微间距；本文保留前一阶段的修复范围和验证记录。

## 原因与处理

| 问题 | 原因 | 处理 |
|---|---|---|
| 不参与的纸面被牵动 | 原先只固定单个子面；恒角度旧折痕仍依靠有限刚度的弹簧保持 | 沿材料邻接关系切断本步活动折痕，合并恒角度区域；固定侧所连区域整体保持起态 |
| 旧折面扭曲 | 新折痕驱动时，旧铰链和纸面的数值弹性允许临时展开、拉伸 | 步骤动画使用刚性区域绕真实材料铰链转动，保持旧折角和区域内距离；普通三维模拟仍走原有求解流程 |
| 纸张配色不一致 | 动画未发送本步配色，使用了模拟器默认颜色 | 传递当前步骤的正面、背面、轮廓颜色，保留正确的相机反射与正反面映射 |
| 三角片明暗分界 | 同一纸面扭曲后，三角片法线不一致 | 通过刚性运动保持面内共面；保留三维方向光照，不通过关闭光照隐藏变形 |
| 重合纸层正反色拼成三角块 | CPU投影提前截成Float32，不同三角细分插值得到不同的共面深度 | CPU局部投影及逆深度计算保留Float64；不放大深度容差，不改GPU或真实微层间距 |

## 动作约束

各区域的姿态由初始材料坐标和真实铰链旋转计算，不把两个端点的顶点坐标线性插值。预折仍执行折下、展开两个阶段；拖动进度和重播均从同一起态求值。

对共享材料顶点、固定点和闭环铰链检查一致性。不兼容的联动动作显示中文原因，不通过拉伸纸张或带动固定区域强行完成。此修复不等于通用碰撞求解：运动纸瓣仍可能与其他纸瓣发生真实路径碰撞。
