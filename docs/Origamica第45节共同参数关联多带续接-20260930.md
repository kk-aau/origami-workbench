# 第 45 节：共同参数关联多带的连续曲折实现

本轮完成一个可调的关联多带输入族：3–6 条递增同心曲线、2–5 条连续直纹带、1–3 项正弦重参数扰动、正负初始折角及有限区间。默认保留原保存输入的 **0.1 非零扰动、五条曲线和四条带**，纠正原算法与调用中的共同参数错误，生成同一二维纸面及其连续等距三维构形。没有用零扰动代替默认输入，没有删除后续带，也没有将光滑曲线采样图包装成精确直线 FOLD。

原调用复放入口保持不变，仍明确显示“第二带不等距”。新入口是纠正参数合同后的实现，**不是 Mathematica 保存的数值 Out，不是忠实重放错误公式所得图像**。总体复现目标仍有任意原生曲线、任意初始函数和全局运动等余项。

## 共同参数续接推导

令 `e(x)=(cos x,sin x)`，平面单位切向 `t_i=(-sin q_i,cos q_i)`，左横向 `l_i=-e(q_i)`，`g_i=q_i′(s)>0`。相邻半径 `r_i<r_j`，`δ=q_j-q_i`，母线向量

```text
h=f_j-f_i=a t_i+b l_i
a=r_j sinδ
b=r_i-r_j cosδ
```

三维标架使用源代码相同的 Darboux 约定：

```text
T′=g L+n N
L′=−g T+τ N
N′=−n T−τ L
```

首带 `g₀=1`，`n₀=g₀ tan(γ₀/2)`。母线可展条件 `a n+b τ=0` 给出 `τ₀=−n₀ a/b`。首曲线满足 `F₀′=r₀ T₀`，三维初值与原保存例一致；有限区间从其起点建立同样的平面初始标架。

下一曲线与左侧标架：

```text
F_j=F_i+a T_i+b L_i
T_j=cosδ T_i+sinδ L_i
L_j,left=−sinδ T_i+cosδ L_i
n_j,left=n_i (r_i cosδ−r_j)/(r_i−r_j cosδ)
```

旋转约定 `L_j,right=cosγ_j L_j,left−sinγ_j N_j,left`。要保持平面测地系数，必须有

```text
g_j cosγ_j−n_j,left sinγ_j=g_j
γ_j=−2 atan(n_j,left/g_j)
    =−2 atan[(g_i/g_j) ((r_j−r_i cosδ)/(r_j cosδ−r_i)) tan(γ_i/2)]
```

这正是原 `ArcTan` 第一分量应改为 `g_j/g_i` 的原因。此处的导数全部相对于共同参数 `s`，没有额外复合一次 `q_j`。

`τ_j,right=τ_j,left−γ_j′`。将下一母线可展条件代入，得到下一原生圆交点的投影比目标

```text
previousRatio=−r_i sinδ/(r_j−r_i cosδ)
k=γ_j′/[g_j tan(γ_j/2)]−previousRatio
r_k sinθ/(r_j−r_k cosθ)=k
```

中央无极点分支可显式求出，不需要逐点 `FindRoot` 后插值：

```text
t=k(r_j−r_k)/(r_k+sqrt(r_k²+(r_k²−r_j²)k²))
q_k=q_j+2 atan(t)
```

有理化半角式在 `k=0` 仍正则。程序用 Taylor 系数 `x^(m)/m!` 的截断算术依次求值，sin/cos、atan、除法、sqrt 和导数均按链式规则处理；不对四次样条再次求高阶导数。偏移 `q_i-s` 独立保存，减少区间算术把相同 `s` 当成无关量而造成的包围膨胀。

每带连续二维及三维参数面分别是

```text
X_i(s,v)=(1-v) f_i(s)+v f_(i+1)(s)
Y_i(s,v)=(1-v) F_i(s)+v F_(i+1)(s)，0≤v≤1
```

公共边使用同一个 `f_i/F_i` 对象，全部带构成一张纸。Darboux 系统、旋转测地匹配及 `a n+b τ=0` 联合保证连续精确方程的 `E,F,G` 相同；渲染的是其高精度数值积分，后端另外计算位置导数、整串标架与度量误差。连续方程身份与积分误差的数值验证是两个不同层次，不能把采样通过当作形式化数值误差证明。

## 全区间正则性与二维纸面的单射条件

`tessellation_curved_linked_common_interval.py` 对整个用户区间自适应二分，最多 4096 次 Taylor 区间求值；叶区间必须同时得到所有 `q_i′>0.01` 及所有 `r_(i+1) cos(q_(i+1)−q_i)−r_i>10⁻⁶` 的严格下界。不能包围分母／根式／正则量时继续细分，预算或最小宽度耗尽即拒绝，而非改参数或丢带。只有完整覆盖后才返回全区间通过。

中央半角根对每一后续带严格满足 `|θ|<acos(r_i/r_j)<π/2`，首带输入门禁同样保证短角；不能仅凭周期性的 `cosδ>0` 就排除跨周分支。对内带母线，`h·f_i=r_i[r_(i+1)cosδ−r_i]>0`，故沿母线的半径严格增大。二维雅可比是两个端点切向投影的凸组合，两个端点在该横向条件与 `q_i′>0` 下同号且不为零；因此固定半径处，纸面极角沿 `s` 严格单调。全部曲线参数的起止端点用区间重新包围，全部极角跨度要求 `<2π−0.05`；母线短角分支处于端点角之间，无整周重绕。每带单射，不同带位于不同径向环带，只在公共折线相接。这给出了**连续二维纸面**的整体无重叠依据，未验证三维自交。

| 验证层次 | 已做到 | 限制 |
|---|---|---|
| 连续参数合同 | 全部 `q_i`、`γ_i` 的解析链式规则和共同参数续接 | 当前原生曲线限于递增同心圆函数族 |
| 全区间参数包围 | 全区间区间 Taylor 细分，覆盖所有带，返回正下界和角域上界 | 工程浮点包围，下面的舍入假设是证书的一部分 |
| 连续二维纸面 | 径向严格单调、非零雅可比、极角不绕周，带间共享边界 | 不等同三维边界无重合／无穿透 |
| 数值三维积分 | DOP853，`rtol=2e-12/atol=2e-14`；独立 257 节点验证，不随显示段数降低 | 未提供积分误差的严格全区间区间包围 |
| 前端严格回读 | 客户端 Taylor 另算全部 `q/q′/γ`；独立重算所有输出节点各带 EFG；从真实母线／导数算两侧法向与有符号二面角，并核初始点／切向，来源与域证书逐字段一致 | 不是独立三维 ODE 求解器 |
| 采用与运动 | 没有采用按钮，所有直线FOLD／碰撞／连续运动字段保持 false | 任意曲线、全局三维无碰撞和精确多带直折痕伴随网格未实现 |

区间运算使用 binary64 基本运算及每次两次 `nextafter` 外向舍入；sin/cos/atan/sqrt 的端点包围采用 **libm 端点误差不超过 2 ULP** 的工程假设。cos 直接包围端点及极值，不能通过 `sin(x+浮点π/2)` 实现，否则在 `x≈−π/2` 相消时会丢掉常数本身的舍入误差；65 位独立点值回归覆盖此问题。`roundingModel` 必须严格回读为 `binary64-outward-2ulp/libm-endpoints-2ulp-assumed`，不能伪改成形式化实数证明。这里的 “Certified” 字段表示按该声明模型通过工程区间门禁，**不宣称经过形式化证明系统或正确舍入超越函数库的无条件证明**。数值标架／度量则只报告独立节点的误差。

默认 `[0,π]`、四带、`a₁=0.1` 得到 383 次求值、192 个覆盖叶区间，`q′` 下界约 `0.04705579`，横向下界约 `0.08181450`，极角跨度上界约 `3.141592653589799`。采样最小参数速度约 `0.76746117`，区间下界保守且较小，不能把它当作实际最小值。

## 当前余项与采用边界

| 仍未实现 | 本轮不能代替它的原因 |
|---|---|
| 任意二维原生曲线及任意 `q₀/q₁/γ₀` 的通用关联多带 | 本轮泛化的是真实参数函数族，显式圆交点中央分支不能冒充任意曲线的根分支追踪 |
| 多带精确直线 FOLD 与共同平面离散网格 | 把弧线连接成弦会改变长度／高斯曲率；不能照首带三角条带策略拼四带后声称整体无拉伸 |
| 三维整体无碰撞／端边单射 | 二维纸面单射和局部连续等距允许三维自交，需要另外的全局验证 |
| 全区间严格数值积分误差包围 | 当前全区间包围的是参数合同和纸面正则性，Darboux 积分使用高精度数值与独立节点诊断 |
| 连续可折路径与采用 | 单个连续等距构形未给出原纸张到它的无碰撞运动路径，因此始终不能冒充运动／层序认证 |
