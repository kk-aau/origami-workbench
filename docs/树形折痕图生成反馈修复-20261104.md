# 树形折痕图生成反馈修复

用户反馈：树形基础形点击“生成折痕图”后没有明显提示。

复现发现：默认树形示例未优化时，引擎能结束构造请求，但只返回不完整构造（`polys_multiple_ibps`），没有完整 FOLD。原界面仅在侧栏显示构造状态。优化后可以生成完整 CP，但原界面仍保持骨架 / 布局视图，没有自动展示生成结果。

| 改动 | 行为 |
| --- | --- |
| 生成期间 | 顶部显示“正在生成折痕图”，保留停止计算 |
| 未完成构造 | 顶部显示原因与后续操作；空骨架提示先建立分支 |
| 成功生成 | 通过编辑区校验后自动切到折痕图并适合纸张，显示线段数量 |
| 结果完整性 | 不完整构造继续禁止导出，不自动优化或改写用户设置 |

验证：`npm run build` 通过；基础形与交互相关 14 项测试通过。浏览器使用本机 Rust 设计工作进程，实际执行空骨架生成、未优化示例生成、优化、再次生成及送入折痕编辑，获得 16 条线的完整 CP。在 1280×900 和 1000×760 窗口确认提示及折痕图可见，控制台无错误。

证据位于 `.runtime/tree-build-feedback-qa/`，交互脚本为 `.runtime/tree-build-feedback-flow.js`。本次仅修改开发源码，没有打包或上传。
