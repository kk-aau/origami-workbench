# 镶嵌连续渲染修复

2026-09-20，源码 v0.12.0。网页构建及独立计算组件已更新；release 的 v0.9.2 安装包未重新制作。

## 卡顿原因与处理

- 每次请求新建 Python 进程、重复加载数值库。改为有界逐行 JSON 协议和常驻计算进程；同一时间仅一个请求。错误参数可继续使用进程，取消、超时或协议错误终止进程，下一次请求重新启动。
- 220ms 防抖及丢弃所有过期结果，使连续拖动始终没有新画面。改为动画帧调度，计算完成后继续处理最新参数；拖动期间可以显示完成的中间结果，同类构造保持视图与缩放。
- 周期、原始—对偶、混合平铺、非周期、自定义、环状等 Shrink-Rotate 构造提供顶点变换系数。在母结构不变且旋转不跨正负号时，浏览器按当前角度和比例直接计算精确几何，不等待后台。结构改变、反向扭转和其他算法仍走常驻引擎。没有使用图片插值冒充构造结果。
- 只读画布跳过编辑器吸附交点及圆交点计算，不随每个预览结果重置编辑手势。
- 四边形分裂求解提供 Kawasaki、边长、面面积和内部约束的解析导数，减少每次迭代的有限差分求值；独立几何与局部检查仍完整执行。

预览与检查分离：只有与当前参数完全对应、计算结束且检查通过的候选才能采用。前端实时坐标不写入已检查结果，也不覆盖原工程。首次启动计算库、改变离散结构和复杂约束优化仍需要计算时间。

## 验证

- 930 项 TypeScript 测试、3 项桌面模块测试、26 项 Python 测试、17 项接口／常驻进程测试，共 976 项通过。新增测试覆盖进程复用、非法输入后恢复、取消后重启、并发拒绝、损坏输出隔离和解析导数的数值差分核对。
- 22 组正反方向及不同母结构的逐帧系数，与重新运行完整构造的边几何比较，按 7 位小数一致；前端测试确认归一化、原结果不被改写和未检查结果不可采用。
- 源码 Electron 桌面冒烟 73 项通过，使用实际打包的常驻计算组件；记录见 `output/tessellation-smooth-desktop-verified/smoke-result.json`。首次沙箱启动因图形子进程环境失败，正常桌面环境复验通过。
- `verify-tessellation-live.browser.js`：39 项；`verify-tessellation-live-safety.browser.js`：9 项；`verify-tessellation-smooth.browser.js`：11 项。覆盖数字框、滑条、九类构造无滚动、取消／失败恢复、最新参数收敛，以及人为阻塞后台时前端仍更新。
