# 第 45 节：通用原生曲线的共同参数关联续接

本轮把已有同心圆共同参数入口扩展为真正的二维原生函数输入：用户填写每条曲线的 `x(u)/y(u)`、显式原生域，以及共同参数下的 `q₀(s)/q₁(s)/γ₀(s)` 和后续起点根种子。新核接受 3–6 条曲线，实际求得全部 2–5 条连续直纹带及三维等距构形，所有带共享同一个 `s` 和同索引公共曲线。非圆曲线、非线性 `q₀/q₁`、非恒定 `γ₀` 的六曲线五带输入已真实验收；没有把圆预设列表当作一般曲线，没有置零扰动、删除带或导出采样弦的精确 FOLD。

这里的“通用”指已实现白名单标量原生表达式与隐函数续接核，**不表示任意 Mathematica 程序、任意奇异参数映射或全部第 45 节函数已完整复现**。一般边界交点验证、拒绝所有整体自交、`NFlatten/NFold` 的全部任意函数职责、精确直线多带 FOLD 与无碰撞连续运动仍有未闭合范围。

## 一次复合与一般续接推导

令原生曲线为 `cᵢ(u)`，`pᵢ(s)=cᵢ(qᵢ(s))`，原生单位切向 `tᵢ=cᵢ,u/|cᵢ,u|`、左法向 `lᵢ=(-tᵢ,y,tᵢ,x)`。所有量只在 `qᵢ(s)` 求值一次。源表达式先求安全 AST 的一阶、二阶原生导数，再由 Taylor 自动导数复合；共同参数系数为

```text
pᵢ′ = cᵢ,u(qᵢ) qᵢ′
speedᵢ = |cᵢ,u(qᵢ)| qᵢ′
gᵢ = det(cᵢ,u(qᵢ), cᵢ,uu(qᵢ)) / |cᵢ,u(qᵢ)|² × qᵢ′
    = det(pᵢ′,pᵢ″) / |pᵢ′|²
```

这里 `gᵢ` 是相对于共同 `s` 的切向转角速度，不是未复合的原生曲率。先按原生导数构造切向，避免区间算术中把相同 `q′` 在分子分母反复相消而膨胀。

记 `h=pⱼ−pᵢ`，`a=h·tᵢ`、`b=h·lᵢ`。首带 Darboux 系统是

```text
Fᵢ′=speedᵢ Tᵢ
Tᵢ′=gᵢ Lᵢ+nᵢ Nᵢ
Lᵢ′=−gᵢ Tᵢ+τᵢ Nᵢ
Nᵢ′=−nᵢ Tᵢ−τᵢ Lᵢ
nᵢ=gᵢ tan(γᵢ/2)，τᵢ=−nᵢ a/b
Fⱼ=Fᵢ+a Tᵢ+b Lᵢ
```

下一折角由保持平面测地系数的非平凡旋转得到：

```text
γⱼ=−2 atan[(gᵢ/gⱼ) (h·lⱼ)/(h·lᵢ) tan(γᵢ/2)]
K=γⱼ′/[gⱼ tan(γⱼ/2)]−(h·tⱼ)/(h·lⱼ)
R(s,u)=(cₖ(u)−pⱼ)·tⱼ−K(cₖ(u)−pⱼ)·lⱼ=0
```

一般下一曲线不是圆半角闭式；它真实求解 `R(s,u)=0`。求得简单根 `qₖ(s₀)` 后，按阶将 Taylor 未知系数设零，计算残差该阶系数，并除以原生 `R_u` 求唯一的隐函数系数。没有对插值节点再求高阶导数。初始阶数 `2×带数+2` 足以保留最终曲线、框架、参数、折角及位置的一阶核验所需导数；每步衍生阶数明确递减。

全部带参数面是 `Xᵢ(s,v)=(1−v)pᵢ+v pᵢ₊₁` 和 `Yᵢ(s,v)=(1−v)Fᵢ+v Fᵢ₊₁`。共享同索引边与同一个 `s`，Darboux、可展母线及折角旋转身份给出连续 `E/F/G` 等距。独立节点数值误差和这些连续方程身份分别报告。

## 小尺度、大平移与回读精度

原生坐标 AST 将加性常数与动态部分分开，常数差用补偿求和。以内侧首曲线起点为原点、首母线长度为相似尺度，再计算一般几何和根支；源查询字符串完全保留。输出同时携带 world 与 normalized 的平面／空间坐标和位置导数，实际绘图及独立 EFG 使用 normalized 字段。

| 项目 | 实际处理 |
|---|---|
| 1e-6、1e-8 图样同时平移 1e9 | 原生源依然 `1e9+scale*u` 与 `1e9+scale*(0.3u²+offset)`，归一化构形、参数、折角及导数与基准吻合 |
| 世界坐标 | `world=origin+scale×normalized`；导数只乘 scale；TS 以本地相似尺度和 4 ULP 核变换 |
| 原点跨语言 | Python libm 与 JS Math 尾位可不同，原点用本地尺度／ULP 容差；内部归一化几何仍由原生源独立算验 |
| 无法保留的世界细节 | 1e9 附近 binary64 间距约 1.19e-7；世界点自身不能编码 1e-8 的形状。归一化值保留真实细节，不能凭已舍入 world 点独自导出此精度 |
| 诊断量纲 | `maxMetricError` 等是归一化几何误差；世界 EFG 差需乘相似尺度平方，平移不改变度量 |
