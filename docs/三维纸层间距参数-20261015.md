2026-10-15。[纸层颜色与双倍间距修复](步骤动画纸层颜色与双倍间距-20261015.md)的后续：将原有自动显示间距开放为用户可调参数，便于寻找适合模型的间距。

同日后续修复见[三维整面纸层间距修复](三维整面纸层间距修复-20261015.md)：生产显示已废止按局部重叠区域裁切纸面的方案，改为保持原三角拓扑、对完整纸面求法向微移与微倾斜。下文保留参数首次接入时的实现与验证记录，其中局部重叠布局和薄显示碎片修正的描述已由该续篇替代。

## 使用方式

| 位置或操作 | 行为 |
|---|---|
| 普通三维模拟控制条底部、步骤动画播放区底部 | 直接显示“纸层间距”数值，无需打开其他设置 |
| 输入倍率 | 支持 **0–1000** 及小数；**1** 对应本次修改前的当前默认间距，**0** 关闭显示分离 |
| 输入有效数值 | 立即更新显示；不推进模拟、不重新规划步骤动画 |
| 空白或未完成输入 | 保留编辑状态，不发送无效参数；失去焦点或按 Enter 时恢复最近有效值 |
| 超出范围 | 编辑时不应用；失去焦点或按 Enter 时校正到 0–1000 范围 |
| 快捷操作 | 提供关闭、1×、10×、100×及“恢复默认” |
| 保存和同步 | 普通模拟与步骤动画共用偏好；重开视图、刷新页面后保留。保存失败时保留本次显示调整并提示未保存 |
| 生效条件 | 目标到达 100%，纸面近平且稳定、层序可信时应用；立体折叠过程中不强行分离或压平 |

## 显示与数据边界

| 部分 | 约束 |
|---|---|
| 基础间距与倍率 | 在按视角和显示精度求得的默认微间距上乘用户倍率；大倍率真实扩大可调显示范围，不再受旧固定间距上限截断 |
| 纸层关系 | 保留可信层序与纸层跨度；倍率只缩放间距，不改变上下关系 |
| 布局缓存 | 复用稳定材料姿态的重叠区域排列；修改倍率不重复求整套重叠布局 |
| 极薄显示碎片 | Float32 显示坐标的修正受源纸面面积预算约束；无法安全生成目标间距时明确提示，保留最近合法显示，不悄悄播放损坏网格 |
| 材料数据 | 只修改显示网格，不改求解器顶点、CP、材料折角、工程数据及实际材料网格导出 |

共享偏好键为 `zhezhi.simulation-layer-gap.v1`，记录格式为 `{version:1,multiplier}`，通过现有偏好存储服务保存。
