# 核心构造核验与修复

范围：兔耳、鱼骨、三点／两线反射、连续／横截反射、三点／两线角平分、局部补线、网格补线及自由补线；同时检查共用提交路径的中垂线、平行线、垂线。

## 已修复

1. **构造提交缺少重合处理。** 三点角平分、三点／两线反射、中垂线以及共用提交路径直接追加线段；编辑器的交点拆分不会消除重合冲突。修复前在已有谷折上构造山折角平分线，浏览器中线段由 5 条变成 6 条，谷折与山折同时保留。现在统一使用 `uncoveredCopies`：完整同型结果提示已存在，部分同型只补缺失区间，线型或折角冲突整次拒绝；错误保留当前输入，方便调整或取消。共用该入口的切线按钮也捕获错误，避免未处理异常。
2. **鱼骨取点误判。** 原先把固定 `1e-4` 同时用于距离与方向判定，靠近但不相交的线会误跳过取点，浅角实际相交又会漏跳过。距离改用工程几何容差，平行判定采用与射线截止一致的角度阈值；被跳过的取点仍推进山谷交替序号。
3. **平行中线自动截止依赖端点存储顺序。** 原锚点取自第二条线的起点，翻转端点或交换两参考线会选到不同的截止区间。改用两条参考线中点的平均位置作为对称锚点；自动选其两侧最近实际截止线，端点翻转和参考顺序不再改变结果。手动指定两个截止线的行为保持原样。

## 核验结果

- 新增 3 项回归测试：修复前全部失败，修复后全部通过。
- 146 项相关现有及新增测试通过，涵盖内心、方向与有限截止、反向输入、山谷及自定义折角、重复与冲突、原工程不变及容量拒绝。
- 51 项实际浏览器检查通过：6 个工具的重合冲突保护；同型去重与部分补线；兔耳错误第三点重选；预览与提交一致；鱼骨和连续反射山谷交替；横截反射保留折角；局部及自由补线继承单邻线属性；Esc、右键和切换工具取消；整组撤销与重做。
- TypeScript 检查及生产构建通过。使用独立服务端数据目录 `output/construction-audit-browser-data`，未操作用户工程。

此轮未证明所有输入或全模型可折；局部补线与山谷数量条件仍按原有能力边界解释。
