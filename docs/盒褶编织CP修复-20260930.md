# 盒褶编织 CP 修复（2026-09-30）

本次针对用户确认的「盒褶编织」（`family= woven`），不是「线组编织」（`woven-lines`）。旧生成器存在构造错误，不能用局部必要条件通过代替整体平折验证。

| 旧行为 | 查实的问题 |
| --- | --- |
| 直接把正交双线网格当作 CP，再按行列给山谷 | 默认 3×3、宽比 0.25 的三种模式均通过几何、Kawasaki、Maekawa，但实际整片层序为 `no-solution` |
| 「三列错位」只对列号取模后取奇偶 | 默认 3 列与「交替」逐顶点、逐边、逐面、逐山谷完全相同 |
| 不设置独立纸张时，只验局部条件即可采用 | 无解 CP 仍能进入折痕工程 |
| 回读盒褶参数时忽略未知字段 | 错标 family 的线组参数可被静默替换为默认盒褶网格 |

修复后的路线从正交条带母图构造真实编织结构，再以逐面反射逆向展开得到 CP，沿用现有线组编织的四度交点拓扑、反射闭合方程和展开几何验证。保存的折后坐标仅用于独立数值核对；画布继续从 CP 重新计算平折几何和山谷层序。固定折痕面使用来源中的零基 `stationaryFoldFace`，避免两种坐标来源采用不同根面。

「条带布局」保留旧参数键 `weave` 和三个旧枚举，含义明确为等距交替、双列成组和三列错位。后两种改变母条带的位置；交点仍逐次交替穿插。它们不声称支持纺织意义的任意篮纹或二上一下斜纹。

所有盒褶编织必须完成整体层序检查才可采用。工作区自动触发、候选检查显示和采用门禁共同调用 `needsTessellationLayerCheck`；过期、计算中、无解和未确认结果均不可采用。正常旧工程参数保留；混入线组专属字段的错误来源拒绝回读。

独立纸张外延仍是单独的未完成范围。旧盒褶纸边扩图建立在错误网格上，不能继续把它当作真实编织的保真规则。新版后端明确拒绝未验证的外延，不返回貌似正确的候选。随后按用户要求加入显式内切：正方形、矩形和正多边形均可裁剪真实 CP；界面新增「方式 → 内切」，外延失败可点击「改用内切纸张」。裁剪后重新核对点／面来源、固定面、反射坐标及整体层序，详见 [内切纸张-20260930.md](内切纸张-20260930.md)。旧工程缺省方式仍为外延，没有静默改成内切。
