## 连续几何证明与拒绝条件

设 `v=|F′|`，`T,N,B` 是 Frenet 标架，`κ>0`、`τ` 是曲率和挠率，`c=cos(γ/2)`、`s=sin(γ/2)`、`K=vκ`、`Ω=vτ`、`q=sK`，`a=γ′/2+Ω`、`b=γ′/2−Ω`。原版 In[3939] 的 `Sign` 写法在 `σ∈{−1,+1}`、`0<γ<π`、`κ>0` 的域内化简为：

```text
Lₗ = σ(cN+sB),            Lᵣ = σ(cN−sB)
mₗ = √(q²+a²),            mᵣ = √(q²+b²)
Rₗ = (σa/mₗ)T+(q/mₗ)Lₗ
Rᵣ = (−σb/mᵣ)T−(q/mᵣ)Lᵣ
```

两侧曲面法向 `Uₗ=σ(−sN+cB)`、`Uᵣ=σ(sN+cB)` 满足 `Uₗ′=σqT−aLₗ`、`Uᵣ′=−σqT+bLᵣ`。因此两侧的 `R·U′` 都恒为 0，`det(F′,R,R′)=0`，即各自为可展直纹面。两侧的切向法曲率投影相同：`Lₗ·T′=Lᵣ·T′=σcK`；这就是展开曲线的转角速率 `φ′`。平面母线保留各自的切向／法向系数 `α,β`，写为 `r=α(cosφ,sinφ)+β(−sinφ,cosφ)`。由母线单位长、可展条件和共同 `φ′`，连续曲面的第一基本形式 `E,F,G` 与平面展开一致。此处的等距是解析参数曲面的性质；离散三角片的对应弦长只随网格加密趋近，并非逐边精确相等。

构造入口要求输入为显式 SymPy 坐标表达式、有限闭参数区间、连续到四阶的空间曲线、全区间 `v>0`、`κ>0`，以及连续到二阶且全区间 `0<γ(u)<π` 的折角。SymPy 必须给出这些量的全域范围；未决符号、零速、零曲率、角度退化、不可证明的范围均拒绝。取有限宽度 `w` 时另证明两侧均满足 `min(v|β|)>w·max|βα′−αβ′−φ′|`，这是避免母线焦线的保守充分条件。优先使用符号全域极值，复杂但受支持的表达式使用定向舍入区间包络；包络不够紧或表达式不受支持即拒绝该宽度，不用少量采样点冒充全区间证明。这些条件只保证参数曲面局部正则与等距，仍不保证全局无自交、厚纸可部署或连续折叠路径。

## 独立 API 与测试

模块 `backend/tessellation_curved_space_curve.py` 独立于共享分发路由：

```python
u = sympy.symbols('u', real=True)
fold = fold_space_curve_3d(
    (sympy.cos(u), sympy.sin(u), u / 2), sympy.pi / 2,
    parameter=u, interval=(0, sympy.pi), orientation=1)
fold.frame(0.5)                          # 解析生成律在 u=0.5 的数值求值
flat = flatten_fold_2d(fold, initial_point=(1, 0), initial_tangent=(0, 1))
flat.exact_flat_expressions()            # 未求值的精确积分表达式
flat.frame(0.5)                          # ODE 求得的平面值及两侧对应母线
mesh = nflatten_fold_2d(flat, ruling_width=1, curve_segments=96,
                        ruling_segments=4)
space_mesh = nspace_curve_fold_3d(fold, ruling_width=1)
```

`mesh` 保留平面／空间同索引顶点、共用折痕、两侧面片和源参数区间；其 `sampledMeshExactIsometry=False`、`deploymentPathChecked=False`、`selfCollisionChecked=False` 明示结论边界。当前 `flatten_fold_2d` 只接受本模块已认证的 `fold_space_curve_3d` 结果；原版对任意外部三维母线输入的 `FlattenFold2D` 范围尚未实现。数值插值入口也未承诺复制 Mathematica `NDSolve`／`FunctionInterpolation` 的插值阶数或误差策略。

## 封闭 JSON 只读查询契约

独立模块 `backend/tessellation_curved_space_curve_query.py` 提供 `validate_curved_space_curve_query(data)` 和 `query_curved_space_curve(data)`。后者只读取输入，调用上面的已认证构造，再返回 JSON 可序列化的配对采样。输入中的字符串仅允许以下三个固定 `family` 值；任何额外字段和表达式字符串都拒绝，绝不将 JSON 文本交给 Python `eval` 或 SymPy `sympify`。

| `family` | 专用参数及默认值 | 折角范围 |
| --- | --- | --- |
| `planar-circle` | `radius=1` | 常角或端点线性变角；默认 `120°`。原版 In[3933]/In[3936]。 |
| `circular-helix` | `radius=1`、`pitchPerRadian=0.5` | 仅常角；默认 `90°`。原版 In[3940]/In[3943]。 |
| `planar-ellipse` | `axisX=2`、`axisY=1`，两轴须不等 | 仅常角；默认 `120°`。这是额外非圆验证子域，不伪称原版保存示例。 |

共有字段：`parameterStartPi=0`、`parameterEndPi=1` 是以 π 为单位的参数端点，各在 `[−2,2]` 且跨度大于 `10⁻⁶`、不超过 2；`foldAngleStartDeg` 与可选 `foldAngleEndDeg` 在 `(0,180)`，相等表示常角，不等只允许平面圆上的线性变角；`orientation=1`，仅接受 `±1`；`rulingWidth` 的默认值随族为 1、1、0.5，必须在 `(0,4]` 且仍须通过焦线前宽度证明；`curveSegments=96` 在 `[8,512]`，`rulingSegments=4` 在 `[1,16]`，总顶点不超过 16000。圆半径和椭圆轴在 `[0.25,4]`，螺旋每弧度轴向进给在 `[−4,4]`。所有数值须为有限 JSON 数字，布尔值不算数字。验证函数只校验这个封闭结构；**完整几何认证在查询函数内完成**。

```json
{"family":"planar-circle"}
{"family":"circular-helix"}
{"family":"planar-ellipse"}
{"family":"planar-circle","parameterEndPi":0.5,
 "foldAngleStartDeg":90,"foldAngleEndDeg":96,"rulingWidth":0.1}
```

成功结果包含规范化的 `query`、`sourceFunctions`、`certification` 与 `sample`。`sample.frames` 在每个共同参数点给 `flatCrease`、`foldedCrease`、两侧二维／三维母线和折角；`sample.flatVertices` 与 `foldedVertices` 同索引，共用 `creaseVertexIndices`，还含两侧边界索引与面片。`certification` 明确报告全区间正则曲率、角度、两侧解析可展、配对连续等距和宽度认证；`sampledMeshExactIsometry`、`exactStraightCreaseFOLD`、`deploymentPathChecked`、`selfCollisionChecked` 均为 `false`。对应直线弦段是画布预览，不是精确直折痕工程或部署路径。查询错误以 `ValueError` 拒绝，没有半认证的成功响应。
