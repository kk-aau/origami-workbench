# 折序自动选层后遗漏遮挡折线

2026-10-18，源码修复。本轮未生成桌面发行包，用户提供的工程和工作日志原件保持不变。

## 问题与正确行为

用户在第 18 步删除折痕后重画，发现 CP 少了一部分；在主图移动线段再移回来，缺少的部分出现。用户确认采用自动选择，并明确：自动选中的纸层是对的，同一选中纸层被遮挡的折线也必须进入 CP。

| 情况 | 正确行为 |
|---|---|
| 自动选择 | 根据折线经过处露出的最上层确定参与纸面 |
| 同一选中纸面在别处被遮挡 | 仍映射这条有限折线在该纸面上的完整部分 |
| 完全隐藏且未被选中的其他纸面 | 不参与；需要时显式使用全部纸层或指定纸面 |
| 改线宽、颜色，新增其他线或移动往返 | 不改变这条线已绑定的参与纸面 |

这不是画布没有提交或刷新缓存的问题。旧逻辑首次绘制按每段的可见性筛选，却只保存纸面编号；后续编辑改按保存的纸面编号映射整面。两条路径的覆盖范围不同，连只改线宽也会让缺线出现。

## 实现

`mapDiagramFoldLines` 先从可见分段取得参与纸面的集合，再映射这些纸面的全部已裁剪分段。仍使用原有限端点、凹域与孔裁剪，不延成无限直线，也不把完全隐藏的其他纸面加入集合。预览保留真实的 visible/hidden 状态。

成功的绘图联动事务保存 `drawingVersion: 1`。重新打开、翻面、旋转观察和纯层序分析时，保留已完整绑定的长线编号、样式、纸面绑定与动画引用，只更新继承的展开折痕。旧工程继续使用原迁移路径；真实 CP 编辑和几何变化仍以 CP 为准重建手柄。
