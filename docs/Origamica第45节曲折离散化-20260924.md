# Origamica 第 45 节：曲折离散化数值核心

只读来源：`workbench/tmp/Origamica-15.0-reference.nb`，340417–341274 行，In[4087]–In[4093]。实现位于 `backend/tessellation_curved_discretization.py`；这是独立 Python 数值工具，尚无工作台接口。原版三个示例只保存了输入和 `ShowExample` 调用，没有可提取的数值 `Out`；本文的测试是按原式重建的几何与残差验收，不声称与运行中的 Wolfram 数值输出逐项对照。

| Python 函数 | 参数契约 | 返回 |
| --- | --- | --- |
| `discretize_system(system, parameters)` | 有序 `(key, callable)` 列表和参数列表；允许重复 key | 同序 `(key, [f(t), …])` 列表；保留函数输出类型 |
| `discretize_curve_uniformly(curve, divisions, (u0, u1), *, derivative=None, tolerance=1e-9, max_evaluations=None)` | `curve(t)` 为有限的二维或三维点；`divisions` 为 1–128 的整数；`u0<u1`；导数可显式提供。省略导数时，在区间内用五点中心差分 | 严格递增的 `divisions+1` 个参数，含精确端点；根未收敛或几何退化时抛出 `ValueError` |
| `fold_angle_multipliers_2d(fold, (left, right), *, kawasaki_tolerance=1e-10, denominator_tolerance=1e-12)` | `fold` 为至少两个二维点；左右 ruling 均为对应顶点出发的同长非零二维向量列表；容差单位分别是弧度和无量纲的正弦值 | 每个顶点一个无量纲的有符号倍率；Kawasaki 失败抛 `LocalFlatFoldabilityError`，分母为零或精度不可分辨时抛 `SingularMultiplierError`，两者包含原版的 **1 起始**顶点序号 |

`DiscretizeCurveUniformly` 在每个内部参数 `tᵢ` 联立求解：

```text
[(f(tᵢ)−f(tᵢ₋₁))/|f(tᵢ)−f(tᵢ₋₁)|
 −(f(tᵢ₊₁)−f(tᵢ))/|f(tᵢ₊₁)−f(tᵢ)|] · f′(tᵢ) = 0
```

端点固定为 `u0`、`u1`，初值是等参数间隔；求根时使用正间隔参数化，以保持几何顺序。除以 `|f′(tᵢ)|` 仅用于无量纲收敛判据，不改变非退化处的零点。这个条件既不是等弧长，也不是等弦长。原版 In[4090] 的抛物线 `f(t)=(-t²,t)`、四等分案例给出近似参数 `[0, 0.183316669579, 0.391274766869, 0.651828020428, 1]`，相邻弦长约为 `[0.18637, 0.23984, 0.37650, 0.67230]`；这些数来自本实现，测试另外代回原方程核验。

`FoldAngleMultipliers2D` 使用原版 `RotationAngle` 的有向逆时针角 `(-π,π]`。内点按前一折线方向、右 ruling、后一折线方向、左 ruling 形成 `a1…a4`，要求 `a1−a2+a3−a4≈0`。首点采用 `sin((a4+a3)/2)/sin((a4−a3)/2)`，其余点采用 `sin((a1+a2)/2)/sin((a1−a2)/2)`；末点因此使用后一种公式，缺少的端点扇区不参与计算。只有内点有四个扇区，故仅检查内点 Kawasaki 条件。该函数只求本地倍率，不证明全局层序、折叠路径或三角面片精确等距。

运行专项测试：在 `workbench/backend` 中执行 `..\.venv\Scripts\python.exe -m unittest test_tessellation_curved_discretization -v`。测试覆盖原版 In[4088] 的系统采样、In[4090] 抛物线的联立残差、三维螺旋、边界倍率公式、局部 Kawasaki 拒绝及零分母。原版 In[4093] 的椭圆系统依赖 `ConicSection2DSystem`，其 `ShowExample` 无数值输出，本模块尚未验证该椭圆的具体分支。

数值范围：当前只求从等参数初值到达的**严格递增**根分支，不枚举所有非线性根，也未处理曲线自交、导数为零、弦退化附近可能存在的其他合法根。隐式符号微分、Wolfram `FindRoot` 的具体停止规则及 In[4093] 的椭圆构造不在本次对照范围内。
