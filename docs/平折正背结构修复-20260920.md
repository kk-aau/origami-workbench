# 平折正背结构修复 · v0.12.7

本次检查覆盖平折几何到可见区域、轮廓合并、边线绘制、异步切面及导出。修复的是显示流水线，未通过改变山谷、强制单色或增加描边宽度掩盖错误。

## 已确认的根因

1. `modelOverlapRegions` 将浮点近似相等的 x 坐标作为不同分割线，再省略极薄分割条，形成数值空槽。边线检测恰好落槽时，整段真实边被当成未知而省略。十边扭转 36°、半径比 0.7 的上下外边可稳定复现；合成矩形案例的 400 周长一度只画出 200。
2. `modelRegionPaths` 的每个颜色组各自焊接坐标，公差不一致；极窄接点可能出现绕行次数为 2 的边，旧实现仅保留正负方向，破坏轮廓入出度平衡。混合 3.6.3.6 在 20°/0.5、60°/0.2 的实际材质填面可抛出“局部纸面轮廓未闭合”，导致整片显示失败。
3. 编辑器、组合图和导出的后备显示不同。局部遮挡未完成时，编辑器可能按纸面编号画实体；而合并色面完成后又覆盖它。部分完成回复只验证区域，没有验证可见边线是否存在。

## 修改

- 全体区域共用归并后的 x 分割线，不再制造贯穿纸面的数值空槽。
- 全部材质和选中高亮共享坐标焊接；保留有向边完整绕行次数，保持非零填充的孔洞和连通关系。
- 继续用合并路径一次绘制同色纸面；独立绘制当前观察方向真正可见的边线，保留同色纸面之间的结构。
- `modelRenderMode` 统一实体、透视、线框及局部区域策略。局部区域下方不再铺任意纸面实体；等待时显示线框，镶嵌在适用时保留已验证快照。
- 区域及边线须共同返回才能作为完整局部实体。单图、组合及批次导出均校验；缺少边线的批次停止并保留此前完整项。
- 镶嵌缓存匹配包含面、边、山谷和起始面；保持独立相机与几何/遮挡原子更新。

## 验证

- 全量单元测试 951 项通过，另有桌面模块测试。
- 独立原面覆盖与层序检查共 88 个已解正背结果、29,142 个真实边探针。十边扭转、混合平铺、方格/矩形铺石及周期案例的实际可见边和顶面材料一致。
- 新浏览器检查 17 项：十边形完整外轮廓、正背内部边线的实际光栅、同色结构、两组混合平铺闭合失败参数、反复切面和相机保持。
- 透色回归 15 项：正背 320/800 像素及背面旋转 45° 的内部透色计数均为 0；选面、高亮、拖动和透视模式有效。
- 实时与铺石回归 11 项：拖动 175 个采样帧中更新 26 次，缺失局部表面 0 次，未验证实体 0 次，画布位移 0；后端请求等待期间仍同步更新。
- 编辑器与导出回归 15 项：延迟局部 Worker 回复 150ms，采样 1627 帧；等待时没有编号实体底图，完成时填色与结构线齐全。正背单图、双视图及实际下载的 SVG 可见边坐标一致。
- 桌面展开程序与免安装包分别通过 84 项实际启动检查；桌面模块测试 3 项通过。
- 核心记录：`output/back-surface-unit.log`、`back-surface-browser.log`、`back-surface-seams.log`、`back-surface-live.log`。

## 检查边界

六边铺石的主画面有全局层序，采用完整纸面绘制。将其强制送入更严格的局部分析时，约 1e-8～1e-7 的近重合边仍会产生公差歧义；本次未扩大公差去吞并潜在真实细节，也不将此诊断分支说成已完全解决。缺失边线的局部回复现在不会被当作完整实体接受。既有三角铺石等无层序解候选仍显示明确线框；此修复不改变求解器支持范围。
