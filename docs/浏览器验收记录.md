## 启动与保存

根目录 `启动折纸工坊.cmd` 调用 `workbench/launch.ps1`。已实测 Windows PowerShell 5.1 解析、重复启动复用现有服务，以及独立端口首次隐藏启动。最终 8787 服务由该启动器重新启动，而非依赖开发终端；日志位于 `workbench/logs/`。

工程库保留“示例 · 手风琴折”和“示例 · 正方缩放旋转镶嵌”。本次创建的 10 份重复或专项测试工程及已有对应备份已移动到 `output/playwright/archived-test-projects/`，没有删除，可手工恢复。用户旧 Java 程序、JAR 和原工作目录均未关闭或修改。
