# Origamica 第 45 节：In[3913] 切线可展面平展保存例

原版只读副本 `tmp/Origamica-15.0-reference.nb` 的 In[3912]（317574–317763 行）定义 `ReshapeTandev3D`，In[3913]（317763–317954 行）保存“Flattening a tangent developable”输入。源码要求母线方向是基线的切向，按源曲线的速度与测地曲率、给定的新扭率和初始 Darboux 标架恢复新曲面。保存例给定 `σ=+1`、分支 `ψ=+1`、新扭率 `τ=0`、`u∈[0,π]`、`v∈[0,1]`、新基线初值 `(-1,0,0)`、新母线初值 `(0,1,0)`、新面法向初值 `(0,0,1)`。这些单元保存了源码输入及绘图调用，没有可机读的 Wolfram 数值曲面 `Out`。下述闭式是按其方程与初值独立推导，不宣称与 Wolfram 内核逐点输出相等。

令 `a=√3/2`。原版源曲面为单位速螺旋的切线可展面：

```text
bb(u)=(-a cos u, a sin u, u/2)
dd(u)=bb′(u)=(a sin u, a cos u, 1/2)
X₃(u,v)=bb(u)+v dd(u)
```

源曲率为 `a`，源扭率为 `−1/2`。按 In[3912] 的 `u=σψ Normalize(dd′)×dd`、`l=u×t`、`sdκg=l·t′`，本例 `sdκg=−a`；给定新扭率零和初始标架，恢复的新基线和母线为

```text
b(u)=(-1+(1−cos(a u))/a, sin(a u)/a, 0)
d(u)=b′(u)=(sin(a u), cos(a u), 0)
X₂(u,v)=b(u)+v d(u)
```

原版第三幅二维图是 `Planarize[b]` 与 `Planarize[d]`，本模块返回同一解析目标的前两坐标。两曲面的参数导数均是 `Xᵤ=d+v d′`、`Xᵥ=d`，其中 `|d|=1`、`d·d′=0`、`|d′|=a`，所以共享严格相同的第一基本形式：`E=1+3v²/4`、`F=1`、`G=1`，行列式 `EG−F²=3v²/4`。两者的单位法向沿同一母线不变，故 `v>0` 的正则内域可展且连续等距。`v=0` 是两边共同的**奇异回归边**；原版绘图区间虽包含它，该处没有唯一切平面，不能把这条边当作正则曲折或证明全闭域是光滑等距浸入。未证明全局无自交、纸张厚度或连续部署。

实现分为 `backend/tessellation_curved_tangent_developable.py` 的固定闭式核心和 `backend/tessellation_curved_tangent_developable_query.py` 的封闭只读查询。请求仅接受 `family="tangent-developable-in3913"`、整数 `curveSegments`（8–256）、整数 `rulingSegments`（1–16）和 `rulingEnd`（0.05–1）；默认是 64、4、1。采样点数最多 4096，额外字段、表达式字符串、非有限数、布尔数字和超限请求直接拒绝。它固定保存例的 `u∈[0,π]` 与 `v` 起点零，仅允许缩短母线终点。响应返回原版 In 编号、源/目标初始标架、曲率与扭率、上述连续证书、共用参数和母线距离、二维／三维对应样点。返回标记 `sampledMeshExactIsometry=false`、`exactStraightCreaseFOLD=false`、`adoptableCreasePattern=false`，不生成三角面或保存折痕候选。

## 反向保存调用 In[3914] / In[3919]

笔记本 In[3914]（317962–318167 行）和数值版 In[3919]（318750–318931 行）把上面的平展曲线 `b,d` 原样作为新的源输入，固定 `σ=+1`、目标扭率 `τ=−1/2`、分支 `ψ=+1`、`u∈[0,π]`、`v∈[0,1]`。反向三维初值为 `bb(0)=(-1,0,0)`、`dd(0)=(0,√3/2,1/2)`、`uu(0)=(0,-1/2,√3/2)`。这个位置初值与正向 In[3913] 的三维源基点 `(-√3/2,0,0)` 不同，故不能声称反向得到逐点相同的绝对坐标。

令 `a=√3/2`，原方程与这些初值唯一给出 `bb_reverse(u)=(-1+a(1−cos u), a sin u, u/2)`、`dd_reverse(u)=(a sin u,a cos u,1/2)`，恰是 In[3913] 的三维源面整体平移 `(a−1,0,0)`；二维源面则与 In[3913] 的平展目标完全同参数相同。两次反向调用因此没有第三种内蕴曲面。双视图现可切换正向 In[3913] 与反向 In[3914]/In[3919]：反向三维采样逐点加上该平移并显示源初值 `bb(0)=(-1,0,0)`，二维展开不动。该平移是本地按原方程推导，后端仍返回经严格回读的正向 In[3913] 采样；In[3919] 的 Wolfram 插值轨迹和数值 Out 未逐点复刻，`v=0` 的回归边奇异性也不因反向调用消失。
