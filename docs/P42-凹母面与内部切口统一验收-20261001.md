## 构造与原式

| 范围 | 实现与证据 |
|---|---|
| 真正凹母面 | `InsetPoly` In[931] 使用相邻偏移直线交点；In[3428] 沿用该式。原凸面代码路径保持不变。凹角不再错误地按全部内半平面交集截断；反向、塌缩、自交内缩仍拒绝。 |
| 独立来源校验 | 原母图、原半边遍历、全局边界点、全部逐边内缩、仿射 FF、赋型、逐面等距、winding 回展、固定面及周期均独立核对；24 份真实响应通过。删除可信标志或伪造 CP/FF/参数不能绕过。 |
| 内部 B 切口 | 仅跨非 B 共边合并面角；内部 B 两侧保留两条单面边，不改成山谷折痕。四组原实例由 10 点/14 边变成 14 点/16 边，5 个原面编号保持，分为 3 个部件。 |
| 原 FF 位置 | 所有部件使用同一原 CP 坐标变换，并保留原 FF 相对位置。不能分别选择起始面重新摆放各部件。原固定面改变 CP 的回展位置，不改变原 FF。 |
| 同画布平折 | 原 FF 几何经验证后进入独立层序求解，继续使用镶嵌现有画布；正背面可见区域、边界和拖动位置保持均验证。未求解时不伪装为实体层序已完成。 |
| 孔洞与裂缝拓扑 | 结构专项覆盖环形孔洞、两端未分离的内部裂缝、边界至内部裂缝以及交叉切口。显式 faces_edges、edges_faces、逐边 faces_faces 防止相同端点的两侧边被合并；这些结构测试本身不是原式可达证明。 |
| 观察与导出 | 同一母图编辑器内可查看母图、原 CP、原 FF，读取边/面编号；保存原来源以及带 CP/FF 两帧的分片 FOLD。输出携带显式 incidence 与原索引映射，不虚构层序数据。 |

## 明确保留

1. 内部切口可以在镶嵌预览、验证层序和导出，尚不能直接采用到普通折痕编辑。普通单纸引擎和采用门禁仍在；完整保存、编辑及重新计算需另行接入，不能只解禁按钮。当前普通 FOLD 导入不接受这个双帧切口文件；本批“导出回读”指独立验证下载文件，不是应用内导入闭环。来源 JSON 和母图包有各自回读入口。
2. 全逐边内缩例的 CP/FF 几何有效，但三角化中有接近共线的薄片，当前层序仍 unsupported，采用禁用。一般凹图不保证任意参数成功。
3. 结构层面保留平行裂缝两侧边，但凹面层序三角化仍按端点恢复部分边关系；尚未认证凹面与平行裂缝的组合。
4. 母图自身有孔洞或断开部件仍未迁移。内部切口分片不等于放开所有母图输入。
5. ≥10 偶度母图未完成。十度椭圆诊断的反射残差近零但 CP 有 21 处交叉；去掉因子上限 50 后仍是同一分支，不能把上限当成已经定位的根因。原平方和最小化 fallback 尚未接入。
6. 完整 Wolfram 符号、求解/绘图选项、插值对象、无预算全域等价仍属完整目标剩余项。层序解不证明连续路径、无碰撞或实际厚纸可折。

真实界面追加修复：层序结果为 unsupported 或 error 时分别明确显示“层序计算受限”“层序计算失败”，不再保持“待确认”；原因保留在提示中。此文字状态映射在完整前端回归之后修改，由最终类型构建及真实 full-insets 场景验证。

最终统一冻结：`output/audits/p42-cut-concave-final-20261001.json`；872 模块构建，29 项唯一真实 GUI 检查，零页面异常。29 项为 16 布局/草稿、2 下载、7 同画布交互、3 凹母面、1 下载独立回读；补充的切口 2 张及凹面 4 个已解层序侧视不重复加计。临时浏览器及 8794 服务已清理，用户 8787 服务未改动。
