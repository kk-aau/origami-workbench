# P42 有限数值 TGraph 入口（2026-09-30）

本轮将原 `MakeSimpleWovenTessellation[TGraph,h,...]` 的有限输入入口接入既有编织流程。支持域为已显式拆交点、单连通凸外边界、严格凸面、内点四／六／八度的有限直边图。输入边可以局部偏折，并不要求形成可还原的全局直线组。本轮没有宣称任意 TGraph 都已复现。

## 原定义及输入索引

源文件为 `tmp/Origamica-15.0-reference.nb`；以下是文件行号，In 标签位于各完整单元结尾。

| 原输入 | 定义位置 | 本轮实际职责 |
|---|---:|---|

| In[1278] `AddTPlaneGraphTo` | 82418–83035 | 沿角排序的顶点邻接，按 `Join[edges, Reverse /@ edges]` 逐半边发现面；保留 V/E，重建 Faces。 |
| In[1280] `RebuildPlaneGraph` | 83064–83075 | 清除已有面的影响并重建面序。不能将调用者手填 Faces 当作固定面编号依据。 |

In[3428] 的 `localfvdata`（253290–253373）只取每个面顶点的前后边方向；`makeverts`（253408 起）使用 `1/Abs[en.Rotate90[ep]]` 和相邻边 h 的位移。这里没有全局直线组，也没有“对边必须共线”假设。母内边两端同为 BoundaryVertices 时，源 `newfaceedges` 将其作为边界切口；本轮尚未接该切口分支，明确拒绝，不能用普通条带代替。

## 可保存的来源合同

```json
{
  "family": "woven-lines",
  "mode": "graph",
  "graph": {
    "vertices": [[0.001,0.001],[1,0],[0,1],[-1,0],[0,-1]],
    "edges": [[1,2],[2,3],[3,4],[4,1],[0,1],[0,2],[0,3],[0,4]]
  },
  "width": 0.08,
  "parity": 1,
  "minPleat": 1,
  "minBorderPleat": 0.01,
  "borderInset": "auto",
  "stationaryFace": 0
}
```

| 字段／规则 | 严格合同 |
|---|---|
| graph.vertices / graph.edges | 零基编号；原顺序及每条边方向原样保存。3–512 点、3–1024 边，坐标有限且每轴 −1000…1000（仅 graph 上下文；旧线组不扩）。不能附带 Faces 或全局 lines。 |
| 输入几何 | 已拆点边交点和交叉；无重复点/边、桥边、悬挂边、孤点；一个凸外边界；至多 256 个严格凸面；内点四／六／八度，边界二或三度；至少一个内边；不接两端均为边界的内部切口。 |
| 面编号 | 源半边发现顺序，`sourceFaceCycles` 保存原 CCW 面循环。API mother 的 CW 绘图合同与之对应，面编号不变。固定面采用零基 source face index；UI 显示 F1…Fn。 |
| width | graph .005…20，完整 h 0…10；默认各内部边 h=width/2；自动边界同样 h=width/2。完整列表存在时，其绝对 h 不随 width 改变。 |
| fullEdgeInsets | 复用完整逐边来源：edgeCount 等于全部源边数；entry.edge 必须原 index；端点戳逐边核验。graph 中 `line=-1` 只表示边界，`line=0` 只表示有限内边分类，绝不是虚构的“线组1”。源结果不输出 lines / segmentInsets。 |
| 戳误差 | 按真实局部图跨度 `1e-9*span + 16*coordinateULP`；同一边反向端点可匹配；不得默默重排条目、焊接点或自动 Intersectify。 |
| 周期 | 延续原空周期合同：缺省 empty=[] 是旧 None；`periodicityEnabled:true` + [] 映射显式 `{}`，全部有效边界 h=0；非空配对自动启用；false+非空拒绝。 |
| 来源保存 | source.graph / metadata.parameters.graph 原文数值回读；metadata 保存 fullEdgeInsets、周期标志和固定面。图几何改变必须明确清 full/segment/periodicity/flag 并重置固定面；仅宽度、褶宽约束或奇偶改变保留来源。 |
| 互斥／串族 | graph 模式拒 lines、boundary、segmentInsets；普通模式拒 graph。非 woven 家族携带 graph 或 mode=graph 拒绝，不能丢来源后加载别的默认构造。 |

内边 h=0 来源仍能通过通用完整列表语法，但非退化编织分子无法构造，明确拒 CP；边界 h=0 可用。Insets 真实进入 `InsetPoly` 及边界褶位移，不能仅添加来源旗标。来源错误、拓扑失败、求解失败均不发出部分 CP，也不能越过整片层序采用门禁。

原圆弦、chord、random 和保存线组例保持各自来源路径。有限图只是既有“线组方式”的第四项和既有编辑/逐段对话框，没有新增工作区、侧栏行或分页。全边可通过地图及完整编号选择器访问；图 JSON 使用已有源编辑方式，源输入框自身可编辑长文本，对话框及主工具不增加滚动。
