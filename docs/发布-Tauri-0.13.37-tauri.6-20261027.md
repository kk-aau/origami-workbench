# 折纸工坊 Tauri 独立版 0.13.37-tauri.6

本版保留四个工作区和完整 Python 离线计算。宿主使用 Tauri／Rust 与系统已有 WebView2，不分发 Electron／Node，不自动下载或安装运行环境。

| 改动 | 行为 |
| --- | --- |
| 大工程 CP 绘制 | GPU 绘制支持缩放和平移；失去 GPU 上下文时回到原显示路径，保留编辑和拾取 |
| 完整平折 | 手动计算正常推进时持续等待，逐区验证完整层序后显示纸面；随时可停止，不把时间长当成无解 |
| 精确分区 | 紧凑拓扑与增量覆盖降低内存；求解和显示共用认证结果，不删除微小区域 |
| 纸面与导出 | 正反面、双/四视图、阴影和导出使用完整可见轮廓；保持原纸面 ID 和选择 |
| 缓存 | 模型历史、相同快照和导出复用已验证纸面；修改几何或层序后失效，缓存不写入工程 |
| 阴影 | 按精确来源线和真实连续顶点合并显示，保留全部原段与边界 |
| 大量顶点 | 避免范围计算的参数展开栈溢出，完整原面编号保留；无法可靠显示的极细面不猜编号位置 |
| 应用体积 | 应用不内嵌完整源码、开发目录或调试映射；必要许可和准确源码获取说明保留 |

适用 Windows 10/11 x64、系统已有 Microsoft Edge WebView2 Runtime。安装版和单文件便携版独立命名，默认数据与原 Electron 版分开；升级时保留 `Zhezhi-Tauri-Data` 或安装目录 `user-data`。

完整对应源码普通 ZIP 与 solid 7z、独立调试材料和 SHA256 清单与应用同版本交付。发行入口为项目现有的 Gitee Releases，实际附件与发布状态以在线发行页为准。源码附件无需下载即可使用应用。

大工程优化的开发验证见[精确平折与显示验证](大工程精确平折与显示验证-20261027.md)。其中 Node 缓存几何实验、实际浏览器计算 Worker 和实际显示组件属于不同测试口径，不混用耗时、区域数量或证书。

本版的最终体积、引擎复用依据、原生桌面与双 EXE 验收结果，以 `release/Tauri-0.13.37-tauri.6/RELEASE-0.13.37-tauri.6.json`、版本化 SHA 清单及本机 `output/tauri-release-0.13.37-tauri.6/` 为准。只有全部打包门禁通过后才执行交付和上传；本文件不代替实包验收。
