# 折序符号自动放大与波浪选区

本次为源码更新，未重新打包桌面发行版。沿用现有“局部放大”和“缩小视图”符号及原插件控制点。

## 使用流程

| 操作 | 本步骤 | 从下一步开始 |
|---|---|---|
| 放置“局部放大”，确认选区 | 保持当前展示，画出选区轮廓和原有放大符号 | 裁切选定区域并适应主画布；后续步骤持续使用此范围 |
| 放置“缩小视图” | 保持本步已有放大 | 恢复完整图示范围 |
| 再放一个“局部放大” | 从完整纸面重新选择范围 | 改用新选区，不累积重复缩放 |
| 删除放大符号、撤销或重做 | 按保存的指令重新推导各步骤 | 相应恢复或取消后续放大 |

1. 在符号库的“视图方向”中选择“局部放大”，点击主图放置。
2. 在弹出的“设置下一步放大区域”中选择圆形或波浪线分区。
3. 确认右侧预览，点击“使用此选区”。点击“取消”不会留下未完成符号或改写步骤标题。
4. 点击“下一步”，查看实际放大效果。放大只改变展示范围，不修改 CP、纸层顺序或三维状态。

选中已经配置的放大符号后，左侧“重新选择放大区域”可以修改范围；旧工程中仅作图示的放大符号也可在这里补选区。移动符号本身只移动其图形，不会悄悄改选纸面区域。

## 圆形选区

在左图按住鼠标，从圆心拖到圆周边缘，选定需要展示的细节。也可输入圆心 X、圆心 Y 和半径，单位为毫米。右侧同步显示圆形裁切后的效果。

拖绘过程中右击或按 Esc 取消本次手势，恢复手势开始前的选区。圆形只裁切展示，不会把纸真的剪成圆形。

## 波浪线分区

在左图拖动两个位置，系统生成一条穿过当前纸幅边界的波浪分界线。松手后点击其中一侧，绿色高亮部分就是要保留的范围。也可在“保留区域”中选择区域一或区域二；键盘 1、2 提供同样操作。

必须选择一侧后才能确认。需要换位置时点击“重画分界线”。波浪边缘、绿色高亮、右侧预览和下一步实际裁切使用同一条边界。

例如，要展示左上角，可以从左边中部向上边中部拖出分界线，再点左上角区域。选较小的细节区域，适应画布后的放大效果更明显。整幅宽度或高度都被保留的长条选区会收紧四周留白，完整保留选区并放大；不会为了显示得更大而再剪掉两端。

## 四步示例

| 步骤 | 操作 | 展示 |
|---|---|---|
| 第 1 步 | 放置局部放大，选择右上角圆形或波浪分区 | 完整纸面、符号和选区范围 |
| 第 2 步 | 绘制这一处的折叠说明 | 放大的局部纸面 |
| 第 3 步 | 继续说明，并放置缩小视图符号 | 仍然放大 |
| 第 4 步 | 继续绘图 | 恢复完整纸面 |

## 保存、输出与交互

- 选区保存在放大符号中，随工程导入、导出、保存和重开；后续有效范围从此前的指令推导，不保存一份可能过期的第二状态。
- 步骤缩略图、整页预览、文档库、SVG、PDF 步骤图和封面采用同样的裁切。圆形细节框与 CP 前后对照框继续使用其原有取样逻辑。
- 选区根据各步纸面或图片的展示范围对应，保持相对图示位置；这是二维展示范围，不是跨折叠的材料跟踪。
- 放大相机与原有普通视图分开，恢复时不把放大相机写回纸面。原始线段、图片和符号坐标保留。
- 纸面与折线按选区裁切；框选、右拖删除、橡皮和吸附不会误操作范围外的隐藏折线。编辑仍作用于被选中的原始对象，不把临时裁切片段写入 CP。
- 缩小、放大及其他操作符号可放在纸面或选区外，仍可显示、选择、拖动、操作原生夹点和删除。下一步选区的指示边线也不受本步旧选区限制。
- PDF 为纸面外的放大／缩小、翻面和旋转符号使用图格留白，避免远端符号让局部图重新缩小；不改写工程中的符号坐标。无标题或说明的图片不再为这两行保留空白。
- 如果工程中极端的选区尺寸不能应用到当前纸幅，保留原数据并提示重新选择，显示完整视图，避免画布崩溃。
