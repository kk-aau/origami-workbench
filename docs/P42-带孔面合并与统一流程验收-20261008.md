# 带孔面合并与统一流程验收（2026-10-08）

完整镶嵌复现目标保持 active。本批完成简单、互不接触的带孔材料面的二维表示、合并及后续构造，不代表原版全部功能完成。源码和网页构建已更新，0.13.5 安装版与免安装版未重新打包。

| 功能 | 本批结果 |
| --- | --- |
| 删除内折痕合并面 | 一个外环与一个或多个孔环作为真正的材料面保存，不添加连接孔洞的虚假折痕。预览显示合并后的实际孔洞，取消、撤销和重做保持原工程。 |
| 单面、跨面与批量构造 | 全部内外边界均可作为锚边；实际折痕按材料区间分段，孔洞与部件间空白不补线。跨孔参考线为紫色虚线，实际构造为青色。带孔单面固定侧明确表示直线左侧/右侧，普通单面保留旧语义。 |
| 切开、粘合、镜像与剪贴板 | 所有内外环同步更新角、边和邻面关联；独立片及切口身份保留，复制不按同坐标焊接。邻孔边被细分后，邻面的孔环也同步更新。 |
| 平折与正背显示 | 使用保原面身份的私有三角分片求解层序；显示、选面、区域边界、阴影和 SVG 均排除孔内空白。辅助三角边不写入 CP/DXF。 |
| 保存与导出 | 带孔面使用材料拓扑 v2；无孔面保持 v1。JSON/FOLD 保内外环及 CP/FF、参考面和活动面；普通 DXF 仍为 R12 AC1009 独立 LINE，沿用既有毫米转换。 |
| 三维模拟 | 尚未接入带孔面。进入第三方三角化前明确拒绝，避免把孔洞填成纸面；拒绝流程的输入不变性已通过单测，最终三维界面流程未单独验收。 |

严格检查孔环方向、接触/相交/覆盖、退化、共享角、真实边归属、Euler 关系和 CP/FF 等距；失败原子拒绝。合并后的自接切口、重复角以及一条线仅连接外环与孔环而形成同面自桥的情况仍未支持。固定点不能放在孔内或孔边。

私有三角化恢复 earcut 省略或跨越的所有原边界角，包括已经出现在其他三角片中、但仍位于长三角边上的角。恢复只使用原点和精确共线判定，不吸附、不新增 CP 点。保持既有层序预算，不将预算不足报告为数学无解。
