# 选区移动、复制与四点定位

新增四个实际入口，当前共 51 项工具，仍不是全工具验收完成。此批未打包。

先用“选择”点击线段或框选多条线，再进入“镜像 / 变换”组：

- 两点移动／两点复制：点击基准点后再点击目标点，也可按住基准点拖到目标点释放。开启吸附时使用网格、端点、交点。
- 四点移动／四点复制：依次点击已有端点或交点 A、B、C、D。A 对应 C、B 对应 D，完成保向旋转、等比缩放和平移。第四点提交；不接受任意空白网格点。
- 紫色虚线只作参考，不采用山谷颜色。固定指南与鼠标右上提示显示当前步骤。按钮沿用紧凑限宽和最多四列布局。
- 右击／Esc 取消已开始的定点或拖动，保留所选线；空闲时右击仍是删除。成功后清空选择，与原版变换结束行为一致。

变换保留每条原线的类型与折角，包括 0 和未知值，不取上方新绘制线型。未选择的线、辅助圆与文字保持原状；目前四个入口处理线段，不变换绘图对象。

相交后进入统一真实分段流程，可以独立选择小段；整组操作一次撤销，保存后可恢复。移动到同类型、同折角覆盖区会合并重合部分，完全覆盖时保留目标并移除源；复制的完全重复结果不再添加。不同类型或折角的正长度重叠拒绝整次操作。零长、过近点、越界、失效选区和保护边界均受校验。

源码依据：MouseHandlerCreaseMove / Copy / Move4p / Copy4p、BaseMouseHandlerLineTransform、FoldLineSet.move(ta,tb,tc,td)。原版两点释放提交及四点相似变换已按本地源码核对；尚未进行原版运行时逐样例等价验收，目录保留“基础可用，变体待齐”。

验证：399 项单元测试；浏览器新变换 35 项、通用交互 98 项、构造拖放 33 项、镜像回归 42 项，共 208 项断言通过。新脚本 output/playwright/verify-selection-transform.js，截图 selection-transform.png；测试使用独立 8799 服务与 selection-transform-data，不改正常 8787 或用户作品。构建通过，已有主包大于 500 KB 的警告仍在。
