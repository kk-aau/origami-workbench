# 三维 100% 显示与折痕样式

日期：2026-10-14。当前源码及网页构建已更新，发行安装包未重新打包。

| 用户操作 | 当前行为 |
|---|---|
| 目标折叠设为100% | 对实际已经近平行、近共面的重叠纸面稳定显示层次，避免微小求解残差引起正反色碎片和背层折线透出 |
| 工具栏“红蓝” | 保留山折红线、谷折蓝色虚线 |
| 工具栏“折痕” | 山谷线改为中性深色细实线，边界仍保留独立颜色 |
| 切换样式、旋转视角 | 只改变显示；暂停时不推进求解，求解坐标及山谷赋型不变 |
| 重连时重复材质设置 | 相同参数不重新启动刚暂停的模型 |
| PNG／SVG | 使用当前样式及相同的显示层修正 |
| FOLD／OBJ／STL | 输出实际求解坐标，不把显示微层间距写入几何文件 |
| 99%及以下、折线／透视模式 | 保留真实求解姿态；透视模式仍可观察背层 |

## 实现与边界

求解器到达100%时并非数学上精确共面：真实单折痕在模拟时钟判定速度暂稳后仍有微小残差。原来的深度测试能稳定完全重合的面，无法消除这些偏差造成的交替着色。

新显示网格以面内F边连接的三角片为一个材料面板，先检查面板平面误差，再检查面板之间的法向、间距及正面积重叠。每组使用固定的首个源面板作为参考，按匹配当前源CP的已求解平折层序生成微小法向层距；缺少可信层序时不按面编号猜顺序。相邻展开面、孔洞中的空区域以及明显弯曲或相交纸面不会被强制拉平。所有位置变换只发生在显示副本中。

距离容差为初始模型半径的5e-4，法向正弦容差2e-3；显示层距为半径的5e-5，同组最多100个材料面板，总扩张小于半径的0.005。过大或不满足条件的组保留原状。该顺序用于稳定画面，不是运动过程的物理层序或无碰撞证明；未添加自接触、纸厚或摩擦求解。

仅在目标100%、模拟时钟判定暂稳、没有抓住纸角且已有匹配层序时启用；等待120毫秒后用300毫秒淡入。环状层序可能没有全局统一排序，此时按实际投影重叠区域逐区查询可信顺序。局部显示裁分保留源三角片的重心权重，并检查覆盖面积；详细修复记录见《三维环状100%层序显示修复-20261014》。

GPU使用独立显示纹理并复用拓扑，不改求解纹理；CPU使用同一显示网格和双精度深度缓冲。近掠射视角按层距的视线投影缩小折线深度偏移，防止偏移跨越显示层距。SVG同步采用逆眼距透视深度和当前折线偏移，避免导出再次透线。应变按每个显示顶点的源节点映射，不因复制面板而重新解释。

显示网格仅在100%且求解步数更新时重算，旋转、缩放及样式切换复用缓存。面板包围盒按较少拥挤的轴筛选，投影按需计算；5000个不相交共面面板的测试实际约21–25毫秒，不以易受环境影响的耗时作为硬性断言。
