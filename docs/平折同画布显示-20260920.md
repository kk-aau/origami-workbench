# 平折同画布显示与配色

版本 v0.12.3，2026-09-20。

折痕编辑与镶嵌两处的平折结果现在都是原折痕画布内的模型图层。打开或收起不会改变折痕画布尺寸，也不再创建默认的平折侧栏和分隔条。左键拖动折后纸面移动模型，在模型上滚轮缩放；其余画布继续用于折痕操作。

画布底部的紧凑工具条提供实体、透视、正面、背面、45° 旋转、位置复位和三个颜色输入：FC 正面、BC 背面、LC 边线。这里的透视指 X 光半透明显示，不是三维透视投影。更多计算或模型操作放在工具条旁的展开菜单。

实体模式默认使用不透明面。层序尚未确认时，显示的是带状态说明的实体几何示意；遮挡顺序不能据此视为验证通过。有完整层序时按层序绘制；镶嵌也接入原有局部区域显示，用于已求得层序关系但没有统一绘制顺序的情况。透视模式显式切换为半透明面。

配色不修改山谷线型或计算参数。编辑区随模型视图保留配色；镶嵌在本次运行中保留配色，调参、收起重开都不重置。镶嵌的实时几何与后台层序计算沿用原机制，参数更新不改变模型的平移与缩放。

验证：相关 27 项单元测试通过；同画布界面 28 项检查通过，包含折痕继续编辑、模型独立拖动缩放、实体/透视、正反配色、收起恢复以及镶嵌实时更新；既有镶嵌平折 19 项回归通过。快速拖动期间模型更新 37 次，画布位移 0，测得 rAF 间隔 P95 约 5.7ms（本机 1000×720）。

脚本：`scripts/verify-shared-fold-canvas.browser.js`、`scripts/verify-tessellation-flat.browser.js`；实际截图：项目根目录 `output/playwright/shared-fold-editor.png` 与 `shared-fold-tess.png`。
