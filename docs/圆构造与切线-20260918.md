# 圆构造与切线 v0.7.0

本轮增加 6 个实际工具，当前工具数 25；不是 Oriedita 全工具移植完成声明。

## 新工具

|工具|点击步骤|生成内容|
|---|---|---|
|分离半径圆|新圆心 → 长度起点 → 长度终点|后两点距离作为半径的新圆|
|同心圆|参考圆 → 增量起点 → 增量终点|半径增加两点距离的新同心圆|
|等半径圆|参考圆 → 新圆心|复制半径，不移动原圆|
|双圆外切调整|圆 A → 圆 B → 确认双圆／点击紫色新圆|两个新同心圆，原圆保留，整组一次撤销|
|点圆切线|起点 → 圆 → 候选线／编号按钮|圆外点至切点的有限线段|
|两圆公切线|圆 A → 圆 B → 候选线／编号按钮|两个切点之间的有限线段|

双圆外切调整的两半径同时增加 `(圆心距离-rA-rB)/2`；允许负增量缩小相交圆，但必须保持两个半径为正。已外切、同心或调整后半径不为正时拒绝，不改原图。

圆外点通常有两条切线；两圆的实公切线随相对位置变化。圆内点、同心／重合圆、严格内含的圆对不能强行生成实切线。圆上点或内／外相切时，重合切点的候选按切线方向延至第一条非辅助线或纸边，正反方向分别展示。没有有限截止几何时给出中文提示，不生成零长度线段。

切线候选带编号，可点击线或键盘操作编号按钮；相交候选难以分辨时使用编号。参考圆、测量线和候选均为紫色，确认后的切线使用当前新绘制线型，并遵循原有真实分段／撤销规则。分离半径与同心圆的测量线仅为临时参考，不写入折痕。

## 交点吸附

- 圆与有限线段、圆与圆的实交点会显示标记并支持吸附，相切点去重。
- 不使用线段延长线的虚交点；同心／重合圆不枚举无限交点。
- 这些是派生辅助点，不写入 objects，也不自行分割折痕或改变纸面。以其为新折痕端点时，实际新增的线线连接照常分段。
- 关闭吸附会同时禁用这些交点。圆移动、改半径、删除、撤销、恢复后重新计算。
- 为限制绘制负担，最多显示 2000 个圆交点标记，最多保留 20000 个圆交点供吸附；达到限制时画布上方明确提示。线段自有端点／交点不占这个上限。

## 兼容与范围

沿用 v2 原生工程，不添加新对象类型或运行依赖。所有多步工具的右击／Esc 清除参考，右击取消不同时删线；再次空闲右击才沿用线段删除规则。生成圆不参与折叠，生成切线是真实折痕。

依据本地固定 Oriedita 1.1.3 提交 `0891f8e8133ddf3aba8c6ec8a2b1ef565a0ea86e` 核对 CircleDrawSeparate、CircleDrawConcentric、CircleDrawConcentricTwoCircleSelect、CircleDrawTangentLine。

目录对应四项接入“基础可用，变体待齐”。本工作台采用分步点击、自由／吸附点，长度参考不额外落成辅助线；切线不照搬上游双向全延长。等半径圆是独立便利入口。受限拖画、按两圆半径差生成同心圆、反演、圆批量变换等仍待补齐。
