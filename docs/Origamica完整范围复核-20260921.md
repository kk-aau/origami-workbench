# Origamica 15.0 范围复核与完成声明更正

本次静态清点用户笔记本的全部 53 个 Section、365 个 Subsection，重点读取构造接口说明，对照 v0.13.0 的前后端输入契约、构造分发、几何实现和交互入口。材料为用户原始笔记本及本地提取记录 `output/original-notebook-notes.json`，未执行 Wolfram 内核。下方 P01–P16 差异表保留当时的 v0.13.0 基线；2026-09-24 之后的工作区进度以 `完整复现执行台账-20260921.md` 为准。末尾大节索引的 43–46 行另按当前源码补记，仍不表示全节完成。

此前“剩余构造目标完成”只能表示当时列出的六组工作完成。那份清单没有覆盖原版全部平面镶嵌能力，且部分旧入口仅实现同类构造。将其当作“剩余构造全部完成”是不准确的。本表更正范围结论，不否定已经通过的具体测试，也不把测试数量解释为原版覆盖率。

## 二、整个笔记本中尚未完整移入的模块

- 局部可折分析工具：四度顶点 LFF 关系图、BLB 高阶顶点逐步归约；目前的 Kawasaki／Maekawa 和层序检查不等价于这些操作。
- 球面顶点、折角相容和刚性四边网格：原版四度球面顶点分支／折角关系、加权折角相容求解、刚性四边网格设计；现有通用三维模拟只是部分相关能力。
- 三维构造族：Huffman grid、Miura/Mars、嫁接及半广义 Miura、Yoshimura、Tachi–Miura、三角化圆柱、褶锥、水雷，以及线性链、空间曲线驱动构造等。
- 应变约束设计：指定顶点位置、折角约束、四边面应变能量、受拉伸褶线等原版专用优化接口。
- 旋转壶体与管状结构：径向壶体和扭转封顶／连接／双连接管已有受限的二维展开与静态等距三维构形；矩形／扭转壶体及全参数等价仍缺。
- 曲线折叠：可展曲面、曲线折痕、带状曲面的展开／重塑、连续及离散曲线折叠、锥柱连接和多条关联曲折。
- Flasher：平面 `MakeFlasher` 已有独立二维初值及数值 CP／三维 FF 求解和赋型；应用入口仍待验收，抛物面 Flasher 的部署形／折后形及全参数等价仍缺。
- 制造模块：激光穿孔刻线、木皮刻槽、实体厚度与间隙、柔性铰链、销轴铰链及装配工具。
- 原版程序环境：Mathematica 符号表达式、图对象类体系、绘图装饰和 Matlab 接口没有逐 API 搬入。已有几何、工程与导出功能属于工作台自身实现。

逐步平折、三维图折叠／展开、通用几何和文件格式有部分相关能力，尚未逐函数证明等价，列为“部分／待细查”，不直接断言全部缺失。原版标记 TBD、IN PROGRESS、deprecated 的条目单独保留状态，不将未完成草稿冒充稳定待复现功能。

## 三、实现与等价验收必须分开

已完成且经过专项验证的项目包括精确四边形分裂四变体、Brocard 七类、20 种双均匀、5 种 Resch、三类任意线组编织，以及基础拼块交互。这并不补齐上表的扩展接口。

没有 Wolfram 内核运行记录。原版笔记本保存输入、公式及有限样例，其中多数壶管和 Flasher 示例没有可提取的最终坐标；本项目的方程推导、自测和桌面检查不能当成所有原版函数逐点等价证明。各族尚未验收的范围见执行台账。

本次保证的是目录层面覆盖与上述差异有具体依据，尚不是逐条 Wolfram 定义及所有选项的穷尽等价审计。因此不承诺“除了这些绝无其他细节差异”。
