# 折纸工坊迁移版 0.13.39-tauri.12

适用于 Windows 10/11 x64，使用系统已有 WebView2，保留完整离线计算引擎。原 `workbench/` 保持不变。

## 本次变化

| 项目 | 更新 |
| --- | --- |
| 应用窗口 | 整合应用标题栏与窗口控制，移除重复的系统标题栏和菜单栏，保留未保存关闭保护 |
| 工作区入口 | 四工作区改为左侧窄竖栏，聚焦画布独立放置；总览、导出、设置等入口重新组织 |
| 工具分组 | 按类型、选择、绘制、删除、变换、修复、注释、生成、测量、整理与检查排列，保留全部工具及自定义排版 |
| 工具样式 | 分类标题居中、细分隔线、简洁图标；中文名称始终显示，长名称自动换行 |
| 自适应列数 | 默认随工具栏宽度增减列数；旧内置四列排版安全迁移，用户明确设置的固定列数保留 |
| 命令与帮助 | 命令框改为可拖动悬浮样式，操作帮助按需展开，移除固定图例和说明占用 |
| 菜单快捷键 | 菜单中保留保存、打开、打印和全屏等全局快捷键，隔离会误操作画布的普通字母及删除键 |
| 大工程重开 | 纳入已保存大工程后台准备及签名顺序修复；保存后重开、改名后撤销及修订轮询列入本次实际发行包验收 |

## 交付与验收边界

安装版与便携版来自同一冻结 payload，应用内不包含完整源码、sourcemap、PDB、开发工具链或用户数据。完整对应源码 ZIP 与 solid 7z 作为同版本独立附件，源码获取说明及原始许可保留在应用内；用户运行应用无需下载源码附件。

离线引擎仅在完整文件清单、相关源码、依赖锁与构建依据一致时复用。沿用同字节引擎既有 1,358 项 Python 回归，本轮不据此声称重跑这些检查；新双 EXE 的实际启动、导入、平折、三维、折序导出、日志、关闭与大工程重开另行验收。

此前 tauri.11 在冻结后发现保存签名顺序问题，已撤回且未上传。tauri.12 使用修复后的源码并重新构建；最终通过状态、产物字节数及 SHA256 以本次验收目录、`RELEASE-0.13.39-tauri.12.json` 与实际发行入口为准。源码冻结时发布尚未完成，本文不代替最终验收报告。

本版本不附带或自动安装 WebView2，缺少系统运行环境时会明确提示。不会以减少包体积为由裁剪完整离线计算或现有功能。
