# Origamica 第 38 节：Goldberg 保存例与可采用纸面边界

本轮核对笔记本的三个保存绘图输入：`In[3323] GoldbergPatch[7,2]`、`In[3325] GoldbergTiling[7,2,Numeric→True]`、`In[3327] GoldbergOffsetTiling[8,2,1,Numeric→True]`。`GoldbergPatch/Tiling/OffsetTiling`（242946–243324 行）返回的是 `UnitTriangleTile` 拼块规格；后续 `MakeGoldbergTiling` 与 `MakeOffsetGoldbergTiling`（246380–247306 行）才把它们转为线图。笔记本在这些样例附近没有可机读的数值 `Out`，下述证据来自保存的构造公式和当前数值网格的拓扑检查。

| 保存输入 | 当前入口与检查 | 是否有本轮新增的可采用子域 |
| --- | --- | --- |
| `GoldbergPatch[7,2]` | “单扇区网格”只读参考保留 4 块三角形及原序号；单扇区是连通面网格，但原函数本身没有山谷赋型或平折结果。 | 没有足够证据把这一拼块列表直接升格为已验证平折候选。 |
| `GoldbergTiling[7,2]` | 原版模式 `m=7,n=2,o=0` 已生成 28 面连续母网格与 CP 候选；几何及局部条件通过。 | 已接入；局部通过不等于全局层序证明。 |
| `GoldbergOffsetTiling[8,2,1]` | 原版模式 `m=8,n=2,o=1` 已生成 32 面连续母网格与 CP 候选；上下半片有 3 条完全重合的单位接缝边，几何及局部条件通过。 | 已接入；无需再造第二个入口。 |

对偏移 `o`，每半片在 `y=0` 的边界长度为 `2n`；上下平移 `−o/2`、`+o/2`。由原版 `GoldbergOffsetTiling` 的平移公式直接得到，`m=8,n=2` 时 `o=4=2n` 的两片只在一个顶点相触，没有共用面边；`o=5` 的最近边界相距 1，原版线图末尾桥接线跨过没有三角面的空隙。这两种都不能作为单张连续二维纸面交给 CP／平折流程。`o=1/2` 虽有长度 3.5 的边界区间重叠，但上、下单位网格没有任何共同端点或整边；原拼块列表存在接缝 T 结点，当前面网格不能直接拼合，更没有该切分后山谷与层序的证据。

另核对 `o=-1`：`GoldbergOffsetTiling` 的拼块列表在几何上仍有 3 条共用整边；但后续原版 `MakeOffsetGoldbergTiling` 明确在 `o<0` 时发出 `badoff` 并中止。因此它不是已保存样例的原版线图／CP 子域，当前只读拼块参考保留该数值语义，不冒充原版可采用折痕。负偏移的可能新折痕构造需要另立来源定义和完整平折验证，不能由共边事实直接推出。

专项新增测试从逐块三角形坐标独立统计上下接缝整边、端点与区间交集，并重新生成两个已保存的完整候选；`backend/test_tessellation_goldberg.py` 23/23 通过。本轮未修改纸面门禁，也未新增缺乏全局平折证据的构造入口。

随后用产品当前默认扭转参数对这两个保存的**母结构**再生成折痕候选并跑完整平折管线：`(7,2,0)` 得到 CP 84/154/71，`(8,2,1)` 得到 CP 96/174/79；两者均几何／局部通过、逐面平折几何 `ready`，但层序约束传播均给出 `no-solution`。因此现在原版 Goldberg **扭转折痕**必须先取得整片层序 `solved` 才能“采用”；这两例当前扭转参数不可采用，原版的母结构排布仍可作为排布使用。回归脚本 `scripts/verify-goldberg-saved-layer.ts` 对这两例及采用门禁做跨后端、前端检查。这是工作区当前扭转赋型的结论，原版 In[3325]/In[3327] 仅保存排布输入，不能据此宣称原版排布不可平折。

生产构建浏览器实测 `m=7,n=2,o=0` 的扭转候选显示“几何通过／局部条件通过／层序无解”，同时“采用折痕副本”禁用；截图见 `output/playwright/p38-goldberg-unsolved-gate-live-20260927.png`。
