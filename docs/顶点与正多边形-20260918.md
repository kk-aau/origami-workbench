# 顶点与正多边形工具 · v0.5.0

当前工具数从 12 增至 15，非 Oriedita 全量完成。

## 使用方式

- 添加顶点：先选源线，再点击分点。鼠标／吸附位置投影至该有限线段，生成两个不同 ID 的小段，保留山谷、其他线型和未知折角。端点、线外及太短分段拒绝。与上游单击插点相比增加来源确认，避免误分割邻线。
- 合并顶点：点共线分点查看紫色预览，再点该点确认；必须恰好两条相连线段、共线且向相反方向、线型和折角完全相同。不同山谷／折角、T 形、交叉、折角与重叠均拒绝，不静默决定保留哪条线的属性。非同型合并变体仍未提供。
- 正多边形：设置整数边数 3–64 和方向，依次点击首边两个端点。第二点确认整个多边形，闭合边明确连接第一点，不依赖浮点累加回到原点。默认屏幕顺时针（Y 向下），支持逆时针。采用当前新绘制线型，包含边界类型；可画出纸外，不自动裁剪，后续诊断负责提示。

所有新工具支持紫色预览、中文分步说明、鼠标旁提示、右击／Esc 取消、切换工具取消、一次撤销和历史恢复。纸边保护禁止插点／合并纸边；正多边形不是修改已有边界的工具。顶点工具只改变分段，不改变实际线形。

## 数据与对照

- 复用原生工程 v2，无新增临时对象类型；保存和恢复保留真实线段与 ID，计算引擎继续使用正常折痕。
- Oriedita 1.1.3 固定提交 `0891f8e8133ddf3aba8c6ec8a2b1ef565a0ea86e` 的 `MouseHandlerDrawPoint`、`MouseHandlerDeletePoint`、`MouseHandlerPolygonSetNoCorners` 已读取。对齐几何含义；当前不是原应用逐项动态对照认证。
- 工具库对应 `DRAW_POINT_14`、`DELETE_POINT_15`、`POLYGON_SET_NO_CORNERS_29`，明确为基础可用。后续仍需跨类型合并、圆／反演、公理和其他高级构造。
- 多边形参数只在当前组件会话中保留，不作为项目设置持久化。上限 64 是本阶段明确限制；全局 1500 小段限制继续由原子提交校验，失败不得部分写入。
