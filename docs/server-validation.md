## 本轮修正

1. 增加受信任环境配置 `ZHEZHI_DATA_DIR`，默认仍为原来的 `workbench/data`。
2. Python stdout/stderr 使用流式 UTF-8 解码，避免多字节中文恰好跨 chunk 时破坏字符。
3. 超过 8 MB 的请求由 400 改为标准的 413，保留中文错误。
4. 保存／恢复接口收到 JSON null 时使用中文结构校验错误，不再暴露英文 TypeError。

## 验证边界

- 原子保存测试验证同目录临时文件 + rename 的正常及并发路径、备份与完整读取；没有断电、磁盘满、权限剥夺或硬件故障注入，不能据此承诺断电后一定持久化。
- 取消测试验证 HTTP 客户端中断和随后重试，不是完整操作系统进程压力测试。
- 测试范围为本机 HTTP 服务，未做公网部署审计；服务仅监听 127.0.0.1。
- 不把镶嵌生成或局部必要条件通过当作整体可折保证。
