# 文字注释工具交互

本轮补齐 TEXT(81) 的基本工作流，绘图入口由 82 增至 83；不是全工具完成。

## 使用

- 左侧“标记与文字 → 文字注释”。点击空白处创建，点击已有文字编辑。多行输入保留空行、空格和中文，Enter 换行，Ctrl+Enter 或“应用文字”提交。
- 草稿显示为紫色，不写入工程。Esc、右击或取消按钮放弃草稿；切换工具、替换工程、撤销引起文档变化也清除草稿。文字编辑期间须先应用或取消，不能误点另一处直接写入。
- 从已应用文字上按住拖动，紫色预览，松开提交移动；右击组合按键或 Esc 取消移动。点击采用实际 SVG 包围盒命中，重叠时选择锚点最近的文字。
- 空闲右击优先删除文字，未命中文字时维持通用删线。右键框选可同时删除文字与线段：向右完整包含，向左接触即可。边界保护仍限制线段删除。编辑面板也可直接删除该文字。
- 每次创建、修改、移动、删除均走工程撤销。文字不进入折叠图；原生 JSON 与恢复副本保留文字，SVG/PNG 采用多行布局，CP 等不支持对象的格式保持信息损失提示。

## 与上游及待验收事项

依据本地 MouseHandlerText、Text、TextEditingArea。当前字号使用世界毫米并随缩放，原版采用屏幕字体；为服从用户取消规则，采用显式应用草稿，而不是原版外点/ESC结束自动保存。右键框选继续用户既定方向规则，并保留通用删线，不照抄原版仅删除文字的模式。

不声称完整动态等价：真实系统中文输入法候选窗、原生颜色选取器焦点行为、特殊字体/空白旧文本命中、全量上游动态对照待继续。窗口失焦按现有 Canvas 取消规则丢弃临时草稿。窄窗面板可换行，工具按钮沿用已有宽度和四列规则。frontend-design 技能用于保持紧凑工程布局，未引入额外装饰框架。
