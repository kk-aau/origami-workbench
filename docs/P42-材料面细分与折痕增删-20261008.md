# 第42节材料面细分与折痕增删（2026-10-08）

完整复现目标继续 active。本批将材料拓扑编辑由切开/粘合扩展到实际增加和删除折痕，更新源码与网页；未重打包免安装 EXE。该入口编辑采用后的材料副本，不会将手工改动伪装成原参数重新生成的结果。

| 操作 | 实际行为 |
|---|---|
| 入口 | 有独立材料拓扑的工程进入“折痕编辑 → 纸张属性 → 编辑材料折痕”。普通几何工程继续使用原画线工具。 |
| 添加折痕 | 明确选择材料面、两端所属边、沿边比例、F/M/V/U与固定侧；在一个简单面内添加直线弦，原面细分成两面。端点可选已有角或精确沿边位置；共享边的两侧面同步更新角槽。可以重复细分构造相交线，不重复创建交点身份。 |
| 切口同步 | 同部件完全重合的切口对侧同步分点，保持独立顶点、B边身份及原FF，不建立跨切口铰链；预览明确显示同步边数。不同部件不会因坐标重合自动连接。 |
| 删除折痕 | 明确选择一条或多条内部材料折痕，合并相邻面；删除后无面引用的顶点清除。纸边与切口边不能被此操作删除。沿原边已有的有效分点保留，因此删除新增弦不意味着恢复旧顶点编号或消除所有边分点。 |
| 固定面与FF | 原固定面被细分时可选保持哪一侧；合并时由明确原面归属映射固定面。相容F编辑逐值保留旧FF；改变反射铰链时沿原固定面姿态重新传播，检查所有共享顶点、闭环及逐面等距。没有原FF时不虚构位置。 |
| 提交 | 中央提交独立重放面编辑意图，比对完整提案；失效或篡改提案不进入历史。撤销/重做恢复完整材料工程，旧平折模型过期后重新计算。 |
| 保存与交换 | JSON/FOLD保独立材料拓扑及CP/FF；实际下载重开后再平折通过。普通DXF沿用R12独立LINE、毫米尺度及一次Y轴转换。经典CP继承原格式限制，F/U明确拒绝；M例按“原始坐标”实际导出并回读一致，不能用经典CP替代完整材料工程保存。 |

可视化窗口使用毫米刻度，选中面紫色、新折痕青色，起终点有可拖动标记。除拖动外，提供边选择、比例滑条与精确百分比输入；缩放围绕当前端点，平移不改变源坐标，恢复全图保留参数。窄面两端重叠时当前端点优先响应拖动，起终文字分开排列。无效比例明确提示，参数修改立即使旧预览失效。1000×720和800×720的添加与删除窗口完整显示，无整体滚动；长删除列表自身滚动。
