# 折纸工坊 v0.13.36

本版减少大型 CP 计算和局部实色显示中的重复扫描、过度拆分及内存占用，并将完整作品自动暂存移入后台。

| 变更 | 行为与边界 |
| --- | --- |
| 大型层序提速 | 优化接触关系候选与三环检查，保留原有几何判定及完整合法性验证 |
| 局部实色显示 | 减少区域拆分和纸层排序开销，正背同显共享结果；未知或冲突区域仍保留诊断 |
| 计算预算 | 大型图案自动预算最长 180 秒，手动最长 600 秒；保留取消、超时和明确终态 |
| 多 CP 与选区 | 多个独立 CP 整页计算前提示框选，选区来源检查提速，修复取消后误报结果过期 |
| 自动暂存 | 后台执行完整作品序列化和校验，保留恢复副本与已有存档格式 |
| 大量线段显示 | 减少首次挂载中的额外扫描，保留全部线段及交互 |

纸面分区和可见边线统一使用显示精度内的坐标，避免微小舍入误差造成外边线丢失。计算结束后分别说明未确认遮挡、细小区域和边界可见性，避免显示“0 个区域未确认”却仍有警告的矛盾提示。

复杂图案仍可能只确认部分区域，应以界面的遮挡和边界诊断为准，不能仅凭出现实色判断全部成品已确认。“单条龙”包含 5 张独立 CP，所测第一张有 20,943 个面且包含真实凹面，仍超出当前大型凹面求解范围；程序明确结束并保留线框，这不表示已经证明无法平折。近 15 万条线的首次导入仍可能出现约 12 秒界面停顿。

本版未加入 GPU 加速，延长预算不保证任意大型图案都能完成。以上耗时来自本机样例验证，具体取决于图案和机器。

Windows x64 安装版与免安装版均包含完整离线引擎。下载所选类型的全部两个分卷，放在同一文件夹，用 7-Zip 打开 `.7z.001` 解压。更新前保存并正常关闭旧版，保留原数据目录。

对应源码以内容相同的 ZIP 和 7z 交付，并提供 SHA256 清单。打包、实包验收及版本归档遵循[打包与体积控制要求](打包与体积控制要求.md)；本机证据保存在 `output/release-0.13.36-20261026/`，最终记录区分本轮执行和沿用检查。
