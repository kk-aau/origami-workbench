# 第 45 节 `NFlattenGeneric2D` 的圆锥保存例

来源为用户提供的 `tmp/Origamica-15.0-reference.nb`：定义 In[3885]，313733–313876 行；保存的二维／三维图 In[3886]，313883–314002 行。原输入固定 `θ=30°`、`s∈[0,π]`、`v∈[-1,1]`、`σ=+1`、`bb(s)=(cosθ,-sinθ cos s,sinθ sin s)`、`dd(s)=-bb(s)`，平面初值 `{s,b,t}={0,(1,0),(0,1)}`。本文的所有数值坐标由这些保存公式推导；笔记本没有可机读的 Wolfram 数值顶点 Out。

## 从原函数恢复出的解析配对

记 `a=sinθ`、`c=cosθ`。原函数先设 `U=σ Normalize(bb′×dd)=(-a,-c cos s,c sin s)`，再由 Darboux 系统取得 `T=bb′/a=(0,sin s,cos s)`、`L=U×T=(-c,a cos s,-a sin s)=dd`。故原函数的两项母线投影是 `cρL=T·dd=0`、`sρL=L·dd=1`；源曲线速度 `ds=a`，测地曲率 `κg=(T′·L)/a=1`。`NRecoverCurve2DSystem` 在保存初值下得到

`b(s)=(cos(as),sin(as))`，`t(s)=(-sin(as),cos(as))`，`d(s)=-b(s)`。

两张对应面因而为 `X₂(s,v)=(1-v)(cos(as),sin(as))` 与 `X₃(s,v)=(1-v)(c,-a cos s,a sin s)`。二者的第一基本形式相同：`E=a²(1-v)², F=0, G=1`，行列式 `a²(1-v)²`。在此受限角度域 `a>0`，所以**恰在 `v<1` 正则**；`v=1` 时所有参数线汇于二维原点／三维锥顶，面参数退化。包含锥顶只为如原图显示边界，不能把它说成正则点、折痕、可制造尖角或已检验部署。两面都可展；这是连续曲面内蕴等距，不是采样折线／三角面逐边精确等距。

## 产品有界范围

专用 `POST /api/tessellation/curved-generic-cone-flatten` 只接受 `family=generic-cone-flatten-in3886`、锥半角 15–60°、曲线 16–256 段、母线 2–16 段、末端 `v∈[0.2,1]`；起端保持 `v=-1`，`s` 保持 `[0,π]`。默认 30° 与 `v=1` 对应保存输入；其他角度或截短的母线明确属于**本地同族推演**。任意 Mathematica 函数、NDSolve 选项、端点外区域、锥点作为原始曲线、一般可展面都不在范围内。普通 `/api/tessellate` 候选操作不接受该只读查询。

工作区「空间构造 → 圆锥通用展开 · 只读」显示配对二维扇区和三维圆锥正交投影、原版基线、对应母线和锥顶。锥角、母线末端、采样密度与三维视角可调；单一闭合带面路径避免多子路径透明穿透。前端严格回读请求参数、原版单元、初值、第一基本形式、锥顶奇异标志、每个二维／三维对应点和不可采用标志。它不写入现行构造、折痕工程或平折画布。

`sampledSurfaceExactFOLD=false`、`adoptableCreasePattern=false`、`deploymentPathChecked=false`、`selfIntersectionChecked=false` 是固定的工程边界；不提供精确直折痕 FOLD、全局无碰撞或连续运动证明。
