# 共线／横截交替山谷界面

2026-09-18，v0.9.2 未打包；新增 alternatecollinear、alternatecross，实际工具 66 项。目录仅 34／36 标基础可用，上游动态对照仍待验。

- 共线模式：已有端点／交点、圆心、显示网格点起终笔。横截模式允许自由起终点与普通吸附。均可两击或左键拖放。
- 紫色参考、整段命中覆盖及“序号·目标线型”文字预览。首型来自当前绘制预设；改预设立即更新顺序，保留已点起点。非山谷预设明确提示统一赋型，不强行交替。
- 松开或第二次点击提交；共线无效终点保留起点重选，右击／Esc取消，空闲右击通用删线。命中未改变线型时不写历史，边界保护过滤 B，山谷改型保留角度大小、0/null。
- 共用受限点 helper 从 restrictedErasePoint 改名 restrictedReferencePoint，加入 alternate 独立手势分支，未借用删除命中判定。横截交替不套用删除工具 Ctrl 角约束。
