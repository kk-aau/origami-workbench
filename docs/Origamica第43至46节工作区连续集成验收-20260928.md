# 第 43–46 节工作区连续集成验收（2026-09-28）

本轮在实际 Chromium 浏览器连续切换镶嵌工作区中的历史只读入口。验收对象是**入口集成和布局**，不把只读曲面示意提升为可采用折痕或精确 FOLD，也不替代各保存例的源式/数值专项。

原有应用主布局设有 `min-width:800px`，因此 390 像素视口的底层工作区本来会横向滚动；本轮只读弹窗没有增加页面宽度或改变滚动位置。移动视口内，较长内容只在弹窗内部纵向滚动，光学、近恒宽、规范柱／锥面和均匀螺旋「形状函数」视图的底部说明与关闭按钮均可到达。均匀螺旋「形状函数」四图在双视口均实际切换、截图核对。桌面视口的 27 个弹窗没有纵向溢出。新增「规范切线／一般可展面」与「三叶结局部曲折」也在最新 27 个入口中。

发现并修复的实际问题：光学六例与近恒宽弹窗共用的移动端布局把左侧参数栏按剩余高度压缩，却允许参数内容溢出，造成下方结果标题重叠。`CurvedConicOpticalDialog.css` 的移动断点改为自然高度垂直堆叠、弹窗自身滚动，并给图形区固定移动端高度；桌面断点保持原样。修复后两例的顶部、底部截图均肉眼复核。

跨弹窗还验证：光学 In[4025]/位置 96、近恒宽 In[3875]/位置 96、平面镜像圆柱例、Flasher Z 变体在关闭重开后分别复位为入口默认值；切换这些只读参数没有修改当前构造家族。P43 径向壶体 In[3483] 与矩形壶体 In[3489]/In[3506]、P44 矩形管 In[3588]/[3589] 是刻意载入保存输入的可编辑入口。前两者的选择器数值均可读回且无校验错误；矩形管参数读回为 `twist-joined-tube`、拼接搭片开启、截面高度差 0.95。
