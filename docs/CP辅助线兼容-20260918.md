# CP 辅助线兼容（开发版 v0.9.2，未打包）

按用户要求，CP 类型 4 在工作台识别为辅助线 A，不参与折叠计算；辅助线导出 CP 也使用 4。

| CP 类型 | 工作台类型 | 再次导出 CP |
| --- | --- | --- |
| 1 | 边界 B | 1 |
| 2 | 山折 M | 2 |
| 3 | 谷折 V | 3 |
| 4 | 辅助 A，折角 0 | 4 |
| 0（旧文件兼容） | 辅助 A，折角 0 | 4 |

CP 和 OPX 使用独立映射，OPX 辅助线仍为 0，不接受 OPX 类型 4。原生工程及 FOLD 的平面边 F 保持原义，不统一转换成辅助线；导出 CP 遇到 F／U 仍明确提示不支持，不静默改型。未知类型、非有限坐标继续校验，并保留原始行号。
