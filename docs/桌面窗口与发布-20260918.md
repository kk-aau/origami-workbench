# 桌面窗口与 Windows 发布

本文保留初版实现及历史验证记录。后续打包必须遵循[打包与体积控制要求](打包与体积控制要求.md)，历史包名及验收数量不代表当前版本。

## 实现

保留现有绘图界面和四工作区，使用 Electron 44.4.2 的独立 BrowserWindow 承载，无浏览器地址栏/标签栏，原生最小化、最大化、关闭与中文文件菜单。未重做绘图交互。

独立 utilityProcess 运行现有本地服务，绑定 127.0.0.1 的系统分配端口，不抢占旧 8787。窗口确认关闭后服务正常结束并等待工程写盘。未保存关闭提示默认返回编辑。renderer 不开放 Node、启用 sandbox/contextIsolation、限制导航和外部网络；预加载仅开放固定菜单通知及打印接口，打印 IPC 验证主 frame。

PyInstaller 6.22.0 将镶嵌后端和 Python/数值依赖封装，生产包不使用开发机 .venv 路径。计算仍真实执行，不使用预生成结果。渲染资源和后端均随包离线提供。

依据：[Electron 安全建议](https://www.electronjs.org/docs/latest/tutorial/security)、[UtilityProcess](https://www.electronjs.org/docs/latest/api/utility-process)、[NSIS 与 portable](https://www.electron.build/v26/docs/nsis/)、[PyInstaller 运行路径](https://www.pyinstaller.org/en/stable/runtime-information.html)。

## 两种交付

- 安装版：`release/Zhezhi-Workbench-0.2.0-Setup-x64.exe`。非强制一键，当前用户安装，可选目录；没有自动运行安装或更改本机安装状态。
- 免安装：`release/Zhezhi-Workbench-0.2.0-Portable-x64.exe`。双击展开内置环境并打开应用；旁边“折纸工坊数据”目录保存 profile、工程与恢复稿。
- `release/win-unpacked` 是未压缩的完整运行目录，不能只复制其中 EXE。单文件 portable 不受这个限制。
- 旧 `启动折纸工坊.cmd` 无参数时优先桌面；新增明确的桌面/浏览器双入口。旧网页不关闭、不刷新。
- 安装版、便携版、旧网页版工程库隔离，不静默搬移原作；通过完整 JSON 导出/打开迁移。帮助菜单可打开当前工程目录。

## 验证与限制

开发态桌面 13 项检查通过：隔离桥接、sandbox、私有服务、封装后端、原生保存/导出、v2 落盘、平折 worker、三维 backend、未保存取消关闭、恢复稿重开等。初版未压缩生产包和便携 EXE 各 10 项检查通过，并将 PATH 限制为 Windows System32，验证未调用系统 Node/Python。最终带图标生产包的补充验证结果记录在任务续接记录与 `output/desktop`。

既有 141 单元测试、9 服务测试通过。原端口 8787 保持可用，已结束的测试端口无监听残留。

尚未签名，Windows 可能提示未知发布者，不要求用户绕过或关闭安全防护。未在干净 Windows 虚拟机、真实打印机上验证；安装向导已生成但未执行系统安装。此发布只是桌面测试版，不代表 Oriedita 全工具完成。应用基础和安全更新需随版本重新打包。

当前对应源码同时生成常规 ZIP 与 solid 7z；随包 `resources/source` 只保留完整 7z、许可证和构建材料，外发另附相同内容的 ZIP／7z 及版本化 SHA256 清单。不包含用户 data、.venv 或工作区私有工程；具体流程以上述现行规范为准。
