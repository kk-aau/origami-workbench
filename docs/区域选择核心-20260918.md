# 区域选择核心（尚未接界面）

本轮针对上游模式66/67、68/69、74/75核对并实现共用几何核心。当前仍51项可用工具，不将此核心计算计为用户可用入口。

源码依据：Select/UnselectPolygon、Select/UnselectLineIntersecting、Select/UnselectLasso六个处理器，BaseMouseHandlerPolygon/Lasso，以及FoldLineSet.select_Takakukei/select_lX/select_lasso、Polygon.inside_outside_check/inside、OritaCalc.isSegmentContainedInGeneralPath。交叉选择进一步核对LineSegment.Intersection.isSegmentOverlapping。

规则：

- 多边形使用奇偶填充，选择全部位于内部或边界上的完整线段，不选穿出区域的段。不能仅检查两端；沿轮廓全部交点分区，再检查每段中点。
- 自由套索使用非零环绕填充，要求两端及整段在内部且不接触轮廓。自由拖画的隐式闭合边也参与校验。自重叠路径不因带符号面积抵消为零而被误判退化。
- 划线选取命中真正X相交或正长度共线重叠，不包含T形接触、共享端点或只在参考线延长线上相交。
- 选取为集合追加、撤选为集合移除，不是切换状态，不修改线段或作品历史；保护边界时排除B，辅助线仍可选。

API位于 `src/app/selectionRegions.ts`：segmentsInSelectionRegion、segmentsCrossingSelectionLine、updateRegionSelection。异常轮廓、非有限坐标和过短参考线提供中文错误。所有输出均为独立Set，原作品及选区不变。

9项新增测试，全量408项通过；构建通过，已有主包大小警告不变。本轮未开测试服务、未动用户作品、未打包。尚未接入六种选择入口、自由拖画、闭合按钮、预览和右键取消，不能宣称交互已完成或原版动态等价验收通过。

上游GeneralPath的边界判定有Java实现细节，其helper遍历时跳过SEG_CLOSE；本实现明确统一为不接触完整闭合轮廓，后续动态对照需记录差异，不能笼统声称完全同版。
