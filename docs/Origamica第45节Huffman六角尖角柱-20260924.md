圆版平面折线由原式给出：`f0=(0,0)`、`f1=(cos t,sin t)`、`f2=(4 cos q−2,4 sin q)`、`f3=(2,4 sin q)`。第二圆中心 `(-2,0)`，半径 4。连接 `f1→f2` 的单位母线是两点差的归一化；平面第三母线沿 `+x`。在 `q=0` 的端区，平面第二、第三折痕重合，这是源几何的退化边界。

## 等距能证明到哪里

把 `Δ=f2−f1=aT+bL` 分解到单位圆的平面切向 `T` 和左法向 `L`，有

```text
a = 2 sin t − 4 sin(t−q)
b = 1 + 2 cos t − 4 cos(t−q)
γ1′ = a tan(γ1/2) / b
```

原版第一折痕的左 Darboux 曲线满足 `F′=T₃`、`T₃′=L₃−tan(γ1/2)U₃`、`L₃′=−T₃`、`U₃′=tan(γ1/2)T₃`，初值为 `F=(1,0,0)`、`T₃=(0,0,1)`、`L₃=(−1,0,0)`、`U₃=(0,−1,0)`。因此 `F=−L₃`、`|F|=1`，第一片圆锥与从原点到平面单位圆的扇形具有相同第一基本形式。

第一折痕右侧横向 `Lᵣ=cosγ1 L₃−sinγ1 U₃`。由 Darboux 方程可得 `T₃′=Lᵣ+tan(γ1/2)Uᵣ`、`Lᵣ′=−T₃−γ1′Uᵣ`。三维连接矢量 `aT₃+bLᵣ` 的导数中，法向系数为 `a tan(γ1/2)−bγ1′=0`，其余两个切面系数与平面连接矢量导数相同。因此第一与第二折痕之间这片直纹面的连续 `E,F,G` 与平面一致。这是方程层面的恒等式；数值网格的弦长本身不逐边精确相等。

第二折痕右侧在原版使用常量三维圆柱母线方向：先在 `(ti1+ti2)/2` 用 `γ2` 和第二折痕 Darboux 框架求方向，再将此方向固定到所有 `t`。本地算出的活动段瞬时方向与这个固定方向差约 `10^-10`，属于**数值证据**。尚无针对全部有效参数的符号证明、奇点全域证明或与原版机器结果的逐点比较。

更直接的整块不等距反例来自 In[4070] 337913–337933 行：

```text
flat distance(f2,f3) = 4(1−cos q)
source spatial ruling length = 4(1−cos q) + 10^-6
```

原版注释明确称这段偏移用于避免零长线。故在 `q=0`，平面第三片退化为零宽，三维却仍有 `10^-6` 宽；在其他位置第三片的直纹向度量 `G` 也不同。即使画面难以察觉，不能声称整块 CP 与三维面精确等距。对镜拼接只做刚体半转，不会消除该差异。全局不自交、连续部署、厚纸与制造也均未认证。

## 独立只读复现

`backend/tessellation_huffman_column.py` 使用保存的三条 ODE、Darboux 初值、四个闭合方程和第三母线偏移。`Circle4Audit.frame(t)` 返回对应的 `f0..f3` 与 `ff0..ff3`；`sample(25)` 给绘图边界和 25 分段；`paired_sample(25)` 加上两种半转展示坐标。它们只用于审计，不定义精确直折痕 FOLD、有效裁切、折叠路径或可制造实体。

```python
from tessellation_huffman_column import solve_saved_circle4_closure

model = solve_saved_circle4_closure()  # 仅搜索 In[4071] 初猜附近的数值根
print(model.closure_residuals())
print(model.paired_sample(25)[0])  # 绘图边界数据；非原版保存 Out
```

本地 SciPy 求得的**独立数值解**约为 `(38.72794743°,80.39502465°,82.11258052°,-63.36130120°)`，四个闭合残差均小于 `3×10^-10`。它不是从原版 `HCwCCircle4Parms` 读取，不能据此推断原版 `FindRoot` 的最终数值、根的唯一性或三维图像逐点一致。原版 `NDSolve`、`NRecoverDarboux3D` 和 `FunctionInterpolationAlt` 的求解／插值策略也没有机器级对齐。

运行 `cd backend; ..\.venv\Scripts\python.exe -m unittest test_tessellation_huffman_column -q`：6 项通过。测试覆盖保存的几何锚点和四个闭合条件、用独立有限差分比较中间直纹面的 `E,F,G`、首片锥面半径和中间连接长度、圆柱方向的数值恒定、对镜刚体长度保持，以及第三母线逐点 `10^-6` 差。结论保持**只读、不可采用**，除非有可机器比较的原版数值输出且先修复并重新证明完整曲面的精确等距。
