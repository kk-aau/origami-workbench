# 三点反射线（开发版 v0.9.2，未打包）

## 新增：两线反射线

当前 32 个实际工具。入口“镜像 / 变换 → 两线反射线”：点击原线段，再点镜面轴，最后选截止线段或纸边。

以两条支撑直线的交点为起点，即使交点位于原有限段之外也允许。原方向指向原线较远端点；两端等距时取 x 较小、再 y 较小的端点，颠倒数据中的端点顺序不改变结果。第二条线为反射轴。两参考线不得平行、重合、过短，异常时保留第一条供重试。

选完两线仅预览，第三次选择实际截止线才生成新线，采用当前新绘制线型和默认折角；原线型与折角不变。仅选一条参考线时右击也只取消不删除。中键平移保留构造，切换工具／Esc 清空；真实交点分割与新线一起撤销，支持保存恢复。

两线入口已实现，但自动延长、横截及连续反射仍未齐，下方为三点入口的历史记录。最新验证：284 单元、21 项两线＋25 项三点＋98 项旧交互浏览器检查通过；生产构建通过。本次未打包。

## 三点入口

入口：左侧“镜像 / 变换 → 三点反射线”。当前实际工具 31 项。

1. 点击被反射的方向点 A。
2. 点击起点 V，也是镜面轴上的一点。
3. 点击镜面轴另一点 B，轴为 V–B。
4. 点击紫色反射方向上的实际线段或纸边作为截止线。

结果从 V 出发，方向为 V→A 关于轴 V–B 的反射方向。终点取射线与所选有限线段的真实交点，不使用第四次鼠标点击坐标。前三次点击只提供紫色参考，不写入工程；最终线采用当前新绘制线型及默认折角，不复制参考线线型。边界保护不禁止以纸边作截止参考。

重合点、轴上方向点、反方向截止、仅延长线相交或平行目标会拒绝，并保留已选有效步骤供重试。右击／Esc 取消；换工具和修改几何会清空构造；改变绘制线型不清空。新线与交点实际分割一起撤销，可保存恢复。未提供连续反射、两线输入及自动延长变体，不冒称完整覆盖 Oriedita 模式 10。

依据：本地固定 Oriedita 源码 MouseHandlerSymmetricDraw.java 三点分支，将第一点对第二／第三点轴反射，从第二点生成线。本产品增加用户指定的截止选择。

验证：新增 7 项几何单测，全部 279 项单元通过；25 项新增浏览器交互检查、98 项原有交互回归通过。生产构建通过，保留既有主包体积警告；浏览器控制台零错误／警告。截图 output/playwright/reflection-preview.png。本轮未打包或执行新 EXE 验收。
