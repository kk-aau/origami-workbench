# 十字标记与射线工具

| 修改 | 当前行为 |
| --- | --- |
| 十字外观 | 缩为 12×12 屏幕像素，4 像素粗臂、单层实心、60% 不透明度；保留深绿 CP 与暖橙结果两种颜色 |
| 中键落点 | 点击哪里标记就出现在哪里；结果落点按模型原坐标保存到当前会话，翻面、旋转、缩放和平移时跟随结果 |
| CP 拖动 | 按用户最新要求暂缓独立拖动，维持原共享画布整体平移；撤除本轮未接入的场景辅助代码 |
| 射线 | 原“受限线”改名“射线”：起点 → 第二点确定前进方向 → 点击前方已有线段，以真实交点为终点 |
| 无效目标 | 空白、后方、平行、共线或只与目标延长线相交时明确提示，保留前两点以便重新选择；Esc 取消 |
| 绘制属性 | 采用当前折线类型、目标角与预览样式，遵守边界保护；提交沿用现有工程操作，可一次撤销 |

射线保留原工具 ID 与 `RL` 快捷键，原受限圆保持现有行为。目标为用户实际选择的有限线段，不自动换成更近的交点，也不延长作为截止参考的线段。

原始／最终源码 SHA256、射线几何测试、标记验证、开发构建与实际交互证据位于 `output/canvas-cp-drag-markers-20261028/`。取消的 CP 场景辅助文件证据保留在 `output/canvas-cp-scene-20261028/`，未进入应用。

本轮仅修改迁移版开发源码与开发构建，不打包、不上传、不修改原项目；最终验收以本轮 `result.json` 为准。
