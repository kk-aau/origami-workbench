# Origamica 第 45 节：零扰动同心圆四带子域

原版第 45 节在 `tmp/Origamica-15.0-reference.nb` 第 339070–340310 行保存了五条同心圆的构造输入，没有可机读的三维数值 `Out`。保存例取 `q₁(s)=s+0.1 sin(2s)`；工作区保留这一输入的首带只读视图，不能认证其后四折整串，原因见 `Origamica第45节关联多曲折保存示例审计-20260924.md`。

新增的“零扰动子域 · 四带”明确把 `q₁` 的扰动改为 `0`。此时 `qᵢ(s)=s`，二维带界为 `fᵢ(s)=(1+0.1i)(cos s,sin s)`，`i=0…4`、`0≤s≤π`。原版各次折角公式在这个子域给出 `+120°、−120°、+120°、−120°`，原保存例的公共参数／自身参数冲突也在此消失。它是原公式的一项精确可证子域，**不是原保存图的完整复现**。

首条三维折痕的 Darboux 标架有闭式解。初始 `T₀=(0,1,0)`、`L₀=(−1,0,0)`、`N₀=(0,0,1)`；设 `A=L₀+√3N₀`，则 `T(s)=T₀ cos(2s)+A sin(2s)/2`，`B(s)=T₀ sin(2s)/2+A(1−cos(2s))/4`，`F₀=(1,0,0)+B`，`L=L₀−B`，`N=N₀−√3B`。两种交替母线方向是 `U₀=L` 和 `U₁=−L/2+√3N/2`，都满足 `U′=−T`；令 `Fᵢ₊₁=Fᵢ−0.1Uᵢ`。因此相邻四带的空间参数化 `Xᵢ(s,v)=Fᵢ(s)−0.1vUᵢ(s)` 满足 `Xₛ=(1+0.1i+0.1v)T`、`Xᵥ=−0.1Uᵢ`，第一基本形式 `E=(1+0.1i+0.1v)²`、`F=0`、`G=0.01`，与对应二维同心圆环带一致。最小半径为 `1`，局部参数化正则；四带沿 `Fᵢ` 共享边界，组成一张连续纸。

但 `Fᵢ(0)=Fᵢ(π)`，而二维纸的两端边界不同，故三维表示有端边接触，不能声称全局嵌入；全局层序、自碰撞和连续展开路径均未核查。UI 仅提供二维／三维正交投影，只读，不产生精确直折痕 FOLD，不采用到工程。后端返回明确的 `boundaryEndContact=true`、`globalLayerOrderChecked=false`、`adoptableCreasePattern=false`，前端严格校验这些标记。
