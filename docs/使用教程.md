# 折纸工坊使用教程

本教程对应当前源码版。软件右上角 **帮助与版本 → 使用教程** 提供相同主题的分章阅读入口，可点击“展开完整教程”。

## 第一次画一个简单作品

| 步骤 | 操作 | 应看到的结果 |
|---|---|---|
| 1 | 打开“工程库”，选择“空白纸张” | 200×200 mm 的纸张与黑色边界 |
| 2 | 选择“线段”，选择“山折”；CAD开启时输入 L 再按 Enter，关闭时按默认快捷键 L | 后续新线采用山折类型 |
| 3 | 点纸张上边中点，再点下边中点；也可左键拖画 | 一条山折，端点与网格或边界对齐 |
| 4 | 切换“选择”，点选这条线，再打开“选区”；CAD开启时输入 V 再按 Enter，关闭时按默认快捷键 V | 可改已有线的类型、目标角和坐标 |
| 5 | Ctrl+S 或“保存折痕” | 折痕文档进入本机工程库 |
| 6 | “保存完整作品” | 下载 .zhezhi-artwork.json，集中保存当前各工作区内容 |
| 7 | 切到“三维模拟”，载入当前折痕，再缓慢增加目标比例 | 当前折痕的数值折叠预览 |

有未保存作品时，新建或打开文件会提示替换；先保存需要保留的内容。

## 保存完整作品与独立文档

| 入口 | 保存范围 | 再次打开 |
|---|---|---|
| 保存折痕 | 当前折痕、纸张、辅助对象、底图与已有元数据 | 折痕文档库 |
| 保存折序工程 | 当前绘图的步骤、各步 CP、纸层状态、符号和图片 | 折序文档库 |
| 保存完整作品 | 当前折痕、镶嵌／曲面构造参数、模型集合、当前折序、三维姿态与固定点、材质参数和观察方向 | “打开文件”选择 `.zhezhi-artwork.json`；折序工作区也有“打开完整作品” |

完整作品以独立文件下载，保存后请确认文件已落盘。它不更改各文档库的独立保存标记。导航栏“作品总览”可查看各工作区内容与来源，并管理完整作品的本机恢复副本：修改后约 2 秒自动暂存，持续模拟每 20 秒更新；正在旋转或塑形时等待手势结束，不打断操作。未采用到 CP 的镶嵌／曲面参数也包含在内。

每个窗口、每次切换作品使用独立恢复记录，恢复旧副本后写入新记录；失败不覆盖上一次成功内容，也不自动淘汰其他窗口副本。恢复副本不设固定单份大小或目录总量上限；可在总览中删除不需要的旧副本，或下载完整作品备份。突然退出可能丢失尚未暂存的操作，下载文件适合额外留档。

模型、折序与三维保留各自计算时的源折痕，因此当前 CP 修改后仍能保存之前的结果。完整作品不包含撤销历史和已验证层序证书：重新打开后历史从此处开始，模型层序需重新分析，三维保持暂停。旧 `.zhezhi.json`、模型集合和折序文件仍可按原入口打开。

普通线段与辅助圆支持混合 Ctrl+C／X／V，粘贴或剪切作为一次撤销。隐藏对象和受保护边界不参与剪切。完整材料部件有独立构造与拓扑；与圆混选时会提示分别复制，不静默丢失对象。

三维底部显示实际折角相对目标角的最大偏差，右侧还提供平均偏差。速度暂稳仅描述运动状态，不能代替达到目标、无碰撞或可制造性判断。未赋型 U 折痕没有驱动目标，不计入角度偏差；步骤轨迹无法可靠比较时明确标注不可用。

## 绘图、选区与构造

| 任务 | 做法 |
|---|---|
| 画线 | 先选新线类型，再点击起点和终点，或拖画后松开；吸附命中网格、端点和真实交点 |
| 修改已有线 | 用“选择”命中线段，打开“选区”修改属性；顶部新线类型不替代选区属性 |
| 平移 / 缩放画布 | 滚轮缩放；按住滚轮或空格拖动平移 |
| 多选 / 删除 | 默认 Shift 多选；Delete 删除所选。边界保护开启时边界受到保护 |
| 辅助线选择 / 删除 | 切到“选择”可点选或框选辅助线；空闲时右键点删。右键向右拖要求整条小段包含在框内，向左拖可删除与框相交的小段；隐藏图层不参与画布选择和删除 |
| 辅助圆选择 / 删除 | “选择”工具点击圆周，Shift 多选，空白处框选完整圆；可按 Delete、“删除所选”或右键点击圆周删除。右键向右框住完整圆，向左框碰到圆周即可删除整圆；圆内未碰圆周的小框不删除圆 |
| 撤销 / 取消 | Ctrl+Z 撤销已提交修改；Ctrl+Y 重做；Esc 取消正在进行的操作 |
| 查找工具 | Ctrl+K 打开工具目录，按名称搜索；画布说明提示当前取点步骤 |
| 隐藏操作提示 | 顶部“显示设置 → 操作提示”可分别关闭顶部操作说明和鼠标旁提示，再点“保存显示设置”；关闭后仍保留工具参数、确认按钮和错误信息 |
| 输入工具命令 | CAD默认开启；在画布键入英文字母，底部命令框接收命令，按 Enter 切换工具，再按原步骤取点 |
| 角平分 | 角边点 → 顶点 → 另一角边点 → 截止线。截止线不是任意鼠标终点 |
| 兔耳 | 三角形第一点 → 第二点 → 第三点 → “确认兔耳构造”或结果线 |
| 自由补线 | 在适用的已有顶点起笔，选候选方向与终点；补线按邻接折痕匹配山谷 |
| 共线交替 | 从第一点朝第二点指定范围，以方向上遇到的第一条原线为起始赋型 |
| 镜像、复制、旋转 | 先选要操作的线，再使用相应变换工具；也可在“选区”输入参数 |

取点或构造参考与结果预览用不同颜色表示。以每个工具的当前步骤和确认按钮为准，未确认的预览不是已保存折线。

工具参数和操作说明悬浮在画布上方，步骤增加、候选出现或文字换行时不改变画布的位置与缩放。参数较多时，可在参数区域滚动查看；在画布上滚轮仍用于缩放。

普通画线、受限画线及角度、反射、兔耳、鱼骨等构造遇到共线重合时，重合部分采用新线的线型与折角，旧线未覆盖部分保留，整次操作可撤销。边界保护开启时仍不能覆盖纸边。

平折结果显示在同一画布时，“绘图工具”将鼠标操作交给折痕画布，辅助线即使与模型重叠也可选择、删除；需要选择或拖动平折模型时，切到“平折参数”。点击绘图工具或执行工具命令会回到折痕编辑。已有起点或构造步骤时，第一次右键先取消当前操作，再次右键才删除。

辅助线默认以实线显示，可在“显示设置 → 折痕显示设置 → 辅助线样式”切换为虚线。此选项同步用于画布、导出和打印，只改变外观，不改变辅助线类型或折叠计算。

辅助圆属于独立辅助对象，仍保持完整圆，不切分成折痕；纸张外的圆也可选择、删除和撤销。选中后可拖动圆，或点击右侧“圆属性”进入圆编辑，修改圆心、半径与颜色。“图层 → 辅助线”同时控制辅助线和圆的显隐，隐藏圆不参与画布拾取；圆仍不参与折叠计算。

折痕编辑与折序的 CP 编辑采用相同的圆选择、拖动和删除规则。Ctrl+A 选择当前可见、可编辑的线和圆；Ctrl+Shift+A 取消全选。Delete 不删除隐藏对象或重新受保护的边界。Esc 优先取消当前绘制手势，空闲时清除选区。两个工作区继续使用各自的撤销历史。

点击“检查折痕”后，全部错误线段和出错顶点默认以红色高亮。点击检查列表中的某一项，只查看该项对应的位置；“全部错误”恢复总览。局部 cAMV 检查采用相同方式。修改工程后旧检查会标为过期并撤下高亮，需重新检查；收起结果也会清除诊断高亮。

## 工具命令（CAD）

折痕编辑画布默认开启直接键入命令。在画布输入 `L`，焦点进入底部命令框；继续输入完整命令，再按 **Enter** 启动工具。输入字母本身不会立即切换工具。命令框也接受中文工具名、完整工具 ID、大小写及全角字符，共覆盖93个已有工具、142条别名。

| 操作 | 行为 |
|---|---|
| `L` → Enter | 切到线段，再按原步骤点起点、终点 |
| `CO` → Enter | 切到两点复制，再按工具提示选择折痕和基准点 |
| ↑ / ↓ | 选择匹配候选，Enter确认 |
| Tab | 补全候选的主命令，Enter确认 |
| 点击候选 | 直接启动所点工具 |
| 命令输入中按 Esc | 取消这次命令输入，保留当前选区 |
| 设置 → 命令编辑 → 关闭“画布直接键入命令”，保存并应用 | 恢复原有单字母快捷键；命令框仍可点击输入 |

画布的Ctrl组合快捷键与1／2山谷快捷键按现有设置使用。命令只切换已有工具；坐标、参数和取点仍使用原工具界面。常用缩写及完整表见[CAD工具命令说明](CAD工具命令-20261014.md)。

## 纸张、网格和底图

清空选区后打开“纸张属性”。宽度、高度输入完成后按 Enter 或移开焦点应用；该方向的几何随尺寸缩放，可撤销。有圆的工程会拒绝单向拉伸，以免把圆暗中变成椭圆。

网格以实际黑色边界的包围盒为基准，宽、高分别等分。例如 200×100 mm、8 等分时，横向格距为25 mm，纵向为12.5 mm。把尺寸改成320×120 mm后，格距更新为40×15 mm。已有格点上的折线与新网格继续对齐。

| 控件 | 用途 |
|---|---|
| 网格等分、÷2、×2 | 调整参考网格密度 |
| 纸内网格 / 全画布 / 关闭 | 调整网格显示范围 |
| 对角线 | 显示单元对角参考，不单独增加吸附点 |
| 吸附 | 控制绘图取点；与网格显示是不同设置 |
| 显示设置 → 网格外观 | 修改颜色、线宽、默认等分和缩小后隐藏过密网格的阈值 |
| 底图 | 导入参考图片，配置透明度、跟随状态和配准；它不是网格层 |

L1/L2 的“格”单位按测量时的横向格距计算，并保留毫米读数；更改网格不会重新解释旧测量值。网格过密被隐藏时，放大画布再使用依赖可见网格的工具。

## 与原工具交换 CP

打开“导出作品”，选择 CP。

| CP 坐标选项 | 适用情形 |
|---|---|
| **对齐原工具网格**（默认） | 导出副本按纸边居中，最长边等比缩放到400；正方形落在−200到200，与原工具默认纸张和网格一致 |
| 保留原始坐标 | 对方已有对应毫米坐标或参考系；接收工具的网格位置和格距需自行匹配 |

两种方式都不改变本工程。非正方形保持宽高比例，不会为填满正方形而拉伸；对方若仍使用正方形网格，需要调整其网格比例。CP 本身不保存网格设置、单位、纸张尺寸字段、底图、圆、文字、目标角或生成参数。需要毫米尺寸和完整编辑数据时，同时保存完整工程 JSON。

CP 线型：1边界、2山折、3谷折、4辅助。辅助线不会参与纸面划分。U未指派或F平面边不能无损写成这些 CP 类型，需先明确处理或改用 FOLD / 完整工程。

| 格式 | 主要用途 |
|---|---|
| .zhezhi-artwork.json | 各工作区的完整作品备份与恢复 |
| .zhezhi.json | 独立折痕工程备份与再次编辑 |
| CP | 经典折痕几何交换 |
| FOLD | 二维折痕拓扑、山谷与目标角交换；不是任意三维多帧无损编辑 |
| ORI | 与 Oriedita 交换其支持的折痕、圆、标记和文字 |
| OPX | 与 ORIPA 交换折痕 |
| SVG / PNG / JPG | 出图；SVG可按毫米尺寸打印 |

FOLD 导出可由 Oriedita 直接打开。标准字段保存折痕几何、山谷与目标折角；辅助线、纸张尺寸、来源参数及材料拓扑保存在 `zhezhi:workbench` 扩展中，工坊重新打开时恢复，其他软件可能忽略这些扩展。材料切口的独立顶点、孔洞与折后帧仍完整保留；旧版工坊导出的 FOLD 也可继续读取。

“打开文件”替换当前工程；“追加导入折痕”只加入线段，不覆盖当前纸张或底图，也不自动缩放。追加前检查两个作品的坐标系。

## 镶嵌设计

选择构造类型后，拖动滑条或输入数值调参并观察实时预览。参数改变后的完整检查尚未完成或报错时，先修正参数；不要把旧结果当成当前参数的可折性结论。检查通过后使用“采用折痕副本”，再在编辑区手工调整与分析。完整工程可保存可用的构造来源参数；CP只保留最终线段。

## 三维模拟

| 操作 | 行为 |
|---|---|
| 载入当前折痕 | 将当前工程副本送入求解器；改折痕后需重新载入 |
| 目标折叠滑条 / 数字框 | 修改目标比例，逐渐增加以观察状态 |
| 拖动画布 / 滚轮 | 旋转视角 / 缩放，不修改模拟顶点 |
| Shift+拖顶点 / 顶点塑形 | 悬停出现亮点后拖动；松手后清除拖动速度，恢复拖动前的运行或暂停状态。未设置固定点时纸面居中；有固定点时保持锚定位置。塑形模式下空白处不旋转 |
| 固定点 / 解除全部 | 点击可见顶点固定，再次点击解除；固定点以方形标记显示。使用 Euler 积分，切到顶点塑形后拖动其他点 |
| 三维撤销 / 重做 | 按钮、Ctrl+Z、Ctrl+Shift+Z 或 Ctrl+Y；恢复塑形、固定点或复位前状态，清除残余速度并暂停，不改二维 CP |
| 保存完整作品 | 保存当前三维姿态、固定点、材质和观察方向；再次打开保持暂停。普通工作区切换也会保留并暂停三维 |
| 暂停 / 继续 / 单步 | 暂停、恢复或推进求解；暂停仍可旋转查看 |
| 复位 | 恢复输入初态与0%目标 |
| 纸面 / 折线 / 透视 / 应变 | 不同观察方式；透视刻意显示后层 |
| 红蓝 / 折痕 | 红蓝区分山谷；折痕改为中性深色细实线，PNG／SVG随当前选择输出 |
| 材质与导出 | 调整硬度、阻尼、颜色并导出当前三维结果 |

未知目标角需要先回选区设置。应变过大或失稳时降低比例并复位。数值稳定不代表实际可折；当前还没有完整的接触响应、纸厚与摩擦求解，复杂模型可能无法连续折到100%。

目前显示实际求解纸面，纸层微间距显示保持关闭。三维 FOLD／OBJ／STL 保存真实求解状态；固定点与姿态历史不会补出碰撞响应。

## 大工程与容量

折痕线段、交点切分以及折痕工程、模型快照、模型集合、完整作品和折序文件均不设固定数量或文件大小上限。打开折痕文件时在独立线程读取并整理交点，可取消导入；取消或文件校验失败不会替换当前作品。保留来源元数据，不自动删线或截断文件。实际处理速度取决于交点数量和可用内存；平折层序和三维网格等计算仍有各自的时间预算与格式要求，超时不代表无解。

常见问题：CP与对方网格偏移时用默认对齐坐标；矩形网格比例不同需调整接收工具；修改纸张后若网格太密看不见，放大画布；未保存时恢复副本可帮助找回近期修改，但不能替代手动保存和独立备份。
