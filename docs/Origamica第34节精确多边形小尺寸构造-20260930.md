# 第 34 节：精确多边形小尺寸构造

原 `PolygonTwistTile` 的边缘分点与相邻褶线交点定义（`tmp/Origamica-15.0-reference.nb` 第 212258–212327 行）使用无量纲褶宽、偏置及角度。对外多边形做正比例缩放和平移，构造应做同一相似变换；不能因为绝对坐标缩小而丢面、合并折痕或误报相邻边共线。此处只核验有限数值构造，不声称取得 Wolfram 数值 Out。

| 原问题 | 修正 |
| --- | --- |
| `10^-6` 方形通过参数读取，却被 `1e-10` 交点行列式阈值判作相邻边共线；更小输入又被固定点距拒绝。 | 精确多边形的点距按外轮廓尺度检查；小于单位尺度的单元先在局部单位坐标求交、提取面及排序，再恢复原坐标。已有单位尺度保存数据不变。 |
| 通用几何检查以至少一个单位计算面积容差，使小尺寸的独立边被误判重叠。 | 长度和面积容差随实际轮廓尺度变化，同时保留四个坐标 ULP 的表示精度下限；交叉边和零长边仍拒绝。 |
| 原始小尺寸 FOLD 经通用文件导入时，折痕会因文件导入容差丢失。 | 镶嵌显示导入在小尺寸原图上先执行同一正比例显示变换，再交给导入器；后台来源坐标及工程参数保留原值。 |
| 几何编辑最小视域 `.1`、五位小数和固定 `.01` 步长导致小尺寸顶点看成一点、坐标显示为零。 | 编辑视域与步长采用实际范围；精确坐标字段保留原始双精度数值（含科学计数），保存采用同一局部形状验证。其他数值字段保持原默认精度。 |

四种原版数值变体（一般、居中褶角、居中扭角、偏置垂直褶线）以 `w=.2` 方形为独立基准，在 `10^-3/10^-6/10^-8` 尺度保留完全一致的边、山谷和面索引，坐标恢复后误差小于 `1e-9`。另以平移 `(.125,-.375)`、尺度 `10^-6` 核对坐标、真实逐面平折、局部条件及 LFF。前端完整经过后端 JSON、显示导入和逐面平折／层序：小尺寸结果仍为 16 点、24 边、9 面及已解层序，与单位尺寸在画布上的全部线段和折后顶点一致。交叉、凹入、重复和相对过近的顶点没有因缩放而放行。

专项：`backend/test_tessellation_tile_twist.py`、`tests/app/polygonTileParams.test.ts`、`tests/app/polygonTileScale.test.ts`。关联 Python 29 项、前端及 In[3088] 来源 15 项通过；额外覆盖原点 `10^-14` 的完整后端／前端平折，以及二十万顶点输入按容量错误正常拒绝。后台逐面平折同样先在局部单位坐标求反射，再还原来源，避免微小共享边被误报退化。
