# 自由端点、真实单桥 CP 与补齐平折（2026-10-09）

当前批次接通可以实际构造、采用、重开改造和普通导出的材料 CP。完整 Origamica 复现目标仍在进行；免安装 EXE 与安装包未更新。

| 功能 | 当前效果与边界 |
| --- | --- |
| 面内自由折痕 | 在“材料曲线批量”选择开放贝塞尔并明确勾选“仅CP”，两端可以位于材料内部。真实折痕保留，未自动延伸、吸附或添加隐藏桥线。默认未勾选时仍明确拒绝悬空端点。 |
| 单边悬空、交叉树及连续路径 | 保留同 indexed 折痕两侧的面角绕行；真实交点分段，纸边身份保持。CP 可以采用和保存，但这些未闭合状态没有平折证书。 |
| 外圈到孔洞的真实单桥 | 保留桥与真实孔洞，允许仅CP的中间构造；不填孔、不自动补另一座桥。补齐对侧实际折痕后可重新计算当前 CP 的平折几何及独立层序。 |
| 后续补齐与删除 | 续建默认保留仅CP。拓扑补齐或明确删除自由边后自动恢复普通 v1/v2 材料结构。手动删除及参数组预览删除均可恢复完整纸面。 |
| 参数与画布编辑 | 毫米刻度、紫色源曲线、青色结果、数值控制点和预览取消沿用现有界面。参数组重开可改；支持整次工程撤销重做、完整部件复制/镜像、剪贴板与移动。手动改动使旧参数模型过期时明确拒绝旧配方覆盖。 |
| 从 CP 重新平折 | 完整材料 CP 即使没有保存 FF，也可以按当前 CP 计算几何，再独立求层序。独立部件各自固定在其 CP 根面位置；明确提示没有保存折后相对姿态。原已验证 FF 的恢复与整体参考系逻辑保留。 |
| 未闭合状态的平折/三维 | 明确提示先连接或删除自由端点、单桥；不显示过期 FF，不引入模拟辅助线代替实际构造。弱轮廓切开和粘合当前明确拒绝。 |

## 数据与几何

新增 `zhezhi-material-topology-v3` 仅表示同 indexed 非 B 折痕的真实双向面角。内孤立边以零面积内边界绕行表示；边界到内部折痕或单桥保留重复顶点/边的外圈绕行。既有 v1/v2 的简单面约束保持，不能用新版本标记伪造合法几何。

独立检查边角归属多重集、相反方向、顶点面扇、真实材料域、纸边接触拆分和欧拉特征。零面积绕行不作为纸张孔洞计数。v3 不允许携带折后位置；复杂独立 B 切口的弱绕行仍不在本批支持范围。JSON/FOLD 保存实际材料图与参数配方；普通 DXF 沿用原 R12 独立 LINE，不含私有优化指令，没有再次缩放或改变 Y 变换。
