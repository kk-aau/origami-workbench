# Origamica 第 45 节曲折：范围复核与独立均匀螺旋构造

参考源为工作区只读副本 `tmp/Origamica-15.0-reference.nb` 第 282822–341277 行。第 341278 行起是 `Flashers`，不属于本节。原版这一节是曲线与曲面的微分系统、可展面操作和曲折构造链，不能用一般直线折痕、静态壶管网格或圆弧绘图抵扣。本次落实了有完整保存输入的均匀螺旋构造族，并新增沿一般空间曲线折叠与展开的已认证核心（另见 `Origamica第45节通用空间曲线折痕-20260924.md`）；未把第 45 节标为全部完成。

## 本次可复现的原版锚点

`CurvedFoldUniformHelix3D` 的解析定义在 In[3945]（322048–322211），保存示例 In[3947]（322371–322404）指定 `r=1`、螺旋角 `θ=30°`、折角 `γ=90°`、参数 `u∈[0,π]`，调用 `CurvedFoldGraphics3D`。`CurvedFoldUniformHelix2D` 的解析定义在 In[3951]（322671–322868），保存示例 In[3953]（322998–323033）用同一参数调用 `CurvedFoldGraphics`。两例保存的是完整输入和渲染调用，后面直接关闭单元组，没有可直接读作 Wolfram 顶点表的数值输出。

按这两条原版表达式独立化简，令 `c=cos θ`、`s=sin θ`、`C=cos(γ/2)`、`S=sin(γ/2)`、`h=√(1−c²C²)`、`k=cC`、`R=r/(Cc²)`。二维展开折痕是以 `(1−R,0)` 为圆心、半径 `R` 的弧，`f(u)=(1+R(cos ku−1), R sin ku)`；三维折痕是 `F(u)=r(cos u, sin u, u tan θ)`。两侧单位母线也按原版解析式生成，使用相同的 `(u,v)` 表面参数 `f/F+v·ruling`。其中二维 `f(0)=(1,0)` 是原版固定平移，即使 `r≠1` 也保留。

保存样例给出以下由**源方程推导**的数值锚点，而非声称 Wolfram 内核逐点输出：

| 量 | 保存样例下的值 |
| --- | --- |
| 展开折痕半径、角速度 | `R=4√2/3≈1.885618083164`；`k=√6/4≈0.612372435696` |
| 三维折痕端点 | `F(0)=(1,0,0)`；`F(π)=(-1,0,π/√3)` |
| `u=0` 的二维左右母线 | `(-√(3/5),√(2/5))`、`(√(3/5),√(2/5))` |
| `u=0` 的三维左右母线 | `(-√(3/10),√(3/40),√(5/8))`、`(√(3/10),√(3/40),√(5/8))` |
| 原版单位母线宽度的焦线距离 | `≈1.460593486680`，所以本例采样至距离 1 不触及参数化尖点。 |

独立模块 `backend/tessellation_curved_uniform_helix.py` 提供 `uniform_helix_curved_fold_frame` 解析值和 `uniform_helix_curved_fold_geometry` 离散面片，输入验证由 `validate_uniform_helix_curved_fold` 完成。默认示例取 `u` 方向 96 段、母线方向每侧 4 段，产生共用一条折痕的 873 个二维／三维对应顶点及 1536 个三角面。解析构造允许正半径、主值螺旋角 `|θ|<90°`、非退化折角 `0<γ<180°`；原版并未写这些输入校验。为使渲染面局部不越过焦线，离散构造另要求母线长度小于其焦线距离，并将绘制区间限制在一圈参数内。

专项测试用独立有限差分比较连续二维和三维面的第一基本形式 `E,F,G`，检验 `det(F′,r,r′)=0` 的可展性及两侧有向法向夹角 `γ`；覆盖保存样例及另一组负螺旋角、另一组钝折角。离散网格的对应弦长误差在 48 段约 `9.90×10⁻⁶`，96 段约 `1.24×10⁻⁶`，随采样加密收敛。**连续参数曲面的等距性质与离散三角片逐边精确等距是两件事**；此网格只用于显示／数值采样，不作为精确直折痕 FOLD 图或连续刚性折叠路径。

后端运行 `cd backend; ..\.venv\Scripts\python.exe -m unittest test_tessellation_curved_uniform_helix -q`，4 项通过。前端独立模块 `src/app/curvedUniformHelix.ts` 提供同一解析曲线、母线和采样预览；`src/components/CurvedUniformHelixDialog.tsx` 在一个只读弹窗中对照二维展开与三维正交投影，并保留参数验证和限制说明。`npx tsx --test tests/app/curvedUniformHelix.test.ts` 的 5 项专项测试及 `npx tsc --noEmit` 均通过。

第 45 节保存的 In[3957]／In[3958] 另外调用 `CurvedFoldShapePlots3D/2D`：三维图为曲率 κ、测地曲率 κg、挠率 τ 和两侧母线角／折角；二维图为左曲率 κl 和两侧母线角／折角。现有弹窗的「形状函数」视图按相同输入实时绘制四图。对原保存参数 `r=1, θ=30°, γ=90°`，解析常值为 `κ=3/4`、`κg=κl=3√2/8`、`τ=√3/4`、四侧母线角 `acos(√(2/5))≈50.7685°`、折角 90°。改变半径、螺旋角或折角会同步更新四图，专项核对负螺旋角的挠率符号和二维／三维母线角一致。In[3958] 用 32 点的 Wolfram 插值版本绘图；本地显示的是连续解析函数，未将插值误差虚构为原版可比数值输出。1000×720 和 390×720 真实浏览器的四图入口、按钮状态与无脚本错误已复核；窄屏由弹窗纵向滚动承载全部图表。

第 45 节 In[3962]/[3964]/[3967] 又以一般 `CurvedFoldHelix3D`、`NCurvedFoldHelix3D`、`NCurvedFoldHelix2D` 调用相同的 `r=1, θ=30°, γ(u)=90°, u∈[0,π]`。这一**固定常角输入的连续几何**与上述解析均匀螺旋相同，弹窗参数栏现明确标示这三条保存调用；其中数值包装的插值坐标、插值阶数和误差仍未逐点复刻，不能由同一预览推断通用变角函数等价。
