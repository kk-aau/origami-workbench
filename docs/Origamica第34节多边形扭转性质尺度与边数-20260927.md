# Origamica 第 34 节：多边形扭转五项性质查询补核

本轮只核对 `PolygonTwistNumSides`、`PolygonTwistTwistAngles`、`PolygonTwistCentralPolygonSides`、`PolygonTwistCentralPolygonAngles` 和 `PolygonTwistCentralPolygonAnglesExcess` 的**只读性质查询**。依据为 `tmp/Origamica-15.0-reference.nb` 第 212258–212327 行的 `PolygonTwistTile` 顶点顺序，以及第 212845–213503 行的五项查询定义与样例输入。笔记本在该处未保存可直接比对的数值 `Out`；下面的数值证据是按保存公式计算和几何不变量验证，不能称为 Wolfram 运行输出逐项等价。

| 发现 | 原行为 | 修正与证据 |
| --- | --- | --- |
| 单位尺度影响有效性 | 保存的不规则四边形 `{{0,0},{1,0},{.8,.9},{-.1,.7}}`，`w=.2,d=.2,τ=90°` 能返回五项性质；全部坐标乘 `10^-6` 后返回 `null`。绝对面积 `1e-12`、交点行列式 `1e-12`、边长 `1e-8` 等门槛将同一个相似图形误判为退化。 | 将输入平移、归一到外轮廓的单位尺度后求射线交点、角和有效性，再把中心顶点、边长变回原坐标单位。原样例扭角仍是约 `34.2580° / 21.3706° / 35.8377° / 19.0860°`；缩小后角度不变、长度按比例缩小。另扫描 `w∈{.09,.2,.4}`、`d∈{-.2,0,.2}`、`τ∈{30°,45°,…,150°}` 的 81 组参数，其中原尺寸有效的 43 组均在 `10^-6` 尺度保持五项性质。 |
| 查询边数比精确单元少 | 精确多边形单元构造接受 3–24 边，但性质查询硬限 3–12 边，13–24 边在对话框被误报为无效。 | 性质查询对齐精确单元的 24 边输入上限；13 和 24 边正多边形均返回完整逐边数据。循环对称的扭角、中心边长与中心角分别相等，中心角和为 `(n-2)×180°`，超额总和为零。25 边仍返回无效。 |

保存的不规则四边形基准还校验四个中心角约 `113.3021° / 64.5838° / 104.4670° / 77.6471°`、和为 `360°`，以及四个超额的和为零。三角形案例与独立 `UnitTriangleOffset` 公式的交叉检验、反向顶点顺序、无效／退化输入的现有回归均保持通过。

验证：`tsx --test tests/app/polygonTwistProperties.test.ts`，7/7 通过；`tsc --noEmit` 通过。

范围边界：这五项只描述由当前参数建立的中心多边形；原笔记本也明确指出一般多边形扭转的扭角会随边变化，因此不保证整片平折。24 边是当前精确单元生成器的产品输入限制，不是原版数学公式的固有限制。本次不修改精确单元的后端生成容差；极小尺寸图形的完整折痕生成仍需另行核查。
