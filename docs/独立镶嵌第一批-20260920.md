# 独立镶嵌构造第一批 · v0.10.0

按用户选择的第二方案，在现有 Python／TypeScript 工作区实现基础构造，无需 Wolfram Mathematica。没有复制、翻译或执行 Origamica 笔记本源码，也尚未与原版运行结果进行等价性比对。

## 已实现

| 入口 | 范围 | 实现 |
| --- | --- | --- |
| 单元扭转 | 3–12 边正多边形，角度、内接半径比、正反向扭转 | 独立解析几何，褶线裁至方形纸张，真实山谷赋型与面拓扑 |
| 周期拼接 | 方格、等边三角格、六角格，2–6 行／列 | 独立生成共享顶点及边的连续母结构，正则面心对偶，MIT Pleat 缩放旋转 |
| 原始—对偶 | 三种规则母结构，1–3 邻接圈 | 保留原有 Pleat 管线，接入统一参数界面 |

三角格每个行列格包含两个三角形。三角扭转角绝对值需大于 30°；所有构造排除接近 0° 的退化角。规模及有限数值由后端校验，未知或错属其他构造的字段拒绝处理。

生成后可在折痕与母结构参考间切换，采用为独立的可编辑工程，继续平折分析、保存或导出。完整工程记录参数、实现来源、版本及检查信息。变更参数后旧候选不可采用；计算中、几何失败、局部条件失败／不完整均不可采用。

界面将行列并排，平铺类型单行显示。1000×720 下常用参数、检查入口和操作全部可见，无需滚动或翻页；详细解释默认收起。

## 几何与稳定性修复

- 小周期拼块可能没有不接触边界的面，中心选面允许边界面，避免两行拼接报错。
- 周期拼接保留边界二度顶点，避免上游简化三角角部时形成重复边。
- 输出按几何坐标规范排序，固定 BFS 中心面平局选择，消除集合遍历顺序造成的文件差异。
- 方形纸张上的多边形扭转使用解析射线，独立计算局部扇区条件；几何检测还会拦截高半径／大角度产生的相交。
- 原始 `tiling/rings/angle/scale` 接口继续兼容，旧六角二圈结果仍为 96 顶点、180 条边。

## 范围与运行

本次更新源码、网页构建及独立计算组件。可从 `workbench` 运行 `npm run desktop` 使用；没有重新制作安装包或免安装发布包，`release/` 的 v0.9.2 不包含本次新增功能。

本批不是 Origamica 全量移植。偏置／分裂扭转、自定义及阿基米德拼块、交互对偶编辑、非周期／Voronoi／Penrose 母结构、铺石、编织、环状镶嵌尚未实现。生成结果标记为候选；局部 Kawasaki／Maekawa 与几何检查不构成整体层序、连续路径或实物可折性证明，可采用后交由现有平折求解器继续分析。
