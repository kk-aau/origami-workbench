# 折纸工坊 0.13.51-tauri.26

日期：2026-10-31。Windows x64 · Tauri 迁移版。

本候选改进大 JSON 折痕工程的导入。Worker 复用已解析的数据，并跳过已完成的重复升级和克隆；草稿保存后，以异步条件写入更新最近打开记录，避免同步请求卡住界面。

实包验收发现系统 WebView2 会将二进制导出块通过 Tauri 的 JSON 备用通道传入 Rust；本候选允许该受限字节数组进入同一分块写入流程，修复 PDF、日志和作品文件在系统保存对话框确认后写入失败的问题。

开发阶段使用 8,991,024 字节、105,000 条非相交线段的样本复测：Worker 建立至开始传回由约 1.39 秒降至 1.07 秒，最长主线程长任务由约 1.62 秒降至 0.28 秒。该数字属于本机浏览器界面与 Rust 本地服务的测试，不代表所有工程或电脑。

数据草稿与恢复副本仍保存完整 JSON；本版未将底层数据存储改为 WAL。现有折纸编辑、导入导出、平折、三维、折序、日志和完整离线 Python 计算引擎继续保留。

安装版、便携版、同版本完整源码 ZIP／7z 与独立调试材料一同交付。源码是独立附件，应用内保留许可和准确的源码获取说明。运行需要系统已有 Microsoft Edge WebView2 Runtime；应用不会自动下载安装该运行环境，也不需要另装 Node 或 Python。
