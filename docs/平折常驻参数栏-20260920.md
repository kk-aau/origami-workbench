# 平折常驻参数栏与位置保持

版本 v0.12.4，2026-09-20。

折痕编辑的实体、透视、正背面、旋转、复位和 FC/BC/LC 配色移到窗口底部原有的折叠控制栏。尚未计算或暂时收起平折时，基本参数仍然可以设置；下一次生成的结果采用这些设置。镶嵌使用同样的常驻底栏。画布内不再重复放置工具框。

底栏新增“删除平折结果”。编辑区删除当前活动模型及其模型历史，沿用原有确认流程；取消确认保留结果。删除最后一个模型后关闭模型图层。镶嵌删除时移除图层并终止其计算，后续调参不会自动重新显示，需再次点击计算平折。两种删除均不修改原折痕或镶嵌构造参数；显示预设保留。

编辑区此前按正背面和实体/透视分别读取相机；切换到另一种显示时会回到该显示的旧位置或初始位置。现在同画布模型使用当前共享位置和缩放，并将提交的相机同步到四种显示设置。镶嵌移除切换背面时的自动重新居中。只有明确点击“复位”才改变位置和缩放；旋转、配色、切换面向和透明模式不触发复位。

验证：相关 22 项单元测试通过；新增真实浏览器 38 项检查通过，覆盖计算前预设、底栏位置、拖动及缩放后反复切换、再次移动后切换、显式复位、删除取消/确认、重新生成、原折痕保留和 1000 像素宽度布局。既有镶嵌实时平折 19 项回归通过；快速拖动时平折更新 39 次，画布位移 0，rAF 间隔 P95 约 5.7ms。

脚本：`scripts/verify-permanent-fold-controls.browser.js`、`scripts/verify-tessellation-flat.browser.js`；完整结果见 `output/permanent-fold-result-final.log`、`output/permanent-fold-live.log`。截图在项目根目录 `output/playwright/permanent-fold-editor.png` 与 `permanent-fold-tess.png`。
