入口：**折痕编辑 → 纸张属性/选区 → 材料单线镜像**。默认保存参数组，采用后在“参数构造组”重新选择原折痕、材料/辅助轴、范围、固定侧及仅CP，顺序重算后组。源码运行版更新，免安装包尚未更新；完整Origamica目标继续。

| 操作 | 效果与范围 |
| --- | --- |
| 有限反射 | 沿用既有不含开方的反射矩阵。原线型/折角/显示色和原件保留；原线保持有限长度，轴按完整直线解释，孔洞/空白不补线。 |

| 后组续接 | 修改轴后细分保持实际子面和端点来源。依赖镜像的后组存在时删除镜像组明确拒绝，预览/取消不写入工程。 |

| 兼容 | v10支持v1–v9；版本读取改为完整后缀，避免把10误读成0。后续复制、剪贴板等不降级，保空状态和辅助线快照。原画布镜像入口保原纯几何流程；新窗口可关闭参数保存。 |
