# 编织原目标求解与可采用示例

完整镶嵌复现目标保持进行中。本批完善第42节的**非周期**倍率平方和求解、两个可采用示例和参数布局；不是全部 Origamica 功能完成。源码和网页构建已更新，免安装 EXE 未重新打包。

| 原问题 | 本批行为 |
|---|---|
| 已有原目标分支仍给下界加 `1e-5` | 仅原目标使用精确输入下界；兼容求解及其既有 CP、来源保持不变。 |
| 无约束下界案例仍调用局部优化器 | 若下界向量通过全部反射方程数值验收，直接使用该向量。因为所有正倍率不小于下界，其平方和已达到理论下界；仍须通过 CP 几何、展开与整片层序门禁。 |
| 反射方程夹紧零向量，可能误报零残差 | 原目标分支拒绝零长、不可靠或非有限方向；解析 Jacobian 按固定 CP 循环顺序求导，独立角度方程及中心差分验证。 |
| 分拓扑搜索可以重复消耗求解预算 | 同次构造共享 12,000 次目标／梯度／反射／Jacobian 调用和 8 秒数值预算；数值分支限512变量／方程。预算耗尽立即返回未认证，不冒称数学无解。负初值拓扑搜索仍是既有170轮上限。 |
| 残差最小化与原平方和目标混淆 | 原目标显式最小化倍率平方和，带等式与正下界，无人工倍率上界。SLSQP 结果标为局部数值候选；KKT 残差只是诊断，不是全局最优或 Wolfram 输出证明。 |
| 界面暗示周期自动转兼容分支 | 提交前明确拒绝“非空周期配对＋原目标”，保留当前参数；需显式选择兼容求解。后台也保持拒绝。 |
| 原目标案例无法实际使用 | 下拉提供“最小褶宽”和“凹母面编织”两个本地母图示例，实际通过层序、采用、保存、下载及再平折。后者使用最小褶宽倍率0.3、边界倍率0.05，避开当前算法不能可靠表示的薄片域。 |
| 常用参数区需上下滚动 | 示例收进单个选择框，详细求解结果进独立窗口，短窗口构造工具五列。1280/1000/800×720均核验无滚动，采用返回后1000/800宽度也通过。 |

使用方式：**镶嵌设计 → 线组编织 → 构造示例**。也可在“褶宽约束／周期／固定面”选择“原目标求解（无周期）”；“求解详情”显示目标值、理论下界、反射残差、KKT诊断和预算。参数与来源随完整工程保存。
