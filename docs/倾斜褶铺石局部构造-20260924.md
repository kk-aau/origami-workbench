# 倾斜褶铺石的原版能力边界

用户提供的 `Origamica 15.0.nb` 在约 248915 行说明铺石有平行褶和倾斜褶两条路线，但 P04 小节只定义了 `MakePrimalDualFlagstoneTessellation[tobj, ρ, opts]` 的平行褶构造。搜索整份笔记本的 `tilted-pleat`、`TriangleStarTwistTriangle` 及相关调用，未发现整张倾斜褶铺石的拼接函数、边界处理、山谷赋型或保存的完整折痕／平折样例。

笔记本约 27188–27595 行独立定义 `TriangleStarTwistTriangle[plist_List, dir_:1]`：六点须逆时针交替为三个等腰尖角与三个凹角，`dir=+1/-1` 分别指定逆／顺时针局部旋向。三条尖角平分线上各取一个点形成中心三角形。原版最小化三个凹角沿中心三角形边反射后的三角形面积平方，并以相邻边交点和三条平分线公共交点给出严格距离界。约 27625/27824 行各有一个 CCW/CW 图示输入，未保存数值 `Output`。图示将三个反射凹角画成同一个 `s` 点。

当前实现提供独立的六点局部查询及工作区对话框：按原版距离界和面积目标搜索，再验证三个反射凹角确实汇聚（只共线但不汇聚的面积零假解会拒绝）。原版示例的两种旋向均得到小于 `1e-8` 的汇聚误差；测试还检查距离严格位于原版上下界内，以及平移／旋转／缩放不改变构造关系。输入可导入或下载 JSON，浏览器会记住上次成功的局部实验；这些值不写入完整工程，因为它们不对应当前整张铺石折痕。

此功能不改变现有平行褶 CP／FF，不输出山谷赋型、整张镶嵌、层序或连续折叠路径。将局部星形求解误写为全局倾斜褶模式会遗漏原版没有给出的拼接规则。
