# 完整检查与修复 · 2026-09-20

本轮完成剩余模块检查、已复现缺陷修复、全量回归与 Windows 桌面打包。修复已包含在源码、dist 和重新生成的 0.9.2 安装版／免安装版中。所有读写验收使用独立测试数据目录，未使用用户工程库。

## 本轮修复

1. **非标准目标角导致模型无法保存。** 自定义角、零角或未知角工程可以算出平折模型，但快照导出把计算用的 ±180° 当成原始拓扑字段比较，误报拓扑不对应；模型集合因复用快照也无法导出。现在结构拓扑严格比较，折角允许原工程值或合法的完全平折值；文件中的原工程与 basis 仍完整保留并严格校验。实际快照及集合下载再打开已验证。
2. **重新分析时丢失正反色约束。** 重置分析状态后读取了新状态的空约束。现在缺省沿用输入模型的约束，显式传入空数组仍可清空。
3. **交点切分 ID 与绘图对象冲突。** 生成小段 ID 时只避开线段，可能撞上已有文字／圆／标记，导致合法绘图操作无法提交。现在避开文档内全部对象 ID，并保留分段选区映射。
4. **粘贴 ID 与绘图对象冲突。** 新粘贴线段现在同样避开全部对象 ID。
5. **模拟失败仍显示“已载入”。** 现在按模拟器返回状态区分载入中、已载入和不可用；失败不再显示成功，未准备好时不能继续模拟。未知折角仍按原规则拒绝，修正目标角后可正常载入。

前四项新增回归测试均先在旧代码上失败，再在修复后通过。模拟状态通过真实 iframe 浏览器流程复现与核验。

同时维护桌面验收脚本：适配当前紧凑工具栏和控件名称；等待布局稳定；验证并处理“已保存折痕、仍有未保存模型”时的刷新确认。构造交互脚本显式设置新线类型，避免继承其他验收脚本留下的边界预设。
