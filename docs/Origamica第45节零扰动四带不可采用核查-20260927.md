# 第 45 节零扰动四带：可采用折痕图的边界核查

本核查只涉及工作区的 `zero-chain` 子域。原笔记本 `tmp/Origamica-15.0-reference.nb` 的 `In[4086]`（约第 340043–340404 行）保存的是 `q₁(s)=s+0.1 sin(2s)` 的**非零扰动**同心圆示例；工作区把扰动设为 `0` 是由原公式推得的另一输入，原笔记本没有保存该输入的平折输出。因此不能把零扰动视图称为原版已认证的折痕图。

| 核查点 | 原版保存输入或本地计算 | 对采用的含义 |
| --- | --- | --- |
| 四带绘制 | `In[4086]` 的二维、三维图各调用 `StyledRuledPatchSequence[..., RulingLineDivisions -> 50]` 并另画 `StyledCurve`；没有传 `TransverseLineStyle`、`RulingLineStyle`、`FaceupFace`，也没有保存 CP 图或全局层序。 | 图像不能直接回读为山谷赋型和正反面顺序。 |
| 绘制默认值 | `In[1757]`（约第 119608–119621 行）定义 `TransverseLineStyle -> None`、`RulingLineStyle -> UnfoldedLine`。 | `In[4086]` 的默认母线不能被解释成山谷折痕。 |
| 相邻例子 | `In[4039]`、`In[4043]`（约第 332549、333366 行）显式给出 `MountainLine`、`ValleyLine` 和山谷母线，但属于另一半圆柱构造。 | 该赋型不能无证明地移植到同心圆四带。 |
| 连续曲面 | 工作区解析式证明四带局部等距且共边连续，折角为 `+120°、−120°、+120°、−120°`。 | 这是非平折的弯曲曲面信息；仍缺全局遮挡、层序和从平纸到终态的路径认证。 |
| 端边接触 | 工作区解析式给出所有带界 `Fᵢ(0)=Fᵢ(π)`，但展开纸的这两端相距 `2(1+0.1i)`。 | 至少存在非邻接端边的空间接触，不能据局部等距直接断定无碰撞全局嵌入。 |

还有一个独立、可数值复验的表示限制。设某条带界半径为 `r∈{1,1.1,1.2,1.3,1.4}`，相邻采样参数差为 `Δ=π/n`。二维展开图的**直线弦**长是 `2r sin(Δ/2)`；对应三维解析曲线采样点的**直线弦**长是 `r sin Δ`。二者在有限 `n` 下不相等。`n=8、r=1` 时分别为 `0.39018064403225655` 和 `0.3826834323650898`，差约 `0.00749721166716675`。连续曲线的弧长等距不受此限制影响；它只证明**不能把当前同位采样点直接连成直边，并声称得到精确保边的 FOLD 2D/3D 顶点对**。若未来采用曲折专用数据模型、重新生成逼近网格或解另一组平折几何，必须另做误差、赋型和层序验证。

因此保留当前结果为只读二维／三维解析预览，不启用“采用为折痕图”。`exactStraightCreaseFOLD=false`、`globalLayerOrderChecked=false`、`adoptableCreasePattern=false` 是有证据的边界，不是待填的任意布尔值。专项复验：在 `backend` 下运行 `python -m unittest test_tessellation_curved_linked_zero_chain_adoption_audit -q`。测试取 `n=8、32、128` 的全部五条带界，核对两套弦长公式和上述认证标记；它使用本地解析采样，不宣称存在原版 Mathematica 可机读 `Out`。
