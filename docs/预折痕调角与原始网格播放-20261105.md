# 预折痕调角与原始网格播放

| 项目 | 行为 |
| --- | --- |
| 故障复现 | 同一六射线中心模型，加入四角的八条 22.5° 展开角平分线后，93% 模拟折角无法在 ±0.25° 范围内闭合；无这些 F 线时可以应用 |
| 根因与修复 | 展开的已有折痕被模拟当成额外柔性铰链，但折序应用按原刚性纸面验证。普通 CP 的非结构性 F 标记不再参与模拟物理面划分，原工程保留全部预折痕；短折痕及索引材料仍保留表达实际材料所需的源连接 |
| 连续调角 | 应用时预折痕交点可能把活动线分成子段，原模拟目标同步映射到子段；保存重开后继续保留完整目标与进度 |
| 动画碰撞保护 | 移除按钮、状态和接触停止展示；生产规划入口忽略旧保护标记，不运行碰撞证书或接触阻挡计算。显示层序仍用于遮挡，不能成为运动约束 |
| 180° / 99% 截断 | 删除旧近折预览模块和额外 seed 接口，局部柔性默认峰值由 99% 改为完整目标；保留 CP 输入角度格式、材料连接与闭合校验，不把结构错误伪装成动画成功 |
| 网格 | 动画仅使用原始 CP 所需三角化；关闭自动加密和数值失败后的细分回退。独立三维工作区不在本次修改范围内 |
| 旧曲面兼容 | 旧工程中按旧预折痕网格保存的曲面仍按原拓扑读取，来源必须与归档 CP 的精确重建一致 |

验证：90%、93%、97% 的四角预折痕回归保留全部 F 路径，并通过原 ±0.25° 修正范围；原工程不可变。生产动画入口接受有交叉的几何路径，不因接触停止且不更换网格。完整 180° 终点、往返预折、旧折角与耦合顶点、短折痕曲面、图像遮挡及旧曲面归档均分别回归。构建与测试结果记录于 `.runtime/precrease-original-*.log` 和 `.runtime/precrease-surface-compatibility.log`。
