# 折序图片与三维截图

本次为源码功能更新，未生成新的桌面发行包。

## 插入图片

| 操作 | 使用方法 |
|---|---|
| 本地图片 | 在折序绘图顶部点击“插入图片”，选择 PNG、JPEG 或 WebP。图片在本机处理，不引用外部文件地址。 |
| 当前三维画面 | 在“三维模拟”中调整折叠比例、视角与颜色，点击“插入折序”。截取当前可见姿态后进入折序当前步骤。 |
| 在折序中模拟截图 | 点击“三维截图”，选择操作前或操作后 CP，调整比例和视角，点击“截取并插入本步”。独立模拟窗口不修改折痕编辑区或当前步骤的 CP。 |
| 动画中间状态 | 打开“步骤动画”，播放或拖到需要的进度，点击“截取本步图片”。截图会暂停动画，插入当前步骤。 |

首次插入图片时，本步改为图片展示，原有纸面和物理折痕数据仍保存。左侧“同时显示折图纸面”可以恢复纸面；移除最后一张图片时自动恢复显示。插入多张图片时会保留当前显示选择。

## 调整与标注

| 需求 | 操作 |
|---|---|
| 移动图片 | 使用“选择”，直接拖动图片。 |
| 调整尺寸 | 选中图片后拖动四角，始终保持原图比例；也可在左侧输入图片宽度。 |
| 旋转或重命名 | 选中图片，在左侧修改“图片旋转”或“图片名称”。 |
| 添加说明 | 继续使用折线、箭头、文字及折纸符号。图片主图模式下的标注线不参与 CP 折叠。 |
| 取消或移除 | 右击或 Esc 取消选择；Delete、Backspace 或左侧“移除这张图片”删除。移动、缩放和移除均可撤销。 |
| 展示原纸面 | 勾选“同时显示折图纸面”。此时原有折痕与 CP 联动按原逻辑工作。 |

照片、截图内嵌于折序工程，保存、导出工程、复制步骤及重开后仍可使用。步骤缩略图和整页预览均显示图片。PDF 的首页展示图可选择当前步骤或最后一步，用图片步骤作为成品图；步骤面板还保留其绘图标注，封面展示图不叠加动作箭头。

## 容量与保护

- 源图片最大 32 MB、单边不超过 8192 像素、总像素不超过 3200 万；仅接受实际格式相符的 PNG、JPEG、WebP。
- 导入时自动缩图和压缩，默认长边最多 1600 像素，保留透明背景；每张嵌入图片最多 2 MB，每步最多 16 张。折序工程沿用总计 8 MB 限制，超限时不覆盖原工程。
- 截图仅保留模拟纸面和线条，不包含工具栏或鼠标。透明底默认开启；折序三维截图窗口可取消透明底。
- 切换工程或步骤、关闭截图窗口、重新载入模型会取消旧请求，不把迟到的图片插入其他步骤。失败时保留原绘图并提示重试。

## 参考点尺寸

新放置的“参考点”圆径与当前“角平分标记”的小圆一致。200 mm 纸张上默认约为 4.317 mm；随纸幅等比变化。已有工程中的尺寸、CAD 参数和原插件控制点保持原值。

## 验证

图片模型、格式校验、容量原子拒绝、保存往返、步骤复制、图片几何、截图协议生命周期及符号尺寸均有回归覆盖。真实浏览器检查包括本地插入、拖动缩放、旋转、右键取消、移除与撤销、纯标注不改 CP、刷新重开、窄窗口、三维与动画截图，以及实际 PDF 导出和渲染检查。验收使用独立临时数据目录，未写入用户工程库。
