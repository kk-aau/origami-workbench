# 弱边界平折、层序和模型保存（2026-10-09）

本批补齐可保持平面的弱边界材料的几何、层序、正背显示、模型快照及后续实际折叠。完整 Origamica 目标继续；免安装版本未重打包。

| 功能 | 当前效果 |
| --- | --- |
| 独立切口平折 | 内部孤立切口、边界悬空切口、交叉树和外圈到孔洞的切口可计算当前平折位置，并独立求层序。实际顶点、两侧边界、面编号及孔洞保留。 |
| 内部 F 平面线 | 默认构造即可生成和预览经过验证的 FF，无需强迫“仅CP”。原版材料各部件原有折后位置及相对姿态保持；明确仅CP仍不携带原 FF。 |
| 真实山谷铰接与弱边界混合 | 共享的山谷铰接仍按反射求解并验证闭环；同面 F 绕行保持平面。测试覆盖真实山折混合平面线/独立切口，原面身份和反射位置保留。 |
| 切口尖端续线 | 修复原绕行把独立反向切口侧当成普通转向，导致新线到达尖端时无法闭合。真实纸边到切口尖端的山折可以完成分面并折叠纸角，独立层序通过。 |
| 正背显示和模型保存 | 几何/覆盖区域/实体与透视/正背面都使用实际模型。模型快照重开不信任旧层序，可重新分析；JSON/FOLD 重开保真实身份及已验证 FF。 |
| 悬空山谷或未指派线 | 若同一刚性面仍沿 M/V/U 自接，继续仅CP并明确拒绝平折。没有用平面线规则伪造山谷折后结果。 |

## 几何和层序一致性

v3/v4 的 CP 独立核查保持，包括真实反向边/切口侧、顶点扇、区域范围及面角关联。FF 验证允许符合平面语义的弱绕行，逐面核对刚性距离、真实外圈/孔洞、分支位置、折后朝向与山谷铰接；未闭合山谷线仍不能附带 FF。

新增内部面积图只用于层序覆盖：同面零面积切口/F 绕行不扣除纸张面积，也不产生额外面。它保留真实区域边及共享铰接，核对独立反向切口侧、分支所属区域、边界接触和完整面关联，再进入原面层序变量求解。它不会替换公开 CP/FF 图；公开模型、线框、快照和普通 DXF 仍含原顶点和所有实际边界，不含内部辅助边。

重开模型后的层序分析继续允许手动模型，但明确提示“不证明原折痕能等距折成该形状”；源材料的 FF 合同仍独立核对等距。覆盖区域核对真实孔洞和零面积绕行，禁止把越出纸张的分支藏在面积图之外。
