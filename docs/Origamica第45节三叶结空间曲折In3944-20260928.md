# Origamica 第 45 节 In[3944]：三叶结空间曲折的可核范围

用户提供的 `tmp/Origamica-15.0-reference.nb` 第 321864–321945 行保存：`ff=KnotData["Trefoil","SpaceCurve"]`、`γ=135°`、`σ=+1`、`u∈[π/3,7π/3]`、`NSpaceCurveFold3D[...,InterpolationPoints→256]`，随后打印 `CurvedFoldShapePlots3D` 的两张图和三维曲折图。该单元保存的是 **In**，没有可机读的 `ff` 函数值或数值 **Out**；因此不能从笔记本自身断定 `KnotData` 的展开式或绘图坐标。

Wolfram 官方 [KnotData 文档](https://reference.wolfram.com/language/ref/KnotData.html) 说明 `SpaceCurve` 返回 `Function` 或 `InterpolatingFunction`，但没有把 `"Trefoil"` 的函数体印成网页文本。两份彼此独立、直接打印 Mathematica 求值结果的记录都得到同一函数：2016 年 [How to add color to a knot](https://mathematica.stackexchange.com/questions/112511/how-to-add-color-to-a-knot) 与 2017 年 [How to pre or post process KnotData](https://mathematica.stackexchange.com/questions/157255/how-to-pre-or-post-process-knotdata-substrate)。这里据此把固定来源式记录为

```text
f(u) = (sin u + 2 sin 2u, cos u − 2 cos 2u, −sin 3u).
```

它是有 **KnotData 实际求值记录** 的分支，而不是任选一种常见三叶结参数化。[Wolfram Community 上另一条手写示例](https://community.wolfram.com/groups/-/m/t/3061291) 的符号和位置不同，不用于本预设。上述两份求值记录不能替代本地同版本 Wolfram 对 In[3944] 的逐点 Out；若将来取得原数值导出，应再核对应版本的坐标。

`src/app/curvedTrefoilSavedIn3944.ts` 把该精确三角表达式及一、二、三阶导数显式编码，`src/components/CurvedTrefoilSavedDialog.tsx` 以只读三维正交投影和两张形状函数图展示它。第一图对应原函数定义的 `κ` 曲率、`κg=κ cos(γ/2)` 测地曲率、`τ` 挠率；第二图对应左／右母线与切线夹角 `ρL=acos(RL·T)`、`ρR=acos(RR·T)` 及 `γ`。采样使用本地 256 **段**绘图，并非声称复刻 `InterpolationPoints→256` 的 Wolfram 插值多项式或像素图。

设 `c=cos(3u)∈[-1,1]`。由保存函数直接代数展开：

```text
|f′|² = 17 + 8c + 9c² ≥ 137/9 > 0
|f′×f″|² = 2338 + 248c − 776c² − 144c³ ≥ 1170 > 0.
```

后一界用各项绝对值的保守估计即可成立。故完整闭区间上速度、Frenet 曲率均非零；`γ=135°∈(0,180°)`，`q=sin(γ/2)|f′|κ>0`，原 In[3939] 两侧母线分母也非零。沿用已审查的源式 `Rₗ=(a/mₗ)T+(q/mₗ)Lₗ`、`Rᵣ=(-b/mᵣ)T-(q/mᵣ)Lᵣ`，其中 `a=|f′|τ`、`b=-|f′|τ`、`m=√(q²+a²)`；方向单位长，局部可展条件 `det(f′,R,R′)=0`。在 `u=π/3` 有 `f=(3√3/2,3/2,0)`、`|f′|=3√2`、`κ=1/2`、`τ=-2/9`，作为独立端点锚点。专项还核 49 个位置的全域恒等式、方向单位长、局部可展残差、区间和错误拒绝。

**范围限制：**现有通用 SymPy 全域极值认证器对该三叶结完整 `2π` 闭区间超过约 70 秒仍未给出有限宽度焦线前证书，本次中断该探针，没有放松门禁。弹窗的短线段只表示当前点的**单位母线方向**，不连接成填充纸带，也不返回二维展开、面、FOLD 或可采用工程。虽然原版调用会生成三维图，当前只复现已能证明的源曲线和局部形状函数；有限宽度的整条曲折面、全局自交／碰撞、连续部署、纸厚与原 Wolfram 插值坐标均未认证。源码、专项和浏览器证据分别见 `src/app/curvedTrefoilSavedIn3944.ts`、`tests/app/curvedTrefoilSavedIn3944.test.ts`、`output/playwright/curved-trefoil-in3944-browser-report.json`。
