# 切开、粘合参数重放（2026-10-09）

本批将切开和粘合加入曲线、线网、直线、射线、批量参数组。完整 Origamica 目标仍在进行，未重打包或发布。

| 入口（折痕编辑 → 纸张属性/选区） | 效果 |
| --- | --- |
| 切开材料折痕 | 默认保存选定内边的来源区间；采用后生成实际独立边界，保CP与已有FF坐标。关闭保存参数保旧几何流程。 |
| 粘合材料边界 | 默认记录明确的两侧、来源区间和连接赋型；只粘合原选择范围，不推断额外接缝或吸附端点。 |
| 参数构造组 | 重开切开/粘合原选择，修改前组顺序重算；改变粘合赋型可独立重折。 |
| 依赖和删除 | 删除粘合可恢复两侧切口；后组依赖切开时删除切开整次拒绝，不改原工程。 |
| 切口侧引用 | 切开后的同坐标两侧有各自来源；后续射线保持实际材料侧和部件，前组移动后也不会转绑另一侧。 |
| 保存与历史 | JSON/FOLD保持可编辑配方；取消不提交，一次撤销/重做恢复全部模型；失效旧配方显式归档并保当前材料。 |

## 来源及兼容

v4继续接受v1曲线、v2线网及v3直线/射线/批量模型，加入切开/粘合后不降级。组和归档仍各限8，编号单调增长。

材料边记录基底或前组来源、沿边区间和源分段数量。相邻且属于同一来源侧的选定切开区间合并记录，前组移动交点后重新解析整条实际后代链；不跨空白补边。切开两侧或粘合保留边的最新身份优先于旧共同折痕，避免重合坐标造成歧义。射线/直线的具体部件按已解析的来源边定位，处理切开后一个基底部件变成多个部件的情况。

粘合两侧区间必须有同样的实际细分，每段有唯一已选择的对应侧，最终沿用原方向/姿态核查。来源被删除、区间落在当前边内部、分段身份变化、断开/重复侧或相容性失败均拒绝。生成曲线拓扑改变后保持连续解析参数位置仍未实现，不宣称任意操作栈已完成。

同时修复切口新ID未避开独立文字/圆等对象ID的问题。其余纯几何切开/粘合算法和原文件格式保持。
