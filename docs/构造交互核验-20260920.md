# 构造交互核验

## 修复内容

- **可见网格取点统一。** 网格补线、自由补线的终点重选，以及共线交替／共线删除的参考取点，使用与显示一致的网格范围和最小屏幕间距。纸内模式不接受纸外和孔洞内的虚拟网格点；全画布模式接受实际显示的纸外网格；关闭或因缩放隐藏的网格不能作为新取点。已有顶点仍可使用，补线保留顶点优先规则，共线操作仍支持圆心。
- **受限绘制保持其纸内约束。** 受限线和受限圆继续只允许纸内网格，修正其固定 3 px 阈值与实际网格设置不一致的问题；起点、终点预览及提交共用同一约束。
- **候选歧义统一处理。** 网格补线、自由补线和局部补线采用同一有限候选拾取函数。两候选距离差不超过屏幕半像素时提示靠近具体方向或使用编号，不再按候选数组顺序选取；容差随缩放变化，避免指针坐标浮点换算造成视觉等距却误选。
- **明确选中状态。** 网格／自由补线的“方向建议”按钮显示选中状态；换方向后旧状态清除，另选终点后不继续高亮原候选。原来的山谷与折角继承规则不变。
