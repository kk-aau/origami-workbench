## 本次功能

“自定义 → 拼块装饰 → 原版 TileIndex 标签来源”可逐块输入字面值；即时显示对应中心文本，自动开启拼块编号。保存后再打开仍保留来源，重复母拼块沿用同一来源和文本。纯文本编辑、自动编号与恢复装饰会清理旧来源；无效来源保留上一次有效预览，阻止保存，切换到其他拼块也不会绕过该校验。

来源存为可选 `TileDecoration.labelExpression`，已有 `label` 继续作为显示文本。`readTileDecorations` 重新解析来源并逐字比较 `label`；源与显示不一致、非法类型、可执行表达式或超限输入均拒绝。JSON 回读、周期重复及顺逆时针归一映射保留这两项，装饰变化不改变 `tessConstructionKey`。

| 支持的字面值 | 显示文本 | 合同 |
|---|---|---|
| `a`、`A12`、`α` | 原符号名字 | 只解释未赋值的符号名字，不查询 Mathematica 全局定义 |
| `\[Alpha]`、`\[CapitalDelta]` | `α`、`Δ` | 转义表依据 Wolfram 命名字符表；Phi/CurlyPhi 分别为 ϕ/φ，Epsilon/CurlyEpsilon 分别为 ϵ/ε |
| `"a"`、`"中心 A"`、`"\[Alpha] + \[Pi]"` | 去掉外层引号后的字串 | 支持普通 Unicode、引号／反斜线转义及有限 Greek 命名转义；HTML 仅作为 React 文本显示 |
| `12`、`+0012`、`-7` | `12`、`12`、`-7` | 有限整数，绝对值不超过 9,999,999,999 |
| `1.25`、`-.5`、`1.` | `1.25`、`-0.5`、`1.` | 最多六个有效数字；非零绝对值在 .001–999999 内，避免科学计数／多行排版和隐式舍入 |
| `None`、`""` | 隐藏 | 保留来源；`"None"` 仍显示文字 None |

源码本身用的是 `ToString[ci]`；Wolfram 官方说明其默认采用 OutputForm，默认 Unicode 保留特殊字符，且可受 Format/MakeBoxes 定义影响。本入口明确采用上述无全局定义的原子合同，未假定任意表达式都能按纯文本等价展开。[ToString 官方说明](https://reference.wolfram.com/language/ref/ToString.html)。短小数的六位边界依据 Wolfram 默认数值打印规则；不支持精度标记、任意精度实数或科学计数输出。[数字说明](https://reference.wolfram.com/language/tutorial/Numbers.html)。Greek 字符映射依据 [Wolfram 命名字符表](https://reference.wolfram.com/language/guide/ListingOfNamedCharacters.html)。

源最多 128 个字符，解析后文本最多 32 个 UTF-16 单位。该入口不支持函数调用、赋值、程序、替换规则、上下文限定、富文本、Subscript/Row/Style/盒结构或多行 OutputForm；Pi/E/I 等有特殊常量语义的未引号原子暂拒绝，写为字符串可显示其名字。这些仍是一般 Mathematica 标签语义差异；In[2863] 的字符串保存例可以直接复现。

浏览器发现旧装饰弹窗用固定 540 单位假定估计字号，实际预览只有约 4px，标签难以读取。本次按真实 SVG 可视尺寸求比例，原版样式的中心标签与顶点号采用同一字号，保持约 12px；旧版无显式原版样式的项目保留中心／顶点 12/10 的相对大小。不改变几何坐标或编号。
