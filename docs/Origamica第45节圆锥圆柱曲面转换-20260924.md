## 已实现的精确样例与 API

独立后端 `backend/tessellation_curved_cone_cylinder.py` 提供：

```python
from tessellation_curved_cone_cylinder import (
    fold_surface_to_cone_example,
    fold_surface_to_cylinder_example,
)

cone = fold_surface_to_cone_example()                 # u in [-pi/3, pi]
cylinder = fold_surface_to_cylinder_example(30, .25)  # u in [0, pi]
frame = cone.frame(0)  # b1,d1,bb1,dd1,b2,d2,bb2,dd2,f,ff
xy = cone.surface('second', 0, .5)
xyz = cone.surface('second', 0, .5, folded=True)
```

`surface('first',u,t)` 从已有曲面的基线走到折线；`surface('second',u,t)` 从折线走到新曲面的基线；`t∈[0,1]`，二维和三维取相同 `(u,t)`。圆锥顶点是参数化奇异边界，但其坐标仍可取值；`singular_boundary` 对柱到锥为 `('second',1)`，对锥到柱为 `('first',0)`。`collision_checked` 恒为 `False`。

柱到锥的原版保存输入为 `b1=(-1,u)`、`d1=(1,0)`、`bb1=(cos u,sin u,-1)`、`dd1=(0,0,1)`，第二锥顶点为 `(2,0)` 与 `(2,0,1)`，定向点 `ui=0`，区间 `[-π/3,π]`。用原版的平方距离差公式可直接化简出

`v(u)=u²/2+2 cos u`, `f(u)=(v−1,u)`, `ff(u)=(cos u,sin u,v−1)`。

圆锥母线取 `d2=(b2−f)/|b2−f|`、`dd2=(bb2−ff)/|bb2−ff|`；定向点的原版符号 `ψ=+1`。在 `u=0`，`v=2`、`f=(1,0)`、`ff=(1,0,1)`，与笔记本保存输入逐式吻合。可选择原区间的非空子区间，不接受超出原示例的参数。

锥到柱的原版保存输入为 `φ=30°`、`ε=.25`、`u∈[0,π]`，已有锥面两组单位母线为 `d1=(cos(u sinφ),sin(u sinφ))` 和 `dd1=(cosφ,−sinφ cosu,sinφ sinu)`，锥顶均在原点。目标二维轴点、方向为 `p2=(1+ε,0), d2=(-1,0)`；三维为 `pp2=((1−ε)cosφ,−(1+ε)sinφ,0), dd2=(cosφ,sinφ,0)`。令 `q=sinφ`、`c=cosφ`，原版投影公式化简为

`D(u)=cos²(qu/2)−q²cos²(u/2)`, `v(u)=c²/D(u)`, `f=v·d1`, `ff=v·dd1`。

第二柱面基线是折线到指定轴方向的正交投影：`b2=f−[(f−p2)·d2]d2`，三维同理。在保存样例的 `u=0`，`v=1`、`f=(1,0)`、`ff=(√3/2,−1/2,0)`、`b2=(1.25,0)`；在 `u=π`，`v=1.5`、`f=(0,1.5)`。模块允许 `5°≤φ≤30°`、`0<ε≤2` 和原 `[0,π]` 的非空子区间；原版一般符号 API 的任意锥角及任意轴定义尚不支持。

## 等距、正则与限制

两例的已有第一片分别是等距的圆柱／圆锥参数化。柱到锥按原版解 `v` 后，二维到新锥顶、三维到新锥顶的距离逐点相等，折线弧长也由已有面的等距性相等。把新锥片写成 `f+t(b2−f)` 后，第一基本形式中的 `E,F,G` 因这两个相等量及其导数而对应相等。该例原区间内 `v>0`；新片的二维正则性由 `J=3+u²/2−2cosu−2u sinu>0` 保证，只有 `t=1` 的锥顶是奇异边界。

锥到柱的 `D>0`：在 `0≤u≤π` 且 `0<q≤1/2`，`cos(qu/2)≥cos(u/2)≥0` 且 `q<1`。故 `v` 有限、为正。`v'≥0`，由 `sin(qu)≥q sin u` 得出；同时 `cos(qu)≥(1+cosu)/2`，推出折线二维横坐标 `f_x≤1`，因此第二条柱面带的宽度 `1+ε−f_x≥ε>0`。其纵坐标导数 `f_y'=v' sin(qu)+vq cos(qu)>0`，除已有锥顶 `t=0` 外局部正则。原版轴点关系使二维和三维到目标母线方向的**有符号**距离及导数相等；与折线弧长相等共同保证第二片的 `E,F,G` 等距。

专项测试从生成的二维／三维坐标独立做中心差分，对两片多个参数点比较第一基本形式 `E,F,G`；另测保存锚点、共用折线、顶点塌缩、非奇异内点的雅可比及越界／非数输入。运行 `cd backend; python -m unittest test_tessellation_curved_cone_cylinder -q`，5 项通过。差分测试是独立数值复核，不代替对未接受参数域的全局证明。

**自交不等于可制造。** 原版在第 333841–333842 行及 334372–334373 行明确说柱到锥的背面范围特意延伸到可见自交。此模块忠实保留该区间，不声称无碰撞、无穿纸、有限厚度可行，也不生成严格等距的直折痕三角网格。按光滑曲面采样的三角弦只是显示近似，不能直接当作 FOLD 工程或刚性折叠路径。

尚未覆盖原版任意四个输入函数／任意锥顶或柱轴、`Simplification`／`Assumptions` 符号选项、`FunctionInterpolation` 插值控制和其逐点误差行为。数值版原来先在区间插值结果函数；本模块对可验证样例直接计算原解析公式，未声称与 Wolfram 插值曲线逐点一致。共享生成路由尚未接入，因此不能将此光滑曲面采样采用为折痕工程。
