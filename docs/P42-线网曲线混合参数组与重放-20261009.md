# 线网与曲线混合参数组及重放（2026-10-09）

本批让材料闭合线网保存构造配方，并与原曲线按顺序重算。完成的是此项接续，完整 Origamica 镶嵌目标仍在进行；本批未打包或发布。

| 用户操作 | 最终效果 |
| --- | --- |
| 材料闭合线网 → 保存参数组（默认勾选） | 采用实际 CP，同时保存节点、边、赋型、固定点、范围和仅 CP 设置。取消勾选仍使用原几何构造流程。 |
| 纸张属性/选区 → 参数构造组 → 编辑 | 重新打开原节点和设置；编辑使用该组之前的材料，采用后重算全部后续曲线或线网。 |
| 曲线与线网混合构造 | 两种顺序均可保存、重开和修改；已有曲线 v1 模型在加入线网时升级为 v2，原配方不丢失。 |
| 删除前组 | 先预览后续构造结果，确认采用后一次提交；按原材料来源映射参考面，不盲用旧面编号。 |
| 改动导致后组无效 | 阻止整个提交并显示失败原因；取消后保留原 CP、配方和历史。 |
| 手工切开等使旧模型失效 | 新建线网保存参数时，归档旧配方并以当前实际材料为基底；显示归档说明，保留手工修改。原失效模型不能直接编辑覆盖当前材料。 |
| JSON/FOLD 保存重开 | 参数组保持可编辑，切口身份、原坐标、FF、辅助线、颜色、纸张和注释保留。 |
| 八组管理及窄窗口 | 统一表格区分曲线和线网，入口按类型打开；管理和线网编辑在测试窗口中无需窗口滚动。 |

## 实现与限制

沿用原参数模型的基底、已采用快照、组编号和严格重放核查。新增 `MaterialGroupRecipe` 联合类型及 v2 模型；v1 继续只接受原曲线配方。组上限仍为 8，旧模型归档上限仍为 8，组编号单调增长。

线网内部几何构造与参数记录分开，曲线重放调用纯几何入口，防止重复嵌套记录。旧无参数标记的核心调用仍只生成几何。用户保存线网时，以配方记录真实来源；前组改变后根据基底材料身份映射后组参考面，固定点和构造合法性重新验证，不静默改点、吸附或填补空白。

组外几何变动不会被旧配方覆盖。失效模型的新基底建立在文档副本上，通过完整检查后才提交，旧配方按原值归档。当前 FF、切口两侧、辅助线和显示属性继续使用原材料流程。

FOLD 导出将辅助线放在材料 CP 之后，重开后的线段数组顺序可能变化。验收按线段 ID 核对各坐标、赋型和样式；实际 CP 顶点、边、面和关联仍严格核对。未修改普通格式、加工优化或单位转换。
