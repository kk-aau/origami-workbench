# 底图四点配准界面

已接工具 backgroundposition，绘图入口总数 80。工具栏「背景与视图」及右侧底图面板均可进入。沿用紧凑工具布局、公共分步提示与鼠标提示。

依据本地上游 MouseHandlerBackgroundChangePosition：前两次按下自由选 A、B；后两次按下取 C、D，接近已有端点／交点时吸附，否则自由取点；第四次松开提交，拖动不改按下点。当前实现不对这四点施加网格／Shift 约束，后两点的既有顶点吸附不受普通自由画线吸附开关限制。变换 A→C、B→D，为保向相似变换，不是透视四角拉伸。

新功能只改 background.placement，保留原始图片字节、图形与折角。重复配准复合当前图片姿态。源点／目标点重合、角点越界均拒绝，保留已有输入供重试；无底图、隐藏底图或透明度零不能开始。紫色参考对与变换后底图/外框预览不写工程。右击、Esc、中键平移、撤销重做、隐藏底图或修改工程的失效规则已接；第四点按下后右击取消不会因迟到的左键松开提交。
