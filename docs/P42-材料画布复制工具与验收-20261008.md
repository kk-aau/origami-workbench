# 第42节材料画布复制工具（2026-10-08）

完整镶嵌复现目标保持 active。本批接通三个画布复制入口，源码和网页构建已更新；现有 0.13.5 免安装 EXE 未重打包。

| 问题与改造 | 当前实际行为 |
|---|---|
| 材料副本与普通线段复制的处理不同 | 两点复制、四点复制、镜像选区遇到材料边时提交独立材料意图；中央提交层从原工程和参考点完整重放，拒绝不一致提案。普通工程仍使用原有流程。 |
| 两点复制 | 直接使用原平移公式，完整部件的 CP 和已有 FF 同时变换；允许原位副本，仍保独立顶点、边、面及部件身份。 |
| 四点复制 | 使用现有 A→C、B→D 的复数相似变换公式；不拆成旋转角/比例再计算，避免额外舍入。四点仍必须为已有端点或交点，退化基准明确拒绝。 |
| 镜像选区 | 使用现有精确轴反射公式，同时反射 CP/FF；保原山谷和折角，重排面角槽保持方向。完整材料不执行普通镜像的近端点补接和重合裁剪，不按坐标焊接切口或副本。 |
| 完整选择 | 从纸张属性的材料部件选择器选择完整部件，包括全部纸边。只选部分折痕/纸边会报错，工程逐值不变；不会自动扩展选区。 |
| 边界保护 | 完整材料复制只新增独立副本，原件不修改，因此允许保留边界保护执行这三个复制入口；普通复制及普通边界保护规则保持原值。 |
| 预览/历史/模型 | 鼠标预览只生成参考线，不逐帧复制材料图。取消不写入工程；完成一次撤销/重做。旧平折过期，重算后正背层序恢复；不复制旧层序证书。平折后若目标点被模型覆盖，可先收起平折再定点。 |
| 保存与导出 | 实际 JSON/FOLD 保存、重开及重新平折已核；普通 DXF 沿用 R12 LINE、毫米坐标和现有一次 Y 转换，未新增加工指令。 |
