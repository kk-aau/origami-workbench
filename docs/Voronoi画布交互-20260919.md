# Voronoi 参考图

## 使用与边界

左侧“精确作图 → Voronoi 参考图”，共 84 个绘图入口。按下左键添加种子，再次点击附近种子移除；两点以上自动生成紫色最近点分区。种子编号与固定/鼠标步骤提示同步，颜色不受山谷预设影响。

本工具保持原版模式 62 的临时参考用途：不直接生成折痕，不进入工程保存、恢复文件或导出，不添加撤销记录。进入模式清空线段选区；初始中垂线总长 1000 mm，每侧 500，不自动裁剪到纸边。紫色线不是纸张轮廓或折叠结果。

中键平移、滚轮缩放保留种子；右击/Esc/清空按钮清除全部。取消优先于删线，空闲后的下一次右击继续通用删除规则。切换工具、文档变化清除临时图。左键按住拖动不重复加点，左键未松时追加右键也可取消。

选点使用工作台现有网格/端点/交点吸附；既有临时种子近距命中优先。网格吸附遵守工作台开关，这属于工作台统一输入规则，不声称与原版所有按下/悬停细节完全一致。

## 计算与可靠性

- `voronoi.worker.ts` 调用既有 `voronoiEdges` 核心；`startVoronoi` 为每次计算建独立 Worker，正常完成、错误或取消均终止它。
- `useVoronoi` 在种子数组变化、关闭工具和卸载时取消旧任务；旧结果有任务完成锁、effect 活跃锁和数组身份检查，不会一帧闪现到新图中。
- 不以固定种子数拒绝计算。主线程保持可取消，但当前核心仍最坏 O(n³)，并非完成所有大型点集性能验收；未加入纸边裁剪或“提交为折线”扩展。
- 无法启动、计算错误、消息传输错误均有中文提示。无结果/错误不伪装成生成成功。
