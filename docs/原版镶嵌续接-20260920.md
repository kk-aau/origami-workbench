# 原版镶嵌续接 · v0.12.0

本轮增加真正具有分裂顶点拓扑的四边形单元，以及三种 Resch 星形母结构。实现独立于 Mathematica，保留 v0.11 的全部构造和后续加入的实时滑条预览。

## 四边形分裂扭转

入口：**单元扭转 → 单元结构 → 四边形分裂扭转**。

一个四边形单元内包含一个六度基点和四个四度内部顶点。对面的原顶点拆为两个顶点，并增加基点到这两个顶点的折痕及连接折痕。可选基点 1–4、连接山／谷、边缘褶宽、目标转角和目标比例，可编辑外四边形。

`backend/tessellation_split.py` 使用独立约束优化：固定外边界及每条边的两个褶线端点，对五个内部顶点求解 Kawasaki 方程，同时约束非零边长、正面面积及顶点在边界内；之后求局部山谷赋型，并执行现有交叉和局部条件检查。目标转角、目标比例用于选择满足约束且接近目标的解，**不等同于原版的精确 pleat-angle 参数**。数值残差、算法和参数随工程保存。无有效解时返回明确错误，不采用上一次候选。

默认单元有 17 个顶点、27 条边、11 个面，内部度数为 `[4,4,4,4,6]`。测试覆盖正反目标角、四个基点、两种连接赋型、不同轮廓、顺逆时针输入与重现性。原有“分裂数”更名为“拼接数”，仍用于普通扭转的镜像单元连接，避免与新功能混淆。

## Resch 星形母结构

入口：**混合平铺 → 顶点构型 → Resch 三尖星／四尖星／六尖星**。

分别搭配正六边形、正方形、等边三角形。星尖角可设为 10–55°，支持 1–2 圈扩展。设星阶为 `n`、星尖角为 `a`，内外半径比由三角关系独立推得：`sin(a/2) / sin(a/2 + π/n)`；统一边长后，以星尖、凹角和规则多边形角在公共顶点合为 360° 的方式拼接。

母结构将星形分为中心凸多边形和星尖三角形，再交给垂直对偶与 Shrink-Rotate 管线生成平面折痕。它是 **Resch 星形母结构的扭转构造**，尚未实现或验证 Resch 原版空间折叠运动，也不代表全部 Resch 平铺目录已覆盖。
