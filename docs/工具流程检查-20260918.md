# 工具流程检查与清理 · v0.4.2

本轮针对当前实际可用的 12 个工具，不代表完成 Oriedita 的全部规划工具。

## 修复

- 垂线：直接点击起点，然后选择参考线；线外点连接到垂足，允许垂足落在参考线的延长线上。若起点在参考直线上，显示两侧紫色候选线，第三次点击候选线或实际截止线段／纸边确认。候选线止于该方向遇到的第一条非辅助线；找不到截止线时不凭空生成无限线。
- 平行线：点击起点 → 参考线 → 紫色候选线或截止线。起点与参考直线重合时拒绝重复构造，可换参考线或右击重新开始。
- 构造不再读取全局选区，因此预选多条线、参考线被交点切分都不会阻断下一次构造。参考线与候选线为紫色，正式线采用当前山谷／其他线型。
- 截止线必须是真实有限线段，不能仅与其延长线相交；平行、重合或经过起点而产生零长度的目标均拒绝，并保留构造输入供重试。
- 保护边界仍可作为构造参考；右击／Esc／切换工具清空起点与参考线，构造中右击不同时删除。

## 其他工具检查

| 范围 | 验证内容 |
| --- | --- |
| 选择、线段、平移 | 交点选择、独立小段删除、点击／拖放画线、中键平移、方向框删、撤销与保护边界 |
| 测量 | 两点长度和方向输出、不创建折痕、取消 |
| 角平分线 | 四步构造、第二点起点、有限目标截止、紫色预览与无效目标重试 |
| 中垂线 | 两基准点中点出发、有限目标、保护纸边、一次撤销 |
| 延长、截断、等分、比例分割 | 参数有效性、源线型和未知折角保留、独立分段、取消、撤销、恢复 |

## 清理范围

移除了 `CreaseCanvas` 中依赖选区的平行／垂线分支和 `construct()` 旧入口；`construction.ts` 中不再使用的“无限线裁满纸张”实现及其六项旧测试，替换为实际新流程的投影、有限截止、双向候选计算与十二项测试。复用已有 `lineTarget` 和距离计算，没有增加依赖。旧实现可从保留的 0.4.1 发布包内对应源码恢复；未删除用户工程、历史 EXE 或无关模块。

## 验证与限制

- 170 单元测试通过。
- 浏览器 225 项断言通过：新构造 36，原交互 98，线段工具 48，布局 43。独立测试脚本在 `output/playwright`，没有操作正常用户工程。
- 服务测试首次有一项镶嵌计算超过 15 秒；未改后端或放宽超时，单独重跑后 9 项全部通过，不能把单次重跑解释为消除了所有性能波动。
- 仍未声明与 Oriedita 所有变体完全一致：当前允许自由点／网格点作为起点；候选方向需存在可相交的实际线段。显式截止可以越过中间折痕，交点会自动分段；不替代整体可折性检查。
