# Origamica 第 45 节：`RibbonPair` 螺旋直纹带的二维／三维配对

只读依据为 `tmp/Origamica-15.0-reference.nb` 第 307674–309036 行。`RibbonPair`（In[3854]，307827–308004）和 `NRibbonPair`（In[3858]，308533–308691）返回 `{b,d,bb,dd}`：二维基线／母线方向和三维基线／母线方向。它们定义的是**单条连续可展直纹带**，没有把这条基线声明成两侧夹角非零的折痕。前者使用符号曲线恢复，后者使用数值曲线恢复及 `FunctionInterpolationAlt`。原版在 307791–307795、308509–308512 行明确说 Frenet 标架在零曲率拐点失去意义。


保存单元提供完整调用和绘图范围，但没有可读取的 Wolfram `Out` 顶点表。以下数值是从原版输入与 `RibbonPair` 方程独立化简得到，**不是 Wolfram 内核的逐点输出**。本模块直接评价该常参数子域的闭式表达式，不复制 `NRibbonPair` 的插值阶数、误差或舍入行为。

## 源方程在常螺旋上的闭式

令一般正半径 `r`、正螺距系数 `p` 的基线为 `C₃(s)=(r cos s,r sin s,p s)`，`V=√(r²+p²)`、`κ=r/V²`、`τ=p/V²`。源公式在 307885–307911 行定义 Frenet–Darboux 横向 `L=cosη N−sinη B` 与曲面法向 `U=sinη N+cosη B`。在常 `η∈(0,π/2)` 的分支上，Frenet 方程给

```text
U′ = −Vκ sinη T − Vτ L
n = √[(κ sinη)² + τ²]
cρ = −τ/n,  sρ = κ sinη/n
```

这与源程序从 `U′·T`、`U′·L` 计算的 `cρ,sρ` 一致（307913–307948）；三维单位母线为 `D₃=σ(cρ T+sρ L)`（307949–307962）。二维恢复曲线的曲率是 `κ₂=κ cosη`（307963–307987）。记 `K=Vκ cosη`、`φ=K(s−s₀)`，以保存的二维初值为坐标约定，可以直接积分为

```text
C₂(s) = (V/K)(sinφ, 1−cosφ)
T₂(s) = (cosφ,sinφ),  L₂(s)=(-sinφ,cosφ)
D₂(s) = σ(cρ T₂+sρ L₂)
X₂(s,v)=C₂(s)+vD₂(s),  X₃(s,v)=C₃(s)+vD₃(s)
```

`D₂` 正是源码 307988–308003 行把同一 `cρ,sρ` 放入二维 Frenet 标架的结果。它保留 `v=0` 的一一对应基线和每条 `s=常数` 的对应母线，整个带宽使用相同参数 `(s,v)`。

## 连续等距、可展和焦线

由 Frenet 方程及上述 `cρ,sρ`，两空间的母线导数都具有相同的切向分量：`D′=σK(cρ L−sρ T)`，其中二维与三维各使用自己的 `T,L`。三维 `D₃′` 的曲面法向分量为零，所以 `det(C₃′,D₃,D₃′)=0`，即直纹面可展。两张连续曲面的第一基本形式完全相同：

```text
E = V² − 2VvσK sρ + v²K²
F = σV cρ
G = 1
EG−F² = (V sρ−vσK)²
```

焦线位于 `v*=σ V sρ/K`，故对称宽度 `|v|≤w` 的局部浸入充分且必要条件是 `w<|v*|`。保存输入给出 `V≈1.118033988750`、`κ=0.8`、`τ=0.4`、`cρ≈−0.489375349341`、`sρ≈0.872073258080`、`K≈0.406061447423`、焦线距离 `≈2.401133004380`。保存宽度 `0.5` 明显在焦线之前。在 `s=0`，由源方程推导的三维母线约为 `(-0.395912974245,−0.090215386201,−0.913845775236)`；这些是可复算锚点而非 Wolfram `Out`。

`backend/tessellation_curved_helix_ribbon_pair.py` 的 `certify_helix_ribbon_pair()` 默认复现上述输入，接受 `r>0,p>0,0<η<π/2,σ∈{−1,+1}`、有限且跨度至多 `π` 的区间及小于焦线距离的正半宽。`frame(s)` 给出配对基线、单位母线和标架；`surface(space,s,v)`、`differentials(...)`、`first_form(v)` 给出连续点、导数与度量；`sample(...)` 只返回一一对应的数值点和共享基线索引。它没有面片、折痕赋值或 FOLD 输出。原版任意空间曲线、变 `η(s)`、零曲率过点以及 `NRibbonPair` 的一般插值路径尚未覆盖；局部等距与可展也不构成全局无碰撞、厚纸部署或连续折叠路径证明。
