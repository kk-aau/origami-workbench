# P42 材料折痕编辑与重新平折

本批继续完整 Origamica 复现目标，未打包。上一批建立了材料切口的保存和计算流程，但所有非辅助折痕修改均因合同过期拒绝。本批接入编辑事务，在保留切口材料身份的前提下修改属性与几何。

| 修改 | 数据处理 |
|---|---|
| 山谷、未指派及目标角 | 更新原边的赋型/角度；完全平折的 M/V/U 几何均为反射。山谷改变必须重新求层序，U 保持未知；目标角仍为工程记录，不冒充该角度的三维形态。 |
| F 与折痕切换 | 按新的零角/反射铰链重算 FF，不能继续使用旧面朝向。 |
| 整部件变换 | 属性面板可按材料部件选择完整边界及折痕。移动、旋转、等比缩放和镜像由显式操作参数重放，不靠近似猜测意图；CP 与该部件的 FF 同步变换。镜像按设计几何镜像处理，保持山谷赋型并重建正向面环关联。 |
| 保持关联的坐标编辑 | 从旧 CP→FF 根面姿态出发，在每个材料部件内部传播新的铰链变换；切口两侧不作为共享铰链。所有闭环、同一材料顶点和逐面等距均重新验证。不能完全平折的修改当前原子拒绝。 |
| 历史与结果 | 编辑准备成功后才提交一个完整历史帧；折痕与材料合同一起撤销/重做。工程签名改变使旧计算失效，不能把旧层序继续当成当前证明。 |

不变的边界：新增或删除材料边、B 与普通折痕互换、材料与辅助线互换仍需要显式切割/粘合/面归属事务，不能靠同坐标推断。没有旧 FF 时无法确定各片相对姿态。当前支持的坐标编辑必须得到一致的完全平折几何；任意非平折中间态的保存与后续再求解尚未接入。
