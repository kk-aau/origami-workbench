# 共线删除与横截删除

2026-09-18，v0.9.2 开发版，未打包。新增两个真实工具，当前共 62 个工具入口；全工具目标未完成。

- 共线删除（模式 64）：从已有端点／交点、辅助圆心或显示网格点起笔，结束也要求匹配这类点。支持左键拖放和两次点击。仅删除正长度共线重叠的整个已有小段，不裁剪出参考线长度的洞。无效终点保留起点供重选。
- 横截删除（模式 65）：有限参考线命中 proper X 相交或正长度共线重叠；不包括 T 接触、共享端点、延长线相交。支持两次点击／拖放，Ctrl 使用共用角度参数（默认组为 180/8，即 22.5°）。
- 参考线、命中小段均为紫色；参数栏显示命中数。松开或第二次点击才提交，参考线不写入作品。保留固定和光标步骤提示，工具按钮沿用紧凑宽度上限与可调列宽。
- 右击／Esc 取消，空闲右击继续使用通用删线规则。遵守边界保护，一次批量删除只记一次历史。无命中不创建历史，圆对象保留。

## 实现与依据

`lineErase.ts` 提供纯删除提案，Canvas 专用 lineerase 手势负责输入与释放提交；正常 onChange 负责验证、历史。restrictedErasePoint 在端点交点、圆心和显示网格点中取最近点，11 屏幕像素半径，不把圆周四象限点当作受限端点。横截工具仅共享角度参数 UI，不复用角度作图的额外预览或提交分支。

本地上游 MouseHandlerCreaseDeleteOverlapping、MouseHandlerCreaseDeleteIntersecting、BaseMouseHandlerLineSelect、FoldLineSet.deleteInsideLine 与 Worker.getClosestPoint 已静态核对。上游 Java 运行时逐例动态对照仍未完成；目录标基础可用，不宣称完整等价。新工作台增加两次点击流程，网格范围等全局变体仍按全工具计划继续补齐。
