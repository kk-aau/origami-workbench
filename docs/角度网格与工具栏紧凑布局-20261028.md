# 角度网格与工具栏紧凑布局

> 后续变更：用户已撤回自定义角度网格，当前采用“方格／方格＋对角／正三角”三种格式，详见 [正三角密铺网格](正三角密铺网格-20261028.md)。下表的角度输入仅为历史方案记录；工具栏紧凑布局和黑色实心点改动继续保留。

| 调整 | 当前行为 |
| --- | --- |
| 自定义角度网格 | 右侧“画布 → 网格与吸附”开启“角度网格”，直接输入角度，例如 15°、22.5°、30°；默认 45° |
| 角度含义 | 相对水平线的真实角度，生成两个相反倾斜方向的平行网格；矩形纸张也按输入度数绘制 |
| 输入与记忆 | 范围大于 0°、小于 90°；Enter／离焦应用有效值，非法草稿不改变已用角度，Esc 恢复；角度保存到本机偏好 |
| 吸附与显示 | 纸内／全画布、显示开关与网格交点吸附使用相同几何；关闭或缩小到不可见时不吸附隐藏网格 |
| 带网格导出 | SVG／PNG／JPG 使用同一角度；SVG 周期纹理避免按巨大输出范围枚举网格线 |
| 实心交点 | 实心圆和实心方块使用黑色；空心圆、选择及悬停强调色保持原样，SVG、GPU 与导出沿用共享颜色 |
| 左侧工具栏留白 | 分类标题最小高度 30→26px；工具按钮 52→46px；按钮间距 4→3px；组底留白 10→5px，移除空工具网格占位 |

左栏仍显示全部中文工具名，保留图标尺寸和自动列数；拉宽面板后可显示更多列。长标签允许扩高，编辑排版的拖放区域和右栏不受这组压缩规则影响。

其他工作区没有传入自定义角度时，继续保留原矩形单元的对角网格语义。旧保存偏好缺少角度时补为 45°；修改网格颜色或线宽不会清除已选角度。
