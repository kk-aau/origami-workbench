# 直线、射线和批量参数重放（2026-10-09）

三种材料构造接入曲线/闭合线网参数模型，可保存、重开、修改并顺序重算后组。完整 Origamica 目标仍在进行，免安装版未更新。

| 入口（折痕编辑 → 纸张属性/选区） | 最终效果 |
| --- | --- |
| 编辑材料折痕 → 跨面直线构造 | 默认保存端点、部件、赋型、固定侧及仅CP设置；单面插入和删除仍保旧流程。 |
| 材料射线构造 | 默认保存来源边比例、方向点和设置；反向、孔洞与空白不补线。 |
| 批量材料构造 | 保存直线列表、固定点及分段赋型，完整构造后采用。 |
| 参数构造组 | 五种配方分别打开原可视编辑器；修改前组重算后组，删除先预览，失败整次拒绝。 |
| 失效模型 | 显示归档说明，以当前实际材料建新基底，保旧配方和手工修改；关闭保存开关保原几何流程。 |
| 保存与历史 | JSON/FOLD重开可编辑，取消不提交，一次撤销/重做完整恢复；保原坐标、切口侧、FF、辅助线、颜色和纸张。 |

原材料模型缺少会被细分的边端点引用。本批新增v3及来源边引用：基底边或前组生成边、沿边比例和来源分段数量。端点沿同一编号边的真实后代定位，不按附近坐标匹配；同坐标切口两侧独立。共享同一索引顶点的两条后代可表示同一材料角，其它歧义、来源删除、分段身份变化或后组重叠均拒绝，要求重选后组端点，不静默吸附、转绑或跨空白连接。

比例转换存在浮点末位差异。独立核查仅容许同一边64倍机器精度比例差或同一索引顶点的边端表示，重放仍采用保存比例，不改已采用几何；最终快照严格对比。此修复避免合法模型被误判失效归档。v1/v2继续读取，后续曲线/线网不把v3降级；组与归档上限仍各8。
