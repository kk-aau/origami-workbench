# 闭合校验开关

折序三维模拟窗口上方增加“严格闭合校验”，默认开启，选择通过现有偏好服务保存，重开窗口后记住。设置键采用宿主支持的格式 `zhezhi.diagram-simulation-strict-closure.v1`，不修改宿主白名单。

| 状态 | 应用当前折角 |
| --- | --- |
| 开启 | 保留现有闭合校验、±0.25° 附近修正和最终几何验证；通过后记录 verified=true |
| 关闭 | 跳过闭合求解及附近修正，直接写入映射得到的实际角度，记录 verified=false，并提示“闭合未确认” |

来源 CP 失效、非有限或退化姿态、折痕映射缺失、同一物理折痕发生弯曲、山谷方向冲突等验证不受开关影响。关闭后不修改实际测量角来伪装闭合，也不生成虚假的已验证纸面。仅影响“应用当前折角到折痕”，截图和应用曲面保持原流程。

Worker 请求显式携带选项，旧调用默认仍严格验证。闭合状态保存在 CP 元数据 `diagramSimulationClosure`，正常联动 CP 应用和工程保存重开保留此状态；后续重算继续按实际几何判断。

开发验证：构建通过，20 项折角与曲面相关测试通过；覆盖原先不闭合输入在开启时失败、关闭时可应用、原文档不变、开关不跳过来源和山谷方向保护。浏览器实际验证默认开启、关闭提示、重开记住和重新开启，宿主偏好文件实际写入确认，控制台无错误。证据 `.runtime/closure-switch-qa/enabled.png`，测试日志 `.runtime/closure-switch-tests.log`。
