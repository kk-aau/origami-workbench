# 前后 CP 之间的重折动画

两端 CP 都能平折，并不代表每条折痕独立插值就能得到连续动作。2026-10-15 的截图案例包含撤销部分旧谷折、增加新山谷折的转换；如果把两端角度相同的旧折痕全程锁定，现有刚性路径搜索找不到合法中间姿态。

| 处理 | 行为 |
| --- | --- |
| 优先直接折叠 | 先保持所有未变化折角，搜索同步、联动和分批路径 |
| 必要时尝试重折 | 仅在几何路径搜索失败、同时存在展开旧折和新增折叠时启用 |
| 确定相关旧折痕 | 从发生变化的铰链出发，经内部材料顶点传播到原已折铰链；纸边顶点不连接独立纸瓣 |
| 临时展开 | 为相关旧折痕增加动画专用的 `viaAngle: 0`，经展开姿态再到目标折角 |
| 固定区域 | 保留全部原固定顶点及其坐标，不缩小固定侧 |
| 用户数据 | 不修改前后 CP、绘图工程、真实折痕或纸层数量 |
| 安全检查 | 重新验证角度指令、纸面刚性、材料连接、初始离层方向、全区间碰撞与纸层时间线 |
| 自动取景 | 载入时按完整运动范围固定相机，防止目标纸面移出画布；不改变材料尺寸或逐帧追踪缩放 |

已有明确预折指令的步骤不会被自动重折策略覆盖。碰撞或未能完成安全证明的直接路径也不会触发该策略；它补充几何候选，不把失败的安全检查当作成功。

多顶点机构的第一个闭合解可能具有不合适的相对速度。规划器在碰撞检查失败后继续尝试其他驱动与初值，并对只通过一个刚体连接的独立铰链块尝试同步配速。所有候选均通过同一完整验证。

连续分离证书可消去两三角形全部顶点共有的刚体祖先变换，在随动坐标系内证明相同的半空间分离关系。公共刚体变换保持距离和相交关系，因而无需改变碰撞容差或时间预算。中途共面换侧检查仍使用原世界坐标轨迹。

另修复了短预折恰好位于已有长 F 折痕上的端点丢失：预折意图以 F 几何加入私有材料分割，山谷方向只用于动作，不写回 CP。
