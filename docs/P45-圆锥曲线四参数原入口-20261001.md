## 九规则原序及分数结构

输出顺序固定为 `CurvedFold2D`、`DirectrixLeft2D`、`DirectorLeft2D`、`CrossCurveLeft2D`、`SecondCrossCurveLeft2D`、`DirectrixRight2D`、`DirectorRight2D`、`CrossCurveRight2D`、`SecondCrossCurveRight2D`。原第一截线确切返回各侧直截线 `cl/cr`，保留这两个重复规则。

记左／右焦点为 `l/r`，第二截线参数为 `h/k`，参数为 `t`，左右直截线为 `L/R`、方向为 `d/e`、第二截线为 `E/H`，返回 `[f,L,d,L,E,R,e,R,H]`。

| 分支 | 原字面公式 |
|---|---|
| 双无穷 | `f=(0,t)`；`L=E=(h,t)`；`R=H=(k,t)`；`d=e=(-1,0)` |
| `l=r` | `f=(l-l cos t,-l sin t)`；`L=R=(l,0)`；`d=e=(-cos t,-sin t)`；`E=(l+(h-l)cos t,(h-l)sin t)`；`H` 中将 `h` 换成 `k` |
| 单侧无穷 | 有限焦点 `a`，有限侧参数 `v`，`D=4a²+t²`：`f=(t²/(4a),t)`；有限直截线 `(a,0)`；有限方向 `(1-8a²/D,4at/D)`；有限第二截线 `((4a²v+(2a-v)t²)/D,4a(a-v)t/D)`。无穷侧为 `(h,t)` 或 `(k,t)`，方向 `(-1,0)` |
| 一般有限 | `P=l+r+(r-l)cos t`；`f=(l-2lr cos t/P,-2lr sin t/P)`；`L=(l,0)`，`d=(-cos t,-sin t)`，`E=(l+(h-l)cos t,(h-l)sin t)` |
| 一般有限右侧 | `q=tan(t/2)`、`D=r²+l²q²`；`R=(r,0)`；`e=(1-2r²/D,-2lrq/D)`；`H=(-k+2r(1+r(k-r)/D),2lr(k-r)q/D)` |

数值核允许等值且保孔的消减改写：圆的 x 为 `2l sin²(t/2)`；一般折痕分母为 `2l sin²(t/2)+2r cos²(t/2)`，x 为 `2l(l+r)sin²(t/2)/P`。右侧原 `tan(t/2)` 仍真实求值；不将其改成无孔的 sin/cos 延拓。线与抛物线的 t 为有符号长度，圆与一般有限分支的 t 为弧度。

焦点没有人为正下限。真实极小参数若有限字面运算下溢而无法核验，明确 `source-numerics` 拒绝，不能把它称数学无解。未知字段、错误侧无穷、0 焦点、空值、NaN／Infinity、重叠域或伪造参数严格拒绝。

一般有限分支在奇数 π 具有原 `None` 下 `tan(t/2)` 的字面孔。异号焦点另有折痕分母极点 `t=±2 atan2(sqrt(abs(r)),sqrt(abs(l)))+2nπ`。预检用 80 位计算和浮点包围记录真实极点；域内部出现真实极点即 `source-pole`，保原域拒绝，不替用户裁域、跨枝连线或改分支。两侧对等幅异号焦点产生原一般分支的退化直线，原分母孔仍保留。相等焦点先进入圆分支，因此可以穿过 π，不借一般分支错误门禁拒绝圆。

浮点 `Math.PI` 略低于实数 π；例如 `[0.1,Math.PI]` 采样可能全部有限，但向外区间无法消除端点附近的字面孔不确定性，输出完整九规则与全部域，状态为 `unknown`，不冒充整域已证。

## 独立回读、几何证据与 UI
