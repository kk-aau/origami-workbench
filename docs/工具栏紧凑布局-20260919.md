# 工具栏紧凑布局

两侧绘图工具栏采用固定布局，全部工具直接显示，没有滚动和分页。

- 左侧默认加宽到 400 px，自动排列 8 列，也可手选 6 / 7 / 8 列。65 个绘图、选择、编辑和扩展工具同时显示。
- 右侧默认宽 252 px，4 列显示 28 个角度、圆、标记与测量工具；检查和整理操作放在右上。
- 撤销、重做和新线类型合为一排；网格数量、倍增、减半、重置和显示范围并排排列。边界保护、吸附和保持选择固定在底部。
- 短标签最多四个汉字，完整名称、操作方法及快捷键保留在悬停提示中。详细解释通过“？”查看。
- 纸张或选区属性、剪贴板和底图由右下按钮打开独立设置窗口；修改线型、坐标、目标角、变换、剪贴板偏移和底图配准功能保留。
- 工具按钮根据可用高度压缩；较窄窗口自动调整列数。低于桌面应用最小尺寸的 800 × 600 浏览器窗口，左栏使用图标，名称仍可通过悬停和无障碍标签读取。

验证：

- `npm run build` 通过。
- 布局、工具映射、网格、面板宽度与快捷键相关 20 项测试通过。
- 1366 × 768、1000 × 720、1024 × 640、1600 × 1000、800 × 600 实际浏览器中，93 个工具都直接存在且唯一；检查全部按钮位置，没有滚动或裁切。
- 已验证网格等分与增减、重置、边界开关、保持选区、帮助与属性窗口、剪贴板复制、底图配准入口及工具快捷键。
