日期：2026-10-28。本版仅本地交付，未上传发行站。基于迁移版持续开发，保留完整离线计算引擎，原 `workbench/` 不变。系统须已有 WebView2，无需另装 Node 或 Python。

| 本次变化 | 行为 |
|---|---|
| 已有折痕角度 | 选中已有山谷折线后修改角度并应用，实际更新选中折线；保留选择，支持撤销、重做和保存重开 |

| 操作入口 | 折痕编辑、折序主图和操作 CP 使用一致的选择后修改方式；选择本身不修改几何 |
| 高级分组 | 绘制中的圆、多边形及相关几何工具移入“高级”；旧默认布局自动迁移，自定义布局保留 |

保留原生文件保存、纸边重合过滤、纸层搜索，以及真实空间主图与步骤动画。空间分支不支持有限短折痕的柔性压痕；不相容的刚性折角仍会明确提示，几何终态不代表连续运动无碰撞。
