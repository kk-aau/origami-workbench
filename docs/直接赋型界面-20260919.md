# 直接赋型界面

新增“直接赋型”四按钮：改为山折、改为谷折、改为边界、改为辅助线。当前共75项实际工具入口，仍非全工具完成。按钮沿用限宽、可调最多四列布局，各有专用线形图标；参数条显示固定目标和预览命中数量，不改变绘制预设。

复用类型编辑的点按／接触框手势和紫色预览，但命中与提案调用 directAssignment 核心：普通最近线等距按文档先后，辅助反向优先，辅助仅转换山谷边界且不穿透不合格近线。框选与拖动方向无关，按下／拖动不改作品，释放一次提交；鼠标移动4像素以上按拖框处理，与其它工作台框工具保持一致。

右击或Esc取消正在进行的手势；空闲右击保持通用删除。固定指南与鼠标旁提示说明当前操作。边界保护、零和未指定折角、交点真实小段、撤销重做及保存恢复均保留。

验证：直接赋型26、原类型筛选29、取消优先级17、通用交互98，共170项交互断言通过；462单元与构建通过。最后更新图标和提示文案后重新构建并重跑直接赋型26项；direct-assignment.png已检查，控制台无错误。原版运行时逐例对照尚未完成，目录仅“基础可用，上游动态对照待验”。
