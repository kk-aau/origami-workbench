# P16：原版整体拼块的折后装饰

原版 `RenderTile[..., FoldedForm2D]` 要求折后 `TileVertices` 与原拼块相似。按 `MonolithicEmbedTiling` 默认删除共享边并清理共线点后，工作区以前只接受“每个折后面恰属一块拼块、每个原拼块角点仍是折痕顶点”的情形，因此原版 In[2984] 四方格在真实平折画面不能显示拼块边线和编号。

现在对每个已验证的可见折后区域使用其最上层纸面的等距映射：先把原拼块与该纸面相交，再将交集折到平面，按原拼块边界裁剪可见区域。原版合并模式下，折后面有时跨过两个拼块，即使生成器仍按面心给它一个拼块编号；这里以实际几何交集为准。清理中消失的共线角点从相邻纸面的等距映射重建，并检查所有候选映射一致、整块折后角点与原角点相似。只有局部遮挡顺序已解、面内映射一致且可见面积由拼块恰好覆盖时才显示边线与编号；否则不猜测。

回归输入是原版 In[2984] 的四方格、`w=.18`、`α=30°`、`V/M/M/V`，显式使用 `KillMergedEdges→True` 与 `CollinearCleanup→True`。本项目生成 36 点、60 边、25 面，其中 5 个面的原始拼块归属为 −1，另有按面心归属却跨越拼块的面。正反面各有 719 个遮挡分区，按实际拼块裁剪后各为 788 个可见片段；面积守恒、四块编号、12 个被清理的角点、错误输入拒绝、200 单位画布缩放及 SVG 输出均有专项测试。隔离浏览器在 1000×720 下实际完成构造、开启装饰、计算平折和正反面切换，四块编号与边线均可见；截图为 `output/playwright/p16-original-merged-ff-front.png` 和 `p16-original-merged-ff-back.png`。图元数和分区数是本项目回归值，原笔记本没有保存此例可直接逐点对照的折后图。

尚未覆盖任意 Mathematica 符号表达式以及不能证明相似或层序的拼块折后装饰。原版镶嵌章节未保存具名拼块的专用 `TGraph3DAssigned` 分派，任意 3D 拼块装饰不列为本项复现门槛；平折边线和编号本身也不代表获得三维形状或连续折叠路径。
