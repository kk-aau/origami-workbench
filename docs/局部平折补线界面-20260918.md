# 局部平折补线（v0.9.2，未打包）

工具栏“折纸公理”组新增局部平折补线，当前46项实际工具。沿用紧凑网格、中文分步提示和紫色参考。

## 用法

1. 点击已有奇数度折线顶点。空白网格点、仅辅助线顶点、偶数度顶点不能开始。
2. 多个候选时，点击紫色方向或上方编号按钮；单候选自动选中，跳过此步。预览长度使用当前网格间距，不是实际新线长度。
3. 点击该方向前方的实际线段或纸边作为截止。没有明确有限交点不生成；失败保留输入，右键／Esc可取消。

只有一条邻线时，按原方向反向延长并保留原线型和折角（包括未知角null）。多邻线时，新线采用当前绘制预设；切换山谷不清除已选顶点或方向。参考折线不改动，生成与真实分割为一次撤销步骤。

这只满足局部交替角和条件，不验证山谷分配、层序或整个模型可折。界面持续显示这个限制。未知山谷参与角度计算、辅助与平面边不参与，详情见核心说明。
