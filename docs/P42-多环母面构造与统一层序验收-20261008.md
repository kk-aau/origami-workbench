# 多环母面构造与统一层序验收（2026-10-08）

本批把有限直线母图的真实多环面接入生成、可视编辑、回展、材料采用和平折及普通导出。完整 Origamica 复现目标继续，未打包或发布免安装 EXE。

入口：镶嵌设计 → 线组编织 → “多环母面 · 内部环孔”；编辑母图中先选择原面，再选择位于该面内部的独立简单闭环并点击“设为环孔”。“定位此圈”只放大视图，方便修改小孔，不改变源坐标。

| 原问题 | 实现后的行为 |
| --- | --- |
| 只能挖掉已有内部单元，单个母面没有内环 | 增加 `graph.ringHoles:[{face,component}]`，绑定原半边面及原独立轮廓部件。该轮廓成为母面的内边界，内部有界面移除，原顶点/边编号、位置及数量保留；不补桥接线。 |
| 轮廓嵌套可能被误当作独立纸片 | 真实环孔与前批 `nestedSheets:true` 是不同的明确输入。没有声明的轮廓继续拒绝；不自动猜测或切换语义。 |
| 内缩、构造和回展只遍历外圈 | 每个内外环按自己的方向求原相邻偏移线交点，逐环生成角点及原赋型；内环参与边面关联、刚性映射、切口拆分和文件保存。生成后的内孔方向、严格包含关系及来源均核对。 |
| 源边连接性无法表示内孔与外圈属于同一张材料 | 从明确环归属派生物理母图片组，面连接内外圈，而不是添加线段连接。支持与旧内部单元孔洞组合；不同实际纸片仍有独立回展根。 |
| 底层库按角度删掉狭长三角形角点 | 保留实际三角形，用同一线性坐标容差验证边长及高度；按原三角形做重叠和层序约束。原未删点路径及内部点候选保留，确实低于坐标容差的片仍拒绝。 |
| 私有三角化边被误当成真实折叠接缝 | 私有J边不作为原折叠接缝参与taco接触判定；原面统一层序变量保证各辅助片在同一层。原折痕接触、M/V约束及相同约束表保留，辅助点边不进入公开CP/DXF。 |

模型核对仍独立重建源角点、边赋型、刚性FF、回展及孔环归属，不信任后台“验证通过”旗标。环孔变化即使不改变点边数组也使旧CP/FF失效；恢复、重新绑定、取消和草稿撤销重做保持一致。绑定后改点边拓扑需先恢复原孔洞/独立圈，避免面或部件编号被静默转移；可以直接拖动原点或精确改坐标。

## 范围与剩余内容

本入口支持有限直线、简单且互不接触的内部轮廓，明确绑定至原有简单母面；同面环孔不能相互包含、跨边界或与母图相接。轮廓中若有其它源边，不能当作空洞静默删除；应先显式编辑成简单闭环。输入仍遵守512点、1024边、32组环孔及原4/6/8度与内缩角门槛；层序预算与求解失败/unknown门禁保留，不能承诺任意输入都可解。

原线网自动拆分来源尚不能附加这种手工环关联，需使用手工有限母图；任意曲线、触碰孔洞、单桥/弱简单面及更复杂交叠轮廓仍是其它未完成域。完整目标还剩≥10偶度有效编织、开放材料线网/自由射线起点、曲线批量、复杂切口合并、任意非平折编辑，以及未复现的Wolfram输入语义/选项/插值及未证数值全域。

最大规模与任意组合性能、原版Wolfram保存Out逐点等价、原生免安装交互、外部FOLD/刻字软件及实机结果、连续无碰撞折叠未验证。不操作设备、不承诺实机提速、不自动发布。冻结清单 `output/audits/woven-multiring-final-1008.json` 与归档 `woven-multiring-artifacts-1008/`，旧证据不覆盖，完整目标保持active。
