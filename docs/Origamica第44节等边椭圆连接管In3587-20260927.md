# 第 44 节 In[3587]：24 边等边椭圆连接管

原版只读副本 `tmp/Origamica-15.0-reference.nb` 的 In[3587]（280706–280776）保存了 `m=24`、`a=GoldenRatio`、`b=1`、`dz=0.2`，以 `DiscreteEllipseEquilateral[m,{a,b}]` 构造下圈，再取 `RotateLeft[(RotationMatrix2D[90 Degree].#)&/@botpts2d,3]` 为上圈，最后调用 `TwistJoinedTubes[botpts2d,toppts2d,dz,PanelOverlap->True]`。原版 In[458]（28496–28599）的等边椭圆定义是极径点列、首点角度 `φ=0`、24 条相邻弦等长的数值方程；它使用 `FindRoot`，并未保存本例可逐点读取的 Wolfram 数值 `Out`。

现有管构造已支持任意经周长校验的点列，但没有可直接选择的这个原版保存输入。工作区的“扭转连接管”现增加 **原版等边椭圆 · 24 边** 按钮；其固定点列求解上述等弦长方程，顶圈严格按原版先旋转 90° 再左移 3 位，并经 `readTessParams` 严格读回。固定数值样例不会扩展为任意参数的 Mathematica `FindRoot` 解释器；用户仍可在已有截面编辑器中编辑点列。

| 来源约束或采用门禁 | 数值检查 |
| --- | --- |
| 首点 `(GoldenRatio,0)`；全部点满足 `x²/GoldenRatio²+y²=1` | 最大椭圆方程误差 `<10⁻¹²` |
| 24 条相邻弦等长，闭合弦包含末点至首点 | 边长约 `0.346217849171274`，最大差 `<10⁻¹²` |
| `top[j]=Rot90(bottom[(j+3) mod 24])`；上下圈周长一致 | 逐点误差 `<10⁻¹²`，严格参数读回通过；将上圈放大 `1.001` 倍会被拒绝 |
| 原版扭转连接管展开与静态空间面 | 104 点、203 边、100 面；二维几何 `passed`；原方程残差 `<10⁻⁸`；逐面全部顶点对 2D/3D 距离误差 `<10⁻⁹` |
| 分级结果 | `local=not_applicable`（空间状态）、`layerOrder=not_checked`；`continuousRigidPathChecked=false`、`selfCollisionChecked=false` |

专项回归 `npx tsx --test tests/app/joinedTubeParams.test.ts` 将来源椭圆、等弦、旋转移位、工程参数读回和后端生成连成同一测试。几何通过表示该展开图和一个静态三维状态逐面等距，不表示已证明可连续刚性折到该状态、无自碰撞或存在平折层序；原版的 `TwistJoinedTubes` 也没有自动自交检查。由于保存本没有数值 `Out`，上述点列是对原版保存方程的独立数值解，不能称为逐点 Wolfram 输出对照。

生产构建浏览器实测“原版等边椭圆 · 24 边”输出 104 顶点／203 边，界面明确显示“静态三维等距已验”和连续折叠、碰撞未检验；截图见 `output/playwright/p44-in3587-ellipse-tube-live-20260927.png`。
