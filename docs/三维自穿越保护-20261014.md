# 三维自穿越保护与验收（历史记录）

**当前状态：本机制已按用户要求取消，不再生效。** 自穿越检测后的回退与暂停、接触检查预算、初态穿透拒绝及接触后停止播放均已撤回；原有非有限值与应变保护、100%近共面显示稳层和“红蓝／折痕”样式保留。以下仅记录此前实施和验收时的行为，测试结果不代表当前仍启用该机制。

此前用户确认“红蓝／折痕”已显示，环状镶嵌和自己的CP在100%仍出现穿透。当时复现了求解网格的真实穿面，并新增穿越检查与回退暂停。显示微层只处理近共面残差；该次新增机制现已取消。

## 历史修改

| 项目 | 行为 |
|---|---|
| CPU／GPU推进 | 每个数值步检查线性扫掠；不等整批20步完成后才检查 |
| 检测 | 移动顶点—三角面与边—边的共面三次多项式；两端不相交但途中穿越也检测 |
| 合法贴合 | 共享整边的邻面、精确共面零厚度贴合允许；仅共享点的面仍检查内部 |
| 初态 | 严格检查输入3D姿态；已穿透或未完成检查的输入拒绝加载，不将其保存为安全回退点 |
| 回退 | 同步CPU／GPU全部位置历史并清除动态速度；GPU重算真实应变；目标、材质、约束、原始坐标保留 |
| 界面 | 接触时暂停并提示目标尚未达到；停止自动播放；单步不能绕过，旋转与样式切换不重新启动求解 |
| 导出 | 三维几何使用回退姿态；FOLD标题与说明记录目标未达到，不冒充100%完成结果 |
| 检查预算 | 最多20,000候选对、20ms；同一未发布姿态允许一次有限重试，仍不完整则回退暂停 |

修改集中于 `src/engine/simSelfContact.ts`、`simCollisionGuard.ts`、`simframe.ts`、`simulator.ts`、`simDisplay.ts`、三维控制与教程，及vendored求解器的姿态恢复接口。默认求解器步进计算路径不变；用户工程和镶嵌实现未改。

|---|---|---|---|
| 默认环状镶嵌 | 第156尝试步，面89／92 | 第156尝试步，面89／92 | 834候选对检查完成，容差外无横向穿透 |
| 保存的手风琴CP | 第208尝试步，面0／5 | 第208尝试步，面0／5 | 21候选对检查完成，容差外无横向穿透 |

第156步的CPU连续事件时间约0.325962，恢复第155步姿态；显示步数保留尝试次数。此时目标仍为100%，实际形态尚未达到。不能把回退停止当成完成折叠。保存的手风琴用于真实自定义CP路径回归，用户此次未提供的其他CP未逐一验证。

复现数据位于 `output/simulation-self-contact-ring-*.json`；最小回归输入位于 `tests/fixtures/simulation-self-contact-default-ring.fold.json` 与 `simulation-self-contact-saved-accordion.fold.json`。没有改写 `data/projects` 原工程。

## 历史实现边界

这是防止继续穿越的检测和暂停保护，尚未实现完整的接触响应、滑动、摩擦或纸厚。复杂环状与自定义CP可能会停在达到100%之前；用户需要的任意复杂CP无穿透连续折至100%尚未完整实现。

检查覆盖每一步之间的线性扫掠及浮点容差。静态／端点近共面残差使用归一化半径的5e-4和法向平行度2e-3，与此前显示稳层相配合；真实动态两侧换位即使落在该距离内仍检查。几何导出保留真实坐标，不保证数学意义上的严格零自交或正确物理层序。检查超时、非有限值、端点三角面塌缩均不能被报告为安全。
