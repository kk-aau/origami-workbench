# 构造工具网格交点吸附修复

日期：2026-10-28。仅修改迁移版，日常开发验证，不打包、不上传、不改版本。

## 问题与修复

普通画线使用了有限线段与网格的交点，但通用构造取点没有传入线段，受限取点也只有顶点、圆心和网格节点。因此，紫色参考线的端点或辅助圆等构造点会停在实际交点附近。

| 入口 | 修复行为 |
| --- | --- |
| 通用构造取点、标记、等分／比例绘线、射线前两点 | 使用可见有限线段与实际网格的精确交点；不额外吸附任意线身 |
| 受限圆、测量等受限取点 | 加入线与网格交点，保留纸面范围、孔洞和原有距离／等距优先规则 |
| 角度拖画、角度投影 | 已确定方向可在网格线交点结束，预览、鼠标取点与提交使用相同计算 |
| 镜像轴第二点、可折取点 | 接入同一有限线段集合；镜像第一点点击线身仍选择对象 |

方格、对角及正三角网格共用真实网格几何。用户后续已撤回自定义角度入口，改用正三角密铺格式。隐藏网格、隐藏参考线不产生新的交点吸附。自由构造遵循吸附开关；受限工具仍保留其必须选择合法参考点的原有规则。要求实际截止线的步骤仍必须选择真实线段；四点变换、局部补线和底图配准仍保留真实顶点限制。

构造吸附只查询鼠标附近交点，不为整个大工程预先生成全部线网格交点。用户折痕、网格数据及原始工程不被吸附查询修改。
