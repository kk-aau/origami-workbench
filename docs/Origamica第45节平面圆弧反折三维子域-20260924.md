# Origamica 第 45 节：从平面圆弧反折三维的严格子域

这一实现针对 `tmp/Origamica-15.0-reference.nb` 的 `FoldCurvedFold3D` 与 `NFoldCurvedFold3D`，只覆盖原版保存的正、负 `120°` 双侧圆弧示例。它接收一个封闭的族选择 `orientation=±1`，返回同一条折痕两侧的连续解析直纹面，并提供对应点的数值取样。它不接受任意平面曲线或母线函数，也不接入共享路由和画布。

## 原版输入契约与保存证据

原版函数说明在 324616–324747 行：输入为二维折痕 `f`、平面左／右母线 `rL/rR` 和初值 `{ui, γi, ffi, tti, bbti}`；后四项分别是初始折角、三维位置、切向、位于两侧中间的上侧副法向。解析函数 In[3972] 定义在 324797–325065 行，返回 `{ff,rrL,rrR}`。数值函数 In[3977] 在 325518–325768 行额外要求区间 `{u0,u1}`，允许插值函数输入，使用 `NDSolve` 和 `FunctionInterpolationAlt`。

两版核心方程一致。先由 `Curve2DSystem` 或 `NCurve2DSystem` 求速度 `ds`、左曲率 `κl`、单位切向 `t` 和左法向 `l`（解析版 324854–324864；数值版 325554–325567）。将左／右母线投影到该标架，其中 `sρL=l·rL`，但 `sρR=−l·rR`（324866–324913；325569–325610）。折角由

```text
γ′ cot(γ/2) = ds κl (cotρL − cotρR),   γ(ui)=γi
κ = |κl| sec(γ/2)
τ = ½ tan(γ/2) κl (cotρL + cotρR)
```

决定，见 324915–324976 与 325612–325677。然后以 `{ui,ffi,tti,Sign[κl(ui)] bbti}` 恢复三维 Frenet 曲线（324978–325000；325679–325703），把平面母线的切向／横向系数带入三维左右直纹母线（325002–325065；325705–325768）。原函数遇到折角积分失败会报 `nosoln` 并中止，不能据此假定任意输入都有解。

保存的解析示例 In[3973]（325107–325225）指定 `u∈[0,π]`、`f=(-1+2cos(u/2),2sin(u/2))`、`rL=(-cos(u/2),-sin(u/2))`、`rR=-rL`、`γi=+120°`；In[3974]（325235–325351）把 `f` 镜像成 `(1−2cos(u/2),2sin(u/2))`、`rL=(-cos(u/2),+sin(u/2))`、`rR=-rL`、`γi=−120°`。两例初值同为 `ui=0`、`ffi=(1,0,0)`、`tti=(0,1,0)`、`bbti=(0,0,1)`。保存的数值示例 In[3978]（325818–325957）和 In[3979]（325967–326085）用 `FunctionInterpolationAlt` 对相同两组输入在 `[0,π]` 数值化，再调用 `NFoldCurvedFold3D`。这些单元保存的是输入及绘图调用；闭合单元后没有可直接比较的 Wolfram 数值 `Out` 点表。以下闭式与数值是由源码方程及初值推得的本地结果，不是 Wolfram 内核逐点输出。

## 源方程导出的闭式解

令 `ε=orientation∈{+1,−1}`；`ε=+1` 对应 In[3973]/In[3978]，`ε=−1` 对应 In[3974]/In[3979]。两组可统一写成：

```text
fε(u)  = (ε(2cos(u/2)−1), 2sin(u/2))
rL(u)  = (−cos(u/2), −ε sin(u/2))
rR(u)  = −rL(u)
γε     = ε 2π/3
```

两条平面母线都是单位法向，`ds=1`、`κl=ε/2`，且 `cotρL=cotρR=0`。折角初值问题在该子域唯一给出常角 `γε`，因此源式得 `κ=1`、`τ=0`。原版把初始副法向乘以 `Sign[κl]=ε`，所以 Frenet 初值为 `F(0)=(1,0,0)`、`T(0)=(0,1,0)`、`B(0)=(0,0,ε)`。解出：

```text
Fε(u)  = (1−ε+ε cos u, sin u, 0)
RL(u)  = (−½ cos u, −ε ½ sin u, ε √3/2)
RR(u)  = ( ½ cos u,  ε ½ sin u, ε √3/2)
```

空间母线是源码 `σ(cos(γ/2)N±sin(γ/2)B)` 在 `σ=ε`、左右横向系数分别 `+1/−1` 下的结果。两个空间曲面及对应平面曲面都按 `X(u,v)=crease(u)+v·ruling(u)` 定义，`v≥0`。

对四个连续曲面直接微分，左右两侧分别得到完全相同的二维／三维第一基本形式：

| 侧 | `E=∂uX·∂uX` | `F=∂uX·∂vX` | `G=∂vX·∂vX` |
| --- | --- | --- | --- |
| 左 | `(1−ε v/2)²` | `0` | `1` |
| 右 | `(1+ε v/2)²` | `0` | `1` |

`RL′=−ε F′/2`、`RR′=ε F′/2`，故两侧 `det(F′,R,R′)=0`，均为可展直纹面。以 `nL=T×RL`、`nR=−T×RR` 作为纸张两面的连续法向，`atan2(T·(nR×nL),nL·nR)=ε 2π/3`，保留了折角符号。`ε=+1` 左带的焦线在 `v=2`，`ε=−1` 右带在 `v=2`；模块保守要求两侧宽度都严格小于 2，保证取样区域内的局部浸入正则性。这里证明的是连续曲面等距和可展，离散取样的对应弦段通常并不等长。

## 独立接口与验证

模块 `backend/tessellation_curved_fold_from_planar_circle.py` 提供：

```python
from tessellation_curved_fold_from_planar_circle import (
    fold_curved_circle_3d, nfold_curved_circle_3d,
)

fold = fold_curved_circle_3d(orientation=1, left_width=1, right_width=1)
fold.exact_expressions(sympy.symbols('u', real=True))
fold.frame(0.5)
fold.surface(3, 'left', 0.5, 0.25)
fold.first_form(3, 'left', 0.5, 0.25)
samples = nfold_curved_circle_3d(orientation=-1, curve_segments=64)
```

`nfold_curved_circle_3d` 对已解出的源折角／Frenet 初值问题进行闭式数值评价，覆盖保存的两个 `NFoldCurvedFold3D` 输入；它不复制 `NDSolve` 或 `FunctionInterpolationAlt` 的插值阶数和逐点舍入。结果保留共用折痕索引、两侧的二维／三维同索引取样和参数距离，并明确标记离散弦段非精确等距、部署路径与自碰撞尚未检查。它不输出三角面或直折痕 FOLD。

专项命令：在 `workbench/backend` 运行 `..\.venv\Scripts\python.exe -m unittest test_tessellation_curved_fold_from_planar_circle -q`。4 项测试通过，分别独立核对原折角 ODE 和 Frenet 初值、两侧连续度量与可展性、有符号折角、数值锚点及输入／焦线拒绝。通用曲线输入、非常折角、非均匀螺旋 In[3980] 与 Wolfram 插值一致性仍在本子域之外；不能据当前结果推断任意输入的求解成功或有限纸张的整体无碰撞折叠。
