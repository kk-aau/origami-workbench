# 第 43–44 节：空间构造进入镶嵌工作区

工作区现可从构造面板选择第 43 节 `MakeRadialPot` 的平面、多边形、圆弧三种边缘，以及第 44 节 `TwistJoinedTubes`、`DoubleJoinedTubes`、`ClosedTwistToppedTube` 三类管状主体。参数改动由原有镶嵌候选生成链路调用本地 Python，返回同一顶点索引的二维展开 FOLD 与真实三维坐标。候选折痕图、静态三维构形在同一画布切换；可将通过当前几何检查的展开图作为副本带到折痕编辑。

空间候选只有当 `source.spatialKind`、`staticGlobalIsometryChecked`、`foldedForm3D` 都存在且可信时才可显示和采用。前端独立重算每个面的所有顶点对距离与共面性，验证边索引和面面积，并要求当前参数签名一致；`local: not_applicable` 不会被误读为“平折已解”。这里确认的是单个三维状态的面内等距，**不是**从展开图连续折到该状态的路径，也不证明无自碰撞。

原版 In[3480] 的壶体样例按平面、多边形、圆弧边缘分别得到 `101/200/100`、`106/205/100`、`161/260/100` 个点／边／面；三者在正反视角的实体面遮挡顺序都通过测试。原版 In[3584] 的扭转连接方管为 `24/43/20`；In[3600] 的双连接管为 `28/51/24`；In[3566] 的封顶扭转方管为 `23/37/15`。这些样例的所有静态面误差均小于 `1e-12`。双连接管和封顶管有几何重合且朝向相反的面；当前遮挡次序无法由静态投影唯一确定时，画布显示线框，不把它渲染成看似可信的彩色实体。扭转连接管与三类壶体可显示实体正反面。

前端回归 `tests/app/spatialMeshView.test.ts` 覆盖六种真实后端输出、正反视角、当前参数采用，以及伪造等距、缺失索引和退化面拒绝；`tests/app/joinedTubeParams.test.ts`、`tests/app/closedTubeParams.test.ts` 覆盖保存参数恢复与无效几何。后端分发专项 `backend/test_tessellation_twist_joined_tube_candidate.py` 与各构造模块专项覆盖原版输入与静态等距。原版笔记本没有保存这些示例的完整 Wolfram 数值输出，因此这里的点／边／面与方程锚点不能代替逐顶点 Wolfram 内核对照。

真实浏览器在 `1000×720` 和 `1600×900` 两个视口共运行 28 次后端构造，覆盖壶体三种外缘、扇区数 5→6、剖面编辑、三类管的数值与截面／会聚点编辑；每次均返回 HTTP 200、二维几何通过、静态三维等距已验、当前候选可采用。两视口中三维拖转、展开／三维切换和采用副本回折痕编辑均通过，页面没有运行时错误、文档横向溢出，几何弹窗按钮均可见。证据在 `output/playwright/spatial-p43-p44-browser-report.json`。检查同时发现并修复了空间家族切换时携带 `paper: undefined` 令后续调参失效的问题。

仍未复现连续刚性折叠路径、面间自碰撞和纸厚。壶体的非等距法兰内缩已在第 43 节三类壶体中单独作为显示副本接入，真实 CP/FF 保持未内缩的等距坐标；详见各 P43 专项文档。管状极端参数的所有求根分支也没有全域证明。
