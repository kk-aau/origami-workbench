# 折序模拟连续调角

| 项目 | 实现 |
| --- | --- |
| 180° 模拟保护 | 移除折序三维对话框开关，不读取旧偏好；载入明确关闭自动折角暂停 |
| 细分网格 | 折序模拟固定原始网格，隐藏曲面精细度及重建网格入口；独立模拟工作区保持现有功能 |
| 连续调角 | 应用实际折角时，在 CP 元数据单独保留原模拟目标与进度；重新进入继续使用原目标，并恢复滑块进度 |
| 源码完整性 | 修改几何、山谷类型或实际角度后，过期续调记录不再覆盖新目标 |
| 折角应用校验 | 实际角度测量、山谷方向与纸面闭合验证继续保留；CP 写入时既有同向过折压平处理保持，不将不合法角度写入工程 |
| 旧工程边界 | 没有续调记录且原目标已被覆盖的旧工程，无法从单一已应用角度反推原目标，需要重新指定一次目标角 |

验证：前端构建通过；`diagramSimulationAngles.test.ts` 7 项通过，覆盖应用 93%、JSON 保存重开、99% 再次应用及目标保持，联动 CP 接收记录、显式改角使旧记录失效、原工程不变和闭合失败保护。未运行本轮最终 GUI 验收，未重新打包。已有 tauri.37 包保持原内容。
