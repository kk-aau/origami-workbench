# 点框撤选与全选命令

新增“点框撤选”，当前58项实际工具，未打包，全工具目标继续。

- 单击线身，从选区移除最近的可编辑线段；重复点击不重新选中。
- 按住左键拖框，松开时撤选与矩形相交或接触的线段，不区分拖动方向。紫色矩形仅为参考，按下期间不改变选择。
- 右键取消当前拖框，不删除线段，也不改变已有选区。空闲右击仍遵守通用删除规则。
- 在选择、区域选择、选区变换和镜像选区中提供“全选线段”“全部撤选”。全选遵守边界保护，含辅助线；只处理线段，不含圆／文字对象。
- Ctrl+A全选，Ctrl+Shift+A全部撤选；在文本输入框内不操作画布选区。按钮会取消当前未完成构造。

依据：MouseHandlerCreaseUnselect、BaseMouseHandlerBoxSelect、Worker.unselect、FoldLineSet.unselect。后者调用totu_boundary_inside，是接触框撤选而非完整包含。本版沿用当前工程只记录几何的撤销策略，选择变更本身不创建作品历史；上游该处理器会record，因此目录仍只标基础可用，不能宣称历史行为完全等价。
