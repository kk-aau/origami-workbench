# 全量工作台 UI 设计 · 2026-09-18

用户已确认 01–27 组全部保留。本稿设计成品信息架构及统一交互，不把未接入的算法宣称为可用功能。

## 本批已落地的界面骨架

- 左侧工具栏默认 260 px、双列。可拖到 192–560 px，自动排为一／二／三／四列（网格按钮最大 132 px；列表最大 280 px），或切换文字列表。分组可折叠，名称／用途可搜索。
- 右侧属性栏默认 284 px，可拖到 236–440 px。两侧受窗口宽度约束，优先保留至少 352 px 中央画布；800 px 为现阶段桌面工作区最小适配宽度。
- 分隔条宽 8 px，有悬停反馈；方向键每次 8 px，Shift+方向键 32 px；双击／Home 恢复该侧默认值；拖动中 Esc 回退。宽度保存在本机布局偏好，不写入工程。
- 改变面板宽度时保持画布中心与世界单位缩放，不移动折痕、不重置构造点。侧栏滚动与画布缩放区域分离。
- “当前可用”显示现有 12 工具；“全量布局”展示固定基线全部 80 个非 UNUSED 交互模式，标注基础版／规划，仅打开规格预览。
- “工具目录”或 Ctrl+K 打开中文目录：分类导航、搜索结果、规格详情。规格含参数区设计、界面位置、反馈规则、原动作别名与开发状态；待开发项没有执行按钮。
- 源码目录当前 202 条分组记录，含交互模式、命令与参数／设置；不是 202 个独立工具，也不构成完成率。
- 现有四工作区、中文用法、鼠标旁步骤、紫色构造、山谷预设与所选赋型分离保留。

## 视觉与密度

采用纸白／浅灰绿工作面、深绿选中态、紫色构造参考；山谷色与实际赋型继续独立。使用本机中文字体和等宽数字，不依赖在线字体。桌面工具格至少 42 px 高，长名称换行；不以纯图标替代全部中文标签。无装饰性连续动画，保留键盘焦点和减少动态效果支持。

## 其他三个工作区的成品规格

### 镶嵌设计

左侧：母结构／单元模板库与参数预设；中央：母结构、缩放旋转单元、折痕预览的显示切换；右侧：拓扑、单元、圈数、边界、角度与比例；底部：几何、局部、全局分级检查。生成与采用副本是不同操作，不覆盖手工作品。当前已接入的受限生成器保留，复杂模板未完成时不显示为已验证。

### 平折分析

左侧上方模型列表，下方解列表；中央 CP／折后结果可对照，当前参考面高亮；右侧输入范围、参考面、颜色约束、结果显示；下方任务进度。线框、X 光、层序解和实际可执行路径分别陈述。多解搜索可中止，取消不等于无解，过期结果不能继续冒用。

### 三维模拟

中央三维模型；右侧目标角、求解质量与应变；底部折叠比例、暂停、复位。CP 变化显式提示重新载入。以后增加步骤或碰撞检查时另做可验证实现，不把比例播放条称为真实折叠教学步骤。此工作区是综合工作台额外能力，不抵扣 Oriedita 平折要求。

## 统一状态与输入合同

- 工具生命周期：待输入 → 逐步构造 → 有效候选 → 用户确认 → 一次历史提交；失败保留可修正输入，不生成半成品。
- 紫色只代表临时参考与候选，山谷／边界是实际对象属性。多候选需可单独选择，禁止悄悄取第一解。
- 构造中右击仅取消；空闲右击删除；右拖向右完整包含删除，向左接触删除。滚轮按住平移仍是全工具通用行为。
- 弹窗保留焦点，Esc 只关闭最上层界面，不误删底层对象；不把普通几何参数做成连续弹窗。
- 设计目录的“基础可用”不是完整上游等价，“待开发／待逐项对齐／上游待核实”各自保留。目录每项能查源标识，参数按钮不重复算独立工具。
- 面板宽度、主题等是本机偏好；折痕、辅助对象和应保存的构造参数是工程状态；窗口布局不进入几何撤销。

## 验证与边界

本批交付为全量信息架构、工具目录与可调整 UI 骨架，非全工具算法实现。已有绘图交互必须回归。桌面工作区按 800／1024／1440／1920 px 验证；完整目录单独支持窄屏，未将整个 CAD 工作区宣称为手机适配。最终验证数量和桌面包以会话续接记录为准。
