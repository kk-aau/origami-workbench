# 原瓣片展开函数与单瓣纸张（2026-10-10）

新增原第 43 节 `SingleGoreData`、`MultipleGoreData`、`SphereSingleGoreData`、`SphereMultipleGoreData` 的完整四组图形数据入口；同时将原径向单瓣图构造成实际 CP 和静态三维纸面。入口为镶嵌设计 → 空间构造 → 原瓣片展开，完整原数据按钮位于该参数栏。

| 原定义 | 输入与完整返回 |
| --- | --- |
| In[3448] SingleGoreData | 实际剖面 pts、瓣数 m；按累计弦长及 tan(π/m) 半宽，返回折后、径向、柱面、多条原二维线图。 |
| In[3450] MultipleGoreData | 保留全部 m 组旋转后的四组原图形。 |
| In[3452] SphereSingleGoreData | 球面分段 n、瓣数 m；0/π 端点按原符号求值后转数值，首尾半径精确为 0。 |
| In[3454] SphereMultipleGoreData | 保留球面剖面的全部旋转组。 |

原二维输出中每瓣的重复线全部保留；构造没有用删重复线伪装完成。原图形数据可独立查询及导出 JSON，负半径等原帮助数据仍按字面返回，不被包装成已认证纸面。公开输入域为 m=3～32、球面 n=2～64、手工 2～65 点，并限制完整图形预算；域外输入明确拒绝，不截断输出。

实际采用的是单瓣径向纸张，保原点列和累计长度来源，按每个源顶点、面、边独立验证静态等距。源证书不会仅靠布尔标记通过；平移伪造折后图、删除原面/边或篡改完整图形均拒绝。多瓣图的材料连接、层序、连续路径、碰撞尚未认证，不宣称完整原图形列表自动等于多瓣可制造纸张。
