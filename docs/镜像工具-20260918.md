# 镜像工具 v0.9.1

v0.9.0 增加 2 项，当前实际工具 30 项。v0.9.1 按用户要求调整镜像选区流程，不新增工具数量。全量工具目录不是全量完成声明。

## 使用

|入口|操作|范围|
|---|---|---|
|镜像线段|选原线段 → 选轴线段／纸边 → 确认|镜像原小段，轴采用所选线的完整支撑直线|
|镜像选区|工具内点线／拖框切换选择 → 两点定轴 → 点镜像区域|只复制选中线段，支持混合线型；不复制圆、文字或标记|

镜像选区中，单击线身切换该线，框选切换所有接触矩形的线，已选取消、未选选中；不需要 Shift，四个拖动方向规则相同，普通选择与右键方向删线规则不变。抬起左键时再区分点击／拖框，从端点开始拖动不会误设镜面，也不会移动已选线。

单击端点／交点（含辅助圆参考点）优先定轴。没有线身命中的空白网格点也可作为第一轴点；线上普通网格位置优先选线，防止常见线身点击被网格拦截。开始定轴后只接收点，不再切换选区；第二点可用网格点。空白任意非点位置不定轴，关闭网格显示或吸附后不能用网格点，但已有几何点仍可显式选取。空选区会先提示选线。

镜面确定后，以镜像副本端点的凸包显示淡紫色确认区域；点击区域内部或副本线即可提交，也保留键盘可达的“确认镜像”按钮。只有单线／共线结果时没有虚构面积，点击线旁命中范围或确认按钮。区域仅用于操作提示，不写入工程、不参与折叠。

选轴前后的线均为临时紫色参考；半成品不写入工程。鼠标旁和固定指南提示下一步，参数区显示原线数与新增段数。沿用现有紧凑工作台、按钮宽度限制及最多四列布局，无新依赖。

这是生成副本，不移动或删除原线。保留原山谷类型及折角，包括未知角 null 与展开角 0；上方新绘制线型不影响副本。如需互换山谷，请提交后使用已有赋型操作。

副本是有限线段，不自动延长到边界，也不裁剪纸外部分。原线与新线交点通过现有工程提交机制真实分段，一次撤销恢复整个提交前状态。

## 重合和安全规则

- 同型且折角相同的已覆盖区间不重复添加，包括多个已有小段组成的覆盖；只添加剩余区间。
- 若剩余结果为空，提示结果已存在／位于轴上，保持有效参考供重选，不添加空撤销记录。
- 与已有线或本批副本发生正长度重合，而线型／折角不同，拒绝整批。仅共享端点不算冲突。
- 边界保护开启时不能把纸边作为镜像原线，但可引用纸边确定轴。确认时再次校验保护与工程容量。
- 空选区、失效选区、短轴、零长原线、超出 ±1000000 mm 坐标及容量限制都会提示；不悄悄修改原图。
- 镜像选区只要已有选择即算操作中，右击／Esc 清空选区及镜面，不删参考线；无选择也无定轴时仍按通用右键删线。切换工具或改变几何会清空本次构造；更改新绘制预设和滚轮平移不会。

## Oriedita 对照

只读核对本地 Oriedita 1.1.3 固定提交 `0891f8e8133ddf3aba8c6ec8a2b1ef565a0ea86e` 的 `MouseHandlerDrawCreaseSymmetric` 与 `MouseHandlerSymmetricDraw`。

前者两点定轴、复制选区并保持线色，是镜像选区的语义依据。本版按用户要求增加工具内切换选择、区域确认、重合检查与边界保护，目录模式 12 标记“基础可用，变体待齐”。镜像线段是有限复制的便捷入口。

后者两线／三点构造反射方向后延长到交线，采用新绘制线型，不能用本轮有限复制代替。模式 10、横截反射 35、连续反射 52 均继续待开发；完整公理、更多变换等亦未完成。
