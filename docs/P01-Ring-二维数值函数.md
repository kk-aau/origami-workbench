# P01：pfn/rfn 二维数值公式入口

原版笔记本 `tmp/Origamica-15.0-reference.nb` 第 197925–197954 行的 In[2677] 将 `pfn[i][φ]`、`rfn[i][φ]` 定义为二维点；`RingFunctionGraphics` 直接按参数角 `φ` 采样，第 198106 行起的 `MakeRingTessellation` 再沿这些轮廓传播。它不是把 `φ` 先变成几何极角的标量极径函数。

工作区的“原版环状传播 → 函数”现在可输入 `outerVectorExpressions`（环数+1 条）和 `creaseVectorExpressions`（环数条）。每条是 `[x(phi), y(phi)]`，最终乘该环既有基准半径。例如 `cos(phi)/(1+0.06*cos(3*phi))` 与 `sin(phi)/(1+0.06*cos(3*phi))` 构成非傅里叶有限和的有理二维曲线，仍保留参数角。

原版 `pfn[i][φ]` / `rfn[i][φ]` 是**各一条随环索引变化的函数**，不要求用户将每一环手工展开。现在“按环索引 i”可输入 `outerVectorTemplate` 和 `creaseVectorTemplate`，每组为一对 `[x(i,phi), y(i,phi)]`；`pfn` 使用 `i=0…n`，`rfn` 使用 `i=0…n−1`。`i` 只作为有限的常数参与四则运算、整数幂及三角函数相位／频率，最终结果仍按各环半径缩放。例如 `cos(phi)/(1+0.015*i*cos(3*phi))` / `sin(phi)/(1+0.015*i*cos(3*phi))` 会在每环生成不同的二维轮廓。保留“逐环单独输入”以处理 `pfn` 与 `rfn` 不能由同一个索引式描述的情况。两种方式都接入 `RingFunctionGraphics` 的参数角采样及 `MakeRingTessellation` 的实际传播、折痕、平折坐标，而非显示用示意线。

光滑公式接受有限数字、`pi`、`tau`、`E`、`Degree`、四则运算、变量项的 0–4 次整数幂、`sin/cos(k*phi+c)`，以及组合其上的 `exp(...)`、`sqrt(...)`。`k` 是绝对值 1–8 的整数、`c` 是有限常数表达式（索引模式还可用 `i`）；纯常数的幂和 `Sin/Cos` 直接求有限实数值，不受变量项的四次幂限制。`exp` 使用单调值域和导数界 `exp(u)u'`；变量项的 `sqrt` 仅在被包围表达式的整个角度区间严格大于零时使用值域及导数界 `u'/(2sqrt(u))`。例如 `sqrt(1-cos(phi))` 在零点不光滑，明确拒绝。解析使用 AST 白名单，不执行 Python 或 Wolfram 代码。所有光滑曲线须有区间认证的正向极角、单圈闭合及有限正半径；环间按既有区间半径界验证严格嵌套，射线用已认证区间求最近正交点。不同 `i` 的相同表达式**不能**套用同形缩放的嵌套捷径，必须重新检查真实轮廓。无法认证的输入会被拒绝，而非以离散采样假定成立。

原版依据是 In[2674] `PolarInt2D` 第 197628–197672 行：接口只要求 `rfn[φ]` 返回二维点，并把该函数交给 `FindRoot`；In[2677] 第 197925–197954 行的保存例则给出具体的有符号幂函数。因此光滑 `Exp`、实数域内的 `Sqrt` 是原版函数接口可数值求值、但之前安全表达式入口缺失的函数族；笔记本没有保存本段指数／平方根示例的 Wolfram 坐标 Out。

界面“填入指数/平方根示例”会给两组 `pfn/rfn` 公式；按环索引模式使用以下分量，逐环模式将 `0.015*i` 固定为 `0.03`：

```text

y = sqrt(1+0.08*cos(2*phi))*exp(0.015*i*cos(3*phi))*sin(phi)
```

该例按 `i=0…n` 与 `i=0…n−1` 分别生成输入轮廓，公式保存在工程参数中，重新打开弹窗可原样回读。8 扇区、2 环的独立后端回归验证 72 点、136 边、65 面的 CP、局部条件、平折面内等距与 `RingFunctionGraphics` 101 点轮廓，并与手工展开每个 `i` 的逐环公式对照；前端参数 JSON 回读及 TypeScript 检查也通过。

原版保存的 “Squaring the Circle” In[2681] 用 `F[x,i] = Sign[x] Abs[x]^(1/(i+1))`，且 `pfn[i]`、`rfn[i]` 的两分量分别把 `x` 换成 `Cos[φ]`、`Sin[φ]`。这个函数在坐标轴处导数不连续，因此只对下面**整对完全匹配**的公式开放专门通道：

```json
{
  "outerVectorTemplate": ["sign(cos(phi))*abs(cos(phi))**(1/(i+1))", "sign(sin(phi))*abs(sin(phi))**(1/(i+1))"],
  "creaseVectorTemplate": ["sign(cos(phi))*abs(cos(phi))**(1/(i+1))", "sign(sin(phi))*abs(sin(phi))**(1/(i+1))"]
}
```

这里的 `sign` / `abs` 是此整对公式的受限记法，不是可任意嵌套的通用函数；只接受相同的 `1/(i+1)`，或逐环两分量相同的整数分母 `1/p`（`p=1…8`）。无索引依赖的分母可由有限常量表达式求值，但必须精确得到该范围整数，例如原函数逐环调用展开后的 `1/(1+0)`；不按容差将近似小数幂认作精确幂。其它非光滑式、错配分母、不同三角相位以及近似小数幂仍拒绝。匹配后走现有 `SignedPowerSuperellipse` 解析半径界和射线交点路径。界面的“采用原版圆→方函数”同时设置保存例的 `m=20`、`n=3`、`α=45°`、`φ0=6°`、`pfn` 基准半径 `0.75+i`、`rfn` 基准半径 `1+i`；公式本身只给无量纲二维坐标。原有“圆→方”快捷入口继续使用同一个解析几何家族，两条路径应产生相同的 CP、FF 与输入轮廓。

回归覆盖圆形公式与原圆形模式逐点一致、有理轮廓的 72 点/136 边/65 面、索引函数与手工逐环展开的 CP/FF 坐标一致、几何与局部条件、逐面平折等距、原版输入轮廓 101 点预览、危险语法/非周期/零分母/反向或多圈拒绝。原版圆到方形公式与已验证的 `outerSignedPowers` / `creaseSignedPowers` 专用路径逐点对照 CP、FF 和 101 点预览，并检查不匹配的式子拒绝。该通用入口仍是原版函数形状的**严格数值子域**：下文已实现有限局部纯函数；一般 Wolfram 定义、一般非光滑函数、符号精确性，以及无法由现有区间界认证的高曲率公式仍缺。原笔记本没有与本次数值公式入口完全相同的保存坐标输出，因此不能声称与 Wolfram 逐点数值结果一致。

## 原版数值公式的安全输入语法

现有二维分量输入同时接受小写数值式与 Mathematica 的**有限数值语法**：`Sin/Cos/Exp/Sqrt/Sign/Abs` 的函数方括号、`Pi`、`E`、`Degree`（以及 `°`、`\[Degree]`）、`φ/ϕ/π`（以及笔记本文本中的 `\[Phi]` 等转义）、幂号 `^`、`1.5*^-2` 科学计数和相邻因子的隐式乘法；本地 `tau` 与 `Tau/τ` 别名也继续接受。词法层只把这些已知符号转换为原有 AST 数值式；工程参数保存用户原文，后端仍执行原有调用白名单、区间值/导数包围、单圈正向极角、环间嵌套和最近射线交点检查。函数方括号只能紧随受支持的内置函数或当前局部纯函数名，`Cos[φ][[1]]` 等 Mathematica Part 结构和括号错配明确拒绝，不会把它们误读成乘法。

幂遵循 [Wolfram 的右结合规则](https://reference.wolfram.com/language/ref/Power.html)，专项验证 `-2^2=-4`、`(-2)^2=4`、`2^2^3=256`，以及 `Cos[φ]^(2^2)` 的值与导数。纯常数可以出现负幂及有实数值的分数幂；`0^0`、`0^-1`、复数幂、溢出常数和零分母会在常数求值阶段拒绝，不能因异常后回退到变量编译而被误放行。任何中间常数仍受有限值与幅度上限约束。

原版 In[2675]（197690–197758 行）的 `rfn[φ_]:=2{Cos[φ],Sin[φ]}` 可按工作区既有二维分量契约写成 `['2 Cos[φ]','2 Sin[φ]']`；对原保存的 `p={1,0},d={1,1}`，首次射线交点为 `{1+t,t}`、`t=(√7−1)/2`，专项直接校验该值。这里**没有**新增任意 `{x,y}` 向量源码解析：输入仍是两段分量字符串。

原版 In[2681]（198996–199104 行）在 `Module` 内定义 `F[x,i]:=Sign[x] Abs[x]^(1/(1+i))`，再令 `pfn[i]` 与 `rfn[i]` 各取 `F[Cos[φ],i]`、`F[Sin[φ],i]`。工作区“采用原版圆→方函数”现在以等价的内联 Mathematica 表达式 `Sign[Cos[φ]] Abs[Cos[φ]]^(1/(i+1))` / `Sign[Sin[φ]] Abs[Sin[φ]]^(1/(i+1))` 保存；外环 `.75+i`、折线环 `1+i` 仍由各环半径字段提供。它使用原先只对**整对完全匹配**式开放的解析有符号幂通道，而不是把 `Sign`/`Abs` 放宽为任意非光滑函数。20 扇区／3 环的折痕与平折顶点逐点等于既有有符号幂专用路径，260/500/241；原文与小写等价式的输入轮廓 101 点也一致。

2026-09-30 第二阶段已接入下文的局部纯函数定义，原 `F[x_,i_]:=...` 与实际 `F[Cos[φ],i]` 调用可以直接输入。任意布尔条件／非光滑 `Piecewise`、未列出的 Mathematica 函数、复数和符号输出仍缺。下面已经接入 Wolfram 的实际 `Piecewise[...]` 列表语法，但只接受能证明一阶连续的数值子域。此处对照的是保存**输入公式**及本地等价路径；笔记本未存可机读 Wolfram CP／FF 数值 `Out`，不能据此声称逐点与 Mathematica 内核输出锚定。专项见 `backend/test_tessellation_ring_mathematica_formula.py`、`backend/test_tessellation_ring_local_functions.py` 与 `tests/app/ringParams.test.ts`。

## 局部纯函数定义与真实原函数调用

“函数 → 按环索引 i → 采用原F圆→方”现在保存原定义文本及实际调用。用户也可以在公式 JSON 中复制、编辑这些字段，按“采用二维公式”生成；局部定义同时可用于“逐环单独输入”，调用参数使用每环的整数值。

```json
{
  "vectorFunctionDefinitions": ["F[x_,i_]:=Sign[x] Abs[x]^(1/(1+i))", "F[0,i_]:=0", "F[x_,0]:=x"],
  "outerVectorTemplate": ["F[Cos[φ],i]", "F[Sin[φ],i]"],
  "creaseVectorTemplate": ["F[Cos[φ],i]", "F[Sin[φ],i]"]
}
```

外环／折线环半径仍由 `.75+i`／`1+i` 的既有字段提供；该按钮同时设置原保存例 20 扇区、3 环、45°／6° 参数。旧“采用原版圆→方函数”保留内联式入口，两种原文都可原样工程回读。本轮已接受原保存的 `F[0,i_]:=0`、`F[x_,0]:=x` 两条字面量特例，详见下文有限模式合同；数值函数体中的局部赋值与纯函数定义也已接入，但包含构造与绘图命令的整个原 `Module` 程序仍不能直接执行。

定义入口允许 1–8 条标量纯定义，函数和参数名可自由使用 1–24 字符的 ASCII 字母／数字名称（首字母必须是字母），不是对 `F` 特判。声明为 `Name[x_,y_]:=表达式` 或 `Name[x_,y_]=表达式`，参数 1–4 个、定义原文最多 240 字符、函数体和各调用分量最多 120 字符。内置函数／常量不可重定义，参数不许重名或与函数名冲突，函数体不能引用未声明的自由变量。可调用其它同批局部函数、允许前向声明，但依赖图必须无环；不接受递归、循环、条件模式、赋值副作用、对象访问、普通列表返回或布尔返回。

例如把名称换成 `Basis[t_,order_]:=Sign[t] Abs[t]^(1/(1+order))`，分量写成 `Basis[Cos[φ],i]`／`Basis[Sin[φ],i]`，生成结果完全相同。一般光滑函数也可经有向无环的定义组合：`Component[t_,c_]:=Radial[t] c` 与 `Radial[t_]:=1+.02 Cos[3t]`，调用 `Component[φ,Cos[φ]]`／`Component[φ,Sin[φ]]` 会进入原区间认证、最近射线交点及真实 CP／FF 传播。

后端先校验所有声明，包括未调用的函数，拒绝非有限／幅度大于 1e6 的字面常量，以及 `0^0`、零分母、溢出等纯常量运算。调用按 AST 同时替换形式参数，保留括号优先级并防止 `phi`／`i` 变量捕获；每次展开的树最多 64 节点，遍历预算 1024，拒绝重复嵌套造成的指数扩张。展开结果随后通过既有 AST、区间域、一阶连续、正向单圈、环间嵌套证书，或整对严格匹配的解析超椭圆证书。定义本身合法不代表任意调用能够得到几何证书。没有 `eval`／`exec` 或 Wolfram 内核执行。

`vectorFunctionDefinitions` 只允许与原版 Ring 的索引／逐环二维数值公式共同保存；其它构造和曲线模式明确拒绝。参数读取保留定义与调用原文，改变角度等独立参数不会丢失；恢复圆形曲线或切换为其它曲线表示会清除不兼容定义。专项同时覆盖自由命名、前向无环调用、换序参数无捕获、未用非法定义拒绝、递归／展开限额，以及索引与逐环原 F 的 CP／FF／101 点输入轮廓全等。

## 平滑分段数值函数的可证子域

原版 In[2674]（197628–197675 行）只要求 `rfn[φ]` 返回二维点，`PolarInt2D` 将它交给 `FindRoot` 求射线交点；`MakeRingTessellation` 同样取 `pfn[i]`、`rfn[i]` 的二维数值结果。原笔记本的 Ring 一节没有保存 `Piecewise` 输入或对应数值 Out，所以以下是**该函数接口的受限实现**，并非声称复现一个保存的分段例子。

当前公式入口接受三参数 `piecewise(g,正支,负支)`，`g(phi)≥0` 时取正支，否则取负支。两支须能按加减法拆出**完全相同的基式**，其余每个差异项须直接含 `g**2`、更高整数幂或两个相乘的 `g` 因子；项的其余因子仍可由安全光滑表达式组成。例如 `piecewise(cos(phi),1+.04*cos(phi)**2,1+.02*cos(phi)**2)`。这使两支之差具有 `g²` 因子，在任意切换点 `g=0` 的函数值和一阶导数均相同。无法从这种有限表达式结构证明接缝的其它三参数写法会被拒绝，即使某些公式实际上连续。原四参数简写 `piecewise(g,b,a,c)` 继续可用，其含义是 `b+g²*(g≥0?a:c)`。

所有分支均须能由上述安全语法求出区间值和一阶导数。每个角度区间都计算两支；若门函数在该区间跨零，就对两支的值与导数分别取并包围，符号确定时采用相应分支的界。全角正向极角、半径、闭合、环间嵌套和首次射线交点仍经既有认证。分母跨零、平方根非严格正值、无法认证的曲线以及跳变、尖点与普通 Python `if/else` 都拒绝。界面有“填入三参数分段示例”，同一公式可按索引 `i` 自动给每环使用，或展开为逐环输入。

2026-09-30 补上原写法，例如 `Piecewise[{{1+.04 Cos[φ]^2,Cos[φ]>=0}},1+.02 Cos[φ]^2] Cos[φ]`，另一个分量将最后的 `Cos` 换为 `Sin`。支持 1–4 个 `{数值式,比较条件}` 分支，条件为两个光滑数值式的 `>`、`>=`、`<`、`<=`（也接受 `≥/≤` 或相应 Wolfram 转义）；优先采用第一条真分支，没有真分支则采用显式默认式，省略默认式时取 0，符合 [Wolfram Piecewise 规则](https://reference.wolfram.com/language/ref/Piecewise.html)。每个比较定义切换函数 `g=左式−右式`；与零比较时保留原非零一侧的结构。**每个分支和默认式的差异都须含每一个切换函数的平方因子**。多分支若只分别检查本分支的条件，会漏掉较早分支失效时转入后续分支的跳变，本次专项明确拒绝这种交叉不连续。判断不确定的区间对所有可能被选中的分支取包围，判断确定为真后不考虑后续分支，保留原版顺序语义。这里仍未支持任意布尔条件、非光滑分支或通用 Wolfram 解释器。

界面“填入 Mathematica 分段”可以在索引和逐环模式使用。同一组实际列表式与已有小写三参数式的值、一阶导数、跨接缝区间包围以及 72 点／136 边／65 面 CP、FF 逐点一致。前端保留公式原文，工程回读不会丢失花括号、比较符和 Unicode 符号。公式编辑弹窗改为固定高度、伸缩文本框，语法解释可展开；默认状态在桌面和窄屏保持所有操作可见。

## 有限字面量模式与数值 Module

原 In[2677]（197923 行起）及 In[2681]（199004–199028 行）实际声明三个同名模式：通式 `F[x_,i_]`、零点 `F[0,i_]` 和初环 `F[x_,0]`。这一阶段不再只通过内联曲线覆盖特例：三条原定义可以一起复制到 `vectorFunctionDefinitions`，一键“采用原F圆→方”也保存三条原文。索引与逐环调用产生的 260 点／500 边／241 面 CP、FF、输入轮廓均与旧解析路径逐点相同。

| 有限模式规则 | 实际行为 |
| --- | --- |
| 模式参数 | 只允许 `name_` 或绝对值不超过 1e6 的有限实数字面量；同名须同元数，须有一条全部 `name_` 的默认定义，模式不可重复。 |
| 常量／环索引匹配 | 用当前真实环索引或有限常量结果精确匹配，字面量较多的模式更具体。例如 `Radius[k_]:=1`、`Radius[2]:=1.1` 会改变真实第三环轮廓；近似 `2+.0000001` 不匹配 2。 |
| 多个同等具体模式 | 若同时匹配，展开结果须为同一 AST 或能求得严格相同的有限常量，否则拒绝歧义，不猜一般 Wolfram DownValues 的排序。 |
| 角度相关字面量 | 未知角度上的孤立匹配不能静默忽略。将匹配字面量代入后，须能证明特例与选定默认值同一 AST／有限常量，才作为同值特例消去；否则拒绝潜在跳变。例如 `F[0,i_]:=0` 合法，改为 1 会拒绝。 |
| 几何证书 | 分派、替换后仍进入既有 AST／区间认证。整对精确 `Cos[phi]`／`Sin[phi]` 对应同一个解析幂 1 子域，保持原 `F[x_,0]:=x` 的精确原图行为。 |
