| 功能 | 实际行为 |
|---|---|
| 入口 | 材料工程的纸张属性新增“复制材料部件”。原“复制所选”按钮也支持完整材料部件的偏移复制；部分折痕选择明确拒绝，不暗中补全或按坐标焊接。 |
| 完整身份 | 复制选中部件的顶点、边、逐角面边归属、面、切口共同端点、并行切口侧及孔洞边界。副本索引和线段ID独立，原位或重叠复制也不合并原件/副本。 |
| 变换与阵列 | 1–64份；每份偏移逐份累加，旋转/正等比缩放/左右或上下镜像每份相同，围绕所选材料CP整体中心。CP与已有FF使用同一世界变换，不重复缩放。镜像重新定向CP面角槽以保持CCW，保原山谷/目标角。 |
| 保留原件 | 原CP、FF、原线段和显示色逐值保留；独立元数据、纸张、底图及标注保持原值。已明确选中的辅助线可同时复制；独立圆、文字、标记不自动复制。缺少FF时不虚构折后位置。 |
| 可视化 | 展开CP/折后FF可切换，有毫米刻度、缩放、平移及恢复全图。原件紫色、副本青色虚线；宽幅阵列按实际长宽比适配，保持图形比例。1000×720与800×720所有参数及底部按钮完整可见，无窗口滚动；部件长列表单独滚动。 |
| 预览/历史 | 改参数使预览失效；无效数量、空选区和容量超额明确拒绝。支持取消、一次应用及整组撤销/重做；旧平折层序过期后重新计算，不复制原模型证书。 |
| 重叠选面 | 材料工程的平折设置增加`materialFace`索引，必须同时匹配当前受校验材料图与原轮廓；普通工程仍按轮廓。选择器新增按部件/面选择的下拉框，不需要在重叠图形上猜点击顺序。细分/合并和同拓扑变换同步更新索引。 |
| JSON/FOLD | JSON保存索引与轮廓。材料FOLD导出将当前有效起始面写入已验证材料合同；重开后保所选副本面，不复用层序。普通FOLD/CP保持原起始面损失提示。失效材料起始面不能被偷偷替换成默认面后导出。 |
| 普通工程修复 | 非材料图上的索引配置标为失效，显式重选普通面会删除该索引并恢复正常计算；不会借用材料索引认定普通图的面身份。 |
