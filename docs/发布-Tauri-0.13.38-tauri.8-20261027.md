# 折纸工坊 Tauri 独立版 0.13.38-tauri.8

本候选在大工程多核认证与恢复保存反馈修复的基础上，补齐不同电脑的能力选择和资源回退。优化不绑定本机的 20 核 CPU、48 GB 内存或独立显卡；仍保留四工作区、完整离线计算与原生关闭保护。

| 环境 | 处理要求 |
| --- | --- |
| 有效多核与共享内存 | 根据实际报告的核心数、可用任务分块和实现上限选择线程数，不把 20 核写成机器门槛 |
| 单核、未知或异常核心数 | 使用兼容的完整 CPU 认证，不生成无效线程数量 |
| 不支持共享内存或跨源隔离 | 使用已优化的串行认证路径，保持全部区域检查 |
| 大缓存或并行准备分配失败 | 在具体资源分配边界回退，必要时使用分页关系存储；不重复尝试已失败的大缓存 |
| 无独立显卡或无 WebGPU | 完整层序求解保持可用，不要求额外显卡或驱动 |
| 输入、关系或遍历无效 | 如实报告错误；不得以兼容回退为由忽略结构或完整性错误 |

浏览器的 `deviceMemory` 是粗略且可能受上限限制的值，不能当作实际物理内存，也不据此把真实高配置电脑强制降为低配置模式。资源兼容调整不删除面、不缩短搜索、不放宽精度，不把部分结果标为完成。

本轮源代码与能力验证：

| 检查 | 结果 |
| --- | --- |
| 前端与 Rust Release 构建 | 通过 |
| 全量单元测试 | 5,546 项通过，无失败或跳过 |
| Rust／实际接口／桌面桥 | 分别 23／78／5 项通过 |
| 并行及资源定向回归 | 39 项通过，含实际 2／4／8／32／64 Worker 证书一致性 |
| 真实 WebView Worker 能力模拟 | 18 种环境通过；36 份完整证书逐字节一致，90 组负例保持拒绝 |
| 能力模拟清理 | 103 个实际检查线程全部终止，原生宿主正常退出 |
| 离线引擎 | 195 文件逐字节核验；沿用历史 1,358 项 Python 回归，本轮未重跑该全套 |

上述能力模拟是在本机原生 WebView2 中控制能力报告及资源失败条件，不代表在 18 台实体电脑上测试。最终双 EXE 的界面、关闭、导出及恢复保存验收单独记录。

本候选的新原生冷计算验收，从原始龙神 ORI 导入到完整双面结果为 231.706 秒（约 3 分 52 秒，排除额外证据哈希计时），自动选择 20 个检查线程。两面各验证 1,827,830 个区域，无未确认项，计算结束后全部 22 个相关线程释放。没有复用几何、拓扑或证书缓存，也没有修改硬件报告或浏览器堆参数；这是正式 Worker 管线耗时，不包含主界面最终绘制。记录见本机 `output/playwright/complete-flat-webview2-tauri8-20261027/complete-report.json`。

恢复保存会等待磁盘结果再确定提醒：浏览器临时缓存配额不足而磁盘写入成功时不误报；真实磁盘失败仍明确提示。前期多核算法及 GPU 实验的准确口径见[大工程速度优先计算](大工程速度优先计算-20261027.md)。该文中的候选 7 数字属于前期验证，不能替代本候选的实包验收。

应用包不内嵌源码。完整 Source.zip／Source.7z、独立调试资料、必要许可与实际 SHA256 按同版本分别交付。最终体积、实际测试数量、双包原生验收及在线状态以本候选发行记录和附件为准。

0.13.38-tauri.7 在正式发布前因补充跨硬件适配而撤回候选，归档和测试证据保留，没有上传；不覆盖其归档或最终 EXE。已获准且已完成的四个旧版应用分卷清理不重复执行。
