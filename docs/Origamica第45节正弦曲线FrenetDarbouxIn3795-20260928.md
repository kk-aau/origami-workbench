# 第 45 节 In[3795]：广义柱面上正弦曲线的两种标架

只读依据是 `tmp/Origamica-15.0-reference.nb` 约 300222–300454 行的实际保存输入。原单元在同一曲面和曲线上并排画 Frenet、Darboux 标架，并在 `t=0.5` 打印测地曲率、法曲率；本入口按保存公式生成连续只读视图。笔记本文字把它叫作“包在柱面上的正弦曲线”，其精确参数曲面是**沿 x 方向平移的广义柱面**，并非圆柱。

| 项目 | 保存输入 | 可核验的解析结果 |
| --- | --- | --- |
| 曲面和曲线 | `S(x,y)=(x,y,1−cos y)`，曲面画域 `x∈[−1,0.5], y∈[−1,1]`；`F(t)=S(cos t−1,t)`，`t∈[−1,1]`。 | `F(t)=(cos t−1,t,1−cos t)`，严格处于曲面且处于平面 `x+z=0`。曲面 `Sₓ=(1,0,0)`、`Sᵧ=(0,1,sin y)`，第一基本形式 `(E,F,G)=(1,0,1+sin²y)`，面积因子 `q=√(1+sin²y)≥1`。它是正则可展广义柱面；本入口没有实现纸张展开。 |
| 原图双标架 | `Curve3DSystem[F]` 与 `Darboux3DSystem[F,U]`；`U=SurfaceNormalFromSurface[S]` 取默认正朝向；`t₀=0.5`，标架向量长 `0.3`。`du=dv=dt=0.1` 虽赋值，但不传给显示函数。 | 设 `s=sin t,c=cos t,p=√(1+2s²),q=√(1+s²)`。`T=(−s,1,s)/p`，Frenet `N=(−1,−2s,1)/(√2 p)`、`B=(1,0,1)/√2`；Darboux `U=(0,−s,1)/q`、`L=U×T=(−q/p,−s/(pq),−s²/(pq))`。两组向量全域正交单位。 |
| 曲率与扭率 | 保存单元打印 `κg(t₀)`、`κn(t₀)`，但没有提供可机读的 Wolfram 数值 `Out` 表供逐点对照。 | 从源定义 `κg=L·T′/p`、`κn=U·T′/p`、`τg=−L·U′/p` 得 `κg=c/(p³q)`、`κn=c/(p²q)`、`τg=−cs/(p²q²)`；Frenet `κ=√2c/p³`、`τ=0`，且 `κ²=κg²+κn²`。**本地源式推导值**在 `t=.5` 是 `κg≈0.4487120503`、`κn≈0.5421246987`、`τg≈−0.2343659361`；这些不是声称读到的 Wolfram 输出。 |
