# 第 37 节双色偏置公式：n=8 受限推演与 n=1、9 只读诊断

2026-09-30 来源赋型更正：撤回此前将 n=9 固定候选写为「局部通过、平折几何 ready、层序 no-solution」的来源结论。那一 CP 来自旧自由褶线算法，它反转了中间六边形的 12 条源褶线。严格按 In[3183] → In[3018] → In[2919] → In[2872] 的赋型，n=9 接缝为 M=1/V=1，局部即拒绝，不生成成功 CP、不计算层序。n=1/8 当前赋型和真实层序复核保持。详细逐边及 HTTP 证据见 [源赋型纠正记录](P37-双色偏置n9源赋型纠正-20260930.md)。

原笔记本的 `TwoColorableArchimedeanPatch[1,8,9]` 保存了具名来源与 2×2 母结构，但没有这三个编号的偏置、Alt 或裁剪 CP 保存输出。下表的单补片 CP 是对原版 `In[3183]` 公式做**本地推演**，不是原版保存 `Out`。其中 n=8 已经过本项目的严格来源回读、几何及层序核验，可从母结构切换到受限推演折痕；n=1、9 仍仅提供只读诊断。

| 原版单元 | 可核对的定义或保存输入 | 工作区边界 |
|---|---|---|
| `In[3156]` / `In[3159]` | 双色 n=1 的来源、奇偶 `[+1,-1]` 与 2×2 母图 | 母结构可选；无该编号的保存 CP Out |
| `In[3164]` / `In[3167]` | 双色 n=8 的来源、六片交替奇偶与 2×2 母图 | 母结构可选；无该编号的保存 CP Out |
| `In[3168]` / `In[3171]` | 双色 n=9 的来源、奇偶 `[+1,-1,+1]` 与 2×2 母图 | 母结构可选；无该编号的保存 CP Out |

| `In[3184]`、`In[3187]`、`In[3188]` | 双色 n=2 的单 patch 偏置、40→16 Alt 裁剪和 40→16 偏置裁剪 | 已有具名保存例；这三例不属于 n=1/8/9 |

本次只选三个固定的、有界单补片候选。参数用原版 `In[3183]` 的 `w`、带 parity 的 `±d`、逐片中心 M/V 类型；它们的数值与赋型是工作区诊断输入，没有对应的保存 CP Out。具名路径通过 `two_colorable_archimedean_patch`、`twist_patch_options(..., variant='offset', parity=...)`、`construct_tile_patch` 构造。通用路径使用同一来源几何、显式逐片 offset 与 monolithic 选项，来源元数据不进入后端请求。

| 来源 | 本地候选 `w, |d|` | 逐片中心类型 | CP 顶点/边/面 | 几何/局部/LFF | 平折几何 | 整片层序／处理 |
|---|---:|---|---:|---|---|---|
| 双色 n=1 | `0.2, 0.1` | `MMM / MMM` | `18/28/11` | 通过/通过/通过 | `ready` | `no-solution`：当前山谷指派的整片层序约束传播无解 |
| 双色 n=8 | `0.05, 0.03` | `MMMM / MMM / MMMM / MMM / MMMM / MMMMMM` | `54/88/35` | 通过/通过/通过 | `ready` | `solved`：本项目原面统一层序精确 1 解；选取此受限推演折痕后仍由工作区对当前输入实时重算再决定采用 |
| 双色 n=9 | `0.2, 0.1` | `VVV / MMMMMM / VVV` | 不生成成功 CP | 接缝固定源山谷赋型拒绝 | 不计算 | 不计算：接缝 M=1/V=1 不满足 Maekawa；旧自由改赋型的 `32/52/21` CP 不代表原公式候选 |

当前 n=1/8 候选的具名与通用 CP 在边拓扑、M/V 指派、折角、面拓扑和来源索引上逐项相等，顶点最大坐标误差为 **0**；n=9 两路径返回相同的明确源接缝赋型错误，无成功响应。n=8 折后 35 个原面的两两顶点距离最大绝对误差 **1.29114×10⁻⁶**、最大相对误差 **3.87867×10⁻⁷**；折后 76 个三角片产生 171 个原面对变量、1168 条去重 CNF 子句，单位传播在 **1 个搜索节点**完成精确唯一解证明。1002 个重叠区域的正背显示全部得到有序遮挡。生产通用预算只把原面对上限由 160 提到 **192**，原面 36、三角片 80、子句 2048、节点 50,000 的上限及几何门禁、Worker 取消/超时均未改变。因而这只证明本项目固定 n=8 候选在数值容差内的几何与零厚度原面统一层序；不证明连续折叠路径、有厚度可制造性或 Wolfram 数值 `Out` 等价。

工作区二色来源弹窗在 n=1/8/9 显示候选来源、无保存 CP Out、数值、奇偶、中心赋型和实际诊断阶段；n=9 明示来源接缝拒绝，不展示不存在的成功 CP 数量或层序。n=8 可选择 `in3183-offset-derived`，此具名记录保留 `notebookFormulaIn=3183` 与 `savedCpOut=false`，其顶点、面、每片偏置和赋型、整体并边选项均须与固定公式输入吻合，篡改任意一项即拒绝回读。选择后仍须等待实时构造与层序，采用按钮沿用工作区的当前结果门禁。n=1 层序无解与 n=9 来源赋型不相容候选仍不可切换、不可采用；三个只读诊断规格本身均拒绝改写编号、奇偶、公式单元、数值或中心赋型。n=2 的三个原版保存例保持原样。
