# 第42节跨面直线构造与验收（2026-10-08）

完整复现目标保持 active。本批将采用后材料编辑扩展为一条直线跨多个面统一构造，源码与网页已更新，免安装 EXE 未重打包。

| 功能 | 当前行为 |
|---|---|
| 入口 | 材料工程进入“折痕编辑 → 纸张属性 → 编辑材料折痕 → 跨面直线构造”。单面添加、批量删除、切开与粘合继续保留。 |
| 明确范围 | 选择一个部件或显式选择全部材料。起终点绑定该范围内的边ID与沿边比例；可拖动、点击边、滑条或精确输入。不移动原顶点或按同坐标焊接材料身份。 |
| 区间裁剪 | 按每个简单材料面的边界交点生成真实内部区间。支持凹面多区间、已有材料孔洞、断开部件及重叠独立部件；纸外/孔洞/部件间空白不生成折痕。 |
| 统一拓扑 | 同一共享边只创建一个交点身份，更新两个邻面的角槽；切口对侧分点保持独立。全部区间在一张新图中生成，最后才做严格拓扑检查与FF处理，不逐面提交不能平折的中间状态。 |
| 折后位置 | F相容时保留旧FF；M/V/U按原固定面姿态重新传播并核对全部共享顶点、铰链闭环和等距。无原FF不虚构位置，U不伪造已认证层序。 |
| 固定侧 | 原固定面被穿过时可选保留起点→终点的画布左侧或右侧。画布Y向下，向右画线的左侧是画面上方；已有回归与实际下载核对，坐标不因此翻转。 |
| 预览与历史 | 虚线为选定参考直线，青色实线为实际新增段；显示段数、经过面/部件数、实际累计长度和空白长度。改参数使预览失效，支持取消、一次应用及整组撤销/重做；旧平折结果过期后重新计算。 |
| 重复提示 | 与已有边重合或部分共线重叠时明确拒绝并提示，不静默合并、不重复生成。数值病态、退化、归属不一致或最终闭环失败原子拒绝。 |
| 交换 | 实际JSON/FOLD下载重开、再平折及普通R12 LINE DXF解析通过。普通CP/DXF原入口、坐标选项与加工优化保留；经典CP的F/U限制仍沿用，不把F猜成山谷。 |

交点分类使用IEEE-754输入的精确二进制有理数方向判定，不用epsilon把近顶点强行吸附到顶点或把近平行线判作重复。新交点仍按原边比例以双精度插值，严格材料校验负责最终有限精度门槛；低于门槛明确失败，不移动源点。实际区间长度与空白长度是双精度指标，约100 mm可能记录为99.99999999999997 mm，显示按三位小数；它不用于调整几何。
