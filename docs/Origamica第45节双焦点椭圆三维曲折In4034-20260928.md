# 第 45 节 In[4034] 双焦点椭圆数值三维曲折

## 原版保存输入与实际执行范围

`tmp/Origamica-15.0-reference.nb` 的 In[4034] 位于 331634–331902 行；它用 In[4019] 的 `ConicSection2DSystem[{-1,-2},{-1/2,1/2},Simplification->Simplify]` 取得平面折线、两侧次横曲线和左右焦点／准线，然后将两侧次横曲线指向折线的向量单位化，交给 `NFoldCurvedFold3D`（In[3977]，325518–325810 行）。初值为 `uᵢ=0`、`γᵢ=−60°`、`FFᵢ=(0,0,0)`、`Tᵢ=(0,1,0)`、`Bᵢ=(0,0,1)`。

**源单元确实先设 `u∈[−60°,60°]`，又在调用 `NFoldCurvedFold3D` 之前重设为 `[0°,120°]`。** 最后的光学图、平面折痕图和三维图都使用第二个范围；本地入口遵循这一实际执行区间。原单元只保存绘图输入和 `ShowExample`，没有可机读的 Wolfram 三维坐标 `Out`。本地不复刻其 `NDSolve`／`FunctionInterpolationAlt` 的插值策略。

## 固定输入可认证的连续子域

令 `c=cos u`、`s=sin u`、`q=tan(u/2)`，在 `0≤u≤2π/3`，源二维折线和单位母线化简为

```text
f(u)  = (-1 + 4c/(3+c), 4s/(3+c))
rL(u) = (-c,-s)
rR(u) = ((4-q²)/(4+q²), 4q/(4+q²))
```

折线满足 `(x+3/2)²/(9/4)+y²/2=1`。设二维折线速率为 `d`、切线角速度为 `φ′`，两侧母线相对切线的源式参数给出

```text
cotρL = cotρR = -sin(u)/(3+cos(u))
φ′ = 3(3+cos(u))/(10+6cos(u))
ρ′ = (3cos(u)+1)/(10+6cos(u))
φ′+ρ′ = 1
d sinρ = 4/(3+cos(u))
```

因此 In[3977] 的折角方程 `γ′ cot(γ/2)=d κL(cotρL−cotρR)` 在保存初值下唯一给出 `γ(u)=−60°`，并无需要强行指定的新折角函数。空间曲率与扭率在 `u` 参数的 Frenet ODE 中分别成为 `φ′ sec(γ/2)` 与 `φ′ cotρ tan(γ/2)`；`src/app/curvedConicEllipseFoldIn4034.ts` 按初始位置／切向／副法向用 RK4 重建 `F,T,N,B`，再按源式组合两侧三维单位母线。全部分母在保存区间非零；固定折角避开 `0,±180°`。

平面／空间每侧同参数直纹面都使用 `X(u,v)=f(u)+v r(u)` 或 `Y(u,v)=F(u)+v R(u)`。Frenet 方程与 `cotρL=cotρR` 使空间母线导数始终留在对应曲面的切平面（可展性），其长度与平面母线导数相等；故连续第一基本形式逐侧相同。局部预览宽度取 `0≤v≤0.5`。左侧有向 Jacobian `J_L=4/(3+cos u)−v≥0.5`；右侧 `J_R=−4/(3+cos u)−v·4/(5+3cos u)≤−1`，所以两侧在此范围均不触焦线。**这是连续局部结论，不是把采样折线或三角片认证为精确等距纸面。** 未判定二维／三维全局自交，也没有连续刚性部署路径。

## 工作区、测试与限制

“空间构造 → 双焦点椭圆三维曲折 · In[4034]”打开只读二维／三维同参数双视图。三维图为本地数值 Frenet 积分后的正交投影，允许滑动同一 `u` 和改变三维视角；保留源参数、区间覆盖、−60° 折角和能力边界。97 个本地预览点、宽 0.5 的双带都不是原版保存的 `InterpolationPoints` 或精确 FOLD；界面没有采用动作，不改纸面和工程。

`tests/app/curvedConicEllipseFoldIn4034.test.ts` 的 4 项专项覆盖来源参数／区间覆盖、椭圆和光线、初始三维母线与 RK4 双分辨率收敛、二维／三维两侧第一基本形式独立有限差分对照。计算的 `cotρ` 差 `<2.3×10⁻¹⁶`，标架正交误差 `<2.3×10⁻¹⁵`，32 与 64 子步每帧积分差 `<1.3×10⁻¹⁴`，平面度量恒等式残差 `<2.7×10⁻¹⁵`；这些不是对 Wolfram `Out` 的误差。`npm run build` 通过。真实 Chromium 在 1000×720 的 14 项入口、双图、滑块、视角、只读和无滚动检查均通过；截图 `output/playwright/in4034-conic-ellipse-fold-ui-20260928.png`，记录 `output/playwright/in4034-conic-ellipse-browser-report.json`。
