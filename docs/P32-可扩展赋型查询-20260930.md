# P32：3–64 边可扩展赋型查询

本轮替换此前“超过12边省略循环枚举”的查询门禁。3–64边有精确总数、有效／居中自包含赋型迭代器、完整列表入口及实际 JSON 下载；对话框为固定容量预览并明确标出总数和显示数，不把预览冒称为完整枚举。查询不会修改实际折痕，也不会将局部判据当成整片层序证明。

## 原定义与本轮实现

行号对应 `tmp/Origamica-15.0-reference.nb` 的原文本。

| 原来源 | 原合同 | 本轮行为 |
| --- | --- | --- |
| AllCyclicTwistTypes，In[2717]，201474–201505 | 生成全部 M/V 字串，再以 `Union[..., SameTest->CyclicSameQ]` 合并旋转等价。 | 二进制 necklace 前缀递归直接生成每个旋转类代表；仅合并旋转，镜像和 M/V 反转没有额外合并。没有先建立2ⁿ全集。 |
| AllValidTwistTypes，In[2719]，201532–201546；RegularPolygonTwistValidQ，201243–201328 | 对全部旋转代表执行原有效性谓词。 | 迭代器与完整列表都使用同一原判据。n≥6、扭角超出混合赋型阈值时，直接处理两个常量赋型或空集，不扫描被排除的巨大混合集。 |
| UnitRegularPolygonCenteredTwistSelfContainedQ，223513–223527 | 原有效性谓词与严格几何包含不等式相与。 | 保留褶倾角／扭角两参数形式，分别提供精确计数与全结果迭代器；任意所选 M/V 串可单独查询。 |
| UnitRegularPolygonOffsetTwistSelfContainedQ，224615–224629 | 根据宽度、偏置换算扭角，并检查原三分之一宽度边界。 | 保留该单串谓词；改变查询字符串会实际改变居中与偏置结果，没有将列表中已有代表冒充任意所选字符串。 |

本段保存了定义、输入和 ShowExample 绘图调用，未提取到可用于新大边数输入的 Wolfram 数值 Out。以下13／24／64边结果是保存规则的本地重算与独立交叉检查，不能称为原笔记本保存的这些大边数输出。核心14项测试在3–13边逐项回放原“全部二进制字串→旋转 Union”，与新代表生成器、分类计数和分类迭代器逐项相同；64边另用独立 BigInt 分解式核对计数。

## 数量、完整输出与预览

| 入口 | 合同 |
| --- | --- |
| `cyclicTwistTypeCount` | 用 Burnside 求旋转类总数：`Σ[2^gcd(n,r), r=0..n-1] / n`，全程 BigInt，不先转成 Number。 |
| `cyclicTwistTypes`／`validTwistTypes`／`centeredTwistTypes` | 3–64边的完整有限迭代器；没有列表截断。消费全部结果需要与真实结果数量相应的时间。 |
| `allCyclicTwistTypes`／`allValidTwistTypes` 与自包含完整列表 | 单次物化容量100000；超过容量明确抛出数量提示，不返回空列表或截断列表。 |
| `twistAssignmentCatalog` | 返回准确十进制字符串计数与有限预览；3–12边沿用原有限全列表，上述范围内其 `enumerated` 反映是否已包含全部旋转类。13–64边保存最多24个代表作预览。 |
| 对话框预览 | 桌面常规最多24个，超过32边最多8个，≤620px宽最多4个；显示实际总数和实际显示数，没有隐藏未声明的行，也没有分页。 |
| “导出全部有效／自包含赋型” | 在准确结果总数≤100000时消费对应迭代器，下载全部实际成员。JSON 含来源标记、边数、查询参数、字符串 `count` 与 `assignments` 数组。超容量准确显示数量并禁用导出。 |
| 13边以上单串查询 | 输入任意长度恰为n的 M/V 串，转大写；无效字符或长度标记为无效并返回不自包含。未要求输入本身为某个旋转规范代表。 |
| 超过64边 | catalog 的 counts 为 null，保留临界角及当前所选串的原数值查询，禁用完整列表导出；没有捏造总数或全枚举。 |

这里的范围仅指查询／赋型来源，不声明普通 twist 构造、任意自定义外轮廓、全局层序或物理折叠路径已扩为64边。此前临界角的相似尺度与阈值包含合同继续适用。

## 实际界面与布局

只调整 `TwistAssignmentCatalog.css` 及 `TwistAnalysisDialog.tsx` 的局部排版：结果模式专属 `:has(.twist-assignment-results)` 范围压缩边距和说明行距，桌面较长预览改为4列；窄窗保持实际4个预览与全宽字符串编辑框。超过12边的两个结果卡使用“当前序列”，避免重复64字符造成窗口膨胀。查询参数或标签改变后清除旧的导出提示。构造性质页与全局 tessellation.css 不受这组结果布局修改影响。

| 验收窗口 | 实际检查 | 结果 |
| --- | --- | --- |
| 1000×720／760×720／390×720 | 各n=13／24／64的α=36°、α=1°及默认自包含页 | 无弹窗横纵滚动、无可滚动结果区、无元素越界；全部输入与导出按钮在窗内。 |
| 1000×720，n=24，α=1° | 24个长串实际排布，不用CSS藏行 | 预览高165.78px，弹窗高472.67px。 |
| 390×720，n=64，自包含 | 任意64字符输入，常量／交替／不完整串逐项切换 | 弹窗高638.25px；常量居中自包含、交替串两谓词不自包含、不完整串被标记无效。 |
| 390×720，n=64，α=1° | 大整数计数、4个真实预览、导出容量提示 | 弹窗高598.66px，完整可见。 |
| 390×720，n=65 | catalog无总数，当前串仍可查询 | 无滚动、无伪造枚举结果，完整导出禁用。 |

测试实际挂载生产 `TwistAnalysisDialog`，通过真实浏览器输入、标签切换和点击导出，并捕获实际 download 事件后读取文件。没有用 mock 列表替代生产迭代器，也没有只检查按钮文案就断言完整导出成功。
