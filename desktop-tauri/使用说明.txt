折纸工坊 Tauri 独立版 0.13.53-tauri.57 · Windows 10/11 x64

本次更新：新建折序绘图先设置纸张尺寸形状、正反颜色与折线样式，绘图界面通过“基本信息”集中调整；不同折序工程的样式互不影响，也不随折痕编辑区的全局样式变化。

图解立体化增加展开量和方向滑条、可拖动的相机方向环。支持层序完整且已确认的真实立体姿态，仅错开显示纸层，原 CP、三维坐标、固定纸面和折角不变；显示三角形支持选面、画折线及反映射，侧立轮廓仍按真实深度逐段遮挡。缺少全局顺序的局部循环层序、未知层序和拖角造型暂不启用该效果。

连续拖转视角改为进入模式时提前准备，跨手势复用同一计算线程和已验证材料，松开复用已确认的精确结果。CP、模型或历史证明变化时仍重新验证；保留精确遮挡、手动停止和退出释放。首次准备和复杂模型每帧计算仍有成本，不承诺所有机器零等待。

学习与引导增加可自行录制的教学步骤：在隔离练习画布实际示范操作、填写说明并记录为一步。引导采用动态高亮与可交互区域，教学弹窗可收起；完成或退出后移除遮罩。

本次更新：修复选择纸面时划过 CP 线段或节点导致预览大小跳动；步骤动画默认不因计算耗时而中断，保留手动停止、数值和几何校验。

此前更新：立体状态中的共面重叠纸层可调整层序、指定上下关系并随工程保存。有实际空间夹角或间距的纸面继续按真实深度显示。拖转视角改为绕纸模中心自由旋转，Shift 慢速微调；预览复用计算线程和已确认的纸模数据，保留精确遮挡。

此前修复：生成立体下一步后，转动视角误报共面、结果消失。保留已验证的纸层接触关系，并仅在同一重叠区域内补全可推导的上下关系。

此前新增：折序绘图可打开“左右对照”，放大对照主图与 CP；鼠标所在位置显示实际重叠范围内的上下各两层编号。导出作品的格式菜单可选择“单独导出 CP”，支持 PDF、SVG、PNG，可使用操作前／后 CP、最后状态、折痕编辑区或文件中的 CP。封面、步骤图及整页打印中的 CP 按可用区域完整等比居中，保留外侧笔画边界。

“将当前姿态应用到下一步”改为生成正常的可编辑立体步骤，支持转动视角、选择纸层、绘制折线及 CP 联动。根据模拟实际折角求闭合姿态，校正角度同步到 CP，并显示最大修正量；保留原模拟目标和进度。必要的角度修正可能使结果与模拟曲面略有不同，不是逐点复制。停止或失败时保留原工程；旧版保存的模拟曲面仍可读取。

“严格闭合校验”开关位于折序三维模拟窗口顶部，默认开启并记住选择。关闭后直接应用测得的折角，跳过闭合求解及 ±0.25° 修正，记录“闭合未确认”；来源、折痕对应和山谷方向检查保持。开关仅影响“应用当前折角到折痕”；生成可编辑下一步会独立求闭合解，不受 ±0.25° 修正范围限制。

修复普通 CP 中提前画出的展开预折痕导致 90% 多折角无法应用的问题：已有 F 标记保留在工程中，不再额外充当柔性铰链；短折痕及索引材料保留必要材料连接。原模拟目标会同步到应用后产生的折痕子段，支持保存重开后继续调角。旧版曲面归档仍按原始拓扑读取。

步骤动画移除碰撞保护开关与接触停止链路，不再执行碰撞拦截；删除旧 99% 近折截断代码。只使用原始 CP 所需的网格划分与三角化，取消自动细分及细分回退。纸层遮挡关系继续用于正确显示颜色，不作为运动约束；不会将过程穿插宣称为已验证无碰撞。

本次更新：折序三维模拟移除 180° 自动暂停和细分网格入口，采用原始网格。应用折角后分别保留原模拟目标与进度，再次进入可继续调节，不把上次应用的角度重新当成 100%。已丢失原始目标的旧工程需要重新指定一次目标角。

立体视角拖动改用与静止画布相同的精确遮挡计算，后台依次处理视角，复杂纸面可能存在预览延迟。步骤动画继承已验证的立体接触层序，数值运动中仅对仍保持整体刚性的旧纸层保留原关系，不用显示偏移修改真实几何。

本次更新：局部 CP 可勾选“屏蔽已有折痕”，仅隐藏局部图中的已有折痕，不删除工程线段；支持随工程保存、预览和导出。折痕编辑新增“旋转复制选区”：先选择线段，再指定旋转中心，以选中线段上的最近点为起始位置，通过鼠标在圆周上的投影预览并点击放置，不需输入角度；Esc 可取消。

树形基础形点击“生成折痕图”后，未完成时在顶部显示原因及处理方法；成功后自动显示完整折痕图。计算期间保留停止。需要优化的树形请先点击“优化布局”后重新生成。

本包的构建与验收范围以同目录 RELEASE-0.13.53-tauri.57.json 为准；对应源码、许可与调试附件独立提供。

本版新增独立“基础形设计”工作区，同时提供 TreeMaker 树形基础形与方格 / Box Pleating。真实计算在本机执行，生成的完整 CP 可作为独立副本送到折痕编辑；不满足构造要求时明确提示，保留设计源。

设计交互：空白起稿、点击延伸分支、多选与框选、群组及末端子树移动、右键插入节点、纸瓣矩形尺寸手柄；支持分屏联动、鼠标位置缩放、空格／中键平移、图层和多个设计标签。拖动连续预览合并请求，松开后只记一次撤销，Esc 可取消。每个标签保留各自的撤销、选择与视图。

设计工程自动暂存到独立文档库，也可保存 .design.json；支持 TreeMaker .tmd/.tmd5 与 BPS .bps 交换。完整作品保存当前活动设计；其他设计请分别保存或保留文档库。参数框未失焦时保存会先提交最新值。关闭设计标签不会删除文档库记录。

修复未打开折序工作区时误报当前草稿未保存的问题；保留此前折序层序与步骤动画改进。数值动画与基础形构造均不证明连续折叠路径无碰撞。

本版使用 Tauri / Rust 与系统 Microsoft Edge WebView2 Runtime。五个工作区、平折、三维及完整 Python 离线计算引擎均保留；不需要安装 Node 或 Python。界面需要系统已有 WebView2，未检测到时会明确提示；本版不会自动联网下载或往 C 盘安装运行环境。无 WebView2 的离线机器可继续使用原 Electron 版。

安装版：运行 Setup EXE，选择可写的安装目录，默认优先 D 盘。新版本有独立名称和注册项，不覆盖原 Electron 版。默认数据位于安装目录 user-data；卸载不删除用户数据。

便携版：将 Portable EXE 放入可写磁盘后直接运行。程序自动解压启动，正常退出后清理本次临时资源。默认数据放在 EXE 旁的 Zhezhi-Tauri-Data，请同时保留并备份该目录。首次打开会询问工程、折序和数据保存位置。

应用内导出统一由 Rust 宿主打开“另存为”并写入文件，包括主图、折序、三维和专用工具。可以选择保存位置，只有文件实际写入完成才报告成功；取消或失败保留原文件。大文件分块传输，不经过浏览器下载管理器。复制或升级前请先保存并正常关闭程序；不要在窗口打开时移动或删除数据。

本版和原版数据分开保存。迁移既有工程请使用“打开文件”“打开完整作品”或折序导入；不会自动改写原版的数据目录。大型 CP 使用 GPU 绘制，手动平折和纸面遮挡正常推进时持续计算，直至完整验证；复杂工程可能需要较长时间，可随时停止。平折结果不证明连续折叠路径无碰撞。

大文件导入会分阶段显示进度。准备交点期间可以缩放、平移、取消和重试；交点完整准备后才能继续依赖交点的编辑。密集交点按画面空间显示，全部交点仍保留吸附、命中与分页键盘选择。自动保存保留完整数据；多窗口冲突检查只读取修订号，不重复传输整份工程。百万线段文件仍需要较多内存与计算时间。

本版新增折痕目标角度设置，折序主图和步骤动画支持实际空间折角；操作 CP 使用实线并区分类型、来源、当前折角和本步目标。边界与轮廓颜色同步到主图及导出。空间分支目前不支持有限短折痕的柔性压痕，不相容的刚性折角会明确提示；原平折功能保留。

折序中新绘折线与原始纸边重合的部分会跳过，原纸边、已完成折痕和其他纸层上的有效折线保持。纸层列表支持按 F 编号或数字搜索。“类型”只保留山折、谷折、边界、辅助四种绘线选择；赋型、互换和循环归入“变换”，两种交替工具归入“修复”。原默认布局自动更新，自定义布局保留。

选中已有山谷折线后，可在画布右下角的可折叠面板设置折叠角度，支持常用角度和自定义数值；折痕编辑、折序主图与操作 CP 均可修改并撤销、重做。圆和多边形相关工具移入“高级”。画布下方增加“悬浮提示”勾选开关，关闭后不显示跟随鼠标的说明和名称提示，吸附与编辑保持；偏好跨工作区共享并自动记住。

工具栏顶部合并为模板、查找、新建、编辑和更多操作；在“⋯”中可导出全部工具排版模板为 JSON，并在其他便携版本中导入。新建保留默认空分类，全部工具在中间等待拖入；导入保留已有模板，保存排版后应用。

方格与对角网格支持整体旋转，正三角网格保持密铺；网格间距以纸张基准尺寸等分，删除和逐边重画边界不会改变网格。新建空白纸张默认 300×300 mm，已有工程尺寸保留。绘制预览、构造取点与导出使用一致网格；旧尺寸快捷区已移除。

发行附件包括相同对应源码的普通 ZIP / solid 7z、独立调试归档、许可和 SHA256 清单。应用内不嵌入完整源码；resources/legal 保留原始许可和 SOURCE-AVAILABILITY 源码获取说明，列出同版本源码附件名称与 SHA256。源码 ZIP / 7z 与应用在同一交付位置提供，使用应用无需下载源码附件。开发工具链、测试数据和用户工程不进入运行包。

本次发行包未进行代码签名，Windows 可能显示未知发布者；请核对提供的 SHA256，不要自行关闭系统安全保护。
