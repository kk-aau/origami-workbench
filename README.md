# 折纸工坊 · Zhezhi Workbench

自 2026-10-28 起，本迁移版是后续开发、修复、体验、打包和发布的默认主项目。原 `../workbench/` 保留为只读历史对照；后续需求直接在本目录落实。

本地优先的中文折纸设计工具，包含折痕编辑、基础形设计、镶嵌设计、三维模拟和折序绘图。当前发行候选为 **0.13.53-tauri.52**，采用 Tauri、系统 WebView2 和 Rust 宿主，保留完整 Python 离线计算引擎。

Windows 10/11 x64 用户可使用发行附件中的 `Setup.exe` 安装版或 `Portable.exe` 免安装版。系统需已安装 Microsoft Edge WebView2 Runtime；应用包不内嵌该运行环境。计算和工程数据在本机处理。

本仓库保存应用源码、锁文件和必要的第三方组件源码，不提交 `node_modules`、工具链缓存、用户工程或本机恢复记录。发行附件另外提供完整对应源码 ZIP／7z（含锁定的 Rust 依赖源码）、独立调试材料和 SHA256 校验清单。GitHub 自动生成的 Source code 附件不能替代完整对应源码附件。

后续发行采用“应用包＋同版本独立源码附件”：应用不内嵌完整源码，完整源码ZIP／7z、调试材料和SHA256清单另行提供；应用保留所有运行功能、离线引擎、必要许可证和源码获取说明。当前规则见[打包与体积控制要求](docs/打包与体积控制要求.md)。

请先阅读 [独立迁移说明](MIGRATION.md)，使用 `npm run desktop` 或 `启动独立迁移版.cmd` 启动。下面保留的原项目介绍用于功能对照，原 Electron 发布命令不适用于迁移版。

## 新增：基础形设计工作区

左侧“基础形设计”提供树形基础形与方格 / Box Pleating 两种方法。可编辑节点和分支长度，调整纸瓣布局，调用本机原生引擎优化并生成 CP；生成的折痕图作为独立副本送入原有编辑区，原设计保留。

设计文档自动暂存，手动保存为 `.design.json`；支持 TreeMaker `.tmd/.tmd5`、BPS `.bps` 文件交换。完整作品同时保存当前可编辑设计，恢复后重新计算派生 CP。长计算可手动停止；失败或停止不替换已有设计。构造 CP 不等于证明连续折叠路径可行。

| 设计操作 | 使用方式 |
| --- | --- |
| 从空白画骨架 | 选择设计方法，在“画分支”模式点击建立节点；选中节点后点击空白处延伸。入口另有示例。 |
| 选择与移动 | Shift / Ctrl 增减选择，拖框多选，拖动选中组；Alt 拖动骨架节点移动末端子树。方向键微调，Shift 放大步长。 |
| 观察设计 | 骨架与布局分屏联动选择；滚轮围绕鼠标缩放，空格拖动或中键平移，Home / 百分比按钮恢复适配。 |
| 修改结构 | 右键菜单插入中间节点、编辑名称或长度、删除末端分支；F2 编辑节点名称。 |
| 调整方格布局 | 拖动纸瓣，使用四角手柄调整矩形尺寸；连续预览合并请求，松开后只记一次撤销，Esc 或“取消拖动”恢复原设计。 |
| 多设计切换 | 顶部标签分别保留选择、视图和撤销／重做；关闭标签后，设计仍在文档库。 |

参数框尚未失焦时保存，会先提交最新参数，再生成设计工程或完整作品。较窄窗口的分屏区域可滚动，也可切换到单画布。

## 原项目功能介绍

一款本地优先的中文折纸设计工作台，集折痕编辑、镶嵌构造、平折分析、三维预览和折序绘图于一体。

## 工作台功能

- **折痕编辑**：绘制和修改 CP，支持山谷线及辅助几何工具。
- **镶嵌构造**：参数化设计折纸镶嵌与纸模型。
- **折叠预览**：平折分析与三维数值预览。
- **折序绘图**：编排折叠步骤，导出图文 PDF。
- **本机文档**：工程管理、独立草稿和多种格式导入导出。

折痕编辑和折序绘图提供共享的“自适应线型”，帮助辨识复杂图案中的短山谷线；折序符号包含纸面局部放大与操作前后 CP 局部图。使用方式见[短折痕自适应线型](docs/短折痕自适应线型-20261019.md)及[圆形细节框](docs/折序拖角节点与圆形细节框-20261019.md)。

“局部放大”符号支持圆形与波浪线分区，从下一步开始自动放大并持续到“缩小视图”符号的下一步。操作与示例见[自动放大选区](docs/折序符号自动放大与波浪选区-20261019.md)。

工程与草稿保存在本地。

## 开发与打包要求

本目录使用 `npm run desktop:build` 进行开发构建，不生成安装包。启动脚本使用最新编译的宿主；当前端或宿主源码比构建更新时，会先构建对应部分，避免旧宿主缺少新功能接口。

正式发行仍须遵循[打包与体积控制要求](docs/打包与体积控制要求.md)中的完整功能、源码许可、调试归档、体积核验及真实验收要求，并补齐 Rust 对应源码与依赖许可。文档中的 Electron 专用命令及旧源码归档不能直接用于迁移版；日常开发不自动发布。
